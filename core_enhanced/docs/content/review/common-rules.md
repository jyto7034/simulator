## 공통 판정의 출발점

<a id="draft-시전과-비용"></a>
### 시전과 비용

기본 active는 최종 시전 수락 때 공명을 전부 소비한다. 미리보기 취소와 수락 전 거절은 소비하지 않고, 수락 후 중단은 원칙적으로 환불하지 않는다. 대상이 필요한 스킬은 수락 순간 대상의 존재와 자격을 확인한다. 다단계 조준은 최종 확정 전 준비 단계와 비용을 소비한 실행 단계를 구별한다.

공명 충전 재개 시점은 스킬 종류에 맞춘다. 즉시 효과는 처리 종료, 발사형은 발사 종료, 연속 공격은 마지막 공격 종료, 유지형 강화는 상태 종료, 집중형은 집중 종료를 기준으로 삼는다. 별도 장판·거미·지속 피해를 남기는 스킬은 생성 후 그 객체가 사라질 때까지 시전자 사용 상태를 유지하지 않는다. 충전량과 세부 조건은 [전투 공통 규칙](../../game_rules/combat.md)을 따른다.

Hello의 마무리처럼 같은 시전의 후속 입력은 새 공명 스킬과 구별한다. 여기에 추가 공명을 요구할지, 사용 중인 스킬을 다시 누르는지 등은 해당 기능의 입력 계약으로 명시한다.

<a id="draft-한-번의-시전과-여러-타격"></a>
### 한 번의 시전과 여러 타격

한 시전에는 여러 타격이 들어갈 수 있다. 나무꾼의 3타, 여러 거미의 폭발, 연속 탄환을 총 피해 한 번으로 합치면 방어막·피격 효과·실제 HP 손실·처치 귀속·다중타격 유물이 달라진다. 따라서 **연출을 단순화해도 의미 있는 타격 수는 유지하는 안을 기본으로 한다.**

각 피해에는 원래 시전, 직접 타격인지 파생 효과인지, 효과를 만든 직원과 장비·파편 사본을 남긴다. 적중, 보호막을 포함한 피해, 실제 HP 손실, 처치 확정은 서로 다른 조건이다. 어떤 효과가 이 중 무엇을 보는지는 개별 항목에서 정한다.

처치 효과는 죽음 확정 한 번을 기준으로 발생한다. 연쇄 효과가 자기 자신을 무제한 재발동하지 않도록 발생 세대·총 발생량·동일 대상 횟수 중 필요한 제한을 둔다. 모든 스킬에 임의의 동일 제한을 씌우는 뜻은 아니다.

<a id="draft-대상과-위치"></a>
### 대상과 위치

유닛 지정은 그 유닛을, 타일 지정은 그 위치를 고정한다. 지정한 적이 죽었다고 다른 적을 자동으로 선택하지 않는다. 매 타격 새 대상을 찾는 스킬은 그 동작을 명시해야 한다. 타일 폭발은 폭발 순간 그 위치의 적을 다시 조회하므로 원래 적이 빠져나가거나 새 적이 들어올 수 있다.

현재 위치를 따라가는 오라와 시전 위치에 남는 장판, 시전 시 한 번만 보호막을 주는 범위 지원은 서로 다른 기능이다. 이 구분만으로 여러 특수 스킬을 같은 형태로 작성할 수 있다.

<a id="draft-상태의-주인과-수명"></a>
### 상태의 주인과 수명

| 상태                          | 소유와 초기화 기준                                           |
| ----------------------------- | ------------------------------------------------------------ |
| 연타 번호·이번 시전의 처치 수 | 한 시전의 실행 기록. 다른 시전과 합치지 않음                 |
| 감염·냉기·개인 방어막         | 대상과 효과 출처. 같은 종류라도 사본별 분리가 필요한지 명시  |
| 거미·장판·발사된 탄환         | 독립 효과. 시전자 이탈 이후 유지 여부를 명시                 |
| 이번 전투의 포만·희생 단계    | 전투 또는 직원의 전투 기록. 재배치를 새 전투로 취급하지 않음 |
| 욕망·발사 횟수 등 원정 누적   | 파편 사본의 원정 기록. 해제·교체만으로 초기화하지 않음       |

재배치된 직원의 새 전투 객체와 동일 직원의 누적 기록을 혼동하지 않는다. 모든 전투 시간은 일시정지 영향을 받는 전투 시계로 계산한다. 원정 상태는 전투 후퇴·체크포인트 복구 시 다른 소비와 함께 일관되게 되돌린다.

<a id="draft-중단과-연출"></a>
### 중단과 연출

강한 행동 제어는 아직 방출하지 않은 동작을 취소할 수 있지만, 이미 발사한 독립 탄환까지 일괄 삭제하지 않는다. 침묵은 신규 시전 차단과 기존 집중 중단을 구별한다. HP 지불은 피해가 아니므로 피격·흡혈·반격 효과를 만들지 않는다.

거대한 도끼나 늑대 입, 여러 조준창, 거미의 도약은 표현 계층에서 그릴 수 있다. 다만 실제 지연·이동·범위 변경이 플레이에 영향을 주면 그 정보는 전투 판정에 있어야 한다. 직원의 돌진 연출을 실제 타일 이동으로 자동 해석하지 않는다.

<a id="draft-에고-침식"></a>
### 에고 침식

침식은 아래 개별 스킬 조립안을 확대 복사하는 방식보다 공통 처리와 고유 연출로 나누는 편이 맞다. 현재 공통안은 일반 침식체를 즉시 처치하고, 엘리트·일반 보스·최종 보스에는 최대 HP 25% 피해를 초기 검증값으로 사용한다. 보호막·무적·페이즈 하한과 필수 전환은 정해진 규칙을 따른다. 침식으로 장비·유물·파편의 처치 연쇄나 적 사망 효과를 발생시키지 않는다.

직원 대가와 피해 처리의 상세는 [에고 침식 경계](../../game_rules/relics.md#%EC%97%90%EA%B3%A0-%EC%B9%A8%EC%8B%9D%EA%B3%BC%EC%9D%98-%EA%B2%BD%EA%B3%84)를 따른다. 과거 개별 노트의 전장 전체 처형 문구를 그대로 새 구현 요구로 옮기지 않는다. 아무 것도 없는의 미정 침식 연출 등은 여기서 새로 확정하지 않는다.

<a id="draft-재사용할-동작과-남겨둘-고유-기능"></a>
## 재사용할 동작과 남겨둘 고유 기능

다음 이름은 설계를 설명하는 말이며 실제 데이터 문법이나 완성된 API 이름이 아니다.

| 공통 동작                          | 조합 예                                                       |
| ---------------------------------- | ------------------------------------------------------------- |

| 단일·범위·직선 피해와 회복         | 회사 스킬, 음양 장판, 증오 광선, 풍운승려                     |
| 상태 부여·교체·제거                | 강화, 둔화, 속박, 다음 평타 강화, HP 하한                     |

| 타격 결과 집계                     | 실제 회복량 방어막, 실제 HP 손실 흡혈, 처치 수 보상           |
| 개인 보호막과 범위 지원            | 포큐버스의 일회 부여, 태아의 유지 오라                        |

이 기반의 상당 부분은 이미 구현되어 있다. 순서·분기·반복, 독립 객체, 개인 보호막·지원 효과, 일부 사망·처치 반응을 사용할 수 있다. 다만 기반 기능이 존재하는 것과 아래 모든 스킬이 제작·검증되었다는 것은 다르다. 구체적인 작성 형태는 [스킬 제작 모델](../../skills/skill_authoring_model.ko.md)의 구현된 범위와 대조해야 한다.

고유 기능 후보는 여러 창의 조준 세션, 계약 예산, 방향을 물려받는 분기 탄환, 거미의 동시 예약처럼 **상태 전이 자체가 특수한 부분**이다. 완성된 고유 기능도 설정을 받아 다른 콘텐츠가 재사용할 수 있게 만들되, 내부의 모든 단계를 범용 작성 문법으로 노출할 필요는 없다.

<a id="draft-태그를-적용하는-기준"></a>
## 태그를 적용하는 기준

태그는 [기초 태그 초안](../tags/README.md#rel-%EA%B8%B0%EC%B4%88-%ED%83%9C%EA%B7%B8-%EC%B4%88%EC%95%88)의 한글 이름을 사용한다. 아래 적용표는 이 조립안에 대한 **설계 후보**이며 정식 tag ID·데이터 등록·runtime 지원을 확정하지 않는다. 새 태그를 임의로 늘리기보다 기존 태그와 세부 속성을 함께 사용한다. 사용자 첨삭에서 추가로 지정한 표기는 해당 카드에 출처와 등록 상태를 따로 적는다.

<a id="draft-분해-축과-태그의-역할"></a>
### 분해 축과 태그의 역할

기존 [15개 분해 축](../principles/effect-review.md#rel-15%EA%B0%9C-%EA%B3%B5%ED%86%B5-%EB%B6%84%ED%95%B4-%EC%B6%95)은 효과를 검토하는 질문이다. 각 카드의 조립 순서·상태·검토 사항과 아래 태그표를 함께 읽는다. 축의 이름을 그대로 태그로 만들지는 않는다.

| 검토할 축                                          | 이 초안에서 기록하는 내용                                |
| -------------------------------------------------- | -------------------------------------------------------- |
| 1 사용·조작, 2 대상·선정, 3 공간, 4 전달·매개      | 입력과 대상 고정, 범위, 실제 투사체·독립 효과 여부       |
| 5 시간, 6 반복·발생, 7 효과 종류                   | 지연·주기·타격 순서와 각 단계의 효과 태그                |
| 8 효과량·참조, 9 집계·분배·공유                    | 계수와 계산 시점, 실제 타격·회복량, 개인량과 공유량 구분 |
| 10 자원·축적, 11 비용·위험, 12 조건·분기·연계      | 스택·소비, HP 비용, 발동 사건·조건과 유물 연결           |
| 13 행동 병행·제약, 14 종료·존속, 15 출처·소유·귀속 | 집중·중단, 만료·이탈, 직원·파편 사본·효과별 출처         |

아래 표의 `변경 후보 속성`은 유물 설계에서 검토할 지점이다. 해당 속성을 공개 편집 기능으로 이미 지원한다거나 아무 유물이나 바꿔도 된다는 뜻은 아니다. 지원 가능한 속성과 수정 범위는 제작 단계에서 확인한다. 값이 미정인 것은 그대로 미정이며, 해당 없는 기능은 태그만으로 새로 만들지 않는다.

<a id="draft-효과-단위-선택과-출처"></a>
### 효과 단위 선택과 출처

- 한 행은 하나의 효과 또는 명시된 공격 순서·영역이다. `·`로 묶은 태그는 그 단위에 함께 적용한다. 다른 행의 태그를 합쳐 조건을 만족시키지 않는다.
- 범위 피해 뒤 자기 회복은 `피해·범위`와 `회복` 두 효과다. 피해 범위를 늘려도 회복 대상은 늘지 않는다.
- `소환물`은 설치물·타일 축적·잔류 영역을 포함한다. HP·이동 AI가 필수는 아니다. 반면 일벌·썰매·늑대 입의 그림만으로 부여하지 않는다.
- 소환물 피해를 고르는 유물은 **생성물과 후속 피해의 관계**를 확인한다. 파편 전체에 `소환물·피해`를 붙이거나, 무관한 피해와 설치 효과를 합쳐 판정하지 않는다.
- `다중타격`은 스킬의 구분된 직접 타격 순서다. 지속 피해의 반복, 한 광역 공격의 여러 대상, 한 타격의 여러 피해 성분은 자동 포함하지 않는다. 독립 거미·분기 탄환처럼 경계에 있는 효과는 별도 판정한다.
- 공격 순서·영역과 실제 피해·회복을 나누어 적은 표는 그 연결도 제작 정의에 기록해야 한다. 특히 다중타격용 유물이 선택하는 실제 직접 피해 효과에 필요한 태그를 명시한다. 별도 행의 태그를 조회 과정에서 무조건 합치거나 타격 수만 보고 엔진이 자동 추론하게 하지 않는다.
- `집중유지`는 실제 행동 제한이 있는 집중이다. 기간형 자기 강화와 조준 화면의 시간 정지는 포함하지 않는다. `투사체`도 실제 충돌·전달 방식이 있는 경우에만 쓴다.
- HP 지불은 `피해`, 능력치 상한 조정은 `회복`, 적중 후 정량 회복은 `흡혈`로 바꾸지 않는다. 처형·계약·변신은 기존 태그만으로 설명이 부족하면 고유 동작과 속성으로 남긴다.

### 유물 조건과 조합

범용 유물은 같은 효과의 태그·세부 속성과 실제 출처 조건을 확인한다. 전용 유물은 지정 파편·장비·기본형/개화형까지 확인하며 일반 태그만 같다고 적용하지 않는다. 새로운 효과에도 태그와 출처를 붙여 다른 유물과 조합할 수 있다.

각 카드의 `유물 연결`은 **기존 설계**와 **새 후보**를 구분한다. 기존 설계도 이름·수치·세부 조건이 미정이면 그 상태를 유지한다. 태그가 호환 후보라는 것만으로 해당 유물의 출시나 현재 구현을 확정하지 않는다.

유물 활성은 현재 실제 효과와 무조건 제공되는 효과에서 시작한다. 서로의 조건만 만들어 주는 유물끼리 스스로 활성화하지 않는다. 장비 변경으로 시작점이 사라지면 다시 평가한다. 전투 중 연쇄는 같은 경로에서 같은 유물 사본의 같은 효과로 되돌아가지 못하며, 분기·합류는 원인 기록을 이어받는다. 모든 효과에 공통 연쇄 횟수 상한을 새로 붙이지 않는다. 에고 침식은 공통 유물 증폭·추가 효과·연쇄에서 제외한다.
