#### 침식형 공통 정책

모든 환상체의 침식형은 **필드의 적을 일괄 처형하는 하나의 형태**로 통일한다. 환상체마다 다른 것은
연출과 서사적 근거뿐이고 게임플레이 결과는 같다.

바리에이션을 두지 않는 이유는 제작 리소스다. 침식은 같은 환상체 파생 4종 보유, 트라우마 임계치,
공명 만충과 명시적 입력이 모두 필요한 최후 수단이라 한 run에서 발동 횟수가 극히 적다. 환상체마다
다른 규칙을 설계하고 구현하고 검증하는 비용이 그 빈도에 비해 크다.

따라서 각 환상체의 침식형 항목에는 **연출 시퀀스만** 기재하고 별도 문법이나 예외 규칙을 만들지
않는다.

공통 open design:

- 처형의 판정. 즉사인지 대미지인지
- 대상 범위. 환상체, 보스급, 공중 유닛과 소환물을 포함하는지
- 연출 동안 battle tick을 정지하는지와 그 정지의 계약
- 처형한 유닛을 처치로 세는지, 도감·보상·파편 trigger에 반영하는지

<a id="frag-역할-분포"></a>
#### 역할 분포

파편은 `딜` / `힐` / `탱` 세 역할로 나눈다. 저지와 제어는 별도 축으로 두지 않고 딜 또는 탱 파편의
부가 효과로 표현한다. 공개 최종 보스 3종과 숨겨진 최종 보스 `흉탄의 사수`는 독자적 특징을 우선하므로
이 분포에서 제외한다.

| | 딜 | 힐 | 탱 | 계 |
| --- | --- | --- | --- | --- |
| 엘리트 | 8 | 1 | 2 | 11 |
| 일반 보스 파편 — 흉탄 제외 | 10 | 2 | 1 | 13 |

위 일반 보스 파편 행은 기존 역할 검토 범위로, 흉탄을 제외한 획득 가능 파편 identity 수를 센다.
일반 보스 계열의 선행 조우 포함 13개 항목과는 집계 기준이 다르며, 흉탄의 최종 보스 정정만으로 파편 역할 수치를 바꾸지 않는다. 녹아내리는 사랑은 일반 승리의
탱커 파편과 퍼펙트 승리 선택에 추가되는 딜러 파편 두 identity를 가지므로 딜과 탱에 각각 한 번
포함한다.

**왜 이 비율인가**

초반은 디펜스지만 보스를 격파하기 시작하면 딜로 밀어붙이는 핵앤슬래시로 옮겨간다. 엘리트 파편이
초중반 주력이므로 회복·방어 역할도 배정하고, 보스 파편은 딜에 몰아 후반의 화력전을 만든다.
허수아비를 원거리 딜러로 전환하면서 현재 엘리트 분포는 `딜 8 / 힐 1 / 탱 2`가 되었으며,
초중반 회복 편성의 충분성은 후속 검증 과제로 남긴다.

엘리트 배정은 run seed 기반 결정론 순서로 미숙달 pool에서 뽑히므로 플레이어가 만날 엘리트를 고를 수
없다. 엘리트 풀의 절반 정도를 돈 뒤 보스에 도전하는 것이 의도한 진행이므로 **11종 중 어느 6종을
얻어도 편성이 서야 한다.** 11종 중 6종을 얻을 때 특정 역할을 하나도 얻지 못할 확률은 아래와 같다.

| 그 역할의 종 수 | 놓칠 확률 |
| --- | --- |
| 1 | 45% |
| 2 | 18% |
| 3 | 6% |
| 4 | 1.5% |

현재 엘리트 힐 파편은 여왕벌 1종이라 6종 획득 시 하나도 만나지 못할 확률이 약 `45%`다. 엘리트의 원본 스킬을
억지로 회복기로 바꾸지 않고, Run 유물·회복 장비와 실제 런 실패율을 함께 본 뒤 힐 파편 수를 늘릴지
판단한다. 저지는 무기의 `block_capacity`가 단독으로 결정하므로 탱 파편이 없어도 저지 편성 자체는
선다.

**엘리트 배정 초안**

아래 표는 현재 11종의 배정 초안이다. 원본 스킬 모방을 우선하고, 전체 상세 설계와 실제 런 검증이
끝난 뒤 역할 분포를 다시 조정한다.

| 역할 | 환상체 | 근거 |
| --- | --- | --- |
| 힐 | 여왕벌 | 감염 타일을 남기고 아군은 포자에 감염되지 않는다. 아군이 밟으면 회복되는 타일로 뒤집는다 |
| 탱 | 흑조의 꿈 | 상시 피해 감소·확률 반사와 수동 패링. Run 유물은 막아낸 피해를 축적해 패링 성공 시 방출한다 |
| 탱 | 포큐버스 | 시전 순간 범위 내 아군마다 독립 방어막을 부여하는 포자막. 각자의 잔량으로 흡수하고 초과 피해는 전달한다 |
| 딜 | 눈의 여왕 | 근접 범위기와 전방 강공격. 단일 빙결은 부가 효과 |
| 딜 | 샤덴프로이데 | 일정 시간 HP 1 생존 보장과 공격력·공격 속도·방어력 강화로 공격을 이어간다. 시간 비례 공격력 누적은 액세서리가 담당한다 |
| 딜 | 풍운승려 | 범위 Physical 염주 Staff와 아귀 형상의 광역 물어뜯기 버스트. 적중 시 1회 자기 회복은 부가 생존 |
| 딜 | 썰매의 루돌타 | 기본 공격과 병행하는 유한 횟수 선물 연속 폭격. 플레이어 직원 자체를 공중 유닛으로 바꾸지는 않는다 |
| 딜 | 이름이 없는 태아 | 웨이브 가속 울음을 아군 가속으로 뒤집는다 |
| 딜 | 따뜻한 마음의 나무꾼 | 빠른 2타 뒤 강력한 마무리를 내리꽂는 순수 도끼 버스트 |
| 딜 | 래티씨아 | 배치한 작은 마녀의 친구를 같은 타일 중첩으로 진화시키고 유물로 연결하는 소환 누커 |
| 딜 | 지혜를 구하는 허수아비 | 저격총의 다음 기본 공격을 헤드샷으로 강화하고, 그 공격으로 처치하면 공격력 +20~30%의 지혜 획득 |

여왕벌과 이름이 없는 태아는 원작 성격을 뒤집은 배정이라 근거가 약한 편이다. 상세 설계에서 원본
스킬 모방이 더 자연스러운 역할이 드러나면 역할별 종 수도 함께 다시 계산한다.

**보스 배정**

| 역할 | 환상체 |
| --- | --- |
| 힐 | 증오의 여왕, 음/양 |
| 탱 | 녹아내리는 사랑 |
| 딜 | 녹아내리는 사랑의 퍼펙트 선택 파편, 절망의 기사, 죽을 나비의 장례와 나머지 7종 |

**역할은 파편과 무기를 함께 본다**

배치 구역과 저지 수는 `weapon_profile`이 단독으로 소유하고 파편은 그 위에 얹히는 스킬이다. 위 표의
역할은 파편 자체가 제공하는 전투 기여를 세며, 파편이 무기의 archetype, `deployment_affinity`나
`block_capacity`를 암묵적으로 바꾼다는 뜻이 아니다. 녹아내리는 사랑의 딜러 파편도 포자 감염과
기폭을 제공할 뿐 장착한 Shield를 원거리 무기로 바꾸지 않는다. 실제 loadout 역할 분포를 맞출 때는
파편 compatibility와 무기 archetype·배치 affinity를 함께 본다.
