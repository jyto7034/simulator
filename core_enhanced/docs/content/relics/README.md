# 유물 목록

[콘텐츠 위키](../README.md) · [태그 사전](../tags/README.md) · [발동·출처·연쇄](../principles/relic-effects.md)

**유물은 적용할 태그와 그 태그에 대한 변경 규칙을 묶은 단위다.** 이름은 유물을 식별하며 태그가 아니다.
2026-10-20 이름과 적용 계약을 정리했다. 효과·수치의 합의·후보·초안 상태와 미정 판정은 유지한다.
최신 합의가 있는 유물을 수록한다. 미채택 유물 제안은 아카이브에서 확인한다.

선행 유물·효과 조건·상호 보완·비호환·중복 제한은 [공통 유물 규칙](../../game_rules/relics.md#선행-유물)과
[관계 작성 기준](../principles/relics.md#유물-관계-작성-기준)을 따른다. 선행 관계는 개별 유물에 명시하며,
기존 조합 추천을 자동으로 필수 장착 조건으로 바꾸지 않는다. 세트 효과는 미도입이다.

## 대상 태그와 변경 규칙

| 유물 | 대상 태그 | 변경 규칙 |
| --- | --- | --- |
| [깨어난 흑조](awakened-black-swan.md) | `피해감소` · `패링` | 상시 감면으로 막은 피해를 축적하고 패링 성공 시 전량 소비해 추가 피해로 방출한다. |
| [승천의 징표](yin-yang-dragon.md) | `시전` · `범위` | 음·양을 같은 중심에 지정하면 지속 지원을 용 1회 출현으로 전환한다. 영역 안 아군·침식체는 즉사, 환상체·보스는 최대 HP 25% 피해 후 종료한다. |
| [깊은 쐐기](deep-wedge.md) | `다중타격` · `피해` | 같은 시전·같은 대상의 직접 적중마다 해당 타격 피해 +2%p, 최대 +20%. 첫 타격부터 +2%를 적용한다. |
| [꿰뚫는 송곳](piercing-damage-increase.md) | `관통` · `피해` | 한 공격이 앞의 적을 관통할수록 뒤이어 맞히는 적의 피해를 높인다. |
| [아직 남은 선물](red-thread.md) | `소환물` · `피해` | 거미 적중 시 선물 10초를 부여하고, 선물 대상 사망 시 작은 친구 1마리를 생성한다. 새 친구도 선물을 부여한다. |
| [관통상](little-red-puncture-wound.md) | `투사체` | 탄환 적중 시 관통상 1스택을 부여하며 스택당 탄환 피해를 30% 높인다. |
| [슬러그탄](little-red-slug-round.md) | `투사체` | 탄환에 밀어내기와 기절을 연결한다. |
| [소이탄](little-red-incendiary-round.md) | `관통` · `투사체` | 탄환이 적을 관통할 때마다 별도 폭발 피해를 만든다. |
| [중첩된폭발](overlapping-explosions.md) | `폭발` | 겹치는 별개 폭발 사이의 동일 대상 피해 횟수 제한을 해제한다. |
| [압축 화약](explosion-vulnerability.md) | `폭발` · `피해` | 가하는 폭발 피해를 증가시킨다. |
| [검은 고치](funeral-butterfly-orb.md) | `스택` · `폭발` | 이번 기폭의 나비 스택이 기준 이상이면 기존 폭발을 중앙의 강력한 구체 폭발 1회로 전환하고 모은 스택을 소비한다. |
| [왕의 위압](king-of-greed-stunning-treasures.md) | `피해` · `범위` | 보구의 범위 피해에 맞은 적에게 기절을 부여한다. |
| [끝없는 금고](king-of-greed-endless-treasury.md) | `시전` · `집중유지` · `스택` | 최대 HP 5%를 매초 직접 지불하며 재고 소비 없이 보구를 무한 사출한다. 수동 종료 전 시간 제한이 없고 회수 패시브·빚은 유지한다. |
| [사냥의 낙인](summon-vulnerability.md) | `소환물` · `피해` | 소환물로 피해를 준 대상에게 5초간 받는 피해 증가를 부여한다. |
| [깨진 균형](broken-balance.md) | `제어` | 강력한 군중제어를 가한 대상에게 5초간 받는 피해 증가를 부여한다. |
| [도전자의 갑주](taunted-enemy-damage-reduction.md) | `제어` | 착용자가 자신이 도발한 적에게 받는 피해를 감소시킨다. |
| [응징의 표식](taunted-enemy-basic-attack-boost.md) | `제어` · `피해` | 자신이 도발한 적에게 가하는 직접 기본 공격 피해를 높인다. |

| [온기의 성배](healing-increase.md) | `회복` | 착용자가 가하는 회복량을 25~40% 증가시킨다. |
| [축적의 문장](beneficial-stack-attack.md) | `스택` · `능력치` | 현재 보유량이 가장 많은 이로운 스택 한 종류의 수에 비례해 공격력을 높인다. |
| [겨울의 유언](snow-queen-remnant.md) | `제어` | 착용자 출처의 냉기 또는 혹한 상태인 적이 사망하면 잔영 하나를 생성한다. 다른 아군 처치도 인정하며 잔영 폭발·파생 피해의 처치는 제외한다. |
| [오롯한 축복](single-target-conversion.md) | `범위` · `대상선정` | 여러 아군에게 주는 범위 지원을 단일 아군 지원으로 바꾸고 해당 효과량을 크게 높인다. |
| [긴 호흡](long-breath.md) | `지속시간` | 유한한 효과 유지 시간을 25% 늘린다. |

| [원경의 렌즈](distant-lens.md) | `피해` | 적이 아군에게 피격될 때, 피해를 가한 대상과 멀수록 받는 피해를 늘린다. 수치·거리 판정은 후속이다. |
| [핏빛 결의](missing-hp-attack.md) | `능력치` | 착용자의 잃은 체력 비율에 비례해 공격력을 높인다. |
