## 효과와 출처

탄환의 직접 피해와 관통 시 발생하는 유물 출처 폭발 피해는 구별한다. 현재 효과는 폭발이며
소이탄이라는 이름만으로 화상·지속피해·지속영역을 추가하지 않는다. 개화형은 보류 상태다.

## 남은 결정

- 폭발 피해량·피해 유형·참조 능력치·반경·공중 대상·아군 피해 여부.
- 관통당 폭발의 정확한 발생 위치와 시점, 최초 관통 대상도 폭발에 맞는지.
- 한 탄환·한 대상의 반복 관통, 여러 폭발의 중첩, 추가 피해와 연쇄 발동의 인정 범위.
- 관통상 증폭과 슬러그탄의 조건부 관통에 대한 결합 판정.

### 2026-10-22 공통 그래프 작성 정책

통상 정책 위임에 따라 직접 피해·상태·밀어내기 뒤 탄환이 계속 비행하는 실제 관통마다 적중 당시 중심에서 별도 폭발을 한 번 처리한다. 적중 한도 소진으로 소멸한 마지막 탄환은 관통하지 않은 것으로 본다. 폭발 시 생존 적에게 한 번씩 피해를 주며 원래 관통 대상도 살아 있으면 포함한다. 아군은 제외하고 공중 포함·피해 유형·위력·범위는 명시적 미정 작성값이다. 서로 다른 관통 폭발은 중복 적중할 수 있다. 유물 출처 파생 피해이며 관통상 증폭·표식·기절·추가 관통/폭발을 재귀 발동하지 않는다.

이 절은 공통 선언의 작성 의미다. 실제 Core 실행 검증은 별도로 기록한다.
