## 현재 효과 — 아직 남은 선물

**거미 공격에 맞은 적에게 10초간 선물을 부여하고, 선물을 가진 적의 사망 위치에 작은 친구 1마리를 만든다.**

| 사건 | 처리 |
| --- | --- |
| 작은·큰·특별한 친구의 공격 적중 | 맞은 적 각각에게 선물 10초 부여 |
| 선물 재부여 | 중첩 없이 남은 시간을 10초로 갱신 |
| 선물을 가진 적 사망 | 처치한 아군과 무관하게 사망 위치에 작은 친구 1마리 생성 |
| 거미 공격으로 즉사 | 선물 부여 후 사망 처리하여 생성 대상에 포함 |
| 생성된 친구의 공격 | 다시 선물을 부여할 수 있음 |
| 적이 없는 위치에 생성 | 대기. 설치 위치 기준 1칸 안에 적이 있으면 도약·폭발 |

큰·특별한 친구가 선물을 부여했어도 사망 시 생성하는 것은 작은 친구 1마리다. 부모의 크기나 합체 수를 복제하지 않는다.
직접 시전의 인접 추가 배치는 사망 생성에 적용하지 않는다.
여러 적이 동시에 사망하면 **거미 생성 → 같은 타일 합체 → 공격 대상 탐색** 순서로 처리한다.
작은 친구 2마리분은 큰 친구, 3마리분 이상은 특별한 친구가 되며 [파편의 합체 규칙](../abnormalities/laetitia/fragment.md)을 따른다.

## 효과 출처와 범용 유물

선물 표식에는 지속시간, 사망 생성에는 소환물, 생성된 친구의 공격에는 피해·폭발·범위 태그를 각각 부여한다.
하나의 효과가 모든 태그를 동시에 가진 것으로 합치지 않는다. 선물은 중첩 스택이나 제어 상태가 아니다.
유물로 생성·합체한 친구의 출처를 보존하면서 해당 조건을 만족하는 압축 화약·넓어진 지평·사냥의 낙인을 적용한다.
긴 호흡은 선물 유지 시간만 10초에서 12.5초로 늘리며, 대기 수명·감지 거리·도약 시간을 함께 늘리지 않는다.

**이 유물은 새 세대의 친구가 선물을 다시 부여하는 연쇄를 명시적으로 허용한다.**
단계마다 새 적중과 선물을 가진 적의 사망이 필요하며, 한 적의 사망을 같은 선물로 반복 소비하지 않는다.
이는 [공통 순환 차단](../principles/relic-effects.md)에 대한 이 전용 효과의 명시된 예외다. 다른 유물의 무조건 재귀 발동을 허용하지 않는다.

## 제외와 후속 판정

붉은 실타래의 거미줄 연결·교차 감지·연결망 소비와 가로·세로·포위·추격 기믹은 사용하지 않는다.
기본 파편은 유물이 없어도 배치·합체·공격을 완결한다. 다른 파편의 소환물에 선물을 자동 확장하지 않는다.

증가 피해·크기별 범위·특별한 친구의 2배 범위 기준, 대기 수명·동시 수·누적 상한,
여러 직원이 부여한 선물의 귀속과 생성 수, 피해 0·보호막 적중의 인정,
사망 타일의 지형·점유·생성 가능 조건, 합체 소유권·능력치 참조와 도약 중 표적 처리는 후속이다.
거리 유물과의 연결 및 서로 다른 폭발의 중복 피해도 별도 미정이다.
