## 효과와 적용 경계

자신이 얻는 해당 스택량을 2배로 늘린다.

검·하트·강화 창·시체 질량·보구 회수 등 각 합의에서 지정한 획득 사건. 초기 지급·대여는 자동 포함하지 않음.

기존 합의의 변경 기능을 이름 있는 유물로 분리했다. 태그 정리를 이유로 다른 파편의 호환이나 새로운 수치·효과를 추가하지 않는다.
