## 조건과 적용

- 현재 자신의 도발이 적용된 적에게 가하는 기본 공격 피해를 강화한다. 다른 아군의 도발이나
  단순한 표적 선택만으로 적용하지 않는다. 여러 적을 공격하면 대상마다 조건을 확인한다.
- 기본 공격 출처를 유지하는 공격 교체도 같은 자격으로 검토한다. 독립 스킬 피해·지속 피해·반사·
  장비 proc를 기본 공격으로 바꾸지 않는다.
- 원래 기본 공격의 피해를 증폭한다. 추가 공격·처형·기절·받는 피해 증가 디버프를 만들지 않는다.
- 도발 관계가 끝나면 해당 조건의 강화도 끝난다. 기본 공격 주기·사거리·저지 수는 변경하지 않는다.

## 웃는 시체의 산 적용

무기 웃음의 주 대상 타격과 기본 공격에 속하는 주변 충격파에서, 각 대상이 자신의 도발에 걸렸는지
확인해 피해를 강화한다. 한 공격의 주 대상과 부 대상이라는 구분은 유지한다.

주 대상 기본 공격으로 막타를 냈을 때만 기존 규칙대로 시체 질량을 얻는다. 강화된 충격파로 부 대상을
처치해도 성장 자원을 얻지 않으며, 이 유물이 성장량을 직접 늘리지 않는다. 획득량 2배는 별도로
선택한 스택획득 연결이다. 다른 호환 무기에는 그 무기의 기본 공격과 기존 처치 규칙을 사용한다.

## 후속 조정

증가율·희귀도·중복 장착, 다른 기본 공격 증폭과의 계산, 도발 교체·해제·면역과 공격의 참조 시점은
후속 판정이다. 다른 도발 출처의 구체적인 호환도 별도로 검토한다. 깨진 균형과는 별개의 효과다.
