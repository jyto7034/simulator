## 검은 고치 — 죽나장 전용 유물, 설계명 지정

> 상태: 2026-10-19 조건부 구체 전환 구조 합의 / 기준 스택·위력·범위·연출 시간·세부 판정 미정

개화형 시전 시 이번 기폭의 총 나비 스택이 기준 이상이면 전투를 일시정지하고 나비를 전장 중앙으로 모아 구체를 만든다. 구체가 빛을 방출해 강력한 광역 피해를 준 뒤 전투를 재개한다.

| 항목 | 내용 |
| --- | --- |
| 호환 | 죽을 나비의 장례 개화형 전용 |
| 발동 조건 | 이번 기폭에 참여하는 총 나비 스택이 기준 이상 |
| 효과 태그 | 피해 · 범위 · 폭발 |
| 탐색 분류 | 전용 전환 |
| 희귀도 | 미정 |

## 조건과 전환

1. 시전할 때 이번 기폭에 참여하는 타일의 나비와 살아 있는 적의 나비 스택을 합산한다.
2. 기준 미만이면 원본의 타일별 계단식·등급별 연속 폭발을 사용한다.
3. 기준 이상이면 전투를 일시정지하고, 타일과 살아 있는 적의 나비가 중앙으로 모여 구체를 형성한다.
4. 구체가 빛을 방출해 하나의 강력한 광역 폭발을 일으킨 뒤 전투를 재개한다.

전환은 이번 시전의 기존 폭발을 대체한다. 일반 폭발을 실행한 뒤 구체를 추가로 발사하는 효과가 아니다.
구체에 모은 스택은 소비하며, 일반 등급별 폭발의 스택 소비 방식까지 이 규칙으로 확정하지 않는다.
살아 있는 적의 나비도 포함하므로 잡몹 사망 타일이 없어도 보스에 축적한 나비로 조건을 만족할 수 있다.

구체 위력은 모은 스택에 따라 증가한다. 전환으로 기존 연속 폭발보다 불리해지는 구간이 없도록
후속 수치를 조정하며, 지금 피해량·공식·기준 스택을 임의 확정하지 않는다.

## 다른 유물과의 관계

- [압축 화약](explosion-vulnerability.md): 구체 폭발 피해 증가를 적용한다.
- [중첩된폭발](overlapping-explosions.md): 구체는 하나의 폭발이므로 추가 효과가 없다. 큰 적에게도 한 번 적중한다.
- 깊은 각인: 전용 무기의 `스택부여` 사건에서 나비 부여량 2배. 구체로 모으는 과정에서 다시 증폭하지 않는다.
- [넓어진 지평](widened-horizon.md): 구체의 피해 범위와 적용 방식은 후속 판정이다.

전장 중앙은 구체가 형성되는 연출 위치다. 광역 피해의 구체 범위·대상과 나비 이동 경로에 따른
판정은 미정이며, 중앙 이동을 새로운 피해·나비 생성으로 자동 취급하지 않는다.

## 후속 조정

기준 스택, 피해 계수·타입·스택 환산·상한, 범위와 대상, 연출 시간, 시전자 이탈·취소·중복 시전·
전투 종료 시 처리, 여러 착용자·사본의 스택 소유권과 소비 시점, 유물 등급·획득을 정한다.
일시정지 연출의 세부 처리와 저장·복구 계약은 구현 단계에서 확정한다. 이 문서는 구현 완료를 뜻하지 않는다.
