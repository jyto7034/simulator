## 왕의 위압

> 상태: 2026-10-20 탐욕의 왕 전용 유물 채택. 효과 구조 합의, 밸런스는 후속.
> 등급·기절 시간·세부 판정 미정. 구현 완료를 뜻하지 않는다.

**탐욕의 왕이 사출한 보구의 범위 피해에 맞은 적에게 기절을 부여한다.**

- 호환: **전용**. 탐욕의 왕 파편의 보구 사출.
- 효과: 보구의 범위 피해에 맞은 적에게 기절을 부여한다.
- 효과 태그: **제어 · 지속시간**. 보구의 피해·범위·투사체와 별도 효과로 분류한다.

| 항목 | 내용 |
| --- | --- |
| 발동 조건 | 보구의 범위 피해 적중 |
| 적용 대상 | 주 표적과 범위에 함께 맞은 적 |
| 지속 시간 | 후속 조정 |
| 적용 형태 | 일반 황금의 지평선 및 체력 소모 무한 사출 |

회수 패시브가 어떤 출처의 피해에도 적용되는 것과 달리, 이 유물은 보구 사출에 기절을 붙인다.
황금 장궁의 일반 공격이나 모든 장비 파생 피해에 자동으로 기절을 추가하지 않는다.

[끝없는 금고](king-of-greed-endless-treasury.md)과 함께 장착할 수 있다. 한 보구의
범위 피해·회수 상태·기절·사망 판정을 마친 뒤 다음 보구의 표적을 고르는 순서를 유지한다.

기절의 시간·갱신·중첩·면역과 보스 적용, 연속 사출 시 제어 유지 정도는 밸런스 단계에서 정한다.
이번 합의에 깨진 균형을 자동 추가하지 않으며, 긴 호흡의 기절 시간 추가 연결도 후속 검토다.


### 2026-10-22 공통 그래프 작성 정책

보구 직접 피해 뒤 살아 있는 각 적에게 공통 `타격 뒤 상태` 기절을 적용한다. 유효 적중이면 보호막만 감소하거나 HP 피해가 0이어도 제어 면역·저항을 따로 검사한다. 같은 출처는 남은 시간과 새 시간 중 큰 값으로 갱신한다. 기존 회수·사망·기절 처리가 모두 끝난 뒤 다음 표적을 고른다. 정확한 기절 시간은 미정이며 긴 호흡·깨진 균형을 새로 연결하지 않는다.

이 절은 공통 선언의 작성 의미다. 실제 Core 실행 검증은 별도로 기록한다.
