# 마탄의 사수 · 검토·이전 기록

[콘텐츠 위키](../../README.md) · [개요](README.md) · [조우](encounter.md)

> 검토·이전 기록. 각 절의 합의·제안·대체 여부를 구분하며, 현재 설계는 연결된 본문을 우선한다.

현재 조우는 [조우 페이지](encounter.md)에서 확인한다. 아래 기록의 내용을 현재 파편에 자동으로 합치지 않는다.


<a id="source-enc-1373-1378"></a>
> **이전 문맥 보존:** 조우 문서의 파편 요약은 상세 파편 설계와 구분하여 보존

<!-- wiki-source:enc-1373-1378 begin -->
## 스킬 파편 능력:

- 직선 관통 마탄 파편. 사선 위 적을 관통할수록 피해가 커지는 직선 스킬로, route를 따라 줄지어 오는 적에게 강력하다.
- 마탄의 최초 조우에서 보여 준 사격은 이후 흉탄의 사수 보상 세트의 마탄 저격총 형태와 같은 시각 언어를
  사용해 흉탄의 사수와 보상의 단서가 된다.
