## 여왕벌

> 상태: 아군 한 명에게 일벌을 저장하고 조건 충족 시 대상 최대 HP 비례 회복을 제공하는 반응형 힐
> 파편, Platform 다중 회복 Staff·전투 시작 벌집 장벽 방어구·회복 대상 공격 속도 액세서리 구조 합의 /
> 일벌 수·사용 조건과 이름·세부 수치·판정 미정

조우 설계는 `abnormality_design_notes.ko.md`의 `여왕벌` 절이 소유한다. 조우의 감염 타일,
`잠재적 변이체`와 적 사망 시 변이는 플레이어 파편에 복제하지 않는다. 녹아내리는 사랑의 감염·전염
딜러와 역할이 겹치지 않도록, 원본의 `대상에게 무언가를 심고 일벌이 나타나는` 이미지만 아군 회복으로
뒤집는다.

### 전용 조합과 독립성

- 파편은 다른 `Staff`와 조합해도 선택한 아군에게 왕실의 벌집을 부여하고 일벌 회복을 완결한다.
- 여왕의 지휘봉은 다른 `Staff` 호환 파편과 조합해도 복수 아군을 기본 치료하는 순수 힐 무기로
  기능한다.
- 벌집 외피는 다른 장비와 무관하게 전투 시작 장벽을 제공한다.
- 로열 젤리는 전용 세트가 아닌 다른 eligible 아군 회복에도 발동한다.
- 전용 조합에서는 지휘봉이 여러 아군의 잔부상을 관리하며 로열 젤리를 분산하고, 파편은 위험한 아군
  한 명에게 제한 횟수 회복과 공격 속도 갱신을 집중한다. 벌집 외피는 그동안 후방의 시전자를 보호한다.

<a id="frag-미결정-사항-14"></a>
### 미결정 사항

- 파편과 장비의 최종 이름, `rarity`, `equip_limit`, 획득 경로와 강화 recipe
- 파편 시전 범위, 자기 자신 선택 가능 여부와 target lifecycle
- 일벌 한 마리의 회복률 `10~20%` 중 exact 값과 회복 modifier 계산 단계
- 최초 일벌 수, 사용 조건, 한 action 소비 상한·내부 cooldown과 다단 공격 처리
- 벌집의 지속 시간, 재시전 시 교체·중첩 여부와 남은 일벌 처리
- 여왕의 지휘봉의 회복 범위·대상 수·우선순위·대상별 회복량·주기와 target 재지정
- 벌집 외피의 장벽량·지속 시간·eligible 피해 type, barrier 우선순위와 전투 시작 적용 timing
- 로열 젤리의 공격 속도 증가량·지속 시간, eligible 회복 source와 modifier 계산 단계
