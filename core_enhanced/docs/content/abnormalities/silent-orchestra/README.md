## Open design:

- 최초 획득은 첫 심포니 승리, 충전은 서로 다른 승리당 1회·최대 4회로 확정했다.
  전조 전패로 파편 없이 보스를 격파하는 경우를 포함한 최종 보상 지급·개화 연결의 구현 세부는 후속 설계한다.
- 각 전조가 올릴 강화 형태와 형태별 exact 효과. 확정된 충전 수는 후속 RON에 반영한다.
- 개화 파편의 공연 지속 시간, 최초 공격의 피해와 처형 HP 기준, 파동의 피해 타입·반경·전파 속도.
  `4~6초` 공연, `6초 동안 아군 피해 +50%`는 논의용 예시이며 확정 수치가 아니다.
- 합창의 증가 단위·중첩 한도·파동 증폭량과 같은 시각의 여러 처형·파동에 적용할 순서.
- 일반 적·Elite·Boss·소환체·공중 적의 착석과 처형 적용 범위, 구속 저항 및 보스의 처형 대체 피해.
- 개화 후 발동 비용·횟수·재시전 조건, 시전자의 행동 제한·중단 처리와 공연 종료 시 착석·피해 증폭·
  합창 및 이미 방출된 파동의 정리 경계.
- 첫 대상 선택과 고정 파동 범위, 관객·합창·공연 잔여 시간을 보여줄 UI.
