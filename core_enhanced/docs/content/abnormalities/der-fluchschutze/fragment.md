## 필수 항목

| 항목 | 값 |
| --- | --- |
| `rarity` | open design |
| `equip_limit` | open design |
| `allowed_range_roles` | 원거리 |
| `allowed_weapon_archetypes` | 전용 무기. 현재 schema 표현은 open design |
| `allowed_deployment_affinity` | `Platform` |
| `block_capacity_min` | `0` |

파편과 전용 무기는 같은 흉탄 격파 보상 transaction에서 함께 지급하므로 강결합으로 인한 dead
reward는 발생하지 않는다. 파편을 다른 무기에서 사용할 수 있게 하는 fallback은 필수 획득 안전장치가
아니며, 별도의 빌드 확장 여부로만 검토한다.

<a id="frag-공통-탄환과-계약-순번"></a>
## 공통 탄환과 계약 순번

- 파편은 authored 최대치까지 충전 스택을 보유한다.
- 시전이 확정되면 파편 1스택을 소비하고 계약 발사 순번을 `1` 증가시킨다.
- 충전 스택 상한 `N`과 7발 단위 계약 발사 순번은 서로 다른 값이다.
- 계약 발사 순번은 **파편 시전 횟수**만 센다. 1~6번째 시전은 일반 탄환을 발사하고, 7번째 시전은
  사용자를 관통한 뒤 강화되는 저주 탄환을 발사한다. 7번째 사격을 처리하면 다음 사격을 1번째로
  세는 새 주기를 시작한다.
- Maintenance에서 기본형과 개화형을 바꿔도 계약 발사 순번은 초기화하지 않는다. 다음 전투에 반영되는
  무기 형태와 사격 문법만 함께 바뀐다.
- 마탄의 관통 후속 피해와 흉탄에서 처치로 생성된 탄환은 새 파편 시전이 아니다. 파편 스택을
  추가 소비하거나 계약 순번을 증가시키지 않는다.
- 7번째 사격의 자해와 강화 사격은 하나의 원자적 시전이다. 관통 피해로 사용자가 전투불능이 되어도
  이미 발생한 강화 탄환은 끝까지 처리한다.

계약 순번의 전투 시작값·전투와 node 사이의 초기화 시점·checkpoint 보존 범위, 충전 획득원은 open
design이다.

<a id="frag-파편--마탄-가칭"></a>
## 파편 — 마탄 (가칭)

개화 전 기본 파편이다. 장착하면 전용 무기를 기본 저격총 형태로 유지하고 저격형 마탄을 발사한다.

**마탄 사격**

- 플레이어가 적 대상 또는 사격 직선을 지정한다. exact cast selection은 open design이다.
- 탄환은 지정한 사선을 따라 적 유닛을 차례대로 관통한다.
- 적에게 명중할 때마다 같은 탄환이 이후 대상에게 가하는 피해가 증가한다.
- 해당 적을 처치하면 단순 명중보다 더 큰 다음 대상 피해 증가를 얻는다.
- 증폭은 그 탄환 하나에서만 유지하며 다음 파편 시전으로 이월하지 않는다.
- 약한 적을 사선 앞에 두고 강한 적을 끝에 두는 배치가 고점이다. 첫 대상부터 충분한 기본 피해를
  보장하되, 단일 대상만 있는 상황에서는 관통 증폭을 얻지 못한다.

일반 마탄 사선이 아군과 중립 오브젝트를 타격하는지, 적 명중·처치당 증가량과 한 발의 증폭 상한은
open design이다. 소환물을 이용한 무한 증폭은 한 발당 증폭 단계 또는 eligible target 제한으로
차단한다.

**7번째 마탄**

7번째 파편 시전에서도 플레이어는 먼저 저격 사선을 확정한다. 그 뒤 사용자가 직접 방아쇠를 당기기
전에 전장 밖의 후방에서 탄환이 날아온다.

1. 후방의 탄환이 파편 사용자를 관통해 큰 피해를 준다.
2. 관통한 탄환이 마법진을 통과해 강화 마탄으로 변한다.
3. 강화 마탄이 미리 지정한 직선을 따라 날아가며 일반 마탄보다 강한 초기 피해와 관통 증폭을 얻는다.

7번째 사격의 사용자 관통 피해와 강화 마탄의 정확한 추가 효과는 open design이다.

<a id="frag-파편-개화형--흉탄-가칭"></a>
## 파편 개화형 — 흉탄 (가칭)

개화하면 기본형과 개화형 중 하나를 Maintenance에서 선택한다. 개화형을 장착하면 전용 저격총이
자동으로 산탄총 형태로 변하고, 파편도 다음 산개 사격을 사용한다. 개화는 무기의 형태와 공격 문법을
바꾸지만 계약의 대가를 다른 유닛에게 이전하지 않는다.

**흉탄 산개 사격**

- 플레이어가 최초 발사 방향과 부채꼴 영역을 지정한다.
- 사용자 위치에서 여러 탄환을 부채꼴로 발사한다.
- 각 탄환은 진행 경로에서 처음 충돌한 유닛에게 피해를 주고 소멸한다.
- 탄환으로 적을 처치하면 그 적의 사망 타일에서 authored 수의 새 탄환이 생성된다.
- 새 탄환은 들어온 진행 방향을 기준으로 더 넓은 전방 부채꼴을 이루며 퍼진다. 뒤로 되돌아가는
  탄환은 생성하지 않는다.
- 새 탄환이 다시 적을 처치하면 다음 세대 탄환을 생성한다. authored 최대 확산 세대에 도달하면
  처치해도 더 생성하지 않는다.
- 아군도 산탄 경로에 있으면 피해를 받지만, 아군의 전투불능은 새 탄환을 생성하지 않는다.

한 번의 시전에서 같은 적은 탄환 생성 조건을 한 번만 발생시킨다. 시전당 최대 생성 탄환 수와 최대
피격 대상 수를 별도로 두며, 후속 세대의 피해 감쇠 또는 동일 대상 피격 상한은 open design이다.
이 상한들은 무한 전파와 projectile 폭증을 막는 안전 경계이고, 최대 확산 세대는 산탄이 얼마나 멀리
퍼지는지를 결정하는 콘텐츠 수치다.

적 하나만 있으면 최초 산탄만 유효하므로 마탄보다 단일 화력이 낮다. 다수의 약한 적이 전방에 연속
배치되면 처치 지점마다 산탄이 갈라지며 전장 깊숙이 퍼지는 것이 흉탄의 고점이다.

**7번째 흉탄**

- 플레이어가 먼저 산탄 방향을 확정하면 후방에서 날아온 탄환이 파편 사용자를 관통해 큰 피해를 준다.
- 관통한 탄환은 사용자 위치에서 강화 산탄으로 분열해 지정한 부채꼴로 날아간다.
- 사용자가 전투불능이 되어도 이미 발생한 강화 산탄과 후속 확산은 끝까지 처리한다.

강화 흉탄은 단순 피해 배율보다 최초 탄환 수, 각도, 처치당 생성 수 또는 최대 확산 세대를 늘리는
방향을 우선한다. 정확한 강화 항목과 수치는 open design이다.

7번째 탄환이 사용자가 아니라 아군을 관통하게 하는 변형은 개화의 기본 효과가 아니다. 해당 효과는
신규 Run 유물 시스템의 흉탄 전용 유물 후보가 소유하며, 유물의 아군 선정·preview·fallback과 산탄
원점 규칙은 임시 유물 문서에서 후속 설계한다.
