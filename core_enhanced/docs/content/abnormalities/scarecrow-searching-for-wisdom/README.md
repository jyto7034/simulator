## 지혜를 구하는 허수아비

> 상태: 머리·약점을 노리는 원거리 저격총, 다음 무기 기본 공격 강화 파편과 그 공격의 처치 시
> 공격력 +20~30% 보상 구조 합의 / 이름·강화 배율·버프 지속 시간·중첩 등 세부 판정 미정 /
> 방어구의 비피격 완충·액세서리의 기본 공격 간격 비례 강화 구조 확정 / 장비 수치 미정 / 현재 미구현

조우 설계는 `abnormality_design_notes.ko.md`의 `지혜를 구하는 허수아비` 절이 소유한다. 플레이어
보상은 기존 흡혈형 힐 후보에서 원거리 단일 딜러로 전환한다. 적의 뇌를 빼앗는 모티프를 헤드샷과
처치 후 공격력 강화로 각색하며, 적 조우의 HP 흡수·회복·행동 및 저지 봉쇄를 기본 파편에 넣지 않는다.

앞서 검토한 활, 낮은 HP 비례 마무리 피해와 별도로 발사하는 액티브 저격은 채택하지 않는다.
파편은 장착 무기의 다음 기본 공격을 강화하는 active이며, 시전 자체가 별도 피해를 가하지 않는다.

### 미결정 사항

- 최종 이름·획득 경로, 파편 희귀도·중복 장착 제한·호환 범위·self 시전 정책
- 저격총의 아키타입·피해 타입·배치·저지 수, 사거리·공격력·주기·조준 시간·표적 선택·대공 여부
- 다음 기본 공격 강화 배율, 다른 피해 modifier 합성, 다단·범위·연쇄 무기의 강화 단위
- 강화 준비의 유효 시간·중복 시전, 기존 windup과의 경계·소비 시점·취소·빗나감 및 철수 lifecycle
- 공격력 +20~30% 중 exact 값, 지혜 획득의 지속 시간·중첩·갱신·해제 및 modifier 합성
- 강화 공격 처치의 source attribution, 추가·지속·범위 피해와 다수 처치·공명·장비 trigger 처리
- 방어구·액세서리의 이름·기본 능력치·테스트 후보 수치 확정(기본 효과 구조는 확정)
- 짚 완충의 eligible 피해, 감면·보호막 합성 순서와 동시 피해 처리
- 액세서리의 release 기준 시간·피해 묶음·강화 배율 합성과 Hard CC·다단·범위 공격 판정
- 전용 Run 유물의 설계 여부, 강화 성장치와 실제 전투 수치 검증
