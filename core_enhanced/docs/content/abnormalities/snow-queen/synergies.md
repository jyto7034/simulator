# 눈의 여왕 · 태그·유물 연결

[콘텐츠 위키](../../README.md) · [개요](README.md) · [파편](fragment.md) · [장비](equipment.md) · [아카이브](review.md)

> 상태: 2026-10-20 냉기·혹한·추격 폭발 잔영의 효과별 태그와 범용 유물 5개·전용 유물 1개 연결 합의.
> 피해량·잔영 수치·T자 확대 형상·면역 등의 후속 판정은 미정이며 구현 완료를 뜻하지 않는다.

## 기본 효과의 분류

| 효과 | 기본 태그 | 적용 범위 |
| --- | --- | --- |
| T자 공격의 직접 피해 | 피해 · 범위 | 지정 방향의 타일 범위에 Magic 피해 |
| 피해 시 냉기 부여 | 제어 · 지속시간 | 장착자 소유 피해의 대상에게 이동 속도 30% 감소·3초. 비중첩, 재부여 시간 갱신 |
| 냉기에서 혹한으로 전환 | 제어 · 범위 · 지속시간 | 이번 액티브 피해 직전에 냉기였던 범위 내 대상의 냉기를 소비해 2초 빙결 |
| 빙결 잔영 생성 | 소환물 | 전장에 남아 추격·폭발하는 이동형 효과. HP·저지·직접 명령 없음 |
| 잔영의 지연 폭발 | 피해 · 범위 · 폭발 · 지연발동 | 잔영에서 발생하는 후속 Magic 피해 |

냉기·혹한은 상태 이름이며 공통 태그가 아니다. 둔화·빙결은 `제어`의 종류로 구분한다.
냉기→혹한은 액티브 적중에 따른 전환이므로 스택·스택부여·진행도를 추가하지 않는다.
냉기는 자체 피해가 없으며 지속피해 태그도 없다. 파도가 지나가는 연출만으로 투사체·관통을 붙이지 않는다.
잔영은 소환물 태그를 갖지만 전투 유닛의 HP·배치·저지 규칙을 자동 상속하지 않는다.

현재 효과 태그의 모음은 `피해 · 범위 · 제어 · 지속시간 · 소환물 · 폭발 · 지연발동`이다.
각 유물은 해당 효과의 출처·조건을 검사하며 서로 다른 효과의 태그를 합쳐 조건을 충족시키지 않는다.

## 합의한 범용 연결 5개

| 유물 | 대상 태그 | 변경 규칙 | 적용 지점·조건 | 남은 판정 |
| --- | --- | --- | --- | --- |
| [긴 호흡](../../relics/long-breath.md) | `지속시간` | 유지 시간 25% 증가 | 파편의 냉기 3→3.75초·혹한 2→2.5초. 냉기 재부여도 3.75초로 갱신 | 다른 시간 변경·저항과의 합성 |
| [깨진 균형](../../relics/broken-balance.md) | `제어` | 5초간 받는 피해 증가 부여 | 혹한으로 실제 빙결된 적. 냉기 둔화·빙결 실패에는 발동하지 않음 | 증가율·재부여·최초 타격과 약화의 적용 순서·합성 |
| [넓어진 지평](../../relics/widened-horizon.md) | `범위` | T자 공격과 잔영 폭발 범위 확대 | T자 피해와 그 범위의 혹한 전환을 함께 확대. 잔영 폭발도 별도 적용 | T자 확대 마스크·잔영 기본 범위·형상별 환산 |
| [압축 화약](../../relics/explosion-vulnerability.md) | `폭발` · `피해` | 폭발 피해 증가 | 기본 파편·겨울의 유언으로 생성된 잔영의 폭발. T자 직접 피해는 제외 | 증가율·다른 증폭과 합성 |
| [사냥의 낙인](../../relics/summon-vulnerability.md) | `소환물` · `피해` | 5초간 받는 피해 증가 부여 | 기본 파편·겨울의 유언의 잔영에서 발생한 피해를 입은 대상 | 증가율·최초 피해 반영 순서·재부여·인정 피해·합성 |

긴 호흡의 이번 연결은 파편의 냉기와 혹한만 늘린다. 둔화율, 잔영 폭발까지의 지연,
깨진 균형·사냥의 낙인의 별도 5초 약화는 변경하지 않는다. 서리 마검 단독 냉기의 수치와 시간 연장은 별도 후속이다.
혹한 중에는 긴 호흡을 장착해도 패시브나 재적중으로 혹한 시간을 갱신하지 않는다.

넓어진 지평은 탐색 거리·추적 속도·잔영 수를 늘리지 않는다. 잔영 기본 범위가 1칸으로 정해지면
공통 규칙의 1칸→3×3을 사용할 수 있지만, 이번 연결로 기본 범위를 1칸이라고 확정하지 않는다.
T자를 정사각형 규칙에 대입하거나 범위 안의 모든 적을 무조건 빙결시키지 않는다. 냉기 선행 조건은 유지한다.

## 합의한 전용 연결 1개

| 유물 | 대상 태그 | 변경 규칙 | 적용 지점·조건 | 남은 판정 |
| --- | --- | --- | --- | --- |
| [겨울의 유언](../../relics/snow-queen-remnant.md) | `제어` | 냉기 또는 혹한 상태의 적 사망 시 잔영 1개 생성 | 착용자 출처의 눈의 여왕 파편·무기 냉기 또는 혹한. 다른 아군 처치도 인정. 동일 착용자·동일 사망당 1개 | 복수 출처·생성 상한·동일 타격의 상태 부여와 사망·유물 사본 처리 |

| 유물이 만든 효과 | 효과 태그 | 적용 경계 |
| --- | --- | --- |
| 사망 위치에 잔영 생성 | 소환물 | 유물 출처와 소유자를 보존 |
| 생성된 잔영의 폭발 | 피해 · 범위 · 폭발 · 지연발동 | 잔영 출처의 피해로 범용 연결 적용 |

냉기→혹한 전환에서 출처를 보존하므로 얼리는 행동이 겨울의 유언 자격을 없애지 않는다.
냉기와 혹한을 같은 사망에서 별개 생성으로 세지 않는다. 기본 액티브의 시전당 생성과 유물의 사망당 생성은 별도 사건이다.
잔영 폭발과 그 파생 피해로 처치한 적에게서는 추가 잔영을 생성하지 않는다.
잔영 피해가 살아남은 적에게 냉기를 부여하는 것은 허용하며, 이후 적의 사망은 실제 사망 출처를 검사한다.
침식 제외와 공통 유물 순환 재발동 금지는 그대로 따른다.

## 제외·보류 연결

- **조여오는 족쇄:** 시간에 따라 제어 진행도를 쌓는 구조가 아니므로 연결하지 않는다.
- **중첩된폭발:** 서로 다른 잔영 폭발의 동일 대상 중복 피해 규칙을 먼저 정한 뒤 검토한다.
- **울림통:** 잔영에 별도 지속 둔화 영역을 두지 않으므로 이번 연결에 포함하지 않는다.
- **스택 계열:** 냉기는 비중첩 상태이고 혹한은 상태 전환이다. 잔영 개체 수를 스택으로 자동 분류하지 않는다.

새 선행 유물·비호환 관계는 추가하지 않는다. 잔영의 수치·상한과 상태의 세부 판정은 [파편](fragment.md)을 따른다.
