# 눈의 여왕 · 스킬 파편

[콘텐츠 위키](../../README.md) · [개요](README.md) · [조우](encounter.md) · [장비](equipment.md) · [태그·유물](synergies.md) · [아카이브](review.md)

> 상태: 2026-10-20 T자 타일 공격·피해 시 냉기·액티브의 혹한 전환·추격 폭발 잔영과 태그·유물 연결 합의.
> 피해량·정확한 타일 형태·잔영 수치·면역 등의 세부 판정은 미정. 문서 설계이며 구현 완료를 뜻하지 않는다.

## 파편 — 빙설의 파도 (가칭)

장착자가 피해를 주면 적에게 냉기를 부여한다. 공명이 가득 차면 지정 방향의 T자 타일 범위를 공격하고,
이미 냉기 상태였던 적을 혹한으로 전환한다. 기본 시전으로 생성한 빙결 잔영은 적을 추격해 폭발한다.

| 항목 | 값 |
| --- | --- |
| `rarity` | 미정 |
| `equip_limit` | 미정 |
| `compatibility` | `Sword` |
| `cast_selection` | 전방 T자 타일 공격의 방향 지정. 길이·폭·정확한 타일 마스크는 후속 |
| 역할 | 범위 마법 피해 / 냉기 준비 후 조건부 빙결 / 잔영의 후속 폭발 |

공명·침식과 종료 조건은 [파편 공통 기준](../../principles/fragments.md#current-corrosion)을 따른다.
파편은 무기의 배치 affinity·저지를 바꾸지 않는다.

## 패시브 — 피해 시 냉기

파편 장착자가 적에게 피해를 입히면 그 대상에게 `냉기`를 부여한다.
피해 유형을 물리·마법 중 하나로 한정하지 않으며, 장착자 소유의 기본 공격·스킬·지속 피해·잔영·유물 피해를 포함한다.
다른 직원의 피해를 자신의 패시브 발동으로 세지 않는다.

| 상태 | 효과 | 기본 지속 시간 | 재부여 |
| --- | --- | --- | --- |
| 냉기 | 이동 속도 30% 감소 | 3초 | 중첩 불가. 남은 시간을 3초로 갱신 |
| 혹한 | 빙결 | 2초 | 패시브 피해로 시간을 갱신하지 않음 |

냉기는 피해를 주는 상태가 아니라 이동 제어다. 지속 피해가 냉기를 부여할 수 있다는 이유로 냉기 자체에
지속피해 태그를 붙이지 않는다. 피해 0·보호막만 감소한 경우의 인정, 사망 확정과 신규 상태 부여의 순서는 후속이다.

## 액티브 — T자 공격과 혹한 전환

지정 방향의 T자 타일 범위에 Magic 피해를 준다. 범위 안에서 이번 액티브 피해가 들어가기 직전에
냉기 상태였던 적은 냉기를 소비하고 `혹한`으로 전환한다. 주 대상 한 명으로 제한하지 않는다.
정확한 타일 수·길이·폭·회전 마스크와 범위 예고는 후속으로 정한다.

- 이번 타격 직전의 냉기 여부를 먼저 판정한다. 이번 액티브가 새로 부여한 냉기를 같은 타격에서 혹한으로 전환하지 않는다.
- 냉기가 없던 적은 이번 피해의 패시브로 냉기에 걸리고, 미리 냉기에 걸린 적은 혹한으로 바뀐다.
- 혹한은 2초간 빙결시키는 상태다. 세부 허용 행동·면역·저항·진행 중 행동 처리는 공통 제어 규칙과 후속 판정을 따른다.
- 혹한 중에는 패시브가 냉기를 덧붙이거나 빙결 시간을 갱신하지 않는다. 액티브로 이미 혹한인 대상을 다시 맞혀도 시간을 갱신하지 않는다.
- 혹한 종료 시 냉기가 자동 복구되지 않는다. 종료 뒤 새로 피해를 주면 냉기를 다시 부여할 수 있다.
- 혹한 전환은 눈의 여왕 액티브에만 있다. 기본 공격·지속 피해·잔영 폭발·다른 스킬은 냉기를 부여할 수 있어도 혹한으로 전환하지 않는다.
- 전환 전 냉기의 출처와 전환한 파편의 출처를 보존한다. 여러 직원의 냉기·혹한이 겹칠 때의 귀속·갱신 세칙은 후속이다.

## 빙결 잔영 — 생성·추격·폭발

액티브가 적 한 명 이상에게 적중하면 주 대상 위치에 빙결 잔영 하나를 생성한다.
기본 생성은 시전당 하나이며 처치를 요구하지 않는다. 주 대상 선정 우선순위·적중과 사망이 겹칠 때의 위치 처리는 후속이다.

- 잔영은 가까운 적을 추격하다가 정해진 지연 뒤 현재 위치에서 광역 Magic 폭발을 일으키고 사라진다.
- 목표가 사라지면 다른 적을 찾는다. 주변에 적이 없으면 현재 위치에서 폭발한다.
- HP·저지·피격·직접 명령이 없는 이동형 효과다. 태그는 `소환물`로 분류하며, 전투 유닛의 배치 규칙을 자동 상속하지 않는다.
- 추격 중 주변에 별도 둔화 영역을 만들지 않는다. 잔영 피해는 장착자 소유 피해로서 살아남은 적에게 냉기를 부여할 수 있다. 혹한 중에는 위 패시브 제한을 따른다.
- 잔영 폭발과 그 파생 피해로 처치한 적은 추가 잔영을 만들지 않는다. 기본 생성과 전용 유물 생성에 같은 출처 제외를 적용한다.
- 이동 속도·탐색 거리·지연 시간·폭발 범위·피해량·동시 생성 상한과 한도 초과 처리는 미정이다.

사망에 따른 추가 생성은 [겨울의 유언](../../relics/snow-queen-remnant.md)이 담당한다.
착용자 출처의 냉기 또는 혹한 상태인 적이 사망하면 처치자가 다른 아군이어도 사망 위치에 잔영 하나를 생성한다.
유물의 사망당 1회 생성과 기본 액티브의 시전당 생성은 별도 사건이다. 동시 발생 시 생성 순서·상한 판정은 후속이다.

## 태그·유물과 남은 결정

[태그·유물 연결](synergies.md)에 기본 효과별 태그, 범용 유물 5개와 전용 유물 1개의 적용 범위를 기록한다.
긴 호흡을 장착하면 냉기는 3.75초, 혹한은 2.5초이며 냉기 재부여도 3.75초로 갱신한다.
냉기 둔화율·잔영 폭발 지연·유물의 별도 약화 시간은 이번 지속시간 연결로 변경하지 않는다.

피해 계수, T자 기본·확대 형태, 잔영 수치·상한, 복수 직원의 상태 소유권, 피해·상태 부여·사망 확정의
동일 사건 처리, 면역·저항과 혹한 전환 실패 시 냉기 처리는 후속이다. 개화형은 아직 정하지 않았다.
앞선 비교용 수치를 확정 수치로 채택하지 않는다.

## 2026-10-22 공통 작성 계약의 세부 정책

P6 구현 위임 범위에서 다음 판정을 채택한다. T자 마스크·계수·잔영 수치는 미정으로 보존한다.

- 소유 피해의 실제 HP 감소가 양수이고 대상이 생존했을 때 냉기를 부여한다. 보호막만 감소한 사건은 제외한다.
  액티브는 피해 직전 상태를 고정하고, 생존한 대상에 대한 기존 냉기의 혹한 전환을 피해 후 처리한다.
  빙결 면역 등으로 전환에 실패하면 기존 냉기를 소비하지 않는다. 이미 혹한인 대상의 시간을 갱신하지 않는다.
- 같은 소유자의 냉기는 출처별 기여분을 보존한다. 전환은 원래 냉기 출처와 시전 출처를 함께 보존한다.
  다른 직원의 냉기·혹한으로 자신의 유물 사망 생성 자격을 얻지 않는다. 무기의 자체 냉기는 별도 정의로 연결한다.
- 직접 액티브의 적중 대상 중 루트 진행도·유닛 ID 순으로 고른 한 대상의 적중 당시 위치에 기본 잔영을 만든다.
  잔영은 생성 당시 Attack을 고정한다. 생성부터 폭발 지연을 세며 가장 가까운 적을 추격하고 동률은 유닛 ID 순이다.
  목표가 없으면 현재 위치에서 남은 지연을 유지한다. 폭발은 당시 위치와 범위로 적마다 한 번 적용한다.
- 기본·유물 잔영은 같은 동시 상한을 공유한다. 사망 유물 생성 뒤 기본 액티브 생성을 처리하며 상한 초과 생성은 생략한다.
  겨울의 유언은 같은 소유 직원·사망당 한 번만 생성한다. 냉기와 혹한, 여러 파편 사본으로 중복 생성하지 않는다.
  잔영 또는 그 파생 피해의 처치는 추가 잔영을 만들지 않으며 침식 처치도 제외한다.
- 독립 잔영은 소유자 이탈 후 이미 시작한 이동·폭발을 유지하고 전투 종료에 정리한다.
  냉기 피해 구독은 살아서 배치된 동안만 동작한다. 냉기·혹한의 기존 유한 기여분은 각 만료 시점까지 유지한다.

### 2026-10-22 실행 경계 보완

- 추격은 기존 전투 이동 정책의 갱신 간격에서 현재 위치를 샘플링한다. 거리 동률은 유닛 ID로 정한다.
  HP 없는 이동 효과는 유닛의 경로 찾기·저지·장애물 충돌을 상속하지 않고 목표를 향해 직선 이동한다.
  별도 고정 50ms 탐색이나 구간 교차 판정을 약속하지 않는다.
- 같은 상태 정의의 혹한이 활성인 동안에는 다른 직원도 냉기를 새로 붙이지 않는다. 이미 있던 다른
  직원의 냉기는 자기 만료까지 남는다. 전환은 해당 시전자가 부여한 냉기만 소비하며, 원래 출처를 보존한다.
- 소유자 이탈 전에 부여한 유한 냉기·혹한은 만료까지 겨울의 유언 조건을 제공한다. 일반 유물이
  계속 장착되어 있고 소유자가 침식 상태가 아니어야 한다. 이탈 후 새 피해 구독은 시작하지 않는다.
  침식 처치·반응 피해·잔영 계보의 파생 피해는 사망 생성을 발동하지 않는다.
- 빙결은 공통 Hard CC와 StunImmune, 둔화는 SlowImmune을 따른다. 출처별 둔화의 최댓값을 적용하고
  중첩해 곱하지 않는다. 무기 자체 냉기는 별도 정의·미정 수치로 남으며 이 파편에 자동 합치지 않는다.
