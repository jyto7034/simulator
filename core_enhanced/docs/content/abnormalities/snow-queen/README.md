# 눈의 여왕

[콘텐츠 위키](../../README.md) · [조우](encounter.md) · [파편](fragment.md) · [장비](equipment.md) · [태그·유물](synergies.md) · [아카이브](review.md)

> 상태: 2026-10-20 냉기 패시브·T자 액티브의 혹한 전환·추격 폭발 잔영·범용 5개·전용 1개 연결 합의.
> 설계 합의이며 구현 완료를 뜻하지 않는다.

**분류:** 엘리트

직원용 파편은 피해로 냉기를 부여하고 T자 범위의 액티브로 혹한에 전환한다. 기본 잔영은 추격 후 폭발하며,
겨울의 유언은 냉기·혹한 상태의 적이 사망할 때 잔영을 추가 생성한다.
적 조우는 높은 기본 스탯으로 Route를 진행하며 근접 범위기·전방 강공격·단일 빙결을 사용하는 기존 정공법 전투를 유지한다.

## 현재 구성과 독립성

- 파편의 호환은 `Sword`다. 다른 Sword에 장착해도 냉기 패시브·T자 공격·혹한·잔영을 사용할 수 있다.
- 서리 마검은 Platform 전용 원거리 광역 Magic 무기로, 다른 호환 파편과 조합해도 자체 냉기를 제공한다.
- 눈꽃의 예복은 HP 조건에서 자기 동결 생존기를 전투당 한 번 제공한다.
- 얼음 왕관은 냉기·혹한을 포함한 인정된 이동 방해 상태의 적에게 피해를 높인다. 전용 세트에만 한정하지 않는다.
- [겨울의 유언](../../relics/snow-queen-remnant.md)은 자신의 파편·무기에서 비롯된 냉기 또는 혹한 상태인 적의 사망에 반응한다.
  자신의 막타를 요구하지 않으며, 상태 전환 뒤에도 출처를 보존한다.

파편 장착자의 모든 소유 피해에 연결되는 냉기 패시브와 서리 마검의 자체 냉기는 별도 출처다.
무기를 단독으로 사용하는 경우의 둔화율·지속 시간은 장비 본문의 미정 사항을 유지한다.

## 남은 결정

- 파편·장비의 최종 이름, 희귀도·중복 장착·획득·강화와 개화형.
- T자 기본·확대 타일 마스크, 피해량, 사거리·표적 조건과 주 대상 선정.
- 빙결 잔영의 이동·탐색·폭발 지연·범위·피해·동시 상한과 한도 초과 처리.
- 피해 0·보호막 피해, 같은 타격의 피해·냉기·혹한·약화·사망 순서, 면역·저항.
- 여러 직원의 냉기와 혹한 전환 출처, 유물 사본별 생성·상한·재배치 처리.
- 장비별 수치와 상태의 합성, 피해 증폭의 합성·최초 피해 적용 순서.

현재 합의와 미정 사항은 각 상세 문서가 소유한다. 이전 설계는 아카이브에 보존한다.
