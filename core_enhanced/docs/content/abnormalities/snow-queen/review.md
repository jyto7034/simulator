### Run 유물 — 이름 미정 (눈의 여왕 전용)

> 2026-09-07 대화 결정: 착용자의 **파편 또는 무기**가 부여한 냉기 디버프로 둔화된 적이
> 사망하면 빙결 잔영을 생성한다. 이름·희귀도·수치·세부 판정 미정 / 현재 미구현.

- 적용 출처는 착용자의 `빙설의 파도`와 `서리 마검`이 부여한 냉기다. 둘 중 하나로 해당 냉기를
  부여하면 사용할 수 있으며, 두 콘텐츠를 동시에 장착해야 하는 조건은 두지 않는다.
- 사망 확정 시 해당 냉기의 이동 속도 감소 효과가 유효해야 한다. 냉기가 만료·해제됐거나 둔화가
  면역으로 적용되지 않은 대상은 이 확장 조건을 충족하지 않는다.
- 처치 피해를 파편의 직접 피해나 착용자의 공격으로 한정하지 않는다. 다른 아군의 공격으로
  사망해도 냉기 조건을 충족하면 사망 위치에 잔영을 생성한다. 침식 처치는 공통 제외 정책을 따른다.
- 같은 착용자의 기본 파편 직접 처치 조건과 유물 조건이 함께 성립해도 한 사망에서 잔영은 하나만
  생성한다. 잔영의 이동·주변 둔화·지연 폭발은 기존 설계를 따른다.

출처 구분, 유물이 생성한 잔영의 연쇄와 남은 판정은

## 17 눈의 여왕

**기존 방향:** 전방 냉기 공격으로 범위 둔화와 주 대상 빙결을 주고, 직접 처치하면 잔영이 이동해 주변을 둔화시키다 폭발한다.

**조립안:** 방향·주 대상 확정 → 범위 Magic 피해·둔화 → 주 대상 빙결 → 직접 처치 위치에 잔영 생성이다. 잔영은 HP·저지·직접 조작 없이 가까운 적을 향해 이동하고 현재 위치 주변에 둔화를 주다가 폭발한다. 기본안에서는 폭발이 다시 잔영을 낳지 않는다.

전용 유물은 착용자의 냉기로 둔화된 적이 죽을 때 처치자와 무관하게 잔영을 만든다. 직접 처치와 유물 조건을 동시에 만족해도 같은 착용자·사망 대상 조합에서는 하나만 생성하는 안을 추천한다.

**기능 경계:** 냉기 공격·사망 반응은 공통. 잔영은 움직이는 효과 중심이므로 위치 갱신이 필요하다. 이동을 전부 그림으로만 처리하면 둔화 대상과 폭발 위치가 달라진다. 고정된 사망 지점의 지연 폭발로 바꾸는 것은 별도 단순화 대안이다.

**검토:** 추천은 이동 잔영을 유지하되 단순한 목표 추적과 수명만 두는 것이다. 이동 속도·재탐색 주기·추적 대상 소멸 시 동작을 정한다. 빙결 주 대상이 피해로 먼저 죽었을 때 제어를 다른 적에게 넘기지 않는다. 자체 방어용 빙결 방어구와 둔화 대상 추가 피해 액세서리는 별도다.

**태그와 유물 적용**

| 효과 단위             | 태그 후보                                                       | 변경 후보 속성과 지켜야 할 경계                                   |
| --------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |
| 전방 냉기 공격        | `피해·범위`                                                     | 형태·범위·위력. 둔화와 빙결은 별도 효과                           |
| 둔화와 주 대상 빙결   | 둔화 `제어·범위` / 빙결 `제어`                                  | 종류별 강도·시간·출처. 주 대상 한정을 보존                        |
| 이동 잔영과 주변 둔화 | 잔류 매개의 `소환물`은 검토, 영역 `지속영역·범위` → 둔화 `제어` | 실제 위치·추적·수명·제어 반경. 영역과 제어의 관계 보존            |
| 잔영 폭발             | `피해·범위·폭발`                                                | 폭발 위력·범위. 잔영의 생성 원인과 연결, 추가 잔영 생성 금지 유지 |

**유물 연결:** 기존 **눈의 여왕 전용 유물**은 정확한 냉기 출처와 대상 사망을 검사하며 모든 둔화에 적용하지 않는다. **울림통**은 잔영 영역이 원형 지속영역으로 확정될 때 후보가 된다. 이동 잔영의 `소환물` 분류가 결정되기 전에는 **소환물 범용 유물** 호환을 확정하지 않는다.
