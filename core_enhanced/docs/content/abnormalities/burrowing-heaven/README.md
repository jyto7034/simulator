## 파고드는 천국

> 상태: 2026-10-19 집중 장판 리메이크·유물 연결 5개 합의. 기본 제어는 비교적 느리게 두고
> 유물로 성능을 강화한다. 전용 지팡이·단순 생존 방어구 유지, 액세서리는 재설계 대기.
> 이름·수치·세부 판정은 후속 조정.

조우 설계는 `abnormality_design_notes.ko.md`의 `파고드는 천국` 절이 소유한다. 조명 중 정지,
암흑마다의 접근과 희생자를 통한 증식을 플레이어 보상에서는 **집중으로 넓은 영역을 주시해
적의 움직임을 점차 늦추고 기절시켜 아군의 공격을 돕는 효과**로 뒤집는다.

### 미결정 사항

- 파편, 무기, 방어구와 액세서리의 최종 이름
- `rarity`, `equip_limit`, 획득 경로와 강화 recipe
- 집중 최대 시간, 장판 크기·형상·중심 지정·고정/추종, 집중 중 행동과 중단 판정
- 둔화 곡선·기절 도달 시간·제어 진행 가속률과 여러 출처 장판의 결합
- 공중·보스·환상체 적용, 기절 후 강제 이동과 기본 20%·깨진 균형의 피해 증폭 합산
- 무기 공격 범위의 형태, 공격력, 공격 주기, windup과 가시 발생 timing
- 같은 타일의 여러 적, 공중 유닛과 이동 중인 적에 대한 tile snapshot·적중 판정
- 주시가 사라진 뒤 전용 액세서리의 새 효과와 이전 스택 증폭 연결 재검토
- 방어구의 생존 stat 조합과 정확한 수치
