## 무기 — 이름 미정

> 공격 방식 합의 / 이름·범위·피해 수치 미정

| 항목 | 값 |
| --- | --- |
| `range_role` | 원거리 |
| `weapon_archetype` | `Staff` |
| `deployment_affinity` | Platform 전용 |
| `block_capacity` | `0` |
| `damage_type` | Magic 우선, exact open design |
| `targeting_profile` | open design |
| `air_capable` | open design |
| `interval_ms` | 느린 공격 주기, exact open design |
| `windup_ms` | open design |
| `delivery` | 범위 안 적 타일에 발생하는 가시 공격 |

일반 공격은 단일 projectile을 발사하지 않는다.

1. 착용자가 Staff를 땅에 강하게 찍는다.
2. 그 공격 시점에 무기 공격 범위 안에 있는 모든 유효한 적의 타일을 확정한다.
3. 확정한 각 적 타일의 바닥에서 가시가 솟구친다.
4. 가시에 적중한 모든 적에게 같은 일반 공격의 광역 피해를 준다.

가시는 각 적을 쫓아가는 projectile이 아니라 공격 시점에 확정한 타일에서 솟는 presentation과
delivery다. 2026-10-19 리메이크로 주시 부여·반복 공격 속박 연결은 대체되었다. 가시의 광역
피해 자체는 유지하며, 장판의 제어 진행은 공격 횟수가 아닌 대상별 체류 시간으로 계산한다.
집중 중 일반 공격 가능 여부는 후속 판정이다.

<a id="frag-방어구--이름-미정-3"></a>
## 방어구 — 이름 미정

자체 trigger나 고유한 특수 효과가 없는 단순 생존 수치 방어구다.

| 항목 | 값 |
| --- | --- |
| 효과 | 방어력·최대 HP·마법 저항 등 생존 stat 중에서 추후 선택 |
| 자체 특수 효과 | 없음 |
| 정확한 stat 조합과 수치 | open design |

장판의 제어 진행 속도나 받는 피해 증가량을 직접 높이지 않는다. 다른 파편·무기와
조합해도 선택한 생존 stat만 제공하는 독립 방어구로 사용한다.

<a id="frag-액세서리--이름-미정-2"></a>
## 액세서리 — 이름 미정

> 리메이크 검토 대기. 아래는 이전 스택 증폭 설계의 보존 기록이며, 새 장판의 체류 시간을
> 스택으로 취급하거나 제어 진행 가속을 이 액세서리의 새 효과로 확정하지 않는다.
> 주시와의 전용 연결은 대체되었고, 다른 콘텐츠의 스택 증폭 연결 재검토도 후속 장비 설계에서 다룬다.

착용자가 스택을 부여할 때 해당 stack definition 또는 stack application effect에 명시적인
**스택 증폭 태그**가 있으면, `100%` 확률로 최초 부여량을 두 배로 만든다. 한 번에 1스택을 부여하면
2스택, 2스택을 부여하면 4스택을 부여한다. 발동 확률은 항상 `100%`이며 확률을 balance knob로
사용하지 않는다.

- 스택의 이름, 현재 수량이나 감소 가능 여부를 runtime에서 추론해 적용하지 않는다.
- 스택 증폭 태그가 없는 부여는 종류와 source에 관계없이 두 배로 만들지 않는다.
- 공명·허기·파편 충전, cooldown counter와 별도 object 수량도 명시적인 스택 증폭 태그가 없는 한
  자동으로 적용 대상이 되지 않는다.

파고드는 천국 파편의 `주시`에는 스택 증폭 태그를 부여한다. 따라서 전용 Staff의 일반 공격으로 적에게
피해를 주면 원래 1스택 대신 2스택을 부여하고, 다음 유효한 스택 부여가 3스택 임계치에 도달하면
기존 규칙대로 스택을 모두 소모하고 1초 속박한다. 최대치를 넘는 스택은 임계치 판정 뒤 저장하지
않는다.

두 배 적용은 착용자가 만든 최초 stack application의 `amount`를 변경하는 한 번의 판정이다. 이미
부여된 스택의 이전·복사·상속이나 해당 스택에서 파생된 후속 효과에는 다시 적용하지 않는다.

스택 적용량 두 배 효과는 파고드는 천국 액세서리가 소유한다. 같은 효과를 사용하던 `죽을 나비의
장례` 액세서리 초안은 폐기하고 별도 효과로 재설계한다.
