# 파고드는 천국 · 태그·유물 연결

[콘텐츠 위키](../../README.md) · [개요](README.md) · [파편](fragment.md) · [장비](equipment.md) · [아카이브](review.md)

> 상태: 2026-10-19 집중 장판 리메이크·유물 연결 5개·유물로 제어 성능을 강화하는 방향 합의 /
> 수치·세부 판정과 전용 액세서리는 후속 조정 / 구현 완료를 뜻하지 않음

## 효과의 기본 분류

| 효과 | 분류 태그 | 적용 범위 |
| --- | --- | --- |
| 시전자가 장판을 유지 | 집중유지 · 지속시간 | 유한한 최대 집중 시간과 중단 조건 |
| 전장에 남는 장판 | 소환물 · 지속영역 · 범위 | 넓은 영역의 체류 판정. 독립 공격 유닛이 아님 |
| 체류에 따른 둔화와 기절 | 제어 | 대상별 진행. 기절은 장판 종료까지 유지 |
| 장판 안 적의 받는 피해 20% 증가 | 받는피해증가 | 진입 순간부터 적용, 기절 면역과 별도 |

소환물은 태그 사전에서 지속 장판을 포함하는 분류다. 빨간 눈 자체를 소환 유닛으로 만들지 않는다.
장판에 직접 피해·지속 피해·스택 태그를 붙이지 않으며, 별도 무기 가시의 피해도 상속하지 않는다.
따라서 소환물 피해 후 약화는 장판만으로 발동하지 않는다.

## 합의한 유물 연결 5개

| 유물 | 대상 태그 | 변경 규칙 | 적용 지점·조건 | 남은 판정 |
| --- | --- | --- | --- | --- |
| [넓어진 지평](../../relics/widened-horizon.md) | `범위` | 단일 대상 피해→타일 1칸, 기존 1칸→3×3, 기존 3×3→4×4로 변경하며 다른 형상은 후속 판정한다. | 장판 범위 확대. 기존 공통 넓어진 지평 정의를 사용하며 장판 형상과 정확한 확대 판정은 후속 조정 | 각 상세 본문의 미정·초안 유지 |
| [깨진 균형](../../relics/broken-balance.md) | `제어` | 기절을 가한 적에게 5초간 추가 받는 피해 증가 | 둔화 진행이 기절로 전환되는 사건. 기절 유지 자체를 매 순간 새 부여로 세지 않음 | 각 상세 본문의 미정·초안 유지 |
| [긴 호흡](../../relics/long-breath.md) | `지속시간` | 최대 집중 시간 25% 증가 | 장판 유지 상한만 연장. 기절 도달 시간을 늘리거나 종속 기절 시간을 다시 증폭하지 않음 | 각 상세 본문의 미정·초안 유지 |
| [무아지경](../../relics/unbroken-trance.md) | `시전` | 외부 군중제어·침묵으로 집중이 중단되지 않음 | 진행 중인 집중 보호. 상태 부착 면역은 아니며 직접 취소·최대 시간 등 종료 조건 유지 | 각 상세 본문의 미정·초안 유지 |
| [조여오는 족쇄](../../relics/tightening-shackles.md) | `제어` · `진행도` | 둔화가 강해지고 기절에 도달하는 속도 증가 | 대상별 체류 진행을 가속. 가속률 미정이며 스킬 쿨다운·공명·집중 상한을 변경하지 않음 | 각 상세 본문의 미정·초안 유지 |

기본 장판은 기절까지 비교적 오래 걸린다. 유물로 더 넓게, 더 오래, 안정적으로, 더 빨리 적을
멈추게 만들어 제어 성능을 강화한다. 새 가속률이나 기본 기절 도달 시간은 임의로 확정하지 않는다.

깨진 균형의 5초 약화는 장판의 기본 20% 증폭과 별도 출처다. 장판이 사라져도 깨진 균형은 자체
수명을 따른다. 증가율과 둘의 합산, 면역·재부여 세칙은 해당 유물의 미정 사항을 유지한다.
긴 호흡으로 장판의 종료 시점이 늦어지면 이미 기절한 적도 그 종료 시점까지 기절한다.

무아지경은 집중 중인 상태를 보호한다. 침묵 중 새 시전을 허용하거나 직접 취소·사망·퇴각을 막는
효과가 아니다. 자세한 의미는 [공통 태그 정의](../../tags/README.md)를 따른다.

## 후속 조정

- 원형 지속영역의 반경을 늘리는 울림통은 장판 형상이 정해진 뒤 검토할 수 있다. 이번 범위 증가와
  별개의 여섯 번째 연결로 추가하지 않는다.
- 기존 주시와 그 스택 증폭 액세서리의 연결은 새 체류 진행에 자동 적용하지 않는다. 액세서리는 재설계한다.
- 정확한 범위·시간·가속률·증가율·피해 증폭 합산, 유물 등급·중복 장착은 후속 조정한다.
