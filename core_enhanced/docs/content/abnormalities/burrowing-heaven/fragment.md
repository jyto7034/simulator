## 파편 — 이름 미정

> 2026-10-19 리메이크 합의: 빨간 눈·집중 장판·체류에 따른 둔화와 기절·받는 피해 20% 증가.
> 유물 연결 5개와 기본 제어는 느리게, 유물로 성능을 강화하는 방향 합의. 상세 수치·판정과
> 전용 액세서리 리메이크는 후속 조정이며 구현 완료를 뜻하지 않는다.

**시전과 집중**

- 스킬을 시전하면 집중 상태에 들어가고 시전자 위에 빨간 눈이 나타난다. 눈은 집중을 보여주는
  연출이며, 별도로 공격하거나 피해를 받는 유닛이 아니다.
- 꽤 넓은 범위의 장판을 만든다. 장판은 시전 당시 시전자 위치에 고정하며 추종하지 않는다. 정확한 크기·형상은 미정이다.
- 집중 중 기본 공격을 중지한다. 이미 발사된 공격은 유지하며 전술 이동·교대는 공통 규칙에 따라 제한한다.
- 집중에는 유한한 최대 유지 시간이 있으며 플레이어가 직접 취소할 수 있다. 기본 최대 시간은 미정이다.
- 집중이 끝나면 장판과 해당 장판이 부여한 둔화·진행도·기절·기본 피해 증폭도 함께 종료한다.
  빨간 눈이 감기거나 사라지는 연출로 종료를 알린다.

**장판 진입 → 둔화 → 기절**

- 장판 안의 적은 머무르는 시간이 길어질수록 이동 속도가 점차 느려지다가 기절한다.
- 진행도는 대상별 체류 시간으로 계산한다. 기본 공격 적중 횟수나 주시 스택으로 계산하지 않는다.
- 기절하기 전에 장판을 벗어나면 둔화와 진행도를 해제한다. 다시 들어오면 처음부터 진행한다.
- 기절에 도달한 적은 장판이 사라질 때까지 기절한다. 이전 설계의 이동만 막는 속박과 달리
  공격·스킬 등 행동도 기절 규칙에 따라 제한한다.
- 기절 뒤 강제로 장판 밖으로 이동해도 해당 장판 종료까지 기절을 유지한다. 둔화와 기본 피해 증폭은
  이탈 시 해제한다. 독립된 고정 기절 시간을 덧붙이지 않는다.

**받는 피해 20% 증가**

- 장판에 들어온 적에게 진입 순간부터 받는 피해 20% 증가를 적용한다. 기절 도달을 기다리지 않는다.
- 기절 면역인 적에게도 장판의 피해 증폭은 적용한다. 둔화·기절의 면역 판정과 분리한다.
- 장판 밖으로 나가거나 장판이 사라지면 이 기본 증폭은 종료한다.
- 장판 자체는 직접 피해나 지속 피해를 주지 않는다. 아군이 가하는 피해를 돕는 약화 효과다.

**유물을 통한 강화 방향**

기본 상태는 기절까지 비교적 오래 걸리도록 설계한다. 적이 머무는 동안 둔화와 받는 피해 증가를
제공하고, 유물 조합으로 범위·유지 시간·집중 안정성·제어 속도를 강화해 제 성능을 발휘하게 한다.
특히 제어 진행 가속은 둔화가 강해지는 속도와 기절 도달 속도를 높인다. 기본 시간이나 가속률의
새 수치는 이번 합의에 추가하지 않는다.

[합의한 유물 연결](synergies.md)은 범위 증가, 깨진 균형, 긴 호흡, 무아지경, 제어 진행 가속이다.
긴 호흡은 최대 집중 시간만 25% 늘리며, 기절 도달 시간을
늘리거나 장판에 종속된 기절에 다시 25%를 곱하지 않는다.

**이전 설계와의 관계**

직접 공격으로 주시 3스택을 쌓아 자동 속박하는 패시브를 대체한다. 주시를 일정 시간 부여하는 액티브와
주시를 시전 시 소비하는 제안도 채택하지 않는다. 이전 20/50% 둔화, 1초 속박, 2초 재부여 내성과
5초 스택 수명을 새 장판의 수치로 가져오지 않는다. 이전 내용은 [아카이브](review.md#previous-passive)에 보존한다.

전용 지팡이의 광역 가시 공격과 단순 생존 방어구는 유지한다. 주시가 사라져 전용 액세서리의 기존
스택 증폭 연결은 재설계가 필요하다. 새 액세서리 효과는 아직 정하지 않았다.

**2026-10-21 작성 정책**

사용자가 시전 위치 고정·기본 공격 중지를 수락하고 통상적인 게임 정책의 자율 판단을 위임했다.
다음은 기본형의 작성 정책이며 실제 Core 구현 완료를 뜻하지 않는다.

- 위치·방향은 최종 입력 접수 시 고정한다. 위치 선택 단계를 추가하지 않고 고정 장판 의미를 유지한다.
- 둔화는 체류 0에서 0%로 시작하여 기절 도달 시점의 최대 둔화율까지 선형 증가한다.
  별도 곡선 매개변수를 늘리지 않는 단순한 기본형이다. 정확한 시간·최대율·범위·최대 공명은 미정 값으로 둔다.
- 같은 기본 장판 여러 개의 둔화·기본 20% 증폭은 각각 가장 강한 값만 적용한다.
  같은 파편의 중복으로 수치가 무제한 쌓이지 않게 하며 기절은 유효한 출처가 하나라도 남으면 유지한다.
  다른 정의·유물에서 온 증폭의 합산은 해당 계약의 미정 사항을 유지한다.
- 대상은 범위 안의 살아 있는 적군이다. 공중·플랫폼·보스라는 이유만으로 제외하지 않고 각 효과의 면역을
  별도로 판정한다. 둔화 면역도 체류 진행 자체를 막지 않는다. 이후 기절 시점에 기절 면역을 별도로 검사한다.
- 기절 뒤 강제 이동에서도 장판 수명에 묶인 기절을 유지한다. 기본 합의를 그대로 적용하며
  이탈 시 둔화·진행·20% 증폭은 해제한다. 재진입은 진행 0부터이며 같은 출처 기절을 중첩하지 않는다.
- 사망·철수·전투 종료·직접 취소·최대 시간 만료는 집중과 종속 장판을 종료한다. Hard CC는 표준 집중을
  취소하고 침묵은 기존 집중을 유지한다. 강제 이동만으로 별도 중단을 추가하지 않으며 고정 장판은 움직이지 않는다.
  무아지경은 외부 중단 보호만 바꾸고 사망·철수·직접 취소·만료는 유지한다.
- 집중 종료는 같은 시각의 체류 도달보다 우선한다. 종속 구독·관계·효과를 정리한 뒤 사용 잠금을 해제하고
  종료 연출을 낸다. 정지 중 진행·재개 시 보충·취소 환불·집중 자동 재개는 없다.

근거: [전투 규칙](../../../game_rules/combat.md)의 배치와 철수, 전술 이동과 자리 교대, 군중 제어와 침묵,
공명과 스킬 사용 및 [유물 연결](synergies.md). 고유 합의가 없는 세부는 위 공통 규칙과
출처별 상태 수명을 우선하여 복잡한 예외를 추가하지 않았다.

**후속 조정**

- 집중 최대 시간, 최대 둔화율과 기절까지의 체류 시간
- 장판 크기·형상과 콘텐츠별 특수 면역 예외
- 기본 20%와 깨진 균형 등 별도 받는 피해 증가의 합산·갱신·면역 판정
- 유물의 정식 등급·가속률·범위 확대 판정, 전용 액세서리 리메이크
