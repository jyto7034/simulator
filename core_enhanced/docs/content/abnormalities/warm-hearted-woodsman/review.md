## 2026-10-20 재검토

현재 합의는 [범위 3연타](fragment.md#current-2026-10-20)와 [범용 유물 5개](synergies.md)다.
1타 최대 2칸 끌어모으기·피해 → 2타 기절·피해 → 3타 강한 피해·쪼개기로 변경했다.
아래의 단일 대상 고정·대상 사망 시 취소 조립안은 이전 검토이며 현재 범위 공격의 확정 규칙이 아니다.

### 채택하지 않은 전용 유물·기믹

- 장작 패기(가칭): 앞선 1·2타로 처치한 적 수에 비례해 마지막 타격 강화. 제안 기록이며 미채택이다.
- 차징 일격 전환: 3단계 공격을 없애고 N초 차징 후 강한 범위 일격·기절·시전자 반대 방향 넉백.
  이후 쪼개기도 이 단발에 적용하는 안을 제안했으나, 기본 스킬에 기믹을 추가한 뒤 사용자가 전용 유물이
  필요하지 않다고 판단하여 최종 채택 목록에서 제외했다. 차징·넉백을 기본 파편에 합치지 않는다.
- 정확한 벌목: 좁은 중심부의 피해를 높이는 대안. 미채택이다.
- 쪼개기와 끌어모으기는 기본 스킬에 채택했고, 긴 호흡을 포함한 범용 5개 연결도 기록 요청으로 합의했다.

## 파편 — 이름 미정

공명이 가득 차면 착용자가 현재 근거리 주 대상에게 나무꾼의 도끼 특수공격을 사용한다. 현재 공격 연출
초안은 도끼를 빠르게 `2회` 내려찍은 뒤 매우 강력한 마지막 한 방을 내리꽂는 3타 구성이다.

- 세 타격은 장착 무기의 공격력에 비례하는 직접 Physical 피해다.
- 전체 위력의 대부분은 마지막 내려찍기에 배분한다.
- 별도 심장 스택, 처치 조건, 회복과 공격 속도 증가는 두지 않는다.
- 유효한 근거리 주 대상이 없으면 시전할 수 없다.
- 첫 번째나 두 번째 타격 뒤 주 대상이 사망·이탈했을 때 남은 타격을 취소할지 다른 대상에게 이어갈지는
  open design이다.
- 세부 타격 수·간격·피해 배율은 실제 구현과 전투 검증에서 달라질 수 있다. 원본의 `빠른 연타 뒤
  강력한 마무리`라는 공격 문법은 유지한다.

엘리트 파편이므로 파편 자체에 추가 성장 순환을 붙이지 않는다. 기본 피해는 일반 보스 파편보다 낮게
두고, 공격력·직접 스킬 피해 등 Run 유물이 순수 화력을 보강한다.

### Run 유물 — 깊은 쐐기 (가칭)

2026-09-07 합의한 첫 유물이며 희귀도는 **희귀**다. 대체 이름은 **때린 곳 또 때리기**다.
나무꾼 파편의 직접 공격에 유물 설계용 `피해·다중타격` 태그를
적용하고, 같은 시전에서 같은 적에게 적중할 때마다 해당 타격의 피해 증가율을 누적한다.
2026-10-18 후속 합의에 따라 첫 타격부터 `+2%`를 적용하고 타격당 `2%p`씩 증가하며,
같은 시전·같은 대상에서 최대 `+20%`로 제한한다. 10번째 유효 타격 이후에도 `+20%`를 유지한다.
다른 파편도 같은 효과 태그·조건으로 사용할 수 있다. 세부 구조와 미정 사항은
[유물 콘텐츠 설계 노트](../../relics/deep-wedge.md#rel-%EA%B9%8A%EC%9D%80-%EC%90%90%EA%B8%B0--%EA%B0%80%EC%B9%AD)가 소유한다.
이 기록은 콘텐츠 설계이며 현재 runtime·live data에 태그나 유물을 구현했다는 뜻은 아니다.

## 14 따뜻한 마음의 나무꾼

**기존 방향:** 현재 근거리 주 대상에게 빠른 2타 후 강한 마지막 1타를 가한다. 원본 조우의 심장 수집은 파편에 넣지 않는다.

**조립안:** 자기 시전 시 유효 근거리 주 대상 고정 → 빠른 타격 → 짧은 간격 → 빠른 타격 → 마무리 지연 → 강한 타격이다. 모두 무기 공격력 기반 직접 Physical 피해이며 한 시전의 서로 다른 타격으로 남긴다. 유효 대상이 없으면 거절한다.

**상태와 표현:** 이번 시전의 대상·타격 번호·다음 시각만 필요하다. 마지막 도끼의 크기나 충격은 연출로 강화한다. 파편에 심장 자원·자체 흡혈·성장을 추가하지 않는다.

**기능 경계:** 공통 연속 공격으로 작성한다. 같은 시전의 같은 적에게 맞힐수록 강화하는 깊은 쐐기는 실제 타격 순서를 참조한다. 방어구의 직접 active 처치 회복과 액세서리의 실제 피해 흡혈은 출처별 후처리다.

**검토:** 추천은 대상 사망·이탈 시 남은 타격을 취소하고 다른 적으로 옮기지 않는 것이다. 방어구 회복은 처치당 적용하되 시전별 상한을 두는 안을 추천한다. 단순히 3타 피해를 합산하면 쐐기 효과와 처치 시점이 바뀌므로 합치지 않는다.

**태그와 유물 적용**

| 효과 단위               | 태그 후보       | 변경 후보 속성과 지켜야 할 경계                           |
| ----------------------- | --------------- | --------------------------------------------------------- |
| 빠른 1·2타와 강한 3타   | `피해·다중타격` | 각 타격 계수·간격·타격 수. 같은 시전의 직접 타격으로 기록 |
| 방어구의 스킬 처치 회복 | `회복`          | 처치당 회복량·시전별 상한. 파편 효과가 아닌 장비 출처     |
| 액세서리 흡혈           | `회복·흡혈`     | 실제 HP 손실 비례량·상한·자격 출처. 3타 피해와 별도 효과  |

**유물 연결:** 기존 **깊은 쐐기**의 대표 적용 대상이다. 같은 시전·같은 적에 대한 실제 적격 타격별로 증가하며 새 타격을 만들지 않는다. 회복 유물은 장비 회복의 출처 조건을 따로 검사한다. 공격 속도 태그나 능력치 변경만으로 3타 간격을 줄이지 않는다.
