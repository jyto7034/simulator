## 기본 효과의 분류

| 효과 | 기본 태그 | 적용 범위 |
| --- | --- | --- |
| 1타 피해 | 피해 · 범위 | 최대 2칸 범위의 적들에게 직접 물리 피해 |
| 1타 끌어모으기 | 제어 · 범위 | 도끼로 적을 끌어당김. 이동 거리·도착점은 미정 |
| 2타 피해 | 피해 · 범위 | 범위 안의 적들에게 직접 물리 피해 |
| 2타 기절 | 제어 · 범위 · 지속시간 | 적에게 부여하는 유한한 기절. 기본 시간 미정 |
| 3타 쪼개기 | 피해 · 범위 | 강한 직접 물리 피해와 대상의 잃은 체력에 따른 피해 증가 |
| 전체 공격 순서 | 다중타격 | 한 시전에서 순서가 있는 세 직접 타격 |

쪼개기는 3타의 대상별 피해 계산 규칙이다. 별도 스택·처형·추가 피해나 받는피해증가 상태로 분류하지 않는다.
기본 파편에 집중유지·폭발·회복·흡혈을 추가하지 않는다. 양철 몸은 회복, 빌린 심장은 회복·흡혈이며
각 장비 효과로 구분한다. 태그를 파편 전체에 합쳐 서로 다른 효과의 조건을 동시에 충족시키지 않는다.

## 합의한 범용 연결 5개

| 유물 | 대상 태그 | 변경 규칙 | 적용 지점·조건 | 남은 판정 |
| --- | --- | --- | --- | --- |
| [깊은 쐐기](../../relics/deep-wedge.md) | `다중타격` · `피해` | 같은 적 적중마다 +2%p, 최대 +20% | 같은 시전·대상별 실제 적중. 세 번 모두 맞은 적에게 +2% / +4% / +6% | 각 상세 본문의 미정·초안 유지 |
| [넓어진 지평](../../relics/widened-horizon.md) | `범위` | 각 단계의 공격·제어 범위 확장 | 1타 피해·끌어모으기, 2타 피해·기절, 3타 피해 범위. 실제 끌어당기는 이동 거리는 늘리지 않음 | 각 상세 본문의 미정·초안 유지 |
| [무아지경](../../relics/unbroken-trance.md) | `시전` | 진행 중인 시전의 외부 중단 방지 | 3연타가 군중제어·침묵 때문에 중단되지 않음. 상태 부착 면역은 아니며 사망·퇴각 등 원래 종료 조건 유지 | 각 상세 본문의 미정·초안 유지 |
| [깨진 균형](../../relics/broken-balance.md) | `제어` | 기절한 적에게 5초간 받는 피해 증가 | 2타 기절에만 연결. 후속 3타와 아군 공격 강화. 1타 끌어당김에는 자동 적용하지 않음 | 각 상세 본문의 미정·초안 유지 |
| [긴 호흡](../../relics/long-breath.md) | `지속시간` | 효과 유지 시간 25% 증가 | 2타 기절 시간에 적용. 타격 간격·시전 시간·공명·끌어당김 이동 시간을 늘리지 않음 | 각 상세 본문의 미정·초안 유지 |

깊은 쐐기는 한 타격에 여러 적이 맞아도 각 대상의 적중 횟수를 따로 센다. 앞선 타격을 맞지 않은 적이
3타에 처음 맞으면 +2%다. 쪼개기와 함께 3타를 강화하되 두 증폭의 정확한 합성 산식은 후속 조정한다.

넓어진 지평은 기존 공통 정의의 범위 확장을 따른다. 1타 기본 대상 범위 2칸과 실제 끌어당기는 거리를
구분하며, 형태별 한 칸 확장 방식과 2·3타 기본 범위는 후속이다.
깨진 균형의 받는 피해 증가와 기절은 별도 효과다. 2타 자체의 피해에 증폭을 적용하는 순서,
기절 면역·재부여 및 다른 약화와의 합성은 해당 유물의 미정 사항을 유지한다.
긴 호흡의 이번 연결은 기본 기절 시간에 한정하며 깨진 균형의 별도 5초 약화까지 연장하는 것으로 확정하지 않는다.

장작 패기·차징 일격 전환은 [아카이브](review.md)에 보존한다. 다음. 및 다음.도 이번 5개에는 포함하지 않는다.

피해 계수·타격 간격·기절 시간·끌어당김 이동과 면역·범위 형태·쪼개기 산식,
범위 중심과 대상 사망·이탈 처리, 장비의 회복 집계·상한은 후속 결정한다.
