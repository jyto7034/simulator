## 파편 — 이름 미정

> 상태: 2026-10-20 범위 3연타·끌어모으기·기절·쪼개기와 범용 유물 5개 연결 합의.
> 전용 유물은 이번 채택 목록에서 제외. 밸런스·세부 판정은 후속이며 구현 완료를 뜻하지 않는다.

공명이 가득 차면 착용자가 도끼로 적을 끌어모으고, 기절시킨 뒤 강하게 내려찍는 3타 공격을 사용한다.
빠른 앞선 두 타격과 강한 마무리라는 구조를 유지하며, **세 타격 모두 범위 물리 피해**다.
이전 단일 대상 공격은 [아카이브](review.md#previous-single-target)에 보존한다.

| 단계 | 합의한 효과 |
| --- | --- |
| 1타 — 끌어모으기 | 최대 2칸 범위의 적을 도끼로 끌어모으며 물리 피해 |
| 2타 — 기절 | 범위 안의 적들에게 물리 피해와 기절 부여 |
| 3타 — 쪼개기 | 강한 범위 물리 피해. 대상의 잃은 체력이 많을수록 해당 타격의 피해 증가 |

- 세 타격은 장착 무기의 공격력에 비례하는 직접 Physical 피해이며 전체 위력은 마지막 타격에 집중한다.
- 1타의 2칸은 끌어모으는 대상 범위다. 실제 이동 거리·도착점·범위 형태와 2·3타 범위의 정확한 크기는 후속 결정한다.
- 쪼개기는 **대상별 잃은 체력에 따른 3타 피해 계산 규칙**이다. 별도 스택, 처형 판정이나 추가 타격이 아니다.
  대상의 잃은 HP 절대량·비율 중 참조 기준, 산식·계수·상한과 HP를 읽는 시점은 후속 조정한다.
- 기본 파편에는 별도 심장 자원, 처치 누적 성장, 자체 회복·흡혈이나 공격 속도 증가를 넣지 않는다.
- 기존 self 시전·공명 사용 체계를 유지한다. 범위 공격으로 바뀐 뒤 필요한 최초 대상 조건,
  각 단계의 범위 중심·방향·대상 재판정과 대상 사망·이탈 처리는 후속 결정한다.
  이전 단일 주 대상 고정·사망 시 취소 제안을 새 범위 공격에 자동 적용하지 않는다.
- 기절 시간·면역·재부여, 끌어당김과 피해의 처리 순서, 단계별 계수·간격은 미정이다.

엘리트 파편으로서 기본 피해는 일반 보스 파편보다 낮게 두고, 범위·제어·연타 유물로 운용을 보강한다.
새 기믹 때문에 조우의 심장 수확이나 무기의 단일 기본 공격까지 변경하지 않는다.

## 2026-10-22 공통 작성 계약의 세부 정책

일반 게임 정책에 대한 작업 위임으로 아래 경계를 구체화한다. 작성 모델에 반영하는 정책이며,
Core 컴파일·실제 전투 검증 완료를 뜻하지 않는다.

1타는 실제 타일 패턴을 별도로 작성하고 기준 타일에서 Chebyshev 거리 2칸 이내인지 검사한다. 피해 뒤 중심을 넘지 않는 강제 이동을 적용하고 지형·충돌·면역을 따른다. 각 타격은 당시 전방 위치·방향과 현재 범위 적을 새로 조회하며 최초 선택 적의 사망 때문에 범위 3연타를 취소하지 않는다. 3타는 피해 직전 대상별 잃은 HP 비율에 따른 선형 증가와 상한을 적용한다. 정확한 타일·계수·이동 거리·간격·기절 시간은 미정이다.


## 2026-10-22 실행 연결에서 확정한 경계

위 작성 정책의 유한 타격·대기·적중 제어를 Core 컴파일과 전투에 연결했다. 미정 밸런스 값은 원본에 그대로 남는다.
최초 접수에는 유효 적과 타격 가능 범위가 필요하며, 접수 이후에는 각 타격 방출 시 현재 전방 범위를 재조회한다.
무기 계수 위력과 최종 잃은 HP 보정 위력은 올림하고, 잃은 HP 비율 자체를 정수 백분율로 자르지 않는다.
피해 뒤 죽었거나 이동 불가인 대상의 당기기는 생략한다. 기절과 그 성공으로 생긴 깨진 균형의 약화는 각각 유한 수명을
소유하므로 3타 종료나 시전자 철수 때문에 함께 끝나지 않는다. 기절 면역이면 약화도 생기지 않는다.
무아지경은 진행 중 스킬의 외부 중단만 보호하며 제어 부착·기본 공격 취소·사망·자발적 철수는 보존한다.
[실행·화면 검증 근거](../../../../../content_assembler/artifacts/p8-strike-20261022/verification.json)는
밸런스 입력을 채운 별도 사본으로 수행한 결과이며 미정 수치를 최종 채택했다는 뜻이 아니다.
