현재 파편 본문: [탐욕의 왕](fragment.md).

**2026-10-20 재합의:** 황금의 지평선을 차징·포탈 붕괴·한 발씩 착탄 확인하는 범위 포격으로 교체했다.
초기 재고 10, 자동 대여 한도 20, 자신의 피해로 5~10초 회수 상태 부여, 상태가 남은 적 사망 시
재고 +1이다. 빚은 다음 전투 지급량에서 차감하고, 대출을 사용한 바로 다음 전투는 대여 불가다.
[범용 5개·전용 2개](synergies.md)까지 구조 설계를 닫고 밸런스는 후속으로 둔다.

아래 욕망 저축·동시 직선 공격·4스택 전용 전장 충격파는 대체된 기록이다. 다음 제안도 현재안에
섞지 않는다: 기본형의 체력 차감·치유 감소, 전투 종료 시 빚 탕감, 대출 허용 토글, 대상별 사격 예약,
표적 고정으로 잔여 보구 소실, 파괴 가능한 포탈. 기본형의 체력 비용 제안과 채택된 전용 무한 사출의
최대 체력 5% 비용은 서로 다르다. 대여 한도 증가 유물은 미채택 추가 후보로 남는다.

## 스킬 파편 능력:

- 욕망은 시간 경과나 처치로 얻지 않는다. 공명 만충에서 `축적`을 선택해 공격 없이 공명을 `0`으로
  반납해야 1스택을 얻으며, 파편 인스턴스가 해당 run 동안 소유한다.
- `발사`는 공명과 욕망을 전부 소비한다. 욕망 `0~3`에서는 포탈 `1~4`개가 한 번의 방향 입력에 따라
  서로 다른 직선 공격선을 덮고, 욕망 `4`에서는 일반 포격 대신 `황금의 지평선`을 사용한다.
- 황금의 지평선은 일괄 처형이 아니라 필드의 eligible 적에게 큰 실제 피해를 주는 광역기다. 무적,
  피해 차단과 Boss phase gate를 우회하지 않는다.
- 조우에서 탐왕이 포식으로 성장하지 않으므로 처치·포식 stack은 파편의 성장 source로 사용하지 않는다.

## 12 탐욕의 왕

**기존 방향:** 공명을 욕망으로 저장하거나, 저장한 욕망을 전부 소모해 차원문 공격을 사용한다.

**조립안:** 최대 공명에서 저장/발사 선택. 저장은 공명 전부 소비와 욕망 1 증가, 발사는 공명과 욕망 전량 소비 후 공격이다. 욕망 0~3은 각각 1~4개 차원문, 4는 전장 유효 대상 공격으로 바뀌는 기존 방향을 사용한다. 최대치에서 저장은 비용 없이 거절한다.

발사는 한 번의 방향·끝점 입력으로 차원문 배치를 정한다. 문마다 별도 조준을 요구하지 않는다. 문은 발사 원점이며 직원이나 적을 이동시키는 포털이 아니다. 같은 적에게 몇 문까지 맞을지는 공격 정의에서 제한한다.

**상태와 표현:** 욕망은 사본의 원정 누적값이다. 차원문 그림과 실제 발사 원점·범위는 대응해야 한다. 활의 수직 화살은 한 공격 행동으로, 액세서리의 유익 효과 소비는 별도 입력으로 다룬다.

**기능 경계:** 선택형 자원 저장·소모 + 다중 발사. 액세서리는 소비 가능한 유익 효과 목록, 출처와 소유권, 실제 소비량에 따른 강화가 필요하다. 임의의 모든 버프를 지우는 기능으로 만들지 않는다.

**검토:** 추천은 같은 적에 대한 문별 타격을 보존하되 최대 적중 횟수를 명시하는 것이다. 욕망 4의 전장 공격이 단일 공격인지 다수 문 타격인지, 비전투 중 형태 교체 때 욕망 유지 방식도 정한다.

**태그와 유물 적용**

| 효과 단위           | 태그 후보                           | 변경 후보 속성과 지켜야 할 경계                                  |
| ------------------- | ----------------------------------- | ---------------------------------------------------------------- |
| 욕망 저장           | `스택`                              | 저장량·상한·단계별 공격 변환. 공명 지불과 사본 원정 수명 유지    |
| 차원문별 공격       | `피해`, 전달에 따라 `투사체`·`관통` | 위력·발사 원점·탄 수·대상별 한도. 문 그림 자체는 `소환물`이 아님 |
| 최대 욕망 전장 공격 | `피해·범위`                         | 자격 대상·타격 수. 범위 유물로 전장 밖 대상을 만들지 않음        |

**유물 연결:** 욕망 상한 변경은 공격 단계표까지 정해야 하는 전용 후보다. 탄환으로 작성된 공격에는 새 투사체 유물을 검토할 수 있다. 여러 문 동시 발사를 자동으로 `다중타격`으로 세지 않는다. 액세서리가 유익 효과를 소비해 주는 강화는 별도 `능력치변경` 효과다.

## 파편 — 황금의 문 (가칭)

공명이 가득 차면 즉시 공격하거나, 그 공격 기회를 포기해 run-local `욕망`으로 축적할 수 있다. 욕망은
시간을 기다리거나 적을 처치해서 자동으로 얻는 스택이 아니다. **이미 완성된 파편 시전 한 번을 실제로
반납해야만** 1스택을 얻는다.

**공명 만충 선택 — 발사 / 축적**

공명 만충에서 플레이어는 다음 두 operation 중 하나를 고른다.

`발사`:

- 현재 욕망에 대응하는 포탈 공격을 시전한다.
- 시전 commit에서 공명과 보유한 욕망을 전부 소비한다.
- 욕망 일부만 남기거나 포탈 수만 낮춰 발사하는 부분 소비는 허용하지 않는다.

`축적`:

- 공격과 피해를 전혀 발생시키지 않는다.
- 완성된 공명을 전부 소비해 `0`으로 되돌리고 욕망 1스택을 얻는다.
- 공명 소비와 욕망 획득은 하나의 원자적 transaction이다. 취소·실패·disconnect에서 한쪽만
  적용하지 않는다.
- 욕망이 최대라면 축적할 수 없고 공명도 소비하지 않는다.

공명 만충 뒤 단순히 시간을 보내거나 skill-ready 상태로 전투를 끝내는 것만으로 욕망을 주지 않는다.
플레이어가 `축적`을 명시적으로 확정해야 한다.

**욕망의 소유권과 유지**

- 욕망은 직원이 아니라 개별 파편 인스턴스가 소유한다.
- 전투와 node 사이, Maintenance와 checkpoint save/load를 넘어 해당 run 동안 유지한다.
- 파편을 다른 직원에게 옮겨도 같은 인스턴스라면 욕망을 보존한다.
- 같은 파편을 여러 개 소유할 수 있다면 각 인스턴스가 별도 욕망을 가진다.
- Retreat는 진입 전 savepoint 값으로 복원하고 run 종료 시 초기화한다.
- 첫 prototype의 최대치는 `4`스택이다. 장착자 HP 0에서 욕망을 잃는 추가 위험은 기본안에 넣지 않고,
  공명 시전 포기만으로 기회비용이 부족할 때 재검토한다.

**욕망별 발사 형태**

| 욕망 | 발사 형태 |
| ---: | --- |
| 0 | 황금 포탈 1개 |
| 1 | 황금 포탈 2개 |
| 2 | 황금 포탈 3개 |
| 3 | 황금 포탈 4개 |
| 4 | 전장 광역기 `황금의 지평선`으로 강제 변환 |

욕망 `0~3`에서는 플레이어가 하나의 주 진행 방향 또는 portal endpoint를 지정한다. 서버가 포탈을
공격선이 서로 다른 전장 구역을 덮도록 deterministic하게 배치하고, 모든 포탈이 같은 timing에
일직선 공격을 발사한다.

- 각 포탈에서는 거대한 황금 무기 또는 탐욕의 왕을 닮은 괴물의 턱이 직선으로 돌진한다. 둘 중 어느
  presentation을 사용할지는 open design이며 gameplay 판정은 동일하다.
- 포탈 수가 늘어날수록 한 대상에게 중첩되는 피해보다 공격선 수와 전장 coverage가 증가한다.
- 여러 공격선이 같은 대상을 겹쳐 지날 때의 최대 피격 횟수에는 상한을 둔다.
- 붉은 두건처럼 포탈마다 방향을 하나씩 수동 지정하지 않는다. 한 번의 방향·endpoint 입력으로 전체
  포탈 배치와 발사를 확정한다.
- 공격선의 길이, 폭, 장애물, 공중 유닛, 아군과 중립 object 판정은 open design이다.

이 구조는 붉은 두건의 처치 기반 창 생성·개별 궤적 설계, 흉탄의 처치 지점 재귀 확산과 다르다.
탐욕의 왕은 현재 전투에 쓸 수 있었던 시전 기회를 저축해 다음 공격의 **물량과 coverage**를 산다.

**최대 욕망 — 황금의 지평선 (가칭)**

욕망 `4`에서 `발사`하면 일반 포탈 포격을 선택할 수 없고 다음 전장 광역기로 강제 변환된다.

1. 전장 바닥 전체에 거대한 황금 포탈과 균열이 나타난다.
2. authored windup 동안 공격 범위와 발동 timing을 충분히 예고한다.
3. 바닥 포탈에서 엄청난 크기의 황금 무기가 하늘을 향해 솟구친다.
4. 무기가 완전히 드러나는 순간 충격파가 발생해 필드의 모든 eligible 적에게 큰 피해를 준다.
5. resolution을 마친 뒤 공명과 욕망은 모두 `0`이다.

황금의 지평선은 침식형의 일괄 처형이 아니라 실제 광역 피해다. 무적, 피해 차단과 Boss phase gate를
우회하지 않고, 일반 적을 정리할 수 있는 고점은 주되 강한 적과 환상체의 생존 여부는 실제 HP와
피해 계산이 결정한다. 피해 type, 대상 범위, 공중 유닛과 소환물 포함 여부는 open design이다.
