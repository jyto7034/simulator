## 탐욕의 왕

> 상태: 2026-10-20 황금의 지평선·재고 대여·범용 유물 5개·전용 유물 2개 구조 설계 종료.
> 장궁·방어구·팔찌의 독립 구조는 유지. 밸런스·세부 판정·이름·장비 수치는 후속.

[조우](encounter.md)의 채굴·포식과 직원용 파편의 재고는 별개다. 파편은 황금 포탈에서 보구를
꺼내 한 발씩 범위 공격하고, 자신의 피해로 상태를 남긴 적이 죽으면 재고를 회수한다. 초기 재고는
10, 자동 대여 한도는 20이며, 남은 빚은 다음 전투 지급량에서 차감하고 그 전투의 대여를 막는다.
무기는 황금 장궁의 화살을 포탈에 넣어 지정 타일 위의 적을 한꺼번에 폭격하는 Platform 광역 딜러다.

플레이어 무기의 최신 합의안은 **길가메쉬 모티브의 황금 장궁**이다. 이전 건틀릿 직접 타격과
후방 포탈 후속타를 조합한 `Sword`안은 대체되었으며, 조우 문서의 이전 무기 요약을 다시 채택하지 않는다.

### 전용 조합과 독립성

- 파편은 황금 장궁 없이도 다른 호환 무기에서 황금의 지평선·재고 회수·대여를 사용할 수 있다.
- 황금 장궁의 기본 공격 포탈은 파편 재고를 소비하지 않는다. 파편 소유자에게 귀속되는 장궁 피해는
  회수용 상태를 부여할 수 있다. 전용 기절은 보구 사출에만 붙고 모든 기본 공격으로 확장하지 않는다.
- 황금 장궁은 다른 파편에서도 고정한 한 타일 위의 적을 포탈 화살로 폭격하는 기본 공격이 완결된다.
- 탐욕의 팔찌는 현재 자기 보유 이로운 효과 중 소비를 허용한 것을 선택해 일시적인 공격력으로
  전환한다. 황금 장궁을 요구하는 set 전용 효과가 아니다. 대체된 욕망의 소비 후보를 새 보구 재고나
  빚에 자동으로 이전하지 않으며, 새 재고의 팔찌 소비 허용 여부는 별도 검토한다.
- 방어구는 세트 자원과 결합하지 않고 Platform 원거리 딜러의 생존 수치만 제공한다.

<a id="frag-미결정-사항-10"></a>
### 미결정 사항

- 파편, 공격, 황금의 지평선, 액세서리의 최종 이름
- 파편과 장비의 `rarity`, `equip_limit`, 획득 경로와 강화 recipe
- 파편 compatibility, 차징·사출 입력, 전개 속도·최대 전개량·포탈 유지·붕괴 기한
- 각 보구의 피해·반경·사거리·비행 시간·표적 추적/타일 고정·공중·장애물·Boss phase gate 처리
- 회수용 상태의 정확한 5~10초 값·표시·대상 자격과 복수 출처 판정
- 재고의 양수 상한, 저장·복수 사본·미참전·이전·합성 시 정산 계약
- 전용 기절 시간·재적용·면역, 무한 사출 HP 비용의 초 경계·반올림·생존 효과 호환
- 황금 장궁의 사거리·공격력·공격 주기·windup·impact 지연과 공격 타일 선택 우선순위
- release/impact 타일 점유, 공중 유닛의 projected tile, 다수 대상 on-hit·resonance·kill credit 계약
- 방어구의 정확한 방어력·최대 HP와 강화 성장치
- 팔찌의 단계 수·소모량 임계치·단계별 공격력 증가율과 고정 지속 시간
- 팔찌의 재사용 대기시간, 버프 유지 중 재사용·갱신·중첩과 다른 공격력 modifier의 합성
- 소모 가능한 이로운 효과 목록·제거 판정, 스택 없는 버프의 소비 허용·수량 환산
- 액티브 입력·사용 시 효과 선택 UI, 소비·버프 부여와 취소·실패 처리, 파편 시전과의 동시 사용 판정
- 팔찌 버프의 공격력 참조 시점, 전투 종료·이탈·재배치와 checkpoint/savepoint 처리
