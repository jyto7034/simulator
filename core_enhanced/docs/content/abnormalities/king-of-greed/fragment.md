## 파편 — 황금의 지평선 (가칭)

> 상태: 2026-10-20 기본 파편·범용 유물 5개·전용 유물 2개 구조 설계 종료.
> 초기 재고 10·자동 대여 한도 20·상태 보유 적 사망 시 재고 +1 합의.
> 상태 유지 시간은 5~10초 범위이며 정확한 값과 나머지 밸런스·세부 판정은 후속 조정. 구현 완료를 뜻하지 않는다.

황금 포탈을 열어 보구를 꺼내고, 준비된 보구를 적에게 한 발씩 사출한다. 보구를 꺼낼 때 재고를
소비하며, 더 큰 포격을 위해 다음 전투의 기본 지급량까지 자동으로 당겨 쓸 수 있다. 피해를 준 적에게
남긴 회수용 상태를 통해 재고를 다시 얻는다. 길가메쉬의 보물고·보구 사출을 모티브로 한다.

이전의 공명 반납→욕망 저축과 욕망 4스택에서만 사용하던 전장 광역기는 대체한다. 이제 공명이
가득 차고 자원·행동 조건을 만족하면 황금의 지평선 자체를 사용할 수 있다. 무상 상시 자동 공격이나
바닥에서 무기가 솟는 일괄 충격파가 아니다. [대체된 원문](review.md#previous-desire)을 별도로 보존한다.

### 전개·사출·포탈 붕괴

- 차징 시작 시 공명을 전부 소비한다. 차징과 연속 사출이 끝날 때까지 공명 획득은 공통 규칙대로
  잠긴다. 보구마다 공명을 다시 소비하거나 사출 재입력에 추가 공명을 요구하지 않는다.
- 차징은 집중 행동이며 이동·기본 공격을 하지 않는다. 황금 포탈이 차례로 열리고 보구가 모습을
  드러낸다. 후반에 포탈 생성 간격이 짧아지는 전개를 기준으로 하되 시간·증가 곡선은 후속 수치다.
- **포탈 1개가 실제 생성될 때 재고 1을 소비한다.** 한 포탈은 보구 한 발을 준비한다. 재고를
  미리 전량 소비하거나 사출·명중 시 같은 비용을 다시 받지 않는다.
- 원하는 시점에 재입력하면 추가 전개를 멈추고 남아 있는 준비 보구 수를 이번 사출량으로 확정한다.
  전량 동시 발사가 아니라 아래의 착탄 확인 순서로 한 발씩 사출한다.
- 한 번의 최대 전개량은 초기 재고·보유 재고·대여 한도와 별도다. 정확한 전개 상한은 후속 조정하며,
  초기 10이나 대여 20을 그대로 동시 포탈 수로 해석하지 않는다.
- 최대 전개 후 잠시 유지할 수 있지만 기한을 넘기면 오래된 포탈부터 닫히며 준비된 보구를 잃는다.
  붕괴가 시작되면 새 포탈을 더 열지 않는다. 남은 보구만 사출할 수 있다.
- 발사 기한은 전개 시작부터 전투 시간으로 진행한다. 재고·대여 한도 부족으로 포탈 생성이 멈춰도
  기한은 멈추지 않는다. 재고를 소진한 상태로 무기한 최대 위력을 보관할 수 없다.
- 사출을 명령하면 확정한 보구에 대한 준비 포탈의 붕괴는 멈춘다. 뒤 순서의 보구가 사출 연출을
  기다린다는 이유로 추가 소실되지 않는다. 외부 효과에 의한 시전 중단은 별도 공통 규칙을 따른다.
- **붕괴·취소·중단으로 잃은 보구의 재고는 환불하지 않는다.** 그때 발생한 대출도 사라지지 않는다.
  기본형에는 보구 생성에 따른 별도 자기 체력 비용을 넣지 않는다.

### 전투 재고와 자동 대여

재고 잔고를 `R`이라고 한다. 양수 재고는 전투 로컬이며, 미상환액과 대출 사용 이력은 다음 전투로
이어진다. 초기값 10은 지급량이지 양수 재고 상한이 아니다. 양수 상한의 필요 여부·값은 후속 조정한다.

| 항목 | 현재 규칙 |
| --- | --- |
| 기본 초기 지급량 | 전투마다 10 |
| 일반 포탈 생성 비용 | 1개당 재고 1 |
| 처치 회수 | 자신의 회수용 상태를 가진 적이 죽으면 재고 +1 |
| 대여 한도 | 미상환 잔고 최대 20. 대여 가능 전투에서 잔고 하한 −20 |
| 대여 입력 | 별도 옵션·허용 토글 없이 자동 적용 |
| 다음 전투의 지급 | 기본 10에서 이전 전투 종료 시 미상환액을 차감 |
| 다음 전투의 대여 | 이전 전투에서 대여를 사용했다면 불가 |

- `R >= 1`이면 재고 1을 지불하고 포탈을 생성한다.
- 재고가 부족해도 이번 전투에서 대여가 가능하고 생성 후 잔고가 −20 이상이면 자동 대여한다.
  실제 대여가 발생하면 이번 전투의 대출 사용 이력을 남긴다.
- 대여 불가 전투에서는 생성 비용을 전부 양수 재고로 지불해야 한다. 잔고가 0 이하라면 일반
  포탈을 추가 생성할 수 없지만, 이미 준비한 보구의 사출이나 기본 공격·패시브 회수는 가능하다.
- 대여 한도는 시전마다 새로 지급하는 20이 아니다. 처치로 일부 갚으면 그만큼 다시 빌릴 수 있지만,
  미상환 잔고 −20을 넘겨 추가 생성하지 않는다.
- 회수한 재고는 잔고에 더한다. 음수이면 먼저 빚을 갚는 결과가 되며, 같은 전투에서 빚을 전부
  갚았어도 **대출 사용 이력은 남아 다음 전투의 대여를 막는다.**
- 사출 중 처치로 얻은 재고는 빚을 갚거나 다음 시전에 쓴다. 이번에 확정한 사출량에 새 포탈을
  끼워 넣거나 처치할 때마다 연속 사출을 무한 연장하지 않는다.

### 전투 사이의 정산

```text
미상환액 = max(0, -전투 종료 잔고)
다음 전투 시작 잔고 = 10 - 미상환액
다음 전투 대여 가능 = 이번 전투에서 대여를 사용하지 않았음
```

이전 전투의 양수 잔고를 다음 전투에 더해 저축하지 않는다. 반대로 음수 잔고를 0으로 보정하거나
전투 종료를 이유로 탕감하지 않는다. 차감 지급으로 갚은 몫을 다시 별도 채무로 중복 청구하지 않는다.

| 예시 | 시작·정산 결과 |
| --- | --- |
| A에서 대여 사용 후 −20으로 종료 | B는 10−20 = **−10**, 대여 불가 |
| B가 −10에서 회수 10회 | 잔고 0. 기본 회수량 기준 11회째부터 포탈 1개 생성 가능 |
| B가 아무것도 회수하지 못해 −10으로 종료 | C는 10−10 = **0**. B에서 새 대여를 쓰지 않았으므로 C는 대여 가능 |
| A가 대여했지만 종료 전 잔고를 0 이상으로 회복 | B는 10으로 시작하지만 대여 불가 |

차감 때문에 음수로 시작한 것은 해당 전투의 새 대출로 세지 않는다. 대출하지 않은 전투를 거치면
다음 전투의 대여 자격은 돌아오지만, 남은 빚은 위 공식으로 계속 차감한다.

재고·회수용 상태의 출처와 정산 기록은 개별 파편 인스턴스에 연결한다. 같은 인스턴스의 직원 교체나
전투 중 재배치로 초기 재고를 다시 지급하거나 빚·대출 제한을 지우지 않는다. 기존 Retreat의 진입 전
savepoint 복원과 run 종료 초기화 원칙은 유지한다. 미참전·파편 합성·복수 사본의 상세 정산 시점은
후속 저장·귀속 계약에서 정하며, 빚을 장착자 교체만으로 탕감하는 규칙으로 바꾸지 않는다.

### 패시브 — 피해 표식과 재고 회수

파편 소유자가 **어떤 방식으로든 자신에게 귀속되는 피해를 입히면**, 피해를 받은 적에게 회수용
상태를 부여한다. 보구 전용 적중 효과가 아니며 기본 공격·스킬·장비 파생 피해·지속 피해에도 적용한다.

- 상태는 **5~10초** 유지한다. 정확한 기본 시간은 후속 조정한다.
- 같은 출처로 다시 피해를 주면 남은 시간을 갱신한다. 상태를 여러 스택으로 쌓지 않는다.
- 상태가 남아 있는 적이 사망하면 해당 출처의 재고를 **1** 얻는다. 마지막 피해를 다른 아군이
  가했어도 획득한다. 상태가 만료된 뒤의 사망에는 지급하지 않는다.
- 첫 피해가 치명타격인 경우에도 그 피해의 상태 부여를 인정한 뒤 사망·회수를 처리한다.
- 한 적이 여러 보구와 범위 피해에 맞았어도 같은 출처에서 같은 사망으로 얻는 기본 재고는 1이다.
- 이 상태 자체는 피해·기절·받는 피해 증가를 제공하지 않는다. 상태 이름과 표시는 미정이다.
- 양수 재고를 얻는 패시브이며 공명 획득과 다르다. 시전 중 공명 획득 잠금이 처치 회수까지 막지는 않는다.

### 공격 처리 — 한 발의 착탄을 확인한 뒤 다음 표적 선택

1. 이번 보구가 공격할 수 있는 살아 있는 적 중 **자신의 회수용 상태가 없는 적**을 우선한다.
2. 우선 대상 중 **루트 진행도가 가장 높은 적**을 고른다. 시전자와의 직선거리가 기준이 아니다.
3. 상태가 없는 유효 적이 없다면 상태 조건을 풀고, 전체 유효 적 중 루트 진행도가 가장 높은 적을 고른다.
4. 보구 한 발을 사출한다. 보구는 실제 투사체로 전달되며 착탄 지점에 범위 피해를 준다.
5. 그 보구의 범위 피해·상태 부여·사망·재고 회수를 모두 처리한 뒤 다음 보구의 표적을 새로 고른다.

단순히 발사 시각만 어긋나게 하고 여러 보구가 동시에 비행하도록 하지 않는다. 앞 보구의 착탄과
피해 판정이 끝나기 전에 다음 표적을 선정하지 않으므로, 별도의 사격 예약·예상 피격 횟수 표식은
사용하지 않는다. 범위 피해로 주변 적도 상태를 얻어 다음 보구가 다른 무리로 향한다.

모든 적에게 상태가 있거나 보스 하나만 남으면 같은 적에게 계속 사출할 수 있다. 같은 적을 이미
맞혔다는 이유만으로 남은 보구를 버리지 않는다. 각 보구의 범위 피해는 같은 적에게 한 번씩 적용하며,
서로 다른 보구는 같은 적을 다시 맞힐 수 있다. 실제 비행 속도·피해·반경은 후속 수치다.

발사 뒤 다른 적으로 자동 표적 변경하는 효과는 추가하지 않는다. 이동 중인 표적을 추적할지,
사출 시점의 타일을 고정할지와 빗나감·장애물·대공 등 세부 전달 판정은 후속 계약이다. 착탄 없이
투사체가 종료되는 경우에도 해당 보구의 판정 종료 후 다음 선택으로 진행하며, 적중하지 않은 적에게
상태나 재고를 지급하지 않는다. 새 적을 고르는 기본 사출 규칙에 유물 `다음.`을 요구하지 않는다.

### 유물·장비·종료

[범용 연결 5개와 전용 유물 2개](synergies.md)를 합의했다. 범용은 넓어진 지평·스택획득·긴 호흡·
깊은 쐐기·무아지경이다. 전용은 [왕의 위압](../../relics/king-of-greed-stunning-treasures.md)와
[끝없는 금고](../../relics/king-of-greed-endless-treasury.md)이며, 두 유물의 최종 등급은 미정이다.

무한 사출은 최대 체력의 5%를 매초 지불하고 재고 소비 없이 집중 사격을 지속하는 전환이다.
일반형의 대출·차징 규칙에 자기 체력 비용을 기본으로 합치지 않는다. 자세한 적용과 종료는 전용 유물이 소유한다.

황금 장궁의 기본 공격에 보이는 포탈은 이 파편의 재고를 소비하지 않는다. 장궁으로 적에게 피해를
주면 파편의 회수용 상태는 부여할 수 있다. 황금광과 탐욕의 팔찌의 독립 효과는 유지하며, 새 재고를
팔찌가 소비할 수 있는 이로운 스택으로 자동 편입하지 않는다.

기절·빙결에 의한 차징·연속 사출 취소와 공명 미환불, 이미 방출한 효과의 진행은
[전투 규칙](../../../game_rules/combat.md)을 따른다. 무아지경은 합의한 시전 보호 범위만 변경하고,
자발적 종료·사망·철수·포탈 기한·재고 비용·대출 정산을 없애지 않는다.

### 후속 조정

## P4 작성 세칙 — 2026-10-22

아래 세칙은 통상 정책을 정하도록 한 2026-10-21 사용자 위임에 따른 작업자 결정이다.
기존 합의된 스킬 구조를 유지하며, 아래에 명시한 항목은 앞선 미정 목록에서 해소한다.

원장은 파편 사본에 귀속한다. 전투 진입에 장착한 사본은 배치 여부와 무관하게 승패 확정에 한 번 정산하고,
미장착 전투는 건너뛴다. 양수 잔고는 이월하지 않고 음수 미상환액과 직전 대출 사용 이력만 보존한다.
직원 교체·재배치로 초기화하지 않으며 Retreat는 진입 전 savepoint, 원정 종료는 초기 상태로 돌아간다.
합성·양도는 원장 승계 연결 계약이 필요하다. 기본형 양수 잔고에는 별도 상한을 두지 않는다.

생성 간격은 최대 포탈 수에 따라 첫/마지막 간격 사이를 선형으로 줄인다. 각 시간과 최대 수는 미정이다.
발사 재입력에서 추가 생성과 붕괴를 멈추고 남은 수를 고정하며, 기한/붕괴는 동시 재입력보다 우선한다.
보구는 물리·공중 포함·장애물 정지이며 원래 대상만 추적한다. 범위/속도/거리/수명은 미정이다.
한 발의 소멸·피해·상태·사망·회수까지 정산한 뒤 다음 적을 고른다. 자기 상태 없음·루트 진행도 뒤 동률은
출현 순서/ID로 결정하고 대상이 없으면 나머지를 무환불 종료한다.
회수 상태는 소유자의 모든 귀속 양수 실제 HP 피해에 붙이며 보호막만 손상·0피해는 제외한다.
치명타격도 사망 전에 부여하고, 이후 다른 아군이 죽여도 상태가 유효하면 사본당 한 번 +1을 지급한다.
방출한 탄환은 집중 종료 후에도 정산하며 미방출 목록을 재개하지 않는다.

실제 노드 그래프·정적 진단·저장 계약은 [P4 공통 계약](../../../../../content_assembler/docs/common-skill-graph-contract.md#관계행동-계획입력-확정전투-원장--p4-2026-10-22)을 따른다.
장비·유물·복수 사본 조합은 P6에서 대조하고, Core 컴파일·전투 실행은 후속이다.
