## 풍운승려

> 상태: Platform·저지 0의 범위 Physical 염주 Staff, 광역 물어뜯기·적중 시 1회 자기 회복 파편,
> 높은 체력 유지 시 공격력 증가 방어구와 물리 방어 관통 액세서리의 기본 구성 합의 /
> 이름·수치·대상 선택 등 세부 판정 미정 / 현재 미구현

조우 설계는 `abnormality_design_notes.ko.md`의 `풍운승려` 절이 소유한다. 플레이어 보상은 원거리
물리 광역 화력을 담당하는 공격형 Staff로 정한다. 무기 분류가 Staff여도 피해 type을 Magic이나
회복으로 고정하지 않는다. 앞서 검토한 근접 Spear 방향은 채택하지 않는다.

원작 참고: [한국어 기록](https://tiphereth.zasz.su/lc/abnormalities/100105/?lang=kr),
[전투 패턴](https://lobotomycorporation.wiki.gg/wiki/Clouded_Monk),
[아미타 무기](https://tiphereth.zasz.su/lc/equip/200105/).
원작의 돌진·물어뜯기·적중 시 자기 회복을 파편의 모티프로 삼되, 후방 배치를 유지할 수 있도록
직원 대신 아귀 형상을 보내고 물어뜯기의 피해를 범위 공격으로 각색한다. 형상과 광역 판정은
플레이어용 각색이지 원작에 그대로 있는 기능은 아니다. 무기는 원작의 석장 대신 염주로 정한다.

### 전용 조합과 역할

- 염주 Staff는 평상시 물리 범위 공격, 파편은 필요할 때 사용하는 큰 광역 타격과 보조 자기 회복이다.
- 해진 가사는 높은 체력 유지에 공격력으로 보상하고, 치아사리는 물리 방어가 높은 적을 상대할
  효율을 보완한다. 어느 쪽도 전용 파편 사용이나 사리 수집을 전제로 하지 않는다.
- 파편은 다른 Staff로도 물리 피해와 자기 회복을 완결한다. Staff 분류나 장착 무기의 피해 type을
  근거로 파편을 Magic으로 바꾸지 않는다.
- 래티씨아의 소환 성장, 눈의 여왕의 Magic·냉기 제어, 태아의 초고속 선형 공격과 구별되는
  `느리고 묵직한 원거리 물리 범위 공격 + 단발 광역 버스트`를 목표로 한다.

### 미결정 사항

- 파편·장비의 최종 이름, 파편 희귀도·중복 장착 제한·호환 범위
- 기본 공격 사거리·범위·주기·위력·대공 여부·목표 선택·목표 위치 확정 시점과 Platform Rest
- 파편의 자동 대상 선택·사거리·범위·준비 시간·전달 방식·위력과 대상 이탈·동시 피해 판정
- 파편의 회복 비율, 보호막 적중 등 유효 적중의 경계와 철수·전투불능 시 lifecycle
- 방어구 기본 stat·체력 임계 비율·공격력 증가율과 기존 modifier 합성
- 액세서리 관통률·eligible source·방어 감소 및 다른 관통과의 적용 순서
- 각 장비 강화 성장치와 실제 전투 수치 검증, 전용 Run 유물의 설계 여부
