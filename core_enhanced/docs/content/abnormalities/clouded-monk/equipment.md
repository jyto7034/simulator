## 무기 — 아미타 (가칭)

> 염주 외형·Staff 분류·범위 Physical 피해, 후방 Platform·저지 0과 묵직한 단발 범위 공격 방향 합의.
> 사거리·범위·주기·위력·대공 여부·목표 선택 등의 세부 수치와 판정은 미정이다.

| 항목 | 값 |
| --- | --- |
| `range_role` | 원거리 광역 물리 딜러 |
| `weapon_archetype` | `Staff` |
| `deployment_affinity` | Platform 전용 |
| `block_capacity` | `0` |
| `ground_defense_focus` | 해당 없음 |
| `platform_rest` | open design |
| `damage_type` | Physical |
| `targeting_profile` | 범위 내 Route 진행도가 가장 높은 적 우선 초안 |
| `air_capable` | open design |
| `interval_ms` | 느린 주기·높은 단발 위력, exact open design |
| `windup_ms` | open design |
| `delivery` | 공중에 펼친 염주가 대상 지점을 함께 내려치는 범위 타격 |

- 지팡이에 염주를 장식한 외형이 아니라 염주 자체를 다루는 Staff다. 염주알들을 공중에 펼친 뒤
  적이 있는 지점을 내려쳐, 충격 범위의 모든 eligible 적에게 Physical 피해를 준다.
- 염주알이 여러 개 보이더라도 기본 판정은 대상당 한 번인 범위 공격으로 정한다. 적 수나
  염주알 수에 따라 한 적이 중복 피해를 받거나 적중 trigger가 여러 번 발생하지 않는다.
- 적이 모일수록 총 화력이 커지되 대상 수로 각 대상의 피해를 나누지 않는다. 낮은 피해를 잘게
  나누는 초고속 연타보다는 묵직한 타격감을 우선한다.
- 기본 공격에는 회복·갈애·방어력 감소·누적 성장 효과를 추가하지 않는다. 파편 없이도 범위 물리
  무기로 완결하고, 다른 호환 파편을 장착해도 기본 공격의 Physical type을 유지한다.

<a id="frag-방어구--해진-가사-가칭"></a>
## 방어구 — 해진 가사 (가칭)

- 기본 능력치는 후방 딜러의 최소 생존을 위한 최대 HP와 물리 방어력으로 구성한다. 수치는 미정이다.
- **현재 HP가 최대 HP의 일정 비율 이상이면 공격력이 증가**한다. 체력 조건을 벗어나면 해제되고,
  회복해 조건을 다시 만족하면 재적용한다. 임계 비율과 공격력 증가율은 미정이다.
- 공격력 강화는 기본 공격과 그 공격력을 참조하는 스킬에 적용한다. 유지 시간에 따른 누적이나
  반복 발동 스택을 만들지 않으며, 장착 무기의 피해 type을 바꾸지 않는다.
- 회복의 출처나 전용 파편 사용 여부를 요구하지 않는다. 파편의 자기 회복뿐 아니라 아군의 치료로도
  체력 조건을 회복할 수 있다. 파편의 피해 판정 뒤 HP가 회복되어도 이미 가한 피해를 증폭하지 않는다.
- 자체 HP 회복·보호막·피해 감소 효과는 추가하지 않는다.

평온한 상태를 유지할수록 강한 힘을 발휘하는 공격형 방어구로 각색한다. 전용 조합에서는 파편의
회복이 공격력 조건 복구를 돕지만, 이 방어구가 없어도 파편의 피해와 회복은 그대로 작동한다.

<a id="frag-액세서리--치아사리-가칭"></a>
## 액세서리 — 치아사리 (가칭)

**착용자의 물리 공격이 대상의 물리 방어력 일부를 비율로 무시**하는 액세서리로 정한다.

- 착용자가 가하는 eligible 직접 Physical 기본 공격과 스킬 피해에 적용한다. 원형 범위 공격에도
  각 대상의 방어력을 기준으로 적용하며, 대상이 많다는 이유로 관통률이 증가하지 않는다.
- 적에게 방어력 감소 디버프를 남기지 않는다. 착용자의 해당 피해 계산에서만 방어를 일부 무시하므로
  다른 아군의 공격에는 효과를 제공하지 않는다.
- 물리 피해를 True 피해로 바꾸지 않고, Magic 피해·회복량·회복 방해·무적에는 영향을 주지 않는다.
- 염주 무기와 탐식 파편 모두에 적용되지만 전용 조합을 요구하지 않는다. 다른 무기의 eligible
  Physical 피해에도 독립적으로 사용할 수 있다.
- 관통률과 다른 방어 감소·관통의 적용 순서는 미정이다. 피해 type 면역이나 무적을 우회하는
  효과로 확대하지 않는다.
