## 죽은 나비들의 장례

> 상태: 무보상 장례 의식과 알 전환 합의 / 세부 연출 미정

직접 제압하거나 보상을 얻는 보스가 아니다. 실패 조건 없는 장례 의식을 마치면 스스로 머리를 쏘고 알로
변한다. 원본은 해당 run에서 다시 출현하지 않으며, 알에서는 정식 전투 아종 `죽을 나비의 장례`가
부화한다.
