## 죽을 나비의 장례

> 상태: 보스전 골격과 파편·Platform 원거리 무기, 처치 후 나비 연쇄 폭발 액세서리 구조 합의 /
> 2026-10-19 원본 파편 유지 및 개화 시 전용 무기 동반 승급 합의 /
> 이름·세부 판정·수치 미정

죽은 나비들의 장례가 남긴 알에서 부화하는 아종이며 정식 전투 노드다. 장례 준비도, 유닛 처형과
지고 있음·내려놓음·열림으로 이어지는 관 페이즈는 `abnormality_design_notes.ko.md`의 별도
`죽을 나비의 장례` 절이 소유한다.
