현재 파편 본문: [웃는 시체의 산](fragment.md).

**2026-10-20 리워크 합의:** 성장의 중심은 무기 웃음에 두고, 파편은 광역 도발로 먹잇감을 모은다.
도발된 적은 빨라지고 1타일 이내에서만 공격하며, 다른 아군에게 이미 저지된 적도 기존 저지를 풀고
시전자에게 향한다. [유물 1~5번](synergies.md)을 모두 채택하고 깨진 균형은 제외했다.
아래 얼굴·처형·기절 후 도발은 대체된 이전 설계다. 파편의 일시 거대화나 지정 대상 마무리 공격
제안도 채택하지 않았다. 무기 성장·시체 회복·부패 액세서리는 현재 장비 문서를 따른다.

## 스킬 파편 능력:

- 공격으로 웃는 얼굴을 쌓고, 얼굴 수에 비례해 저체력 대상의 처형 임계점을 올린다.
- 처형은 death finalization을 직접 호출하지 않고 장착 무기의 전용 처형 모션과 `999,999` 실제 피해를
  사용한다. `웃음`의 유효한 주 대상 공격이 발동시켰다면 그 공격의 막타와 무기 스택으로 인정한다.
- 시전 `합창`은 범위 내 얼굴을 소비한다. 먼저 기절시킨 뒤 도발하고, 소비량에 비례해 두 효과의
  시간이 길어진다. 얼굴을 유지해 처형을 노릴지 긴급 제어로 바꿀지가 핵심 판단이다. 액세서리의
  부패는 합창으로 소비되지 않는다.

## 11 웃는 시체의 산

**기존 방향:** 직접 공격으로 웃는 얼굴을 쌓고 저HP 적에게 큰 마무리 피해를 준다. active는 주변 얼굴을 소비해 제어한다.

**조립안:** 직접 타격 후 대상에 얼굴 부여 → 현재 HP 비율과 얼굴 수로 마무리 조건 확인 → 같은 공격에서 한 번만 추가 최종 피해다. 기존 999999 피해는 즉사 명령과 구별하고 무적·페이즈 하한을 존중한다. 추가 피해가 자기 자신을 재발동하지 않으며 흡혈은 실제 HP 손실만 참조한다.

active는 범위 안 자기 출처의 얼굴 수집·소비 → 수에 따른 기절 → 도발로 구성하고 직접 피해를 더하지 않는다. 얼굴 0개에도 최소 제어가 있는 기존 방향을 유지한다. 최대 5개·6초·처형선 5%+스택당 2%는 밸런스 초안이다.

**기능 경계:** 직접 공격 반응·상태 스택·조건부 추가 피해·범위 소비·제어. 무기 처치 성장, 시체 회복, 액세서리의 별도 방어 약화는 얼굴 상태와 합치지 않는다.

**검토:** active에 상시 부가 효과를 붙이는 구조를 명확히 허용해야 한다. 마무리 조건이 이번 타격으로 새로 얻은 얼굴을 포함할지 결정한다. 추천은 포함하고 행동·대상당 1회만 검사하는 것이다. 개화형은 상세 설계 후 추가한다.

**태그와 유물 적용**

| 효과 단위        | 태그 후보   | 변경 후보 속성과 지켜야 할 경계                                        |
| ---------------- | ----------- | ---------------------------------------------------------------------- |
| 웃는 얼굴        | `스택`      | 획득량·상한·기간. 적용 타격과 소유 사본 보존                           |
| 임계 HP 마무리   | `피해`      | 발동 HP 조건·피해량. 처형 명령이나 원래 공격의 새 다중타격 단계가 아님 |
| active 기절·도발 | `제어·범위` | 제어별 시간·소비량 환산·범위. 직접 피해를 새로 추가하지 않음           |

**유물 연결:** 스택 유지·제어 강화는 새 범용 후보다. 마무리 피해는 해당 추가 피해의 출처 조건을 충족하는 증폭만 받는다. 얼굴 획득량 변경과 마무리 임계값 변경을 하나로 취급하지 않는다. 회복·시체 소비는 장비 효과를 따로 선택한다.

## 파편 — 시체들의 합창 (가칭)

파편은 공격으로 적에게 `웃는 얼굴`을 붙인다. 얼굴을 유지하면 처형 임계점이 커지고, 시전하여
소비하면 기절 뒤 도발로 전선을 통제한다. 새로운 효과를 병렬로 늘어놓는 대신 하나의 대상별 스택을
유지할지 소비할지가 파편의 핵심 판단이다.

**웃는 얼굴**

- 착용자의 eligible 직접 공격이 적중한 대상에게 `웃는 얼굴` 1스택을 부여한다.
- 같은 공격 행동은 같은 대상에게 최대 1스택만 부여한다. 다단 공격 한 번으로 즉시 상한에
  도달하지 않는다.
- 지속 피해, 반사, 장비 proc와 환경 피해는 스택을 부여하지 않는다. 기본 공격을 교체하는 authored
  replacement attack과 스킬 직접 공격을 포함할지는 exact source tag로 정한다.
- 스택은 대상별로 보유하고 새 스택을 부여하면 지속 시간을 갱신한다.
- 첫 prototype 후보는 최대 `5`스택, 지속 시간 `6초`다. exact 상한과 지속 시간은 수치 설계에서
  확정한다.

웃는 얼굴은 적의 몸에 녹아붙은 흰 가면으로 표시한다. 스택 수가 늘어날수록 가면의 수와 웃음소리가
늘어나야 하며, 일반 debuff icon만으로 exact 수량을 숨기지 않는다.

**처형 임계점과 무기 처형**

직접 공격의 원래 피해가 끝난 뒤에도 대상이 살아 있으면 현재 HP 비율과 웃는 얼굴 수로 처형 가능
여부를 검사한다. 첫 prototype의 임계점 후보는 다음과 같다.

```text
처형 임계점 = 최대 HP의 (5% + 웃는 얼굴 1스택당 2%)
```

| 웃는 얼굴 | 처형 임계점 후보 |
| ---: | ---: |
| 0 | HP `5%` 이하 |
| 1 | HP `7%` 이하 |
| 3 | HP `11%` 이하 |
| 5 | HP `15%` 이하 |

임계점 이하라면 장착 무기의 authored 처형 모션을 재생하고 같은 공격 resolution의 마지막 damage
segment로 `999,999` 피해를 한 번 가한다. 이는 death finalization을 직접 호출하는 즉사나 처형
판정이 아니라 실제 피해다.

- 무적, 피해 차단과 Boss phase gate를 우회하지 않는다. gate에서 clamp된 초과 피해를 다음 phase로
  이월하지 않는다.
- HP 0 뒤의 death-prevent, 사망·처치 trigger와 보상 판정은 일반 피해 사망 순서를 그대로 따른다.
- 처형 segment는 자신을 포함한 on-hit·처형 trigger를 다시 발생시키지 않는다.
- raw `999,999`를 회복·흡혈·공명으로 변환하지 않는다. 실제로 감소시킨 HP만 기존 source 규칙에
  따라 후속 계산에 사용할 수 있다.
- 처형 피해의 소유자, 장착 무기와 공격 action identity는 발동시킨 직접 공격에서 상속한다. 따라서
  `웃음`의 유효한 주 대상 기본 공격이 이 피해로 대상을 사망시키면 `웃음`의 막타로 인정한다.
- 장착 무기에 전용 처형 presentation이 없으면 공통 중량 무기 마무리 모션을 fallback으로 사용한다.
  `웃음`은 입을 벌린 망치가 대상을 물어뜯어 으깨는 전용 모션을 가진다.

일반 적, 엘리트와 환상체에 같은 임계식을 적용할지, 환상체만 더 낮은 계수 또는 authored 면역을
가질지는 open design이다. 수치를 달리하더라도 `999,999`의 실제 피해라는 판정은 바꾸지 않는다.

**시전 — 합창**

시전하면 착용자가 포효하고 범위 내 적에게 붙은 웃는 얼굴도 동시에 입을 벌려 합창한다.

- 범위 내 각 적이 가진 웃는 얼굴을 전부 소비한다.
- 해당 적을 먼저 기절시키고, 기절이 끝난 뒤 착용자를 우선 공격하는 도발을 부여한다.
- 적마다 소비한 스택이 많을수록 그 적에게 적용되는 기절과 도발 시간이 증가한다.
- 웃는 얼굴이 없는 적도 착용자 본체의 포효를 받아 authored 최소 기절·도발을 얻는다. 따라서 스택을
  쌓을 대상이 없는 단일 강적전이나 긴급 시전에서도 스킬이 완전히 비지 않는다.
- 포효 자체는 피해를 주지 않는다. 파편 시전이 적의 막타를 빼앗거나 무기 성장 source가 되지 않는다.

첫 timing 후보는 다음과 같으며 exact 수치는 open design이다.

```text
기절 시간 = 0.5초 + 소비한 웃는 얼굴 1스택당 0.2초
도발 시간 = 2초 + 소비한 웃는 얼굴 1스택당 0.5초
```

다른 아군이 이미 저지 중인 적을 강제로 빼앗지 않는 방향을 우선한다. 저지되지 않은 적과 착용자가
저지 중인 적의 target 우선순위, 현재 공격 resolution, Boss의 기절·도발 면역 및 감소 규칙은 후속
판정에서 확정한다.

**유지와 소비의 선택**

- 얼굴을 유지하면 착용자가 더 높은 HP에서 처형을 확정할 수 있다.
- 합창으로 소비하면 높은 처형 임계점을 잃는 대신 즉시 기절·도발로 무너지는 전선을 붙잡는다.
- 합창 뒤에는 공격으로 얼굴을 처음부터 다시 쌓는다. 공명 시전 한 번이 스택 유지와 소비를 동시에
  만족시키지 않는다.

파고드는 천국 액세서리의 적용 대상으로 웃는 얼굴에 스택 증폭 태그를 부여할지는 open design이다.
허용한다면 최초 application의 수량만 두 배로 하고, 처형 검사와 합창 소비 과정에서 다시 증폭하지
않는다. 죽을 나비의 장례 액세서리는 해당 두 배 효과 초안을 폐기했으므로 이 판정에 관여하지 않는다.
