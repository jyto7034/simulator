## 파편 — 시체들의 합창 (가칭)

> 상태: 2026-10-20 광역 도발 리워크·기존 저지 해제·유물 연결 5개 합의. 깨진 균형 제외.
> 범위·시간·속도·유물 수치는 후속 조정. 도발 세칙은 아래 2026-10-21 작성 정책 참조. 전투 실행 완료를 뜻하지 않는다.

주된 성장의 재미는 무기 `웃음`의 run-local 막타 성장에 둔다. 파편은 매우 넓은 범위의 적을
시전자 앞으로 모아, 무기가 공격하고 주 대상 막타를 낼 기회를 만든다. 파편 자체에 거대화나
별도 성장 자원을 추가하지 않는다.

**시전 — 광역 도발과 접근 강제**

- 시전자 중심의 매우 넓은 범위에 있는 적들을 도발한다. 정확한 크기·형상은 미정이다.
- 도발된 적은 시전자를 공격 대상으로 삼으며, 이동 속도가 증가해 시전자에게 빠르게 접근한다.
- 도발 중에는 시전자에게 **1타일 이내로 접근해야 공격할 수 있다.** 원거리 일반 공격과 공격
  스킬도 이 거리 제한을 적용받으므로 멀리서 공격하며 버티지 못한다.
- 공격 가능 거리를 제한하는 효과다. 적에게 새 근접 공격을 주거나 원래 피해량을 높이지 않는다.
- 접근은 이동 속도가 증가한 추적 이동이다. 순간이동이나 벽·유닛을 통과하는 강제 이동을 추가하지 않는다.

**이미 저지된 적도 빼앗기**

- 다른 아군이 이미 저지하던 적도 도발 대상으로 삼는다. 기존 아군과의 저지 관계를 풀고 시전자에게
  향하게 한다. 기존 저지 대상을 빼앗지 않던 이전 방향을 대체한다.
- 시전자에게 즉시 전송하거나 멀리서 저지한 것으로 처리하지 않는다. 실제로 접근한 뒤 시전자의
  기존 저지 규칙을 적용하며, 이 파편이 저지 수를 무제한으로 늘리지는 않는다.
- 2026-10-21 사용자 합의: 도발 중에는 시전자 이외 아군의 새 저지를 허용하지 않는다.
  시전자에게 실제 접근한 뒤에는 기존 저지 수와 조건을 적용한다. 지형·경로·충돌 규칙은 유지한다.
  진행 중 공격·접근 불가 등의 세칙은 아래 작성 정책을 따른다.

**공통 유지 시간과 종료**

- 도발·이동 속도 증가·1타일 공격 제한은 같은 지속 시간을 사용한다. 기본 시간과 속도 증가율은 미정이다.
- 도발 효과가 끝나면 해당 출처의 이동 속도 증가와 공격 거리 제한도 함께 끝나고 원래 행동 규칙으로
  복귀한다. 이전 저지 위치로 순간이동시키지는 않는다.
- 시전으로 대상에게 상태를 부여한다. 집중 유지나 전장에 남는 장판은 아니며, 시전 이후 기본 공격으로
  적을 처리한다. 직접 피해·기절·자동 처형은 제공하지 않는다.
- 도발 면역·출처 경합·시전자 사망과 철수의 처리는 아래 작성 정책을 따른다.

**성장형 무기와 유물**

`웃음`은 기존대로 유효한 **주 대상 기본 공격 막타**에서 시체 질량을 얻는다. 주변 충격파로 죽은
부 대상이나 아군이 처치한 적까지 성장 대상으로 바꾸지 않는다. 파편은 적을 공급하고, 무기는
실제로 막타를 내며 성장한다. 전용 무기 없이도 호환 무기의 근접전·집결 지원에 사용할 수 있다.

[합의한 연결 5개](synergies.md)는 범위 증가, 긴 호흡, 도발 대상 피해 감소, 도발 대상 기본 공격
강화와 무기 시체 질량의 스택획득이다. 스택획득은 파편에 새 스택을 만드는 효과가 아니라 장착한
`웃음`의 유효한 획득량을 2배로 하는 연결이다. **깨진 균형은 제외한다.**

### 2026-10-21 작성 정책

다른 아군의 새 저지 금지는 사용자가 확정했다. 아래 통상 세칙은 2026-10-21의 정책 판단 위임에 따라
작성자가 결정했다. 신규 게임 동작의 실행 지원 완료를 뜻하지 않는다.

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 대상 조회 | 효과 방출 시 시전자 위치·방향의 범위 안에 있는 살아 있는 적을 한 번 고른다. 이후 범위 이탈만으로 상태를 해제하지 않는다. | 시전 시 상태 부여이며 지속 장판이 아님 |
| 대상·면역 | 높이·보스 분류만으로 제외하지 않고 대상의 명시적인 도발 면역을 따른다. 도발이 거절되면 속도 증가·거리 제한·저지 해제도 적용하지 않는다. | 면역 대상에게 접근 제약만 남기지 않고 묶음 적용을 일관되게 처리 |
| 상태 수명 | 대상별 활성 하나가 도발·속도 증가·거리 제한을 소유한다. 만료·대상 소멸·시전자 사망/철수·전투 종료에 함께 정리한다. 시전자 Hard CC·침묵만으로 이미 부여한 상태를 제거하지 않는다. | 추적할 시전자가 사라지면 종료하며 집중과 구분 |
| 여러 도발 | 나중에 성공한 도발이 기존 도발 활성을 대체하고 그 활성의 부가 효과도 끝낸다. 같은 시각에는 전투의 확정 처리 순서를 따른다. 이전 도발은 되살리지 않는다. | 한 적의 추적 대상과 부가 효과 출처를 하나로 유지 |
| 진행 중 공격 | 도발 시작 시 아직 방출하지 않은 적대적 대상 공격·공격 스킬은 취소하고 비용을 환불하지 않는다. 이미 방출한 발사체·독립 효과는 원래 대상으로 계속 진행한다. | 뒤늦은 발사체 재지정과 즉시 재공격을 방지 |
| 공격 제한 | 적대적 기본 공격·공격 스킬은 시전자를 주 대상으로 삼고 시작·방출 시 실제 평면 연속 위치 사이 거리가 1타일 이내여야 한다. 대형·공중 대상도 같은 기준 위치를 쓴다. 원래 사거리가 더 짧으면 그 제한을 유지한다. | 연출·판정 타일과 실제 접근 거리를 구분하고 사거리를 늘리지 않음 |
| 이동과 접근 불가 | 시전자의 현재 위치로 정상 추적한다. 경로가 없거나 도달 지점이 혼잡하면 기존 경로 탐색·대기를 따르며 순간이동·통과용 강제 이동·원거리 공격으로 우회하지 않는다. | 원문의 접근 방식 보존 |
| 시간과 사용 완료 | 도발 상태는 양수 전투 시간 동안 유지된다. Pause에는 진행하지 않고 만료는 같은 시각 후속 처리보다 우선한다. 일회 부여 동작이 끝나면 스킬 사용을 완료하고 공명 충전을 재개한다. | 시전 후 기본 공격을 하는 즉발 상태 부여로 분류하며 채널 잠금을 만들지 않음 |

속도 증가 기여분은 같은 종류 중 가장 강한 값, 공격 거리 상한은 가장 작은 값을 적용하며
한 출처의 종료는 다른 출처의 기여분을 제거하지 않는다. 기본 공격의 새 피해·공격을 추가하지 않는다.
현재 표현과 Core 차이는 [공통 스킬 그래프 계약](../../../../../content_assembler/docs/common-skill-graph-contract.md)에서 관리한다.

**이전 설계와 후속 조정**

웃는 얼굴 축적·자동 처형·얼굴 소비 후 기절→도발은 이번 리워크로 대체한다. 예전 얼굴 상한·기간,
처형 임계식·999,999 피해와 스택당 기절·도발 시간을 새 파편의 수치로 가져오지 않는다.
[이전 원문](review.md#previous-faces)을 보존하며 무기 성장, 방어구의 시체 회복과 액세서리의 부패는 유지한다.

- 범위의 정확한 크기·형상, 공통 지속 시간과 적 이동 속도 증가율
- 새 유물의 증가율·감소율·등급·중복 장착과 공격·피해 출처별 상세 적용
- 개화형·침식형과 최종 이름은 후속 검토
