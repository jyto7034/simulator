## 흑조의 꿈

> 상태: 상시 피해 감소·확률 반사, 수동 패링의 성공 후 0.5초 피해·행동제어 면역·강한 받아치기와 실패 빈틈, Run 유물의
> 피해 축적·성공 시 방출, 지상 저지 3 범위 Magic 우산 Shield·물리 방어 특화 방어구와
> 적 처치 공명 액세서리 구조 합의 /
> 성공 면역 규칙은 2026-10-13 합의 / 그 외 이름·수치·세부 판정 미정 / 현재 미구현

조우 설계는 `abnormality_design_notes.ko.md`의 `흑조의 꿈` 절이 소유한다. 기본 파편은 우산으로
평소 공격을 버티며 일부를 반사하고, 플레이어가 중요한 공격에 맞추어 패링을 사용하는 탱커다.
Run 유물은 그동안 막아낸 피해를 모아 패링 성공 시 강한 공격으로 방출하는 고점을 추가한다.

원작 참고: [흑조의 꿈 기록](https://tiphereth.zasz.su/lc/abnormalities/100045/?lang=kr),
[E.G.O 무기 흑조](https://tiphereth.zasz.su/lc/equip/200045/),
[E.G.O 방어구 흑조](https://tiphereth.zasz.su/lc/equip/300045/).

### 미결정 사항

- 파편·유물의 최종 이름, `rarity`, `equip_limit`, `compatibility`와 획득 경로
- 상시 감면율, 감면 대상 피해와 방향 제한, 확률 반사 발동률·기준 피해·비율과 다단 공격 판정
- 패링 성공 전 판정 창의 길이, 실패 빈틈과 성공을 일으킬 eligible 직접 공격의 세부 목록
- 성공 전 판정 창의 기본 행동·저지와 Silence·Hard CC·interrupt, 명시적 중지·철수 처리.
  성공 후 면역은 0.5초의 모든 피해·행동제어 차단으로 확정하며 그 외 효과는 정상 적용한다.
- 기본 받아치기 피해의 기준·계수·type와 공격자 부재·사망·무적·phase gate 처리
- 유물 축적량의 계산 순서, 배율·상한, 폭발 범위·피해 배분과 전투 lifecycle
- 감면·반사·받아치기·유물 방출 자체의 공명·치명타·흡혈·장비 trigger eligibility와 재귀 방지.
  액세서리의 처치 공명은 이 피해 기반 공명과 별개다.
- 장비의 최종 이름, 무기의 범위·피해·공격 주기·대공 여부 등 미정 profile과 방어 수치·강화 성장치
- 액세서리의 처치당 공명량, 한 공격·시전의 획득 상한 여부와 지속 피해·소환물의 처치 귀속
