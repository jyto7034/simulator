## 무기 — 흑조

> 상태: 지상 저지 3 우산형 Shield와 빠른 근거리 범위 Magic 기본 공격 구조 합의 /
> 정확한 피해·사거리·공격 주기와 세부 판정 미정

| 항목 | 값 |
| --- | --- |
| `range_role` | 근거리 / 범위 공격 |
| `weapon_archetype` | `Shield` |
| `deployment_affinity` | 지상 전용 |
| `block_capacity` | `3` |
| `ground_defense_focus` | open design |
| `platform_rest` | 해당 없음 |
| `damage_type` | Magic |
| `targeting_profile` | 저지 중인 적 우선, exact open design |
| `air_capable` | 불가능 제안 |
| `interval_ms` | 빠름, exact open design |
| `windup_ms` | open design |
| `delivery` | 우산으로 주 대상과 주변 근거리 적을 함께 휩쓰는 타격 |

기본 공격의 단발 위력은 낮게 두고, 저지한 적들이 모인 곳을 반복해서 때린다. 원작 우산의 근거리
공격 외형을 유지하되, 플레이어용 무기 역할은 다수 저지를 가진 `Shield`로 정한다. 자체 패링,
확률 반사와 축적 자원을 추가하지 않고, 다른 호환 파편을 장착해도 기본 역할을 수행한다.

<a id="frag-방어구--쐐기풀-외투-가칭"></a>
## 방어구 — 쐐기풀 외투 (가칭)

> 상태: 높은 최대 HP·Physical 방어와 낮은 Magic 저항의 물리 방어 특화 구조 합의 /
> 별도 발동 효과 없음 / 정확한 능력치·강화 성장치 미정

반복적인 근접 공격을 버틸 기본 내구도를 제공한다. 별도 발동 효과 없이 생존 stat으로 완결하며,
패링 실패 빈틈에도 이 방어구의 방어력은 유지된다. 파편 없이 다른 전열 직원에게도 사용할 수 있다.

<a id="frag-액세서리--추억의-브로치-가칭"></a>
## 액세서리 — 추억의 브로치 (가칭)

> 상태: 착용자의 적 처치 시 공명 획득 구조 합의 / 이름·수치·세부 판정 미정

착용자가 eligible 적을 처치하면 처치한 적 한 명당 일정량의 공명을 획득한다. 피해량이 아니라
실제 처치 수를 기준으로 다음 스킬 사용을 돕는다.

- 착용자에게 처치가 귀속되고 적의 사망이 확정되었을 때 한 번 발동한다. 단순 피격, 저지와 처치
  기여만으로는 발동하지 않으며, 같은 적의 다단 피격이나 overkill을 여러 처치로 세지 않는다.
- 기본 공격과 active 파편뿐 아니라 착용자가 소유한 확률 반사, 패링 받아치기와 Run 유물 방출로
  처치한 적도 인정한다. 지속 피해·소환물 등 나머지 source의 귀속은 후속 판정에서
  정한다.
- 반사·받아치기 피해 자체가 공명을 생성하는 것과는 별개의 `OnKill` 장비 효과다. 적을 처치하지
  못한 반사나 성공한 패링만으로는 이 액세서리의 공명을 지급하지 않는다.
- 파편 시전 공명을 소비한 뒤 받아치기·방출로 적을 처치하면 새 공명을 획득한다. 이는 시전 비용의
  환불이 아니며, 기본 파편의 성공·실패 시 공명 환불 없음 정책을 바꾸지 않는다.
- 공명 최대치와 획득 제한을 따른다. 만충 중 초과분을 별도로 저장하거나 다음 시전 뒤로 이월하지
  않으며, 만충이 되어도 스킬을 자동 시전하지 않는다.
- 처치당 획득량과 한 공격·시전에서의 획득 상한 여부는 open design이다. 유물의 광역 방출로 여러
  적을 처치했을 때 패링과 무적이 지나치게 연속되지 않는지 함께 검토한다.

전용 조합에서는 반사와 강한 받아치기 처치가 다음 패링의 준비를 앞당긴다. 다른 파편과 조합하면
직접 적을 처치하는 딜러의 스킬 순환에도 사용할 수 있다. 아군이 마무리하는 순수 저지 운용이나
추가 적이 없는 단일 보스전에서는 효용이 낮다는 조건을 가진다.

## 2026-10-22 공통 공명 잠금과의 실행 대조

추억의 브로치의 처치 귀속에는 반사·받아치기도 포함한다. 다만 위의 ‘새 공명 획득’은
[현행 전투 규칙](../../../game_rules/combat.md)의 획득 제한을 우회하는 예외가 아니다.
패링 창·성공 면역·실패 빈틈이 사용 의무로 남아 있는 동안에는 처치 효과가 양수 획득을 요청해도
실제 획득량은 0이다. 잠금 종료 후 소급 지급하거나 적립하지 않는다. 스킬 사용 중이 아닌
상시 반사 처치는 같은 OnKill 연결로 공명을 획득할 수 있다. 장비의 별도 획득 제한 예외는
합의되지 않았으므로 추가하지 않는다. 처치당 25는 실행 검사 fixture 값이며 밸런스 확정값이 아니다.
