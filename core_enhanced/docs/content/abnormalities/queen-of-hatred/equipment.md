## 무기 — 사랑과 증오의 이름으로 (가칭)

| 항목 | 값 |
| --- | --- |
| `range_role` | 원거리 순수 힐러 |
| `weapon_archetype` | `Staff` |
| `deployment_affinity` | Platform 전용 |
| `block_capacity` | `0` |
| `damage_type` | 해당 없음 |
| `targeting_profile` | 회복 범위 안에서 HP 비율이 가장 낮은 eligible 아군 |
| `air_capable` | 공격하지 않음. 지상·Platform 아군 모두 회복 후보 |
| `interval_ms` | 안정적인 단일 HPS를 보장하는 주기, exact open design |
| `windup_ms` | open design |
| `delivery` | 하트와 별이 섞인 분홍빛 단일 회복 광선 |

일반 공격을 적 피해가 아니라 아군 한 명에 대한 직접 회복으로 완전히 교체한다. 명일방주의 단일 대상
Medic처럼 적이 없어도 계속 전선을 치료하는 것이 무기의 기본 역할이다.

- 회복 범위 안에서 현재 HP 비율이 가장 낮은 부상 아군을 우선한다.
- HP 비율이 같으면 실제로 잃은 HP가 더 큰 대상을 우선하고, 이후 동률은 공통 deterministic 순서로
  해소한다.
- 적을 대상으로 삼거나 피해를 주지 않는다. 적의 존재, 방어력, 무적과 타겟팅 불가 상태는 회복
  가능 여부에 영향을 주지 않는다.
- 지상과 Platform의 eligible 아군을 모두 회복할 수 있다.
- 부상 아군이 없으면 회복을 저장하거나 보호막·공격으로 바꾸지 않고 다음 회복 시점을 기다린다.
- 적 공격 적중이나 실제 감소 HP에 회복량을 연동하지 않는다.

무기의 기본 회복은 파편의 회복과 별도 출처다. 히스테릭이 무기 자체의 회복 효과를 아군 피해로
변환하지는 않는다. 다만 파편 시전·집중 중 기본 행동을 병행하는지는 행동 제한을 따라야 하며,
시전 내내 기본 치료가 무조건 계속된다고 단정하지 않는다. 정확한 회복량과 주기는 일반적인
전투에서 단독 주치유사로 기능할 수 있는 값을 전제로 정한다.

<a id="frag-방어구--정의의-결계-가칭"></a>
## 방어구 — 정의의 결계 (가칭)

> 상태: 위급 대상 회복 시 결계 구조 합의 / 기본 생존 수치·세부 판정 미정

기본 최대 HP와 방어력을 제공하는 후방 지원형 방어구다. 착용자가 회복 직전 HP `50%` 이하인 다른
아군의 battle HP를 실제로 회복하면 그 대상에게 `사랑의 결계`를 부여한다.

| 항목 | 첫 prototype |
| --- | --- |
| 결계량 | 해당 action의 실제 회복량 `25%` |
| 지속 시간 | `5초` |
| 대상별 내부 cooldown | `8초` |

- Overheal은 실제 회복량에 포함하지 않고 남은 양을 결계로 저장하지 않는다.
- 같은 대상에게 기존 결계가 남아 있으면 합산하지 않고 기존 값과 새 값 중 큰 쪽을 유지한다.
- 흡혈, 최대 HP 증가, HP 비용 취소와 다른 유닛이 준 회복은 이 방어구의 trigger가 아니다.
- 전용 무기뿐 아니라 착용자가 사용하는 다른 무기·파편의 eligible 직접 회복으로도 발동한다.
- 액세서리 등으로 회복량을 증폭한 뒤의 실제 회복량을 기준으로 결계량을 계산한다.

방어구 자체의 방어력·최대 HP, 결계의 HP type, 일반 barrier와의 우선순위 및 dispel·전투 종료 처리는
open design이다.

<a id="frag-액세서리--마법소녀의-브로치-가칭"></a>
## 액세서리 — 마법소녀의 브로치 (가칭)

| 항목 | 값 |
| --- | --- |
| 효과 | 착용자가 다른 아군에게 주는 회복량 `25%` 증가 |

- 전용 무기의 기본 회복과 파편 광선의 아군 회복에 모두 적용한다.
- 자기 회복, 흡혈, 최대 HP 증가와 다른 유닛이 소유한 회복에는 적용하지 않는다.
- 보호막과 결계량을 직접 `25%` 늘리지 않는다. 증가한 실제 회복량을 읽는 `정의의 결계`에는 간접적으로
  더 큰 기준값을 제공한다.
- 별도 발동 조건, 확률과 스택은 두지 않는다.
