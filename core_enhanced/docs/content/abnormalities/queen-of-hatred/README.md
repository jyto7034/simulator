## 증오의 여왕

> 상태: 2026-10-18 사용자 리워크·7개 태그 합의 반영. 하트는 전투 로컬이며 6개에서 히스테릭 자동 공격.
> 이름·시간·수치는 작업안, 세부 판정·밸런스·runtime 반영은 별도 작업이다.

조우 설계는 `abnormality_design_notes.ko.md`의 `증오의 여왕` 절이 소유한다. Event 합류·run-wide
동행·3연승 및 아군 전력 20% 퇴각에 의한 보스전 진입과, 아래 플레이어 파편의 히스테릭을 구분한다.

### 전용 조합과 독립성

- 파편은 다른 compatible 무기에서도 광선 회복과 전투 로컬 하트·블랙홀·히스테릭을 사용한다.
- 사랑과 증오의 이름으로는 파편 없이도 적과 무관하게 단일 아군을 지속 회복한다.
- 정의의 결계는 착용자가 제공하는 다른 직접 회복에도 발동한다.
- 마법소녀의 브로치는 전용 세트가 아닌 다른 아군 직접 회복도 증폭한다.

전용 세트는 `단일 대상 지속 회복 → 브로치의 회복 증폭 → 위급 대상에게 사랑의 결계`를 기본
안전망으로 사용한다. 파편은 범위에 닿은 아군의 회복과 블랙홀 집결을 제공하지만, 하트 6개에서는
아군 피해를 동반하는 히스테릭으로 전환된다. 파편 시전 중 무기 기본 행동 병행 여부는 별도 판정을 따른다.

<a id="frag-미결정-사항-1"></a>
### 미결정 사항

- 파편, 무기, 방어구와 액세서리의 최종 이름, `rarity`, `equip_limit`, 획득 경로와 강화 recipe
- 무기의 회복 범위·타일 형태, 회복량, 공격 주기, windup과 동률 target 순서
- 회복 windup 중 target이 완전히 회복·이탈·사망했을 때 재지정 또는 빈 action 처리
- Staff의 회복 action과 공명·Platform Rest의 관계
- 방어구의 기본 방어력·최대 HP, HP `50%` 판정 시점과 eligible 직접 회복 tag
- 사랑의 결계 수치, barrier 우선순위, 대상별 cooldown과 checkpoint/resync 처리
- 액세서리의 회복 modifier 계산 단계와 적용 가능한 아군·회복 source 범위
