## 파편 — 황홀의 포자막 (가칭)

아래는 유물 없는 기본 파편의 개인 보호 구조다. 범용 유물에 의한 단일 전환은 별도 절을 따른다.

공명 만충에서 시전하면 **시전 순간 범위 안에 있는 각 아군에게 독립 방어막을 한 번씩 부여**한다.
보호 대상 집합은 이때 확정하며, 생성한 방어막은 대상별로 유한한 보호량과 지속 시간을 가진다.

**보호 대상과 부여 시점**

- 현재 범위 초안은 시전자 중심의 authored 원형 범위다. 최종 반경·타일 형태는 추후 결정한다.
- 시전자 본인을 포함한 범위 내 active player 직원을 대상으로 하며, Ground와 Platform을 모두
  포함하는 안을 우선한다. Guest, 소환물과 방어 오브젝트의 포함 여부는 open design이다.
- 각 대상에 최대 보호량·현재 잔량·남은 시간을 따로 둔다. 제공자 출처는 원래 시전자로 보존하되
  잔량을 공유하지 않는다. 한 아군의 피격은 다른 아군의 방어막을 소모하지 않는다.
- 시전 뒤 새로 범위에 들어온 아군에게는 부여하지 않는다. 이미 받은 아군은 범위를 벗어나도
  남은 방어막을 유지하며, 재진입으로 추가 부여·복제·재충전하지 않는다. 시전자 이동도 재부여를 만들지 않는다.
- 포자막은 적이 별도로 타격하는 유닛이나 저지 오브젝트가 아니다. 공격 대상과 저지는 기존 아군에게
  남고, 포자막은 그 아군에게 들어오는 피해를 흡수한다.

**피해 흡수**

```text
피격 아군의 방어력·저항·피해 감소를 적용한 피해
-> 그 아군의 개인 방어막에서 가능한 만큼 차감
-> 그 공격의 초과분을 피격 아군 HP에 적용
```

- 광역 공격도 대상별 방어·감면과 각자의 방어막으로 처리한다. 다른 아군의 잔량을 빌리거나
  먼저 피격된 아군이 전체 보호량을 소진하는 공용 풀을 만들지 않는다.
- 예를 들어 A와 B가 각각 보호량 `200`을 받았고 방어 계산 후 A에게 `400`, B에게 `150` 피해가
  들어오면 A는 방어막 소진 후 HP가 `200` 감소하고 B는 방어막 `50`이 남는다. 수치는 판정 예시다.
- 초과분에 방어력·저항을 다시 적용하지 않는다. 시전자의 방어력을 모든 보호 대상에게 복사하거나
  시전자에게 피해를 이전하는 방식도 아니다.
- 공격자의 거리와 무관하게 동일한 잔량 규칙을 적용한다. 포자막 자체는 무적, 공격 취소와
  부착 상태 이상 면역을 제공하지 않는다.
- HP 희생·비용은 흡수하지 않는다. 기타 피해 type과 source의 흡수 가능 여부, 다른 개인 보호막과의
  우선순위는 후속 공통 판정에서 정한다.

**유지와 소멸**

- 시전 후 집중을 유지할 필요가 없으며 기본 공격 등 일반 행동을 계속할 수 있다.
- 각 방어막은 자신의 잔량 소진 또는 지속 시간 만료 시 종료한다. 일반 HP 회복, Platform Rest와
  시간 경과로 잔량을 회복하지 않는다. 아래 액세서리도 생성 시 초기 보호량만 증폭한다.
- 같은 시전자의 재시전은 기존 부여분을 새 부여분으로 교체하는 안을 우선하며, 정상 공명을 소비한다.
  이전 잔량 합산 여부를 임의로 도입하지 않는다. 이전 대상 중 새 범위 밖 대상의 정리 등 교체 세부는 후속 결정한다.
- 시전자 철수·전투불능·사망과 전투 종료 시 부여분을 종료하는 기존 초안은 유지하되, 대상별 수명과
  대상 자신의 철수·전투불능·사망 처리는 후속 확정한다. 단순 범위 이탈은 종료 사유가 아니다.
- 시전 release 뒤의 Hard CC·Silence만으로 이미 생성된 포자막을 취소하지 않고 공통 persistent
  effect 규칙을 따르는 방향을 유지한다.
- 흡수한 피해는 아군의 실제 HP 손실이 아니다. 피격·공명·흡혈·반사 trigger와 연결할 범위는
  후속 판정에서 명시하며, 한 대상의 흡수량을 다른 보호 대상의 피격량으로 중복 계산하지 않는다.

장비 설계를 위한 **개인 방어막 하나의 초기 보호량** 초안은 `시전 시점의 시전자 최대 HP × 파편 계수`다.
계산식·계수는 미정이다. 동일한 개인 보호량을 `S`, 시전 시 대상 수를 `N`이라 하면 총 생성량은
`N × S`가 된다. 고정 총량을 N명에게 분할하거나 개인 보호량 자체에 N을 곱하는 방식은 아니다.
기존 공용 보호량을 그대로 개인에게 복제하지 않고 개인 보호량·범위·지속 시간·재충전 속도를 함께
재조정해 다수 보호와 보스 강공격 대응의 균형을 잡는다.

## 2026-10-22 공통 작성 계약의 세부 정책

일반 게임 정책에 대한 작업 위임으로 아래 경계를 구체화한다. 작성 모델에 반영하는 정책이며,
Core 컴파일·실제 전투 검증 완료를 뜻하지 않는다.

개인 보호량은 부여 시 시전자 최대 HP × 작성 계수로 고정한다. Guest·소환물·방어 오브젝트는 제외하고 Ground/Platform의 active player 직원과 시전자 자신을 포함한다. 같은 출처·같은 대상의 재부여는 새 잔량·시간으로 교체하고, 새 범위 밖 이전 대상은 기존 만료까지 유지한다. 제공자 또는 대상의 철수·사망, 전투 종료에는 정리한다. HP 비용·최대 HP 희생은 흡수하지 않는다. 계수·범위·시간은 미정이다.


### 2026-10-22 Core 연결의 계산 경계

개인량은 release 시 시전자 최대 HP 비율을 내림해 고정한다. 단일 전환은 이 개인량에 작성 배율을 곱해 다시 내림하며
대상 수를 사용하지 않는다. 새 대상만 교체하고 새 범위 밖 이전 대상은 원래 잔량·만료를 유지하는 정책을 명시적
설정으로 전달한다. 20%, 0.2초, 2.5배와 3×3/5×5 타일은 실행 검증 전용 입력이며 원문의 미정 밸런스를 확정하지 않는다.
검증 결과·범위는 콘텐츠 조립기 작업 파이프라인에 별도로 기록한다.
