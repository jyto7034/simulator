## 무기 — 쾌락

> 상태: 지상 저지 3 가시 Shield, 빠른 단일 Magic 공격과 황홀독 지속 피해 구조 합의 /
> 정확한 피해·사거리·공격 주기와 세부 판정 미정

| 항목 | 값 |
| --- | --- |
| `range_role` | 근거리 / 단일 직접 피해와 지속 피해 |
| `weapon_archetype` | `Shield` |
| `deployment_affinity` | 지상 전용 |
| `block_capacity` | `3` |
| `ground_defense_focus` | open design |
| `platform_rest` | 해당 없음 |
| `damage_type` | Magic |
| `targeting_profile` | 저지 중인 적 우선, exact 우선순위 open design |
| `air_capable` | 불가능 초안 |
| `interval_ms` | 빠름, exact open design |
| `windup_ms` | 짧음, exact open design |
| `delivery` | 가시 방패의 덩굴을 뻗어 가까운 적을 찌르는 직접 타격 |

- 꽃과 가시덩굴이 얽힌 커다란 방패로 적을 저지한다. 기본 공격은 가까운 적 하나를 찔러 낮은 직접
  Magic 피해를 주고 일정 시간 `황홀독`을 부여한다.
- 황홀독은 주기적으로 추가 Magic 피해를 준다. 같은 착용자의 재적중은 중첩 피해를 무한히 쌓지 않고
  지속 시간만 갱신한다. 갱신 때문에 기존 tick 시점을 계속 뒤로 미뤄 피해가 발생하지 않게 해서는 안 된다.
- 지속 피해는 새로운 기본 공격 적중으로 취급하지 않는다. 자체 적중 효과, 독 재부여와 장비 연쇄
  trigger를 다시 생성하지 않는다.
- 독을 다른 적에게 전염시키거나 독으로 포자막을 재충전하지 않는다. 파편이 없어도 직접 공격과
  지속 피해, 기본 저지 `3`으로 기능한다. 기본 저지 수를 포자막의 잔량에 연동하지 않는다.

파편 사용 사이에도 적을 붙잡고 지속적인 압박을 주며, 포자막이 유지되는 동안에도 계속 공격한다.
직접 피해·독 피해의 배분, 갱신 시 위력 snapshot과 다른 착용자의 독 중첩은 후속 수치·판정 설계에서
정한다. 원작의 가시·빠른 공격·추가 지속 피해를 직접 저지하는 근거리 Shield로 각색한 profile이다.

## 방어구 — 황홀의 외피 (가칭)

> 상태: 높은 최대 HP·Magic 저항과 전열 저지를 유지할 기본 Physical 방어 구조 합의 /
> 별도 발동 효과 없음 / 정확한 능력치·강화 성장치 미정

별도 발동 효과 없이 시전자 자신의 내구도를 보강한다. 포자막이 소진되어도 저지 중인 적의 공격을
버틸 수 있어야 하므로 Physical 방어를 후방 장비 수준으로 낮추지 않는다. 최대 HP 비례 포자막
계산식을 채택하면 쉴드 초기량도 함께 늘어난다. 착용자의 방어력·Magic 저항을 보호 대상 모두에게
전달하지는 않는다.

최대 HP 비례 계산식은 파편의 수치 초안이므로, 이 방어구의 기본 생존 효과가 해당 파편을 전제로
해야 하는 것은 아니다. 다른 전열 직원에게도 독립적으로 사용할 수 있다. 정확한 HP·저항·방어력과
강화 성장치는 open design이다.

<a id="frag-액세서리--쾌락의-고리-가칭"></a>
## 액세서리 — 쾌락의 고리 (가칭)

> 상태: 착용자가 생성하는 쉴드의 초기 보호량 증가와 각 개인 방어막에 한 번만 적용하는 구조 합의 /
> 이름·증가율·eligible 보호막 분류와 세부 판정 미정

- 착용자가 source인 eligible 보호막을 생성할 때 초기 최대량과 현재량을 같은 비율로 증가시킨다.
- 포자막에는 **시전자가 생성하는 각 개인 방어막에 한 번씩** 적용한다. 개인 보호량의 증가율에
  아군 수를 곱하거나 보호를 받는 아군들의 액세서리 효과를 모아 다시 증폭하지 않는다.
- 포자막 외에도 착용자의 다른 파편·장비가 생성하는 eligible 개인 보호막에 적용할 수 있다.
  다른 아군이 만든 쉴드를 받기만 한 경우에는 그 원천의 양을 늘리지 않는다.
- 생성 후 buff가 바뀌어도 잔량을 재충전하지 않는다. 포자막은 나중에 범위에 들어온 아군에게 새로 부여하지 않는다.
  지속 시간, 피해 감소율과 HP 회복량은 늘리지 않는다.
- 소환물·고기벽의 HP와 고기방패 같은 별도 전용 자원은 일반 보호막으로 암묵적으로 취급하지 않는다.
  eligible 보호막의 정확한 분류와 생성량 modifier 합성 순서는 후속 판정에서 정한다.
