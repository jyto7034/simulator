## 스킬 파편 능력:

- 2026-10-07 변경: `황홀의 포자막`은 시전 순간 범위 안 아군마다 독립 방어막을 한 번 부여한다.
  시전자 본인도 대상이며, Ground·Platform 직원 포함을 우선하고 Guest·소환물·오브젝트 자격은 미정이다.
- 피격 아군의 방어·감면 계산 후 자기 방어막만 소모하고 초과 피해는 자기 HP에 적용한다.
  다른 아군의 잔량을 사용하지 않으며 각 방어막은 소진·만료 시 종료하고 자동 재생하지 않는다.
- 시전 후 새로 범위에 들어온 아군에게는 부여하지 않는다. 받은 아군은 범위에서 나가도 유지하며
  재진입으로 추가 부여·충전되지 않는다. 제공자 출처는 시전자이고 시전 후 기본 행동을 계속할 수 있다.
- 조우의 거리 기반 무효화는 플레이어 파편으로 옮기지 않는다. 파편·무기·방어구·액세서리의 합의
  구조는 `abnormality_skill_fragments_design_notes.md`의 `포큐버스` 절이 소유한다.
- 최종 범위·개인 보호량 계산식·계수·지속 시간은 추후 결정한다. 동일 개인량 `S`를 N명에게 주면
  총량이 `N × S`이므로 기존 공용량을 그대로 복제하지 않고 재조정한다. 최대 HP 비례는 초안이다.
- 단일 전환 유물은 여러 개인 방어막을 한 명의 강화 방어막으로 바꾼다. 기존 공용 기준 2배·침식
  4배 비교안은 새 개인량에 승계하지 않고 배율·패널티를 다시 결정한다. 이번 변경은 문서 정책이다.

### Run 유물 적용 — 단일 대상 전환·효과 증폭

2026-09-08 합의한 범용 단일 전환 방향은 유지한다. 2026-10-07 개인 방어막 변경에 따라
공통 효과와 15개 축 검토도
[단일 대상 전환·효과 증폭 범용 유물](../../relics/single-target-conversion.md#rel-%EB%8B%A8%EC%9D%BC-%EB%8C%80%EC%83%81-%EC%A0%84%ED%99%98%ED%9A%A8%EA%B3%BC-%EC%A6%9D%ED%8F%AD--%EB%B2%94%EC%9A%A9-%EC%9C%A0%EB%AC%BC)에서 갱신한다.

- 여러 아군에게 개인 방어막을 부여하는 효과를 **선택한 아군 한 명에게 강화된 개인 방어막을 부여**하는 효과로 전환한다.
- 선택 대상은 원래 보호 자격 안에서 정한다. 시전자 자신도 후보이며, 수동 지정·선택 사거리·대상
  무효화 세부는 후속 설계한다. 생성 뒤 단순 범위 이탈로 사라지지 않는 원본 규칙은 유지한다.
- 일반·침식 강화 배율은 개인 보호량 `S`를 기준으로 다시 결정한다. 기존 일반 `2S`·침식 `4S`는
  공용 보호량 기준의 과거 비교 기록이며 새 개인 방어막의 확정 수치로 승계하지 않는다.
  원래 대상 수를 단일 보호량에 자동으로 곱하거나 여러 방어막을 한 대상에 중첩하지 않는다.
- 제공자는 시전자다. 선택 대상의 방어·감면 계산 후 피해를 그 대상의 잔량에서 흡수하고 초과분은
  해당 HP에 적용한다. 다른 아군에게는 이 시전의 방어막을 부여하지 않는다.
- 유물이 집중을 요구하거나 기본 공격·저지를 중단시키지 않는다. 원본의 지속 시간과 만료·소진,
  재시전·철수 등 lifecycle 초안과 미결정 사항을 유지한다.
- `쾌락의 고리`는 시전자가 생성하는 이 개인 방어막에 한 번 적용한다. 유물과의 증폭 합성은 미정이며,
  일반 회복으로 충전하거나 수혜자의 액세서리로 다시 증폭하지 않는다.
- 침식 배율은 시전자에게 줄 생존 위험과 함께 다시 결정한다. 태아의 기본 공격 강화 수치·집중
  시간을 포큐버스에 가져오지 않으며, 태아의 기존 수치 합의는 유지한다.

## 20 포큐버스

**기존 방향:** 시전 시 범위 안 아군 각각에게 개인 방어막을 준다. 공용 보호막이나 유지 오라가 아니다.

**조립안:** 범위의 아군 목록 고정 → 대상별 독립 보호막 생성 → 각 보호막이 자기 대상의 피해만 흡수한다. 받은 아군이 범위를 벗어나도 유지하고, 나중에 들어온 아군에게 추가하지 않는다. 단일 대상 전환 유물은 한 명에게 강화된 개인 방어막을 주는 방식이다.

**상태와 표현:** 대상마다 남은 보호량·출처·만료를 가진다. 서로 연결된 그림을 사용하더라도 보호량을 공유하지 않는다. 예전 공용 보호막 기준의 2배/4배 배율은 새 개인 방어막에 그대로 적용하지 않는다.

**기능 경계:** 공통 개인 방어막과 한 번의 범위 대상 조회다. 무기의 지속 피해는 갱신 시 다음 주기 피해를 계속 미루지 않고, 액세서리의 방어막 증폭은 최초 생성 시 적용한다.

**검토:** 보호량 식·유지 시간·시전자 이탈 후 유지·같은 출처 재시전의 교체 규칙이 남아 있다. 추천은 시전자 이탈 후 유지, 같은 출처는 새 보호막으로 교체다. 새 값이 작을 때도 교체할지는 플레이 검토가 필요하다.

**태그와 유물 적용**

| 효과 단위          | 태그 후보 | 변경 후보 속성과 지켜야 할 경계                               |
| ------------------ | --------- | ------------------------------------------------------------- |
| 시전 시 대상 조회  | `범위`    | 부여 반경·대상 수. 한 번의 조회이며 `지속영역`이 아님         |
| 아군별 개인 보호막 | `보호막`  | 대상별 보호량·기간·우선순위. 독립 잔량이며 합계 공용량이 아님 |

**유물 연결:** 기존 **단일 대상 전환**은 범위 부여와 개인 보호막의 관계를 확인해 한 명의 강화 보호막으로 바꾼다. 보호량 증가는 새 범용 후보다. **울림통**은 일회성 부여 범위에 적용하지 않는다. 포자 그림만으로 `소환물`을 붙이지 않으며, 보호량 증가가 수혜자 수를 늘리지 않는다.
