## 포큐버스

> 상태: 2026-10-07 공용 쉴드를 범위 내 아군별 개인 방어막으로 변경 합의 /
> 시전 순간 대상 확정·대상별 1회 부여·독립 잔량 / 직접 저지하는 전열 탱커와 장비 구조 유지 /
> 개인 보호량 계산식·계수·최종 보호 범위·지속 시간·세부 판정 미정 / 이번 변경은 문서 정책이며 구현 반영 전
> 기존 단일 전환의 일반 2배·침식 4배 비교안은 공용 보호량을 전제로 한 과거 기준이다.
> 단일 대상 강화 방향은 유지하며 개인 방어막 기준 배율은 다시 결정한다.

조우 설계는 `abnormality_design_notes.ko.md`의 `포큐버스` 절이 소유한다. 조우의 아군 강화 포자를
플레이어용 아군 보호 수단으로 옮긴다. 조우의 거리 기반 공격 무효화는 플레이어 파편으로
이식하지 않는다. 보스의 공격도 피격 아군 자신의 방어막 잔량을 넘으면 HP에 피해를 주어야 한다.

### 전용 조합과 독립성

- 파편은 다른 호환 무기로도 시전 순간 범위 내 아군에게 개인 방어막을 부여하는 보호를 완결한다.
- 쾌락은 다른 Shield 호환 파편과 조합해도 기본 저지 `3`, 가시 타격과 황홀독을 제공한다.
  포자막의 존재와 잔량을 기본 공격·저지 조건으로 삼지 않는다.
- 황홀의 외피는 시전자의 전열 내구, 쾌락의 고리는 생성되는 보호막의 초기량을 담당한다.
- 최대 HP 비례 계산식을 채택하면 전용 조합은 `시전자 체력으로 개인 보호량 계산 -> 각 방어막의 생성량
  증폭을 한 번 적용 -> 아군마다 독립 잔량 유지`가 된다. 보호량 계산식 자체는 별개로 미정이다.
  그동안 무기는 독으로 적을 공격하며, 어떤 장비도 소진된 포자막을 자동 재생시키지 않는다.
- 무기와 파편이 회복을 제공하지 않으므로 소진 이후의 HP 손실은 별도의 회복 수단으로 보완한다.

<a id="frag-미결정-사항-18"></a>
### 미결정 사항

- `Rare`·`GlobalExclusive`·`Shield` 초안의 채택 여부, 최종 이름과 획득 경로
- 사용자 보류 — 추후 결정: 최종 보호 범위·타일 형태와 개인 보호량 계산식·계수
- 보호 대상 eligibility, 철수·전투불능·사망 때 제공자와 대상의 lifecycle
- 개인 방어막 지속 시간, 재시전 교체와 다른 쉴드의 적용 우선순위
- 단일 전환 유물의 일반·침식 강화 배율과 침식 패널티 재조정
- 피해 type·source·상태 이상, 동시 피해와 흡수량의 공명·피격 trigger 처리
- 무기의 미정 profile·사거리·공격 주기·대공 여부와 직접 피해·독의 주기·지속 시간·위력
- 방어구 stat 배분과 강화 성장치, 액세서리 생성량 증가율·snapshot·eligible 보호막 분류
