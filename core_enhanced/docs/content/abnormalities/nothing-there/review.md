## 스킬 파편 능력:

- 기본 파편은 `Hello / Goodbye`(가칭) 구조로 합의했다. 공명 만충에서 첫 시전하면 일정 시간 팔이
  포신처럼 변형되고, 기본 공격이 긴 직선상의 적을 관통하는 공격으로 바뀐다. 배치 위치·저지 수는
  유지하며, 변형 공격은 무기의 직접 기본 공격으로 처리한다.
- 변형 중 다시 입력하면 추가 공명 소비 없이 남은 시간을 포기하고, 생체 칼날의 `Goodbye`로
  전방 넓은 범위를 강하게 공격한다. 포기한 변형 시간이 길수록 마무리 위력이 커진다.
- Hello를 오래 유지해 관통 공격을 이어갈지, 일찍 끝내 강한 일격을 넣을지 선택한다. 자연 만료 시
  원래 기본 공격으로 돌아가며 Goodbye를 자동 발동하거나 이후를 위해 저장하지 않는다.
- 미미크리를 장착했다면 Hello에는 기존 기본 공격 흡혈을 적용한다. Goodbye는 별도 스킬 피해이므로
  미미크리 무기의 흡혈 대상이 아니다. 파편은 전용 장비 없이도 다른 호환 무기로 사용할 수 있다.
- 파편 자체에 추가 능력치 증가·재생·부활·HP 1 생존 보장이나 종료 후 피해·약화를 넣지 않는다.
  파편의 일시 변형은 미미크리 액세서리의 부활 누적·적대적 변태와 별개다.
- 최신 파편·장비 상세는 `abnormality_skill_fragments_design_notes.md`의 `아무 것도 없는` 절이
  소유한다. 개화형 효과·침식형 연출은 사용자 요청으로 추후 결정하며, 기본형과 장비의 합의는
  유지한다. 정확한 지속 시간·위력·범위·입력·취소 판정은 미정이다.

## 10 아무 것도 없는

**기존 방향:** Hello 동안 평타를 직선 관통 공격으로 교체하고, 재입력으로 남은 시간을 소모해 Goodbye를 사용한다. 자연 종료는 마무리 공격을 만들지 않는다.

**조립안:** 자기 시전 → 원래 무기의 공격력·출처를 참조하는 임시 평타 모드 → 재입력 시 잔여 시간 고정 → 모드 종료 → 잔여 시간에 따른 마무리 공격이다. 재입력은 최초 사용의 후속 단계이며 추가 공명을 요구하지 않는 안을 사용한다. HP 1 고정이나 무료 흡혈을 파편에 덧붙이지 않는다.

**상태와 표현:** 모드와 남은 시간, 마무리 사용 여부를 관리한다. 변신이 다른 장비와 원래 공격 출처를 지우지 않는다. 개화형·침식 표현은 기존 보류를 유지한다.

**기능 경계:** 평타 임시 교체 + 후속 입력 + 잔여 시간 환산. 무기의 실제 HP 손실 기반 흡혈, 방어구 비피격 회복은 공통 반응이다. 액세서리의 전투 1회 부활·원정 누적 후 적대화/영구 손실은 별도 생애주기 기능이다.

**검토:** 추천은 강제 중단 때 Hello를 끝내되 Goodbye를 자동 발동하지 않는 것이다. 마무리의 대상 입력과 사거리, 발사 후 시전자 이탈 처리, 재입력 가능 시점을 정한다.

**태그와 유물 적용**

| 효과 단위   | 태그 후보      | 변경 후보 속성과 지켜야 할 경계                       |
| ----------- | -------------- | ----------------------------------------------------- |
| Hello 모드  | `기본공격변형` | 모드 기간·공격 교체 내용. 사용자의 재입력 분기는 별도 |
| 변형된 평타 | `피해·관통`    | 평타 계수·관통 범위. 무기 기본 공격 출처 유지         |
| Goodbye     | `피해·범위`    | 범위·잔여 시간 환산 계수. 직접 스킬 출처 유지         |

**유물 연결:** 평타 강화 유물은 Hello의 평타에, 범위 공격 변경 후보는 Goodbye에 적용한다. 두 효과를 묶어 `피해·관통·범위` 하나로 선택하지 않는다. Hello 기간 증가는 새 후보이며 잔여 시간에 비례하는 Goodbye도 함께 강해질 수 있다. 모드는 `집중유지`가 아니다.
