## 아무 것도 없는

> 상태: Hello 관통 기본 공격 변형·재입력 Goodbye 마무리 파편 기본형과 미미크리 무기·방어구,
> 부활/변태 액세서리 구조 합의 / 개화형 효과·침식형 연출은 사용자 요청으로 추후 결정 /
> 이름·정확한 수치·세부 판정 미정

조우 설계는 `abnormality_design_notes.ko.md`의 `아무 것도 없는` 절이 소유한다. 강아지·고치·인간
형태와 재생, 신체를 무기로 바꾸는 모방을 플레이어 보상으로 옮긴다. 파편은 변형 기본 공격을
유지할지 남은 시간을 포기하고 강한 마무리를 사용할지 선택하는 구조다. 흡혈·재생·부활은 기존
장비가 담당하며, 파편 자체에 같은 생존 효과를 추가하지 않는다.

### 미결정 사항

- 사용자 보류 — 추후 결정: 개화형 효과와 침식형 연출
- 파편의 최종 이름
- Hello의 지속 시간·공격 profile·위력·사거리·관통 대상·대공 여부와 기본 공격 교체 경계
- Goodbye의 기본 피해·남은 시간별 위력 증가 곡선·상한·범위·피해 type과 시간 확정 시점
- 첫 시전과 재입력의 UI·허용 상태·공격 전환·취소 및 Hard CC·Silence·철수·전투불능·부활 판정
- Hello·Goodbye의 공명·장비 trigger·흡혈 source 및 다른 기본 공격 교체 효과와의 합성
- 미미크리 일반 공격의 범위·동시 타격 상한과 흡혈의 공격당 회복 상한
- 방어구의 방어력·Physical 감소량, 재생 시작 지연과 초당 회복량
- 액세서리 부활이 보존·취소할 action/target/engagement와 같은 battle-local state
- 세 번째 부활 변태체의 형태·스탯·공격·승리 등록과 장비·파편·액세서리 disposition
- 파편과 장비의 rarity, equip limit, 획득 경로와 강화 recipe
