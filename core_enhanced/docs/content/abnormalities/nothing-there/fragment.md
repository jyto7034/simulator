## 파편 — Hello / Goodbye (가칭)

> 상태: 한시적 직선 관통 기본 공격, 추가 공명 소비 없는 수동 마무리와 남은 시간 비례 위력 구조 합의 /
> 정확한 지속 시간·피해·범위·입력 및 취소 판정 미정 / 현재 미구현

공명이 가득 찼을 때 시전하면 신체 일부를 무기로 바꾸는 `Hello` 상태에 들어간다. 변형을 유지하며
공격할 수 있고, 플레이어가 원하면 남은 시간을 포기해 `Goodbye`로 마무리한다. 적을 처치해 변형을
연장하거나 별도 성장 스택을 쌓는 효과가 아니다.

**첫 시전 — Hello**

- 공명을 정상적으로 소비하고 일정 시간 팔이 포신처럼 변형된다. 이 상태에서는 무기의 기본 공격을
  **긴 직선상의 적들을 관통하는 기본 공격**으로 교체한다.
- 시전 자체가 즉시 별도 공격을 가하거나 기본 공격 주기를 초기화하는 효과는 아니다. 변형 상태의
  공격 주기·사거리·직선 폭·피해·관통 대상·대공 여부는 후속 설계에서 정한다.
- 변형 공격은 장착 무기의 직접 기본 공격 출처를 유지한다. 파편이 부여한 한시적 공격 교체지만
  모든 피해를 스킬 피해로 재분류하거나 원래 기본 공격과 변형 공격을 동시에 발생시키지 않는다.
- 배치 위치·배치 affinity·저지 수와 장착 무기의 archetype은 유지한다. 팔의 포신 연출만으로
  무기가 `Gun`으로 바뀌거나 직원이 Platform으로 이동하지 않는다. 공격 범위 변경은 이 파편의
  명시적인 한시 효과이며 종료하면 원래 무기 기본 공격으로 돌아간다.
- 별도의 집중을 요구하지 않으며, 변형 중에도 공통 행동 가능 규칙에 따라 기본 공격과 저지를 한다.
  이미 부여된 변형의 시간은 battle time을 따르고 Pause 중에는 흐르지 않는다.

**변형 중 재입력 — Goodbye**

- Hello가 유지되는 동안 플레이어가 다시 입력하면 변형을 조기에 끝내고, 팔을 거대한 생체 칼날로
  바꾸어 **전방의 넓은 범위에 강한 일격**을 가한다.
- 추가 공명 소비나 공명 만충을 요구하지 않는다. 활성 중인 변형을 끝내는 후속 사용이며, 별도의
  Hello 시전이나 지속 시간 갱신으로 처리하지 않는다. Hello의 시간제 공격 교체가 유지되는 동안에는
  공통 사용 잠금에 따라 공명 충전·양수 획득을 막는다. 추가 소비 없음이 유지 중 충전을 허용한다는 뜻은 아니다.
- **포기한 변형 시간이 길수록 Goodbye의 위력이 커진다.** 오래 유지하면 관통 공격을 더 많이 하고,
  일찍 종료하면 그 기회를 포기하는 대신 강한 한 방을 얻는다. 기본 위력·시간별 증가 곡선·상한과
  남은 시간을 확정하는 정확한 시점은 후속 판정에서 정한다.
- Goodbye는 무기 기본 공격이 아니라 파편의 직접 스킬 피해다. 해당 Hello에서 한 번만 사용할 수
  있고, 사용 뒤에는 원래 무기 기본 공격으로 복귀한다.
- 재입력하지 않고 시간이 만료되면 원래 기본 공격으로 돌아간다. Goodbye를 자동 발동하거나
  종료 뒤 사용할 수 있는 마무리 공격으로 저장하지 않는다.

**새 유물 — 관통 피해 증가**

2026-10-19 [꿰뚫는 송곳](../../relics/piercing-damage-increase.md)를 새 유물로 추가한다.
Hello의 한 기본 공격이 적을 관통할수록 뒤이어 맞히는 적에게 가하는 피해가 증가한다.
다음 기본 공격은 처음부터 계산하며 Hello 전체에 보너스를 누적하지 않는다. Goodbye에는 적용하지 않는다.
증가율·증가 곡선·상한·등급은 미정이며, 다른 유물 연결 후보와 긴 호흡의 잔여 시간 환산은 별도 검토한다.

**장비와의 연동·독립성**

- 미미크리 무기를 장착했다면 Hello의 관통 공격에는 기존 기본 공격 흡혈을 적용한다. 실제로 줄인
  적 HP를 합산하고 공격당 회복 상한을 한 번 적용하는 기존 규칙을 유지한다.
- Goodbye에는 미미크리 무기의 흡혈을 적용하지 않는다. 다른 장비의 회복 판정까지 일괄 금지하거나
  무기 흡혈의 source 범위를 일반 스킬 피해 전체로 넓히는 변경은 아니다.
- 파편은 미미크리 없이도 다른 호환 무기에서 변형 공격과 마무리를 사용할 수 있다. 이때 미미크리의
  흡혈·방어구 재생·액세서리 부활을 파편이 자체 제공하지 않는다.
- 파편 자체의 추가 공격력·공격 속도·방어력 증가, HP 1 생존 보장, 재생·부활이나 종료 후 피해·약화는
  기본 구성에 넣지 않는다. 일시 변형과 수동 마무리에 집중한다.
- Hello 시전은 액세서리의 부활 횟수에 포함하지 않고, 파편 종료가 액세서리의 적대적 변태를
  발생시키지도 않는다. 두 효과는 같은 신체 모방 연출을 사용하더라도 별개의 조건으로 작동한다.

개화형 효과와 침식형 연출은 사용자 요청으로 추후 결정한다. 기본형과 장비의 합의는 유지하며,
보류한 두 항목을 이번에 확정하거나 폐기하지 않는다.

**2026-10-20 재입력 정책 합의**

- Goodbye 재입력은 공격 태세에서 행동 가능할 때만 허용한다. Hard CC·Silence 중에는
  거절하며, Hello 자신의 사용 잠금만 예외로 처리한다. 다른 행동 제한은 유지한다.
- Hello 만료 시각에는 이미 종료된 것으로 보아 재입력을 거절한다. 처리 시각이 만료
  시각과 같은 요청도 Goodbye를 만들지 않는다.
- 추가 공명 만충·소비 없음, 활성당 마무리 한 번, 자연 만료 시 자동 Goodbye 없음은 유지한다.
- 공통 기준은 [활성 스킬의 수동 재입력](../../../game_rules/combat.md#활성-스킬의-수동-재입력)이 소유한다.

잔여 시간 고정 시점, 진행 중 기본 공격과의 전환, 수락 뒤 취소·철수·전투불능 및 부활과의
경계는 후속 상세화한다. Hard CC·Silence가 새 재입력을 막는 것과 이미 적용된 Hello의
시간제 버프 수명은 구분한다.
이번 기록은 문서 설계이며 runtime·data 구현은 포함하지 않는다.

### 2026-10-22 실행 연결에서 확정한 통상 판정

P5~P8 구현 위임에 따라 다음 입력·전환 정책을 구체화했다. 유지 시간·공격 위력·길이·폭,
마무리 위력 곡선과 계수·상한·타일 범위는 작성값이며 원본 예제의 미정 값을 검증용 수치로 채우지 않는다.

- 첫 입력은 자기 사용이다. 같은 직원·장착 파편 사본의 활성에서 같은 입력을 보내면 수동 마무리
  허가를 검사한다. 만료 우선·공격 태세·Hard CC/Silence 거절을 유지하고, 다른 사용의 잠금은 면제하지 않는다.
- 마무리는 수락 시 잔여 밀리초와 방향을 고정하고, 같은 처리 안에서 교체 해제와 전방 일격을 확정한다.
  준비나 지연 연출을 추가하지 않는다. 식은 작성한 기본 위력 + 초당 증가량 × 잔여 밀리초 / 1000이며,
  선택한 상한을 적용한 최종 정수 위력을 올림한다. 현재 예제의 일격 피해 유형은 물리로 명시했다.
- 이미 준비 중인 기본 공격의 교체 여부는 방출 시점에 정한다. 시작·수동 종료·만료가 기존 기본 공격
  주기를 초기화하거나 다음 공격을 늦추지 않는다. 먼저 방출한 독립 공격은 그 공격의 방출 설정을 유지한다.
- 직선 기본 공격은 방출 시 선택 대상 방향을 향하는 즉시 판정이다. 길이·폭은 타일당 1,000,000 단위로
  보존하며, 유효 적의 몸체와 폭을 가진 선분의 접촉을 계산한다. 접촉이 빠른 순서, 동률은 안정된 개체 ID
  순서로 처리하고 같은 개체는 한 번만 센다. 대공 여부·피해 유형·무기 효과는 장착 무기를 보존한다.
  물리 투사체·비행 시간·장애물 충돌을 새로 부여하지 않는다.
- 꿰뚫는 송곳의 장착 조건·곡선·증가량·상한을 공격 설정에 연결한다. 숫자와 곡선은 미정 상태로 저장한다.
  현재 실행 대상은 명시적으로 선택한 상한 있는 선형 증가를 지원한다. 자세한 접촉 집계는 유물 문서를 따른다.
- 철수·전투불능·전투 종료는 이번 교체와 후속 권리를 정리하고 마무리를 보상하지 않는다.
  실제 전투불능이 발생하지 않은 별도 사망 방지 효과를 철수나 재시전으로 취급하지 않는다.

작성·컴파일·실행의 실제 검사 결과와 미검증 범위는 콘텐츠 조립기의 작업 파이프라인에 별도로 기록한다.
