### Run 유물 — 붉은 실타래 (가칭)

> 2026-09-07 대화 결정: 래티씨아 기본·개화 파편 **전용 유물**로 유지한다.
> 기존 연결·연쇄 공격 구조는 유지하며, 최종 이름·희귀도·수치·세부 판정은 미정이다.

파편과 별도로 획득하는 래티씨아 전용 Run 유물이다. 기본 파편의 작은·큰 친구와 개화 파편이
즉시 배치하는 큰 친구에 적용하며, 다른 파편의 설치물·영역으로 대상을 자동 확장하지 않는다.
유물이 없으면 작은·큰 친구는 각자 독립된 함정으로 발동하며, 유물을 얻으면 가까운 친구들이
눈에 보이는 거미줄로 연결된다. 전용 지정과 유물의 합의·미정 상태는
[유물 콘텐츠 설계 노트](../../relics/red-thread.md#rel-%EB%B6%89%EC%9D%80-%EC%8B%A4%ED%83%80%EB%9E%98--%EA%B0%80%EC%B9%AD)에 함께 기록한다.

- 친구를 배치하거나 진화시킬 때 authored 연결 거리 안의 작은·큰 친구와 자동으로 연결한다.
- 적이 연결된 친구 하나를 발동시키거나 연결된 거미줄을 가로지르면 해당 연결망이 발동한다.
- 연결망의 작은 친구들이 deterministic 순서로 달려들어 공격하고, 큰 친구가 있다면 작은 친구들 뒤에
  더 강한 광역 공격을 가한다.
- 발동한 친구는 자기 공격을 마친 뒤 사라진다. 연결망 전체를 항상 모두 소비할지, trigger·공격 범위
  안에 유효한 대상이 있는 node만 소비할지는 open design이다.
- 기본형은 여러 작은 친구를 펼친 뒤 같은 타일 중첩으로 큰 친구를 연결망의 고점 node로 만들 수
  있다. 개화형은 모든 배치가 즉시 큰 node가 되어 훨씬 빠르게 높은 피해망을 만든다.

직선·삼각형·사각형처럼 별도 조합식을 외우게 하지 않는다. 가까이 배치하면 연결되고, 흩으면 coverage,
모으면 연쇄 화력이라는 한 가지 규칙만 사용한다. 연결 거리, 최대 node 수, 공격 순서, node당 피해
증가와 전체 projectile·피해 상한은 후속 유물 수치 설계에서 확정한다.

## 15 래티씨아

**이번 대화의 방향:** 적이 거미 하나에 접근하면 주변의 같은 출처 거미들이 그 적에게 뛰어들어 폭발한다. 거미줄 연결과 선을 넘는 판정은 실제 전투 규칙에서 제거한다. 화면에서는 거미들이 연결된 것처럼 보여도 된다.

**조립안:** 타일에 작은 거미 설치 → 같은 사본의 거미가 있는 타일에 재시전하면 큰 거미로 진화 → 적이 거미 하나의 감지 범위에 진입 → 그 거미를 기준으로 반경 안 참여 거미 목록 확정 → 참여 거미 예약 → 각 거미의 공격 → 각 거미 소모다. 개화형의 큰 거미 설치 방향은 유지한다. 이미 큰 거미인 곳에 세 번째 단계로 쌓는 기능은 추가하지 않는다.

참여 조회는 최초 감지 거미 주변에서 한 번만 한다. 참여 거미 주변을 다시 조회하여 끝없이 연결하는 규칙은 넣지 않는다. 여러 적이 동시에 접근해도 예약된 거미를 다른 발동이 중복 사용하지 못한다. 같은 사본만 참여시키는 안을 추천하며, 같은 종류의 다른 직원 거미를 자동 합치지 않는다.

**타격 추천:** 작은 거미는 접근한 적에게 단일 피해, 큰 거미는 그 적을 중심으로 범위 피해라는 기존 구별을 유지한다. 거미 4마리면 개별 공격 4회로 처리하고 총합 피해 1회로 바꾸지 않는다. 참여 순서는 작은 거미부터, 같은 종류는 안정된 생성 순서로 정하는 안을 제안한다.

**대상과 소모 추천:** 각 거미는 발사 직전에 원래 적의 유효성을 확인한다. 그때 이미 죽거나 전장에서 사라졌다면 아직 출발하지 않은 거미는 남긴다. 출발한 거미는 소모를 확정하며 되돌리지 않는다. 큰 거미의 폭발 위치는 출발 시 적의 타일로 고정하는 안을 제안한다. 고정 후 적이 이동해도 그 위치에서 폭발한다. 도약에 판정 지연을 둘지는 별도로 정하며, 지연이 없다면 같은 전투 처리 안에서 순서대로 해결한다.

**상태와 표현:** 거미의 출처·위치·크기·남은 수명·예약 여부와 짧은 발동 기록만 관리한다. 진화는 같은 설치물을 갱신하고 수명을 재설정하는 기존 방향을 따른다. 시전자 이탈 후 독립 객체 유지 원칙도 이어받는다. 거미줄 그림·도약 곡선·튀는 파편에는 충돌선을 만들지 않는다.

**기능 경계:** 설치·진화·범위 조회·개별 피해·소모는 공통. 참여 목록의 예약과 동시 발동 처리는 작은 고유 기능 후보다. 지속 연결 그래프·간선 통과 감지·거미 이동 AI는 필요하지 않다.

**검토:** 먼저 작은 거미 단일/큰 거미 광역을 유지할지, 모두 같은 형태로 단순화할지 정한다. 다음은 대상이 중간에 죽으면 미출발 거미를 남기는 추천안과, 처음부터 참여 거미 전부를 소비하는 대안 중 선택한다. 감지 반경·참여 반경·피해·설치 상한은 이 결정 뒤에 조정한다. 위 순서·예약·소모 세칙은 대화에서 확정한 사항이 아니다.

**태그와 유물 적용**

| 효과 단위      | 태그 후보                        | 변경 후보 속성과 지켜야 할 경계                             |
| -------------- | -------------------------------- | ----------------------------------------------------------- |
| 작은·큰 거미   | `소환물`                         | 수명·동시 수·감지 반경·진화. 참여 반경은 별도 발동 규칙     |
| 작은 거미 공격 | `피해`, 폭발 판정 채택 시 `폭발` | 단일 피해량. 단일 폭발이라면 `범위`는 부여하지 않음         |
| 큰 거미 폭발   | `피해·범위·폭발`                 | 피해량·폭발 범위. 출발 타일·목표 고정 규칙 보존             |
| 주변 거미 참여 | 고유 조회·예약 동작              | 참여 반경·개수·순서. `전파`나 영구 연결망으로 표현하지 않음 |

**유물 연결:** 기존 **소환물 범용 유물**은 거미에서 발생한 피해를 선택해 대상 약화를 줄 수 있다. 거미줄 둔화는 무기 효과이므로 폭발에 자동 상속하지 않는다. 거미 여러 마리의 독립 공격은 **깊은 쐐기**에 자동 포함하지 않는다.

**붉은 실타래 재검토:** 기존 유물의 간선 통과·연결망은 이번 단순화 방향과 맞지 않는다. 기본 파편의 독립 발동을 유지하고 **붉은 실타래가 주변 거미 참여를 추가하는 안**을 우선 추천한다. 앞 조립안의 주변 참여를 기본 파편에 포함하려는 의도라면 유물은 참여 반경·수 등을 바꾸는 역할로 다시 설계해야 한다. 두 기능을 중복 지급하지 않으며, 어느 쪽이든 래티씨아 기본·개화형 전용 조건을 유지한다. 기능의 소유 위치는 첨삭으로 확정한다.

### 이전 파편 — 기본 파편 — 이름 미정

공명이 가득 차면 authored 배치 범위 안의 eligible 타일 하나를 선택해 `작은 마녀의 친구`를 배치한다.
작은 친구는 일반 직원처럼 저지하거나 지속 기본 공격을 하는 유닛이 아니라, 적의 접근을 기다렸다가
한 번 공격하는 비저지 함정형 소환물이다.

- 빈 eligible 타일에 처음 시전하면 작은 친구 하나를 배치한다.
- 적이 작은 친구의 authored trigger 범위에 들어오면 대상에게 달려들어 장착 무기의 공격력에 비례한
  직접 피해를 주고 사라진다.
- 작은 친구가 이미 있는 **같은 타일**을 다시 선택하면 두 번째 개체를 겹쳐 쌓지 않고 기존 작은
  친구를 `큰 마녀의 친구` 하나로 변환한다.
- 같은 타일 재시전도 정상적으로 공명 만충과 시전 1회를 소비한다. 따라서 큰 친구 하나는 기본형의
  완성된 시전 두 번을 요구한다.
- 큰 친구가 있는 타일에는 기본형을 세 번째로 중첩할 수 없다.
- 큰 친구는 더 넓은 trigger·피해 범위를 가지고, 발동하면 작은 친구보다 훨씬 강한 광역 공격을 한
  뒤 사라진다.
- 적, 직원, 다른 소환물과 일반 전장 object가 점유한 타일은 선택할 수 없다. 자기 파편이 배치한 작은
  친구의 타일만 진화를 위한 명시적 occupied-tile 예외다.

이 구조의 기본 선택은 `여러 타일에 작은 친구를 펼쳐 coverage를 얻을지`와 `같은 타일에 두 번 투자해
큰 친구의 한방을 만들지`다. 감염 관리, 시간제 변이와 별도 소환수 조작은 요구하지 않는다.

### 이전 파편 — 개화형 파편 — 이름 미정

개화형은 작은 친구를 배치하지 않는다. 공명 만충 시 빈 eligible 타일 하나를 선택하면 `큰 마녀의
친구`를 즉시 배치한다.

- 시전 한 번과 공명 만충 한 번만 소비한다.
- 큰 친구의 trigger·공격·소멸 규칙은 기본형이 두 시전으로 완성한 큰 친구와 같다.
- 이미 작은 친구가 있는 타일을 개화형이 선택하는 상황은 전투 중 파편 교체를 허용하지 않는 현재
  방향에서는 발생하지 않는다. 파편 형태 전환을 전투 중 허용하게 되면 별도 migration 규칙을 정한다.
- 개화형의 큰 친구도 아래 Run 유물에서 하나의 연결 node로 정상 취급한다.

개화형의 차이는 별도 감염 기믹이나 단순 피해 배율이 아니라, 큰 친구를 만들기 위한 배치 준비를
`2회 -> 1회`로 줄여 전개 속도와 같은 시간 안의 큰 친구 수를 바꾸는 데 있다.

조우 설계는 `abnormality_design_notes.ko.md`의 `래티씨아` 절이 소유한다. 조우의 선물 감염, 숙주와
래티씨아 사이의 거리 판정과 숙주 교체는 플레이어 파편에 복제하지 않는다. 엘리트 파편 공통 원칙에
따라 선물에서 `작은 마녀의 친구`가 나타나는 결과만 직접 배치형 active skill로 옮긴다.

### 이전 개요 — 전용 조합과 독립성

- 파편은 다른 `Staff`와 조합해도 장착 무기의 공격력을 참조해 작은·큰 친구의 공격을 완결한다.
- 전용 Staff는 다른 `Staff` 호환 파편과 조합해도 Platform 원거리 단일 마법 공격과 피격 대상의
  거미줄 이동 속도 20% 감소를 제공한다.
- 방어구는 주변 아군 직원 조건으로 착용자의 공격력을 높이며, 다른 파편과도 독립적으로 사용한다.
  액세서리는 파편 종류와 무관하게 eligible 공명 획득을 증폭한다.
- 전용 조합에서는 방어구가 친구의 개별 위력을 높이고, 액세서리는 배치 회전율을 높인다.
  어느 장비도 소환물 동시 배치 상한을 직접 늘리지 않는다.

### 이전 개요 — 미결정 사항

- 기본·개화형 파편, Run 유물과 장비의 최종 이름, `rarity`, `equip_limit`, 획득 경로와 강화 recipe
- 기본형·개화형의 배치 범위, valid tile 규칙, 공명 비용과 전장 동시 배치 상한
- 작은·큰 친구의 trigger·피해 범위, 공격력 계수, 발동 지연, 유지 시간과 소멸·파괴 가능 여부
- 같은 타일 재시전의 선택 UI·preview, 변환 resolution과 큰 친구 위 추가 배치 금지 처리
- 큰 친구가 전장 동시 배치 상한에서 작은 친구 몇 개분으로 계산되는지
- 붉은 실타래의 연결 거리·최대 node 수, 거미줄 교차 판정, 연쇄 순서와 피해 공식
- 연결망 발동 시 유효 대상이 없는 node의 소비 여부와 전장 전체 피해·연출 safety 상한
- 전용 Staff의 피해량·사거리·공격 주기·대상 선정·대공 여부와 전달 방식
- 거미줄의 둔화 지속 시간, 재부여·중첩 및 다른 둔화·면역·저항과의 판정
- 방어구의 공격력 증가율·판정 범위·최대 HP·Magic 저항 수치와 강화 성장치
- 방어구의 아군 직원 거리·유효성 갱신과 작은·큰 친구 피해의 공격력 참조 시점·modifier 합성
- 액세서리의 공명 획득 증가율, eligible source, 계산 순서·소수점·상한 처리

### 이전 유물 — 붉은 실타래

> 상태: 2026-09-07 사용자 대화에서 전용 유물로 유지하기로 합의 /
> 래티씨아 기본·개화 파편 대상 / 기존 연결·연쇄 공격 구조 유지 /
> 희귀도·수치·세부 판정 미정 / 현재 runtime·live data 구현은 포함하지 않음.

**가까운 작은·큰 마녀의 친구를 거미줄로 연결한다. 적이 친구 하나를 발동시키거나 연결된 거미줄을
가로지르면, 연결된 친구들이 연쇄 공격한다.**

| 항목 | 내용 |
| --- | --- |
| 구분 | 래티씨아 파편 전용 유물 |
| 적용 대상 | 기본 파편의 작은·큰 친구와 개화 파편이 즉시 배치하는 큰 친구 |
| 희귀도 | 미정 |

| 연결 시점 | 친구를 배치하거나 진화시킬 때 연결 거리 안의 친구들과 연결 |
| 발동 | 적이 연결된 친구를 발동시키거나 거미줄을 가로지름 |
| 공격 순서 | 작은 친구들이 정해진 순서로 공격하고, 큰 친구가 뒤이어 강한 광역 공격 |
| 소비 | 발동한 친구는 자기 공격을 마친 뒤 사라짐. 연결망 전체 소비 여부는 미정 |

작은·큰 친구의 배치와 진화, 기본·개화형 차이를 함께 활용하므로 전용으로 둔다. 다른 파편의
고기벽·회복 장판·타일 스택을 연결 대상으로 자동 확장하지 않는다. 파편은 유물이 없어도 각 친구의
독립 발동으로 완결된다.

기존 세부 구조는 [래티씨아 파편 설계](README.md)를 따른다.
연결 거리·최대 연결 수, 전체 연결망 또는 유효 대상이 있는 친구만 소비할지, 다른 직원이 배치한
친구와의 연결 여부, 세부 공격 순서·피해 증가·상한, 중복·비호환과 획득 방식은 후속 설계한다.

## 이번 검토에서 폐기한 안

- 폭발 직후 작은 친구를 곧바로 남기는 초기안: 선물 대상의 사망 생성으로 대체.
- 작은 친구 4마리 이상부터 합체하는 안: 2마리분 큰 친구·3마리분 이상 특별한 친구로 대체.
- 일반형 중심 1마리와 주변 2마리 배치안: 선택 타일 1마리와 동서남북 인접 한 곳 1마리, 총 2마리로 대체.
- 왕을 참고한 가로·세로 폭발 모양, 포위·추격, 거미줄 연결과 주변 참여 연쇄안: 제외.
