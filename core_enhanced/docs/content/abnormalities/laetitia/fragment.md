## 현재 합의 — 2026-10-20

> 일반형 작은 친구 2마리 / 개화형 큰 친구와 작은 친구 / 같은 타일 2마리분은 큰 친구, 3마리분 이상은 특별한 친구.
> 감지 1칸·도약 폭발, 범용 유물 4개·전용 유물 1개 연결 합의. 수치·세부 판정은 후속이며 구현 완료를 뜻하지 않는다.

공명이 가득 차면 배치 범위 안의 유효한 타일 하나를 선택해 마녀의 친구를 배치한다.
친구는 일반 직원처럼 저지하거나 지속 기본 공격을 하는 유닛이 아닌 **비저지 함정형 소환물**이다.
공격은 장착 무기의 공격력을 참조하며, 다른 Staff와도 파편 자체의 배치·공격을 완결한다.

<a id="frag-기본-파편--이름-미정"></a>
## 기본 파편 — 이름 미정

- 선택 타일에 작은 친구 1마리, 그 타일의 **동서남북 중 인접 타일 한 곳**에 작은 친구 1마리를 배치한다.
- 시전 한 번에 작은 친구 총 2마리를 배치한다. 대각선이나 인접 타일 여러 곳에 추가하지 않는다.
- 인접한 곳에 배치할 공간이 없으면 선택 타일에 **큰 친구 1마리**를 배치한다. 작은 친구를 따로 더 남기지 않는다.
- 어느 인접 타일을 고를지, 유효한 지형·점유 조건과 선택 UI는 후속으로 정한다.

<a id="frag-개화형-파편--이름-미정"></a>
## 개화형 파편 — 이름 미정

- 선택 타일에 **큰 친구 1마리**, 동서남북 중 인접 타일 한 곳에 **작은 친구 1마리**를 배치한다.
- 인접 공간이 없으면 큰 친구와 작은 친구가 선택 타일에서 합쳐져 **특별한 친구 1마리**가 된다.
- 큰 친구 2마리나 작은 친구 3마리를 각각 흩어 배치하는 형태가 아니다. 인접 위치의 세칙은 일반형과 함께 후속으로 정한다.

## 같은 타일의 합체

마릿수는 작은 친구 1마리분을 기준으로 합산한다. 큰 친구는 2마리분이며 특별한 친구는 실제 누적 수를 보존한다.

| 같은 타일의 누적 수 | 결과 | 공격 특징 |
| --- | --- | --- |
| 1마리분 | 작은 친구 | 기본 폭발 |
| 2마리분 | 큰 친구 | 작은 친구보다 강한 광역 폭발 |
| 3마리분 이상 | 특별한 친구 | 누적 수에 따라 피해 증가, 폭발 범위 2배 |

- 작은 친구 2마리는 큰 친구, 큰 친구와 작은 친구는 3마리분의 특별한 친구가 된다.
- 특별한 친구가 있는 타일에 추가 생성되면 기존 개체에 합류하고 누적 수가 증가한다.
- 재시전·추가 배치로 기존 친구와 같은 타일에 모이는 경우도 누적 수로 합체한다. 기존의 큰 친구 위 추가 배치 금지는 폐기한다.
- 공간 부족으로 생성하는 큰·특별한 친구는 이번 시전의 2·3마리분을 표현한다. 기존 친구를 지우거나 누적 수를 초기화하는 규칙이 아니다.
- 특별한 친구의 **2배 범위 기준, 반경·면적·타일 모양과 피해 환산식은 미정**이다. 합류할 때마다 범위가 계속 2배가 되지 않는다.
- 합체 누적 수는 고유 수치다. 이 합의만으로 스택·스택획득·스택한도 유물의 대상으로 만들지 않는다.
- 서로 다른 직원이 소유한 친구의 합체 여부·귀속은 후속이며, 현재 합의만으로 타 직원의 거미를 자동 합치지 않는다.

## 감지·도약·폭발

1. 작은·큰·특별한 친구 모두 **설치 위치 기준 1칸** 안의 적을 감지한다.
2. 적이 있으면 그 적의 타일로 날아가 폭발하고 소멸한다. 적이 없으면 대기한다.
3. 세 종류 모두 폭발 공격이다. 큰·특별한 친구의 피해 범위가 커져도 감지 거리가 자동으로 늘어나지 않는다.

감지 1칸의 거리 계산·대각선 인정, 여러 적 중 대상 선정, 도약 시간·목표 위치 고정 시점,
도약 도중 대상의 이동·사망·이탈 처리는 후속이다. 도약 연출만으로 투사체 충돌 태그를 부여하지 않는다.
각 폭발은 독립 공격이며, 이를 한 시전의 순서 있는 직접 연타로 묶어 깊은 쐐기를 적용하지 않는다.
서로 다른 폭발이 같은 적에게 주는 중복 피해 판정은 미정이다.

## 전용 유물과 범용 연결

[아직 남은 선물](../../relics/red-thread.md)은 거미 공격에 10초 선물을 추가하고, 선물을 가진 적이
사망하면 사망 위치에 작은 친구 1마리를 만든다. 생성된 친구도 선물을 부여할 수 있다.
여러 적이 동시에 사망하면 **거미 생성 → 합체 → 공격 대상 탐색** 순서로 처리한다.
이 사망 생성에는 직접 시전의 인접 추가 배치를 붙이지 않는다.

선물과 사망 생성은 전용 유물의 효과다. 유물이 없을 때 기본 파편에 자동 지급하지 않는다.
[태그·유물 연결](synergies.md)의 범용 4개는 압축 화약·넓어진 지평·사냥의 낙인·긴 호흡이며,
긴 호흡은 전용 유물의 선물 10초를 12.5초로 늘리는 조건부 연결이다.

## 제외한 기믹과 후속 결정

가로·세로 배치에 따른 폭발 형태, 포위·추격, 거미줄 연결·교차 감지·주변 거미의 연결망 연쇄 공격은 제외한다.
조우의 거리 기반 숙주 변이와 직원용 파편·유물의 사망 생성은 서로 다른 규칙이다.

배치 범위·공명 비용·유효 타일과 인접 선택 순서, 크기별 피해·폭발 범위·타입,
특별한 친구의 2배 범위 기준과 피해 환산, 대기 수명·파괴 가능 여부·전장 상한,
합체 소유권·누적 상한·능력치 참조 시점, 도약 중 대상 처리와 중복 폭발 피해는 후속이다.
장비 효과와 그 수치·미정은 [장비](equipment.md)를 유지한다.

## 2026-10-22 공통 작성 계약의 세부 정책

P6 구현 위임 범위에서 다음 판정을 채택한다. 피해·범위·속도·수명·상한의 미정 수치는 그대로 둔다.

- 감지는 설치 타일과 상하좌우 1칸이다. 가장 가까운 eligible 적, 동률은 유닛 ID 순으로 고른다.
  도약을 시작하면 당시 목표 타일을 고정한다. 이동 속도로 도착한 뒤 별도 폭발 지연을 적용하며,
  도약 후 목표의 이동·사망으로 목적지를 바꾸지 않는다. 대기 수명은 도약 전까지만 적용한다.
- 선택·인접 배치는 유효 지상 타일과 다른 전투 유닛의 점유를 확인한다. 인접 후보는 북→동→남→서
  순서로 정한다. 같은 계열의 대기 친구는 점유 장애물이 아니며 배치 묶음의 생성·합체 뒤 탐색한다.
- 합체 키는 소유 직원·파편 사본·계열 정의·타일이다. 실제 누적 수를 보존하며 도약한 친구는 합체하지 않는다.
  타일 상한을 넘는 새 타일 생성은 생략하고 기존 타일 합체는 허용한다. 누적 상한 초과분은 버린다.
  직접 시전은 전체 배치가 가능할 때만 비용을 확정한다. 사망 생성의 상한 초과는 앞선 사망을 되돌리지 않는다.
- 공격은 Magic으로 작성한다. Attack은 최초 생성 때 고정하며 합체로 최신 생성자의 능력치를 덮어쓰지 않는다.
  큰 친구는 기본 위력 증가, 특별한 친구는 큰 친구 위력에 실제 누적 수의 2 초과분별 비율 증가를 적용한다.
  특별한 친구의 범위는 큰 친구 폭발의 연속 타일 영역을 길이 2배로 확대해 정수 타일 중심으로 판정한다.
  합체할 때마다 재귀 확대하지 않는다. 감지 범위는 그대로다.
- 한 폭발의 적별 적중은 한 번이다. 서로 다른 친구의 독립 폭발은 각각 적중한다. 이 판정만으로
  보류한 중첩된폭발 유물을 추가하지 않는다. 이미 방출한 효과는 소유자 이탈 후에도 유지하고 전투 종료에 정리한다.
- 선물은 같은 출처 재부여 시 10초로 갱신하며 치명 적중도 사망 확정 전에 표식을 부여한다.
  사망 ID·출처당 한 번 생성하고, 동시 사망은 생성→합체→탐색 순서다. 선물에서 만든 친구도 다시 선물을 부여한다.
  전용 무기의 거미줄 둔화는 자동 상속하지 않는다.
- 대기 감지는 전투의 `movement_tick_ms` 간격으로 현재 위치를 표본 조회한다. 생성 직후에는 같은 사건의
  생성·합체를 마친 뒤 바로 탐색한다. 연속 이동의 구간 교차 전체를 별도로 충돌 검사하지 않는다.
  대기 만료와 탐지가 같은 시각이면 만료를 먼저 처리한다.
- 선물 후속 효과에는 직접 부모 효과 activation과 실제 장착 유물 사본·정의를 보존한다.
  이미 대기 중인 효과로 합체하면 최초 효과의 생성 시각·Attack·출처를 유지한다.
