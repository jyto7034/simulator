## 래티씨아

> 상태: 2026-10-20 일반형 작은 친구 2마리·개화형 큰 친구와 작은 친구, 2마리분 큰 친구·3마리분 이상 특별한 친구 합의.
> 감지 1칸·도약 폭발, 특별한 친구 범위 2배, 선물 10초 사망 생성, 범용 4개·전용 1개 연결 합의. 밸런스·세부 판정 후속.

일반형은 선택 타일과 동서남북 중 인접 한 곳에 작은 친구를 배치하며, 인접 공간이 없으면 큰 친구를 배치한다.
개화형은 큰 친구와 작은 친구를 배치하고 인접 공간이 없으면 특별한 친구로 합친다.
가로·세로 배치 기믹과 거미줄 연결은 폐기했다. 조우의 선물·거리·숙주 변이는 [조우](encounter.md)에
남으며, 직원용 파편의 선물 사망 생성은 전용 유물 [아직 남은 선물](../../relics/red-thread.md)이 소유한다.

### 전용 조합과 독립성

- 파편은 다른 Staff와 조합해도 장착 무기의 공격력을 참조해 세 종류 친구의 공격을 완결한다.
- 전용 Staff의 Platform 단일 Magic 기본 공격·피격 대상 이동 속도 20% 감소는 장비 효과로 유지한다. 친구 폭발에 자동 상속하지 않는다.
- 방어구는 주변 아군 직원 조건으로 착용자의 공격력을 높이며, 액세서리는 eligible 공명 획득을 증폭한다.
- 장비의 기존 합의·초기 수치 후보·미정은 [장비](equipment.md)를 따른다. 이번 파편·유물 변경으로 별도 장비 개편을 하지 않는다.

<a id="frag-미결정-사항-13"></a>
### 미결정 사항

- 파편·장비의 최종 이름, rarity·equip_limit·획득·강화, 배치 범위·공명 비용
- 유효 타일·점유 예외·동서남북 선택 우선순위와 입력·preview
- 감지 1칸의 거리 계산, 크기별 피해·폭발 범위·타입, 특별한 친구의 2배 범위 기준과 피해 환산
- 대기 수명·파괴 가능 여부·전장 동시 상한, 합체 누적 상한·소유권·능력치 참조 시점
- 도약 시간·표적 선정·목표 위치 고정과 이동·사망·이탈 처리, 별개 폭발의 중복 피해
- 선물의 복수 직원 귀속·동시 사망 집계·사망 타일 점유와 생성 가능 조건
- 사냥의 낙인의 증가율·합성, 넓어진 지평과 특별한 친구 범위의 계산 순서, 거리 유물의 기준점·측정 시점
- 무기·방어구·액세서리의 수치와 세부 판정은 장비 문서의 기존 미정을 유지
