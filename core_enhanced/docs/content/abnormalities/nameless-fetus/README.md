## 이름이 없는 태아

> 상태: 시전자가 기본 행동을 포기하는 지속 집중 동안 범위 내 아군의 기본 공격 피해·속도를 높이는
> 공격 지원 파편, Platform 초고속 음파 `Gun`인 `울대`, Magic 방어 특화 방어구와 플레이어가 선택한
> 최대 HP 희생 단계만큼 공격 속도를 얻는 액세서리 구조 합의 / 가칭 이름과 수치·세부 판정 미정
> 2026-09-07 후속 합의: 기본 / 단일 전환 범용 유물 / 침식된 단일 전환 범용 유물의 기본 공격 피해 `+20% / +40% / +80%`,
> 공격 속도 `+15 / +20 / +30`으로 교체 적용 / 집중 시간·침식 패널티의 세부 설계 미정
> 2026-09-08 후속 결정: 단일 전환·효과 증폭은 포큐버스에도 쓰는 범용 유물로 이전. 태아 적용 수치는 유지하며 태아 전용 유물은 미정.

조우 설계는 `abnormality_design_notes.ko.md`의 `이름이 없는 태아` 절이 소유한다. 원작에서 태아의
울음은 넓은 구역의 직원에게 정신 피해를 주고 다른 환상체의 위험까지 연쇄적으로 앞당긴다. 원작
E.G.O `울대`는 낮은 단발 위력을 매우 빠른 장거리 공격으로 보완하며, 방어구와 기프트는 울음에
대응하는 정신 피해 저항과 공격 속도를 제공한다.

무작위 직원을 인신공양하는 룰렛은 이 게임의 파편이나 상시 장비 효과로 옮기지 않는다. 장비를
사용했다는 이유로 통제할 수 없는 run-local 직원 영구 손실을 만들면 loadout 선택보다 회피와
rollback을 강요하고, 단순·즉시 사용을 지향하는 엘리트 파편의 범위를 벗어난다. 룰렛, 지워지는 이름과
배의 입은 파편·장비의 외형, 설명과 침식 연출에만 사용할 수 있다. 실제 전투 문법은 `울음`, `빠른
장거리 공격`, `정신 피해 저항`과 `속도를 얻는 대신 약해지는 신체`에 집중한다.

### 전용 조합과 독립성

- 파편은 다른 `Gun`과 조합해도 시전자의 행동을 포기하는 동안 범위 내 아군의 기본 공격 피해·속도를
  높이는 지속 집중을 완결한다.
- `울대`는 다른 `Gun` 호환 파편과 조합해도 매우 빠른 장거리 선형 Magic 무기로 기능한다.
- 양막의 수의는 전용 세트 없이도 Magic 피해가 강한 전투를 대비하는 편향형 방어구다.
- 울대 수신기는 전용 파편이 없어도 기본 공격 중심 직원이 원하는 위험 단계만큼 최대 HP를 희생하는
  능동형 속도 장비로 사용한다.
- 전용 조합에서 집중 중인 착용자는 `울대`로 공격하지 않으므로, 울대 수신기의 공격 속도 단계는
  집중을 중단하고 직접 공격으로 돌아온 구간에 효력을 발휘한다. 양막의 수의는 최대 HP를 희생한
  시전자가 집중 중 후방을 노리는 Magic 공격에 버티도록 보조한다. 박동을 받은 아군과 수신기 착용자의
  공격 속도 modifier 합성 방식·최소 공격 주기 clamp는 공통 stat 정책을 따른다.

<a id="frag-미결정-사항-16"></a>
### 미결정 사항

- 파편·방어구·액세서리의 최종 이름, 획득 경로와 강화 recipe
- `Rare`와 `GlobalExclusive` 초안의 최종 채택 여부
- 준비 `0.5초`·기본 반경 `2타일` 초안의 채택·조정과 aura 편입·이탈 판정. 기본 공격 피해 `20/40/80%`·공격 속도 `15/20/30`의 상태별 교체는 합의됨
- 비침식 집중 `6~8초` 방향의 정확한 값(`8초`는 비교 초안), 유지 중 추가 자원 소모 없음 초안과 공명 충전 주기를 포함한 실제 유지율
- 단일 전환 범용 유물의 단일 대상 선정·지정 사거리·부착 및 종료 규칙, 침식된 단일 전환 범용 유물의 패널티·집중 유지 방식과 HP 비용 판정
- 집중 중 block engagement와 enemy overlap 처리
- 명시적 시전 중지 command, authored interrupt 분류와 강제 이동·전투 종료 시 exact cleanup reason
- 진행 중 아군 기본 공격과 박동 시작·종료가 만나는 boundary의 exact snapshot timing
- `울대`의 공격력·사거리·직선 폭·공격 주기·windup, 관통 상한·피해 감쇠와 공중 target eligibility
- 양막의 수의의 방어력·Magic 저항·최대 HP, 장비 강화 시 편향을 유지하는 성장 비율
- 울대 수신기의 단계 수와 단계별 최대 HP 희생률·공격 속도 증가율
- 액세서리 상호작용 UI, command capability, Pause 허용 여부와 단계 상승 preflight·실패 reason
- 울대 수신기와 박동을 포함한 여러 공격 속도 modifier의 합성 순서와 최소 공격 주기
