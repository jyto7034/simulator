## 커다랗고 나쁠 늑대

> 상태: 2026-10-19 파편 제외, 장비만 유지 / 변신 무기와 run-local 타락 액세서리 방향 합의 /
> 이름·수치·세부 판정 미정

조우 설계는 `abnormality_design_notes.ko.md`의 `커다랗고 나쁠 늑대` 절이 소유한다. 보상은 원작
기믹을 그대로 복제하기보다, 전투로 허기를 쌓고 늑대인간으로 변한 뒤 흡혈로 버티는 **근거리
광전사 딜탱**을 중심으로 설계한다.

새 weapon archetype은 만들지 않는다. 발톱과 이빨을 사용하는 presentation과 별개로 파생 무기는
기존 지상 근거리 공격형 분류인 `Sword`를 사용한다.

### 미결정 사항

- 무기, 방어구와 액세서리의 최종 이름
- 세 장비의 rarity, 우호·적대 결말별 획득 경로와 중복 소유 정책
- 무기 강화 recipe
- 방어구의 정확한 stat 분배
- 액세서리 네 형태의 최종 이름·외형·설명과 각 단계의 효과 수치
- `K1`, `K2`, `K3`, eligible 직접 처치 source와 전이 순간의 초과 처치 처리
- 액세서리 instance의 장착·이전·강화·checkpoint·carry-in lifecycle
- 양의 탈 run 종료 이스터에그의 인정 조건과 미래 run의 보상 지급 방식. 늑대 파편은 제외
- 커다랗고 나쁠 늑대 재조우 특별 Event의 발동 조건·내용·결과
- 무기 자체 허기·변신과 액세서리 전이의 authoring·validation 방식
