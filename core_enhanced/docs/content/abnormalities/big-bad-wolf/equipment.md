# 커다랗고 나쁠 늑대 · 장비

[콘텐츠 위키](../../README.md) · [개요](README.md) · [조우](encounter.md) · [파편 없음](fragment.md) · [아카이브](review.md)

> 콘텐츠 설계. 2026-10-19 늑대 파편을 제외하고 장비만 유지한다. 구현 완료를 뜻하지 않는다.

무기 자체 허기·변신·흡혈, 방어구와 양의 탈은 유지한다. 제외한 파편의 포식·포만·혈광폭화 효과를 장비에 추가하지 않는다.

## 무기 — 이름 미정

| 항목 | 값 |
| --- | --- |
| `range_role` | 근거리 |
| `weapon_archetype` | `Sword` |
| `deployment_affinity` | 지상 전용 |
| `block_capacity` | 인간형 `1` / 짐승형 `3` |
| `ground_defense_focus` | open design |
| `platform_rest` | 해당 없음 |
| `damage_type` | 물리 |
| `targeting_profile` | 저지 중인 적 우선 |
| `air_capable` | 불가능 |
| `defense_tile_range` | 근거리 |
| `interval_ms` | 형태별 open design |
| `windup_ms` | 형태별 open design |
| `delivery` | 즉시 근접 타격 |

무기는 인간형과 짐승형을 오가는 변신형 근거리 딜탱이다. 외형상 무기를 들지 않고 발톱과 이빨로
공격하지만 기존 combat compatibility와 profile 분류는 `Sword`를 사용한다.

**인간형과 허기**

- 전투 시작 시 인간형이다.
- 인간형은 적 하나만 저지하고 단일 대상을 공격한다.
- 기본 공격으로 실제 피해를 가하거나 저지 중 실제 피해를 받으면 `허기`를 얻는다.
- 허기가 최대가 되면 자동으로 짐승형으로 변신한다.

**짐승형**

- 저지 수가 `3`으로 증가한다.
- 공격력과 공격 속도가 증가한다.
- 한 번의 발톱 공격으로 현재 저지 중인 적을 모두 타격한다.
- 짐승형 기본 공격이 실제로 감소시킨 HP 일부만큼 착용자의 HP를 회복한다.
- 적을 처치하면 허기를 회복해 변신 시간을 연장한다.
- 허기는 시간에 따라 감소하며 모두 소진되면 인간형으로 복귀한다.

흡혈은 늑대 무기의 짐승형 **직접 기본 공격**만 source로 인정한다. 파편, 유물 proc, 반사, 환경 피해나
흡혈로 발생한 회복이 다시 흡혈을 일으키지 않는다. 과잉 피해를 제외하고 실제로 감소시킨 HP만
참조하며 physical damage와 trauma는 회복하지 않는다. 다수 타격에서의 대상별 효율 또는 공격 1회당
총 회복 상한은 수치 설계에서 정한다.

Attack/Defense 태세의 공통 규칙은 두 형태에 그대로 적용한다. DefenseFocus 중에는 저지와 피해 감소
효과를 얻지만 새 기본 공격을 시작하지 않으므로 짐승형 흡혈도 멈춘다. 생존을 위해 방어할지,
공격하며 흡혈할지를 선택하게 한다.

open design:

- 형태별 공격력, 공격 주기와 windup
- 가한·받은 피해당 허기 획득량, 허기 상한과 시간 감소량
- 짐승형 기본 공격의 범위와 저지 대상 동시 타격 순서
- 흡혈률, 다수 타격 효율과 공격당 회복 상한
- 변신·복귀 도중 targeting, 공격과 저지 snapshot
- Ground DefenseFocus의 block bonus와 피해 감소량
- 최종 이름과 인간형·짐승형 presentation

## 방어구 — 이름 미정

변신 전까지 버티고 짐승형 흡혈이 작동할 체력 여유를 제공하는 단순 수치 방어구다.

| 항목 | 값 |
| --- | --- |
| 효과 | 높은 최대 HP와 방어력·물리 저항 계열 단순 수치 |
| 자체 특수 효과 | 없음 |
| 정확한 수치 | open design |

<a id="frag-액세서리--양의-탈-가칭"></a>
## 액세서리 — 양의 탈 (가칭)

> 상태: 네 형태의 run-local 영구 전이와 단계별 효과 교체 구조 합의 /
> 처치 임계치·효과 수치·설명 문구·이스터에그 상세 open design

착한 존재로 남고 싶었던 늑대가 세상이 요구한 `나쁜 늑대`의 역할을 받아들이는 과정을 액세서리의
외형과 설명으로 보여 주는 run-local 변형 장비다.

**형태와 효과**

| 형태 | 외형·설명 방향 | gameplay 효과 방향 |
| --- | --- | --- |
| `양의 탈` | 웃고 있는 온순한 늑대. 아직 누구도 해치고 싶지 않다 | 단순한 이로운 효과. 최대 HP 증가를 첫 prototype으로 검토 |
| `흐려진 미소` | 웃음에 그늘이 생긴다 | 단순 공격력 증가 |
| `금이 간 탈` | 미소가 사라지고 탈에 금이 간다 | 착용자가 받는 최종 피해 증가 |
| `나쁜 늑대` | 이빨을 드러낸 포악한 표정 | 공격력 대폭 증가 |

각 형태의 효과는 누적하지 않고 **완전히 교체**한다. 따라서 `금이 간 탈`에서는 앞 단계의 공격력
증가를 잃고 받는 피해 증가만 적용한다. `나쁜 늑대`가 되면 금이 간 탈의 받는 피해 증가는 사라지고
마지막 형태의 대폭적인 공격력 증가만 적용한다.

형태가 바뀔 때 장착 아이콘 또는 외형과 액세서리 설명도 즉시 현재 형태에 맞게 교체한다. 정확한
설명 문장은 후속 narrative authoring에서 정하며, 이름·효과 수치와 함께 `open design`이다.

**처치 진행과 run-local 전이**

```text
양의 탈 ── K1킬 ──> 흐려진 미소
흐려진 미소 ── K2킬 ──> 금이 간 탈
금이 간 탈 ── K3킬 ──> 나쁜 늑대

K1 < K2 < K3
```

- 액세서리를 장착한 직원이 직접 death finalization을 확정한 eligible 적만 현재 형태의 처치 진행도를
  올린다.
- 각 형태는 자신의 전이 임계치를 가진다. 다음 형태로 바뀌면 이전 단계의 진행도는 끝나고 새 단계의
  처치 진행도를 `0`부터 쌓는다.
- 뒤 단계로 갈수록 다음 전이에 필요한 처치 수가 증가한다. `K1`, `K2`, `K3`의 exact 값은
  `open design`이다.
- 임계치에 도달하면 전투 중에도 즉시 다음 형태로 바뀌며 외형·설명·효과를 함께 교체한다.
- 형태와 현재 처치 진행도는 해당 run 동안 액세서리 instance가 소유한다. 다른 직원에게 옮기거나
  장착을 해제해도 초기화되지 않지만, 장착하지 않은 동안의 처치는 진행도를 올리지 않는다.
- Retreat·패배는 attempt 진입 전의 형태와 진행도로 되돌린다. 승리로 commit한 처치와 형태 전이만
  이후 node에 유지한다.
- 새 run에서는 같은 액세서리를 carry-in하더라도 `양의 탈`과 첫 단계 진행도 `0`에서 다시 시작한다.

이 액세서리는 무기의 `허기`를 생성·충전하지 않는다. 다른 파편·무기를 사용해도
직접 처치, 형태 전이와 현재 형태의 효과를 모두 독립적으로 사용한다.

**Open design 이스터에그**

- run이 끝날 때 액세서리가 아직 `양의 탈`이라면 이스터에그를 발생시키는 방향을 둔다. 성공·실패·중도
  종료 중 어떤 run 종료를 인정할지, 장착 중이어야 하는지 또는 보유만 해도 되는지는 `open design`이다.
- 이 이스터에그는 향후 새로 생성되는 모든 run-local에 장비 또는 파편을 부여하는 profile-level
  후속 보상과 연결한다. 늑대 자체 파편은 제외하며, 지급할 다른 보상과 자동 지급인지 carry-in 선택 후보 추가인지, 기존의
  `몇 개를 챙겨가는` roguelike carry-in 계획과 어떤 방식으로 결합할지는 모두 `open design`이다.
- 이 액세서리를 carry-in하거나 관련 조건을 만족한 뒤 `커다랗고 나쁠 늑대`와 다시 조우하면 특별
  Event를 발생시키는 방향을 둔다. 필요한 탈의 형태, 대화·연출·선택지와 gameplay 결과는
  `open design`이다.
