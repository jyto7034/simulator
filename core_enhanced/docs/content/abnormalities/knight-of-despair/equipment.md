> 현재 합의한 설계와 남은 미정 사항. 구현 완료를 뜻하지 않는다.

**연결 검토 필요:** 이 페이지는 기존 장비 자체의 설계를 보존한다. 파편은 이후 리워크되었다. 방어구의 보호 대상 공유·액세서리의 마지막 검 자기 관통·기존 세트 순환을 새 파편에 자동 적용하지 않는다.
새 파편의 가호 선택·절망 진입과 장비의 연결은 [최신 파편](fragment.md) 및 [이전 세트 기록](review.md)을 대조해 후속 합의한다.

## 무기 — 눈물로 벼려낸 검

| 항목 | 값 |
| --- | --- |
| `range_role` | 근접 |
| `weapon_archetype` | `Sword` |
| `deployment_affinity` | 지상 전용 |
| `block_capacity` | `1` |
| `ground_defense_focus` | open design |
| `platform_rest` | 해당 없음 |
| `damage_type` | 물리 |
| `targeting_profile` | 저지 중인 적 우선, 없으면 사거리 내 단일 대상 |
| `air_capable` | 불가능 |
| `defense_tile_range` | 일반 `Sword`보다 조금 긴 근거리, exact open design |
| `interval_ms` | 빠름, exact open design |
| `windup_ms` | 짧음, exact open design |
| `delivery` | 레이피어의 즉시 단일 찌르기 |

무기의 외형과 공격 presentation은 빠른 찌르기를 사용하는 레이피어로 유지하지만 gameplay
archetype은 기존 `Sword`를 사용한다. 별도 `Rapier` archetype은 신설하지 않는다.

**무기 자체 효과 — 깊은 상처**

기본 공격이 적중하면 대상에게 무기 착용자별 `깊은 상처` 1스택을 부여하고 지속 시간을 갱신한다.
첫 prototype은 최대 `5`스택이며, 1스택마다 그 대상이 해당 착용자의 eligible 직접 피해를 `3%` 더
받아 최대 `15%`까지 증가한다.

- 무기 기본 공격과 착용자가 시전한 파편의 직접 피해에 적용한다.
- 다른 아군의 피해, 지속 피해, 반사, 환경 피해와 별도 장비 proc에는 적용하지 않는다.
- 스택은 공격에 소비되지 않고 대상이 사망하거나 지속 시간이 끝나면 사라진다.
- 여러 착용자의 깊은 상처는 source별로 분리하며 각 착용자는 자신의 modifier만 읽는다.

따라서 무기는 다른 파편과 조합해도 같은 적을 연속으로 찌른 뒤 직접 피해를 집중하는 단일 딜러로
완결된다. 전용 조합에서는 깊은 상처를 먼저 쌓고 일반 또는 절망의 검을 발사한다.

<a id="frag-방어구--별자리의-수의-가칭"></a>
## 방어구 — 별자리의 수의 (가칭)

> 상태: 보호 대상 피해 이전 구조 합의 / 기본 방어 수치·세부 판정 미정

**방어구 자체 효과 — 가호**

전투 시작 시 착용자가 아닌 eligible 아군 직원 한 명을 보호 대상으로 지정한다. 절망의 기사 파편과
함께 장착했다면 별도 대상을 고르지 않고 파편과 동일한 선택을 공유한다.

- 보호 대상이 받을 최종 실제 HP 피해의 `20%`를 착용자에게 이전한다.
- 예를 들어 원래 최종 피해가 `100`이면 보호 대상은 `80`, 착용자는 이전 피해 `20`을 받는다.
- 이전량은 원래 대상의 방어 계산 뒤 확정하며 착용자의 방어력으로 두 번째 감쇄를 하지 않는다.
- 이전 피해는 다른 피해 공유·이전 효과의 새 source가 되지 않는다.
- 착용자가 전투불능이 되거나 보호 대상의 death finalization이 확정되면 가호를 종료한다.
- 파편 없이도 방어구만으로 보호 대상을 선택하고 효과를 완결할 수 있다.

착용자의 무적·피해 차단, 한 공격당 이전 상한, 이전 피해의 공명·피격 trigger와 두 가호가 서로를
지정하는 순환 validation은 open design이다. 전용 액세서리는 이 이전 피해를 eligible 피격으로 읽는다.

<a id="frag-액세서리--검은-눈물-가칭"></a>
## 액세서리 — 검은 눈물 (가칭)

> 상태: 피격 스택과 자기 관통 최대 스택 구조 합의 / 수치·세부 판정 미정

착용자가 한 공격 action으로 실제 HP 피해를 받으면 `검은 눈물` 1스택을 얻고 전체 지속 시간을
갱신한다. 한 action의 다단 피해는 여러 스택을 만들지 않는다.

| 항목 | 첫 prototype |
| --- | --- |
| 최대 스택 | `3` |
| 스택당 효과 | 공격 속도 `+7%` |
| 최대 효과 | 공격 속도 `+21%` |
| 지속 시간 | `5초` |

- `별자리의 수의`로 이전받은 실제 피해도 유효하다.
- 절망의 기사 파편의 마지막 절망의 검이 자신을 꿰뚫으면 현재 수량과 관계없이 즉시 최대 스택이 된다.
- 파편·방어구가 없어도 일반적인 적 피격으로 스택을 얻으므로 독립적으로 사용할 수 있다.
- 피해가 `0`으로 막힌 공격, HP 비용, 일반 최대 HP 변경과 환경 피해의 eligibility는 open design이다.
