> 상태: 실낙원의 네 형태·직접 선택·독립 장비 성격 유지. 2026-10-20 사도 형태를 창·낫·봉·호위로 통일.
> 형태별 기술·수치와 유물 호환, 사도 공격을 직원용 무기에 적용하는 세부는 후속. 현재 미구현.

## 무기 — 실낙원

실낙원은 창·낫·봉·호위 사도의 무기 형태로 변형하는 하나의 장비다.
일반 직원이 장착하면 플레이어가 직접 조종하며, 전투 중 원하는 형태를 선택한다.
파편으로 사도화된 직원의 조종 불가 규칙을 실낙원 단독 사용자에게 적용하지 않는다.

각 형태는 해당 사도의 공격·기술을 공유하는 설계 방향을 유지한다.
현재 참조할 사도 공격은 다음과 같으며, 독립 장비의 실제 사거리·범위·기술 구성·수치는 후속이다.

| 무기 형태 | 참조하는 사도의 공격·기술 |
| --- | --- |
| 창 | 일직선으로 적을 꿰뚫는 공격 |
| 낫 | 낫을 휘둘러 발사하는 검기 |
| 봉 | 적 머리 위로 떨어뜨리는 낙뢰 |
| 호위 | 근접 공격과 도발 |

사도의 지상 자율 이동·공중 이동·봉 호위 행동은 파편의 사도 AI다.
실낙원을 장착했다는 이유로 직원이 자동 비행하거나 봉을 따라 이동하게 하지 않는다.
봉 사도의 전장 전체 표적 범위를 독립 장비에 적용하는 구체 사거리·기술 계약도 후속 설계에서 정한다.

- 실낙원은 지상·플랫폼 모두에 배치할 수 있으며 네 형태 모두 현재 배치 타일에서 사용할 수 있다.
- 형태 전환은 현재 배치를 유지한다. 지상에서 봉 형태로 바꿔도 철수나 재배치를 요구하지 않는다.
- 형태 전환에는 전환 대기시간을 두며 정확한 시간은 미정이다. 형태를 바꿔도 이미 시작된 전용 기술의 재사용 대기시간을 초기화하지 않는다.
- 형태 전환 자체는 파편의 누적 사도화 진행도를 올리거나 사도화 타이머를 시작하지 않는다.
- 파편의 창→낫→봉→호위 고정 순서는 사도화 형태 배정 규칙이다. 실낙원의 수동 형태 선택 순서를 강제하지 않는다.
- 실낙원의 효과 태그·유물 호환은 별도 결정한다. 백야 파편·사도에 유물 연결이 없다는 합의를 독립 장비의 호환 금지로 확대하지 않는다.

## 실낙원 형태 선택 UI

- 실낙원을 장착한 일반 직원을 선택하면 직원 선택 패널의 무기 아이콘에 현재 형태를 표시한다.
- 무기 아이콘을 누르면 창·낫·봉·호위의 네 아이콘으로 구성된 형태 선택기가 펼쳐진다.
- 각 형태의 사거리·저지 수·전용 기술을 미리 보여주고, 전환 대기 중에는 남은 시간을 표시한다.
- 전환 성공 뒤 무기 아이콘·공격 범위·저지 수·전용 기술 표시를 함께 갱신한다.
- 기존 전투 Pause 상태에서도 형태를 선택하고 전환할 수 있다.
- 무기가 접히거나 펼쳐지고 해당 사도의 실루엣이 겹쳐 보이는 형태 전환 연출을 유지한다.

파편으로 사도화된 직원을 선택했을 때는 정보만 확인한다. 그 화면에는 위 형태 선택이나 다른 직접 명령을 제공하지 않는다.

## 남은 장비 설계

- 각 형태의 정확한 공격·기술·피해 타입·사거리·범위·저지 수·스탯과 전환 대기시간.
- 사도와 공유할 공격·기술을 일반 직원의 고정 배치·직접 조종에 적용하는 방법.
- 전용 기술의 수동/자동 발동 방식과 파편 스킬을 함께 사용하는 조작·표시.
- 최초 장착·전투 진입 시 기본 형태와 전투 사이 형태 선택 유지 여부.
- 공격·기술 시전 중 전환, Hard CC 등 상태 제한과 진행 중 동작의 처리.
- 형태별 타일 효과·무기 조건을 요구하는 파편의 호환과 실낙원의 효과 태그·유물 연결.
- 방어구·액세서리의 구체 효과. 조우의 보상 모티프를 유지하되 새 효과를 임의 확정하지 않는다.
