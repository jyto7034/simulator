## 현재 합의

- 직원은 치료 표식 순서대로 사도화하며 형태는 창→낫→봉→호위를 반복한다.
- 사도화는 직원 전장 개체를 제거하고 같은 자리에 사도를 소환하는 처리다. 기존 후퇴·제거와 소환 기능을
  재사용하며, 백야가 사용하는 사도의 정의·공격·자율 행동을 파편에서도 공유한다.
- 창은 지상 관통 공격, 낫은 공중 검기, 봉은 고정 위치의 전장 범위 낙뢰, 호위는 봉 주변 순회·도발·근접 공격을 수행한다.
- 사도는 직접 조종할 수 없고 정보만 확인할 수 있다.
- 사도화 직원·순서와 다음 사도화까지 남은 시간을 원정에 저장한다. 이후 전투에서 시전하면 기존 사도를 재현하고 남은 시간부터 진행한다.
- 발동한 전투에서는 시전자 상태와 무관하게 진행하며, 표식 직원 전원이 사도화되면 즉시 백야 재현현·전멸한다.
- 파편·사도에 효과 태그나 전용/범용 유물 연결을 두지 않는다. 사도화·원정 누적은 설명용 분류다.
- 실낙원 단독 사용자는 직접 조종·형태 선택을 유지하며 유물 호환은 별도로 정한다.

사도화 간격·전투 수치·복수 봉과 호위의 연결·사망/미배치 직원·능력치 계승 등의 미정은 각 상세 문서를 따른다.
이번 파편 합의가 적 백야 조우나 One Sin 문답을 변경하지 않는다.
