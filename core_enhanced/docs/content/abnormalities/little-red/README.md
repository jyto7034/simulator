### 미결정 사항

- 파편, 기본 스킬, 개화형, 무기, 방어구와 액세서리의 최종 이름
- 파편과 세 장비의 rarity, 획득 경로, 중복 소유와 강화 recipe
- 방어구의 기본 생존 stat, 숙적 피해 감소율·지속 시간과 source identity lifecycle
- 숙적을 만드는 첫 공격의 다단 피해, 지속 피해·반사·환경 피해와 무적·barrier 피격 판정
- 현상금 node의 생성 확률·최소/최대 제시 횟수, 지도 표시와 어려운 난이도 등급 판정
- 액세서리의 node 생성 효과를 활성화하는 장착·보유 시점과 장비 이전·해제 시 처리
- 늑대 현상금 표적의 능력치·행동·출현 시점, 막타 eligibility와 node 완료 transaction
- 수금의 소유권·저장 lifecycle, 공격력 단계 임계치·증가량과 최대 단계
