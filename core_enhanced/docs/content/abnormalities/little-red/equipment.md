## 무기 — 이름 미정

| 항목 | 값 |
| --- | --- |
| `range_role` | 원거리 / 바로 앞 타일에 적이 있으면 근거리 전환 |
| `weapon_archetype` | `Gun` |
| `deployment_affinity` | Platform 전용 |
| `block_capacity` | `0` |
| `damage_type` | 물리 |
| `targeting_profile` | 바로 앞 타일의 적 우선 / 그 외 원거리 mode exact open design |
| `air_capable` | 권총 가능 / 도끼 불가능 |
| `defense_tile_range` | 권총은 원거리, 도끼는 바로 앞 타일 |
| `interval_ms` | mode별 open design |
| `windup_ms` | mode별 open design |
| `delivery` | 권총 projectile / 바로 앞 타일 전체에 도끼 즉시 근접 타격 |

무기는 권총과 도끼를 함께 사용하는 Platform 원거리 딜러 무기다. 별도 archetype을 추가하지 않고
기존 `Gun` 안에서 적의 위치에 따라 공격 presentation과 타격 범위를 바꾼다.

- 바로 앞 타일에 eligible 지상 적이 없으면 권총으로 원거리 기본 공격을 한다.
- 바로 앞 타일에 eligible 지상 적이 하나 이상 있으면 권총 대신 도끼로 전환해 **그 타일 전체의
  eligible 지상 적을 한 번에 공격한다.** 착용자는 적을 저지하지 않으며 타일 점유도 바꾸지 않는다.
- 도끼 mode는 권총보다 높은 단일 적 기준 타격 피해를 가진다. 정확한 공격 주기까지 더 빠르게 할지는
  수치 설계에서 정한다.
- 공격 시작 시점에 권총/도끼 mode와 target을 확정한다. 이미 발사한 권총 projectile은 이후
  바로 앞 타일에 적이 들어와도 도끼 공격으로 바뀌지 않는다.

open design:

- 권총과 도끼의 공격력, 공격 주기, windup과 사거리
- 권총 projectile 속도와 바로 앞 타일 경계 판정
- 원거리 mode의 targeting profile과 현상금 표식 우선 여부
- 도끼 공격의 소환물·오브젝트 eligibility
- Platform Rest와 공격 mode 확정·취소의 상호작용
- 최종 이름

<a id="frag-방어구--붉은-흉터-가칭"></a>
## 방어구 — 붉은 흉터 (가칭)

> 상태: 단일 숙적 지정과 후속 피해 감소 구조 합의 / 기본 생존 수치·감소율·지속 시간·세부 판정 미정

적 하나와 오래 맞붙을수록 단단해지는 단일 대상 탱킹 방어구다.

- eligible 적이 착용자에게 실제 battle HP 피해를 처음 가하면 그 적을 착용자의 `숙적`(가칭)으로
  지정한다. 동시에 활성화되는 숙적은 하나다.
- 숙적을 만든 첫 피해에는 이 방어구의 피해 감소를 적용하지 않는다.
- 이후 착용자가 숙적에게 받는 최종 피해를 `N%` 감소시킨다.
- 숙적에게 실제 battle HP 피해를 다시 받을 때마다 지정 지속 시간을 갱신한다.
- 숙적이 사망·이탈·무효화되거나 일정 시간 동안 착용자를 공격하지 않아 지정이 끝나야 다른 적을 새
  숙적으로 지정할 수 있다. 다른 적의 피격만으로 현재 숙적을 즉시 교체하지 않는다.

방어구는 숙적에게 주는 피해를 높이지 않고, 별도의 스택도 만들지 않는다. 따라서 파고드는 천국
액세서리의 스택 증폭 판정과 관계없다. 여러 적이 피해를 나누어 가하는 전투와 첫 고화력 공격에는
약하지만, 같은 원거리 적이나 보스에게 반복 공격받는 상황에서는 후속 피해를 안정적으로 줄인다.

전용 무기와 함께 사용하면 바로 앞 타일에 접근한 적 무리를 도끼로 걷어내면서 숙적의 반복 공격을
버틴다. 그러나 효과는 권총·도끼 무기나 붉은 두건 파편을 요구하지 않으므로 다른 loadout에서도
독립적으로 사용할 수 있다. 방어구 자체의 기본 방어력·최대 HP 계열 stat, `N%`, 숙적 지속 시간과
exact lifecycle은 `open design`이다.

<a id="frag-액세서리--이름-미정"></a>
## 액세서리 — 이름 미정

> 상태: 어려운 일반 전투 node의 늑대 현상금·run-local 수금·임계치 공격력 증가 구조 합의 /
> 이름·수치·세부 판정 미정

이 액세서리는 전투마다 많은 적을 반복 처치해 스택을 파밍하는 장비가 아니라, 더 위험한 일반 전투
node를 선택할 이유를 만드는 run 경로 장비다.

**현상금 node 생성**

- 이 액세서리의 node 생성 효과가 활성화된 run에서는 일반 전투 node 일부가 무작위로
  `현상금 node`가 된다.
- 현상금 node는 현재 전투력을 기준으로 함께 생성된 후보 중 **어려운 난이도 등급**에만 나타난다.
- 현상금 여부는 node 진입 전에 지도에서 식별할 수 있다. 플레이어는 일반 경로와 더 위험한 현상금
  경로를 비교해 어느 쪽을 진행할지 선택한다.
- 현상금 node의 전투에는 일반 적 하나를 표적으로 바꾸거나 기존 적에게 표식만 붙이는 대신, 별도의
  **늑대 현상금 표적**이 출현한다. 늑대의 전투 능력, 행동, 출현 시점과 presentation은
  `open design`이다.

전투 중 `N초`마다 무작위 적에게 현상금을 새로 부여하는 방식은 사용하지 않는다. 한 node 안의 많은
wave를 이용해 수금을 빠르게 반복 획득하는 구조도 두지 않는다.

**수금과 node 완료**

- 액세서리 착용자가 늑대 현상금 표적에게 직접 막타를 가해 death finalization을 확정하면 해당
  node의 `수금 성공`을 기록한다.
- 다른 아군, 소환물, 환경 피해나 다른 source가 막타를 가져가면 수금에 실패한다. 전투 자체의 승리와
  일반 보상은 막지 않는다.
- 수금 스택은 늑대의 사망 순간 즉시 확정하지 않는다. 수금 성공을 기록한 뒤 해당 node를 승리로
  완료해야 run-local `수금` 1스택을 확정한다.
- Retreat, 패배와 완료되지 않은 attempt는 수금을 남기지 않는다. 같은 node와 늑대를 반복해
  수금하는 방식으로 이용할 수 없다.

**임계치 공격력 증가**

`수금`은 스택 하나마다 공격력 modifier를 더하지 않는다. authored 누적 임계치에 도달할 때마다
공격력 보너스가 다음 단계로 상승하고, 임계치 사이의 스택에서는 공격력이 변하지 않는다.

| 항목 | 값 |
| --- | --- |
| 수금 유지 범위 | 해당 run |
| 스택당 공격력 증가 | 없음 |
| 단계 상승 조건 | authored 수금 임계치 도달 |
| 단계별 공격력 증가량 | open design |
| 임계치와 최대 단계 | open design |

첫 prototype에서는 첫 현상금 성공으로 첫 공격력 단계를 열고 이후 단계의 요구 임계치를 점차 벌리는
방향을 우선 검토한다. 정확한 임계치 배열과 단계별 증가량은 한 run에 제시되는 현상금 node의 기대
횟수를 기준으로 정한다.

**파편과의 결합**

- 일반 node에서는 붉은 두건 파편이 기존 규칙대로 자체 현상금 표식을 생성한다.
- 현상금 node에서 파편과 액세서리를 함께 사용하면 늑대 현상금 표적을 파편도 자신의 활성 현상금
  대상으로 읽으며, 별도의 두 번째 현상금 표식을 만들지 않는다.
- 늑대가 사망하면 파편은 마지막 공격의 소유자와 관계없이 기존 규칙대로 창을 생성한다.
- 액세서리의 수금은 착용자가 직접 막타를 가하고 node를 승리로 완료한 경우에만 얻는다.

액세서리는 파편 없이도 현상금 node와 늑대 표적, 수금과 임계치 보너스를 모두 사용한다. 파편도
액세서리 없이 기존 전투 내 현상금 표식과 창 생성을 사용한다.
