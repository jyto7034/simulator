## 4 붉은 두건의 용병

**기존 방향:** 표식 대상의 사망은 처치자와 무관하게 조준창을 주고, 착용자의 다른 직접 처치는 확률로 창을 준다. 모은 창을 사용해 시간을 멈추고 조준한다. 개화형은 선불 계약으로 전환한다.

**조립안:** 표식·처치 이벤트 → 창 수 누적 → 사용 시 창 수와 발사 위치 고정 → 전투 정지와 조준 → 최종 확정 → 각 창의 공격 해결 → 정지 해제다. 창 수 상한 5와 추가 획득 확률 25%는 현재 초안 수치다. 발사 위치는 맵이 제공하는 앵커에서 정하며 직원의 실제 위치를 이동시키지 않는다.

기존 선택지는 창별 대상 조준과 한 타일 집중 사격이다. **단순화 추천은 첫 버전에서 한 타일 집중 사격만 사용하는 것**이다. 화면에는 여러 창을 유지하되 한 번의 위치 선택으로 각각 발사한다. 이는 기존 조작 선택지를 줄이는 변경 제안이다. 창별 조준을 유지한다면 고유 조준 세션이 필요하다.

개화형은 창·표식 대신 예산을 미리 지불하고 계약 대상에게 줄 피해를 관리한다. 대상 사망 후 남은 예산은 환불·이전하지 않고, 보스 페이즈를 넘는 초과 피해를 다음 페이즈에 이월하지 않는다. 예산 종류·지불량·계약 시간·공격 방식은 검토 후 정한다.

**기능 경계:** 누적 이벤트와 개별 발사는 공통. 정지·조준 세션과 개화형 계약 예산은 고유 기능 후보다. 이중 권총·도끼의 거리별 무기 동작, 숙적, 현상금의 원정 성장은 별도 장비·원정 기능이다.

**검토:** 집중 사격만 남길지, 창별 조준도 유지할지가 우선이다. 추천은 최종 확정 전 취소 시 창과 공명 유지, 확정 후 창별 별도 타격과 결정된 처리 순서 유지다. 정지 중에는 전투 시계·지속 효과가 진행되지 않아야 한다.

**태그와 유물 적용**

| 효과 단위               | 태그 후보       | 변경 후보 속성과 지켜야 할 경계                                               |
| ----------------------- | --------------- | ----------------------------------------------------------------------------- |
| 표식 처치와 조준창 저장 | `스택`          | 창 상한·획득 확률. 표식 대상 사망과 다른 직접 처치를 구별                     |
| 각 창에서 나가는 사격   | `피해·관통`     | 사격 계수·관통 조건. 실제 탄환 전달이면 `투사체` 추가                         |
| 여러 창의 발사 순서     | `다중타격` 후보 | 개별 직접 타격 순서로 확정할 때 적용. 동시에 보이는 창 수만으로 판정하지 않음 |
| 개화형 선불 계약        | 고유 계약 동작  | 예산·기간·대상당 한도. 일반 `스택`만으로 지불·환불 규칙을 바꾸지 않음         |

**유물 연결:** 기본형 사격이 직접 다중타격으로 작성되면 **깊은 쐐기** 연결을 검토한다. 사격 위력·관통 강화는 새 범용 후보, 창 획득·계약 예산 변경은 전용 후보다. 조준 정지는 효과의 유한한 유지 시간이 아니라 입력 준비 단계이므로 **긴 호흡**을 적용하지 않는다.

## 이어서 검토 — 2026-10-19

> 후속 기본형 합의로 대체된 검토 기록. 현재 적용안은 [파편 본문](fragment.md#current-2026-10-19)을 따른다.

> 상태: 음양 다음, 기존 파편별 조립안의 4번 순서로 검토 재개. 아래 추천은 아직 사용자 합의가 아니다.
> 현행 기본형·개화형은 [파편 본문](fragment.md)을 따른다. 기존 집중사격만 남기는 단순화 제안도
> 이전 제안으로 보존하되, 이번 추천은 창별 탄도 설계라는 현재 재미를 유지하는 쪽이다.

**현재 동작**

현상금 대상 사망은 막타와 관계없이 창을 확정 생성한다. 그 외 착용자의 직접 처치는 25% 확률로
창을 만들고 일반 상한은 5개다. 맵의 사격 원점에서 전투 시간을 멈추고 창별 방향을 정하는 지정사격,
한 지점을 선택하는 집중사격 중 하나로 관통 궤적을 확정한다. 교차한 궤적은 같은 적에게 각각 적중한다.
개화형은 이 창·표식 동작 대신 선불 계약으로 적 하나에게 정해진 피해량을 집행한다.

**이번 추천과 우선 선택**

1. **지정사격과 집중사격을 모두 유지한다.** 한 적을 노릴 때는 한 번에, 여러 경로를 나눠 막을 때는
   창별로 조준한다. 집중사격은 선택 가능한 편의 기능이며 창별 조준을 없애는 대체안으로 만들지 않는다.
2. **창 0개 사용성은 별도로 정한다.** 추천 후보는 직원의 현재 위치에서 약한 관통 사격 1회를 허용하는
   것이다. 적이 없는 맵 앵커를 임의 생성하는 방식과 구분한다. 보스 단독전에서 창을 얻지 못한 경우의
   공백을 줄일 수 있으나 원문 미정 항목의 신규 제안이므로 아직 본문에 적용하지 않는다.
3. **발사 순서와 유물 자격을 분리한다.** 현재는 여러 궤적을 같은 해결 단계에서 쏜다. 화면에 여러 발이
   보인다는 이유만으로 다중타격을 확정하지 않는다. 피해·관통은 유지하고, 깊은 쐐기는 구분된 타격 단계와
   처리 순서를 선택한 다음 연결한다. 창을 반드시 시간차 발사하도록 변경하는 것도 별도 선택이다.
4. **개화형은 자원부터 정한다.** 전투 전술 자원과 원정 보유 자원 중 무엇을 선불할지에 따라 조작·손실의
   의미가 달라진다. 자원 종류를 고르기 전에 환율·피해 상한을 임의로 고정하지 않는다. 미집행량의
   환불·다른 적 이전 없음과 페이즈 초과분 미이월은 현재 방향을 유지한다.

| --- | --- | --- |
| 현상금 처치와 창 저장 | 스택; 스택획득·스택한도해제 후보 | 획득 사건에만 적용. 창 개수와 실제 맵의 빈 사격 원점 수는 별개 |

## 리워크 제안 — 사냥감을 정하고, 사냥을 이어가기 (2026-10-19)

> 미채택 이전 제안. 표적 지정·공격 누적·일부 창 소비·공명 환급·순차 발사·개화 추격을 현재 기본형에 적용하지 않는다.

> 상태: 사용자의 리워크 요청에 따른 **검토 제안**. 아래는 현행 파편을 대체할 후보이며 아직 합의·구현된
> 동작이 아니다. 앞 절의 소규모 보완안과 구분한다. 현재 설계는 [파편 본문](fragment.md)에 유지한다.

**설계 판단:** 기존안은 창을 얻기 위해 처치와 확률을 기다리고, 준비한 창을 한꺼번에 사용하는 비중이
크다. 사격 원점을 활용하는 재미를 살리면서 표적 선정·자원 확보·소비량·사살 뒤의 다음 행동을
플레이어가 조절하도록 바꾼다. 기본형은 여러 사격 경로를 설계하는 **포위 사격**, 개화형은 같은 준비를
한 적의 추격과 마무리에 투자하는 **끝까지 사냥**으로 제안한다. 이름과 아래 수치는 가칭·시작값이다.

### 두 형태의 공통 준비 — 현상금 사냥

- 살아 있는 적 하나를 현상금 표적으로 지정한다. 동시에 하나만 유지한다. 별도로 지정하지 않았다면
  착용자가 처음 기본 공격을 시작한 적을 최초 표적으로 삼는 편의안을 쓴다.
- 플레이어는 표적을 바꿀 수 있다. 변경에는 3초 재사용 대기시간을 두고, 진행 중인 창 획득 카운터는
  초기화하되 이미 저장한 창은 유지한다. 표식이 공격 사거리·적의 피격 자격을 무시하게 만들지는 않는다.
- 착용자의 기본 공격이 현상금 대상에게 실제 피해를 준 **행동 2회마다 창 1개**를 얻는다. 한 행동의
  여러 탄환·피해 구간은 한 번만 센다. 파편 사격·도끼 마무리·유물 추가 피해·반사·다른 직원의 피해는
  이 획득 카운터를 올리지 않는다. 카운터는 화면에서 다음 창까지 0/2, 1/2로만 표시한다.
- 현상금 대상이 사망하면 마지막 공격의 소유자와 관계없이 **창 2개**를 얻는다. 같은 사망에서 표적
  사망 보상을 한 번만 처리하고, 다음 표적은 이후 입력 또는 다음 기본 공격에서 선정한다.
- 일반 처치 25% 창 생성은 이 후보에서는 위의 표적 공격·사망 두 경로로 대체한다. 첫 시전 준비용으로
  전투당 최초 배치 시 창 1개를 지급하며, 재배치로 다시 지급하지 않는다.
- 일반 저장 상한은 5개다. 상한 초과분과 상한에서 발생한 공격 카운터의 초과 적립은 버리는 시작안이다.
  창은 전투 종료 시 사라지며, 철수 시 보존 여부는 기존 배치 수명 규칙과 함께 후속 결정한다.
- 기본형과 개화형 모두 이 준비를 사용한다. 개화형에서 창·표식 생성을 하지 않던 구안과 다른 제안이다.
  맵의 사격 원점 수용량은 그대로 필요하며, 유효한 빈 원점 없이 임의 좌표에 창을 만들지 않는다.
  첫 비교 맵은 정상 저장 상한 5개를 모두 수용하도록 준비한다.

### 기본형 후보 — 포위 사격

공명 만충에서 조준에 들어가면 전투 시간을 잠시 멈춘다. **저장한 창 중 이번에 쓸 창을 1~5개 선택**하고,
선택하지 않은 창은 남긴다. 창 선택 순서를 무작위로 강제하지 않고, 선택한 순서를 발사 순서로 사용한다.

- **지정사격:** 선택한 창마다 방향을 지정한다. 경로를 서로 다른 적 무리에 나누거나 현상금 표적에게
  교차시킨다. 붉은 두건 형상은 창의 위치에서 조준하지만 직원의 실제 배치·저지는 바뀌지 않는다.
- **집중사격:** 타일 하나를 고르면 선택한 모든 창에서 그 지점을 향한 궤적을 잡는다. 짧은 조작으로
  한 적 또는 한 지점을 집중 공격하는 선택지다. 두 모드는 같은 사격 효과를 사용한다.
- 최종 확정 전에는 창·공명을 소비하지 않는다. 확정 시 선택한 창과 공명을 소비하고 전투 정지를
  해제한 뒤 선택 순서대로 **0.15초 간격**의 별도 직접 사격을 실행한다. 조준 정지는 발사 중까지
  유지하지 않는다. 따라서 실제 발사 시점의 적 위치·무적·장애물 판정이 적용된다.
- 한 창의 시작 피해량은 무기 공격력의 **180% Physical**, 선형 관통 폭은 **0.75타일**을 제안한다.
  길이·장애물·공중 대상은 현재 맵·사격 정의에서 별도로 결정한다. 계수는 타격 순간 새로 바뀌지 않도록
  최종 확정 시 공격력을 고정하는 비교안을 쓴다.
- 한 발은 한 적에게 최대 한 번 적중하며, 서로 다른 창의 궤적이 같은 적을 지나면 각각 적중한다.
  5개를 쓰면 최대 0.6초에 걸쳐 5발이 나간다. 여러 적에게 맞히는 한 발을 여러 타격 단계로 세지 않는다.
- 이번 시전의 직접 사격이 현상금 대상의 사망을 확정하면 **최대 공명의 25%를 한 번 회복**한다.
  이때 창 2개는 공통 현상금 사망 보상 한 번만 받는다. 다른 아군이 죽이면 창은 받지만 이 공명 보상은 없다.
- 창 0개에서는 시전을 시작하지 않고 공명을 보존한다. 별도의 약한 임시 사격 대신 최초 창 1개와
  생존 표적에 대한 공격 누적으로 첫 사용과 보스 단독전의 자원 공급을 해결하는 안이다.

**선택의 의미:** 지금 창 1~2개로 위험한 적을 마무리하고 사냥 보상을 받을지, 5개를 모아 여러 경로를
동시에 정리할지 결정한다. 분산 사격으로 잡몹 무리를 처리할 수 있고 교차 사격으로 강적에게 집중할
수 있다. 표적 사살이 다음 창과 공명을 준비하지만 즉시 자동 재시전은 발생하지 않는다.

### 개화형 후보 — 끝까지 사냥

같은 현상금·창 획득 규칙을 사용하되, 공명 만충에서 현상금 표적 하나를 선택하여 **보유한 창 전부**를
소비한다. 현재 제안에서는 별도 원정 자원을 선불하는 구안 대신 이미 준비한 창을 사냥의 대가로 쓴다.
이 자원 변경은 리워크 후보의 차이이며, 현행 선불 계약을 이미 폐기했다는 뜻은 아니다.

1. 창의 수만큼 표적을 겨냥해 짧게 연속 사격한다. 시작값은 0.25초 간격, 한 발마다 공격력 100% Physical.
2. 마지막 사격 0.4초 뒤 붉은 두건의 형상이 표적 곁에 나타나 도끼로 마무리한다. 마무리 시작값은
   `공격력 × (200% + 소비한 창 수 × 100%)`다. 예를 들어 창 3개는 사격 300% + 도끼 500%다.
3. 사격과 도끼는 모두 그 표적 한 명에게만 적용한다. 관통·광역은 사용하지 않는다. 시전 시 지정
   사거리는 4타일을 제안하고, 이후 같은 전장에 유효하게 남아 있는 그 표적을 추적한다.
4. 두건의 이동·도끼는 효과 연출이며 직원 본체의 배치·저지 위치를 바꾸지 않는다. HP·저지·기본 행동이
   있는 별도 소환 유닛을 만들지 않는다. 원래 시전 중 행동 제한은 유지한다.
5. 표적이 먼저 사망·이탈하거나 보스 페이즈가 바뀌면 남은 사격·도끼는 종료한다. 다른 적에게 자동으로
   넘기지 않고, 미사용 창을 환불하지 않는다. 무적일 때의 타격은 기존 피해 자격대로 무효가 될 수 있다.
6. 이번 시전의 직접 피해로 현상금 표적을 사살하면 기본형과 같은 창 2개와 공명 25% 보상을 한 번 받는다.
   아군이 먼저 사살했다면 공통 창 보상만 받는다. 조준 취소 등 최종 확정 전에는 비용을 소비하지 않는다.

기본형은 위치와 여러 궤적을 조절하는 범위 대응, 개화형은 모아 둔 창을 단일 표적에 강하게 투자하는
추격·마무리 역할이다. 사격 중 표적이 죽으면 불필요한 도끼를 발생시키지 않으며, 무조건 즉사나
최대 HP 비례 피해를 새로 추가하지 않는다. 숫자는 이 역할 차이를 비교하기 위한 초안이다.

### 효과별 태그·유물 검토

| 효과 | 이 리워크 후보의 태그 | 유물 연결 후보와 경계 |
| --- | --- | --- |
| 창의 저장·획득 | 스택 | 스택획득은 창을 얻는 사건에 적용. 기본 공격 2회 카운터와 이중 곱하지 않음 |
| 창 상한 | 스택한도해제 후보 | 창의 수치 상한과 맵에 실제 제공된 사격 원점의 수용량은 별개 |
| 기본형 사격 | 피해·관통·다중타격 | 별도 0.15초 타격 단계를 채택한 경우 깊은 쐐기 연결. 같은 시전·대상의 적격 타격만 누적 |
| 기본형 궤적 폭 | 범위증폭 후보 | 폭의 확장부터 검토. 사격 길이와 지정 사거리를 동시에 늘리지 않음 |
| 개화형 사격·도끼 | 피해·다중타격 | 사격과 마지막 도끼를 같은 시전의 직접 타격으로 기록. 기본형 관통을 자동 상속하지 않음 |
| 조준·발사·추격 | 무아지경 후보 | 진행 중인 시전 보호 범위 검토. 사망·퇴각·목표 무효 등 고유 종료는 유지 |
| 공명 보상 | 표적 직접 처치 사건 | 스택획득·회복·버프효율증가만으로 공명 보상을 증폭하지 않음 |

그림이 여러 창·두건 형상을 쓴다는 이유만으로 소환물 태그를 확정하지 않는다. 조준 시간·사격 간격에
긴 호흡을 연결하지 않으며, 공격이어가기는 개화형의 표적 고정과 충돌하므로 별도 유물 변형을 선택할 때
다시 검토한다. 현행 위키의 확정 태그에는 위 후보를 아직 추가하지 않는다.

### 남는 연결과 검증 항목

- 기존 권총·도끼 무기와 단일 숙적 방어구는 독립 효과를 유지한다. 무기의 기본 공격은 공통 획득
  카운터를 올릴 수 있지만, 파편의 도끼 마무리는 무기 기본 공격으로 재분류하지 않는다.
- 늑대 현상금 노드 액세서리를 함께 쓰면 그 노드의 늑대가 활성 현상금 표적을 맡는 기존 연결을
  우선한다. 그동안 임의 표적 변경은 제한하는 후보로 둔다. 파편의 표적 사망 보상과 액세서리의
  직접 막타·노드 승리 후 수금은 다른 사건이며, 한쪽 조건으로 다른 보상을 대신 지급하지 않는다.
- 전투 재배치로 최초 창을 반복 획득하지 않는지, 다른 아군의 처치로 공명을 받지 않는지, 마지막
  사격과 도끼가 같은 사망을 두 번 집계하지 않는지 확인한다. 파편이 생성한 피해로 창 획득 카운터를
  다시 채우는 순환은 만들지 않는다. 표적 사망의 일회 보상은 위 규칙대로 남긴다.
- 빠른 연사 무기와 느린 도끼의 창 획득 속도, 웨이브/단일 보스에서의 공명 수급, 한두 창 조기 사용과
  5창 집중 사용, 이동·제어 면역 보스와의 실제 적중률을 비교해야 한다.
- 남은 세부: 기본 공격의 보호막 피해 인정 여부, 조준 연결 해제 복구, 창의 배치 수명, 표적 변경
  우선순위, 사격 관통 길이·장애물·대공·투사체 전달, 두 형태의 최종 이름·계수·호환.

**우선 의견을 받을 부분:** 표적을 직접 고르고 공격 누적으로 창을 얻는 공통 준비, 필요한 창만 쓰는
기본형, 모든 창을 투자해 사격 뒤 도끼로 마무리하는 개화형이라는 두 역할의 대비가 원하는 두건에
맞는지 확인한다. 수치와 개별 유물은 이 방향을 고른 뒤 조정한다.

## 파편 — 이름 미정

역할은 **처치로 사격 거점을 쌓고 플레이어가 여러 탄도를 설계하는 딜 파편**이다. 단순 피해 증가가
아니라, 전장에 남은 창의 위치를 사격 원점으로 바꾸는 것이 핵심 문법이다.

**현상금 표식과 창 생성**

- 전투 중 유효한 적 하나에 무작위로 현상금 표식을 부여한다. 동시에 활성화되는 현상금 표식은
  하나다.
- 현상금 표식 대상이 사망하면 마지막 공격의 소유자와 관계없이 창을 `100%` 생성한다.
- 그 외 적을 파편 착용자가 직접 처치하면 `25%` 확률로 창을 생성한다.
- 일반 활성 창 상한은 `5`개다. 맵 RON은 현상금 표식 대상의 사망으로 생성되는 창이 이 상한을
  무시할 수 있는지 명시한다.
- 같은 피해·사망 처리 안에서 다음 적에게 표식을 즉시 넘겨 연쇄 확정 생성을 만들지 않는다. 다음
  표식의 재선정 시점과 지연은 RON이 명시하며, 후보가 없으면 다음 유효 적이 출현할 때까지 기다린다.
- 보상·Wave authority가 없는 임시 소환물, non-kill despawn과 다른 특수 lifecycle을 표식 및 일반
  처치 후보에 포함할지는 authored eligibility가 명시한다.

창의 생성 위치와 수용량은 battlefield/map RON이 작성한다. 각 맵은 창 생성 anchor와 선택 정책을
명시하며, 일반 창은 기본 상한과 남은 anchor를 모두 만족할 때만 생성한다. 상한 무시 현상금 창도
맵에 남은 유효 anchor가 있을 때만 생성한다. 스킬 사용으로 창이 소비되면 해당 anchor는 다시 사용할
수 있다. 임의 좌표 fallback은 두지 않는다.

**스킬 시전**

스킬을 시전하면 server가 전투 시간을 정지하는 scripted freeze를 시작하고 플레이어는
`지정사격`과 `집중사격` 중 하나를 고른다.

`지정사격`:

1. 아직 사용하지 않은 창 하나를 고른다. 창 선택 순서는 무작위다.
2. 붉은 두건의 형상이 해당 창으로 순간이동해 저격 자세를 취한다. 이는 presentation과 skill delivery의
   사격 원점이며, 직원 runtime의 실제 배치·점유·저지 위치를 옮기지 않는다.
3. Unity가 현재 창에서 시작하는 총알 궤적 preview를 표시하고 플레이어가 마우스로 방향을 조절한다.
4. 클릭하면 해당 궤적을 확정하고 다음 창으로 넘어간다.
5. 사용할 창이 남아 있는 동안 같은 과정을 반복한다.

`집중사격`:

1. 플레이어가 battlefield의 유효 타일 하나를 고른다.
2. 모든 창에서 선택 타일까지 향하는 궤적을 한 번에 확정한다.

두 mode의 피해 규칙은 같고 조작 방식만 다르다. 모든 궤적을 확정하면 창을 소비하고, 기록한 각
궤적을 따라 폭발적인 관통 사격을 같은 resolution에서 실행한 뒤 scripted freeze를 종료한다. 여러
궤적이 같은 적을 지나면 해당 적은 각 궤적의 공격을 각각 받으므로, 플레이어는 넓게 분산해 Wave를
정리하거나 한 지점에 교차시켜 강적에게 집중할 수 있다.

open design:

- 파편과 스킬 이름, `rarity`, `equip_limit`과 정확한 compatibility
- 창이 0개일 때 기본 사격을 허용할지와 그 사격 원점
- 맵별 anchor 수·위치·선정 방식과 현상금 창의 일반 상한 무시 여부
- 다음 현상금 표식의 재선정 지연, 후보 filter와 deterministic random 순서
- 궤적의 폭·길이·관통·장애물·공중 유닛 판정과 궤적별 피해량
- scripted freeze의 cancel, disconnect, checkpoint/resync와 허용 command 계약
- 사용한 창의 정확한 소비 시점과 발사 presentation

## 파편 개화형 — 선불 계약 (가칭)

> 상태: 핵심 문법 합의 / 지불 자원·수치·세부 판정 미정

개화형은 창과 탄도를 사용하는 기본형 대신, 붉은 두건의 직업적 용병 계약을 직접 사용한다.
Maintenance에서 개화 전 형태와 개화형 중 하나를 선택하며, 개화형을 선택한 전투에서는 소비자가 없는
창과 현상금 표식 생성 runtime을 만들지 않는다.

플레이어는 자원을 선불하고 적 하나를 수동 지정한다. 붉은 두건의 형상은 계약된 피해량을 해당
대상에게 가하며, 대상이 살아 있어도 계약 피해를 모두 가하면 사냥을 종료한다.

```text
계약 피해량 = 기본 보장 피해 + 선불 금액 × authored 변환 계수
```

기본 보장 피해는 자원을 추가로 투자하지 않아도 엘리트급 스킬의 기본값을 제공한다. 선불 금액이
커질수록 단일 대상 고점이 올라가지만, 최대 선불 금액과 계약 피해의 절대 상한은 RON이 직접 작성한다.

- 유효한 대상과 지불 가능 금액을 모두 검증한 뒤 자원을 원자적으로 소비한다.
- 대상이 먼저 사망·이탈·무효화돼도 남은 계약량을 다른 적에게 넘기거나 선불 자원을 환불하지 않는다.
- Boss phase 관문을 넘는 초과 피해는 다음 phase로 이월하지 않는다.
- 취소와 유효하지 않은 대상 지정은 자원, 공명과 전투 상태를 바꾸지 않는다.

open design:

- 선불에 사용할 자원. 전투 중 전술 포인트 또는 전투 전에 저장하는 run 자원 중에서 결정
- 지불 단위, 기본 보장 피해, 변환 계수와 최대 계약 피해
- 계약 사격의 시간, 타수, 피해 type과 phase 관문 도달 시 종료 처리
- 개화형 이름과 presentation

## 후속 논의에서 채택하지 않은 제안

- 강화탄 추가 적중당 속박 0.5초 연장·최대 4초: 최신 합의는 강화탄 2초 속박이며 재부여 규칙은 미정이다.
- 관통상 최대 5스택·6초 유지와 피해 후 스택 부여: 초기 추천값이며 개별 유물 문서에서 미정으로 구분한다.
- 개화형 사냥터: 창 8초 유지·창당 2발·1.5초 간격·기본형 대비 70% 피해의 자동 사격 제안. 사용자가 개화형 검토를 보류했으므로 채택하지 않는다.
- 스택한도해제·범위증폭·긴 호흡 등의 추가 연결: 이번에 선택한 범용 연결은 슬러그탄의 기절→깨진 균형, 강화 창 스택획득, 관통상 스택부여 세 가지다.
