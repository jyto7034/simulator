## 보상 방향:

- 검은·흰 펜던트, 잉어, 태극과 분리·균형을 소재로 삼는다.
- exact 파편·장비 계약은 `abnormality_skill_fragments_design_notes.md`의 `음/양` 절이 소유한다.
- 음과 양은 하나의 환상체와 하나의 파편으로 취급한다.
- 파편 `음양의 순환`(가칭)은 플레이어가 지정한 위치에 일정 시간 유지되는 광역 회복 장판을 만든다.
- 전용 `Staff`는 적을 공격하지 않고 적의 존재·명중·피해량과 무관하게 아군을 기본 치료하는 순수 힐
  무기다. 한 행동의 대상 수와 선정 방식은 open design이다.
- 방어구 `태극`(가칭)은 착용자 HP가 `50%`를 초과하면 방어력을 높이고, `50%` 이하면 착용자가 다른
  아군에게 주는 회복량을 높인다.
- 액세서리 `검은·흰 펜던트`(가칭)는 기본 회복 행동으로 다른 아군을 실제로 회복하면 그 회복량 일부를
  기준으로 착용자 자신도 action당 한 번 회복한다.
- 실패 현상인 용은 기본 파편이나 장비가 자유롭게 소환하지 않는다. 파생 4종 보유와 공통 침식 조건을
  만족한 formal 침식형에서만 적 처형 연출로 사용한다.

## 스킬 파편 능력:

- 역할은 `힐`이다. 공명 만충에서 유효한 전장 타일 하나를 지정해 같은 위치에 지속 광역 회복 장판을
  생성한다.
- 장판이 유지되는 동안 범위 안의 모든 eligible 아군을 계속 회복한다. 적의 존재·피해·처치와 아군
  HP 희생은 생성·회복 조건이 아니다.
- 장판에서 검은색과 흰색 파동이 번갈아 퍼지지만 두 파동은 별개의 효과가 아니라 지속 회복을 보여
  주는 presentation이다.
- 침식형에서는 조우의 용이 전장을 가로지르며 적을 처형한다. 판정과 대상 범위는 침식형 공통 정책을
  따르며 기본 회복 장판에 용 소환을 섞지 않는다.

### 전용 유물 — 숨겨진 용 출현·이름 미정

> 상태: 2026-10-18 사용자 합의. 직접 경험하기 전까지 정체와 효과를 모르는 이스터에그.

- 음양 전용 유물을 장착하고 한 시전의 음·양 **중심 타일을 동일하게 지정**하면 해당 영역에
  용이 한 번 출현한다. 일부 교집합이나 다른 시전의 영역 중첩만으로는 발동하지 않는다.
- 영역 안 **아군과 침식체는 즉사**한다. 시전자도 영역 안에 있으면 아군 판정을 따른다.
- 영역 안 **환상체 및 보스는 최대 HP의 25% 피해**를 받는다. 해당 분류는 침식체 즉사보다 우선한다.
- 용의 일회 출현·판정 뒤 후속 효과 없이 스킬을 종료한다. 지속 장판·회복·순환 회복·교집합 버프를 남기지 않는다.
- 플레이어에게 발동 전 유물의 정체·효과·조건을 설명하거나 경고하지 않는다. 같은 중심을 고를 때
  위험 범위로 바뀌는 조준 표시·피격 아군 강조·별도 확인창도 추가하지 않는다.
- 조건이 충족되지 않으면 기존 회복·지원 파편으로 작동한다. 전용 유물 없는 같은 중심 시전은
  기존 교집합의 회복·버프를 따르며 용을 소환하지 않는다.

이 전용 유물은 아래 에고 침식과 별도 효과다. 이름·등급·획득처·발견 후 공개 방식,
범위·판정 시점·중단, 감면·보호막·무적·생존 보장·보스 페이즈·처치 연쇄 판정은 미정이다.
상세 합의와 분해 검토는 [음양 전용 이스터에그 유물](../../relics/yin-yang-dragon.md#rel-%EC%9D%8C%EC%96%91-%EC%A0%84%EC%9A%A9-%EC%9D%B4%EC%8A%A4%ED%84%B0%EC%97%90%EA%B7%B8-%EC%9C%A0%EB%AC%BC--%EC%9D%B4%EB%A6%84-%EB%AF%B8%EC%A0%95)을 따른다.

## 3 음양

**상태: 2026-10-18 사용자 합의 — 음·양의 회복·순환 회복·교집합 버프, 전용 이스터에그 유물과 5개 태그 연결을 반영했다.** 회복량·버프 종류·세부 판정은 미정이다.

**합의한 핵심:** 음과 양을 별개 파편으로 나누지 않고 하나의 파편으로 다룬다. 두 위치를 지정해 한쪽에는 **음의 영역**, 다른 쪽에는 **양의 영역**을 만들고 지속 시간 동안 두 구역의 아군을 회복한다. 기존 단일 위치 회복 장판을 이 구조로 대체한다. 전용 유물의 용 전환이 없는 기본 동작은 적 피해나 아군 HP 희생을 요구하지 않는 회복·지원 역할을 유지한다.

**영역별 효과 — 후속 합의:** 음 또는 양만 존재하는 독립 영역에서는 아군을 회복한다. 음과 양이 겹치는 교집합에서는 아군을 회복하고 이로운 버프를 부여한다. 교집합의 회복량 증가·양쪽 회복 중복 적용 여부는 확정하지 않는다. 버프 종류·수치·지속·재부여·영역 이탈 시 처리는 미정이며, 앞서 제안한 피해 감소·공격 속도 증가와 `조화` 명칭은 확정 사항이 아니다. 이 버프는 파편 자체의 교집합 효과이며 회복 후 버프를 주는 유물과 구분한다.

**순환 회복 — 후속 합의:** 음과 양의 기본 회복 성질은 같게 둔다. 각 회복 주기에 두 영역이 먼저 각자 아군을 회복하고, 아군 HP가 가득 차 쓰이지 않은 회복량 일부를 반대 영역의 부상 아군에게 추가 회복으로 전달한다. 전달하는 쪽에도 아군이 있어야 하며, 아군이 없는 빈 영역에서 전달 회복량을 만들지 않는다. 전달된 추가 회복의 초과분은 다시 반대편으로 보내지 않는다. 전달 비율·여러 아군의 초과 회복 집계·수혜자 배분은 미정이다.

**조립 검토안:** 두 타일 지정 → 음·양 회복 영역 생성 → 정해진 주기마다 각 영역의 현재 아군 조회 → 회복·순환 회복, 교집합의 아군에게 이로운 버프 제공이다. 버프의 부여 시점은 회복 주기와 동일하다고 확정하지 않는다. 범위 밖으로 나간 아군에게 별도 지속 회복을 남기지 않는 기존 방향을 유지한다. 두 위치를 고르는 순서와 시전 확정·영역 생성 시점은 미정이며, 장판 생성 후 시전자 스킬 사용을 끝내는 독립 설치 방식은 제안 상태다.

**상태와 표현:** 두 영역의 위치·수명·회복 주기를 구분한다. 이전의 단일 장판 흑백 파동 교대 설명 대신 음의 영역과 양의 영역을 공간적으로 구분한다. 이름과 색의 차이만으로 서로 다른 버프·피해·회복 계수를 확정하지 않는다. 순수 회복 무기, HP 구간에 따른 방어구 보정 교체, 기본 회복 행동당 한 번의 액세서리 자기 회복은 별도로 유지한다.

**기능 경계:** 공통 고정 장판과 주기 회복으로 구성한다. 개화형은 별도 상세 설계가 없어 추가하지 않는다.

**미정:** 영역별 범위·회복량·주기·지속 시간, 두 위치 사이의 거리, 교집합의 회복량·중복 회복과 순환 회복의 관계, 버프 종류·수치·부여 및 종료 조건, 순환 회복의 전달 비율·집계·배분, 생성 즉시 첫 회복 여부, 재시전 교체·여러 사본 중첩, 시전자 이탈 시 존속. 독립 설치·즉시 첫 회복·재시전 교체는 계속 제안 상태다. 다른 시전·파편 사본 사이의 겹침은 별도 미정이다.

| `회복한 아군에게 버프 부여` | 실제로 회복한 아군에게 유물의 추가 버프 제공. 교집합 밖에서도 회복받으면 적용 가능 | 버프 종류·수치·지속·재부여·중첩, 회복 0·초과 회복·자기 회복·순환 회복의 발동 인정 |
| `범위 증폭` | 음·양 영역을 각각 확대하고 확대된 두 영역으로 교집합을 판정 | 공통 `범위증폭`과 연결. 모양별 확장 판정과 다른 범위 유물과의 합성 |
| `지속시간` | `긴 호흡`으로 음·양 장판 각각의 유지 시간 25% 증가 | 교집합 버프의 독립된 수명 여부는 미정. 장판 연장만으로 별도 버프 수명까지 확정하지 않음 |
| `버프효율증가` | 파편 자체의 교집합 버프 수치 강화 | 원본 버프 종류, 증폭률·계산식·중첩. 버프 종류나 지속 시간을 자동 변경하지 않음 |

기초 분류는 음·양 영역의 `소환물·범위·지속영역·지속시간`과 각 회복 효과의 `회복`을 사용한다. `소환물`에는 설치 장판이 포함되며, 교집합 버프의 세부 효과 분류는 종류 결정 후 붙인다. 파편 자체의 교집합 버프와 회복 후 유물이 제공하는 버프는 별개이고, 두 버프의 중첩은 미정이다.

`긴 호흡`의 적용 태그는 기존 합의대로 `지속시간`이며, 회복 주기·회복량·순환 회복 전달 비율을 변경하지 않는다. `범위 증폭`은 지정 사거리나 중심 타일을 바꾸지 않는다. 전용 유물의 용 출현은 별도 고유 효과이며, 즉사·최대 HP 비례 피해의 세부 태그와 범위·피해 증폭 등 다른 유물과의 조합은 아직 미정이다.

**울림통**은 원형 지속영역일 때의 추가 호환 후보로 남기며 이번 5개 목록에 별도 유물 채택으로 추가하지 않는다. 일반 회복 장판은 피해가 없어 소환물 피해 후 약화를 자체 발동시키지 않는다. 회복 주기 단축도 이번 목록에 포함하지 않는다. 상세는 [음양 태그와 유물 연결](synergies.md#rel-%EC%9D%8C%EC%96%91-%ED%83%9C%EA%B7%B8%EC%99%80-%EC%9C%A0%EB%AC%BC-%EC%97%B0%EA%B2%B0--2026-10-18-%EC%82%AC%EC%9A%A9%EC%9E%90-%ED%95%A9%EC%9D%98)을 따른다.

**전용 이스터에그 유물 — 2026-10-18 사용자 합의:** 유물을 장착하고 한 시전에서 음·양의 중심 타일을 동일하게 지정하면 해당 영역에 용이 한 번 나타난다. 영역 안 아군·침식체는 즉사하고, 환상체·보스는 최대 HP 25% 피해를 받는다. 시전자도 영역 안이면 아군 판정을 따른다. 용의 판정 후 장판·회복·순환 회복·교집합 버프 등 후속 효과 없이 스킬이 종료된다. 중심이 다른 일부 교집합이나 별도 시전끼리의 중첩은 발동 조건이 아니다. 조건 불충족·유물 미장착 시 기존 회복·지원 구조를 유지한다.

직접 경험하기 전까지 유물의 정체·발동 효과를 알리지 않으며, 조준 경고·위험 범위 전환·피격 아군 강조·별도 확인창을 넣지 않는다. 발견 후 공개 방식, 이름·등급, 범위·판정 시점, 방어·무적·생존 보장·페이즈와 처치 연쇄 세부는 미정이다. 이 효과는 에고 침식과 별도이며, 같은 25% 수치를 쓴다는 이유로 침식의 다른 규칙을 자동 상속하지 않는다. 상세는 [전용 유물 설계](../../relics/yin-yang-dragon.md#rel-%EC%9D%8C%EC%96%91-%EC%A0%84%EC%9A%A9-%EC%9D%B4%EC%8A%A4%ED%84%B0%EC%97%90%EA%B7%B8-%EC%9C%A0%EB%AC%BC--%EC%9D%B4%EB%A6%84-%EB%AF%B8%EC%A0%95)를 따른다.
