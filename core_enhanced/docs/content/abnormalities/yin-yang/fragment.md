## 파편 — 음양의 순환 (가칭)

기본 파편의 역할은 **힐**이다. 전용 유물의 용 전환이 없는 기본 동작은 적 피해나 아군의 대가 없이, 플레이어가 지정한 두 위치에
**음의 영역**과 **양의 영역**을 만들어 지속 시간 동안 두 구역의 아군을 회복하고, 교집합의 아군에게 이로운 버프를 제공한다.

| 항목 | 값 |
| --- | --- |
| `rarity` | open design |
| `equip_limit` | open design |
| `compatibility` | open design |
| `cast_selection` | 음/양 순서로 전장 위치 2곳 지정. 최종 접수는 두 위치와 비용을 함께 확정 |
| 역할 | 힐·지원 / 음의 영역·양의 영역의 지속 회복과 교집합 버프 |

공명 만충에서 플레이어가 두 위치를 지정하면 한쪽에 **음의 영역**, 다른 쪽에 **양의 영역**을 만든다.
2026-10-18 사용자 합의에 따라 기존의 단일 위치 회복 장판을 이 두 영역 구조로 대체한다.

- 두 영역은 지정한 위치에 유지되며, 지속 시간 동안 각 구역 범위 안의 eligible 아군을 회복한다.
- 아군이 범위에 들어오면 회복 대상이 되고, 범위를 벗어나면 더 이상 회복받지 않는다. 대상은 장판의
  각 회복 판정 시점에 현재 위치를 기준으로 다시 정한다.
- 적의 존재·명중·피해량·처치 여부와 아군 HP 희생은 장판의 생성이나 회복 조건이 아니다.
- 이전의 단일 장판 흑백 파동 교대 설명 대신 음의 영역과 양의 영역을 공간적으로 구분한다.
  두 영역의 이름만으로 서로 다른 회복 성질·계수·추가 버프를 부여하지 않는다.

**순환 회복 — 2026-10-18 후속 합의**

- 음과 양의 기본 회복 성질은 같게 둔다. 각 회복 주기에 두 영역이 먼저 각자 범위 안 아군을 회복한다.
- 아군 HP가 가득 차 실제로 쓰이지 않은 회복량 일부를 반대 영역의 부상 아군에게 추가 회복으로 전달한다.
- 전달하는 영역에도 아군이 있어야 한다. 아군이 없는 빈 영역에서 전달 회복량을 만들지 않는다.
- 전달된 추가 회복의 초과분은 다시 반대편으로 보내지 않는다.
- 전달 비율은 미정으로 남기고 집계·배분·겹침 처리는 아래 작성 정책을 따른다.

**독립 영역과 교집합 — 2026-10-18 후속 합의**

| 위치 | 파편 효과 |
| --- | --- |
| 음의 영역만 있는 곳 | 회복 |
| 양의 영역만 있는 곳 | 회복 |
| 음과 양이 겹치는 교집합 | 회복 + 이로운 버프 |

기존 순환 회복 합의는 유지한다. 2026-10-21 사용자 합의: 기본 회복은 대상당 한 번만 적용하고,
교집합 안에서 기본 공격 속도 증가를 부여한다. 이탈·영역 종료 시 해제하며 증가량은 미정이다.
교집합 버프는 실제 HP 회복을 발동 조건으로 삼지 않는다. 아래 작성 정책에서 집계·출처를 구분한다.

두 영역의 범위·지속 시간·회복 주기·회복량은 미정이다. 최초 판정·설치 후 행동·재시전은 아래 작성 정책을 따른다.
파편은 어떤 compatible 무기와 조합해도 두 회복 영역 자체로 광역 회복 역할을 완결한다.

### 2026-10-21 작성 정책

교집합의 기본 회복 단회 적용·기본 공격 속도 증가·이탈 즉시 해제는 사용자 승인 사항이다.
아래 나머지 세칙은 통상 정책 판단 위임에 따라 정했으며 과거 시험 수치를 최종값으로 가져오지 않는다.

| 항목 | 작성 규칙과 근거 |
| --- | --- |
| 입력·생성 | 음/양 순서로 두 타일을 고르고 최종 접수에서 두 위치의 자격·범위와 공명 비용을 원자적으로 확정한다. 한쪽 선택만으로 소비/생성하지 않는다. 동일 타일도 허용하며 전용 유물 분기는 별도다. 두 영역 생성 후 사용을 끝내고 자유 행동·공명 충전을 재개한다. |
| 수명 | 동일 시전의 두 영역은 같은 유한 수명을 공유한다. 같은 사본의 새 생성이 성공하면 기존 두 영역을 함께 교체한다. 실패 시 기존 영역은 유지한다. 시전자 사망·철수·전투 종료에서 두 영역과 교집합 기여분을 정리한다. |
| 주기 | 첫 회복은 생성 후 한 주기 뒤다. 종료가 같은 시각의 주기보다 우선한다. 두 영역을 같은 주기 회차로 조회하고 대상 집합을 고정한다. Pause 중 진행/보충은 없다. |
| 중복 집계 | 각 아군은 현재 타일의 맨해튼 거리로 가까운 중심에 한 번만 집계하고 같은 거리면 음에 집계한다. 실제 두 영역의 교집합 여부와 집계 소속을 분리한다. 빈 영역은 예산 0이다. 서로 다른 사본은 별도 시전으로 회복하지만 교집합 판정에 다른 사본의 영역을 섞지 않는다. |
| 기본 결과 | 두 영역의 기본 회복을 모두 처리한 뒤 HP 상한 때문에 사용하지 못한 양만 집계한다. 거절·면역·회복 불가·대상 소멸은 초과 회복 예산을 만들지 않는다. 요청량·실제 HP 회복·HP 상한 초과분은 별도 결과다. |
| 전달 | 각 소속 영역의 초과분 합계 × 전달률을 내림해 정수 예산으로 만든다. 반대 소속의 부상 아군에 남은 결손 HP 비례로 배분하고 나눗셈 잔여는 안정된 ID 순으로 나눈다. HP 상한을 넘는 배정·사라진 대상·수혜자 부재의 잔여는 버린다. 전달 예산/회복을 재전달하지 않으며 시전자의 같은 회복 증가를 두 번 적용하지 않는다. 받는 회복 보정은 수혜자 규칙을 따른다. |
| 버프 | 기본 공격 속도에 더하는 양수 포인트이며 중립 100 기준이다. 파편 판정 주기·시전 시간을 줄이지 않는다. 같은 사본의 교집합 내에서는 한 번, 다른 사본의 동일 버프는 가장 강한 값만 적용한다. 진입 때 부여하고 이탈/수명 종료 때 해당 출처의 기여분만 제거한다. |

현재 작성 구조와 실제 실행의 차이는 [공통 그래프 계약](../../../../../content_assembler/docs/common-skill-graph-contract.md)에서 관리한다.

## 파편 침식형 — 이름 미정

> 상태: 소재 합의 / 범위와 수치 미정

필드에 **용**이 나타난다. 조우에서 음과 양이 합체했을 때 전장을 가로지르는 그 용이다.

조우 설계는 `실패 현상인 용을 플레이어가 자유롭게 소환하는 보상으로 바로 옮기지 않는다`를 단서로
달아 두었다. 침식은 파생 4종 보유, 트라우마 임계치, 공명 만충과 명시적 입력이 모두 필요한 최후
수단이라 `자유롭게`에 해당하지 않으므로 이 단서와 충돌하지 않는다. 2026-10-18에 별도로 합의한
전용 유물의 숨겨진 용 출현은 이 옛 보상 방향의 예외이며, 에고 침식의 조건·효과와 합치지 않는다.

용은 **적만 처형한다.** 조우의 용이 아군까지 즉사시키는 것과 달리 여기서는 `침식형 공통 정책`을
그대로 따르며 예외를 만들지 않는다.

open design:

- 이름과 수치

판정과 대상 범위는 위 `침식형 공통 정책`이 소유한다.
