## 음/양

> 상태: 2026-10-18 두 위치의 음의 영역·양의 영역에서 지속 회복하고 남은 회복량 일부를 반대 영역으로 전달하는 순환 구조 합의.
> 후속 합의: 독립 영역은 회복, 음·양의 교집합은 회복과 이로운 버프. 교집합 회복량·버프 종류와 수치 미정.
> 전용 유물 후속 합의: 같은 중심 타일 시전 시 경고 없이 용 1회 출현 후 종료. 아군·침식체 즉사, 환상체·보스 최대 HP 25% 피해.
> 태그 후속 합의: 회복량 증가 / 회복한 아군에게 버프 부여 / 범위 증폭 / 지속시간 / 선명한 축복의 5개 연결.
> 순수 힐 Staff·HP 구간 방어구·순환 회복 액세서리 구조 유지 /
> 이름·수치·세부 판정 미정

조우 설계는 `abnormality_design_notes.ko.md`의 `음/양` 절이 소유한다. 양면 미로 관제, 경로 소모,
분리 격리와 합체 시의 용은 그쪽을 읽는다.

**음과 양을 하나의 환상체로 취급하고 파편도 하나만 둔다.** 룰북의 `각 스킬 파편은 정확히 하나의
환상체에만 대응한다`를 따르며, 둘로 나뉜 live placeholder(`fragment_yin_trace` /
`fragment_yang_trace`와 장비 6종)는 하나로 통합한다.

<a id="frag-전용-조합과-독립성-2"></a>
### 전용 조합과 독립성

- 파편은 다른 compatible 무기에서도 두 위치를 지정해 음의 영역과 양의 영역을 사용한다.
- 무기는 다른 파편에서도 적의 상태와 무관하게 아군을 기본 치료한다.
- 태극은 전용 무기나 파편이 아니어도 착용자의 HP 구간과 다른 아군에게 주는 eligible 회복만으로
  효과를 결정한다.
- 검은·흰 펜던트는 전용 Staff가 아닌 다른 기본 회복 행동에도 발동한다.

<a id="frag-미결정-사항-2"></a>
### 미결정 사항

- 파편, 무기와 액세서리의 최종 이름, `rarity`, `equip_limit`, 획득 경로와 강화 recipe
- 파편 compatibility, 음·양 영역 각각의 범위·지속 시간·회복 주기·회복량과 최초 회복 timing
- 두 위치의 지정 순서·시전 확정과 생성 시점, 지정 사거리·영역 간 거리, 교집합의 회복량·중복 회복
- 교집합 버프의 종류·수치·지속 시간·부여 및 재부여·영역 이탈 시 처리
- 순환 회복의 전달 비율·초과 회복 집계·수혜자 배분과 영역 겹침 시 처리
- 독립 설치 여부, 재시전 교체·복수 사본 장판 중첩, 시전자 철수·전투불능과 효과 종료의 exact lifecycle
- 무기의 회복 범위, 한 행동의 대상 수·선정 순서, 회복량, 주기, windup과 target 재지정
- 태극의 방어력·회복량 증가 수치, modifier 계산 단계와 HP `50%` 경계 갱신 timing
- 펜던트의 실제 회복량 집계, 자기 회복 비율, action당 상한과 eligible 기본 회복 tag
- **개화형의 존재 여부.** 현재는 두지 않는 쪽이 유력하며 추후 정한다
