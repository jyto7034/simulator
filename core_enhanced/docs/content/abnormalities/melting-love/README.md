## 녹아내리는 사랑

> 상태: 2026-10-19 공격형의 감염 성장·유예 후 자연 감소·숙주 일제 기폭 및 유물 6개 구조 설계 종료.
> 방어형 검토 보류. 기존 일반 승리 탱커·퍼펙트 탱/딜 선택형 보상은 재편 없이 기록 유지.
> 퍼펙트 exact 조건·선택 재획득·이름·수치·세부 판정은 후속 조정.

조우 설계는 `abnormality_design_notes.ko.md`의 `녹아내리는 사랑` 절이 소유한다. 보상은 분홍 점액과
사랑이라는 외형 위에, 감염된 시체를 흡수해 육벽을 보충하는 **좀비형 순수 탱커**와 살아 있는 적
사이로 포자를 증식시킨 뒤 일제 기폭하는 **전염형 순수 딜러**를 분리한다.

### 미결정 사항

- 두 파편, 무기, 방어구와 액세서리의 최종 이름
- 두 파편과 세 장비의 rarity, 획득 경로와 중복 소유 정책
- 퍼펙트 승리의 exact 조건, 선택 결과 commit, repeat reward와 나머지 파편 재획득 정책
- 무기 강화 recipe와 파편·장비의 정확한 수치
- 고기방패, 고기벽, 탱커 무기의 감염도와 딜러 파편 포자 감염의 open design 판정
