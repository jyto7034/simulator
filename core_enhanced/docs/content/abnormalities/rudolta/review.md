## 스킬 파편 능력:

- `악의의 선물`은 시전하면 썰매 형상이 일정 간격으로 유한 횟수의 선물 폭탄을 투하하는 구조로 합의했다.
  매 투하 때 유한한 탐색 구역의 적을 선택하고, 낙하 목표 타일을 고정한 뒤 범위 Physical 피해를 준다.
- 착용자는 비행하거나 집중 상태에 들어가지 않고 기본 공격을 계속한다. 썰매는 독립 소환물이 아니다.
- 같은 적도 여러 선물에 반복해서 맞을 수 있지만, 적이 없던 투하 기회는 저장하지 않는다.
- 파편의 피해 type·대공·구역·횟수·간격·범위·수치·세부 판정은 미정이다.

## 23 썰매의 루돌타

**기존 방향:** 평타와 별개로 일정 시간 여러 번 폭탄을 투하한다. 썰매가 독립 전투 유닛일 필요는 없다.

**조립안:** 자기 시전 → 투하 영역과 총 기회 수 고정 → 매 기회에 영역 내 우선 대상 선택 → 투하 타일 고정 → 착탄 시 현재 적을 조회해 범위 피해다. 빈 영역이어도 해당 기회는 지나가며 공격 속도가 투하 간격을 바꾸지 않는다. 한 시전의 여러 타격으로 기록한다.

**상태와 표현:** 남은 투하 수·다음 시각·영역과 이미 투하한 폭탄의 착탄 기록을 유지한다. 썰매 이동은 장식할 수 있지만 실제 투하 지점과 착탄 위치는 일치해야 한다.

**기능 경계:** 유한 주기 발사 + 지연 타일 폭발. 액세서리는 단일 공격을 범위로 바꾸거나 기존 범위를 한 번 넓힌다. 주 대상 피해를 원래 공격과 새 범위 공격으로 중복 적용하지 않는다. 방어구의 스킬 시전 공속 강화는 별도다.

**검토:** 추천은 시전자 사망·철수 시 새 투하를 중단하되 이미 떨어지는 폭탄은 유지하는 것이다. 영역을 시전 위치에 고정할지 시전자를 따라가게 할지도 정한다. 이 초안은 고정 영역을 추천한다.

**태그와 유물 적용**

| 효과 단위         | 태그 후보        | 변경 후보 속성과 지켜야 할 경계                                  |
| ----------------- | ---------------- | ---------------------------------------------------------------- |
| 유한 투하 순서    | `다중타격`       | 투하 횟수·간격. 각 폭발을 원본 시전의 직접 타격으로 연결         |
| 개별 선물 폭발    | `피해·범위·폭발` | 폭발 반경·위력. 투하 영역과 폭발 반경 구별                       |
| 투하 후 착탄 지연 | `지연발동` 후보  | 독립 지연으로 채택할 경우의 시간. 실제 탄환일 때만 `투사체` 추가 |

**유물 연결:** 기존 **깊은 쐐기**는 같은 적에게 이어지는 직접 폭격의 타격별 피해를 강화한다. 폭발 반경 증가는 새 범용 후보다. **울림통**은 일회성 폭발에 적용하지 않는다. 반복 폭격은 `지속피해`가 아니고 썰매 그림은 `소환물`이 아니다.
