## 썰매의 루돌타

> 상태: 단일 피해 유탄발사기·단일 피해의 범위화 및 기존 범위 확대 액세서리,
> 유한 횟수 선물 연속 폭격 파편·active 파편 시전 후 기본 공격 속도 증가 방어구 구조 합의 /
> 무기의 Gun 분류·배치 등 세부 profile, 이름·수치·판정 미정 /
> 현재 미구현

조우 설계는 `abnormality_design_notes.ko.md`의 `썰매의 루돌타` 절이 소유한다. 플레이어 보상은
기본적으로 단일 피해를 주는 유탄발사기와 여러 차례 떨어지는 선물 폭격을 함께 사용하는 원거리
딜러다. 액세서리를 조합하면 유탄은 범위 피해로 바뀌고 파편의 기존 폭발은 더 넓어진다.
선물은 폭탄의 포장과 연출이며, 별도 개봉·수집·무작위 보상·적 유인 기믹을 만들지 않는다.
적 조우에 선물 상자 기믹을 두지 않는 기존 결정도 변경하지 않는다.

풍운승려의 느린 범위 기본 공격·단발 광역 버스트와 달리, 평상시 단일 사격을 유지하면서 파편의
추가 폭격이 시간차로 전장을 정리하는 역할이다. 파편의 썰매는 공격 연출이지 직원을 태워 비행시키는
탈것이나 독립 소환물이 아니다. 무기의 배치·저지·공격 범위를 파편이 암묵적으로 바꾸지 않는다.

### 전용 조합과 역할

- 파편이 반복 광역 피해를 맡고, 유탄발사기는 단독 장착 시 단일 적을 계속 공격한다.
- 선물자루를 조합하면 유탄이 범위 피해로 바뀌고, 원래 범위 피해인 파편 폭격은 더 넓어진다.
- 외투는 파편 시전을 유탄 발사의 가속으로 연결한다. 범위화 여부와 관계없이 기본 공격만 가속하고
  선물 폭격의 투하 횟수·간격은 바꾸지 않는다.
- 모든 장비는 전용 파편을 요구하지 않는다. 외투는 다른 active 파편과, 선물자루는 다른 eligible
  단일·범위 공격과 조합할 수 있으며, 유탄발사기는 액세서리 없이도 기본 단일 공격으로 기능한다.
- 파편은 다른 호환 무기로도 독립적인 폭격을 제공한다. 별도의 회복·피해 면역·이동 방해·선물 수집
  순환을 붙이지 않고 원거리 화력 보강에 집중한다.

<a id="frag-미결정-사항-21"></a>
### 미결정 사항

- 최종 이름·획득 경로·파편 희귀도·중복 제한·호환 범위
- 유탄발사기의 Gun·Physical·Platform·저지 0·대공 및 표적 우선순위 후보, 공격력·사거리·주기·적중 판정
- 파편의 self 시전·고정 탐색 구역·투하 대상 선택, 횟수·간격·낙하 지연·범위·피해와 대공 판정
- 빈 구역·이동·재시전·철수·전투불능 때의 투하 및 이미 release된 효과 lifecycle
- 외투의 기본 stat·발동 이벤트·공속 증가율·지속 시간·다른 공속 modifier 합성
- 선물자루의 단일 피해 전환 범위·주변 피해 계수·상한, 기존 범위 확대량·형태별 타일 확장 규칙
- 액세서리의 eligible 단일·범위 피해 source, 다단·지속 피해·부가 효과·trigger·공명과 범위 snapshot
- 각 장비 강화 성장치와 전투 수치 검증, 전용 Run 유물의 설계 여부
