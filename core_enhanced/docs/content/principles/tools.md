## 도구 공통 규칙 — 2026-10-04 채택

도구형 환상체는 전투 유닛이나 일반 파편 보상으로 일괄 전환하지 않는다. 이벤트·정비·지원 등
도구 조우에서 얻는 아이템, 계약, 특수 장비와 전장 기믹으로 구현한다. 아래 `도구 노드`는 개별
콘텐츠의 조우 역할이며 별도 새 노드 종류나 매 방 공급 보장을 확정하는 뜻은 아니다.
구체적인 공급 위치·빈도·비용은 시설의 예약/배정·최초 입장 비용 규칙 안에서 작성한다.

| 분류 | 도구 | 일반 소비품 한 칸과의 관계 |
| --- | --- | --- |
| 전투 전 기간형 소비품 | 거목수액·발광 팔찌 | 직원당 활성 소비품 효과 한 칸 사용. 새 소비품으로 교체하면 기존 효과가 끝나고 아이템 환불 없음 |
| 지속 계약 | 이계의 초상 | 일반 소비품 교체로 해제되지 않는 원정 계약 |
| 전투 중 재사용 도구 | 살점 우상 | 명시된 전투 중 사용 예외. 기도·참여자·사용 횟수를 별도 보존 |
| 조립 장비 | 부서져 가는 갑옷 | 특수 슬롯의 장비 개체. 일반 장비·유물 슬롯 수를 함께 바꾸지 않음 |
| 즉시 치료/강화 | 피의 욕조·오래전의 믿음과 약속 | 사용 결과를 즉시 처리하며 일반 소비품의 기간형 효과 한 칸을 점유하지 않음 |
| 전장 기믹 보유권 | 지옥행 급행열차 | 원정 보유 상태가 비최종 전장의 부스/선로를 활성화 |
| 직원 불참/복귀 | 뚜껑 따인 웰치어스 | 납치 상태와 후속 활동 노드 진행을 별도 보존 |

- 모든 도구의 아이템·효과·계약·특수 조립·납치 상태와 특별 강화는 원정 전용이다. 다음 원정의
  직원에게 넘기지 않는다. 도구가 주는 일반 자원/장비의 회수 가능 여부는 해당 자산의 공통 규칙을 따른다.
- 일반 피해로 battle HP가 0이 되면 전투불능과 부상·트라우마 누적을 적용한다. 명시된 희생·저주
  대가만 영구 run 사망이다. `사망`이라는 옛 표현만으로 둘을 혼용하지 않는다.
- 최대 HP 증가만으로 현재 HP를 자동 회복하지 않는다. 감소 시 상한을 넘는 HP는 공통 규칙대로
  낮춘다. 직접 회복 효과는 별도로 실행한다.
- 수동 전투 후퇴는 전투 진입 전에 이미 사용한 도구를 환불하지 않는다. 진입 시 보유 효과·계약·
  아이템 상태를 복원하고 전투 중 변화만 되돌린다. 최초 노드 입장 비용·유예·입장 사망과 이미
  사용한 후퇴 횟수는 최신 공통 규칙대로 유지한다. 승패가 성립한 뒤에는 후퇴할 수 없다.
- 결과가 없는 프로세스 종료 후 이어하기는 해당 노드 입장 전을, 같은 프로세스 재접속은 현재
  진행을 복원한다. 완료된 노드와 승패 결과는 확인 화면과 무관하게 보존한다.
- 과거 SavePoint를 명시적으로 불러오면 도구·직원·자산·사용 횟수/위험·결과를 그 시점으로 함께
  복원한다. 영구 run 사망·무기 소멸이라는 명칭으로 공통 체크포인트 복구를 금지하지 않는다.
  중복 입력은 한 번만 적용하고 복구한 동일 시도는 같은 결과를 사용한다. 새로운 난수 결과를
  뽑는 편법을 막는 것과 도구 결과 전체를 복구 불가능한 영구 장부로 만드는 것은 구분한다.
- 남은 기간은 전투 승패 결과 확정 때 한 번 줄이며 후퇴·비전투 활동에서는 줄지 않는다.
  도구의 실제 사용·대가·아이템 소비·장비 회수와 결과 저장은 부분 적용되지 않게 함께 처리한다.

공통 근거는 [시설/소비품](../../game_rules/run-and-map.md#%EB%AC%BC%ED%92%88%EA%B3%BC-%EC%86%8C%EB%B9%84-%EC%95%84%EC%9D%B4%ED%85%9C),
[전투 능력치](../../game_rules/combat.md#%EC%A0%84%ED%88%AC-%EB%8A%A5%EB%A0%A5%EC%B9%98%EC%99%80-hp),
[직원 상태·후퇴·저장](../../game_rules/results-and-save.md)다.
이하 수치의 `초기값`, `범위`, `미정`은 구조 합의와 구분하며 실제 플레이로 조절한다.
