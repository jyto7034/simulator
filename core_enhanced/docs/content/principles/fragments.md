<a id="frag-목적"></a>
## 목적

abnormality_design_notes.ko.md 에서 작성된 환상체들이 보상으로 지급하는 스킬 파편에 대해서 서술되어 있는 문서

기록은 사용자 결정에 근거하며, 명시하지 않은 사항은 `open design`으로 남기고 값이나 규칙을 추론해
채우지 않는다. 파편·장비 콘텐츠는 이 문서, 환상체 조우는 `abnormality_design_notes.ko.md`, 공통 시스템의
세부 명세는 별도 시스템 문서가 소유한다. 기존 placeholder 데이터에 맞춰 설계를 축소하지 않는 방침을 유지한다.

<a id="frag-설계-원칙"></a>
## 설계 원칙

우리 게임은 명일방주식 DefenseRoute 기반 게임이지만, Hack and slash 를 지향한다.
메인스트림급 성능을 가진 스킬파편은 보스 혹은 최종보스들에서 얻을 수 있다. 하지만 최종보스는 물론이고 일반 보스는 자주 만날 수 있게 설계되어 있진 않다.
최종/일반 보스를 만나기 전까진 엘리트급 보스의 스킬파편을 사용해야한다.
그러한 인내의 과정 중에서 다수의 적들을 시원하게 썰고 부수는 재미를 못느끼지 않게 엘리트급 보스들이 지급하는 스킬 파편의 성능을 잘 설계해야한다.
그렇다고 엘리트의 스킬파편을 너무 강하게 만들면 안 된다. 그러면 일반 보스의 스킬 파편이 그저 엘리트의 상위호환으로 느낄 수 있기 때문이다.

이 문서의 설계 원칙과 기재 규칙은 **권장 기준이지 강제가 아니다.** 개별 환상체의 설계가 더 나은
결과를 낸다면 규칙을 벗어날 수 있고, 그때는 해당 항목에 벗어난 이유를 적는다.

<a id="frag-등급별-문법-분리"></a>
### 등급별 문법 분리

등급 차이를 수치 서열이 아니라 문법으로 나눈다. 그래야 상위 파편이 하위의 상위호환이 되지 않는다.

| 등급 | 문법 | 조건 |
| --- | --- | --- |
| 엘리트 | 원본 환상체의 대표 스킬을 단순하게 모방한다 | 복잡한 파생 기믹 없이 즉시 사용. 부족한 화력은 Run 유물로 보강한다 |
| 일반 보스 | 플레이어 개입이 열린다. 수동 지정으로 각을 만든다 | 조건부 고점 첫 등장. 조건 미충족이어도 엘리트급 기본값을 보장한다 |
| 최종 보스 | 전장 규칙을 잠시 바꾼다. 준비 과정과 대가를 가진다 | 조건 자체가 정체성 |

엘리트 파편은 조우의 대표 공격·방어·지원 스킬을 플레이어용 active skill로 직접 옮긴다. 원본에
그대로 옮길 만한 스킬이 없거나 플레이어 전투 규칙과 충돌할 때만 별도 스킬안을 설계한다. 일반 보스
파편처럼 독자적인 장기 순환을 새로 만들지 않으며, 단순한 기본 효과와 다소 부족한 피해를 Run 유물이
보완하는 것을 전제로 한다.

판단 기준은 **교체 직후 첫 시전에서 차이가 보여야 한다**는 것이다. 활성 슬롯이 1개이므로 파편 교체는
직접 A/B 비교가 된다. 피해량 증가는 이 기준을 통과하지 못하고, 영향 범위와 선택 주체의 변화는 통과한다.

<a id="frag-기재-규칙"></a>
## 기재 규칙

<a id="frag-환상체당-구성"></a>
### 환상체당 구성

환상체 하나는 스킬 파편 1종과 파생 장비 3종(무기 / 방어구 / 액세서리)을 가진다. 파편 정책과 같이
확장 여지는 남기되 기본은 이 구성이다.

각 환상체의 장비 모티프는 `abnormality_design_notes.ko.md`의 `보상 방향` 항목을 authoring 재료로 쓴다.

<a id="frag-파편-필수-기재-항목"></a>
### 파편 필수 기재 항목

효과와 별개로 파편마다 반드시 정한다.

- **희귀도** (`rarity`) — `Common` / `Rare` / `Exceptional`
- **중복 장착** (`equip_limit`) — `OwnedCopies` / `GlobalExclusive`
- **아키타입** (`compatibility`) — 장착 가능 무기 profile

`compatibility`의 default는 제한 없음이므로, 명시하지 않으면 모든 무기에 장착된다.

E.G.O 침식은 같은 환상체 파생 4종을 모두 **보유**하면 성립하며 장착을 요구하지 않는다. 따라서
파편의 `allowed_weapon_archetypes`와 세트 무기의 archetype이 반드시 일치할 필요는 없다. 침식 시스템
자체는 별도 시스템 메모가 소유한다.

<a id="frag-개화-형태-선택"></a>
### 개화 형태 선택

개화한 파편은 개화 전 스킬과 개화 후 스킬 중 어느 쪽을 사용할지 플레이어가 Maintenance에서 고를 수
있다. 개화는 일방향 교체가 아니라 선택지 추가다.
