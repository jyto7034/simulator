## 태그·유물 정리 — 2026-10-20

[태그 사전](tags/README.md)은 변경 가능한 효과 단위를, [유물 목록](relics/README.md)은 이름과 대상 태그·변경 규칙을 관리한다.
기존 유물 기능을 이름 있는 문서로 분리하고 파편별 연결표를 통일했다. 기믹·수치의 합의·초안·미정은 유지한다.

## 읽고 고치는 기준

- 현재 본문에는 최신 합의와 남은 **미정** 사항을 표시한다. 대체된 합의·미채택 제안·확정 전 시험용 세부는 아카이브에 보존하며 합의로 승격하지 않는다.
- 조우의 행동과 직원이 사용하는 파편 효과를 구분한다. 파편·장비·유물의 상태와 출처도 각각 유지한다.
- 한 규칙의 상세는 해당 페이지에서 관리한다. 다른 페이지에는 연결과 적용 지점을 적고, 전체 본문을 다시 복사하지 않는다.
- 설계 변경은 제안 → 사용자 합의 → 해당 본문 갱신 순서로 진행한다. 미채택 제안과 대체된 동작은 검토 기록에 둔다.
- 위키의 설계 합의는 구현 완료를 뜻하지 않는다. 현재 데이터·구현 근거는 별도로 확인한다.
