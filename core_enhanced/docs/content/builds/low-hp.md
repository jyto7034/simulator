## 저체력 조합용 범용 유물

> 상태: 2026-09-08 착용자 자신의 받는 피해 증가 유물 기록 합의 / 잃은 체력 비례 공격력 증가 방향 기록 /
> 생존 유물은 사용자 제시 `빌려온 댓가`의 10초 생존 보장·종료 회복·대가 구조로 변경 /
> 범용 유물들의 희귀도·증가율, 생존 유물의 발동·횟수·회복 기준과 대가 세부는 후속 설계 /
> 문서 설계이며 현재 runtime·live data 구현은 포함하지 않음.

세 효과는 각각 공용 슬롯 하나를 사용하는 별도 범용 유물로 검토한다. 흑조에서 출발했지만 특정
파편·무기를 요구하지 않는다. `깨어난 흑조`의 전용 축적·방출 구조는 원본대로 유지한다.

### 현재 조합의 범위

- 각 유물은 별도 공용 슬롯 하나를 사용한다. 세 유물을 모두 장착하면 공용 슬롯 3개를 사용한다.
- 받는 피해 증가, 잃은 체력 비례 공격력 증가, 생존 보장·종료 회복·후불 대가는 각각 독립된 효과다.
- 회복으로 부족한 HP 비율이 줄면 잃은 체력 비례 공격력 보너스도 낮아진다.
- 생존 보장으로 막아 실제 HP가 줄지 않은 피해는 실제 HP 손실로 집계하지 않는다.
- 정확한 증가율·발동 방식·회복 기준·대가의 세부는 각 유물의 미정 사항이다.
