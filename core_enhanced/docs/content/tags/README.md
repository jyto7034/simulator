## 태그와 유물의 정의 — 2026-10-20

**태그는 스킬의 효과 중 공통된 방식으로 증폭하거나 변형할 수 있는 단위를 묶은 분류이며, 유물은 적용할 태그와 그 태그에 대한 변경 규칙을 묶은 단위다.**

- 태그는 변경 대상의 공통 분류다. 태그 자체가 피해를 늘리거나 새 효과를 발동시키지 않는다.
- 유물은 이름을 가지며, 하나 이상의 규칙으로 대상 태그·적용 조건·변경 내용을 묶는다.
- 기절 여부, 아군 대상, 직접 피해, 현재 시전, 지정 자원, 특정 파편·형태 등은 규칙의 세부 조건이다.
- 같은 태그를 가진 효과라도 조건이 다르면 유물이 적용되지 않을 수 있다. 전용 유물의 콘텐츠 조건도 유지한다.
- [선행 유물](../../game_rules/relics.md#선행-유물)은 특정 유물의 장착·활성을 요구하는 조건이다.
  효과 조건·상호 보완·비호환·중복 제한과 구분하며, 이 관계들을 공통 효과 태그로 등록하지 않는다.
- 스킬·장비·유물에 속한 각 효과의 출처를 보존한다. 문서에 나열된 태그를 서로 다른 효과 사이에서 합쳐 조건을 충족시키지 않는다.
- 정식 데이터 ID 등록이나 엔진 구현 완료를 뜻하지 않는다. 아직 미정인 수치·호환·판정은 개별 문서를 따른다.

## 기록 단위

| 구분 | 기록할 내용 | 예 |
| --- | --- | --- |
| 스킬의 효과 | 해당 효과가 가진 태그와 세부 속성 | 나무꾼 2타 기절: 제어·범위·지속시간, 제어 종류는 기절 |
| 유물의 대상 | 변경할 태그와 적용 조건 | 깨진 균형: 제어 중 기절·빙결 등 인정된 강력한 제어 |
| 유물의 변경 규칙 | 바꾸는 값·대상·구조 또는 생성할 후속 효과 | 기절한 적에게 5초간 받는 피해 증가 부여 |
| 유물이 만든 효과 | 새 효과 자신의 태그와 출처 | 받는피해증가·지속시간, 출처는 깨진 균형 |

‘범위증폭’은 변경 규칙이며 대상 태그는 `범위`다. ‘무아지경’은 유물 이름이며 대상 태그는 `시전`이다.
`스택획득`·`스택부여`는 사건 단위의 태그로 유지한다. 획득·부여량 2배는 각각 두 겹의 수확·깊은 각인의 규칙이다.
`다중타격`은 순서 있는 직접 타격 구조이며 같은 적 적중당 +2%p는 깊은 쐐기의 규칙이다.

## 적용 관계와 합의 범위

태그는 효과 단위에 붙인다. `범위 · 회복`이 같은 회복 장판에 속하는지, 서로 다른 공격과 자기 회복에
나뉘어 속하는지 구분한다. 위키의 문서별 태그 모음은 탐색용이며 엔진의 호환 판정을 대신하지 않는다.

유물의 조건은 하나의 효과를 검사할 수도 있고, 명시한 관계를 검사할 수도 있다. 예를 들어 사냥의 낙인은
소환물과 그 소환물이 가한 피해의 출처 관계를 읽는다. 같은 스킬에 무관한 소환물·피해가 있다는 이유만으로 발동하지 않는다.

능력치 유물은 착용자의 `능력치` 값을 직접 변경할 수 있다. 기존 `능력치변경` 버프 보유를 요구하지 않는다.
긴 호흡의 대상은 `지속시간`이며, 늘릴 효과의 수명을 개별 연결에서 지정한다. 시전과 집중, 상태 부착과
행동 중단, 스택 보유와 획득·부여·한도, 자원의 성장·감소·소비를 별도 변경 단위로 구분한다.

파편 없음·전용 전환·저체력·검토 제안 등은 문서 분류나 조건 설명이다. 공통 효과 태그와 섞지 않는다.

2026-10-20 [백야 파편](../abnormalities/white-night/fragment.md)은 고유 규칙으로 관리하며,
파편과 사도에 효과 태그·전용/범용 유물 연결을 두지 않기로 합의했다.
사도화·원정 누적은 설명용 분류이며, 사도화 타이머를 주기 태그로 등록하지 않는다.
공격의 피해 유형·범위 등 전투 판정 정보는 별도로 명시한다. 실낙원의 호환은 독립 장비 설계에서 정한다.
