## 깨진 균형 — 강력한 군중제어 범용 유물

> 상태: 2026-10-18 사용자 요청으로 범용 유물 추가. 강력한 군중제어 시 받는 피해 증가와 5초 지속은
> 합의한 설계 방향이다. 설계명은 깨진 균형이며 증가율·희귀도·상세 판정은 미확정이다.

**착용자가 적에게 강력한 군중제어를 가하면, 그 적이 5초간 받는 피해가 증가한다.**

| 항목 | 내용 |
| --- | --- |
| 구분 | 태그 기반 범용 유물, 제어와 후속 피해를 연결 |
| 이름 | 깨진 균형 |
| 적용 태그 | `제어`. 기절·빙결 등 강력한 제어라는 조건과 출처를 함께 확인 |
| 발동 사건 | 착용자 출처의 강력한 군중제어가 대상에게 적용됨 |
| 대표 제어 | 기절·빙결. 다른 제어의 포함 여부는 후속 정의 |
| 생성 효과 | 해당 적에게 유물 출처의 `받는피해증가` 상태 부여 |
| 지속 시간 | 5초 |
| 피해 증가율·희귀도 | 미정 |
| 대표 조합 | 절망의 기사 첫 찌르기·데스비오의 기절, 개화 일반 큰 검의 2초 기절 |

**2026-10-19 두건 연결 합의:** [슬러그탄](little-red-slug-round.md)의 기절에도 이 유물을 연결한다. 기절의 발생 시점·지속시간은 슬러그탄의 미정 사항이다. 기본 강화탄의 2초 속박이나 밀어내기에 자동 확장하지 않는다. [두건 연결표](../abnormalities/little-red/synergies.md#agreed-2026-10-19)를 따른다.

큰 검의 기절이 2초여도 유물이 부여하는 피해 증가의 수명은 5초다. 제어 효과와 피해 증가 효과는
서로 다른 상태이며, 제어가 끝났다고 피해 증가도 함께 끝나는 것으로 처리하지 않는다. 절망의 기사
상처와도 별도 출처 효과다. 상처 스택을 새로 부여하거나 기존 상처의 5% 수치를 이 유물의 증가율로
자동 채택하지 않는다.

**세부 판정 제안:** 제어가 실제로 부착된 경우에 발동하며, 면역으로 부착되지 않은 경우에는 발동하지
않는 안을 추천한다. 같은 유물 출처의 재발동은 증가율을 중첩하지 않고 지속 시간만 5초로 갱신하는
안을 추천한다. 이 두 세칙은 사용자 확정 전 제안이다.

후속 결정: 증가율·희귀도, 강력한 군중제어의 정확한 목록, 면역·재부여 처리,
제어를 가하는 타격 자체와 증폭의 적용 순서, 여러 출처 및 상처와의 합산·중복 장착 규칙.
침식 제외와 유물의 순환 재발동 금지는 공통 정책을 따른다.

## 파고드는 천국 — 2026-10-19 연결 합의

[파고드는 천국의 집중 장판](../abnormalities/burrowing-heaven/synergies.md)이 적을 기절시킬 때
연결한다. 둔화 진행이나 기절 유지 매 순간을 새로운 기절 부여로 세지 않는다. 장판 자체의 받는
피해 20% 증가와 별도 출처·수명이며 유물의 약화는 장판 종료 뒤에도 자체 5초 수명을 따른다.
둘의 합산·면역·재부여 세칙과 유물 증가율은 후속 조정한다.

## 따뜻한 마음의 나무꾼 — 2026-10-20 연결 합의

[나무꾼 연결표](../abnormalities/warm-hearted-woodsman/synergies.md)의 적용 범위를 따른다.
2타 기절에 연결해 해당 적에게 5초간 받는 피해 증가를 부여한다. 1타 끌어당김에는 확대하지 않는다. 증가율·면역·재부여 및 2타 자체 피해와의 적용 순서는 기존 미정 사항을 유지한다.
