## 무기 — 황금 장궁 (가칭)

> 상태: Bow 분류·Platform 장궁·단일 타일 포탈 폭격 구조 합의 / 이름·수치·세부 판정 미정

| 항목 | 값 |
| --- | --- |
| `range_role` | 원거리 / 단일 타일 광역 공격 |
| `weapon_archetype` | `Bow` |
| `deployment_affinity` | Platform 전용 |
| `block_capacity` | `0` |
| `ground_defense_focus` | 해당 없음 |
| `platform_rest` | open design |
| `damage_type` | Physical 우선, exact open design |
| `targeting_profile` | 사거리 안의 적을 기준으로 공격 타일 하나를 선택, exact 우선순위 open design |
| `air_capable` | 가능. 공격 타일 상공의 eligible 공중 유닛도 포함 |
| `defense_tile_range` | 장거리, exact open design |
| `interval_ms` | 중간~느림, exact open design |
| `windup_ms` | 장궁의 시위를 충분히 당기는 분명한 windup, exact open design |
| `delivery` | 화살이 포탈로 진입한 뒤 공격 타일 상공의 여러 포탈에서 수직으로 내리꽂히는 고정 타일 폭격 |

황금 장궁은 길가메쉬 모티브를 바탕으로, 왕이 직접 전선에 들어가지 않고 여러 황금 포탈을 통해
화살을 쏟아붓는 Platform 광역 딜러다. 별도 archetype을 추가하지 않고 기존 `Bow`를 사용한다.

기본 공격은 하나의 action으로 다음 순서로 진행한다.

1. 착용자가 사거리 안의 주 대상을 기준으로 공격 타일 하나를 정하고 장궁의 시위를 당긴다.
2. 시위를 놓으면 발사한 화살이 착용자 앞의 황금 포탈 안으로 들어간다.
3. 화살이 포탈에 들어간 release 시점의 공격 타일을 고정한다.
4. authored 지연 뒤 공격 타일 위에 여러 개의 황금 포탈이 열린다.
5. 각 포탈에서 황금 화살이 바닥을 향해 내리꽂히며, impact 시점에 그 타일 위에 있는 모든 eligible
   적을 공격한다.

- 공격 타일은 release 뒤 움직이지 않는 fixed delivery다. 최초 주 대상이 이동·사망·이탈해도 따라가거나
  다른 타일로 재지정하지 않으며, impact 때 타일이 비어 있으면 빗나간 공격으로 끝난다.
- 대상 목록은 release 때 잠그지 않고 impact 시점의 실제 타일 점유로 정한다. 따라서 최초 주 대상이
  떠나도 뒤따르던 다른 적이 같은 타일에 들어오면 공격받는다.
- 한 타일의 eligible 적 수에는 공격 대상 상한을 두지 않는다. 지상 적과 해당 타일 상공의 공중 적을
  모두 포함한다.
- 포탈과 화살 수는 다방향 폭격을 보여 주는 presentation이다. 같은 적은 이 기본 공격에서 정확히 한 번만
  피해를 받으며 포탈 수만큼 피해 segment, on-hit, 공명과 장비 proc를 반복하지 않는다.
- 타일을 확정하기 전에는 공통 사거리·타겟 유효성 검사를 통과해야 한다. 확정 뒤 화살은 수직으로
  내리꽂히므로 시전자와 공격 타일 사이의 지상 장애물로 다시 차단하지 않는다.

미미크리는 전방 광역 흡혈, 늑대 무기는 변신형 딜탱, 눈물로 벼려낸 검은 관통 파생 누커다. 황금
장궁은 긴 windup과 짧은 impact 지연을 읽어 route 위 한 타일의 적 무리를 한꺼번에 처리하는 원거리
광역 딜러 자리를 맡는다. 파편은 재고와 다음 전투의 지급량을 투자해 보구를 한 발씩 범위 사출하고,
무기는 반복 기본 공격으로 한 타일만 폭격한다. 장궁 기본 공격의 포탈은 파편 재고를 소비하지 않는다.

2026-10-20 파편 리워크 후, 장궁을 포함한 소유자 귀속 피해는 회수용 상태를 부여할 수 있다.
그 상태가 남은 적의 사망으로 얻는 재고는 파편의 패시브다. 장궁 자체가 별도 재고나 대여 기능을
갖지는 않는다. 보구 기절 전용 유물도 장궁의 일반 공격에 자동 적용하지 않는다.

<a id="frag-방어구--황금광"></a>
## 방어구 — 황금광

> 상태: 높은 방어력·최대 HP, 자체 특수 효과 없는 기본안으로 현 단계 합의 /
> 정확한 수치·강화 성장치 미정

파편의 차징·재고 대여와 장궁의 고정 타일 포탈 폭격이 이미 고유한 공격 구조를 가지므로, 방어구는
현 단계에서 별도 trigger나 전용 자원을 추가하지 않는 단순 생존 장비로 둔다. 후속 설계에서 재검토할
수는 있으나, 당장의 기본안은 아래 구성으로 합의한다.

| 항목 | 값 |
| --- | --- |
| 효과 | 높은 기본 방어력과 최대 HP 증가 |
| 자체 특수 효과 | 없음 |
| 정확한 수치 | open design |

Platform에서 공격하는 황금 장궁 착용자에게 기본 생존 체급을 제공하되, 공격력·폭격 범위·포탈 수·재고
회수량이나 대여 한도를 직접 높이지 않는다. 체력 소모 무한 사출의 최대 HP 비례 비용을 보호막이나
피해 감소로 대신 지불하거나 줄일 수 없다.

<a id="frag-액세서리--탐욕의-팔찌-가칭"></a>
## 액세서리 — 탐욕의 팔찌 (가칭)

> 상태: 2026-09-07 사용자 대화에서 액티브 사용·이로운 효과 한 종류의 전 스택 소비와
> 고정 지속 시간·소모량에 따른 계단식 공격력 버프 구조 합의 /
> 단계·증가율·지속 시간·재사용 대기시간·소모 대상·선택 UI 미정 / 현재 미구현.

**사용 시 자신이 현재 가진 소모 가능한 이로운 효과 한 종류를 선택해 그 효과의 스택을 전부
소비한다. 실제 소비한 스택 수에 따른 단계의 공격력 버프를 고정된 시간 동안 얻는다.**

기존 Maintenance 사전 지정과 보유량 비례 상시 공격력 방식은 이 액티브 구조로 교체한다.
기존 후보 수치 `스택당 +5% / 최대 5스택 / 최대 +25%`도 새 구조의 수치로 이어받지 않는다.

**사용과 보상**

1. 전투 중 팔찌를 사용하면 현재 자신에게 적용되거나 장착 콘텐츠가 제공하는 eligible 이로운
   효과 중 한 종류를 선택한다. 선택은 사용할 때마다 하며, 서로 다른 효과를 한 번에 합산하지 않는다.
2. 선택한 효과가 현재 보유한 스택을 전부 소비한다. 소모할 수량을 별도로 고르거나 일부만 남기는
   방식은 사용하지 않는다.
3. 실제 소비 수량으로 버프 단계를 정하고 착용자에게 해당 단계의 공격력 증가를 부여한다.

```text
버프 단계 = 실제 소비한 스택 수가 도달한 단계
공격력 증가율 = 해당 단계에 작성된 증가율
지속 시간 = 모든 단계에서 동일한 T초
```

- 소비 수량이 단계 임계치를 넘으면 더 높은 공격력 버프를 얻는다. 단계 수·임계치·단계별 증가율과
  고정 지속 시간 `T`는 후속 수치 설계에서 정한다. 지속 시간을 스택 수에 비례해 함께 늘리지 않는다.
- 버프 단계는 소비 시점에 확정한다. 이후 같은 종류의 스택을 새로 얻거나 잃어도 이미 받은 팔찌
  버프의 단계가 실시간 보유량을 따라 변하지 않는다.
- 소모한 효과의 기존 이득은 그 효과의 제거·소비 판정에 따라 잃는다. 팔찌 버프가 끝나도 소모한
  스택을 자동 복구하지 않는다.
- 선택 취소·대상 소실·유효 스택 부재로 소비가 성립하지 않으면 공격력 버프도 부여하지 않는다.
  소비와 버프 부여는 함께 성립하도록 처리한다.

**소모 대상**

대상은 팔찌로 실제 제거·소비할 수 있다고 명시한 자기 보유 이로운 효과다. 원래 파편에 능동 소비
기능이 있는 스택만으로 한정하지 않으며, 이로운 효과인지와 팔찌 소비를 허용할지는 개별 정의에
기록한다. 시간 제한이나 숫자 표시만 보고 자동 분류하지 않는다.

- 장비의 상시 능력치와 탐욕의 팔찌가 생성한 공격력 버프는 소모 대상에서 제외한다.
- 다른 아군에게 부여한 효과, 적이나 타일에 적용한 스택은 착용자 자신의 효과로 선택하지 않는다.
- 공명·공격 순번 같은 공통 counter, 고기방패의 HP 구간과 전장 object 수량을 이로운 효과의
  스택으로 자동 변환하지 않는다. 스택 없는 단일 버프의 소비 허용과 수량 환산은 미정이다.
- 떠다니는 검·파편 충전, 포만·검은 눈물과 왕실의 벌집의 일벌 등은 개별 소비 가능 여부와 기존
  효과 제거 결과를 확인할 후보로 둔다. 기존 팔찌의 소비형/비소비형 구분만으로 확정 포함·제외하지 않는다.
- 탐욕의 왕의 옛 `욕망` 소비 후보는 파편 리워크로 대체됐다. 새 보구 재고를 팔찌의 소비 가능한
  이로운 스택으로 자동 간주하지 않는다. 음수 잔고·빚·대여 한도는 실제 보유한 이로운 스택이 아니다.

**조합의 방향**

- 새 보구 재고를 팔찌로 소비하는 연결은 이번 합의에 없다. 추후 허용 여부를 정할 때에는 재고를
  소유한 파편 인스턴스와 실제 양수 보유량을 확인하고, 팔찌 사용으로 자동 대여하거나 빚을 지우지
  않도록 별도 계약이 필요하다. 이 검토 항목 자체가 소비 허용을 뜻하지 않는다.
- 왕실의 벌집의 일벌을 허용하면, 벌집을 받은 아군이 팔찌를 사용해 남은 회복 기회를 포기하고
  공격력을 얻는다. 벌집 시전자가 다른 아군의 일벌을 대신 소비하는 효과는 아니다.
- 사용을 서둘러 낮은 단계의 공격력을 얻거나, 다음 단계에 필요한 스택을 더 모을 수 있다.
  정확한 재사용 대기시간, 버프 유지 중 재사용·갱신·중첩 규칙은 후속 결정이다.
