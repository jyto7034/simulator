## 무기 — 이름 미정

> 상태: 2026-09-07 단일 대상 마법 기본 공격과 피격 대상의 거미줄 이동 속도 20% 감소 합의 /
> 이름·피해량·사거리·공격 주기·둔화 지속 시간과 세부 판정 미정.

| 항목 | 값 |
| --- | --- |
| `range_role` | 원거리 |
| `weapon_archetype` | `Staff` |
| `deployment_affinity` | Platform 전용 |
| `block_capacity` | `0` |
| `damage_type` | Magic |
| `targeting_profile` | 사거리 안의 적 한 명, 선정 우선순위 open design |
| `air_capable` | open design |
| `interval_ms` | open design |
| `windup_ms` | open design |
| `delivery` | 단일 대상 마법 공격, exact 전달 방식 open design |

Platform에 배치하는 공격형 마법 Staff다. 기본 공격은 **적 한 명에게 Magic 피해**를 주고,
피격된 적에게 `거미줄` 효과를 부여해 **이동 속도를 20% 감소**시킨다.

- 거미줄은 기본 공격에 맞은 대상에게 부여하는 둔화 상태다. 전용 유물 [아직 남은 선물](../../relics/red-thread.md)의
  선물 표식·사망 생성과 구분한다. 이전 붉은 실타래의 연결 효과는 폐기했으며 무기의 둔화 효과는 유지한다.
- 둔화 지속 시간, 재부여 시 갱신·중첩 여부, 다른 이동 속도 감소와의 합성 및 면역·저항 판정은
  후속 설계에서 정한다.
- 작은·큰 마녀의 친구가 가하는 피해는 장착 무기의 공격력을 참조하며, 아래 방어구의 조건부
  공격력 증가도 친구 피해 계산에 포함한다. 기본 공격의 거미줄 부여를 친구 공격에 자동 상속하지 않는다.

정확한 피해량·사거리·공격 주기·대상 선정 우선순위·대공 여부와 공격 전달 방식은 미정이다.

<a id="frag-방어구--작은-마녀의-드레스-가칭"></a>
## 방어구 — 작은 마녀의 드레스 (가칭)

> 상태: 주변 아군 직원 존재 시 공격력 증가와 친구 피해 반영 구조 합의 /
> 이름·증가율·범위·기본 능력치 수치와 세부 판정 미정 / 현재 미구현

후방 Platform 딜러를 위한 공격형 방어구다. 기본 능력치는 최대 HP와 Magic 저항을 보조적으로
제공하며 정확한 값은 미정이다.

**고유 효과 — 친구와 함께**

- 착용자 주변 일정 범위에 **자신을 제외한 배치된 아군 직원이 한 명 이상 있으면 착용자의 공격력이
  증가**한다. 주변 아군 수가 늘어도 증가량은 중첩되지 않는다.
- 조건을 만족하는 직원이 범위에서 모두 사라지면 해제하고, 다시 조건을 만족하면 재적용한다.
  별도 지속 시간 누적이나 처치 스택을 만들지 않는다.
- 자기 자신, 작은·큰 마녀의 친구를 포함한 소환물과 일반 전장 object는 인원 조건에 포함하지 않는다.
  래티씨아 파편만으로 자동 충족하는 소환물 수 조건으로 바꾸지 않는다.
- 공격력 증가율의 초기 테스트 후보는 **20%**다. 정확한 증가율과 판정 범위는 후속 테스트에서
  확정하며, 아군의 배치 층·이동·철수·전투불능에 따른 거리 및 유효성 판정도 별도로 명시한다.
- 착용자의 Attack stat을 증가시켜 기본 공격과 그 공격력을 참조하는 스킬에 적용한다.
  주변 아군에게 공격력 버프를 나눠 주는 오라가 아니라 착용자 자신에게만 적용하는 조건부 강화다.
- 작은·큰 마녀의 친구 피해 계산에도 이 방어구로 증가한 공격력을 포함한다. 배치·진화·발동 중
  어느 시점의 공격력을 고정할지 또는 실시간으로 참조할지는 후속 판정에서 정한다.
- 전용 무기·파편을 요구하지 않는다. 다른 장비 조합에서도 아군과 가까이 배치하면 공격력 증가를
  얻을 수 있다. 소환물의 동시 배치 상한이나 공명 획득량을 방어구에서 직접 늘리지는 않는다.

액세서리가 친구를 더 자주 배치하도록 돕는다면 방어구는 친구 한 번의 공격을 더 강하게 만든다.
아군과 가까운 배치를 보상하되, 밀집 배치 시 적의 광역 공격에 여러 직원이 함께 노출되는 부담은
그대로 남긴다.

<a id="frag-액세서리--이름-미정-4"></a>
## 액세서리 — 이름 미정

착용자가 eligible source로부터 획득하는 공명량을 증가시킨다. 정확한 증가율, 적용할 공명 source와
소수점·상한 처리는 open design이다.

- 래티씨아 파편과 조합하면 공명 만충 주기를 단축해 작은·큰 친구를 더 자주 배치할 수 있다.
- 다른 active 파편을 장착해도 시전 주기를 앞당기는 독립적인 효용을 가진다.
- 공명 요구량을 낮추거나 공명을 직접 채우는 효과는 아니며, 소환물의 동시 배치 상한이나 피해량도
  직접 증가시키지 않는다.
- 소환물 동시 배치 상한 증가는 현재 플레이어 소환물이 사실상 래티씨아 계열뿐이므로 장비 효과에서
  제외한다. 필요하다면 래티씨아 계열 Run 유물의 전용 강화 후보로 다룬다.
