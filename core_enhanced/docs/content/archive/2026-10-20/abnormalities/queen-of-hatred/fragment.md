# 증오의 여왕 · 스킬 파편

[콘텐츠 위키](../../../../README.md) · [개요](../../../../abnormalities/queen-of-hatred/README.md) · [조우](../../../../abnormalities/queen-of-hatred/encounter.md) · [장비](../../../../abnormalities/queen-of-hatred/equipment.md) · [태그·유물](../../../../abnormalities/queen-of-hatred/synergies.md) · [검토 기록](../../../../abnormalities/queen-of-hatred/review.md)

> 콘텐츠 설계. 원문의 합의·초안·미정 구분을 유지한다. 구현 완료를 뜻하지 않는다.

<a id="frag-일반-광선--사랑의-이름으로-가칭"></a>
## 일반 광선 — 사랑의 이름으로! (가칭)

기본형·개화형 모두 타일을 지정해 그 방향으로 2초 동안 집중 광선을 발사한다. 발사 방향은 고정하고
0.5초마다 광선에 닿은 적에게 피해를 주며 아군을 회복한다. 적만 공격하거나 아군만 회복해도 유효하다.

- 끝까지 시전하면 하트 1개를 얻는다.
- 같은 시전에서 적에게 실제 피해를 주고 아군의 HP도 실제로 회복했다면 추가로 1개를 얻는다.
- 완주 보상과 동시 성공 보상은 각각 시전당 한 번이다. 여러 대상·여러 주기의 적중마다 더 얻지 않는다.
- 하트는 시전 완료 후 얻는다. 진행 중인 일반 광선이 하트 보상 때문에 갑자기 아군 공격으로 바뀌지 않는다.

<a id="frag-하트--전투-로컬-자원"></a>
## 하트 — 전투 로컬 자원

하트는 파편 사본에 귀속하며 최대 6개다. 후퇴·전투 종료·사망 시 초기화하고 전술 이동으로는
사라지지 않는다. 다음 전투까지 광선 횟수를 보존하던 이전 run-local 안을 대체한다.

- 광선 보상 외에 전장에 배치된 동안 15초마다 하트 1개를 자동 획득한다.
- 블랙홀로 하트를 소비하면 자동 획득 타이머도 초기화한다.
- 히스테릭 공격 중에는 자동 획득을 정지하고 정상 상태로 돌아오면 다시 시간을 센다.
- 새 전투의 타이머와 마지막 지정 타일 초기 상태는 후속 판정으로 남긴다. 하트 자체의 초기화는 확정이다.

<a id="frag-기본형-수동-블랙홀--증오의-중심-가칭"></a>
## 기본형 수동 블랙홀 — 증오의 중심 (가칭)

하트 3~5개에서 공명 만충이면 파편 메뉴로 다음 스킬을 광선 대신 블랙홀로 선택할 수 있다.
시전 확정 시 보유 하트를 전부 소비한다.

- 지정 타일에 2초간 블랙홀을 생성하고 0.5초마다 침식체 적을 중심으로 끌어당긴다.
- 한 번에 순간이동시키지 않고 여러 차례 당겨 모은다. 아군과 환상체는 끌어당기지 않는다.
- 범위에 닿은 아군에게 같은 주기로 회복을 준다.
- 소비한 하트가 많을수록 흡인 범위와 회복량이 증가한다. 유지 시간은 고정한다.
- 이 비히스테릭 기본형 블랙홀에 별도 적 피해나 하트 생성은 추가하지 않는다.

<a id="frag-개화형-수동-블랙홀과-빛기둥"></a>
## 개화형 수동 블랙홀과 빛기둥

개화형은 하트 0개여도 공명 만충이면 블랙홀을 선택할 수 있다. 0개에서는 기본 성능으로,
1~5개에서는 보유 하트를 전부 소비해 강화된 성능으로 시전한다.

1. 블랙홀이 2초간 침식체 적을 모으고 범위에 닿은 아군을 회복한다.
2. 블랙홀 중심에서 위로 솟구치는 거대한 빛기둥을 3초간 유지한다.
3. 빛기둥에 닿은 적에게 반복 피해, 아군에게 반복 회복을 준다. 피해량·회복량은 소비 하트에 비례한다.

전체가 하나의 집중 시전이다. 시전자에게서 중심을 향해 쏘는 빔으로 바꾸지 않는다. 환상체도
빛기둥 범위 안에서 피해를 받지만 흡인되지는 않는다. 이 연속 시전으로 하트를 다시 얻지 않는다.

<a id="frag-히스테릭--하트-6개에서-강제-자동-공격"></a>
## 히스테릭 — 하트 6개에서 강제 자동 공격

광선 완료 보상 또는 시간 경과로 하트 6개에 도달하면 히스테릭에 진입해 블랙홀과 후속 공격을
자동 시전한다. 발동을 미루거나 히스테릭 강화 상태로 머무를 수 없다. 이전의 파편 히스테릭·폭주
페널티 제외안은 이 리워크로 대체한다. 별도의 파편 침식형과는 다른 상태다.

| 항목 | 기본형 | 개화형 |
| --- | --- | --- |
| 순서 | 블랙홀 → 시전자에게서 블랙홀 중심을 향하는 강력한 광선 | 블랙홀 → 중심에서 위로 솟구치는 강력한 빛기둥 |
| 피해 | 블랙홀과 후속 공격 모두 아군·적군에게 피해 | 동일 |
| 회복 | 없음 | 없음 |
| 이동 | 침식체 적만 흡인. 아군과 환상체는 이동시키지 않음 | 동일 |
| 종료 | 하트를 전부 소진하고 정상 상태로 복귀 | 동일 |

아군은 피해만 받고 블랙홀로 이동하지 않는다. 환상체도 범위에 있으면 피해를 받지만 흡인되지 않는다.
추가 공명 소비와 중단 시 처리, 다른 시전 도중 자동 획득으로 6개가 되었을 때의 실행 순서는 미정이다.

<a id="frag-자동-시전-위치와-예고"></a>
## 자동 시전 위치와 예고

- 마지막 일반 광선에서 지정한 타일에 블랙홀을 만든다. 광선으로 6개가 되었다면 방금 지정한 타일,
  시간 경과로 6개가 되었다면 마지막으로 지정해 둔 타일을 사용한다.
- 고정 타일이며 선택했던 유닛의 이동·사망을 추적하지 않는다.
- 아직 광선을 사용하지 않았다면 시전자 타일을 중심으로 삼는다. 이때 기본형 광선은 현재 바라보는 방향이다.
- 예정 타일을 계속 표시하고, 광선 조준 시 6개 도달 가능성이 있으면 자동 공격 위험 범위를 함께 보여 준다.
- 하트 5개에서는 다음 자동 획득까지 남은 시간을 강조한다.

<a id="frag-회복과-태그의-경계"></a>
## 회복과 태그의 경계

파편의 회복은 히스테릭이 아닌 광선·블랙홀·빛기둥에 실제로 닿은 아군에게 해당 회복 주기에만
발생한다. 범위 밖 회복이나 히스테릭 회복은 없다. 무기·방어구 등 별도 출처의 효과를 파편의
자동 회복으로 합치지 않는다.

## 파편 후속 결정

- 수동 시전의 유효 대상 부재 처리, 자동 시전 추가 공명 소비와 다른 시전·중단과의 우선순위.
- 새 전투의 자동 획득 타이머·지정 타일 초기 상태와 checkpoint/Retreat 복원 처리. 후퇴 시 하트 초기화는 유지한다.
- 기본형 폭주 광선 지속 시간, 각 단계의 사거리·모양·피해·회복·흡인 거리와 하트별 증가식.
- 스택 획득 증폭으로 6개를 넘으면 6개로 제한해 한 번 발동하고 초과분을 넘기지 않는 안은 추천 상태다.
- 회복 후 버프 종류·판정과 겹친 외피의 구체적 연결 지점 등 위 7개 태그의 미정 세칙.
- 최종 희귀도·장착 제한·호환성·개화 재료·획득처. 2초·3초·0.5초·15초는 현재 작업 수치다.

<a id="frag-파편-침식형--이름-미정"></a>
## 파편 침식형 — 이름 미정

> 상태: 구조 합의 / 이름·수치·판정 미정

1. 하늘에서 작은 빛 하나가 내려온다
2. 빛이 바닥에 닿는 순간 화면이 암전된다
3. 엄청난 빛기둥이 생기며 **모든 적을 처형**한다

open design:

- 이름과 수치

판정과 대상 범위는 위 `침식형 공통 정책`이 소유한다.
