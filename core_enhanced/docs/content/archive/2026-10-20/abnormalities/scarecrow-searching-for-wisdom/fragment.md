<a id="frag-파편--지혜-수확-가칭"></a>
## 파편 — 지혜 수확 (가칭)

공명 만충에서 시전하면 다음 무기 기본 공격을 `헤드샷 준비` 상태로 강화한다. 그 강화 공격으로
적을 처치하면 `지혜 획득`을 얻어 착용자의 공격력이 **20~30% 증가**한다.

**다음 기본 공격 강화**

- 파편 시전은 정상적으로 공명을 소비하고 다음 기본 공격 1회에 사용할 강화를 준비한다.
  별도 저격 피해나 추가 탄환을 시전 즉시 생성하지 않는다.
- 다음 무기 기본 공격은 머리 또는 약점을 겨냥하는 강한 한 발이 된다. 공격의 피해를 높은 배율로
  강화하되, 정확한 배율과 다른 피해 modifier의 합성은 미정이다.
- 무기의 사거리·기본 표적 선택·피해 type·배치·저지 규칙을 따른다. 파편 때문에 직원이 이동하거나
  장착 무기가 아닌 별도의 저격총으로 공격하지 않는다.
- 준비 상태는 집중 채널이 아니다. 기본 공격 주기를 즉시 초기화하지 않고 다음 정상 공격에
  적용하는 안을 우선한다. 기존 windup 진행 중 시전했을 때의 적용 경계는 후속 판정에서 정한다.
- 강화는 해당 기본 공격의 release 때 소비하는 안이다. release 전 취소 시 준비 상태를 보존하고,
  release 뒤 탄환이 빗나가도 공명이나 준비 상태를 환불하지 않는 안을 기준으로 한다.
- 머리를 직접 클릭하거나 별도 머리 hitbox를 맞히는 조작은 요구하지 않는다. 머리가 없는 대상은
  눈·핵 등 약점을 노리는 연출로 표현한다. 헤드샷은 강한 피해의 표현이며 강제 처형이나 별도
  치명타 시스템을 암묵적으로 도입하는 효과가 아니다.

**강화 공격 처치 보상 — 지혜 획득**

- 이 파편으로 강화된 기본 공격의 직접 피해가 적의 처치를 확정하면 착용자에게 공격력 증가를 준다.
  일반 평타 처치·아군의 마무리·단순 어시스트만으로는 발동하지 않는다.
- 공격력 증가율은 `20~30%` 범위로 정하고 exact 값은 후속 수치 설계에서 선택한다. 처치마다
  이 범위에서 무작위로 수치를 뽑는 효과는 아니다.
- 강화 공격은 기본 공격이라는 성격을 유지하면서 파편 강화의 출처를 보존해야 한다. 이 파편의
  처치 보상 판정에서는 인정하되, 모든 시스템에서 일반 스킬 피해로 재분류하거나 기본 공격·스킬
  피해를 각각 한 번씩 중복 처리하지 않는다.
- 공격력 증가는 단순한 기본 공격 추가 피해가 아니라 착용자의 Attack stat 증가다. 이후 기본
  공격과 해당 공격력을 참조하는 스킬에 적용하며, 이미 처치를 만든 공격의 피해를 소급해서 늘리지 않는다.
- 버프 지속 시간과 중첩 정책은 미정이다. 앞서 제안한 `일정 시간 유지 / 수치 중첩 없이 재획득 시
  지속 시간 갱신`을 우선 후보로 두며, 영구 성장이나 처치당 +20~30% 무한 누적을 확정한 것은 아니다.
- 처치에 실패해도 강화 공격의 피해는 정상 적용되며, 처치 보상만 얻지 못한다. 회복·공명 환불·
  추가 강화탄 장전은 기본 보상에 포함하지 않는다.
- 다단 무기·액세서리 범위화로 여러 적을 처치할 때의 집계, 부가 피해·지속 피해·연쇄 피해의
  포함 여부는 후속 판정에서 정한다. 한 강화 공격에서 여러 적을 처치해도 버프는 한 번만 부여하는
  안을 우선한다.

현재 룰북의 active 결과로 표현하는 기본 공격 강화 방향을 따른다. 구현 시에는 준비 상태의 소유권·
소비 시점과 기본 공격에 남는 파편 출처를 명시해야 하며, 기존 장착 즉시 passive 평타 강화와 구분한다.
