# 지혜를 구하는 허수아비 · 장비

[콘텐츠 위키](../../../../README.md) · [개요](../../../../abnormalities/scarecrow-searching-for-wisdom/README.md) · [조우](../../../../abnormalities/scarecrow-searching-for-wisdom/encounter.md) · [파편](../../../../abnormalities/scarecrow-searching-for-wisdom/fragment.md) · [검토 기록](../../../../abnormalities/scarecrow-searching-for-wisdom/review.md)

> 콘텐츠 설계. 원문의 합의·초안·미정 구분을 유지한다. 구현 완료를 뜻하지 않는다.

## 무기 — 수확 (가칭)

> 저격총 외형과 원거리 단일 딜러 방향 합의. Gun·Physical·Platform·저지 0 등 세부 profile은 후보안이다.

| 항목 | 값 |
| --- | --- |
| `range_role` | 장거리 단일 딜러 |
| `weapon_archetype` | `Gun` 후보 |
| `deployment_affinity` | Platform 전용 후보 |
| `block_capacity` | `0` 후보 |
| `ground_defense_focus` | Platform 전용 채택 시 해당 없음 |
| `platform_rest` | open design |
| `damage_type` | Physical 후보 |
| `targeting_profile` | open design |
| `air_capable` | open design |
| `interval_ms` | 느린 주기·높은 단발 위력 후보, exact open design |
| `windup_ms` | 조준 동작, exact open design |
| `delivery` | 적 하나를 겨냥하는 저격 탄환 |

- 짚과 낡은 천, 책의 문양 등으로 허수아비의 모티프를 표현하는 긴 총신의 저격총이다.
  외형의 세부 장식은 미정이다.
- 무기만으로도 원거리 단일 공격을 수행한다. 헤드샷 준비와 처치 후 공격력 보상은 파편이 소유하며,
  모든 평타가 자동으로 이 파편의 처치 보상을 발생시키지는 않는다.
- 파편이 다른 호환 무기에도 장착 가능하도록 확정되면, 그 무기의 다음 기본 공격을 강화한다.
  저격총 외의 무기까지 강제로 단일 저격 탄환으로 교체하는 기능은 아니다.

<a id="frag-방어구--짚으로-엮은-외투-가칭"></a>
## 방어구 — 짚으로 엮은 외투 (가칭)

> 상태: 비피격 충전과 다음 HP 피해 1회 감소 구조 확정 / 이름·수치·세부 판정 미정

안전하게 자리 잡은 저격수가 갑작스러운 피해 한 번을 버티도록 돕는 방어구다. 기본 능력치는
최대 HP와 물리 방어력으로 구성하며, 정확한 값은 미정이다.

**고유 효과 — 짚 완충**

- 배치된 상태에서 일정 시간 실제 HP 피해를 받지 않으면 `짚 완충` 1회를 준비한다. 준비된 동안
  다음 HP 피해 1회의 피해량을 줄이고 소모한다. 시간 경과로 여러 회분이 쌓이지 않는다.
- 초기 테스트 후보는 **비피격 5초 / 다음 피해 1회 40% 감소**다. 확정 밸런스 수치는 아니다.
- 배치 직후에는 준비되지 않은 상태로 시작한다. 실제 HP 피해를 받으면 비피격 시간을 처음부터
  다시 세며, 이후 조건을 충족하면 다시 준비된다. 준비 후 공격하거나 스킬을 사용해도 유지된다.
- 무적이나 보호막으로 HP 손실이 전부 막힌 피해는 준비를 소모하거나 시간을 초기화하지 않는다.
  방어구 적용 전 HP 손실이 발생할 피해를 기준으로 소모를 결정하며, 지속 피해도 해당하면 소모한다.
  다단 공격 전체를 하나로 막는 효과가 아니라, 먼저 들어오는 eligible 피해 1건에만 적용한다.
- HP 비용·최대 HP 희생·직접 처형은 감면하지 않는다. 자체 회복·무적·HP 1 생존 보장은 없으며,
  감면한 피해로도 HP가 0이 될 수 있다. 다른 피해 감소와 보호막의 정확한 계산 순서는 후속 판정한다.
- 전투 종료·철수·전투불능 때 준비와 경과 시간을 초기화한다. 시간은 battle time으로 계산하므로
  Pause 중에는 쌓이지 않는다. 허수아비 파편이나 저격총을 요구하지 않는다.

지속해서 맞는 전열 탱커보다 간헐적으로 공격받는 후방 딜러·힐러에게 잘 맞는다. 피해 뒤 HP를
회복하는 미미크리 방어구와 달리, 다음 피해 한 번의 위력을 줄이는 역할이다.

<a id="frag-액세서리--여물지-않은-지혜-가칭"></a>
## 액세서리 — 여물지 않은 지혜 (가칭)

> 상태: 기본 공격 사이 경과 시간에 비례한 다음 기본 공격 1회 강화 구조 확정 / 이름·수치·세부 판정 미정

**마지막 기본 공격 이후 지난 시간에 비례하여 다음 기본 공격 1회의 피해가 증가**한다.
빠르게 연사하기보다 긴 사격 간격을 묵직한 한 발로 바꾸는 액세서리다.

- 초기 테스트 후보는 **기본 공격 사이 1초당 피해 +10%, 최대 +50%**다. 예를 들어 3초 뒤 쏘는
  다음 기본 공격은 +30%, 5초 이상 뒤 쏘면 +50%를 받는다. 확정 밸런스 수치는 아니다.
- 배치 시 경과 시간은 0에서 시작한다. 이후 각 기본 공격의 release 직전까지 지난 battle time으로
  강화량을 정하고, 그 공격에 강화량을 고정한 뒤 시간을 0으로 초기화한다. 명중 시각이 기준은 아니다.
- 공격 대기와 조준 동작 동안에도 시간이 흐른다. 공격을 일부러 중단해야 하는 별도 행동은 없으며,
  무기의 기본 공격 주기나 표적 선택을 바꾸거나 첫 공격을 강제로 늦추지 않는다.
- release 전 취소는 시간을 초기화하지 않는다. release 뒤 빗나가거나 대상이 사라져도 이미 쓴
  강화량은 환불하지 않는다. 강화 예약을 여러 발 쌓거나 최대치를 넘는 시간을 이월하지 않는다.
- 피해 type은 원래 기본 공격을 따른다. Attack stat 자체를 늘리지 않으며, 별도 스킬 피해·반사·
  지속 피해·소환물 공격에는 적용하지 않는다. 스킬 사용 자체는 이 기본 공격 간격을 초기화하지 않는다.
- 허수아비 파편으로 강화한 기본 공격에도 함께 적용한다. 액세서리는 그 한 발의 피해 계산에만
  참여하고 별도 추가 타격을 만들지 않으므로, 처치 시 파편의 지혜 획득 조건을 그대로 사용할 수 있다.
- 다른 무기의 기본 공격에도 사용할 수 있다. 다단·범위 기본 공격에서 1회 강화가 포함할 피해 묶음과
  다른 평타 강화 배율의 합성 순서는 후속 판정한다. 타격·대상마다 시간을 별도로 재충전하지 않는다.
- 전투 종료·철수·전투불능 때 시간을 초기화하고, 미배치 상태와 Pause 중에는 시간이 쌓이지 않는다.
  현재 강화량과 최대치 도달 여부는 UI에서 확인할 수 있게 한다.

샤덴프로이데 액세서리는 끊기지 않는 연속 공격으로 Attack stat을 키우고, 이 액세서리는 매 기본
공격 사이의 시간으로 다음 한 번의 피해를 키운다. 처치가 없어도 작동하므로 보스전에서도 사용할 수
있으며, 허수아비 파편의 처치 후 Attack 증가 효과를 장비에 중복해서 넣지 않는다.

두 장비의 기본 효과 구조는 사용자 확인을 받아 확정했다. 위 테스트 후보 수치와 세부 판정까지
확정한 것은 아니다. 비피격 충전과 수신 피해 감면, 기본 공격 release 시점의 강화량 고정은
구현 시 별도 명시가 필요하다. 현재 룰북의
`OnAttack`·`OnHit`는 기본 공격의 확정 hit occurrence이므로 이를 release나 모든 HP 피해 사건으로
암묵적으로 확대하지 않는다. 이번 기록은 문서 설계이며 runtime·data 구현은 포함하지 않는다.
