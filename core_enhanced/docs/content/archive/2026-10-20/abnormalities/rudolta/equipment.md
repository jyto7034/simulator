## 무기 — 선물 배송기 (가칭)

> 유탄발사기 외형·기본 단일 피해·액세서리 조합 시 범위 피해 전환은 합의.
> 기존 Bow 초안은 대체하며, Gun 분류·Physical 피해·배치·대공 등 세부 profile은 아래 후보안이다.

| 항목 | 값 |
| --- | --- |
| `range_role` | 원거리 단일 물리 딜러 |
| `weapon_archetype` | `Gun` 후보 |
| `deployment_affinity` | Platform 전용 후보 |
| `block_capacity` | `0` 후보 |
| `ground_defense_focus` | Platform 전용 채택 시 해당 없음 |
| `platform_rest` | open design |
| `damage_type` | Physical 초안 |
| `targeting_profile` | 사거리 내 공중 적 우선, 없으면 Route 진행도가 가장 높은 지상 적 초안 |
| `air_capable` | 가능 초안 |
| `interval_ms` | open design |
| `windup_ms` | open design |
| `delivery` | 주 대상에게 단일 피해를 주는 유탄 projectile |

- 선물 모양 유탄을 발사하는 유탄발사기다. 리본·방울 등 외형 장식은 미정이며, 새 무기 분류를
  만들지 않고 기존 `Gun`에 배정하는 안이다.
- 무기만 장착했을 때는 유탄 한 발이 적 하나에게만 피해를 준다. 연출상 유탄이 터지더라도
  주변 적에게 피해를 주는 범위 판정은 기본 무기에 없다.
- `커다란 선물자루`를 장착하면 단일 피해가 적중 지점 중심의 범위 피해로 전환된다. 범위화의
  source는 액세서리이며, 파편을 시전하지 않아도 적용된다.
- 대공 가능·공중 적 우선은 세부 후보로 유지한다. 공중 우선은 표적 선택 규칙이며 별도의 공중
  피해 보너스를 암묵적으로 제공하지 않는다.
- 단일 적을 공격하는 기본 주기와 범위 폭격의 투하 주기는 독립적이다. 파편을 교체하거나 폭격이
  끝나도 유탄 발사가 유지되며, 파편이 켜졌다는 이유만으로 유탄이 범위 공격으로 변하지 않는다.
- 풍운승려의 염주 Staff나 탐욕의 왕의 타일 폭격 Bow와 달리, 무기 자체는 단일 피해이고
  액세서리 조합이 기본 공격의 범위화를 담당한다.

<a id="frag-방어구--배달부의-외투-가칭"></a>
## 방어구 — 배달부의 외투 (가칭)

> 상태: 최대 HP·Magic 저항과 active 파편 시전 후 한시적 기본 공격 속도 증가 구조 합의 /
> 정확한 수치·지속 시간·발동 시점과 세부 판정 미정 / 현재 미구현

최대 HP와 Magic 저항을 기본 능력치로 제공하고, **active 파편을 시전하면 일정 시간 기본 공격
속도가 증가**하는 공격 보조 방어구로 정한다. 기본 능력치·공속 증가율·지속 시간은 미정이다.

- 정상적인 active 파편 시전 한 번에 한 번 발동한다. 거부된 시전 요청이나 이미 진행 중인 파편의
  추가 타격·폭격·주기적 효과는 새 발동으로 인정하지 않는다.
- 공속 증가는 무기의 기본 공격 주기에 적용한다. 파편 시전 시간, 선물 투하 간격·횟수·폭발 지연과
  공명 획득량 자체를 직접 증폭하지 않는다.
- 재발동 시 증가율을 중첩하지 않고 지속 시간을 갱신하는 안이다. 다른 active 파편을 사용해도
  효과가 발동하므로 전용 폭격이나 Gun 장착을 요구하지 않는다.
- 현재 룰북의 장비 trigger 목록에는 파편 시전 전용 occurrence가 없으므로, 구현 전 시전 시작과
  release 중 어느 시점에 발동할지 및 전용 이벤트·authoring 경로를 정해야 한다. `OnAttack`을
  폭격 적중으로 재해석해 이 효과를 구현하지 않는다.

전용 조합에서는 하늘에서 선물이 떨어지는 동안 착용자가 더 빠르게 유탄을 발사한다. 폭격의
투하 주기를 공속으로 이중 증폭하지 않으며, 액세서리까지 장착하면 범위 유탄의 발사 주기가 빨라진다.

<a id="frag-액세서리--커다란-선물자루-가칭"></a>
## 액세서리 — 커다란 선물자루 (가칭)

**폭발 효과 증가: 단일 피해는 범위 피해로 바꾸고, 범위 피해는 더 큰 범위 피해로 확대**한다.
이 두 갈래의 기본 효과는 합의하며, 초기 범위·확대량·세부 적용 판정은 미정이다.

- 단일 피해 공격은 주 대상의 적중 지점을 중심으로 폭발 범위를 갖는다. 유탄발사기의 기본 공격은
  이 효과로 주 대상과 주변 적에게 피해를 주는 공격이 된다.
- 이미 범위 피해인 공격은 기존 피해 범위를 넓힌다. 루돌타 파편의 선물 폭격은 이 갈래를 적용한다.
- 기존에 폭발 범위가 있는 공격에만 한정하지 않는다. 착용자의 다른 무기·파편도 단일 피해의
  범위화 또는 범위 피해 확대를 받을 수 있으며, 정확한 eligible 피해 source는 후속 판정에서 정한다.

**판정 정리 — 세부 초안**

- 같은 원천 피해 판정에는 액세서리를 한 번만 적용한다. 단일 공격을 범위화한 결과에 다시 범위
  확대를 적용하거나, 새로 맞은 주변 적마다 또 폭발을 만드는 재귀 효과는 두지 않는다.
- 단일 피해와 별도의 폭발 피해를 주 대상에게 겹쳐 주는 방식이 아니라 피해 대상 범위를 변환한다.
  주 대상은 원래의 1회 피해를 유지하며, 주변 피해의 계수·감쇠·대상 상한은 미정이다.
- 기존 범위 확대는 범위를 늘릴 뿐 같은 대상의 피해량·적중 횟수를 자동으로 증가시키지 않는다.
  피해 type은 원래 공격을 따르며, 폭발 연출만으로 Physical 또는 True로 바꾸지 않는다.
- 선물을 투하할 적을 찾는 탐색 구역이나 무기·파편의 사거리는 늘리지 않는다. 회복·보호막·지원
  aura·시야·소환 범위도 확대하지 않는다. 피해 외 상태 이상이나 처형 효과를 주변에 자동 복제하지 않는다.
- 최초 범위, 기존 범위의 확대량, 타일 기반 반경·직선 폭 등 형태별 확장, 피해 범위 snapshot과
  projectile 적중·빗나감, 다단·지속 피해 및 공명·장비 trigger 판정은 후속 설계에서 정한다.
