## 기본형 — 창 배치와 궤적 지정

> 상태: 창 획득·배치, 정밀·집중 사격, 전체 동시 발사, 강화탄 2초 속박 합의 / 수치·세부 판정 미정 / 개화형 보류

시간으로 일반 창을 모으고 별도로 출현하는 늑대를 사냥해 강화 창을 얻는다. 시전 시 전투를 멈추고
창을 떨어뜨릴 타일과 사격 궤적을 정한다. 모든 입력을 확정하면 전투를 재개하고 각 창 위치에서
총알을 동시에 발사하는 관통 사격 파편이다.

### 일반 창과 강화 창 획득

- 시간이 지나면 일반 창을 하나씩 획득한다. 획득 주기는 미정이다.
- 전장에 늑대 형태의 별도 적이 주기적으로 출현한다. 기존 적에게 표식만 붙이는 방식이 아니다.
- 해당 늑대를 처치하면 강화 창을 획득한다. 기본 획득량은 1개다.
- 늑대는 두건 계열 파편 또는 무기에서 나온 피해를 50% 더 받는다. 해당 출처에 한정된 약점이며,
  단순히 두건 장비를 착용했다는 이유로 그 직원의 모든 피해를 증가시키는 효과는 아니다.
- 일반 창과 강화 창은 종류를 구별해 보유·소비한다. 보유 단계에서 맵의 고정 앵커를 점유하지 않는다.
- 창 획득과 늑대 출현의 시간은 전투 진행을 따른다. 배치·조준으로 전투가 정지된 동안에는 진행하지 않는다.
- 보유 상한, 일반·강화 창의 상한 공유 여부, 가득 찼을 때 강화 창 보상 처리, 늑대 처치자의 인정 범위는 미정이다.

이전의 무작위 현상금 표식, 착용자의 다른 적 처치 시 25% 생성, 맵별 고정 창 앵커 방식은 이
획득·배치 설계로 대체한다. 이전 상한 5개를 새 구조의 확정값으로 자동 계승하지 않는다.
파편의 사냥감 늑대와 장비 액세서리의 현상금 노드, 보스 조우의 늑대 계약은 별도 기능이다.

### 파편 메뉴와 창 배치

| 메뉴 | 선택 |
| --- | --- |
| 사격 방식 | 정밀 사격 / 집중 사격 |
| 이전 타일 위치 재사용 | 켜기 / 끄기 |

1. Core가 스킬 준비를 시작하면서 전투를 일시정지하고, 현재 보유한 일반·강화 창 수를 기준으로 배치를 준비한다.
2. 직접 선택할 때는 보유한 창 수만큼 타일을 지정한다. 마우스 좌클릭은 일반 창, 우클릭은 강화 창이다.
3. 재사용 스위치를 켜면 마지막으로 지정한 창 배치를 사용한다. 재사용 대상은 배치이며 사격 방향은 다시 입력한다.
4. 배치가 끝나면 지정한 타일에 하늘에서 창이 내려꽂힌다. 일반 창은 창만 떨어지고, 강화 창은 늑대를 꿰뚫은 모습으로 떨어진다.

배치 순서는 정밀 사격의 조준 순서다. 재사용 시 창 수·종류가 달라졌거나 타일이 무효가 된 경우의
보정·재선택 방식, 배치 가능 범위와 중복 타일 허용 여부는 후속 설계한다. 현재 합의는 기존처럼
맵에 개별 발사 앵커를 미리 배치하는 방식이 아니라 플레이어가 유효 타일을 선택하는 방식이다.

### 정밀 사격

1. 파편 장착 유닛의 화면상 모습이 사라지고, 두건의 형상이 지정 순서대로 창 위치에 나타난다.
2. 현재 창 위치에서 시작하는 직선 사격 궤적이 마우스 커서를 따라 움직인다.
3. 좌클릭하면 해당 궤적을 저장하고 다음 창으로 넘어간다. 이 입력으로 실제 총알이나 피해가 발생하지 않는다.
4. 모든 창의 궤적을 정하면 전체 발사 입력이 완성된다.

두건의 순간이동은 조준 연출이다. 직원 runtime의 실제 배치·점유·저지 위치를 이동시키지 않는다.
창 선택 순서를 무작위로 만드는 이전 방식과, 조준할 때마다 한 발씩 실제로 쏘는 방식은 사용하지 않는다.

### 집중 사격

배치 후 유효한 목표 타일 하나를 지정한다. 모든 창에서 그 타일 중심을 향하는 궤적을 한 번에
결정한다. 일반·강화 창의 효과는 정밀 사격과 같으며 조준 절차만 다르다.

### 발사 확정과 전투 재개

Unity는 창별 위치·일반/강화 구분·사격 방향을 한 묶음으로 전달한다. Core는 전체 입력과 보유량을
검증한 뒤 창·공명 소비, 모든 탄환의 발사 확정, 전투 재개를 하나의 처리로 확정하는 방향이다.
집중 사격의 방향은 각 창 위치와 공통 목표 타일에서 계산한다.

**정밀 사격과 집중 사격 모두 모든 궤적을 정한 뒤, 전투 재개 시 모든 창에서 동시에 발사한다.**
총알은 지정 타일을 출발점으로 삼아 정한 방향으로 빠르게 진행하며 적을 관통한다. 피해와 충돌은
재개된 전투에서 처리한다. 정지 상태에서 피해만 별도로 해결하거나, 정밀 사격을 순차 발사로 바꾸지 않는다.
동시 발사와 동시 적중은 구별하며, 여러 탄환이 같은 적을 맞히면 각 탄환의 판정을 유지한다.

| 탄환 | 기본 효과 | 연출 |
| --- | --- | --- |
| 일반탄 | 단순 관통 피해 | 창 위치에서 발사되는 탄환 |
| 강화탄 | 일반탄보다 강력한 관통 피해와 적중 대상의 2초 속박 | 적에게 창이 꽂히는 모습과 함께 속박 |

강화탄의 속박과 직접 피해는 별도 효과다. 피해량·피해 유형·속도·폭·길이·관통 한도·장애물·공중
판정은 미정이다. 속박 재부여와 제어 저항·면역 처리는 후속 정의하며, 추가 강화탄마다 0.5초씩
늘려 최대 4초로 만드는 앞선 추천 수치는 채택하지 않았다.

### 중단·복구와 구현 경계

- 발사 확정 전 연결이 끊기면 임시 배치·조준을 폐기하고, Core가 전투를 정지한 시점의 상태로 돌아간다.
  진행 중인 모든 궤적과 연출을 완벽히 복원하지 않는다. 창·공명은 발사 확정 전 소비하지 않는다.
- 연결 중단으로 준비를 취소한 뒤에도 전투는 정지 상태를 유지한다. 재접속 후 다시 준비할 수 있다.
- Core가 이미 발사를 확정한 뒤 응답만 유실된 경우에는 확정된 소비와 발사를 되돌리지 않는다.
- 프로세스 종료로 진행 중인 전투 상태가 소실되면 노드 진입 전 저장 경계로 복귀하는 방침이다.
- 일반 취소 입력, 발사 확정과 재전송의 식별 규칙, 전투 종료·소유자 이탈 시 정리는 후속 세부 계약이다.

현재 구조에 공통 다중 위치·방향 입력과 임의 원점 발사 기능을 확장하는 구현 방향이다. Core 판정과
Unity 표현을 분리하고 외부 콘텐츠 조립에 사용할 공통 기능으로 검토한다. 이 문서는 해당 기능의
구현·테스트 완료 또는 정식 schema 등록을 선언하지 않는다.

### 태그와 유물

기본 효과는 `피해·투사체·관통`, 강화탄의 속박은 `제어·지속시간`, 일반·강화 창 보유량은 각각
`스택`으로 분류한다. 개별 적용 지점과 범용 유물 연결 3개는 [태그·유물 연결](../../../../abnormalities/little-red/synergies.md)이 소유한다.

전용 유물 후보는 [관통상](../../../../relics/little-red-puncture-wound.md),
[슬러그탄](../../../../relics/little-red-slug-round.md), [소이탄](../../../../relics/little-red-incendiary-round.md)이다.
유물 효과를 파편의 기본 탄환에 상시 포함하지 않는다.

<a id="frag-파편-개화형--선불-계약-가칭"></a>
## 개화형 — 보류

2026-10-19 사용자 결정으로 개화형 검토는 보류한다. 이전 선불 계약과 추격·도끼 마무리 제안,
후속 사냥터 제안을 현재 개화형으로 채택하지 않는다. 관련 대조는 [아카이브](../../../../abnormalities/little-red/review.md)에서 확인한다.

## 남은 설계

- 파편·스킬의 최종 이름, 등급, 호환 범위, 중복 장착과 여러 착용자 간 사냥감·보상의 소유권.
- 창 획득 주기·보유 상한, 늑대 출현 주기·위치·능력치·행동·퇴장·처치 보상·전투 종료 판정.
- 창이 0개인 경우의 사용 가능 여부, 배치 제약, 재사용 실패·부분 수정·취소 조작.
- 탄환 피해·기하·충돌과 속박 재부여·저항, 전투 재개 후 본체·효과 정리.
- 세 전용 유물의 세부 판정과 수치. 관통상 5스택·6초 등 추천값은 아직 확정값이 아니다.
