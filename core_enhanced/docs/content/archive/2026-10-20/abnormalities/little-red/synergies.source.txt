## 기본 효과의 태그

태그는 개별 효과에 붙인다. 파편의 여러 효과를 합쳐 하나의 효과가 모든 조건을 만족한다고 판단하지 않는다.

| 효과 | 태그 | 적용 범위 |
| --- | --- | --- |
| 일반탄 직접 피해 | 피해 · 투사체 · 관통 | 발사된 일반탄의 관통 피해 |
| 강화탄 직접 피해 | 피해 · 투사체 · 관통 | 일반탄보다 강한 관통 피해 |
| 강화탄 속박 | 제어 · 지속시간 | 적중 대상에게 부여하는 2초 속박 |
| 일반 창 보유 | 스택 | 시간 획득과 발사 시 소비 |
| 강화 창 보유 | 스택 | 늑대 처치 획득과 발사 시 소비 |

늑대의 두건 계열 파편·무기 피해 +50%는 해당 적의 조건부 받는피해증가다. 파편이 모든 적에게
부여하는 기본 약화 효과로 합치지 않는다. 보유 스택도 일반 창과 강화 창의 종류를 구분한다.

## 합의한 범용 유물 연결 3개

기본 분류 태그와 별개로 아래 세 연결만 선택했다. 유물을 적용할 때 해당 효과가 발생하며, 다른
범용 연결을 태그 보유만으로 이번 합의 목록에 추가하지 않는다.

| 유물 | 대상 태그 | 변경 규칙 | 적용 지점·조건 | 남은 판정 |
| --- | --- | --- | --- | --- |
| [깨진 균형](../../relics/broken-balance.md) | `제어` | 강력한 군중제어 대상에게 5초간 받는 피해 증가 | 슬러그탄 유물의 기절. 기본 강화탄의 속박에 자동 연결하지 않음 | 각 상세 본문의 미정·초안 유지 |
| [두 겹의 수확](../../relics/double-harvest.md) | `스택획득` | 자신이 획득하는 해당 스택량 2배 | 늑대 처치로 얻는 강화 창 1개 → 2개. 시간으로 얻는 일반 창은 이번 연결 대상이 아님 | 각 상세 본문의 미정·초안 유지 |
| [깊은 각인](../../relics/deep-imprint.md) | `스택부여` | 다른 대상에게 부여하는 해당 스택량 2배 | 관통상 유물의 적중당 관통상 1스택 → 2스택. 스택당 30% 수치는 그대로 | 각 상세 본문의 미정·초안 유지 |

깨진 균형의 받는 피해 증가와 관통상은 각각 별도 유물 출처 상태다. 증가율 합산·중첩과 동일 시점
적중의 순서는 공통 정책과 개별 미정 판정을 따른다. 슬러그탄의 기절 발생 시점·지속시간도 미정이다.

## 전용 유물 후보의 효과 태그

| 유물 후보 | 효과 태그 | 출처와 조건 |
| --- | --- | --- |
| [관통상](../../relics/little-red-puncture-wound.md) | 받는피해증가 · 스택 | 탄환 적중으로 적에게 부여하는 누적 디버프. 보유 창 스택과 별개 |
| [슬러그탄](../../relics/little-red-slug-round.md) | 제어 / 피해 · 투사체 · 관통 | 밀어내기·기절과 막힘 후 관통 피해를 구분. 관통 조건의 최신 결합 판정은 상세 미정 |
| [소이탄](../../relics/little-red-incendiary-round.md) | 피해 · 범위 · 폭발 | 탄환이 적을 관통할 때 발생하는 별도의 폭발 피해 |

관통상의 유지시간이 정해지면 해당 상태의 지속시간 태그를 검토한다. 소이탄은 현재 폭발이며
화상·지속피해를 자동 추가하지 않는다. 태그를 실제 source 판정이나 runtime 지원 등록으로 대신하지 않는다.

## 이번에 추가하지 않는 연결과 분류

- 정밀·집중 사격 모두 전체 동시 발사다. 조준 순서나 탄환 도착 시간의 차이를 근거로 다중타격·깊은 쐐기를 자동 연결하지 않는다.
- 배치·조준은 입력 준비다. 집중유지·지연발동으로 분류하지 않는다.
- 창 낙하·두건 잔상은 현재 사격 준비·전달 연출이다. 소환물·지속영역으로 자동 분류하지 않는다.
- 발사한 탄환이 대상 사망 후 다른 적을 재지정하는 다음. 효과는 없다.
- 밑 빠진 잔, 넓어진 지평, 긴 호흡, 무아지경 등의 추가 연결은 이번에 선택하지 않았다.
- 개화형은 보류이며, 미채택 사냥터의 설치·반복 사격 태그를 기본형에 붙이지 않는다.
