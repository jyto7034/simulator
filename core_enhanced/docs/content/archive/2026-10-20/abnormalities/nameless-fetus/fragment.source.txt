## 파편 — 멈추지 않는 울음 (가칭)

아래 작동 방식은 **유물 없는 기본 파편**을 기준으로 한다. 단일 전환 범용 유물의 단일 지원 전환과
침식된 유물의 강화는 아래 수치 절과 연결된 유물 문서에서 별도로 정의한다.

공명이 가득 차면 착용자가 울음을 터뜨리고 `울음 집중`에 들어간다. 집중이 유지되는 동안 시전자
중심의 authored 원형 범위가 지속되고, 그 안의 active player 직원에게만 `불안정한 박동`이 활성화된다.
울음 자체는 적에게 피해나 상태를 적용하지 않는다.

`울음 집중`은 `player_unit`/`player_tile` 선택에 사용하는 tactical focus가 아니라, 스킬이 성공적으로
시작된 뒤 시전자가 유지하는 battle-time `channel/focus` action이다. `cast_selection: self`이므로 별도
대상 선택 단계나 감속된 targeting focus를 열지 않는다.

- `불안정한 박동`은 regular 기본 공격의 공격 속도와 피해를 증가시킨다. 직원의 범용 Attack stat을
  바꾸지 않으므로 active 파편, 장비 proc, persistent area와 소환물의 피해는 증가시키지 않는다.
- 공격 속도 증가는 active 파편의 시전 속도·공명 획득량, 장비 trigger, Field Work, Platform Rest와
  전술 포인트 자연 회복을 가속하지 않는다.
- 시전자 자신은 집중 때문에 기본 공격할 수 없으므로 박동의 대상에서 제외한다. Guest, defense
  object와 소환물도 대상에서 제외한다.
- 박동은 남은 지속 시간을 가진 독립 buff가 아니라 집중과 범위에서 파생되는 aura다. 집중 중 새로
  배치·재배치하거나 범위 안으로 들어온 직원에게 활성화되고, 범위를 벗어나거나 철수하면 즉시
  비활성화된다.
- 박동이 활성화되어도 이미 시작한 기본 공격 windup을 즉시 완료하거나 release 시점을 소급하지
  않는다. 활성화 뒤 새로 시작하는 regular 기본 공격부터 빨라진 주기를 사용한다.
- 여러 source의 박동 범위가 겹쳐도 기본 공격 피해·속도 증가 수치를 중첩하지 않는다.
- 범위 안에 박동을 받을 수 있고 regular 기본 공격이 가능한 다른 직원이 한 명 이상 있어야 유용한
  시전이다. 시전자 혼자만 배치된 상태에서는 시작할 수 없다.

집중 중 시전자는 action을 점유하므로 아래 행동을 할 수 없다.

- regular 기본 공격과 다른 automatic/manual skill 시작
- Attack/Defense 태세 전환
- 전술 이동과 자리 교대 참여
- Field Work assignment 시작과 그 밖에 새 action lock을 요구하는 직접 행동

시전자는 집중 중에도 배치 타일과 allied occupancy를 유지하고 적의 target과 피해 대상이 된다.
Passive/reactive 장비 trigger, 이미 release된 projectile·persistent area와 자신에게 적용된 buff/debuff는
각자의 기존 lifecycle을 계속한다. 무기가 저지 수를 가진 경우 기존 block을 유지할지 집중 시작과 함께
해제할지는 open design이다.

집중은 아래 원인 중 하나가 확정되면 즉시 중단된다.

- 플레이어의 명시적 `시전 중지` 입력
- Hard CC 또는 별도의 authored interrupt effect
- 자발적 철수, 강제 이동, 전투불능과 사망
- 전투 종료 또는 Retreat

일반 HP 피해만으로는 중단하지 않는다. Silence는 공통 규칙대로 집중 시작을 막지만 이미 시작된 집중을
중단하지 않는다. Pause는 집중과 박동을 제거하지 않고 battle clock과 함께 그대로 동결한다.

집중 종료와 박동 제거는 같은 state transition에서 처리한다. 집중 종료 자체는 별도 recovery lock을
남기지 않으므로 시전자는 다시 새 기본 행동을 시작할 수 있다. 단, 집중을 끊은 Hard CC나 다른 행동
제한이 아직 남아 있다면 그 효과가 허용할 때까지 해당 행동은 계속 금지된다. 집중 전에 중단했거나
집중 중 실행하지 못한 기본 공격을 즉시 발사하거나 catch-up하지 않고 새 windup부터 시작한다. 이미
release된 아군 공격은 시작·release 때 확정한 snapshot을 유지하고, 종료 뒤 새로 시작하는 공격부터
박동을 적용하지 않는다. 직접 중지와 외부 interrupt 모두 소비한 공명을 환불하지 않는다.

원작의 시설 전체 울음과 조우의 주변 침식체 가속을 그대로 전장 전체 효과로 만들지 않고, 시전자의
배치 위치와 집중 유지 여부에 따라 범위가 달라지는 공격형 지원기로 축소한다. 플레이어는 시전자 한
명의 기본 행동을 포기하고 주변 여러 직원의 공격 빈도와 피해를 높일지, 집중을 끊고 시전자를 다시
직접 화력으로 사용할지 선택한다. 기본 공격 피해와 속도 증가량은 함께 곱해지는 효과를 고려해 일반
보스 파편보다 낮게 두고, 범위·기본 공격·공격 속도 계열 Run 유물이 화력을 보강한다.

<a id="frag-멈추지-않는-울음-수치와-유물-적용"></a>
### 멈추지 않는 울음 수치와 유물 적용

2026-09-07 후속 대화에서 사용자가 아래 세 상태의 강화 수치를 정하고, 상태별 최종 증가량으로
교체하며 이전 상태와 합산하지 않는 해석을 확인했다. 이는 콘텐츠 수치 합의이며 현재 runtime에
반영됐다는 뜻은 아니다. 2026-09-08 단일 전환·효과 증폭을 범용으로 옮기면서 아래 수치는
그 범용 유물의 태아 적용 사례로 유지한다. 전체 효과에 동일 배율을 곱하는 공통 산식은 미정이다.

| 상태 | 적용 대상 | 기본 공격 피해 증가 | 기본 공격 속도 증가 |
| --- | --- | --- | --- |
| 기본 파편 | 범위 내 다른 eligible 아군 직원 | `+20%` | `+15`포인트 |
| 단일 전환 범용 유물 적용 | 단일 아군 지원으로 전환 | `+40%` | `+20`포인트 |
| 침식된 단일 전환 범용 유물 적용 | 단일 아군 지원 | `+80%` | `+30`포인트 |

- 피해 증가율은 `20% → 40% → 80%`로 교체한다. `20% + 40%`처럼 앞 상태의 수치를 더하지 않는다.
- 공격 속도도 `+15 → +20 → +30`으로 교체한다. 다른 modifier가 없고 기준값이 100이면 각각
  `115 / 120 / 130`이다. 기존 공격 속도 전체에 상태별 배율을 곱하는 방식이 아니다.
- 기본 공격 피해 강화는 범용 Attack stat 증가와 구분한다. 각 상태는 별도의 동시 중첩 버프나
  파편·유물의 레벨이 아니다. 다른 modifier와의 합성·최소 주기·진행 중 공격의 적용 경계는 후속 판정에서 정한다.

| 그 밖의 항목 | 현재 상태 |
| --- | --- |
| 시전 준비 시간 | `0.5초` 초안. 준비 완료 시 집중과 박동을 함께 시작한다. |
| 비침식 상태의 집중 시간 | 짧은 `6~8초`로 조정하는 방향. 비교용으로 `8초`를 사용하며 정확한 값은 미확정이다. 준비 시간은 제외한다. |
| 기본 파편 범위 | 시전자 중심 반경 `2타일`의 원형 초안. 배치 타일 중심 사이의 직선거리로 비교하는 안이다. |
| 기본 파편 대상 수 | 기존 자격을 만족하는 범위 내 다른 아군 직원 전원. 별도 인원 상한 없음 초안. |
| 기본 사용 비용 | 기존 공명 만충 조건과 시전 소비 규칙. 비침식 상태에서 유지 중 추가 자원 소모 없음 초안. |
| 기본 버프 잔존 시간 | `0초`. 범위 이탈 또는 집중 종료 시 박동이 즉시 사라지는 기본 구조를 유지한다. |
| 단일 전환 범용 유물의 선정·존속 | 아군 한 명을 수동 지정하는 안. 지정 사거리·부착 방식·대상 이동 및 무효화 처리는 미정. |
| 침식된 단일 전환 범용 유물의 대가 | 죽음에 이를 수 있는 패널티를 설계한다. 종류·수치·유지 방식은 미정이며 HP 희생에 따른 무기한 집중을 확정하지 않는다. |

일반 HP 피해로 집중이 끊기지 않는 규칙, Hard CC 등 중단 조건과 시전자 행동 제한은 기본 구조를
따른다. 시전자는 집중 중 재시전으로 시간을 갱신하지 않으며, 새 시전은 공명과 행동 가능 조건을
다시 만족해야 한다. 침식 패널티가 HP 비용·피격·생존 보장과 상호작용하는 세부 판정은 별도 설계한다.

다른 강화가 없고 공격 속도 100에서 계속 기본 공격하는 아군 한 명의 단순 화력 계수는 상태별로
`1.20 × 1.15 = 1.38`, `1.40 × 1.20 = 1.68`, `1.80 × 1.30 = 2.34`다. 기본 파편은 여러 명을
지원하고 단일 전환 범용 유물은 한 명을 지원하므로 이 값만으로 파티 전체의 우열을 정하지 않는다. 준비·표적
공백, 피해 계산·반올림, 다른 강화, 스킬 피해와 공명 충전 주기를 포함한 실제 전투 검증은 남아 있다.

15개 축 검토와 범용 유물 `긴 호흡`·`울림통`의 적용은
[태아 파편 기반 유물](synergies.md#rel-%ED%83%9C%EC%95%84-%ED%8C%8C%ED%8E%B8-%EA%B8%B0%EB%B0%98-%EC%9C%A0%EB%AC%BC)을 따른다.
단일 전환·증폭의 공통 구조와 침식된 변형은
[오롯한 축복](../../relics/single-target-conversion.md#rel-%EB%8B%A8%EC%9D%BC-%EB%8C%80%EC%83%81-%EC%A0%84%ED%99%98%ED%9A%A8%EA%B3%BC-%EC%A6%9D%ED%8F%AD--%EB%B2%94%EC%9A%A9-%EC%9C%A0%EB%AC%BC)이 소유한다.

<a id="frag-태아-전용-유물--미정"></a>
### 태아 전용 유물 — 미정

2026-09-08 사용자 요청으로 태아 전용 유물은 이름·효과·희귀도·수치 모두 미정으로 정리한다.
이전 가칭 `깊어지는 울음`의 단일 전환과 증폭은 위 범용 유물로 이전했다. 그 적용 수치나 침식된
변형을 새로운 태아 전용 유물에 다시 배정하지 않는다.
