# 음양 · 스킬 파편

[콘텐츠 위키](../../README.md) · [개요](README.md) · [조우](encounter.md) · [장비](equipment.md) · [태그·유물](synergies.md) · [검토 기록](review.md)

> 콘텐츠 설계. 원문의 합의·초안·미정 구분을 유지한다. 구현 완료를 뜻하지 않는다.

본문의 공명·침식 공통 정책은 [파편 공통 기준](../../principles/fragments.md#current-corrosion)에서 확인한다. 이관 전 문구와 현재 공통 규칙의 차이는 후속 검토 대상으로 남긴다.

전용 유물을 장착하고 두 중심 타일이 같으면 일반 회복 시전이 [승천의 징표](../../relics/yin-yang-dragon.md)으로 바뀐다. 유물의 효과·경고 없음·대상별 판정은 유물 페이지에서 관리한다.

## 파편 — 음양의 순환 (가칭)

기본 파편의 역할은 **힐**이다. 전용 유물의 용 전환이 없는 기본 동작은 적 피해나 아군의 대가 없이, 플레이어가 지정한 두 위치에
**음의 영역**과 **양의 영역**을 만들어 지속 시간 동안 두 구역의 아군을 회복하고, 교집합의 아군에게 이로운 버프를 제공한다.

| 항목 | 값 |
| --- | --- |
| `rarity` | open design |
| `equip_limit` | open design |
| `compatibility` | open design |
| `cast_selection` | 전장 위치 2곳 지정. 세부 입력 순서·정식 데이터 표현 미정 |
| 역할 | 힐·지원 / 음의 영역·양의 영역의 지속 회복과 교집합 버프 |

공명 만충에서 플레이어가 두 위치를 지정하면 한쪽에 **음의 영역**, 다른 쪽에 **양의 영역**을 만든다.
2026-10-18 사용자 합의에 따라 기존의 단일 위치 회복 장판을 이 두 영역 구조로 대체한다.

- 두 영역은 지정한 위치에 유지되며, 지속 시간 동안 각 구역 범위 안의 eligible 아군을 회복한다.
- 아군이 범위에 들어오면 회복 대상이 되고, 범위를 벗어나면 더 이상 회복받지 않는다. 대상은 장판의
  각 회복 판정 시점에 현재 위치를 기준으로 다시 정한다.
- 적의 존재·명중·피해량·처치 여부와 아군 HP 희생은 장판의 생성이나 회복 조건이 아니다.
- 이전의 단일 장판 흑백 파동 교대 설명 대신 음의 영역과 양의 영역을 공간적으로 구분한다.
  두 영역의 이름만으로 서로 다른 회복 성질·계수·추가 버프를 부여하지 않는다.

**순환 회복 — 2026-10-18 후속 합의**

- 음과 양의 기본 회복 성질은 같게 둔다. 각 회복 주기에 두 영역이 먼저 각자 범위 안 아군을 회복한다.
- 아군 HP가 가득 차 실제로 쓰이지 않은 회복량 일부를 반대 영역의 부상 아군에게 추가 회복으로 전달한다.
- 전달하는 영역에도 아군이 있어야 한다. 아군이 없는 빈 영역에서 전달 회복량을 만들지 않는다.
- 전달된 추가 회복의 초과분은 다시 반대편으로 보내지 않는다.
- 전달 비율, 여러 아군의 초과 회복 집계와 수혜자 배분, 두 영역이 겹칠 때의 처리는 미정이다.

**독립 영역과 교집합 — 2026-10-18 후속 합의**

| 위치 | 파편 효과 |
| --- | --- |
| 음의 영역만 있는 곳 | 회복 |
| 양의 영역만 있는 곳 | 회복 |
| 음과 양이 겹치는 교집합 | 회복 + 이로운 버프 |

기존 순환 회복 합의는 유지한다. 교집합의 회복량 증가·양쪽 회복 중복 적용은 아직 확정하지 않았다.
버프 종류·수치·지속 시간·부여 및 재부여 시점·영역 이탈 시 처리는 미정이다. 피해 감소·공격 속도
증가와 `조화` 명칭은 앞선 제안이며 이번 합의만으로 채택하지 않는다. 교집합 버프는 파편 자체 효과로,
실제 HP 회복을 발동 조건으로 삼는 유물 효과와 구분한다. 다른 시전·파편 사본 사이의 겹침은 별도 미정이다.

두 영역의 범위·지속 시간·회복 주기·회복량과 최초 회복 시점은 미정이다. 독립 설치 후
자유 행동·설치 즉시 첫 회복·재시전 시 기존 장판 교체는 계속 제안 상태다.
파편은 어떤 compatible 무기와 조합해도 두 회복 영역 자체로 광역 회복 역할을 완결한다.

## 파편 침식형 — 이름 미정

> 상태: 소재 합의 / 범위와 수치 미정

필드에 **용**이 나타난다. 조우에서 음과 양이 합체했을 때 전장을 가로지르는 그 용이다.

조우 설계는 `실패 현상인 용을 플레이어가 자유롭게 소환하는 보상으로 바로 옮기지 않는다`를 단서로
달아 두었다. 침식은 파생 4종 보유, 트라우마 임계치, 공명 만충과 명시적 입력이 모두 필요한 최후
수단이라 `자유롭게`에 해당하지 않으므로 이 단서와 충돌하지 않는다. 2026-10-18에 별도로 합의한
전용 유물의 숨겨진 용 출현은 이 옛 보상 방향의 예외이며, 에고 침식의 조건·효과와 합치지 않는다.

용은 **적만 처형한다.** 조우의 용이 아군까지 즉사시키는 것과 달리 여기서는 `침식형 공통 정책`을
그대로 따르며 예외를 만들지 않는다.

open design:

- 이름과 수치

판정과 대상 범위는 위 `침식형 공통 정책`이 소유한다.

## 초기 검증값 — 2026-10-19

> 상태: 사용자가 초기 수치 설정을 위임하여 정한 **첫 테스트용 초안**. 전투 검증이나 구현을 마친 값이 아니다.
> 위 합의한 두 영역·순환 회복 구조를 유지한다. 수치를 시험하는 데 필요한 임시 판정과 버프 후보도
> 아래에 명시하며, 최종 설계·밸런스 확정과 구분한다.

| 항목 | 시작값 |
| --- | --- |
| 각 영역의 범위 | 중심에서 반경 1.5타일. 테스트에서는 타일 중심 간 직선거리로 포함 여부 판정 |
| 위치 지정 사거리 | 시전자에서 각 중심까지 4타일. 두 중심 사이의 별도 거리 제한은 두지 않는 시험안 |
| 생성 준비 시간 | 두 위치를 최종 확정한 뒤 0.5초 |
| 영역 유지 시간 | 생성 후 12초 |
| 회복 주기·첫 회복 | 1초 주기, 생성 1초 후 첫 회복. 1~12초에 총 12회 회복한 뒤 종료 |
| 아군 1명당 기본 회복량 | 매회 시전자 주문력의 30%. 생성 시 주문력을 고정하는 초기안 |
| 순환 회복 전달률 | 각 영역에서 실제로 남은 기본 회복량 합계의 50%를 반대 영역으로 전달 |
| 교집합 회복 | 한 대상에게 기본 회복 1회만 적용. 두 장판에 걸쳤다고 회복량을 두 배로 만들지 않는 시험안 |
| 교집합 버프 후보 | 기본 공격 속도 +10. 중립 100 기준 110이며, 주기 10% 감소나 파편 시전 가속이 아님 |
| 교집합 버프 수명 후보 | 교집합 안에서만 유지하고 이탈·장판 종료 시 즉시 해제. 별도의 잔여 지속 시간 없음 |

**시험용 집계·종료 규칙**

- 두 위치를 고르는 동안에는 시전이 확정되지 않는다. 취소 시 공명을 소비하지 않는다. 확정 시 기존
  공명 비용을 지불하고 준비 시간 후 두 영역을 함께 생성한다. 생성 후 자유 행동이 가능한 독립 설치안을 시험한다.
- 한 시전 안에서 각 아군은 가까운 중심의 영역에 한 번만 집계하며, 거리가 같으면 음에 집계한다.
  교집합 여부는 이 집계 구분과 별도로 실제 두 영역의 겹침으로 판단한다. 중복 집계로 전달 예산을 만들지 않는다.
- 먼저 양쪽의 기본 회복을 모두 처리한 뒤 실제 HP 상한 때문에 사용하지 못한 양만 모은다.
  회복 면역·회복 불가로 거절된 요청은 초과 회복으로 세지 않는다. 아군이 없는 영역은 예산 0이다.
- 전달 예산은 반대 영역에 집계된 부상 아군의 남은 결손 HP 비율로 나눈다. 남은 HP 이상은 회복하지
  않으며 수혜자 부재·초과분은 버린다. 정수 나눗셈 잔여량은 안정된 대상 ID 순으로 배분하는 초기안이다.
- 양쪽 예산은 기본 회복 결과로 한 번만 계산한다. 전달 회복을 다시 전달하거나, 전달된 값에 시전자의
  같은 회복량 증가를 두 번 곱하지 않는다. 받는 대상의 회복 보정은 해당 대상의 원래 판정을 따른다.
- 같은 시전의 교집합 버프는 중복하지 않는다. 재시전이 실제로 성공해 새 두 영역을 생성할 때 기존
  두 영역을 함께 교체한다. 시전자 철수·전투불능·전투 종료 시 제거하는 안으로 첫 테스트를 한다.
  서로 다른 직원·파편 사본의 중첩은 별도 검토하며, 이번 초기 비교는 음양 한 사본으로 한정한다.

**수치 기준과 비교 예시**

다른 보정을 생략하고 주문력이 100이면 한 번에 아군마다 30, 한 영역에 12초 머물면 최대 360을
요청한다. 같은 예시에서 음에 만피 아군 2명, 양에 충분히 다친 아군 2명이 있으면 음의 기본 회복
요청 60이 남아 30을 양에 전달한다. 양의 두 아군이 같은 결손 HP라면 각각 기본 30 + 전달 15를 받는다.
아군이 없는 음에서는 이 추가 30을 만들지 않는다. 모두 실제 HP 상한 내에서만 회복한다.

범위를 나누면 두 전선을 지원하고, 겹치면 회복 중복 대신 버프를 얻도록 비교하는 시작점이다.
교집합의 공격 속도 버프는 **새로 제시한 시험 후보**이며 기존 합의로 소급하지 않는다. 피해 감소 등
다른 버프 후보를 함께 넣지 않는다. 기본 유지 시간에 `긴 호흡`만 적용하면 15초·15회가 된다.

최종 희귀도·호환 무기·개화형 여부, 다른 사본과의 중첩, 교집합 버프의 최종 종류는 계속 후속
결정 대상이다. 장비 초기값은 [장비](equipment.md#initial-values-2026-10-19), 유물 계수는
[태그·유물 연결](synergies.md#initial-values-2026-10-19)에서 관리한다.
