## 무기 — 이름 미정

> 상태: 2026-10-19 파편 개화와 전용 무기의 미니건 동반 승급 합의 / 이름·수치·승급 대상 세부 미정

죽을 나비의 장례 파편을 **개화하면 전용 무기도 쌍권총에서 미니건으로 함께 승급**한다.
승급은 무기 자체에 남으며, 개화 파편을 착용한 동안에만 적용되는 임시 형태가 아니다.
공명량에 따른 자동 형상변화는 이 동반 승급 규칙으로 대체한다.

| 항목 | 값 |
| --- | --- |
| `range_role` | 원거리 |
| `weapon_archetype` | `Gun` |
| `deployment_affinity` | Platform 전용 |
| `block_capacity` | `0` |
| `defense_tile_range` | 긴 편 |
| 그 외 항목 | open design |

두 형태 모두 Platform에서 총으로 직접 공격하며 적을 저지하지 않는다. 관을 세워 적을 막거나 관을
해체해 무기를 꺼내는 구조와 연출은 사용하지 않는다.

**쌍권총**

기본 형태에서는 Platform에 배치된 착용자가 쌍권총으로 원거리 사격한다. 쌍권총도 피해를 입히면
나비 스택을 쌓는다.

**미니건**

파편 개화에 따라 승급한 무기는 처음부터 미니건으로 사용한다. 배치 위치와 `block_capacity 0`은
변하지 않는다. 다른 호환 파편으로 교체해도 승급한 무기는 미니건을 유지한다.

- 무한 관통
- 피격당한 적을 뒤로 조금씩 밀어낸다
- 피격 시 나비 스택이 `1` 쌓인다

2026-10-19 [유물 연결 합의](../../../../abnormalities/funeral-of-dying-butterflies/synergies.md)에 따라 스택부여를 적용하면 적에게 붙이는 나비 스택이
2배가 된다. 미니건은 적중당 `1 → 2`이며, 적 사망 후 타일로 이전하거나 구체로 모을 때는 다시
증폭하지 않는다. 쌍권총도 확정된 기본 부여량의 2배를 적용하되 기본량은 미정이다.

**설계 근거**

쌍권총은 일반 원거리 사격으로 나비 스택을 쌓고, 미니건은 관통·넉백과 더 빠른 스택 부여로 다수의
적을 압박한다. 지상 저지 역할을 겸하지 않는 대신 두 형태의 화력 차이와 파편 폭발 시점에 집중하는
Platform 원거리 딜러다. 개화 전에는 쌍권총과 경로 전체 폭발을, 개화 후에는 미니건의 축적과
원본의 등급별 연속 폭발을 조합한다. 무기 승급 조건으로 공명 임계치를 사용하지 않는다.

파편 시전은 공명을 0으로 되돌리지만, 승급한 미니건은 쌍권총으로 돌아가지 않는다.
전투 종료나 파편 교체를 이유로 무기 승급을 해제하지 않는다. 새 run의 보유·반입 정책은 별도다.

이번 동반 승급의 구체적인 대상은 전용 무기다. 방어구·액세서리의 추가 승급 효과는 정하지 않았다.
이전 공명 90% 변환안은 [아카이브](../../../../abnormalities/funeral-of-dying-butterflies/review.md#weapon-before-awakening-2026-10-19)에 보존한다.

open design:

- 쌍권총의 스택 축적량과 미니건과의 차이
- 넉백 거리와 대상 판정
- 전용 무기를 보유하지 않은 상태의 개화, 여러 사본 보유 시 승급 대상, 승급 무기의 이후 획득·반입 정책
- 두 형태의 사거리·공격 주기·targeting profile과 Platform Rest 판정

<a id="frag-액세서리--장례의-잔향-가칭"></a>
## 액세서리 — 장례의 잔향 (가칭)

> 상태: 기존 스택 적용량 두 배 초안 폐기 / 처치 후 나비 연쇄 폭발 구조 합의 /
> 이름·수치·세부 판정 미정 / 현재 미구현

기존에는 착용자가 적에게 직접 부여하는 `증폭 허용 스택`의 적용량을 항상 두 배로 만드는 효과를
검토했다. 이 문법은 `파고드는 천국` 액세서리가 주시 스택을 두 배로 만드는 효과와 사실상 같으므로
죽을 나비의 장례 액세서리에서는 사용하지 않는다.

**고유 효과 — 이어지는 장례**

착용자가 적을 처치하면 적이 죽은 자리에 나비가 모이고, 잠시 뒤 폭발하여 주변 적에게 범위 피해를
준다. **이 폭발로 처치한 적도 자기 자리에서 다시 나비 폭발을 일으킨다.** 적 무리가 밀집한 곳에서
첫 처치를 만들면 다음 처치로 이어지는 연쇄 폭발 액세서리다.

- 처치가 착용자에게 귀속되는 기본 공격과 일반 스킬 모두 발동시킬 수 있다. 단순 어시스트나
  다른 아군의 처치만으로는 발동하지 않는다. 허수아비 등 다른 파편·무기와도 독립적으로 사용한다.
- 각 적의 사망 확정당 폭발을 한 번만 예약한다. 같은 적을 여러 발로 동시에 처치하거나 한 사망을
  중복 처리해도 폭발 수가 늘지 않는다. 단순 HP 임계치 통과·형태 전환·이탈은 처치로 세지 않는다.
- 예약된 폭발은 사망 위치에 고정되며 살아 있는 적을 추적하지 않는다. 폭발 시 범위 안의 적에게
  각 1회 피해를 주고, 이미 죽은 원래 적이나 아군에는 피해를 주지 않는다.
- 초기 테스트 후보는 **처치 후 0.5초 / 착용자 공격력의 50%에 해당하는 작은 범위 Magic 피해**다.
  핵심 구조 합의와 별개로 정확한 지연·범위·피해 type·계수는 후속 테스트에서 확정한다.
- 폭발 위력은 처치된 적의 최대 HP나 나비 스택 수가 아니라 착용자의 공격력을 기준으로 한다.
  연쇄 횟수에 따른 위력 증가는 없고, 각 후속 폭발도 같은 계수로 계산한다. 공격력은 각 폭발을
  예약할 때 고정하는 안이다. 내구도가 높은 적 하나의 죽음이 비례 피해 폭탄이 되지는 않는다.
- 액세서리 폭발의 처치는 착용자에게 귀속시켜 다음 연쇄를 허용한다. 별도 사망과 지연을 거쳐
  이어지며, 같은 시체가 반복 폭발하거나 처치 없이 폭발이 스스로 재생성되지는 않는다.
- 폭발은 액세서리 출처의 별도 피해다. 무기의 기본 공격으로 재분류하지 않으며, 기본 공격용
  `OnAttack`·`OnHit`나 나비 스택 부여를 자동 발생시키지 않는다. 소환물·지속 피해 등의 최초
  처치 귀속, 다른 처치 효과와의 연동 및 침식형 일괄 처형의 포함 여부는 후속 판정에서 정한다.

**전용 조합과 한계**

- 쌍권총·미니건으로 첫 적을 처치하면, 폭발이 주변 적의 HP를 줄여 후속 총격과 연쇄 처치를 돕는다.
  무기 피격으로 이미 쌓인 나비 스택은 기존 규칙대로 사망 타일에 남는다.
- 기본 파편의 경로 폭발이나 개화 파편의 스택 폭발로 적을 처치해도 추가 폭발이 이어진다.
  액세서리는 타일 스택을 새로 부여하거나 증폭·소모하지 않으며, 스택 없는 적의 연쇄 처치가
  나비 스택을 무에서 만들어 내지는 않는다.
- 루돌타 액세서리가 공격 자체를 범위화·확대하는 것과 달리, 이 액세서리는 **처치 뒤에만** 별도
  피해를 만든다. 잡몹 없는 단일 보스를 처치하기 전에는 기여하지 않는 군집전 특화 장비다.
- 문서 설계만 추가하며 runtime·data 구현은 포함하지 않는다. 사망 위치와 처치 귀속 보존,
  예약 폭발의 정확히 한 번 처리, 시전자 이탈·전투 종료 시 정리는 구현 전에 별도로 확정한다.
