## 무기 — 실낙원:

- 설계 상태: 사도 무기 변형과 선택 UI 기획 합의(2026-09-06) / 현재 미구현. 각 형태의 상세
  기술·수치와 runtime/data/wire 계약은 후속 설계 대상이다.
- 실낙원은 `낫 사도`, `창 사도`, `지팡이 사도`, `수호 사도`의 무기 형태로 변형하는 하나의
  장비다. 플레이어는 전투 중 원하는 형태를 직접 선택한다.
- 형태를 바꾸면 해당 사도의 기본 공격과 전용 기술을 함께 사용한다. 사도별 무기·기술을 설계할
  때 우호 사도와 실낙원 해당 형태가 같은 공격·기술을 사용하도록 정한다.
- 각 형태는 FinalBoss 무기에 맞는 강력한 성능을 가지며, 전선 상황에 맞춰 형태를 바꾸는 것이
  핵심 운용이다. 형태별 역할과 공격·기술의 방향은 다음과 같다.

| 형태 | 공격·기술 방향 | 전투 역할 |
| --- | --- | --- |
| 낫 사도 | 넓은 베기와 붙잡기·처형 | 밀집한 적의 근접 정리 |
| 창 사도 | 준비 동작 후 강력한 관통 돌진 | 일렬로 늘어선 적 돌파 |
| 지팡이 사도 | 충전 후 지속 광선 | 원거리 화력 집중 |
| 수호 사도 | 강력한 근접 공격과 높은 저지 성능 | 핵심 전선 유지 |

- 실낙원은 지상·플랫폼 모두에 배치할 수 있으며 네 형태 모두 현재 배치 타일에서 사용할 수
  있다. 형태 전환은 현재 배치를 유지한다. 지상에서 지팡이형으로 바꾸는 경우에도 철수나
  다른 타일로의 재배치를 요구하지 않는다.
- 형태 전환에는 전환 대기시간을 두며 exact 시간은 후속 설계에서 정한다. 형태를 바꿔도 이미
  시작된 전용 기술의 재사용 대기시간을 초기화하지 않는다.
- 무기 형태 전환 자체는 파편의 누적 사도화 진행도를 올리거나 사도화 타이머를 시작하지 않는다.

## 실낙원 형태 선택 UI:

- 실낙원을 장착한 직원을 선택하면 직원 선택 패널의 무기 아이콘에 현재 형태를 표시한다.
- 무기 아이콘을 누르면 `낫·창·지팡이·수호` 네 아이콘으로 구성된 작은 형태 선택기가 펼쳐진다.
  플레이어가 원하는 아이콘을 선택하면 직원은 현재 위치에서 해당 무기로 변형한다.
- 현재 형태를 강조하고, 각 아이콘에 커서를 올리면 그 형태의 사거리·저지 수·전용 기술을
  미리 보여준다. 전환 대기 중에는 남은 시간을 표시한다.
- 전환 성공 뒤 현재 무기 아이콘, 공격 범위, 저지 수와 전용 기술 표시를 함께 갱신한다.
- 기존 전투 Pause 상태에서도 형태를 선택하고 전환할 수 있다.
- 변형 시 무기가 접히거나 펼쳐지고 해당 사도의 실루엣이 잠깐 겹쳐 보이는 연출을 사용한다.

## 무기 Open design:

- 각 형태의 정확한 공격·기술, 피해 타입, 사거리·저지 수·스탯과 전환 대기시간.
- 전용 기술의 수동/자동 발동 방식과 파편 스킬을 함께 사용하는 조작·표시 방식.
- 최초 장착·전투 진입 시 기본 형태와 전투 사이의 형태 선택 유지 여부.
- 공격·기술 시전 중 전환, Hard CC 등 상태 제한과 전환 중 진행 중인 동작의 처리.
- 형태별 타일 효과와 무기 조건을 요구하는 스킬 파편의 호환 규칙. 모든 형태를 지상·플랫폼에서
  사용할 수 있다는 합의는 유지한다.
