## 피의 욕조

정책 상태: 직원 희생과 다른 직원의 완전 치료를 교환하는 즉시 도구로 채택.

- 도구 VN에서 얻는 run-local 1회성 아이템이며 지도 보기/전투 진입 전 확인에서 사용한다.
  서로 다른 살아 있는 직원 두 명을 희생자와 회복 대상으로 명시한다. Dead는 어느 쪽도 될 수 없다.
- 희생자는 명시적 대가로 영구 run 사망하며 일반 사망 방지로 취소하지 않는다. 회복 대상은
  persistent 부상과 트라우마를 모두 0으로 만들고 기존 Breakdown 유예를 해제한다.
- Critical·Breakdown도 치료할 수 있으나 이미 노드 입장 유예 처리에서 Dead가 된 직원을
  뒤늦게 되살리지 않는다. 전투 HP 회복과 지속 condition 치료를 혼용하지 않는다.
- 희생자의 장비·공유 active 파편·장착 유물·특수 갑옷/파츠는 공통 영구 사망 회수 규칙을 따른다.
- 희생·치료·소비·장비 회수는 전부 성공하거나 전부 실패한다. 자동 대상 대체·부분 희생·부분
  치료·Dead 부활은 없다. 일반 소비품의 기간형 효과 한 칸을 점유하지 않는다.
- 확률·시간 제한·추가 미니게임은 없다. 사용 전 대상과 희생/치료 결과를 명확히 표시한다.
  사용 후 원정의 진행/회복 가능성은 공통 실패·복구 규칙으로 다시 판정한다.

정식 파편화는 별도 정책이며 영구 희생과 condition 회복의 교환을 보존해야 한다.
