## 부서져 가는 갑옷

정책 상태: 특수 슬롯의 원정 전용 조립 장비와 5단계 개별 철수 대가로 채택.

- 직원의 특수 슬롯 하나에 넣는 장비 개체다. 도구 VN 조우에서 일본 갑옷 구성의 고정 파츠 풀 중
  미획득 파츠 하나를 얻는다. 기본안은 최대 5파츠이며 같은 파츠를 중복 지급·조립하지 않는다.
- 파츠·단계는 갑옷 개체에 귀속되고 다른 직원에게 옮길 때도 함께 이동한다. 파츠를 여러 직원에게
  나누어 장착할 수 없다. 파츠별 작은 고유 효과+단계 효과의 혼합은 권장안이며 exact 효과는 미정이다.
- HP 감소는 최대 HP modifier이며 아래 수치는 초기 조절값이다.

| 단계 | 최대 HP modifier | 공격력 modifier |
| --- | --- | --- |
| 1 | -10% | 파츠 고유 효과만 |
| 2 | -15% | 파츠 고유 효과만 |
| 3 | -30% | +30% |
| 4 | -50% | +40% |
| 5 | -80% | +100% |

- 5단계 착용자가 전투에 들어가면 해당 전투에 `무모의 맹세`를 적용한다. **개별 Withdraw 시도는
  철수 대신 즉시 영구 run 사망**이며 사망 방지로 취소하지 않는다. 기존 합의대로 확인 modal·
  자동 취소·안전한 fallback을 추가하지 않는다. 파츠 수와 5단계 효과는 플레이어가 확인할 수 있어야 한다.
- 일반 전투불능은 공통 부상·트라우마 규칙을 따르며 5단계라는 이유만으로 영구 사망으로 바꾸지 않는다.
- 착용자가 영구 사망하면 갑옷/파츠는 일반 장비 회수 규칙으로 원정 인벤토리에 돌아간다.
- 전투 전체 **Battle Retreat는 기본 허용**하며 공통 최대 횟수·복원 경계를 적용한다. 전투 전에
  이미 조립·장착한 상태를 지우지 않고 전투 중 맹세/직원 상태의 변화를 진입 시점으로 복원한다.
- 명시된 조우는 `max_stage_battle_retreat_forbidden`을 opt-in하여 활성 5단계 착용자가 있을 때
  전체 후퇴를 막을 수 있다. 일반 획득만으로 이 옵션을 켜지 않는다.

정식 파편화는 별도 정책이며 단순 공격력 버프로 축소하지 않는다.
