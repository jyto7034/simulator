## 뚜껑 따인 웰치어스

정책 상태: 납치 후 **서로 다른 후속 활동 노드 5개 해결**로 복귀하는 직원 투자 도구로 채택.
5개는 초기 플레이 검증값이다. 옛 `5 Floors/다섯 번째 Gate` 기준은 사용하지 않는다.

## 사용·납치:

- 도구 VN에서 얻는 run-local 1회성 아이템이며 지도 보기/전투 진입 전 확인에서 살아 있는
  직원 한 명에게 사용한다. 플레이어가 직원을 명시적으로 고르고 D20 결과를 확정한다.
- 성공은 `맛있다.`로 아이템만 소모하고 직원 상태·자원·장비에 변화가 없다. 실패는 `납치되었다.`로
  직원에게 `AbductedByWellcheers`를 부여한다. 랜덤 버프나 즉시 사망 도구가 아니다.
- 납치 직원의 roster identity와 condition은 보존하지만 전투·Event·고위험 선택·loadout 등
  모든 직원 행동에서 제외한다. Dead가 아니므로 납치 자체에 사망 방지/부활을 적용하지 않는다.
- 납치 확정 때 무기·장비·공유 active 파편·장착 유물·특수 장비는 공통 자산 회수 경로로 즉시
  원정 인벤토리에 돌려준다. 직원 부재가 대가이며 장비까지 함께 장기간 묶지 않는다.

## 진행·복귀:

- 납치가 확정된 뒤 **새로 해결한 서로 다른 활동 노드**를 센다. 전투는 승리/패배 결과 확정으로
  소비될 때, 비전투 활동은 완료가 확정될 때 한 번 센다. 같은 층 탐사도 유효하다.
- 입장만 한 노드·미리보기·활동 거절로 미완료인 노드·후퇴·재접속·재방문·Gate 이동/귀환은 세지 않는다.
  같은 노드의 중복 결과/여러 서비스 이용/후퇴 후 재진입으로 횟수를 늘리지 않는다.
- 기준에 도달한 노드의 결과와 복귀/보상을 한 번만 확정하고 활동이 끝난 준비 화면에서 알린다.
  node 중간이나 active battle에 끼어들어 배치하지 않는다. UI 확인이 최초 복귀/보상 지급자가 아니다.
- 복귀 직원에게 `많은 일이 있었어…`라는 결과와 대량 XP/level 성장·run-local 자원 묶음을 준다.
  정확한 성장 방식·자원 종류/수량·5개 기준의 체감은 플레이 검증으로 정한다.
- 복귀 조건 도달 전에 원정 종료/실패가 확정되면 복귀·성장·자원 보상이 없다. 다음 원정으로
  납치 직원을 넘기지 않는다. 원정의 생존/회복 가능성 판정은 최신 공통 실패·복구 규칙을 따른다.
- 납치·누적 노드 ID/횟수·복귀·보상 receipt는 함께 저장한다. 과거 체크포인트를 불러오면 같은
  시점으로 함께 복원한다. 도구 사용 판정과 동일 노드 결과를 재추첨/중복 적용하지 않는다.
- UI는 남은 활동 수·불참 상태·즉시 장비 회수·원정 종료 전 복귀하지 못하면 보상 없음과 복귀 결과를 표시한다.

정식 파편화는 별도 정책이며 직원 부재와 지연된 성장/보상의 교환을 유지해야 한다.
