## 이계의 초상

정책 상태: 배치된 동료에 대한 피해 전이·캔버스 누적 부담·주체 대가의 지속 계약으로 채택.

## 계약·대상:

- 도구 조우의 VN 뒤 `이계의 초상 캔버스`를 얻고 한 직원에게 사용해 **주체(subject)** 로 새긴다.
  일반 소비품 교체로 계약을 해제하지 않는다. 같은 run에서 다른 직원에게 되새기면 기존 주체는
  즉시 영구 run 사망한다. 임의 폐기·안전한 해제 수단은 기본 제공하지 않는다.
- 객체(object)는 주체를 제외한 **현재 배치되어 유효한 직원** 중 무작위로 고른다. 대기 직원과
  소환물은 후보가 아니다. 주체의 최초 배치/재배치에는 다른 유효 직원이 있어야 하며 없으면 배치를 거절한다.
- 객체가 전투불능·영구 사망·철수 등으로 유효하지 않게 되면 다음 전이 직전에 새 객체를 고른다.
  영구 사망할 때까지 같은 전투불능 개체를 붙잡아 두지 않는다. 직원 identity와 현재 전투 개체를 구분한다.
- 이미 배치된 주체가 전이할 피해를 받는 시점에 유효한 객체가 없으면 주체가 영구 run 사망한다.
  단순히 객체가 사라진 시점에 곧바로 주체를 죽이지 않는다. 하나의 피해를 여러 객체로 연쇄 전이하지 않는다.
- 대상 선택은 seed/동일 시도에 대해 재현 가능하게 확정하고 주체·객체를 표시한다.

## 피해·진행:

- 주체가 받을 최종 피해를 객체가 대신 받으며, 전이 피해를 객체의 남은 HP로 잘라내지 않는다.
  피해 부담은 객체 개인이 아니라 캔버스에 쌓이고 초상 단계는 객체 교체나 전투 종료만으로 내려가지 않는다.
- 공격·지속·환경 피해의 HP 손실은 전이 대상으로 다룬다. HP 비용·직접 희생·초상 자체의 영구
  사망 대가는 전이하지 않는다. 보호막·최종 피해 산출/전이 순서와 자해의 피해/비용 분류는 후속 판정 계약으로 정한다.
- 단계는 1단계 `1.25x`, 2단계 `1.5x`, 3단계 `2.0x`, 4단계 `2.0x`의 전이 배율 구조다.
  4단계에서 다음 부담 임계치를 넘으면 주체가 영구 run 사망한다.
- 임계치의 기준 HP(새길 당시/현재 최대 HP), 비율과 전투 종료 시 미달성 부담 이월 비율
  (기존 후보 `25~50%`)은 별도 정책/밸런스 결정으로 남긴다. 이번 대상 정책 채택으로 함께 확정하지 않는다.
- 객체가 일반 전이 피해로 HP 0이 되면 공통 전투불능·부상/트라우마 처리를 한 번 적용한다.
  객체가 전투불능이 되었다는 이유만으로 즉시 영구 사망시키지 않는다.
- 객체 부재 시 피해, 재각인, 4단계 한계 초과에 의한 **주체의 영구 사망 대가**는 사망 방지로 취소하지 않는다.
  이 대가도 공통 후퇴/과거 체크포인트의 복구 범위까지 무효화하는 것은 아니다.
- UI에는 대상·단계·부담·다음 임계치와 주체 배치 불가 사유를 제공한다.

정식 파편화는 별도 정책이며, 무제한 피해 이전·소환체 희생으로 단순화하지 않는다.
