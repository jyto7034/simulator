## 거목수액

정책 상태: 원정 공통 위험을 가진 기간형 최대 HP 소비품으로 채택 / 현재 미구현.

## 획득·사용:

- 도구 조우에서 run-local 소비 아이템을 얻고 지도 보기 또는 전투 진입 전 확인에서 직원 한 명에게 사용한다.
- 직원당 일반 소비품 효과 한 칸을 사용한다. 새 소비품으로 교체하면 성공/실패 효과 모두 끝나지만
  사용한 수액과 원정 공통 누적 위험은 환불·초기화하지 않는다. 과거 체크포인트 복구는 공통 규칙을 따른다.
- 성공하면 `N`회 전투 동안 최대 HP 증가, 실패하면 같은 기간 최대 HP 감소 `수액 과증식`을 부여한다.
  기존 검토 범위는 성공 `+20~30%`, 실패 `-20~40%`이며 정확량과 `N`은 밸런스 데이터로 정한다.
  일반 소비품 교체 규칙을 따르므로 같은 직원의 수액 효과를 무제한 중첩하지 않는다.
- 최대 HP 증가를 즉시 HP 회복·사망 뒤 폭발·주변 White 피해로 대체하지 않는다.

## 위험·판정:

- 모든 수액 개체가 같은 원정 위험 장부를 공유한다. 직원 교체로 위험을 분산하지 못한다.
- 첫 유효 사용은 실패 `0%`이며 실패 판정 주사위를 굴리지 않고 성공한다. 이후 실패가 없으면
  `15% → 30% → 45% → 60%`로 증가하고 60%에서 멈춘다. 실패 후 다음 유효 사용은 `15%`다.
- D20 실패 면 `0/3/6/9/12`로 표현하며 전체 사용 수와 최근 실패 이후 사용 수를 구별한다.
- 판정 receipt·수량 감소·위험 장부·효과는 함께 확정한다. 거절된 사용은 RNG/아이템/위험을 바꾸지 않는다.
  중복 입력·재접속은 재소비/재추첨하지 않고, SavePoint 복구는 아이템과 장부를 같은 시점으로 복원한다.
- UI는 다음 사용의 위험과 현재 효과·남은 전투 수를 Core 결과로 표시한다.

정식 파편화는 기본 경로가 아니다. 별도 채택 없이 공명 충전이나 폭발 스킬로 바꾸지 않는다.
