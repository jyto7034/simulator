## 회사 지급 스킬

회사 지급 스킬은 복잡한 전용 규칙 없이 공통 기능을 확인하는 기준 콘텐츠로 둔다. 아래는 동작의 분해이며 현재 데이터의 수치 확정을 뜻하지 않는다.

| 스킬          | 조립안과 태그 후보                             | 변경 후보 속성                    | 검토할 경계                                                           |
| ------------- | ---------------------------------------------- | --------------------------------- | --------------------------------------------------------------------- |
| 아드레날린    | 자기 기간 강화 `능력치변경`                    | 공격력·공속·기간 각각             | 같은 출처 재사용은 갱신, 중첩 없음 추천                               |
| 광전사        | 기간 강화 `능력치변경` / 평타 흡혈 `회복·흡혈` | 강화량·기간 / 흡혈률·상한         | 평타 흡혈 출처 유지. 스킬 피해까지 확대하지 않음                      |
| 최후의 방어선 | 자기 기간 방어 `피해감소`                      | 경감률·기간                       | 다른 감소와의 합성은 공통 피해 규칙 사용                              |
| 돌파          | 공격 `피해·범위` → 개인 `보호막`               | 공격 위력·범위 / 보호량·기간      | 추천은 적중 수와 무관한 방어막. 피해 범위를 넓혀도 보호막 대상은 자신 |
| 단일 회복     | 지정 아군 `회복`                               | 회복량·지정 사거리                | 실제 회복량과 요청량 구분, 만피 대상 허용 여부                        |
| 범위 회복     | 한 번의 영역 조회와 `회복·범위`                | 회복량·효과 범위·지정 사거리 각각 | 즉시 회복이며 `소환물·지속영역`이 아님                                |

**유물 연결:** 기존 **가하는 회복량 증가**는 두 회복 스킬에 연결하고 광전사의 흡혈은 유물의 인정 출처를 확인한다. 능력치·경감·보호량 강화는 각 효과를 선택하는 새 후보로 둔다. **긴 호흡**은 기간 강화·기간 방어·유한한 보호막 등의 `지속시간` 효과에 연결할 수 있으며, 개별 태그 적용은 검토 대상이다. 즉시 회복이나 순간 공격에 새 지속 시간을 만들지 않는다. 범위 회복의 한 번의 영역에도 **울림통**을 적용하지 않는다.
