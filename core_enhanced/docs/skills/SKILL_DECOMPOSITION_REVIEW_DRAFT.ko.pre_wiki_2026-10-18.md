# 스킬 분해와 재조립 검토 초안

작성일: 2026-10-16 · 수정일: 2026-10-18 · 상태: 사용자 첨삭 반영 중 — 절망의 기사 및 증오의 여왕 리워크·태그 합의 반영

스킬의 재미와 표현을 유지하면서, 전투에서 실제로 계산할 일을 작고 명확하게 나누는 초안이다. 환상체 파편 24개 구성안과 회사 지급 스킬 6종을 다루며, 각 효과의 태그·변경할 속성·장비와 유물 연결도 함께 정리한다. 녹아내리는 사랑의 탱커형과 딜러형은 별도 구성안으로 센다. 환상체 조우 AI와 보스 본체의 기술은 대상이 아니다.

**추천 방향은 공통 동작을 조합하고, 특별한 상태 관리만 작은 고유 기능으로 남기는 것이다.** 화면의 거미줄·늑대·나비·차원문마다 전투 객체를 만들 필요는 없다. 반대로 투사체 방향이나 이동하는 효과 범위처럼 결과를 바꾸는 정보는 실제 판정에 남겨야 한다.

`기존 방향`은 현재 설계 자료와 대화에서 유지하려는 핵심이다. `조립안`과 `추천`은 이번에 제안하는 세부 동작이며 사용자 합의가 아니다. `검토`에는 결과를 바꾸는 선택을 남겼다. 수치가 이미 언급되어도 초기 검증값과 확정 규칙을 구분한다. `사용자 합의`로 표시한 카드는 후속 첨삭과 답변을 반영한 것으로, 미합의 추천안과 구분한다. 이 문서를 작성하는 것만으로 기존 정책·로드맵·제품 동작을 변경하지 않는다.

## 검토 순서

1. 아래 공통 판정에서 타격·처치·자원·중단의 뜻을 맞춘다.
2. 각 파편의 조립안을 읽고 원하는 플레이와 다른 부분을 고친다.
3. 특히 래티씨아, 붉은 두건, 흉탄의 사수의 단순화 범위를 결정한다.
4. 파고드는 천국 등 active 원칙과 개별 설계가 충돌하는 곳을 정한다.
5. 효과별 태그와 속성으로 어떤 유물을 연결할지 확인한다. 그다음 공통 기능과 고유 기능의 경계를 확정하고, 구현 순서와 수치를 붙인다.

수정 의견은 각 항목의 `첨삭`에 바로 적을 수 있다. 동작이 확정되지 않은 곳의 피해 배율부터 정할 필요는 없다.

## 공통 판정의 출발점

### 시전과 비용

기본 active는 최종 시전 수락 때 공명을 전부 소비한다. 미리보기 취소와 수락 전 거절은 소비하지 않고, 수락 후 중단은 원칙적으로 환불하지 않는다. 대상이 필요한 스킬은 수락 순간 대상의 존재와 자격을 확인한다. 다단계 조준은 최종 확정 전 준비 단계와 비용을 소비한 실행 단계를 구별한다.

공명 충전 재개 시점은 스킬 종류에 맞춘다. 즉시 효과는 처리 종료, 발사형은 발사 종료, 연속 공격은 마지막 공격 종료, 유지형 강화는 상태 종료, 집중형은 집중 종료를 기준으로 삼는다. 별도 장판·거미·지속 피해를 남기는 스킬은 생성 후 그 객체가 사라질 때까지 시전자 사용 상태를 유지하지 않는다. 충전량과 세부 조건은 [전투 공통 규칙](../game_rules/combat.md)을 따른다.

Hello의 마무리처럼 같은 시전의 후속 입력은 새 공명 스킬과 구별한다. 여기에 추가 공명을 요구할지, 사용 중인 스킬을 다시 누르는지 등은 해당 기능의 입력 계약으로 명시한다.

### 한 번의 시전과 여러 타격

한 시전에는 여러 타격이 들어갈 수 있다. 나무꾼의 3타, 여러 거미의 폭발, 연속 탄환을 총 피해 한 번으로 합치면 방어막·피격 효과·실제 HP 손실·처치 귀속·다중타격 유물이 달라진다. 따라서 **연출을 단순화해도 의미 있는 타격 수는 유지하는 안을 기본으로 한다.**

각 피해에는 원래 시전, 직접 타격인지 파생 효과인지, 효과를 만든 직원과 장비·파편 사본을 남긴다. 적중, 보호막을 포함한 피해, 실제 HP 손실, 처치 확정은 서로 다른 조건이다. 어떤 효과가 이 중 무엇을 보는지는 개별 항목에서 정한다.

처치 효과는 죽음 확정 한 번을 기준으로 발생한다. 연쇄 효과가 자기 자신을 무제한 재발동하지 않도록 발생 세대·총 발생량·동일 대상 횟수 중 필요한 제한을 둔다. 모든 스킬에 임의의 동일 제한을 씌우는 뜻은 아니다.

### 대상과 위치

유닛 지정은 그 유닛을, 타일 지정은 그 위치를 고정한다. 지정한 적이 죽었다고 다른 적을 자동으로 선택하지 않는다. 매 타격 새 대상을 찾는 스킬은 그 동작을 명시해야 한다. 타일 폭발은 폭발 순간 그 위치의 적을 다시 조회하므로 원래 적이 빠져나가거나 새 적이 들어올 수 있다.

현재 위치를 따라가는 오라와 시전 위치에 남는 장판, 시전 시 한 번만 보호막을 주는 범위 지원은 서로 다른 기능이다. 이 구분만으로 여러 특수 스킬을 같은 형태로 작성할 수 있다.

### 상태의 주인과 수명

| 상태                          | 소유와 초기화 기준                                           |
| ----------------------------- | ------------------------------------------------------------ |
| 연타 번호·이번 시전의 처치 수 | 한 시전의 실행 기록. 다른 시전과 합치지 않음                 |
| 감염·냉기·개인 방어막         | 대상과 효과 출처. 같은 종류라도 사본별 분리가 필요한지 명시  |
| 거미·장판·발사된 탄환         | 독립 효과. 시전자 이탈 이후 유지 여부를 명시                 |
| 이번 전투의 포만·희생 단계    | 전투 또는 직원의 전투 기록. 재배치를 새 전투로 취급하지 않음 |
| 욕망·발사 횟수 등 원정 누적   | 파편 사본의 원정 기록. 해제·교체만으로 초기화하지 않음       |

재배치된 직원의 새 전투 객체와 동일 직원의 누적 기록을 혼동하지 않는다. 모든 전투 시간은 일시정지 영향을 받는 전투 시계로 계산한다. 원정 상태는 전투 후퇴·체크포인트 복구 시 다른 소비와 함께 일관되게 되돌린다.

### 중단과 연출

강한 행동 제어는 아직 방출하지 않은 동작을 취소할 수 있지만, 이미 발사한 독립 탄환까지 일괄 삭제하지 않는다. 침묵은 신규 시전 차단과 기존 집중 중단을 구별한다. HP 지불은 피해가 아니므로 피격·흡혈·반격 효과를 만들지 않는다.

거대한 도끼나 늑대 입, 여러 조준창, 거미의 도약은 표현 계층에서 그릴 수 있다. 다만 실제 지연·이동·범위 변경이 플레이에 영향을 주면 그 정보는 전투 판정에 있어야 한다. 직원의 돌진 연출을 실제 타일 이동으로 자동 해석하지 않는다.

### 에고 침식

침식은 아래 개별 스킬 조립안을 확대 복사하는 방식보다 공통 처리와 고유 연출로 나누는 편이 맞다. 현재 공통안은 일반 침식체를 즉시 처치하고, 엘리트·일반 보스·최종 보스에는 최대 HP 25% 피해를 초기 검증값으로 사용한다. 보호막·무적·페이즈 하한과 필수 전환은 정해진 규칙을 따른다. 침식으로 장비·유물·파편의 처치 연쇄나 적 사망 효과를 발생시키지 않는다.

직원 대가와 피해 처리의 상세는 [에고 침식 경계](../game_rules/relics.md#에고-침식과의-경계)를 따른다. 과거 개별 노트의 전장 전체 처형 문구를 그대로 새 구현 요구로 옮기지 않는다. 아무 것도 없는의 미정 침식 연출 등은 여기서 새로 확정하지 않는다.

## 재사용할 동작과 남겨둘 고유 기능

다음 이름은 설계를 설명하는 말이며 실제 데이터 문법이나 완성된 API 이름이 아니다.

| 공통 동작                          | 조합 예                                                       |
| ---------------------------------- | ------------------------------------------------------------- |
| 대상 조회와 고정                   | 전방 침식체, 가장 진척한 적, 같은 사본의 감염자, 반경 안 거미 |
| 순서 실행·지연·유한 반복·조건 분기 | 나무꾼 3타, 나비 연속 폭발, 처치 시 회복                      |
| 단일·범위·직선 피해와 회복         | 회사 스킬, 음양 장판, 증오 광선, 풍운승려                     |
| 상태 부여·교체·제거                | 강화, 둔화, 속박, 다음 평타 강화, HP 하한                     |
| 수치 기록·증가·한도·소비           | 검, 포만, 욕망, 발사 횟수, 누적 경감량                        |
| 출처가 있는 이벤트 반응            | 직접 타격 감염, 처치 보상, 사망 잔영, 피격 회복               |
| 독립 효과 생성·진화·소모           | 거미, 장판, 고기 벽, 발사된 탄환                              |
| 타격 결과 집계                     | 실제 회복량 방어막, 실제 HP 손실 흡혈, 처치 수 보상           |
| 개인 보호막과 범위 지원            | 포큐버스의 일회 부여, 태아의 유지 오라                        |

이 기반의 상당 부분은 이미 구현되어 있다. 순서·분기·반복, 독립 객체, 개인 보호막·지원 효과, 일부 사망·처치 반응을 사용할 수 있다. 다만 기반 기능이 존재하는 것과 아래 모든 스킬이 제작·검증되었다는 것은 다르다. 구체적인 작성 형태는 [스킬 제작 모델](skill_authoring_model.ko.md)의 구현된 범위와 대조해야 한다.

고유 기능 후보는 여러 창의 조준 세션, 계약 예산, 방향을 물려받는 분기 탄환, 거미의 동시 예약처럼 **상태 전이 자체가 특수한 부분**이다. 완성된 고유 기능도 설정을 받아 다른 콘텐츠가 재사용할 수 있게 만들되, 내부의 모든 단계를 범용 작성 문법으로 노출할 필요는 없다.

## 태그를 적용하는 기준

태그는 [기초 태그 초안](run_relic_content_design_notes.ko.md#기초-태그-초안)의 한글 이름을 사용한다. 아래 적용표는 이 조립안에 대한 **설계 후보**이며 정식 tag ID·데이터 등록·runtime 지원을 확정하지 않는다. 새 태그를 임의로 늘리기보다 기존 태그와 세부 속성을 함께 사용한다. 사용자 첨삭에서 추가로 지정한 표기는 해당 카드에 출처와 등록 상태를 따로 적는다.

### 분해 축과 태그의 역할

기존 [15개 분해 축](run_relic_content_design_notes.ko.md#15개-공통-분해-축)은 효과를 검토하는 질문이다. 각 카드의 조립 순서·상태·검토 사항과 아래 태그표를 함께 읽는다. 축의 이름을 그대로 태그로 만들지는 않는다.

| 검토할 축                                          | 이 초안에서 기록하는 내용                                |
| -------------------------------------------------- | -------------------------------------------------------- |
| 1 사용·조작, 2 대상·선정, 3 공간, 4 전달·매개      | 입력과 대상 고정, 범위, 실제 투사체·독립 효과 여부       |
| 5 시간, 6 반복·발생, 7 효과 종류                   | 지연·주기·타격 순서와 각 단계의 효과 태그                |
| 8 효과량·참조, 9 집계·분배·공유                    | 계수와 계산 시점, 실제 타격·회복량, 개인량과 공유량 구분 |
| 10 자원·축적, 11 비용·위험, 12 조건·분기·연계      | 스택·소비, HP 비용, 발동 사건·조건과 유물 연결           |
| 13 행동 병행·제약, 14 종료·존속, 15 출처·소유·귀속 | 집중·중단, 만료·이탈, 직원·파편 사본·효과별 출처         |

아래 표의 `변경 후보 속성`은 유물 설계에서 검토할 지점이다. 해당 속성을 공개 편집 기능으로 이미 지원한다거나 아무 유물이나 바꿔도 된다는 뜻은 아니다. 지원 가능한 속성과 수정 범위는 제작 단계에서 확인한다. 값이 미정인 것은 그대로 미정이며, 해당 없는 기능은 태그만으로 새로 만들지 않는다.

### 효과 단위 선택과 출처

- 한 행은 하나의 효과 또는 명시된 공격 순서·영역이다. `·`로 묶은 태그는 그 단위에 함께 적용한다. 다른 행의 태그를 합쳐 조건을 만족시키지 않는다.
- 범위 피해 뒤 자기 회복은 `피해·범위`와 `회복` 두 효과다. 피해 범위를 늘려도 회복 대상은 늘지 않는다.
- `소환물`은 설치물·타일 축적·잔류 영역을 포함한다. HP·이동 AI가 필수는 아니다. 반면 일벌·썰매·늑대 입의 그림만으로 부여하지 않는다.
- 소환물 피해를 고르는 유물은 **생성물과 후속 피해의 관계**를 확인한다. 파편 전체에 `소환물·피해`를 붙이거나, 무관한 피해와 설치 효과를 합쳐 판정하지 않는다.
- `다중타격`은 스킬의 구분된 직접 타격 순서다. 지속 피해의 반복, 한 광역 공격의 여러 대상, 한 타격의 여러 피해 성분은 자동 포함하지 않는다. 독립 거미·분기 탄환처럼 경계에 있는 효과는 별도 판정한다.
- 공격 순서·영역과 실제 피해·회복을 나누어 적은 표는 그 연결도 제작 정의에 기록해야 한다. 특히 다중타격용 유물이 선택하는 실제 직접 피해 효과에 필요한 태그를 명시한다. 별도 행의 태그를 조회 과정에서 무조건 합치거나 타격 수만 보고 엔진이 자동 추론하게 하지 않는다.
- `집중유지`는 실제 행동 제한이 있는 집중이다. 기간형 자기 강화와 조준 화면의 시간 정지는 포함하지 않는다. `투사체`도 실제 충돌·전달 방식이 있는 경우에만 쓴다.
- HP 지불은 `피해`, 능력치 상한 조정은 `회복`, 적중 후 정량 회복은 `흡혈`로 바꾸지 않는다. 처형·계약·변신은 기존 태그만으로 설명이 부족하면 고유 동작과 속성으로 남긴다.

### 유물 조건과 조합

범용 유물은 같은 효과의 태그·세부 속성과 실제 출처 조건을 확인한다. 전용 유물은 지정 파편·장비·기본형/개화형까지 확인하며 일반 태그만 같다고 적용하지 않는다. 새로운 효과에도 태그와 출처를 붙여 다른 유물과 조합할 수 있다.

각 카드의 `유물 연결`은 **기존 설계**와 **새 후보**를 구분한다. 기존 설계도 이름·수치·세부 조건이 미정이면 그 상태를 유지한다. 태그가 호환 후보라는 것만으로 해당 유물의 출시나 현재 구현을 확정하지 않는다.

유물 활성은 현재 실제 효과와 무조건 제공되는 효과에서 시작한다. 서로의 조건만 만들어 주는 유물끼리 스스로 활성화하지 않는다. 장비 변경으로 시작점이 사라지면 다시 평가한다. 전투 중 연쇄는 같은 경로에서 같은 유물 사본의 같은 효과로 되돌아가지 못하며, 분기·합류는 원인 기록을 이어받는다. 모든 효과에 공통 연쇄 횟수 상한을 새로 붙이지 않는다. 에고 침식은 공통 유물 증폭·추가 효과·연쇄에서 제외한다.

## 파편별 조립안

### 1 절망의 기사

**상태: 사용자 첨삭과 후속 답변 반영 — 기본형·개화형 각각의 일반 상태·절망 상태 동작 합의.** 아래 합의안은 이 카드의 이전 초안을 대체한다. 개화형은 2026-10-17 후속 답변까지 반영했다. 미확정 수치와 계산식 제안은 별도로 표시한다. 제품 구현이나 정식 정책 반영이 완료되었다는 뜻은 아니다.

**핵심 흐름:** 파편 메뉴로 가호 대상을 관리 → 가호의 주기마다 검 축적 → 기본형은 다음 기본 공격을 검 소비 연속기로 변경하고 개화형은 검 전량을 소비하는 범위 낙검 → 가호 대상의 HP 0 퇴각 시 다음 행동 직전에 절망 전환 → 검을 보존하며 기본형은 엑시큐션, 개화형은 검 수에 따라 유지 시간이 늘어나는 범위 공격으로 변경.

#### 가호 지정과 검 생성

- 전투 중 파편 우측 메뉴에서 아군을 지정한다. 자신도 지정할 수 있다. 동시에 가호를 부여할 수 있는 대상은 1명이다. 지정 횟수를 전투당 1회로 제한하는 뜻이 아니다.
- 현재 가호 대상을 다시 선택하면 가호를 해제한다. 다른 아군을 선택하면 기존 가호를 제거하고 새 대상에게 부여한다. 같은 대상을 다시 선택하는 것만으로 재부착하지 않는다.
- 가호는 받는 모든 피해를 20~30% 감소시킨다. 이 범위는 밸런스 조정값이다.
- 가호 대상의 HP가 최대 HP의 10% 이하가 되면, 전투 중 1회 최대 HP의 50%에 해당하는 보호막을 15초간 부여한다. 이미 HP가 10% 이하인 살아 있는 아군에게 가호를 붙여도 즉시 발동한다. HP 0으로 사망한 대상을 되살리는 효과는 아니다.
- 긴급 보호막의 사용 기록은 파편에 남는다. 가호를 해제하거나 다른 대상에게 옮겨도 전투 중 1회 사용 기록을 초기화하지 않는다.
- 가호는 부착 시점부터 자체 쿨다운을 진행하며, 완료할 때마다 파편 소유자에게 검 1스택을 부여하고 다음 주기를 시작한다. 새로 부착한 가호의 타이머는 처음부터 시작한다. 주기 길이는 미정이다.
- 검의 기본 최대량은 4개다. `스택한도해제` 유물이 적용되면 이 명시된 스택 한도를 무시한다. `스택획득`은 가호 쿨다운 완료 시 검 획득량을 1개에서 2개로 바꾸고, `쿨다운속도감소`는 해당 쿨다운의 완료 시간을 단축하는 방향으로 연결한다. 시간 감소율·계산식은 미정이다.

#### 기본형 일반 상태의 강화 공격

스킬 시전은 다음 기본 공격을 강화 공격으로 변경한다. 첫 공격과 네 후속 단계는 하나의 강화 공격에 속하며, 단계마다 새 공명 스킬을 시전하는 것으로 취급하지 않는다.

1. 주 대상에게 중간 정도의 피해를 주는 찌르기를 1회 수행하고 1초간 기절시킨다. 검이 없어도 이 공격은 수행한다.
2. 강화 공격 시작 시 보유 검 수를 `S`로 기록하고, 후속 단계당 소비량을 `c = max(1, floor(S / 4))`로 한 번 확정한다. 남은 검 수로 매 단계 다시 나누지 않는다.
3. 아탕호 → 에스토카다 → 데스비오 → 엑시큐션 순으로 수행한다. 각 단계 시작 시 검 `c`개를 소비한다. 필요한 검이 부족하면 남은 단계를 종료하며, 엑시큐션까지 수행하면 연속기는 끝난다.
4. **각 단계의 공격을 처리한 직후**, 그 단계에서 실제 소비한 검 1개당 주 대상에게 상처 1스택을 부여한 다음 다음 단계로 진행한다. 즉 아탕호 → 상처 `c`스택 → 에스토카다 → 상처 `c`스택 → 데스비오 → 상처 `c`스택 → 엑시큐션 → 상처 `c`스택 순서다. 상처는 받는 모든 피해를 스택당 5% 증가시킨다. 지속 시간은 5초이며 스택이 증가하면 전체 지속 시간을 다시 5초로 설정한다. 앞 단계에서 부여한 상처는 지속 중인 동안 뒤 단계의 피해에도 적용된다.

| 단계       | 실제 동작                                                                          | 초기 위력·제어                                              |
| ---------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 첫 찌르기  | 주 대상 1회 찌르기                                                                 | 중간 피해, 기절 1초                                         |
| 아탕호     | 레이피어를 위에서 아래로 휘두르기                                                  | 약한 피해, 기본 공격 불가 3초                               |
| 에스토카다 | 강한 찌르기                                                                        | 높은 피해                                                   |
| 데스비오   | 1초 방어 자세 동안 자신에게 받는 피해 감소 20% 부여 → 자세 종료 후 전방 2칸 찌르기 | 중간 피해, 기절 1초                                         |
| 엑시큐션   | 주 대상에게 연속 찌르기 `n`회                                                      | 매우 강한 정도의 피해를 각 타격에 적용. `n`과 배율은 조정값 |

| 시작 검 수 | 단계당 소비량 | 완주 시 소비량 | 남는 검 수 |
| ---------- | ------------- | -------------- | ---------- |
| 4          | 1             | 4              | 0          |
| 8          | 2             | 8              | 0          |
| 16         | 4             | 16             | 0          |

위 예시는 도중에 새 검이 생성되지 않은 경우다. 4의 배수가 아닌 보유량은 몫으로 계산하므로, 예를 들어 7개에서 시작하면 단계마다 1개씩 사용하고 3개가 남는다. 검 소비량이 해당 단계의 기본 피해 배율이나 타수를 직접 늘리지는 않는다. 소비량에 연동해 각 단계 직후 부여하는 상처가 누적되며, 뒤 단계의 공격은 앞서 쌓인 상처의 피해 증가를 적용받는다.

`다음.` 유물 미적용 시, 주 대상이 도중에 사망하면 남은 연속기는 종료하고 다른 적에게 넘기지 않는다. 아직 시작하지 않은 단계의 검은 소비하지 않으며, 이미 소비한 검은 반환하지 않는다. 사망한 대상의 상처를 다른 적에게 이전하지 않는다.

#### 공통 절망 전환과 기본형 엑시큐션

- 가호 대상이 **HP 0에 의한 퇴각**을 하면 절망 전환을 예약한다. 수동 퇴각은 절망을 일으키지 않는다.
- 현재 행동 전체를 마친 뒤 다음 행동 직전에 절망에 진입한다. 일반 연속기의 에스토카다 도중 가호 대상이 죽어도, 행동을 계속 수행할 수 있다면 남은 데스비오·엑시큐션까지 마친 다음 전환한다. 주 대상 사망 등 현재 행동의 종료 조건은 그대로 적용한다.
- 자신에게 가호가 부여된 상태에서 자신이 HP 0이 되면 그냥 사망 처리한다. 죽은 장착자에게 별도의 절망 행동이나 부활을 부여하지 않는다.
- 절망에 진입하면 가호를 새로 부여할 수 없다. 가호 대상이 나중에 부활해도 절망은 유지된다.
- 진입 시 보유한 검을 자신에게 꽂아 **검 1개당 최대 HP의 5% 고정 피해**를 준다. 보호막을 무시하고, 이 피해로 HP 0 퇴각이 가능하다. 체력 지불이나 최대 HP 감소로 바꾸지 않는다. 이 피해 규칙과 수치는 추후 밸런스 조정 대상이다.
- 진입 피해로 검을 소비하지 않는다. 절망 상태에서 엑시큐션을 시전해도 검을 소비하지 않는다.
- 기본형 절망 상태의 스킬은 다음 기본 공격을 기다리지 않고 엑시큐션을 즉시 시작한다. 절망 진입 자체가 무료 엑시큐션을 발동시키는 것은 아니다.
- 절망 엑시큐션은 기본 타수 `n`에 현재 검 수만큼 타수를 더한다. 타수가 늘어도 전체 시전 시간은 늘어나지 않는다. 각 타격은 같은 시간 안에 순서대로 처리하며, 총피해 한 번으로 합치지 않는다.
- 적중할 때마다 **이번 엑시큐션에서 해당 대상에게 주는 후속 타격 피해만 10%씩 증가**시킨다. 먼저 현재 타격을 처리한 다음 후속 타격의 증가량을 쌓는다. 받는 모든 피해 증가나 일반 상태의 상처가 아니다. 다른 공격·다른 시전·다른 대상에 적용하지 않으며, 이번 엑시큐션 종료 시 초기화한다.
- `다음.` 유물 미적용 시 절망 엑시큐션도 주 대상 사망 시 남은 타격을 종료하고 다른 적에게 넘기지 않는다.

#### 개화형

가호 지정·해제, 검 생성과 한도, 긴급 보호막의 전투 중 1회 기록, 절망 전환 조건과 진입 피해는 위 공통 규칙을 사용한다. 공격은 기본형의 단일 대상 연속기 대신 타일을 지정하는 범위 공격으로 바뀐다.

**개화 일반 — 큰 검과 작은 검의 순차 낙하**

1. 타일을 지정하면 그 중앙에 큰 검을 소환하고, 현재 보유한 검 스택 수만큼 주변에 작은 검을 생성하는 연출을 한다.
2. 큰 검을 방출할 때 보유 검 수를 확정하여 전부 소비하고, 그 수만큼 작은 검의 후속 공격 횟수를 확정한다.
3. 큰 검이 지정 타일 중앙에 꽂히면서 범위 안의 적에게 큰 피해를 주고 2초간 기절시킨다.
4. 이후 작은 검들이 차례대로 내려꽂히며 피해를 준다. **작은 검도 각각 큰 검과 동일한 범위 전체에 피해를 준다.** 작은 검의 시각적 낙하지점으로 실제 피해 범위를 나누지 않는다.

각 낙검은 별도 타격이며, 해당 타격 시점의 범위 안 적을 판정한다. 한 적을 고정해 끝까지 쫓는 공격이 아니므로 처음 맞은 적이 사망해도 고정된 타일에 대한 나머지 공격은 이어진다. 작은 검의 피해량과 낙하 간격은 조정값이다. 큰 검의 2초 기절을 작은 검마다 반복 부여하는 것으로 확대하지 않는다.

**개화 절망 — 검이 솟아오르는 유지형 범위 공격**

1. 스킬을 시전하면 몸에 꽂힌 검들이 뽑혀 하나의 큰 검으로 합쳐지고, 지정 타일 중앙에 꽂힌다. 검 스택은 소비하지 않는다.
2. 스킬 범위의 바닥에서 검이 위로 솟아오르는 연출을 유지한다. 실제 판정은 **0.5초마다 현재 범위 안의 모든 적에게 피해를 주는 주기 공격**이다. 각 검을 별도 이동 객체로 계산할 필요는 없다.
3. 적이 주기 피해를 받을 때마다 그 적에게 상처 1스택을 부여한다. 상처는 스택당 받는 모든 피해 5% 증가, 5초 지속이며 스택 증가 시 지속 시간을 다시 5초로 설정한다. 이번 타격을 처리한 뒤 상처를 추가하여 다음 피해부터 반영한다.
4. 시전 유지 중 **1초마다 자신의 최대 HP 10%에 해당하는 피해**를 받는다. 이 유지 피해에는 보호막과 피해 감소가 적용된다. 절망 진입 시의 보호막을 무시하는 검당 최대 HP 5% 고정 피해와 별도 효과로 처리한다.
5. 검 수가 많을수록 최대 유지 시간이 늘어난다. 시간이 다 되면 자동 종료한다. 사용자가 직접 중단하거나 시전자가 사망해도 종료한다.
6. 기절·빙결처럼 행동을 막는 군중제어 또는 **침묵을 받으면 진행 중인 시전도 즉시 종료**한다. 둔화처럼 행동을 막지 않는 효과에는 유지한다. 침묵이 진행 중 시전을 끊는다는 것은 이 스킬에 명시된 중단 규칙이다.
7. 시전이 종료되면 이후의 범위 주기 공격과 유지 자기 피해도 끝난다. 이미 부여된 상처는 자신의 5초 지속 규칙을 따른다.

범위와 공격 주기 0.5초는 검 수로 바뀌지 않고, 검 수는 유지 시간에 연결한다. 이전 검토에서 제안했던 검 수에 따른 주기 타격 피해량 증가는 이번 합의에 포함하지 않는다. 상처는 일반 피해를 증폭하는 실제 디버프이며, 기본형 절망 엑시큐션의 시전 내부 후속 타격 증가량과 구분한다. 계속 범위 안에서 피해를 받는 적에게 상처가 누적되는 것은 의도한 동작이고, 추후 밸런스 검토 대상이다.

**유지 시간 계산식 제안:** 시전 시작 시 보유 검 수 `S`로 최대 유지 시간을 확정하고, `T = 기본 지속 시간 + S × 검당 추가 시간`으로 계산하는 안을 제안한다. **검 수에 따라 시간이 증가한다는 방향은 합의했지만, 이 계산식과 각 시간 값은 아직 확정하지 않았다.** 공격·자기 피해의 최초 발생 시점, 종료 시각과 주기가 겹칠 때의 처리 순서는 후속 시간 규칙으로 정리한다.

| 형태 | 검 사용 | 공격 방식 | 종료·중단 |
| --- | --- | --- | --- |
| 기본형 일반 | 시작 수로 정한 단계당 소비량 | 단일 대상 중심 강화 기본 공격과 연속기 | 완주·검 부족·대상 사망 및 공통 중단 규칙 |
| 기본형 절망 | 보존 | 같은 총시간 안에 `n + 검 수`회의 엑시큐션 | 공격 종료·대상 사망 및 공통 중단 규칙 |
| 개화형 일반 | 큰 검 방출 때 전량 소비 | 큰 검 1회 후 작은 검 수만큼 동일 범위 순차 타격 | 순차 공격 종료 및 공통 중단 규칙 |
| 개화형 절망 | 보존 | 0.5초 주기 범위 공격·상처 누적, 1초 주기 자기 피해 | 검 수에 따른 시간 만료·직접 중단·사망·행동 차단 군중제어·침묵 |

#### 상태·태그·기능 경계

가호 대상, 긴급 보호막 사용 여부, 검 수, 일반/절망 전환 예약/절망 상태는 전투의 파편 기록이다. 가호 타이머는 부착된 가호에, 시작 검 수·단계당 소비량·실제 소비량은 이번 강화 공격에, 절망 엑시큐션의 후속 피해 증가량은 이번 시전과 대상에 귀속한다. 개화형의 선택 타일·남은 낙검 수·유지 시간·범위 공격과 자기 피해의 두 주기·중단 상태는 해당 시전의 기록이다. 타격의 출처도 유지해 강화된 기본 공격과 절망 상태의 직접 스킬 공격을 무조건 같은 판정으로 합치지 않는다.

파편 메뉴의 대상 선택·해제, 보호 관계 변경, 주기적 스택 생성, 다음 기본 공격 교체, 순차 실행과 단계별 소비, 조건부 보호막, 상태 전환 예약을 조합한다. 개화형에는 타일 고정 범위 공격, 검 수에 따른 유한 순차 타격, 유지형 영역과 두 주기, 직접 중단 입력 및 군중제어·침묵에 의한 종료가 필요하다. 메뉴는 실제 기능 추가가 필요한 기반이며, 현재 구현 완료로 표시하지 않는다. 검의 부유·자기 관통·빠른 찌르기·바닥에서 솟는 검은 연출로 표현하되, 개별 타격과 상태 전환 순서는 실제 판정으로 유지한다.

#### 태그와 유물 적용 — 2026-10-18 사용자 합의

아래 10개는 절망의 기사에 적용하기로 합의한 태그와 유물 효과다. `다중타격`은 직접 연타 구조를 나타내는 기존 태그이며 깊은 쐐기와 연결한다. 실제 유물 효과는 해당 유물이 적용될 때 발생하며, 파편의 기본 효과에 모두 상시 포함되는 뜻은 아니다. `피해`·`제어`·`스택` 등의 일반 분류 외에 유물과의 연결이 합의된 태그를 기록한다.

| 합의한 태그 | 유물 효과 | 절망의 기사 적용 지점 |
| --- | --- | --- |
| `다중타격` | 깊은 쐐기: 같은 시전·같은 대상의 직접 타격마다 피해 증가율 `+2%p`, 최대 `+20%`. 첫 타격부터 적용 | 기본형 일반 연속기·기본형 절망 엑시큐션·개화형 일반 큰 검과 작은 검. 개화형 절망의 장판 주기 피해는 제외 |
| `쿨다운속도감소` | 쿨다운 완료까지 걸리는 시간 단축 | 가호의 검 생성 쿨다운. 공명 충전이나 개화 절망의 공격·자기 피해 주기와 구분 |
| `치명적인군중제어` | 강력한 군중제어를 가한 대상에게 5초간 받는 피해 증가 | 첫 찌르기·데스비오·개화 일반 큰 검의 기절. 공통 유물 이름은 가칭 `깨진 균형` |
| `스택한도해제` | 해당 효과에 명시된 스택 한도 무시 | 검의 기본 최대 4개 제한 무시 |
| `보호막효율증가` | 생성하는 보호막량을 퍼센트로 증가 | 가호의 긴급 보호막량. 발동 HP 조건·전투당 횟수·지속 시간과 구분 |
| `스택부여` | 대상에게 부여하는 스택량 2배 | 기본형은 각 단계 직후 상처 `c → 2c`, 개화 절망은 주기 피해마다 상처 `1 → 2` |
| `스택획득` | 자신이 획득하는 스택량 2배 | 가호 쿨다운 완료 시 파편 소유자가 얻는 검 `1 → 2` |
| `범위증폭` | 단일 대상 스킬은 작은 범위 스킬로 전환, 기존 범위 스킬은 한 칸씩 확장 | 기본형의 단일 대상 공격, 데스비오의 전방 공격, 개화 일반의 큰 검·작은 검, 개화 절망의 공격 영역 |
| `무아지경` | 스킬 시전 중 군중제어·침묵 등 외부 효과에 의한 시전 행동·집중 중단 방지 | 진행 중인 검술의 시전 행동과 개화 절망의 집중 유지. 직접 중단·시간 만료·사망·퇴각 등 원래 종료 조건은 유지 |

**아직 미정인 항목:** 쿨다운 단축률·계산식, 보호막 증가율, 강력한 군중제어 유물의 피해 증가율·최종 이름·희귀도, 변환된 작은 범위의 크기와 모양별 확장 판정. 이 미정 사항은 위 효과 방향의 합의를 되돌리는 것이 아니다. 정식 태그 ID와 데이터·엔진 구현은 별도 작업이다.

**유물 연결:** **깊은 쐐기**는 위 `다중타격` 직접 공격에 적용하며, 같은 시전·같은 대상의 10번째 유효 타격부터 `+20%`를 유지한다. 새 대상은 자기 적중 횟수로 계산하고 새 시전은 누적을 초기화한다. 강화된 기본 공격의 출처는 그대로 유지한다. 이 상한은 깊은 쐐기의 보너스만 제한하며 검 수·타격 수·상처·엑시큐션 자체의 후속 피해 증가에는 적용하지 않는다. 상세는 [깊은 쐐기 설계](run_relic_content_design_notes.ko.md#깊은-쐐기--가칭)를 따른다. 검 한도 해제는 기본형 일반 연속기의 단계당 소비량과 상처 수, 절망 진입 피해와 엑시큐션 타수, 개화형 일반의 작은 검 수와 개화형 절망의 유지 시간에 영향을 준다. 개화형 절망의 보호막·피해 감소 지원은 유지 자기 피해를 줄일 수 있으며, 공격과 자기 피해를 같은 범위 피해 증폭 대상으로 자동 결합하지 않는다. 추가 태그의 정의는 [효과 변형 태그](run_relic_content_design_notes.ko.md#효과-변형-태그--2026-10-18-사용자-추가)에 기록했다. 정식 ID·지원 속성 등록이 완료되었다는 뜻은 아니다. 기존 무기 상처와 새 파편 상처의 동명 관계 및 중첩 범위는 장비 연결 검토에서 맞춘다.

**합의한 적용 구분:** `스택획득`은 검을 얻는 사건에, `스택부여`는 상처를 붙이는 사건에 연결한다. 같은 검 생성에 두 효과를 겹쳐 자동으로 4배 적용하지 않는다. `범위증폭`은 공격 범위 변형으로 연결하며 가호의 동시 보호 대상 1명 제한을 자동 변경하지 않는다. 단일 공격의 작은 범위 크기와 기절·상처까지 함께 범위화할지는 후속 효과 연결에서 명시한다.

**무아지경과 종료 — 2026-10-18 후속 합의:** 유물 미적용 시 개화 절망의 군중제어·침묵 중단 규칙은 위와 같다. `무아지경`의 공통 정의를 **스킬 시전 중 군중제어·침묵 등 외부 효과로 시전 행동이나 집중이 중단되지 않는다**로 확장한다. 집중형에만 한정하지 않으며 진행 중인 검술 시전에도 같은 원칙을 적용한다. 기절·빙결·침묵 상태와 강제 이동 자체의 부착 면역을 부여하는 것은 아니지만, 그것 때문에 진행 중인 시전 동작·집중을 멈추지는 않는다. 강제 이동 후에도 개화 절망의 공격 범위는 처음 지정한 타일에 고정된다. 직접 중단·지속 시간 만료·사망·퇴각 등 원래 종료 조건, 피해·디버프와 유지 자기 피해는 유지한다. 침묵 중 새 스킬을 시작하게 하거나 시전과 무관한 다른 행동 제한을 없애는 효과는 아니다.

**신규 공통 유물:** 가칭 **깨진 균형**은 첫 찌르기·데스비오·개화 일반 큰 검의 강력한 군중제어에 연결해 대상에게 5초간 받는 피해 증가를 부여한다. 이름은 추천안이고 증가율은 미정이다. 상처와 별도 유물 출처 효과이며 상세는 [공통 유물 설계](run_relic_content_design_notes.ko.md#깨진-균형--강력한-군중제어-범용-유물이름-가칭)를 따른다.

**대상 사망 후 연결 — 2026-10-18 합의:** 기본형 일반 연속기와 기본형 절망 엑시큐션에 `공격이어가기`를 연결한다. 희귀 유물 **다음.**을 적용하면 현재 대상이 사망했을 때 그 사망 위치에서 한 칸 이내의 가장 가까운 적에게 남은 연속기 단계·엑시큐션 타격을 이어간다. 시전자와 새 대상 사이의 사거리는 제한하지 않는다. 아군이 대상을 처치해도 발동하고, 새 대상도 사망하면 같은 방식으로 이어가며, 주변에 적이 없으면 종료한다. 태그만으로는 자동 대상 변경이 발생하지 않는다. 상처를 이전하거나 공격 순서를 처음부터 재시작하지 않는다. 깊은 쐐기의 누적은 새 대상의 기록으로 계산한다. 상세와 미정 세칙은 [다음. 설계](run_relic_content_design_notes.ko.md#다음--희귀-범용-유물)를 따른다.

**후속 조정:** 검 생성 주기, 가호 경감률의 최종값, 각 공격의 배율·간격, 엑시큐션 기본 타수 `n`과 총 시전 시간, 개화형 범위·피해량·작은 검 간격·절망 유지 시간 계산식을 남긴다. 개화형 절망의 큰 검 설치 순간에 별도 피해가 있는지는 아직 명시하지 않았으므로 주기 피해 외의 타격을 임의로 더하지 않는다. 복수 파편 사본 사이의 상태 공유, 장비·유물과의 상세 판정은 후속 연결 검토 대상이다. 이를 이유로 위 합의된 동작을 이전 초안으로 되돌리지 않는다.

아래는 사용자가 문서에 적은 원문이다. 단계당 소비량, 절망 전환 시점, 상처 및 절망 엑시큐션의 증폭 범위 등 후속 답변으로 수정된 동작은 위 합의안을 따른다.

첨삭:
전투 중 언제든지 파편 우측 메뉴(이하 파편 메뉴)에서 버튼을 눌러 대상을 지정할 수 있다.
대상은 아군만 지정할 수 있으며 본인 포함이다. 지정 가능 최대 횟수는 1회 이다.
지정하면 대상에게 보호 버프(이하 가호)를 부여한다. 해당 버프는 이미 해당 버프를 소지하고 있는 유닛이 파편 메뉴로 재지정 되거나, 다른 대상이 지정되는 경우에 기존 유닛에게 부여된 버프는 사라진다. (축약하면 버프는 전장에서 오직 한 유닛에게만 부착될 수 있다.)
가호의 효과는 다음과 같다.

1. 받는 모든 피해를 20~30% 감소 시킨다.
2. 전투 중 1회, 체력이 10% 이하가 된다면 최대체력의 50%에 달하는 보호막을 15초간 부여한다. 해당 효과는 가호가 재지정되어도 상태가 유지된다. 재지정된다 해서 횟수가 초기화되지 않는다.

아군에게 부착된 가호는 자체적으로 쿨다운을 가진다. 해당 쿨다운은 가호가 부착된 시점부터 시작된다.
쿨다운이 완료될 때마다, 절망의 기사 파편 소유자에게 "검" 스택을 1회 부여한다. 스택의 최대 한도 4개이며, 유물로 변경될 수 있다. (태그: 스택한도해제)

절망의 기사 스킬을 시전하면 다음 기본 공격을 강화 공격으로 변경한다.
강화된 공격 다음처럼 진행된다.

1. 먼저 1초간 기절시키는 찌르기 공격을 1회 가한다. 중간 정도의 피해.
2. 현재 "검" 스택을 가지고 있다면 스킬 [아탕호], [에스토카다], [데스비오], [엑시큐션] 연속 수행한다. 스킬 1회당 현재 보유중인 스택 갯수를 4로 나눈 몫을 소비한다. 만약 몫이 0이라면 1회를 고정 소모한다. 스택이 부족하다면 스킬이 중단된다. 엑시큐션을 수행하면 스킬을 종료한다.
   2-1. [아탕호]: 레이피어를 위에서 아래로 휘둘러 피해를 입힌다. 상대에게 기본 공격 불가 효과를 3초간 부여한다. 약한 정도의 피해.
   2-2. [에스토카다]: 레이피어를 강하게 찔러 피해를 입힌다. 높은 피해.
   2-3. [데스비오]: 1초간 방어자세를 취한다. 방어 자세동안 자신에게 받는 피해 감소 20% 을 부여한다. 방어 자세가 종료되면 전방 2칸을 강하게 찔러 중간 정도의 피해를 주고 1초간 기절 시킨다.
   2-4. [엑시큐션]: 타겟에게 연속 찌르기를 하여 매우 강한 정도의 피해를 n회 입힌다.
3. 소모된 스택 1회당 대상에게 [받는모든피해증가5%] 을 부여한다.

가호를 부여한 유닛이 사망한다면(hp 0 에 의한 퇴각) 절망의 기사 파편 장착자는 즉시 절망 상태로 진입한다.
가호를 더 이상 새롭게 부여할 수 없으며, "검" 스택만큼 자기 자신에게 꽂아 최대체력 5%의 데미지를 가한다. 이 피해로 hp=0 퇴각이 가능하다. 스택은 유지된다.
스킬 파편을 시전하면 엑시큐션이 즉시 발동된다. 이때 발동되는 엑시큐션의 타수는 현재 보유중인 스택만큼 증가한다.
스택이 많다고 엑시큐션의 시전 시간이 늘어나지 않는다.
엑시큐션의 타수가 적중할 때마다 대상에게 [받는모든피해증가10%] 을 부여한다.

### 2 증오의 여왕

> 상태: 2026-10-18 사용자 합의 — 광선·하트·수동 블랙홀·히스테릭 자동 공격과 아래 7개 태그.
> 이름·시간·수치는 작업안이며 세부 판정과 실제 구현은 별도다.

**일반 광선:** 타일을 지정해 고정 방향으로 2초간 집중 광선을 발사한다. 0.5초마다 광선에 닿은 적에게 피해를 주고 아군을 회복한다. 끝까지 시전하면 하트 1개, 같은 시전에서 적에게 실제 피해를 주고 아군의 HP도 실제로 회복했다면 추가 1개를 얻는다. 각 보상은 시전당 한 번이다. 하트는 완료 후 얻으므로 발사 중인 광선이 갑자기 아군 공격으로 바뀌지 않는다.

**하트:** 최대 6개의 전투 로컬 자원이다. 파편 사본에 귀속하고 후퇴·전투 종료·사망 시 초기화한다. 전술 이동으로는 사라지지 않는다. 전장에 배치된 동안 15초마다 1개를 자동 획득한다. 블랙홀로 하트를 소비하면 자동 획득 타이머도 초기화하고, 히스테릭 공격 중에는 정지했다가 정상 상태 복귀 후 다시 센다. 다음 전투로 횟수를 보존하던 이전 안은 대체한다.

**기본형:** 하트 3~5개에서 공명 만충이면 파편 메뉴로 광선 대신 블랙홀을 선택할 수 있다. 시전 확정 시 하트를 전부 소비한다. 지정 타일에 2초 동안 블랙홀을 만들고 0.5초마다 침식체 적을 중심으로 여러 차례 끌어당기며, 범위에 닿은 아군을 회복한다. 아군과 환상체는 이동시키지 않는다. 소비한 하트가 많을수록 흡인 범위·회복량이 증가하고 유지 시간은 고정한다.

**개화형:** 하트 0개여도 공명 만충이면 블랙홀을 선택한다. 0개에서는 기본 성능, 1~5개에서는 전부 소비해 강화한 성능을 사용한다. 2초 블랙홀 뒤 중심에서 위로 솟구치는 빛기둥을 3초간 유지하며, 닿은 적에게 반복 피해·아군에게 반복 회복을 준다. 빛기둥의 피해·회복량은 소비 하트에 비례한다. 전체가 하나의 집중 시전이고 이 연속 시전으로 하트를 다시 얻지 않는다. 환상체도 범위 안에서 피해를 받지만 흡인되지는 않는다.

**히스테릭:** 광선 또는 시간에 따른 획득으로 하트 6개에 도달하면 블랙홀과 후속 공격을 강제로 자동 시전한다. 기본형은 시전자에게서 블랙홀 중심을 향하는 광선, 개화형은 중심에서 솟구치는 빛기둥이다. 블랙홀과 후속 공격 모두 아군·적군에게 강력한 피해를 주며 회복하지 않는다. 흡인은 침식체 적에게만 적용한다. 아군은 피해만 받고 이동하지 않으며 환상체도 흡인되지 않는다. 공격이 끝나면 하트를 전부 소진하고 정상 상태로 돌아온다. 히스테릭 강화 상태를 유지하거나 발동을 미루는 선택은 없다.

**자동 시전 위치와 예고:** 마지막 일반 광선에서 지정한 고정 타일을 사용한다. 타이머로 6개가 되어도 같은 규칙이며 유닛 이동·사망을 추적하지 않는다. 아직 광선을 쓰지 않았다면 시전자 타일을 중심으로 삼고 기본형 광선은 현재 바라보는 방향으로 발사한다. 예정 타일을 계속 표시하고, 6개 도달 가능성이 있는 조준에서는 위험 범위를 함께 보여 준다. 하트 5개에서는 다음 자동 획득까지 남은 시간을 강조한다.

**회복 경계:** 파편의 회복은 비히스테릭 광선·블랙홀·빛기둥에 실제로 닿은 아군에게 해당 회복 주기에만 발생한다. 범위 밖 회복이나 히스테릭 회복은 없다. 장비 자체의 회복·결계와 파편 효과의 출처는 구분한다.

위 7개는 사용자가 선택한 유물 연결 목록이다. `피해`·`회복`·`범위`·`제어(끌어당김)`·`집중유지` 등 구조를 설명하는 분류와 구분한다. 긴 호흡·울림통·깊은 쐐기·다음. 등을 이번 합의 목록에 자동 추가하지 않는다. 공통 정의와 유물 후속 설계는 [증오의 여왕 유물 연결](run_relic_content_design_notes.ko.md#증오의-여왕-태그와-유물-연결--2026-10-18-사용자-합의)을 따른다.

**미정:** 자동 시전의 추가 공명 소비, 다른 시전 도중 타이머로 6개가 되었을 때의 처리, 중단 시 처리, 새 전투의 타이머·지정 타일 초기 상태, 기본형 폭주 광선 지속 시간, 수동 블랙홀의 유효 대상 부재, 피해·회복·범위 수치와 위 유물 세부 판정. 스택 획득 증폭으로 6개를 초과할 때 6개로 제한해 한 번 발동하고 초과분을 넘기지 않는 안은 추천이며 아직 별도 확정 전이다. 사망·후퇴 시 하트 초기화는 미정이 아니다.

상세 설계는 [파편 원본](abnormality_skill_fragments_design_notes.md#증오의-여왕)에 반영했다. 조우 본체의 히스테릭 조건이나 별도 침식형을 이 플레이어 파편 상태와 합치지 않는다.

첨삭:

### 3 음양

**상태: 2026-10-18 사용자 합의 — 음·양의 회복·순환 회복·교집합 버프, 전용 이스터에그 유물과 5개 태그 연결을 반영했다.** 회복량·버프 종류·세부 판정은 미정이다.

**합의한 핵심:** 음과 양을 별개 파편으로 나누지 않고 하나의 파편으로 다룬다. 두 위치를 지정해 한쪽에는 **음의 영역**, 다른 쪽에는 **양의 영역**을 만들고 지속 시간 동안 두 구역의 아군을 회복한다. 기존 단일 위치 회복 장판을 이 구조로 대체한다. 전용 유물의 용 전환이 없는 기본 동작은 적 피해나 아군 HP 희생을 요구하지 않는 회복·지원 역할을 유지한다.

**영역별 효과 — 후속 합의:** 음 또는 양만 존재하는 독립 영역에서는 아군을 회복한다. 음과 양이 겹치는 교집합에서는 아군을 회복하고 이로운 버프를 부여한다. 교집합의 회복량 증가·양쪽 회복 중복 적용 여부는 확정하지 않는다. 버프 종류·수치·지속·재부여·영역 이탈 시 처리는 미정이며, 앞서 제안한 피해 감소·공격 속도 증가와 `조화` 명칭은 확정 사항이 아니다. 이 버프는 파편 자체의 교집합 효과이며 회복 후 버프를 주는 유물과 구분한다.

**순환 회복 — 후속 합의:** 음과 양의 기본 회복 성질은 같게 둔다. 각 회복 주기에 두 영역이 먼저 각자 아군을 회복하고, 아군 HP가 가득 차 쓰이지 않은 회복량 일부를 반대 영역의 부상 아군에게 추가 회복으로 전달한다. 전달하는 쪽에도 아군이 있어야 하며, 아군이 없는 빈 영역에서 전달 회복량을 만들지 않는다. 전달된 추가 회복의 초과분은 다시 반대편으로 보내지 않는다. 전달 비율·여러 아군의 초과 회복 집계·수혜자 배분은 미정이다.

**조립 검토안:** 두 타일 지정 → 음·양 회복 영역 생성 → 정해진 주기마다 각 영역의 현재 아군 조회 → 회복·순환 회복, 교집합의 아군에게 이로운 버프 제공이다. 버프의 부여 시점은 회복 주기와 동일하다고 확정하지 않는다. 범위 밖으로 나간 아군에게 별도 지속 회복을 남기지 않는 기존 방향을 유지한다. 두 위치를 고르는 순서와 시전 확정·영역 생성 시점은 미정이며, 장판 생성 후 시전자 스킬 사용을 끝내는 독립 설치 방식은 제안 상태다.

**상태와 표현:** 두 영역의 위치·수명·회복 주기를 구분한다. 이전의 단일 장판 흑백 파동 교대 설명 대신 음의 영역과 양의 영역을 공간적으로 구분한다. 이름과 색의 차이만으로 서로 다른 버프·피해·회복 계수를 확정하지 않는다. 순수 회복 무기, HP 구간에 따른 방어구 보정 교체, 기본 회복 행동당 한 번의 액세서리 자기 회복은 별도로 유지한다.

**기능 경계:** 공통 고정 장판과 주기 회복으로 구성한다. 개화형은 별도 상세 설계가 없어 추가하지 않는다.

**미정:** 영역별 범위·회복량·주기·지속 시간, 두 위치 사이의 거리, 교집합의 회복량·중복 회복과 순환 회복의 관계, 버프 종류·수치·부여 및 종료 조건, 순환 회복의 전달 비율·집계·배분, 생성 즉시 첫 회복 여부, 재시전 교체·여러 사본 중첩, 시전자 이탈 시 존속. 독립 설치·즉시 첫 회복·재시전 교체는 계속 제안 상태다. 다른 시전·파편 사본 사이의 겹침은 별도 미정이다.

**태그와 유물 적용 — 2026-10-18 사용자 합의**

아래 5개를 음양의 유물 연결 목록으로 채택한다. 연결 방향의 합의이며 미정 수치·버프 종류와 정식 태그 ID·구현까지 확정하는 것은 아니다.

| 합의한 태그·효과 | 음양 적용 지점 | 남은 판정 |
| --- | --- | --- |
| `회복량 증가` | 음·양 장판의 회복량 강화. 기존 가하는 회복량 증가 유물과 연결 | 최종 증가율·이름·등급, 초과 회복 집계와 전달된 순환 회복의 재증폭 여부 |
| `회복한 아군에게 버프 부여` | 실제로 회복한 아군에게 유물의 추가 버프 제공. 교집합 밖에서도 회복받으면 적용 가능 | 버프 종류·수치·지속·재부여·중첩, 회복 0·초과 회복·자기 회복·순환 회복의 발동 인정 |

기초 분류는 음·양 영역의 `소환물·범위·지속영역·지속시간`과 각 회복 효과의 `회복`을 사용한다. `소환물`에는 설치 장판이 포함되며, 교집합 버프의 세부 효과 분류는 종류 결정 후 붙인다. 파편 자체의 교집합 버프와 회복 후 유물이 제공하는 버프는 별개이고, 두 버프의 중첩은 미정이다.

`긴 호흡`의 적용 태그는 기존 합의대로 `지속시간`이며, 회복 주기·회복량·순환 회복 전달 비율을 변경하지 않는다. `범위 증폭`은 지정 사거리나 중심 타일을 바꾸지 않는다. 전용 유물의 용 출현은 별도 고유 효과이며, 즉사·최대 HP 비례 피해의 세부 태그와 범위·피해 증폭 등 다른 유물과의 조합은 아직 미정이다.

**울림통**은 원형 지속영역일 때의 추가 호환 후보로 남기며 이번 5개 목록에 별도 유물 채택으로 추가하지 않는다. 일반 회복 장판은 피해가 없어 소환물 피해 후 약화를 자체 발동시키지 않는다. 회복 주기 단축도 이번 목록에 포함하지 않는다. 상세는 [음양 태그와 유물 연결](run_relic_content_design_notes.ko.md#음양-태그와-유물-연결--2026-10-18-사용자-합의)을 따른다.

**전용 이스터에그 유물 — 2026-10-18 사용자 합의:** 유물을 장착하고 한 시전에서 음·양의 중심 타일을 동일하게 지정하면 해당 영역에 용이 한 번 나타난다. 영역 안 아군·침식체는 즉사하고, 환상체·보스는 최대 HP 25% 피해를 받는다. 시전자도 영역 안이면 아군 판정을 따른다. 용의 판정 후 장판·회복·순환 회복·교집합 버프 등 후속 효과 없이 스킬이 종료된다. 중심이 다른 일부 교집합이나 별도 시전끼리의 중첩은 발동 조건이 아니다. 조건 불충족·유물 미장착 시 기존 회복·지원 구조를 유지한다.

직접 경험하기 전까지 유물의 정체·발동 효과를 알리지 않으며, 조준 경고·위험 범위 전환·피격 아군 강조·별도 확인창을 넣지 않는다. 발견 후 공개 방식, 이름·등급, 범위·판정 시점, 방어·무적·생존 보장·페이즈와 처치 연쇄 세부는 미정이다. 이 효과는 에고 침식과 별도이며, 같은 25% 수치를 쓴다는 이유로 침식의 다른 규칙을 자동 상속하지 않는다. 상세는 [전용 유물 설계](run_relic_content_design_notes.ko.md#음양-전용-이스터에그-유물--이름-미정)를 따른다.

### 4 붉은 두건의 용병

**기존 방향:** 표식 대상의 사망은 처치자와 무관하게 조준창을 주고, 착용자의 다른 직접 처치는 확률로 창을 준다. 모은 창을 사용해 시간을 멈추고 조준한다. 개화형은 선불 계약으로 전환한다.

**조립안:** 표식·처치 이벤트 → 창 수 누적 → 사용 시 창 수와 발사 위치 고정 → 전투 정지와 조준 → 최종 확정 → 각 창의 공격 해결 → 정지 해제다. 창 수 상한 5와 추가 획득 확률 25%는 현재 초안 수치다. 발사 위치는 맵이 제공하는 앵커에서 정하며 직원의 실제 위치를 이동시키지 않는다.

기존 선택지는 창별 대상 조준과 한 타일 집중 사격이다. **단순화 추천은 첫 버전에서 한 타일 집중 사격만 사용하는 것**이다. 화면에는 여러 창을 유지하되 한 번의 위치 선택으로 각각 발사한다. 이는 기존 조작 선택지를 줄이는 변경 제안이다. 창별 조준을 유지한다면 고유 조준 세션이 필요하다.

개화형은 창·표식 대신 예산을 미리 지불하고 계약 대상에게 줄 피해를 관리한다. 대상 사망 후 남은 예산은 환불·이전하지 않고, 보스 페이즈를 넘는 초과 피해를 다음 페이즈에 이월하지 않는다. 예산 종류·지불량·계약 시간·공격 방식은 검토 후 정한다.

**기능 경계:** 누적 이벤트와 개별 발사는 공통. 정지·조준 세션과 개화형 계약 예산은 고유 기능 후보다. 이중 권총·도끼의 거리별 무기 동작, 숙적, 현상금의 원정 성장은 별도 장비·원정 기능이다.

**검토:** 집중 사격만 남길지, 창별 조준도 유지할지가 우선이다. 추천은 최종 확정 전 취소 시 창과 공명 유지, 확정 후 창별 별도 타격과 결정된 처리 순서 유지다. 정지 중에는 전투 시계·지속 효과가 진행되지 않아야 한다.

**태그와 유물 적용**

| 효과 단위               | 태그 후보       | 변경 후보 속성과 지켜야 할 경계                                               |
| ----------------------- | --------------- | ----------------------------------------------------------------------------- |
| 표식 처치와 조준창 저장 | `스택`          | 창 상한·획득 확률. 표식 대상 사망과 다른 직접 처치를 구별                     |
| 각 창에서 나가는 사격   | `피해·관통`     | 사격 계수·관통 조건. 실제 탄환 전달이면 `투사체` 추가                         |
| 여러 창의 발사 순서     | `다중타격` 후보 | 개별 직접 타격 순서로 확정할 때 적용. 동시에 보이는 창 수만으로 판정하지 않음 |
| 개화형 선불 계약        | 고유 계약 동작  | 예산·기간·대상당 한도. 일반 `스택`만으로 지불·환불 규칙을 바꾸지 않음         |

**유물 연결:** 기본형 사격이 직접 다중타격으로 작성되면 **깊은 쐐기** 연결을 검토한다. 사격 위력·관통 강화는 새 범용 후보, 창 획득·계약 예산 변경은 전용 후보다. 조준 정지는 효과의 유한한 유지 시간이 아니라 입력 준비 단계이므로 **긴 호흡**을 적용하지 않는다.

### 5 커다랗고 나쁠 늑대

**기존 방향:** 기본형은 전방 침식체를 포식해 회복하고 포만을 얻는다. 개화형은 자기 HP를 지불하고 광전사가 된다. 늑대 무기의 변신은 파편 없이도 동작한다.

**조립안:** 기본형은 자기 시전 → 전방 1타일의 처형 가능한 침식체 조회 → 처형 → 실제 성공 수로 회복·포만 증가다. 포만은 전투 동안 유지하며 상한을 둔다. 상한을 넘는 포식도 즉시 회복에는 반영한다. 포식 가능한 대상이 없으면 수락하지 않는 안을 추천한다. 보스·환상체를 거대한 일반 피해로 우회 처형하지 않는다.

개화형은 비치명적인 HP 비용 지불 → 공격 속도·평타 흡혈·잃은 HP에 비례한 평타 강화 → 처치 시 제한된 지속 시간 연장이다. 늑대 무기를 장착했다면 즉시 변신하고 최소 지속 시간을 보장한다. 다른 Sword에서도 파편 자체 효과는 동작한다.

**기능 경계:** 분류별 처형·성공 수 집계·전투 누적·기간 강화는 공통 후보. 무기의 허기와 변신 모드 연결은 장비 기능이다. 거대한 입은 연출이며 별도 늑대 소환이 아니다. 가면의 원정 누적과 후속 이벤트도 전투 스킬 내부에서 처리하지 않는다.

**검토:** 공중·소환 침식체 포함 여부와 처형의 처치 효과 발동 여부를 정한다. 포만으로 최대 HP가 늘 때 현재 HP를 얼마나 올릴지도 별도 결정이다. HP 비용으로 시전자 사망은 허용하지 않는 안을 추천한다.

**태그와 유물 적용**

| 효과 단위               | 태그 후보                              | 변경 후보 속성과 지켜야 할 경계                                         |
| ----------------------- | -------------------------------------- | ----------------------------------------------------------------------- |
| 포식                    | 고유 처형 동작                         | 전방 범위·자격. `피해` 증폭으로 처형 면역이나 분류 제한을 우회하지 않음 |
| 포식 성공 후 회복       | `회복`                                 | 성공 수당 회복량. 처형을 가한 피해량에 비례하는 흡혈로 바꾸지 않음      |
| 포만과 그 보너스        | `스택` / `능력치변경` 각각 분리        | 상한·스택당 최대 HP·공속. 획득과 수혜 출처 보존                         |
| 개화형 평타 강화와 흡혈 | `기본공격강화` / `회복·흡혈` 각각 분리 | 결손 HP 환산·흡혈률·상한. 공속 보정은 별도 `능력치변경`                 |

**유물 연결:** 기존 **가하는 회복량 증가**는 포식 회복에 연결하고 흡혈 포함 범위는 해당 유물의 출처 조건을 확인한다. 포만 최대량·평타 전문화는 새 후보다. HP 비용은 피해·피격 태그를 갖지 않으며 늑대 입 연출은 `소환물`이 아니다.

### 6 죽을 나비의 장례

**기존 방향:** 기본형은 이동 가능한 경로 타일에 나비를 배치한 뒤 폭발시킨다. 개화형은 적과 타일에 쌓은 나비를 모아 연속 폭발한다.

**조립안:** 기본형은 해당 경로 타일 목록 고정 → 폭발 지연 → 각 범위의 적 조회와 피해다. 나비마다 독립 유닛을 만들지 않는다. 겹치는 폭발의 동일 대상 피해 횟수는 범위 설계에서 명시한다.

개화형은 적중으로 대상 스택 축적 → 대상 사망 시 현재 타일로 스택 이전 → 시전 시 살아 있는 대상과 타일의 스택 합산 → 이번 폭발량 결정 → 소비 → 유한 반복 폭발이다. 다른 사본이 만든 나비는 섞지 않는 안을 추천한다.

**상태와 표현:** 대상 스택과 타일 스택은 서로 다른 저장 위치지만 같은 출처를 가진다. 액세서리의 처치 폭발도 원래 처치와 파생 폭발의 출처를 구분한다. 나비 비행은 효과 전달에 실제 시간이 필요한 경우에만 판정 지연을 가진다.

**기능 경계:** 스택 이전·합산·소비와 반복 범위 공격으로 구성한다. 경로 전체 배치에 일반 이동 AI는 필요하지 않다.

**검토:** 기존 초안은 스택 0일 때 기본 폭발 횟수, 일정 스택 이상에서 환산 횟수를 사용하는데 경계에서 횟수가 줄어들 수 있다. 추천은 스택 증가로 최종 횟수가 감소하지 않는 표로 정리하는 것이다. 합산 대상 범위와 소비 시점을 함께 정한다.

**태그와 유물 적용**

| 효과 단위                  | 태그 후보                        | 변경 후보 속성과 지켜야 할 경계                              |
| -------------------------- | -------------------------------- | ------------------------------------------------------------ |
| 경로에 배치한 나비         | `소환물·지연발동`                | 배치 위치·기폭 지연. 실제 유닛 이동이나 투사체를 뜻하지 않음 |
| 적의 스택과 사망 타일 축적 | 대상 `스택` / 타일 `소환물·스택` | 획득·이전·상한·합산 범위. 출처별로 별도 보존                 |
| 나비 폭발                  | `피해·범위·폭발`                 | 개별 폭발 위력·반경·횟수. 원래 배치물과의 관계 보존          |
| 개화형 연속 폭발 순서      | `다중타격` 여부 검토             | 독립 배치물의 피해인지 원본 직접 스킬 단계인지 먼저 결정     |

**유물 연결:** 기존 **소환물 범용 유물**은 나비에서 발생한 피해에 연결할 수 있다. 폭발 반경 증가는 새 범용 후보다. 반복 폭발이라는 이유만으로 **깊은 쐐기**를 적용하지 않는다. 타일 스택 합산량을 바꾸는 전용 후보는 총 횟수·소비와 함께 검토한다.

### 7 녹아내리는 사랑 탱커형

**기존 방향:** 자기 자원을 지불해 고기 벽을 세운다. 개화형은 두지 않는 방향이다.

**조립안:** 설치 타일 확인 → 사용 가능한 개인 방어막 분절 지불, 없으면 비치명적인 HP 비용 지불 → 실제 지불량에 따른 고기 벽 생성이다. 비용과 생성은 함께 성공해야 한다. 벽은 자체 HP로 지상 적을 저지하고 공중에는 영향을 주지 않는다.

**상태와 표현:** 벽은 전장에 남는 독립 객체다. 일반 회복과 시체 보상 대상으로 취급하지 않고 경로 재탐색을 유발하는 지형으로 만들지 않는다. 시체 소비 장비는 한 시체를 여러 효과가 중복 소유하지 않도록 별도 소비 판정을 사용한다.

**기능 경계:** 개인 자원 지불 + 고정 저지 객체. 고기 분절은 UI 표현과 실제 지불 단위를 맞춘다.

**검토:** 추천은 설치 불가·지불 불가 시 공명 포함 전부 미소비다. 벽 최대 수, 설치 가능 위치, 만료와 시전자 이탈 시 유지, HP 지불의 최소 잔여 HP를 정한다.

**태그와 유물 적용**

| 효과 단위      | 태그 후보       | 변경 후보 속성과 지켜야 할 경계                               |
| -------------- | --------------- | ------------------------------------------------------------- |
| 고기 벽        | `소환물·방해물` | 벽 HP·저지 수·수명·동시 수. 개인 방어막과 다른 피격 객체      |
| 벽 생성용 지불 | 자원 소비 동작  | 실제 분절/HP 지불량과 벽 HP 환산. `피해`·`회복`을 붙이지 않음 |

**유물 연결:** 벽의 HP·수명 증가는 새 범용 설치물 후보, 비용 전환은 전용 후보다. `보호막` 유물은 벽에 자동 적용하지 않는다. 벽이 피해를 주지 않으므로 **소환물 범용 유물**의 피해 후 약화도 자체 발동하지 않는다.

### 8 녹아내리는 사랑 딜러형

**기존 방향:** 감염을 퍼뜨리고, active로 자신의 감염을 한꺼번에 폭발시킨다. 포자는 피해 타입이 아니라 효과 출처다.

**조립안:** 자격 있는 기본 공격의 행동·대상당 최초 감염 판정 → 감염자 피격 또는 사망 때 확산 → 주기 피해와 출처별 감염 위력 축적이다. 치명타격으로 사망한 경우 피격 확산과 사망 확산을 중복 실행하지 않고 사망 쪽을 우선한다. 방금 감염된 적이 같은 사건 안에서 다시 감염을 퍼뜨리지 않는다.

active는 같은 파편 사본의 감염자 목록과 위력 고정 → 각 감염자의 위치에서 폭발 → 해당 감염과 누적 위력 소모다. 이 폭발 자체로 재감염·사망 확산을 일으키지 않는다. 감염자가 없으면 수락을 거절한다.

**상태와 표현:** 사본별 감염자 목록·대상별 지속 시간·전투 내 위력 기록으로 충분하다. 대상 사이의 연결 그래프를 지속 유지할 이유는 없다. 점액이 서로 연결되어 보이는 효과는 연출에서 만들 수 있다.

**기능 경계:** 출처별 상태 조회·이벤트 확산·주기 피해·일괄 소모. 감염 부가 효과와 active의 결합을 파편의 허용된 구조로 명시해야 한다. 개화형은 새로 만들지 않는다.

**검토:** 추천은 폭발 수락 시 목록을 고정하고 전량 소비하는 것이다. 일부 감염자가 먼저 죽어도 소비를 되돌리지 않는다. 여러 폭발 반경이 겹칠 때 동일 적 다중 피해를 허용할지, 위력 누적을 감염 수와 시간 중 어떻게 계산할지 정한다.

**태그와 유물 적용**

| 효과 단위        | 태그 후보                              | 변경 후보 속성과 지켜야 할 경계                                            |
| ---------------- | -------------------------------------- | -------------------------------------------------------------------------- |
| 감염 전파        | `전파`                                 | 최초 확률·전파 거리·대상 수. 피격/사망 사건과 같은 사건의 재전파 제한 유지 |
| 감염의 주기 피해 | `피해·지속피해`                        | 주기·기간·피해량. 직접 평타나 직접 연타로 재분류하지 않음                  |
| 출처별 감염 위력 | 누적 상태, `스택`은 단위형으로 정할 때 | 감염 수·시간 환산과 상한. 다른 사본 자원과 합치지 않음                     |
| active 기폭      | `피해·범위·폭발`                       | 개별 기폭 위력·반경. 감염 소모와 전파 억제는 별도 규칙                     |

**유물 연결:** 지속 피해 강화·전파 거리 증가·폭발 반경 증가는 새 범용 후보로 각각 다른 효과를 선택한다. 감염자가 여럿이라는 이유로 `소환물`이나 `다중타격`을 붙이지 않는다. 유물이 추가한 폭발에도 출처를 남기고 감염의 재전파 금지를 우회하지 않게 한다.

### 9 파고드는 천국

**기존 방향:** 직접 타격으로 주시를 쌓아 둔화시키고, 일정 스택에서 소모해 속박한다. 그러나 현재 개별안은 수동 발동이 없는 passive여서 파편 active 원칙과 충돌한다.

**조립안 제안:** 자기 active로 일정 시간 주시 부여 능력을 얻는다. 그동안 자격 있는 직접 공격이 행동·대상당 주시를 하나 부여한다. 지속 피해·반사·부가 발동은 제외한다. 스택에 따라 둔화를 교체하고, 최대 스택이면 소모 후 속박한다. 속박 종료 뒤 같은 출처의 재속박을 잠시 막는다.

**상태와 표현:** 활성 기간, 대상별 주시, 재속박 제한을 분리한다. 기존 3스택·둔화 20/50%·속박 1초·재속박 제한 2초는 검증용 수치로 둔다. 눈과 가지의 움직임은 상태 표시다.

**기능 경계:** 기간 강화 + 직접 타격 반응 + 스택별 상태 교체. 무기의 고정 타일 가시와 액세서리의 최초 스택 부여 증폭은 별도 효과다.

**검토:** 우선 active 추가안을 택할지, 흑조처럼 passive 예외로 남길지 결정해야 한다. 추천은 위 기간형 active다. 종료 시 남은 주시를 즉시 제거할지 원래 시간까지 유지할지 정한다. 이 변경은 아직 기존 합의가 아니다.

**태그와 유물 적용**

| 효과 단위               | 태그 후보        | 변경 후보 속성과 지켜야 할 경계                                  |
| ----------------------- | ---------------- | ---------------------------------------------------------------- |
| 주시 축적               | `스택`           | 획득량·상한·기간. 직접 타격 자격과 행동당 집계는 별도            |
| 단계별 둔화·속박        | `제어`           | 제어 종류·강도·지속 시간. 두 제어와 재속박 제한을 구별           |
| 제안한 active 활성 기간 | 기간형 부여 규칙 | 주시 부여 능력의 유지 시간. 행동 집중이 아니므로 `집중유지` 제외 |

**유물 연결:** 스택 획득량 변경은 새 범용 후보다. 주시 획득량 증가가 임계 도달·소모 순서까지 바꾸므로 함께 검토한다. **긴 호흡**은 확대된 `지속시간` 정의에 따라 유한한 active 활성 기간이나 제어 효과의 지속 시간에 연결할 수 있다. active 변경안 자체와 개별 효과의 태그 적용은 아직 검토 대상이며, 재속박 제한 시간을 자동으로 늘리지 않는다. 무기 가시의 `피해` 효과는 파편 표와 별도다.

### 10 아무 것도 없는

**기존 방향:** Hello 동안 평타를 직선 관통 공격으로 교체하고, 재입력으로 남은 시간을 소모해 Goodbye를 사용한다. 자연 종료는 마무리 공격을 만들지 않는다.

**조립안:** 자기 시전 → 원래 무기의 공격력·출처를 참조하는 임시 평타 모드 → 재입력 시 잔여 시간 고정 → 모드 종료 → 잔여 시간에 따른 마무리 공격이다. 재입력은 최초 사용의 후속 단계이며 추가 공명을 요구하지 않는 안을 사용한다. HP 1 고정이나 무료 흡혈을 파편에 덧붙이지 않는다.

**상태와 표현:** 모드와 남은 시간, 마무리 사용 여부를 관리한다. 변신이 다른 장비와 원래 공격 출처를 지우지 않는다. 개화형·침식 표현은 기존 보류를 유지한다.

**기능 경계:** 평타 임시 교체 + 후속 입력 + 잔여 시간 환산. 무기의 실제 HP 손실 기반 흡혈, 방어구 비피격 회복은 공통 반응이다. 액세서리의 전투 1회 부활·원정 누적 후 적대화/영구 손실은 별도 생애주기 기능이다.

**검토:** 추천은 강제 중단 때 Hello를 끝내되 Goodbye를 자동 발동하지 않는 것이다. 마무리의 대상 입력과 사거리, 발사 후 시전자 이탈 처리, 재입력 가능 시점을 정한다.

**태그와 유물 적용**

| 효과 단위   | 태그 후보      | 변경 후보 속성과 지켜야 할 경계                       |
| ----------- | -------------- | ----------------------------------------------------- |
| Hello 모드  | `기본공격변형` | 모드 기간·공격 교체 내용. 사용자의 재입력 분기는 별도 |
| 변형된 평타 | `피해·관통`    | 평타 계수·관통 범위. 무기 기본 공격 출처 유지         |
| Goodbye     | `피해·범위`    | 범위·잔여 시간 환산 계수. 직접 스킬 출처 유지         |

**유물 연결:** 평타 강화 유물은 Hello의 평타에, 범위 공격 변경 후보는 Goodbye에 적용한다. 두 효과를 묶어 `피해·관통·범위` 하나로 선택하지 않는다. Hello 기간 증가는 새 후보이며 잔여 시간에 비례하는 Goodbye도 함께 강해질 수 있다. 모드는 `집중유지`가 아니다.

### 11 웃는 시체의 산

**기존 방향:** 직접 공격으로 웃는 얼굴을 쌓고 저HP 적에게 큰 마무리 피해를 준다. active는 주변 얼굴을 소비해 제어한다.

**조립안:** 직접 타격 후 대상에 얼굴 부여 → 현재 HP 비율과 얼굴 수로 마무리 조건 확인 → 같은 공격에서 한 번만 추가 최종 피해다. 기존 999999 피해는 즉사 명령과 구별하고 무적·페이즈 하한을 존중한다. 추가 피해가 자기 자신을 재발동하지 않으며 흡혈은 실제 HP 손실만 참조한다.

active는 범위 안 자기 출처의 얼굴 수집·소비 → 수에 따른 기절 → 도발로 구성하고 직접 피해를 더하지 않는다. 얼굴 0개에도 최소 제어가 있는 기존 방향을 유지한다. 최대 5개·6초·처형선 5%+스택당 2%는 밸런스 초안이다.

**기능 경계:** 직접 공격 반응·상태 스택·조건부 추가 피해·범위 소비·제어. 무기 처치 성장, 시체 회복, 액세서리의 별도 방어 약화는 얼굴 상태와 합치지 않는다.

**검토:** active에 상시 부가 효과를 붙이는 구조를 명확히 허용해야 한다. 마무리 조건이 이번 타격으로 새로 얻은 얼굴을 포함할지 결정한다. 추천은 포함하고 행동·대상당 1회만 검사하는 것이다. 개화형은 상세 설계 후 추가한다.

**태그와 유물 적용**

| 효과 단위        | 태그 후보   | 변경 후보 속성과 지켜야 할 경계                                        |
| ---------------- | ----------- | ---------------------------------------------------------------------- |
| 웃는 얼굴        | `스택`      | 획득량·상한·기간. 적용 타격과 소유 사본 보존                           |
| 임계 HP 마무리   | `피해`      | 발동 HP 조건·피해량. 처형 명령이나 원래 공격의 새 다중타격 단계가 아님 |
| active 기절·도발 | `제어·범위` | 제어별 시간·소비량 환산·범위. 직접 피해를 새로 추가하지 않음           |

**유물 연결:** 스택 유지·제어 강화는 새 범용 후보다. 마무리 피해는 해당 추가 피해의 출처 조건을 충족하는 증폭만 받는다. 얼굴 획득량 변경과 마무리 임계값 변경을 하나로 취급하지 않는다. 회복·시체 소비는 장비 효과를 따로 선택한다.

### 12 탐욕의 왕

**기존 방향:** 공명을 욕망으로 저장하거나, 저장한 욕망을 전부 소모해 차원문 공격을 사용한다.

**조립안:** 최대 공명에서 저장/발사 선택. 저장은 공명 전부 소비와 욕망 1 증가, 발사는 공명과 욕망 전량 소비 후 공격이다. 욕망 0~3은 각각 1~4개 차원문, 4는 전장 유효 대상 공격으로 바뀌는 기존 방향을 사용한다. 최대치에서 저장은 비용 없이 거절한다.

발사는 한 번의 방향·끝점 입력으로 차원문 배치를 정한다. 문마다 별도 조준을 요구하지 않는다. 문은 발사 원점이며 직원이나 적을 이동시키는 포털이 아니다. 같은 적에게 몇 문까지 맞을지는 공격 정의에서 제한한다.

**상태와 표현:** 욕망은 사본의 원정 누적값이다. 차원문 그림과 실제 발사 원점·범위는 대응해야 한다. 활의 수직 화살은 한 공격 행동으로, 액세서리의 유익 효과 소비는 별도 입력으로 다룬다.

**기능 경계:** 선택형 자원 저장·소모 + 다중 발사. 액세서리는 소비 가능한 유익 효과 목록, 출처와 소유권, 실제 소비량에 따른 강화가 필요하다. 임의의 모든 버프를 지우는 기능으로 만들지 않는다.

**검토:** 추천은 같은 적에 대한 문별 타격을 보존하되 최대 적중 횟수를 명시하는 것이다. 욕망 4의 전장 공격이 단일 공격인지 다수 문 타격인지, 비전투 중 형태 교체 때 욕망 유지 방식도 정한다.

**태그와 유물 적용**

| 효과 단위           | 태그 후보                           | 변경 후보 속성과 지켜야 할 경계                                  |
| ------------------- | ----------------------------------- | ---------------------------------------------------------------- |
| 욕망 저장           | `스택`                              | 저장량·상한·단계별 공격 변환. 공명 지불과 사본 원정 수명 유지    |
| 차원문별 공격       | `피해`, 전달에 따라 `투사체`·`관통` | 위력·발사 원점·탄 수·대상별 한도. 문 그림 자체는 `소환물`이 아님 |
| 최대 욕망 전장 공격 | `피해·범위`                         | 자격 대상·타격 수. 범위 유물로 전장 밖 대상을 만들지 않음        |

**유물 연결:** 욕망 상한 변경은 공격 단계표까지 정해야 하는 전용 후보다. 탄환으로 작성된 공격에는 새 투사체 유물을 검토할 수 있다. 여러 문 동시 발사를 자동으로 `다중타격`으로 세지 않는다. 액세서리가 유익 효과를 소비해 주는 강화는 별도 `능력치변경` 효과다.

### 13 흉탄의 사수

**기존 방향:** 기본형은 관통하며 처치 결과로 뒤쪽 타격을 강화한다. 개화형은 적을 죽인 탄환이 진행 방향을 이어받아 여러 탄환으로 갈라진다. 최종 보스 본체 구현과 보상 파편 설계는 분리한다.

**조립안:** 기본형은 방향 선택 → 관통 탄환 생성 → 충돌 순서대로 피해 → 처치 결과로 해당 탄환의 다음 피해 증가다. 한 발 내부의 누적값이며 다른 동시 탄환과 합치지 않는다. 탄환이 지나는 순서가 위력에 영향을 주므로 대상 목록을 무작위 순서로 한꺼번에 처리하면 안 된다.

개화형은 부채꼴 탄환 발사 → 각 탄환은 첫 충돌에서 피해 후 소멸 → 적의 죽음 확정 시 그 탄환의 입사 방향을 기준으로 자식 탄환 발사다. 세대 수·전체 생성 수·동일 대상 적중 제한을 정한다. 아군도 맞을 수 있지만 아군 사망은 추가 분기를 만들지 않는다. 하나의 사망으로 여러 부모가 중복 분기를 만들지 않는다.

기본·개화형은 자체 탄환 자원과 7번째 발사 횟수 기록을 공명과 구별한다. 정비 중 형태를 바꾸어도 횟수를 초기화하지 않는다. 7번째 자기 피해와 강화탄 발사를 정해진 순서로 처리하고, 이미 발사한 강화탄은 시전자가 죽어도 유지한다.

**기능 경계:** 관통 충돌·처치 귀속은 공통, 탄환별 누적과 방향을 물려받는 분기는 완성된 고유 모듈 후보다. 제작자는 부채꼴 각도·탄 수·세대 제한 등을 설정한다.

**검토:** 추천은 방향과 실제 탄환을 유지하는 것이다. 더 단순한 대안은 사망 위치의 전방 부채꼴 범위 공격으로 바꾸는 것이지만 이동 중 충돌과 다른 적의 가로막기가 사라지므로 별도 설계 변경이다. 분기 한도, 피해 증가 시점, 자원과 공명의 지불 관계가 필요하다.

**태그와 유물 적용**

| 효과 단위                   | 태그 후보                           | 변경 후보 속성과 지켜야 할 경계                                  |
| --------------------------- | ----------------------------------- | ---------------------------------------------------------------- |
| 기본형 탄환                 | `피해·투사체·관통`                  | 피해량·탄속·관통 조건. 충돌 순서와 처치별 누적 보존              |
| 개화형 각 탄환              | `피해·투사체`                       | 각도·탄 수·위력. 첫 충돌 소멸을 관통으로 자동 변경하지 않음      |
| 처치 후 분기                | 고유 분기 동작                      | 세대·총량·적중 한도·부모 방향. 감염의 `전파`와 구별              |
| 7번째 발사 기록과 자기 피해 | `스택` / 자기 대상 `피해` 각각 분리 | 횟수와 자해량. 적 공격 피해 강화에서 자기 피해를 명시적으로 제외 |

**유물 연결:** 투사체 위력·탄속 변경은 새 범용 후보, 처치별 성장·방향 분기 변경은 고유 속성 또는 전용 후보로 둔다. 파생 탄환이 많다는 이유로 **깊은 쐐기**의 원본 직접 타격이 되지 않는다. 탄환을 추가하는 유물도 기존 분기 한도·아군 처치 제외·연쇄 기록을 따라야 한다.

### 14 따뜻한 마음의 나무꾼

**기존 방향:** 현재 근거리 주 대상에게 빠른 2타 후 강한 마지막 1타를 가한다. 원본 조우의 심장 수집은 파편에 넣지 않는다.

**조립안:** 자기 시전 시 유효 근거리 주 대상 고정 → 빠른 타격 → 짧은 간격 → 빠른 타격 → 마무리 지연 → 강한 타격이다. 모두 무기 공격력 기반 직접 Physical 피해이며 한 시전의 서로 다른 타격으로 남긴다. 유효 대상이 없으면 거절한다.

**상태와 표현:** 이번 시전의 대상·타격 번호·다음 시각만 필요하다. 마지막 도끼의 크기나 충격은 연출로 강화한다. 파편에 심장 자원·자체 흡혈·성장을 추가하지 않는다.

**기능 경계:** 공통 연속 공격으로 작성한다. 같은 시전의 같은 적에게 맞힐수록 강화하는 깊은 쐐기는 실제 타격 순서를 참조한다. 방어구의 직접 active 처치 회복과 액세서리의 실제 피해 흡혈은 출처별 후처리다.

**검토:** 추천은 대상 사망·이탈 시 남은 타격을 취소하고 다른 적으로 옮기지 않는 것이다. 방어구 회복은 처치당 적용하되 시전별 상한을 두는 안을 추천한다. 단순히 3타 피해를 합산하면 쐐기 효과와 처치 시점이 바뀌므로 합치지 않는다.

**태그와 유물 적용**

| 효과 단위               | 태그 후보       | 변경 후보 속성과 지켜야 할 경계                           |
| ----------------------- | --------------- | --------------------------------------------------------- |
| 빠른 1·2타와 강한 3타   | `피해·다중타격` | 각 타격 계수·간격·타격 수. 같은 시전의 직접 타격으로 기록 |
| 방어구의 스킬 처치 회복 | `회복`          | 처치당 회복량·시전별 상한. 파편 효과가 아닌 장비 출처     |
| 액세서리 흡혈           | `회복·흡혈`     | 실제 HP 손실 비례량·상한·자격 출처. 3타 피해와 별도 효과  |

**유물 연결:** 기존 **깊은 쐐기**의 대표 적용 대상이다. 같은 시전·같은 적에 대한 실제 적격 타격별로 증가하며 새 타격을 만들지 않는다. 회복 유물은 장비 회복의 출처 조건을 따로 검사한다. 공격 속도 태그나 능력치 변경만으로 3타 간격을 줄이지 않는다.

### 15 래티씨아

**이번 대화의 방향:** 적이 거미 하나에 접근하면 주변의 같은 출처 거미들이 그 적에게 뛰어들어 폭발한다. 거미줄 연결과 선을 넘는 판정은 실제 전투 규칙에서 제거한다. 화면에서는 거미들이 연결된 것처럼 보여도 된다.

**조립안:** 타일에 작은 거미 설치 → 같은 사본의 거미가 있는 타일에 재시전하면 큰 거미로 진화 → 적이 거미 하나의 감지 범위에 진입 → 그 거미를 기준으로 반경 안 참여 거미 목록 확정 → 참여 거미 예약 → 각 거미의 공격 → 각 거미 소모다. 개화형의 큰 거미 설치 방향은 유지한다. 이미 큰 거미인 곳에 세 번째 단계로 쌓는 기능은 추가하지 않는다.

참여 조회는 최초 감지 거미 주변에서 한 번만 한다. 참여 거미 주변을 다시 조회하여 끝없이 연결하는 규칙은 넣지 않는다. 여러 적이 동시에 접근해도 예약된 거미를 다른 발동이 중복 사용하지 못한다. 같은 사본만 참여시키는 안을 추천하며, 같은 종류의 다른 직원 거미를 자동 합치지 않는다.

**타격 추천:** 작은 거미는 접근한 적에게 단일 피해, 큰 거미는 그 적을 중심으로 범위 피해라는 기존 구별을 유지한다. 거미 4마리면 개별 공격 4회로 처리하고 총합 피해 1회로 바꾸지 않는다. 참여 순서는 작은 거미부터, 같은 종류는 안정된 생성 순서로 정하는 안을 제안한다.

**대상과 소모 추천:** 각 거미는 발사 직전에 원래 적의 유효성을 확인한다. 그때 이미 죽거나 전장에서 사라졌다면 아직 출발하지 않은 거미는 남긴다. 출발한 거미는 소모를 확정하며 되돌리지 않는다. 큰 거미의 폭발 위치는 출발 시 적의 타일로 고정하는 안을 제안한다. 고정 후 적이 이동해도 그 위치에서 폭발한다. 도약에 판정 지연을 둘지는 별도로 정하며, 지연이 없다면 같은 전투 처리 안에서 순서대로 해결한다.

**상태와 표현:** 거미의 출처·위치·크기·남은 수명·예약 여부와 짧은 발동 기록만 관리한다. 진화는 같은 설치물을 갱신하고 수명을 재설정하는 기존 방향을 따른다. 시전자 이탈 후 독립 객체 유지 원칙도 이어받는다. 거미줄 그림·도약 곡선·튀는 파편에는 충돌선을 만들지 않는다.

**기능 경계:** 설치·진화·범위 조회·개별 피해·소모는 공통. 참여 목록의 예약과 동시 발동 처리는 작은 고유 기능 후보다. 지속 연결 그래프·간선 통과 감지·거미 이동 AI는 필요하지 않다.

**검토:** 먼저 작은 거미 단일/큰 거미 광역을 유지할지, 모두 같은 형태로 단순화할지 정한다. 다음은 대상이 중간에 죽으면 미출발 거미를 남기는 추천안과, 처음부터 참여 거미 전부를 소비하는 대안 중 선택한다. 감지 반경·참여 반경·피해·설치 상한은 이 결정 뒤에 조정한다. 위 순서·예약·소모 세칙은 대화에서 확정한 사항이 아니다.

**태그와 유물 적용**

| 효과 단위      | 태그 후보                        | 변경 후보 속성과 지켜야 할 경계                             |
| -------------- | -------------------------------- | ----------------------------------------------------------- |
| 작은·큰 거미   | `소환물`                         | 수명·동시 수·감지 반경·진화. 참여 반경은 별도 발동 규칙     |
| 작은 거미 공격 | `피해`, 폭발 판정 채택 시 `폭발` | 단일 피해량. 단일 폭발이라면 `범위`는 부여하지 않음         |
| 큰 거미 폭발   | `피해·범위·폭발`                 | 피해량·폭발 범위. 출발 타일·목표 고정 규칙 보존             |

**유물 연결:** 기존 **소환물 범용 유물**은 거미에서 발생한 피해를 선택해 대상 약화를 줄 수 있다. 거미줄 둔화는 무기 효과이므로 폭발에 자동 상속하지 않는다. 거미 여러 마리의 독립 공격은 **깊은 쐐기**에 자동 포함하지 않는다.

**붉은 실타래 재검토:** 기존 유물의 간선 통과·연결망은 이번 단순화 방향과 맞지 않는다. 기본 파편의 독립 발동을 유지하고 **붉은 실타래가 주변 거미 참여를 추가하는 안**을 우선 추천한다. 앞 조립안의 주변 참여를 기본 파편에 포함하려는 의도라면 유물은 참여 반경·수 등을 바꾸는 역할로 다시 설계해야 한다. 두 기능을 중복 지급하지 않으며, 어느 쪽이든 래티씨아 기본·개화형 전용 조건을 유지한다. 기능의 소유 위치는 첨삭으로 확정한다.

### 16 여왕벌

**기존 방향:** 지정 아군에게 유한한 벌을 붙여, 피해를 받으면 벌을 소비하고 회복한다.

**조립안:** 아군 지정 → 벌 수와 유지 시간 저장 → 자격 있는 피격 사건 확인 → 벌 1개 소비 → 대상 최대 HP에 비례한 회복이다. 벌은 지원 횟수를 표시하며 각자 이동·표적 탐색하는 소환물이 아니다. 치명 피해로 이미 죽음이 확정된 대상을 부활시키지 않는다.

**기능 경계:** 대상 부착형 유한 반응 효과 + 회복. 순수 회복 무기는 여러 서로 다른 아군을 고르고 남는 회복 수를 한 명에게 몰아주지 않는다. 방어구의 전투 진입 방어막과 액세서리의 실제 회복 시 대상 공속 증가는 별도 효과다.

**검토:** 추천은 실제 HP 손실이 발생한 적 행동당 한 번만 벌을 소비하는 것이다. 보호막만 깎이는 피해에도 소비할지, 지속 피해가 발동하는지 정한다. 같은 대상 재시전은 남은 벌 교체를 추천한다. 회복량 10~20%는 확정값이 아닌 기존 범위다. 개화형은 미정이다.

**태그와 유물 적용**

| 효과 단위        | 태그 후보   | 변경 후보 속성과 지켜야 할 경계                               |
| ---------------- | ----------- | ------------------------------------------------------------- |
| 벌집의 저장 횟수 | `스택` 후보 | 저장 수·재부여·수명. 피격당 소비 자격을 별도 명시             |
| 발동 시 회복     | `회복`      | 대상 최대 HP 계수·1회 회복량. 실제 회복 사건과 지불 횟수 구별 |

**유물 연결:** 기존 **가하는 회복량 증가**는 회복에 연결한다. 벌 수 증가는 새 후보이며 스택 증가가 같은 피격에 여러 번 회복한다는 뜻은 아니다. 벌 비행 그림은 `소환물`·`투사체`가 아니고, 유한 회복 횟수는 `다중타격`이 아니다. 치명 피해 후 부활 효과를 태그로 새로 만들지 않는다.

### 17 눈의 여왕

**기존 방향:** 전방 냉기 공격으로 범위 둔화와 주 대상 빙결을 주고, 직접 처치하면 잔영이 이동해 주변을 둔화시키다 폭발한다.

**조립안:** 방향·주 대상 확정 → 범위 Magic 피해·둔화 → 주 대상 빙결 → 직접 처치 위치에 잔영 생성이다. 잔영은 HP·저지·직접 조작 없이 가까운 적을 향해 이동하고 현재 위치 주변에 둔화를 주다가 폭발한다. 기본안에서는 폭발이 다시 잔영을 낳지 않는다.

전용 유물은 착용자의 냉기로 둔화된 적이 죽을 때 처치자와 무관하게 잔영을 만든다. 직접 처치와 유물 조건을 동시에 만족해도 같은 착용자·사망 대상 조합에서는 하나만 생성하는 안을 추천한다.

**기능 경계:** 냉기 공격·사망 반응은 공통. 잔영은 움직이는 효과 중심이므로 위치 갱신이 필요하다. 이동을 전부 그림으로만 처리하면 둔화 대상과 폭발 위치가 달라진다. 고정된 사망 지점의 지연 폭발로 바꾸는 것은 별도 단순화 대안이다.

**검토:** 추천은 이동 잔영을 유지하되 단순한 목표 추적과 수명만 두는 것이다. 이동 속도·재탐색 주기·추적 대상 소멸 시 동작을 정한다. 빙결 주 대상이 피해로 먼저 죽었을 때 제어를 다른 적에게 넘기지 않는다. 자체 방어용 빙결 방어구와 둔화 대상 추가 피해 액세서리는 별도다.

| --------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |

### 18 이름이 없는 태아

**기존 방향:** 시전자가 집중하는 동안 다른 실제 배치 직원들의 평타를 강화한다. 기본형·단일 대상 전환·침식된 전환 유물의 강화는 서로 교체한다.

**조립안:** 자기 집중 시작 → 대상 아군 조회 → 집중 유지 동안 현재 자격을 갖춘 직원에게 지원 → 종료 사건에서 지원과 집중을 함께 제거한다. 시전자는 평타·다른 스킬·전술 이동·자세 변경·작업을 할 수 없다. 자신·게스트·소환물은 수혜 대상에서 제외한다. 같은 지원의 중첩은 허용하지 않는다.

일반 피해와 침묵만으로 집중이 끊기지는 않는다. 수동 중지·강한 행동 제어·철수·강제 이동·행동 불능·전투 종료는 집중을 끝낸다. 일시정지는 남은 시간을 보존한다. 6~8초는 후보 범위다.

**상태와 표현:** 기본은 평타 피해 +20%와 공속 +15%p, 단일 전환은 +40%/+20%p, 침식 전환은 +80%/+30%p의 기존 초안이며 공격력 전체 증가로 바꾸지 않는다. 유물 전환은 덧셈이 아니라 효과 교체다.

**기능 경계:** 집중 상태와 동적 대상 지원은 공통. 액세서리의 HP 희생 단계는 대상 직원의 전투 기록으로 별도 관리한다. 재배치로 초기화하지 않고 전투 진입 최대 HP를 기준으로 비누적 계산하며, 높은 단계로 바로 선택할 수 있다.

**검토:** 단일 전환의 대상 선택, 정확한 집중 시간, 침식 유물의 패널티가 필요하다. HP 희생으로 사망하는 선택은 거절하는 안을 추천한다. 파편 지원 범위와 액세서리의 평타 공속 강화 범위를 혼동하지 않는다.

**태그와 유물 적용**

| 효과 단위                | 태그 후보                | 변경 후보 속성과 지켜야 할 경계                             |
| ------------------------ | ------------------------ | ----------------------------------------------------------- |
| 울음 집중과 지원 영역    | `집중유지·지속영역·범위·지속시간` | 유한 최대 집중 시간·영역 형태·반경. 자기 행동 포기 유지     |
| 아군 평타 피해 증가      | `기본공격강화`           | 평타 피해 증가량. 일반 공격력이나 스킬 피해로 확대하지 않음 |
| 아군 평타 공격 속도 증가 | `능력치변경`             | 평타 공속 가산값. 실제 공격·처치는 수혜자에게 귀속          |

### 19 흑조의 꿈

**기존 방향:** 상시 피해 경감·확률 반사와 active 패링을 결합하는 명시적 예외다. 성공 패링은 최초 타격을 포함해 500ms 동안 모든 피해와 행동 제어를 막는다.

**조립안:** active로 패링 대기 → 첫 자격 있는 직접 타격을 판정 → 성공 시 해당 타격 방어와 반격 1회 → 500ms 보호 → 정상 상태 복귀다. 보호 중 추가 피해가 들어와도 패링·반사·반격을 다시 만들거나 보호 시간을 연장하지 않는다. 보호 중 다른 버프·디버프의 일반 부착·제거는 계속 허용한다. HP 비용은 피해 면역과 구별한다.

실패하면 자기 상시 경감만 잠시 비활성화하고 다른 방어 효과를 지우지 않는다. 전용 유물은 이 파편이 실제 경감한 양만 저장하고 성공 때 소비한다. 패링 무효화량·반사량·다른 방어 효과의 경감량은 저장하지 않으며 실패 때는 유지한다.

**기능 경계:** 최초 타격을 소비하는 패링 상태와 500ms 보호, 실제 경감 결과 누적이다. 일반 무적 버프 하나만 붙여서 모든 반응까지 차단하는 방식은 맞지 않는다.

**검토:** 500ms 보호는 현행 규칙으로 유지하고, 입력 후 패링 대기 시간·실패 패널티 시간·반사 자격을 정한다. 추천은 유물 저장량을 성공 시 한 번만 소비하고 반격이 빗나가도 반환하지 않는 것이다.

| --------------------- | ----------------------------- | ----------------------------------------------------------------------------- |
| 상시 경감             | `피해감소`                    | 경감률·자격 피해. 실제 자기 경감량만 유물 저장으로 전달                       |

**유물 연결:** 기존 **깨어난 흑조**는 정확한 파편의 실제 경감과 패링 성공을 연결한다. 아무 `피해감소` 효과에 같은 전용 저장을 부여하지 않는다. 반격 강화는 새 후보이며 패링 성공률·면역 시간과 별도다. 일반 버프 부착·제거를 `피해차단`으로 막지 않는다.

### 24 지혜를 구하는 허수아비

**기존 방향:** 다음 일반 평타를 크게 강화하고 그 직접 공격으로 처치하면 추가 강화한다.

**조립안:** 자기 시전 → 다음 일반 평타 대기 → 그 평타 발사 시 강화 예약을 연결·소모 → 강화된 직접 피해 → 같은 공격의 처치 확정 시 공격력 버프다. 시전만으로 공격 주기를 초기화하거나 새 평타를 즉시 만들지 않는다. 범위 평타로 여러 적을 죽여도 버프 발동은 공격당 한 번으로 제한하는 안을 추천한다.

**기능 경계:** 다음 평타 수정 + 특정 공격의 처치 반응. 비피격 뒤 최초 HP 손실을 줄이는 방어구, 평타 발사 간격을 보는 액세서리는 별도 기록을 사용한다.

**검토:** 추천은 발사 전 공격 취소 때 준비를 유지하고, 발사 후 탄환이 빗나가면 반환하지 않는 것이다. 처치 버프는 중첩 없이 갱신을 추천한다. 액세서리는 전투 첫 공격의 이전 발사 시각이 없을 때 보너스를 줄지 정해야 한다.

**태그와 유물 적용**

| 효과 단위                | 태그 후보                        | 변경 후보 속성과 지켜야 할 경계                                |

| 강화받은 실제 평타       | `피해`, 원래 무기 형태 태그 유지 | 원래 무기의 단일/범위·전달. 직접 스킬 공격으로 재분류하지 않음 |
| 그 평타로 처치 후 보너스 | `능력치변경`                     | 공격력 증가량·기간·갱신. 처치 사건은 별도 조건                 |

**유물 연결:** 평타 강화와 처치 후 능력치 강화는 각각 다른 유물 후보를 선택한다. 새 폭발 유물이 평타에 추가 피해를 만들더라도 그 폭발의 처치를 원래 직접 평타 처치로 자동 인정하지 않는다. `다중타격`·**깊은 쐐기**는 단순히 강화가 붙었다는 이유로 적용하지 않는다.

첨삭:

## 회사 지급 스킬

회사 지급 스킬은 복잡한 전용 규칙 없이 공통 기능을 확인하는 기준 콘텐츠로 둔다. 아래는 동작의 분해이며 현재 데이터의 수치 확정을 뜻하지 않는다.

| 스킬          | 조립안과 태그 후보                             | 변경 후보 속성                    | 검토할 경계                                                           |
| ------------- | ---------------------------------------------- | --------------------------------- | --------------------------------------------------------------------- |
| 아드레날린    | 자기 기간 강화 `능력치변경`                    | 공격력·공속·기간 각각             | 같은 출처 재사용은 갱신, 중첩 없음 추천                               |
| 광전사        | 기간 강화 `능력치변경` / 평타 흡혈 `회복·흡혈` | 강화량·기간 / 흡혈률·상한         | 평타 흡혈 출처 유지. 스킬 피해까지 확대하지 않음                      |
| 최후의 방어선 | 자기 기간 방어 `피해감소`                      | 경감률·기간                       | 다른 감소와의 합성은 공통 피해 규칙 사용                              |
| 돌파          | 공격 `피해·범위` → 개인 `보호막`               | 공격 위력·범위 / 보호량·기간      | 추천은 적중 수와 무관한 방어막. 피해 범위를 넓혀도 보호막 대상은 자신 |
| 단일 회복     | 지정 아군 `회복`                               | 회복량·지정 사거리                | 실제 회복량과 요청량 구분, 만피 대상 허용 여부                        |
| 범위 회복     | 한 번의 영역 조회와 `회복·범위`                | 회복량·효과 범위·지정 사거리 각각 | 즉시 회복이며 `소환물·지속영역`이 아님                                |

**유물 연결:** 기존 **가하는 회복량 증가**는 두 회복 스킬에 연결하고 광전사의 흡혈은 유물의 인정 출처를 확인한다. 능력치·경감·보호량 강화는 각 효과를 선택하는 새 후보로 둔다. **긴 호흡**은 기간 강화·기간 방어·유한한 보호막 등의 `지속시간` 효과에 연결할 수 있으며, 개별 태그 적용은 검토 대상이다. 즉시 회복이나 순간 공격에 새 지속 시간을 만들지 않는다. 범위 회복의 한 번의 영역에도 **울림통**을 적용하지 않는다.

첨삭:

## 장비와 유물에서 공통으로 정할 것

파편만 단순화하고 장비 반응을 그대로 뒤섞으면 같은 문제가 남는다. 각 파편 카드의 장비 의존성은 다음 공통 규칙으로 모으는 것을 추천한다.

| 효과 종류                 | 태그와 추천하는 분해                                    | 먼저 정할 조건                                                                             |
| ------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 흡혈                      | 실제 HP 손실 참조 → `회복·흡혈`                         | 평타/직접 스킬/지속 피해/파생 피해 포함 범위와 행동별 상한                                 |
| 회복에 따른 지원          | 실제 회복 사건 → 별도 `보호막` 또는 `능력치변경`        | 초과 치유 포함 여부. 추천은 실제 회복만. 새 지원 효과에 `회복`을 복사하지 않음             |
| 피격 후 회복·스택         | 실제 HP 손실 사건 → 각각 `회복` 또는 `스택`             | 다단타·지속 피해의 집계 단위. 피격은 태그가 아닌 사건                                      |
| 피해 경감량 저장          | 원래 `피해감소` → 수치 기록 → 별도 방출 효과            | 저장값은 양의 집계이지 자동으로 `스택`이 아님. 다른 방어·패링·무적의 양 제외               |
| 처치 성장                 | 죽음 확정 → 누적 기록 → `능력치변경` 등 실제 보상       | 직접·간접 처치 자격과 전투/원정 수명. 처치 사건을 모든 보상 효과의 태그로 복사하지 않음    |
| 시체 소비                 | 사망 기록 확보·소비 → `회복`·`소환물` 등 실제 생성 결과 | 여러 장비 동시 요청의 우선순위, 한 시체 중복 소비 금지                                     |
| 다음 평타 수정            | `기본공격강화` 준비 → 특정 평타에 연결 → 발사 때 소비   | 발사 전 취소·발사 후 실패·동시 다른 수정과의 결합                                          |
| 유익 효과 소비형 액세서리 | 허용 목록 선택·소비 → 별도 `능력치변경`                 | 선택 UI, 자기 소유/외부 지원 구분, 제거 불가 효과. `스택` 태그 하나로 소비 허가하지 않음   |
| 부활·변신·적대화          | 고유 상태 전이 → 실제 부가 효과만 별도 분류             | 일반 `회복`·`기본공격변형`만으로 생애주기 전체를 표현하지 않음. 재배치·전투·원정 수명 명시 |

원정 보상·현상금·영구 손실은 전투 효과가 결과를 알리고 원정 시스템이 처리한다. 스킬 내부에서 창고·노드·저장 데이터를 직접 변경하는 구성은 피한다.

## 태그로 연결해 보는 대표 조합

아래는 적용 조건을 검토하기 위한 예시다. 기존 유물의 미정 수치를 확정하거나 새 유물을 제품에 추가하지 않는다.

| 조합                            | 적용 조건과 변경 효과                                                            | 확인할 플레이 변화                                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 나무꾼과 깊은 쐐기              | 같은 시전·같은 적의 `피해·다중타격` 직접 타격을 선택해 해당 타격 증폭            | 강한 마지막 타격까지 같은 적에게 이어갈 가치 증가. 지속 피해·장비 추가타는 별도                      |
| 래티씨아와 소환물 범용 유물     | 거미에서 나온 실제 피해 사건 → 맞은 적에게 `받는피해증가` 5초 부여               | 거미가 사라져도 약화는 남음. 최초 피해·보호막 피해 인정과 재부여는 기존 미정 유지                    |
| 태아와 긴 호흡과 울림통         | `지속시간`이 지정된 집중의 유한 최대 시간, `지속영역`의 원형 반경을 각각 선택                  | 더 오래·넓게 지원하되 시전자 행동 포기 유지. 단일 전환으로 영역이 사라지면 그 효과의 울림통은 비활성 |
| 추가 폭발 유물과 폭발 반경 유물 | 새 후보 A가 적격 적중 후 `피해·범위·폭발` 생성 → 새 후보 B가 그 폭발의 반경 수정 | 새 효과도 조합 가능. 원래 공격의 흡혈·감염·직접 처치 자격을 무조건 상속하지 않음                     |

**제작 단계에서 확인할 차이:** 깊은 쐐기의 일반 설계 문구는 유효 적중을 기준으로 설명하지만, [현재 작성 포트](skill_authoring_model.ko.md#wedge와-기존-금액-단계)는 실제 양수 HP 손실이 있는 직접 타격에서 횟수를 확정하고 완전 보호막 흡수·무적·피해 0은 횟수를 소비하지 않는다. 이 초안의 태그 적용만으로 그 차이를 새 정책으로 확정하지 않는다. 관련 카드를 확정할 때 적중의 뜻을 맞춰야 한다.

## 범위가 비어 있거나 분리된 콘텐츠

| 항목                                                 | 이번 초안의 처리                                                                                       |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 죽은 나비들의 장례                                   | 플레이어 보상 파편을 별도로 만들지 않는 기존 방향. 죽을 나비의 장례와 중복 설계하지 않음               |
| 백야                                                 | 개별 플레이어 스킬 상세가 비어 있어 신규 효과를 임의 작성하지 않음                                     |
| 고요한 오케스트라·종말새                             | 개별 플레이어 스킬의 충분한 상세안이 없어 여기서 확정하지 않음. 최종 보스 본체 범위와도 분리           |
| 흉탄의 사수                                          | 상세안이 있는 보상 파편은 위에서 검토하되, 이것이 최종 보스 본체 구현이나 획득 경로 승인을 뜻하지 않음 |
| 개화형이 없는/미정인 파편                            | 이미 서술된 형태만 분해. 모든 파편에 두 번째 형태를 새로 발명하지 않음                                 |
| 현재 데이터의 starter·reference·메타데이터 전용 항목 | 이름이 등록된 사실만으로 완성 설계나 구현 완료로 세지 않음. 실제 제작 대상 확정 때 원본 설계와 대응    |

음·양의 기존 분리 데이터나 `BasicAttackModifier` 자리표시자 등은 새 합의 이후 제작 대상으로 정리할 일이다. 이 초안은 현재 모든 라이브 콘텐츠가 위 동작과 일치한다고 주장하지 않는다.

## 먼저 결정하면 구현을 줄일 수 있는 항목

| 순서 | 결정                             | 이 초안의 추천                                                                                     | 달라지는 구현                                                                      |
| ---- | -------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 1    | 래티씨아의 참여와 소모·유물 역할 | 같은 사본의 가까운 거미만, 개별 타격, 미출발 거미 보존. 주변 참여는 붉은 실타래가 추가하는 안 우선 | 연결 그래프를 없애고 한 번의 조회·예약으로 처리. 기본 파편과 유물의 중복 기능 방지 |
| 2    | 붉은 두건의 조준                 | 첫 버전은 한 타일 집중 사격                                                                        | 여러 창의 개별 선택 상태와 입력 단계를 줄임                                        |
| 3    | 흉탄의 분기                      | 방향과 실제 탄환 유지, 유한 한도 설정                                                              | 고유 분기 모듈이 필요하나 원래 공격 특성 보존                                      |
| 4    | 파고드는 천국                    | 기간형 active에 기존 주시 효과 결합                                                                | 상시 passive 예외를 추가하지 않고 사용 시점을 제공                                 |
| 5    | 타격과 처치의 기본 단위          | 개별 타격 유지, 행동당 반응은 별도 지정                                                            | 여러 피해의 단순 합산에서 생기는 장비 상호작용 차이를 방지                         |
| 6    | 잔영·썰매·거미의 실체            | 위치가 결과를 바꾸는 효과만 실제 위치 관리                                                         | 표현용 소환물과 불필요한 AI를 줄임                                                 |
| 7    | 장비 active 입력                 | 스킬 슬롯과 별개인 입력·비용·취소 규칙 명시                                                        | 탐욕 액세서리 등 선택형 효과의 공통 입력 기반 결정                                 |
| 8    | 경계 효과의 태그와 호환          | 거미·나비·분기탄의 직접 타격 여부, 이동 잔영의 소환물 분류를 각각 결정                             | 깊은 쐐기·소환물 피해 유물의 적용 범위를 실제 출처와 일치시킴                      |

위 항목이 정해지면 회사 스킬·나무꾼·풍운승려로 기본 조합을 확인하고, 개인 보호막·회복 장판·기간 강화로 상태와 수명을 확인한다. 그다음 감염·처치 반응·거미를 붙이고, 조준 세션·계약·분기 탄환을 고유 기능으로 마무리하는 순서를 추천한다. 이는 내용 제작 순서 제안이며 기존 로드맵의 선행 조건을 대체하지 않는다.

로드맵상 기반과 침식·고유 규칙을 정리하는 U18/U19, 범위 내 콘텐츠를 완성하는 U21, 제작 지원과 외부 제작으로 확인하는 U27/U29는 구분한다. 공통 엔진의 존재만으로 전체 스킬 완료를 선언하거나, 전체 스킬을 논의했다는 이유로 전부 이미 제작 가능하다고 간주하지 않는다.
