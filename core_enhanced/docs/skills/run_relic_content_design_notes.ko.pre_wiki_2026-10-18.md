# Run 유물 콘텐츠 설계 노트

## 문서 상태와 책임

- 작성: 2026-09-06.
- 갱신: 2026-10-18.
- 상태: 사용자와 논의한 재미의 기준, 역할 분류·희귀도, 기초 태그와 개별 유물 설계 기록. 첫 유물 `깊은 쐐기`의 타격별 누적 피해 증가 구조와 희귀 등급을 합의했고, 2026-10-18에 타격당 `2%p`·같은 시전 같은 대상 최대 `20%`로 갱신했다. 최종 표시 이름·세부 판정과 나머지 유물은 후속 설계한다.
- 무기 수치 유물 초안 (2026-09-08): 사용자는 무기에 적용하는 유물의 첫 범위를 단순 수치 강화로 정하고 등급별 설계를 요청했다. 아래 공격력·공격 속도·기본 공격 피해 3계열의 9종은 AI 제안이며, 이름·등급별 수치·중복 장착과 세부 적용 규칙은 사용자 확정 및 전투 밸런스 검증 전이다.
- 기초 태그 기록 (2026-09-06): 파편을 먼저 훑어 기초 태그를 만들고, 스킬·유물에 적용하며 확장하는 순서로 진행한다. 아래 한글 태그와 적용 예시는 그 출발점인 초안이다.
- 절망의 기사 후속 태그·공통 유물 (2026-10-18): 사용자가 `쿨다운속도감소`와 7개 효과 변형 태그의 적용 방향을 제시했다. 검 획득 쿨다운, 검 상한 해제, 보호막량 증폭, 스택 부여·획득량 2배, 범위 변형을 아래에 기록한다. `무아지경`은 후속 합의에 따라 군중제어 자체 면역에서 스킬 시전 중 외부 효과에 의한 시전 행동·집중 중단 방지로 변경했다. 강력한 군중제어를 가한 대상에게 5초간 받는 피해 증가를 부여하는 범용 유물을 추가하며, 이름 `깨진 균형`은 AI 추천 가칭이다. 피해 증가율·희귀도·세부 판정은 미정이다.
- 증오의 여왕 리워크·태그 (2026-10-18): 전투 로컬 하트·히스테릭 리워크에 맞춰 회복량 증가, 회복한 아군에게 버프 부여, 범위 증폭, 스택 획득, 쿨다운속도감소, 보호막효율증가, 무아지경의 7개 연결을 합의했다. 회복 후 버프 종류와 보호막의 구체적 연결은 미정이다. 무아지경은 집중형에만 한정하지 않는다.
- 음양 리워크·순환 회복 (2026-10-18): 두 위치를 지정해 음의 영역과 양의 영역을 만들고 지속 시간 동안 두 구역을 회복한다. 후속 합의로 각 영역이 먼저 회복한 뒤 초과 회복량 일부를 반대 영역의 부상 아군에게 전달한다. 전달하는 쪽에도 아군이 있어야 하며, 전달된 회복의 초과분은 다시 보내지 않는다. 전달 비율·집계·배분·영역 겹침과 태그·유물 연결 목록은 후속 설계한다. 아래 기초 태그 예시는 이번 리워크의 유물 채택 합의를 뜻하지 않는다.
- 음양 교집합 (2026-10-18 후속 합의): 독립 영역은 회복, 음·양의 교집합은 회복과 이로운 버프를 제공한다. 기존 순환 회복은 유지한다. 교집합 회복량·버프 종류·수치·지속 및 이탈 판정은 미정이다. 교집합 버프는 파편 자체 효과이며 별도 회복 후 버프 유물의 채택을 뜻하지 않는다.
- 음양 태그 연결 (2026-10-18 후속 합의): 회복량 증가, 회복한 아군에게 버프 부여, 범위 증폭, 지속시간, 버프효율증가의 5개 연결을 채택한다. `지속시간`은 긴 호흡과 연결하며 `버프효율증가`는 교집합 버프의 수치를 강화한다. 버프 종류·미정 수치·순환 회복 계산과 용 전용 유물의 다른 유물 조합은 후속 결정한다.
- 긴 호흡 적용 태그 확대 (2026-10-18 사용자 합의): 적용 조건을 `집중유지`에서 `지속시간`으로 확대한다. 유한한 지속 시간이 있는 효과를 대상으로 하며, 음양에서는 음·양 장판의 유지 시간에 연결한다. 기존 증가율 25%는 유지하고 이름·일반 등급의 제안 상태는 바꾸지 않는다. 다른 파편의 유물 선택 목록을 자동으로 추가 확정하는 것은 아니다.
- 음양 전용 이스터에그 유물 (2026-10-18 사용자 합의): 장착한 상태에서 한 시전의 음·양 중심 타일을 동일하게 지정하면 해당 영역에 용이 한 번 출현한다. 아군과 침식체는 즉사, 환상체·보스는 최대 HP 25% 피해를 받는다. 후속 장판·회복·버프 없이 스킬이 종료된다. 직접 경험하기 전까지 유물의 정체·발동 효과를 드러내거나 경고하지 않는다. 이름·등급·세부 판정은 아래 개별 설계 절에 남긴다.
- 대상 사망 후 연속 공격 유물 (2026-10-18): 이름 `다음.`과 희귀 등급을 사용자 확정했다. 현재 대상이 사망하면 사망 위치의 한 칸 이내에서 가장 가까운 적에게 남은 공격을 이어가며, 시전자와 새 대상 사이의 사거리는 제한하지 않는다. 아군 처치에도 발동하고, 새 대상도 사망하면 같은 규칙으로 이어간다. 이름 끝의 마침표를 포함해 기록한다.
- 파편 분해 축 기록 (2026-09-07, 보완 2026-09-08): 기본형·개화형과 탱커·딜러 분기를 검토한 15개 공통 분해 축을 유지한다. 사용 방식, 피해 외의 반복 발생, 집계, 조건 분기, 소유 관계가 드러나도록 다섯 축의 명칭·설명을 보완했다. 효과의 단계·분기·병행 관계를 먼저 적고 개별 효과에 축을 대입한다. 아래 검토표와 작성 양식으로 부족한 부분 보완·강점 확대·운용 방식 변화의 후보를 찾으며, 분해 축·태그·수치·판정 규칙을 구분한다.
- 포큐버스 후속 합의 (2026-10-07): 시전 순간 범위 내 아군마다 독립 방어막을 1회 부여한다. 범위 진입·재진입으로 재부여하지 않으며 이탈 후에도 각자의 잔량을 유지한다. 단일 전환은 한 명의 강화 방어막으로 바꾸되 일반·침식 배율을 다시 결정한다. 기존 공용 보호량 기준 일반 2배·침식 4배 비교안은 과거 기준이며 새 개인 보호량에 자동 승계하지 않는다.
- 태아 수치·유물 합의 (2026-09-07, 범용화 2026-09-08): `긴 호흡`·`울림통`의 범용안을 유지한다. 이전 가칭 `깊어지는 울음`의 단일 전환·효과 증폭은 포큐버스에도 적용하는 범용 유물로 옮기고 태아 전용 유물은 미정으로 되돌린다. 기본 / 범용 유물 적용 / 침식된 범용 유물 적용 시 태아의 기본 공격 피해 `+20% / +40% / +80%`, 공격 속도 `+15 / +20 / +30`은 유지한다. 범용 유물의 이름·공통 증폭 규칙·포큐버스 수치, 집중 시간·대상 선정·침식 패널티와 희귀도는 후속 설계한다.
- 침식된 유물 기록 (2026-09-07): 효과를 크게 강화하는 대신 죽음에 이를 수 있는 패널티를 가진 유물 변형을 도입한다. 직접 드롭하지 않고 침식 아이템을 유물에 적용해 얻는다. 개별 패널티·아이템 획득처·적용 세부는 미정이며 파편 침식형과 구분한다.
- 다중타격·첫 유물 기록 (2026-09-07): 기존 `연속타격`의 명칭을 `다중타격`으로 정리하고, 나무꾼에서 출발한 공용 유물 `깊은 쐐기`를 기록한다. 개별 유물의 합의·미정 상태는 해당 절을 따른다.
- 희귀도 기록 (2026-09-07): 일반·희귀·특급의 획득 희귀도를 둔다. `깊은 쐐기`는 희귀이며 대체 이름은 `때린 곳 또 때리기`다.
- 전용 유물 기록 (2026-09-07): 태그 기반 범용 유물을 기본으로 삼되 고유한 스킬 구조를 확장하는 전용 유물도 허용한다. `붉은 실타래`는 래티씨아 기본·개화 파편 전용으로 남기며, 희귀도·수치·세부 판정은 미정이다.
- 소환물 기록 (2026-09-07): 대화에서 `잔류형`·`설치형`으로 검토한 범용 태그의 이름을 `소환물`로 정한다. 범용 유물은 소환물로 피해를 입은 대상에게 5초간 받는 피해 증가를 부여하는 구조로 정하며, 이름·증가율·희귀도·세부 판정은 미정이다.
- 회복 유물 기록 (2026-09-07): 가하는 회복량을 `25~40%` 증가시키는 범용 유물을 추가한다. 범위 안의 최종 증가율·이름·희귀도·세부 적용은 미정이다.
- 이로운 스택 유물 기록 (2026-09-07): 현재 자신이 보유한 이로운 스택 중 보유량이 가장 많은 한 종류의 수량만큼 공격력이 증가하는 범용 유물을 채택한다. `5·3·2`스택이면 `5`스택분이며 여러 종류를 합산하지 않는다. 이름·스택당 증가율·희귀도·세부 판정은 미정이다.
- 눈의 여왕 전용 유물 기록 (2026-09-07): 착용자의 파편 또는 무기가 부여한 냉기 디버프로 둔화된 적이 사망하면 빙결 잔영을 생성한다. 파편·무기를 모두 적용 출처에 포함하며, 이름·희귀도·수치·세부 판정은 미정이다.
- 흑조 전용 유물 기록 (2026-09-08): `깨어난 흑조`는 `검은 우산` 전용으로 기존 축적·패링 성공 시 방출 구조를 유지한다. 원본 파편 문서의 효과를 따르며 이름·희귀도·수치·세부 판정은 후속 설계한다.
- 저체력 조합 기록 (2026-09-08): 착용자 자신의 받는 피해를 증가시키는 독립 범용 유물을 남긴다. 잃은 체력 비례 공격력 증가의 방향도 기록하며 두 유물의 증가율·희귀도는 미정이다. 생존 유물은 사용자 명명 `빌려온 댓가`와 10초 HP 1 보장 → HP 절반 회복 → `대가` 디버프 부여로 변경한다. 자동 발동·전투당 1회, 회복 기준과 대가의 조합·세부 수치는 계속 제안 상태다.
- 강화형·전문화형·연결형·전환형은 콘텐츠를 설계하기 위한 역할 분류이며, 희귀도·획득 순서·유물 강화 단계와 구분한다.
- 분류 설명용 효과 예시는 개별 유물의 채택을 뜻하지 않는다. 별도 개별 유물 절의 구조 합의도 구현 완료를 뜻하지 않는다.

## 유물에서 얻고 싶은 재미

핵심 경험은 **“이걸 얻었으니, 이번 런에서는 이렇게 싸워볼까?”**다. 유물 획득이 현재 파편·장비를
다시 평가하게 하고, 다음 선택의 가치를 바꾸며, 그 런의 싸우는 방식을 기억하게 만드는 것을 목표로 한다.

| 재미 | 플레이어가 경험하는 변화 |
| --- | --- |
| 발견 | 따로 보던 효과들이 연결되고, 자신이 조합을 찾아냈다고 느낀다. |
| 운용 변화 | 같은 파편을 단일 강적 처리, 군집전, 장기 유지 등 서로 다른 방식으로 사용한다. |
| 성장 체감 | 적을 쓰러뜨리는 공격 횟수가 줄거나, 탄환·범위·연쇄 등 전장 결과가 눈에 띄게 달라진다. |
| 다음 선택에 대한 기대 | 새 유물 때문에 이전에는 관심 없던 파편·장비·다른 유물이 필요해진다. |

수치 증가도 성장 체감과 성능 보완이라는 역할이 있다. 모든 유물이 새 조작이나 복잡한 규칙을 요구할
필요는 없다. 다만 전체 목록이 같은 피해 증가만 반복하면 런마다 운용이 달라지기 어렵다.

모든 유물에 페널티를 붙이지 않는다. 장착 슬롯, 다른 유물을 포기하는 비용, 효과가 잘 발휘되는 상황과
발동 시점도 충분한 선택 요소가 된다. 조건이나 대가를 추가할 때는 그로 인해 어떤 판단이 생기는지 설명한다.

## 설계 범위와 공통 정책 연결

첫 콘텐츠 검토 범위는 **일반 보스(흉탄의 사수 제외)와 엘리트의 파편 및 무기·방어구·액세서리**다.
2026-09-12 분류 통일을 반영한 표기다. 기존 환상체별 검토 대상은 유지한다.
무기 하나만 보지 않고 기본·개화 파편과 장비의 역할, 독립 사용과 조합을 함께 읽는다.

- `죽은 나비들의 장례`는 알을 남기는 무보상 조우다. 파편·장비 유물 검토는 아종 `죽을 나비의 장례`를 대상으로 한다.
- 일반 보스 `마탄의 사수` 조우도 직접 보상이 없다. 보상 파편·장비의 소유자인 일반 보스
  `흉탄의 사수`는 첫 환상체별 유물 설계 범위에 포함하지 않는다. 공통 분해 축을 도출할 때는
  흉탄의 탄환·연쇄 구조도 참고한다.
- 녹아내리는 사랑은 탱커·딜러 파편의 두 방향을 따로 읽고 같은 장비와의 조합도 확인한다.
- 최종 보스·흉탄의 사수와 도구형은 첫 환상체별 설계 범위 밖이다. 공통 유물의 태그 호환성을
  검토할 때는 최종 보스도 같은 체계를 따른다는 기존 목표 정책을 유지한다.

콘텐츠 설계에 직접 필요한 기존 공통 목표의 요약은 다음과 같다. 상세 변경은 위 시스템 문서를 따른다.

| 항목 | 설계에 적용할 기준 |
| --- | --- |
| 장착 | 직원마다 용도 제한 없는 공용 유물 슬롯 3개. 서로 다른 직원에게 옮겨 사용할 수 있다. |
| 성장 | 유물 자체 레벨·반복 강화 단계는 없다. 동일 유물 획득은 별도 사본이며 중복 장착 여부는 개별 태그를 따른다. 침식 아이템을 적용하는 유물 변형은 아래 별도 정책을 따른다. |
| 희귀도 | 일반·희귀·특급. 역할 분류와 독립된 획득 희귀도이며, 개별 유물의 등급은 해당 설계 절에 기록한다. |
| 호환성 | 범용 유물은 효과 태그 조건으로 표현한다. 고유한 스킬 구조를 확장하는 전용 유물도 허용하며, 전용 대상과 적용 형태를 개별 설계에 명시한다. |
| 조합 | 유물이 새로 부여한 효과도 태그를 가지며 다른 유물의 강화·발동 조건에 참여할 수 있다. |
| 효과 범위 | 전투 안의 효과. 상점 가격, 보상량과 맵 생성 변경은 유물 효과에 넣지 않는다. |
| 누적 상태 | 유물 자체의 누적 상태는 전투마다 초기화한다. 기존 파편·장비가 소유한 run-local 진행도와 구별한다. |
| 연쇄 | 효과 간 연쇄는 허용하되 한 경로가 동일 유물 사본의 같은 효과로 되돌아오는 순환 재발동은 금지한다. |
| 파편 침식형 | 필드 적 처형 행동에는 유물의 증폭·추가 효과·연쇄 발동을 적용하지 않는다. 침식된 유물의 변형 상태와 구분한다. |
| 침식된 유물 | 효과를 크게 강화하고 죽음에 이를 수 있는 대가를 부여한다. 직접 드롭 없이 침식 아이템 적용으로 얻으며, 개별 패널티와 적용 세부는 후속 설계한다. |
| 획득 | 일반 유물과 침식 아이템의 획득처·빈도·후보 구성·선택 방식은 보류 상태다. 침식된 유물의 아이템 적용 방식 외에는 콘텐츠 분류만으로 자동 결정하지 않는다. |

범용 유물은 환상체를 출발점으로 구상하더라도 같은 효과를 가진 다른 장비에서 어떻게 쓰이는지
검토한다. 전용 유물은 아래 방침에 따라 원본 콘텐츠의 고유 구조를 확장한다.

### 범용 유물과 전용 유물

2026-09-07 후속 대화에서 **범용 유물을 기본으로 삼되 전용 유물도 남기기로 했다.** 기존의 모든
유물을 태그 조건만으로 범용화하던 방향을 수정한다.

- **범용 유물:** 효과 태그와 세부 속성으로 적용 대상을 정하고, 여러 파편·장비의 조합에 사용한다.
- **전용 유물:** 특정 파편·장비의 고유한 구조를 확장한다. 대상 콘텐츠와 기본형·개화형 등 적용
  형태를 명시하며, 같은 일반 태그를 가진 다른 효과에 전용 기능을 자동으로 적용하지 않는다.
- `붉은 실타래`는 첫 전용 유물 사례다. 래티씨아의 작은·큰 친구를 연결하고 순서대로 공격시키는
  구조를 유지한다. `깊은 쐐기`는 기존의 `다중타격` 기반 범용 유물로 유지한다.
- 범용·전용은 호환 범위의 구분이다. 희귀도나 강화형·전문화형·연결형·전환형의 역할을 자동으로
  결정하지 않는다. 슬롯·이전·중복·연쇄·침식 제외는 같은 공통 유물 정책을 따른다.
- 전용 유물이 생성하거나 변경하는 효과도 출처와 태그를 보존해 범용 유물과 조합할 수 있다.
  전용 조건의 정식 ID·schema 표현은 후속 구현 검토에서 정한다.

침식된 유물의 공통 방향과 남은 결정은
[침식된 유물 정책](../tmp/run_relic_system_design_notes_2026-08-21.ko.md#침식된-유물--대화-결정과-후속-설계)을 따른다.
HP 희생 유지, 침식체들의 최우선 공격 대상, 받는 피해 `100%` 증가 등은 서로 다른 패널티 후보다.
여러 후보를 모든 유물에 동시에 적용하거나, 아래 단일 전환 범용 유물의 침식 패널티가 확정된 것으로 읽지 않는다.

## 유물의 희귀도

2026-09-07 대화에서 **일반·희귀·특급**의 세 등급을 두기로 했다. 획득 시 기대감과 등장 빈도를
설계하는 기준이며, 유물 자체의 레벨이나 강화 단계가 아니다. 공통 정책은
[유물 시스템 설계 노트](../tmp/run_relic_system_design_notes_2026-08-21.ko.md#유물의-희귀도--대화-결정)를 따른다.

| 희귀도 | 콘텐츠 설계 방향 |
| --- | --- |
| 일반 | 자주 만나며 빌드의 기초를 만드는 선택 |
| 희귀 | 특정 운용이나 조합에서 높은 효과를 내는 선택 |
| 특급 | 런 전체에 미치는 영향이 커서 드물게 제공할 선택 |

희귀도는 강화형·전문화형·연결형·전환형과 독립적이다. 단순한 능력치 증가도 성능에 따라 특급일 수
있고, 사용 방식을 바꾸는 유물도 일반일 수 있다. 일반 유물도 특정 빌드에서는 끝까지 사용할 가치를
갖도록 설계한다. 등급별 정확한 획득처·출현 확률·후보 구성과 선택 방식은 계속 보류한다.

첫 배정은 `깊은 쐐기`의 **희귀** 등급이다. 대체 이름 `때린 곳 또 때리기`는 같은 유물을 가리킨다.

## 유물의 네 가지 역할

설계 분류는 **강화형·전문화형·연결형·전환형**으로 둔다. 유물이 빌드에서 맡는 주된 역할을 나타내며
네 분류 사이에 성능 서열을 두지 않는다.

| 분류 | 역할 | 설명용 효과 예시 | 선택하는 이유 |
| --- | --- | --- | --- |
| 강화형 | 현재 행동을 안정적으로 더 좋게 만든다. | 공격력 증가, 폭발 반경 증가, 보호막 생성량 증가 | 부족한 성능을 보완하고 기존 운용을 강화한다. |
| 전문화형 | 특정 상황이나 운용에서 큰 고점을 만든다. | 공격이 적 하나만 맞히면 피해 증가, 다수 저지 중 반격 강화 | 맡길 역할과 효과를 발휘할 전장 상황을 선택한다. |
| 연결형 | 한 효과가 다른 효과를 작동하게 한다. | 자기 회복 후 다음 기본 공격 강화, 이동을 멈춘 적에게 추가 폭발 | 서로 다른 파편·장비의 효과를 하나의 조합으로 엮는다. |
| 전환형 | 기존 효과의 사용 방식을 바꾼다. | 한 번의 큰 폭발을 여러 차례의 시간차 폭격으로 변경 | 익숙한 장비로 다른 싸우는 방식을 만든다. |

### 강화형

현재 빌드가 하는 일을 더 잘하게 만든다. 직원의 공격력·주문력·최대 HP 같은 능력치와, 이미 보유한
효과의 범위·횟수·지속 시간·생성량 같은 항목을 모두 검토할 수 있다.

- 조건을 외우지 않아도 성능이 체감되는 안정적인 선택을 제공한다.
- 단순 수치 유물도 하나의 슬롯을 사용할 가치가 있어야 한다.
- 효과가 실제로 어느 공격·회복·보호막에 적용되는지 읽을 수 있어야 한다.

### 전문화형

특정 상황에서 더 강해지는 방향을 선택하게 한다. 단일 강적, 밀집한 적, 다수 저지, 긴 공격 유지 등
상황에 따라 같은 장비의 역할이 달라질 수 있다.

- 조건은 배치·표적·사용 타이밍 같은 플레이어 판단과 연결될수록 좋다.
- 반드시 직접적인 불이익을 붙일 필요는 없다. 유리한 상황을 만들기 위한 선택 자체가 비용이 될 수 있다.
- 특정 역할에 투자한 효과가 실제로 드러나야 하며, 항상 자동 충족되는 조건인지도 확인한다.

### 연결형

이미 가진 효과를 다음 효과의 시작점으로 만든다. 회복, 보호막, 처치, 스택과 이동 방해 같은 전투
요소들이 다른 환상체의 파편·장비와 연결될 수 있다.

- 예를 들어 자기 회복 뒤 다음 기본 공격을 강화하는 아이디어는 미미크리의 기본 공격 흡혈과
  풍운승려 파편의 자기 회복에서 서로 다른 운용을 만들 수 있다. 흡혈·직접 회복의 포함 여부와
  발동 횟수는 개별 설계에서 명시하며, 두 source의 호환을 이 예시로 확정하지 않는다.
- 새 효과가 다른 유물의 태그 조건을 만족하면 추가 조합이 가능해야 한다.
- 연쇄가 무엇에서 시작되고 무엇을 만들어내는지 플레이어가 이해할 수 있어야 한다.
- 연쇄 허용과 순환 재발동 제한은 공통 시스템 목표를 따른다.

### 전환형

전달 방식, 시간 배분이나 자원 사용 방식 등을 바꾸어 새로운 운용을 연다. 기존 효과의 수치만
높이는 것보다 플레이어가 배워야 할 변화가 크므로, 한 유물의 중심 변화가 명확한 후보부터 검토한다.

- 일제 폭발을 시간차 폭격으로 바꾸는 예시는 순간 화력, 후속 웨이브 대응과 적을 붙잡아둘 필요를 바꾼다.
- 원래 파편·장비의 정체성과 역할을 읽은 뒤 어떤 부분을 바꿀지 정한다.
- 전환형이라는 이유로 자동으로 가장 강하거나 가장 희귀하게 취급하지 않는다.
- 전환형 하나가 런의 중심이 될 수 있지만, 모든 빌드에 전환형을 요구하지 않는다.

### 분류를 적용하는 방법

- 유물마다 주된 역할 하나를 먼저 적는다. 부수적으로 다른 역할을 가질 수 있으며 완전한 상호 배타성을 강제하지 않는다.
- 한 유물이 강화·전문화·연결·전환을 전부 수행한다면 효과를 과도하게 묶었는지 검토한다.
- 환상체마다 네 분류를 같은 수로 채우지 않는다. 전체 목록에서 다양한 선택이 성립하는지를 본다.
- 역할 분류별로 희귀도를 고정 배정하지 않는다. 출현 비율과 제작 수량은 후속 설계한다.

## 처음 논의한 세 가지 예시와의 관계

처음 제시된 `단순 수치 증가 / 효과 증폭 / 효과 추가`는 무엇을 바꾸는지 설명하는 유용한 관점으로
남긴다. 이후 제안한 네 가지 역할 분류와 일대일로 대응하는 별도 성장 단계는 아니다.

| 변화 방식 | 네 역할 분류에서의 해석 |
| --- | --- |
| 단순 수치 증가 | 일반적인 능력치 증가는 강화형이다. 특정 운용 조건에서만 큰 증가를 얻으면 전문화형이 될 수 있다. |
| 효과 증폭 | 기존 효과의 범위·횟수·지속 시간 등을 늘리는 강화형이 기본이다. 조건에 따라 전문화형도 가능하다. |
| 효과 추가 | 새 효과를 부여할 수 있다. 기존 효과를 발동 조건으로 연결하면 연결형, 기존 사용 방식까지 바꾸면 전환형을 주된 역할로 검토한다. |

숫자를 변경했다는 이유만으로 같은 분류로 보지 않는다. 공격력 증가와 폭발 반경 증가는 모두 숫자를
바꾸지만 적용 대상과 체감이 다르다. 분류의 목적은 구현 형식을 분리하는 것이 아니라 선택의 의미를 설명하는 것이다.

## 3슬롯에서 만들고 싶은 선택

각 직원의 슬롯 3개는 다음과 같이 서로 다른 조합을 허용해야 한다.

- 강화형을 모아 안정적인 성능을 확보한다.
- 전문화형을 모아 단일 보스 처리나 군집전 등 특정 역할에 투자한다.
- 연결형을 조합해 여러 효과가 이어지게 한다.
- 전환형 하나를 중심으로 나머지 슬롯을 구성한다.
- 여러 역할을 섞어 기존 효과와 새 효과를 함께 강화한다.

설명용 조합:

```text
투사체 적중 시 폭발을 만드는 유물
→ 새 폭발의 범위를 넓히는 유물
→ 해당 피해가 참조하는 공격력 또는 주문력을 높이는 유물
```

이는 필수 조합식이 아니다. 새로운 효과를 더 붙이는 것보다 기존 효과의 범위를 넓히는 편이 유리한
경우도 있어야 한다. 효과 추가·전환만으로 세 슬롯을 채우는 선택이 항상 정답이 되지 않도록 검토한다.

## 파편·장비를 읽으며 확인한 설계 재료

다음은 개별 콘텐츠 본문을 읽고 정리한 운용 요소다. 같은 행에 있다는 이유로 동일한 정식 태그를
부여하거나 서로의 효과를 자동 공유하지 않는다. 최신 세부 의미는 원본 파편·장비 문서를 확인한다.

| 전투 요소 | 관련 환상체 |
| --- | --- |
| 강한 한 방과 특정 공격의 처치 | 따뜻한 마음의 나무꾼, 지혜를 구하는 허수아비, 절망의 기사 |
| 기본 공격 유지·변형·종료 시점 | 샤덴프로이데, 아무 것도 없는, 커다랗고 나쁠 늑대 |
| 아군 배치와 기본 공격 지원 | 이름이 없는 태아 |
| 사격 방향·고정 타일·폭격 타이밍 | 붉은 두건의 용병, 탐욕의 왕, 썰매의 루돌타, 풍운승려 |
| 대상별 스택 축적·소비·이동 제어 | 파고드는 천국, 웃는 시체의 산 |
| 감염 전파·사망 위치·폭발 | 녹아내리는 사랑의 딜러 파편, 죽을 나비의 장례 |
| 피해 방어·패링·보호 자원 관리 | 흑조의 꿈, 포큐버스, 녹아내리는 사랑의 탱커 파편 |
| 회복 대상·위치·조건과 후속 지원 | 여왕벌, 증오의 여왕, 음/양 |
| 함정 배치·중첩 진화·연결 | 래티씨아 |

### 장비 자체 효과와의 관계

현재 콘텐츠 설계에는 이미 다음 효과가 장비에 들어 있다.

| 장비 | 기존 역할 |
| --- | --- |
| 죽을 나비의 장례 액세서리 | 처치 위치에서 나비 폭발을 만들고 후속 처치로 연쇄 폭발한다. |
| 루돌타 액세서리 | 단일 피해를 범위화하고 기존 피해 범위를 확대한다. |
| 파고드는 천국 액세서리 | 증폭이 허용된 스택의 최초 부여량을 늘린다. |
| 샤덴프로이데 액세서리 | 공격을 연속으로 유지한 시간에 따라 공격력을 누적한다. |
| 허수아비 액세서리 | 기본 공격 사이의 경과 시간으로 다음 한 번의 공격을 강화한다. |
| 여왕벌 액세서리 | 실제로 회복한 아군에게 공격 속도를 부여한다. |

이런 특수 효과를 장비에서 모두 떼어 유물로 옮기지 않는다. 유물은 기존 장비 효과와 조합했을 때
새로운 가치가 생기는지, 같은 기능을 중복해서 지급하는지 확인하며 설계한다.

## 파편 효과 분해와 유물 설계 검토표

2026-09-07 대화에서 파편의 개별 능력뿐 아니라 그 능력을 구성하는 하위 요소를 분석하고,
부족한 부분이나 강화했을 때 재미있을 부분을 유물로 채우기로 했다. 원본 파편 문서의 기본형·개화형과
녹아내리는 사랑의 탱커·딜러 분기를 훑어 아래 **15개 축을 공통 검토 틀**로 정리한다.
2026-09-08에는 축 수를 유지하면서 복합 효과의 단계·분기를 먼저 기록하고, 반복 발생·집계·소유
관계를 더 명확히 표현하도록 보완했다. 현재 검토한 파편들을 설명하는 공통 틀이며, 모든 축이 서로
독립적이거나 이후 모든 효과를 빠짐없이 표현하는 고정 규격이라는 뜻은 아니다.

### 효과 단위로 분해하는 원칙

- **파편 → 효과의 단계·분기·병행 관계 → 개별 효과 → 분해 축** 순서로 읽는다. 풍운승려의 광역
  물어뜯기와 적중 후 자기 회복은 연결 관계를 적되 각각 분해한다. 공격 범위를 늘렸다는 이유로
  자기 회복까지 광역 회복으로 바꾸지 않는다.
- 유물을 설계할 때마다 15개 축을 확인하고, 실제로 변경할 효과와 축을 특정한다. 모든 축에서
  유물을 하나씩 만들거나 한 유물로 여러 약점을 동시에 해결할 필요는 없다.
- 원본에 없는 속성은 `해당 없음`, 아직 결정하지 않은 속성은 `미정`으로 남긴다. `미정`을 0이나
  무제한으로 해석하지 않으며, 유물 설계를 위해 원본의 수치·판정을 임의로 확정하지 않는다.
  원본의 수치·규칙이 미정인 것과 그 속성을 담을 분해 축이 부족한 것은 구분한다.
- 소환물처럼 세부 구조가 많은 효과에는 HP·이동·피격·저지·동시 존재 수 등의 **전용 하위 항목**을
  붙인다. 변신의 교체·복귀 규칙이나 공유 자원의 참가·이탈 규칙도 필요한 효과에서 보충한다.
  `소환물` 태그만으로 모든 매개체가 같은 유닛 구조나 능력을 가진다고 보지 않으며, 특수 사례 하나마다
  공통 축을 늘리지 않는다.
- 파편 침식형은 기존 공통 정책대로 유물 증폭·추가 효과·연쇄의 적용 대상에서 제외한다.
  침식 아이템으로 변형하는 `침식된 유물`과 구분한다.

### 효과의 단계와 분기를 먼저 기록

먼저 사용·사건에서 시작해 어떤 상태와 효과가 이어지는지 적는다. 단계 사이에는 전환 사건·조건을,
같은 단계에서 함께 작동하는 효과에는 병행 관계를 표시한다. 단순한 효과는 한 단계로 충분하며,
표를 채우려고 새 단계나 분기를 만들지 않는다. 흐름 기록은 16번째 축이 아니라 **15개 축을 대입할
효과와 그 연결을 먼저 정하는 절차**다.

예를 들어 `Hello / Goodbye`는 다음과 같이 읽는다.

| 단계·상태 | 전환 사건·조건 | 효과와 종료 처리 |
| --- | --- | --- |
| 첫 시전 → Hello 유지 | 공명 만충에서 시전, 공명 소비 | 기본 공격을 직선 관통 공격으로 교체. 별도 집중 없이 기본 공격·저지 가능 |
| Hello → 자연 종료 | 재입력 없이 유지 시간 만료 | 원래 기본 공격으로 복귀. Goodbye는 발생하지 않음 |
| Hello → Goodbye → 종료 | Hello 유지 중 재입력 | 남은 변형 시간을 포기하고 직접 스킬 공격 1회 후 복귀. 추가 공명 소비 없음 |

그다음 Hello의 기본 공격 교체와 Goodbye의 일격을 각각 분해한다. 남은 시간에 따른 Goodbye의
위력은 8번, 재입력 분기는 12번, 종료 후 복귀는 14번, 두 공격의 서로 다른 출처는 15번에서 확인한다.
취소·철수 등 원본에서 미정인 종료 판정은 이 예시로 확정하지 않는다.

### 15개 공통 분해 축

| 분해 축 | 살펴볼 하위 요소 | 실제 파편에서 확인한 사례 |
| --- | --- | --- |
| 1. 사용·조작 방식 | 상시·자동 적용, 수동 사용, 재입력, 사용 모드 선택 등 조작 방식 | 흑조의 상시 방어와 수동 패링, Hello 중 Goodbye 재입력 |
| 2. 대상·선정 | 자신·아군·적, 단일·다수, 대상 수, 우선순위, 재선정, 대상 제한 | 여왕벌의 아군 한 명 지정, 늑대의 침식체 한정 포식 |
| 3. 공간 구조 | 시전 사거리, 탐색 범위, 효과 범위·형태, 발생 위치, 고정·추종 | 음/양의 고정 회복 장판, 붉은 두건의 여러 사격 원점 |
| 4. 전달·매개 | 즉시 적용, 투사체, 관통, 접촉, 부착 상태, 소환물·설치물 | 흉탄의 탄환, 래티씨아의 친구, 포자 감염의 숙주 |
| 5. 시간 구조 | 준비 시간, 발동 지연, 유지 시간, 효과 발생 간격 | 나비의 지연 폭발, 음/양의 회복 주기 |
| 6. 반복·발생 구조 | 피해·회복·보호막 재부여·소환 등의 발생 횟수, 동시·순차 실행, 같은 대상 반복 적용, 회차별 효과량 배분 | 나무꾼의 연타와 강한 마지막 타격, 음/양의 반복 회복, 루돌타의 유한 횟수 폭격 |
| 7. 효과의 종류 | 피해, 회복, 보호막, 능력치 강화, 기본 공격 변형, 제어, 생존 보장 | 태아의 기본 공격 강화, 샤덴프로이데의 HP 1 유지 |
| 8. 효과량·참조 기준 | 기본값·계수, 공격력·최대 HP·결손 HP·남은 시간 등에 비례, 계산 시점 | 여왕벌의 대상 최대 HP 비례 회복, Goodbye의 남은 시간 비례 위력 |
| 9. 집계·분배·공유 | 입력값의 합산·최댓값 선택과 집계 단위, 대상별 동일량 지급, 총량 분할, 공용 잔량, 주 대상 집중 | 나비 개화형은 타일·그 위 유닛의 스택을 타일 단위로 합산, 포큐버스는 시전 시 대상마다 독립 보호량 지급 |
| 10. 자원·축적 | 저장량, 획득 방식, 상한, 갱신·감쇠, 소비량, 단계별 변화 | 떠다니는 검, 욕망, 웃는 얼굴, 타일에 쌓이는 나비 |
| 11. 비용·위험 | 공명·HP·자원 지불, 시전 기회 포기, 자해, 실패 불이익 | 탐욕의 시전 기회 저축, 늑대 개화형의 HP 비용, 흑조의 패링 실패 |
| 12. 조건·분기·연계 | 적중·처치·피격·임계치 등 사건과 조건, 판정 시점·확률·인정 단위와 횟수, 성공·실패·종료 방식에 따른 분기, 동시 조건의 우선순위, 전파·연쇄 | Hello의 자연 만료와 재입력 분기, 포자 감염의 사망 전파 우선 처리 |
| 13. 행동 병행·제약 | 기본 공격·이동·저지와 병행하는지, 집중이 필요한지, 중단 조건 | 태아는 집중 중 행동 제한, 루돌타는 폭격과 기본 공격 병행 |
| 14. 종료·존속 | 만료·소진·재사용·이탈·사망 시 처리, 잔존 여부, 전투·런을 넘는 유지 | 고기벽은 시전자 철수 뒤에도 존속, 증오의 하트는 전투 로컬로 사망·후퇴·전투 종료 시 초기화하고 전술 이동 시 유지 |
| 15. 출처·소유·귀속 | 기본 공격·직접 스킬·지속 피해 등의 출처, 효과를 만든 주체, 상태·자원의 소유자와 보유자·수혜자, 공격·회복·처치의 귀속 | Hello는 무기 기본 공격이고 Goodbye는 직접 스킬 피해, 욕망은 직원이 아니라 개별 파편 인스턴스 소유 |

### 축을 대입할 때 구분할 것

- **조작과 조건·분기(1·12):** 재입력하는 조작은 1번, 재입력이 허용되는 상태와 그때 실행할 효과는
  12번이다. 자동 효과도 무엇이 발동 사건이고 어떤 조건을 요구하는지 별도로 적는다.
- **시간·횟수·종료(5·6·14):** 루돌타의 투하 간격을 줄이면 정해진 횟수를 빨리 소진한다. 횟수
  증가와 별도 변경이며, 공격 속도 증가가 투하 간격·횟수를 자동으로 바꾸지도 않는다. 얼마 동안
  유지하는지와 몇 번 발생하는지, 소진·중단 뒤 무엇이 남는지를 나눠 본다.
- **집계·계산·축적(9·8·10):** 나비의 타일·유닛 스택을 어떤 단위로 합칠지는 9번, 집계한 값으로
  폭발 횟수·위력을 어떻게 계산할지는 6·8번, 스택의 획득·상한·소비는 10번이다. 이로운 스택 유물의
  `가장 많은 한 종류만 참조`도 9번에서 기록한다. 집계 방식을 정했다고 저장·소비 규칙까지 정해진
  것으로 보지 않는다.
- **대상 수와 총 효과량(2·8·9):** 포큐버스는 각 대상의 보호량 `S`를 유지해도 대상 수 `N`이 늘면 총 생성량이 `N × S`로 늘어난다. 범위·개인 보호량·지속 시간을 함께 조정한다.
- **서로 다른 시간(5·14):** 파편 유지 시간과 부여한 상태의 지속 시간을 구분한다. 태아는 집중·범위에서
  파생되는 오라여서 별도 버프 잔여 시간이 없고, 정확한 최대 집중 시간은 미정이다. `범위 이탈 후 잠시
  버프 유지`는 현재 효과의 시간 수치만 늘리는 것이 아니라 잔존 규칙을 추가하는 후보다.
- **참조 관계와 출처·소유(8·15):** 기본 공격 피해 증가, Attack stat 증가, 공격 속도 증가는 영향을
  주는 효과와 방식이 다르다. 광역 공격 뒤의 자기 회복이나 소환물의 후속 피해도 각각의 출처를 보존한다.
  효과의 제공자와 수혜자, 자원을 소유한 파편과 장착 직원이 같다고 가정하지 않는다. 다른 아군에게
  공격 강화를 부여했다고 그 아군의 공격·처치가 제공자의 것으로 바뀌지 않는다.
- **분해 축과 태그:** 축은 설계 검토 항목이다. `집중유지`는 분류 태그, 유지 시간은 수치,
  `집중 종료 시 버프 제거`는 판정 규칙으로 기록한다. 여러 효과가 공유하고 유물의 적용 조건으로
  쓰기 좋은 특징을 태그로 뽑으며, 15개 축의 이름을 그대로 정식 태그로 만들지 않는다.

같은 규칙이 여러 축에 걸치면 주된 항목에 적고 관련 축에서 참조해도 된다. 중복을 억지로 없애기보다
어떤 효과의 어떤 판단을 다루는지 명확히 남긴다.

### 유물 설계 때마다 적용하는 순서

1. 원본 파편·장비와 기본형·개화형 등 검토 형태를 명시한다. 효과의 단계·분기·병행 관계와 전환 조건을
   먼저 적고, 축을 대입할 개별 효과를 구분한다.
2. 각 효과에 15개 축을 대입해 현재 구조와 미정 항목을 기록한다. 기존 흐름·분해표가 있으면 원본이
   바뀌었는지 확인한 뒤 재사용하고, 필요한 전용 하위 항목을 보충한다.
3. **부족한 부분 보완·강점 확대·운용 방식 변화**의 관점에서 후보를 찾고, 이번 유물이 바꿀 효과와 축을
   고른다. 이 세 관점은 기존 강화형·전문화형·연결형·전환형과 별개의 유물 등급이나 역할 분류가 아니다.
4. 변경 전후 효과와 플레이어의 달라지는 배치·표적·사용 시점·조합을 적는다. 다른 단계·분기의 조건,
   자원 소비·잔존과 후속 효과에 미치는 영향도 확인한다. 시전자의 행동 포기처럼 핵심 선택을 만드는
   제약을 바꿀 때는 변경 뒤 어떤 선택이 남는지도 확인한다.
5. 범용·전용 조건과 실제 태그·수치·판정 규칙을 정리하고, 기존 장비·유물과의 중복 및 조합을
   확인한다. 미정 사항을 남긴 채 아래 개별 유물 기록 항목으로 연결한다.

### 복사해서 사용하는 검토 양식

검토 대상의 흐름을 먼저 한 번 작성한 뒤 개별 효과마다 축 표를 작성한다. 관련 없는 원본 속성은
`해당 없음`, 아직 정하지 않은 값·규칙은 `미정`, 이번 유물이 바꾸지 않을 축은 `변경 없음`으로
표시한다. 기존 흐름·분해표를 재사용할 때는 그 위치를 참조하고 이번에 변경할 효과·축과 후보를 갱신한다.

## 기초 태그 초안

2026-09-06 대화에서 파편들의 기초 태그를 먼저 만들고 스킬·유물에 적용하며 확장하기로 했다.
아래는 그 검토를 시작할 한글 태그 초안이다. 정식 tag ID, RON/schema와 runtime 지원 목록의 확정이나
현재 파편·장비 데이터에 태그를 적용했다는 뜻은 아니다. 개별 효과의 미정 수치·대상·판정은 원본
파편 문서의 open design으로 유지한다.

### 적용 단위와 출처

태그는 **파편 전체가 아니라 개별 효과에 붙인다.** 한 파편의 서로 다른 효과가 가진 태그를 합쳐
하나의 효과가 모든 조건을 만족한다고 판단하지 않는다.

- 풍운승려의 광역 물어뜯기와 자기 회복은 별도 효과다. 공격의 범위 증가가 자기 회복을 광역 회복으로
  바꾸지 않는다.
- Hello의 관통 기본 공격과 Goodbye의 광역 스킬 피해는 따로 분류한다. 허수아비가 강화한 공격도
  기본 공격이라는 출처를 유지한다.
- 기본 공격, 파편의 직접 공격, 지속 피해, 장비·유물의 추가 효과 등 어떤 경로에서 발생했는지 함께
  보존한다. 같은 `피해` 태그가 있어도 모든 적중·처치·흡혈 조건을 공유하는 것은 아니다.
- 장비의 효과는 파편 자체의 효과와 구분한다. 나무꾼 방어구의 스킬 처치 회복과 액세서리의 흡혈을
  나무꾼 파편의 기본 효과로 붙이지 않는다.

### 효과의 종류

| 태그 | 의미 | 파편에서의 사례 |
| --- | --- | --- |
| `피해` | 대상의 HP를 감소시키는 효과 | 나무꾼의 도끼 공격 |
| `받는피해증가` | 대상이 받는 피해를 증가시키는 상태 | 소환물 범용 유물의 피격 대상 약화, 저체력 조합용 유물의 착용자 자신에 대한 증가 |
| `회복` | 대상의 HP를 회복하는 효과 | 여왕벌의 일벌, 풍운승려의 자기 회복 |
| `보호막` | 유한한 보호량으로 피해를 흡수 | 포큐버스의 아군별 개인 포자막 |
| `피해감소` | 들어오는 피해량을 줄임 | 흑조의 상시 감면 |
| `피해차단` | 해당 피해를 무효화 | 흑조는 패링 성공 첫 타격부터 0.5초간 모든 피해·행동제어 면역. 그 외 효과의 부착·해제는 정상 적용하며 세부는 원본 파편 설계를 따른다 |
| `생존보장` | 피해를 받아도 일정 HP 아래로 내려가지 않음 | 샤덴프로이데의 HP 1 유지 |
| `능력치변경` | 공격력·공격 속도·최대 HP 등의 능력치를 변경 | 샤덴프로이데의 자기 강화, 늑대의 포만 |
| `기본공격강화` | 기본 공격의 피해 등을 직접 강화 | 허수아비의 다음 공격 강화, 태아의 공격 지원 |
| `기본공격변형` | 기본 공격의 범위·공격 방식을 교체 | 아무 것도 없는의 Hello |
| `제어` | 적의 이동·행동·표적 선택에 개입 | 감속, 속박, 빙결, 기절, 도발, 끌어당김 |
| `반사` | 받은 공격을 근거로 공격자에게 피해를 돌려줌 | 흑조의 확률 반사 |
| `패링` | 짧은 판정 창에서 공격을 받아내는 효과 | 흑조의 수동 패링 |
| `스택` | 횟수나 단위로 축적하고 사용하는 상태 | 떠다니는 검, 주시, 웃는 얼굴, 욕망 |
| `전파` | 한 대상의 상태를 다른 대상에게 퍼뜨림 | 녹아내리는 사랑의 포자 감염 |
| `소환물` | 전장 위치에 설치물·축적 상태·영역을 남겨 이후 발동하거나 효과를 유지 | 래티씨아의 친구, 죽나장의 타일 나비, 고기벽, 음/양의 회복 장판 |
| `방해물` | 전장에 남아 적의 진행을 막는 파괴 가능한 물체 | 녹아내리는 사랑의 고기벽 |

`능력치변경`과 `기본공격강화`는 구분한다. 공격력 증가라면 그 능력치를 참조하는 스킬에도 영향을
줄 수 있지만, 기본 공격 피해 증가가 스킬 피해까지 높이지는 않는다. 태그를 찾은 뒤 실제로 변경할
항목은 유물 효과에 적는다. 일반 공격력 증가 유물도 이미 `능력치변경` 효과를 가진 파편만 요구하는
것이 아니라, 직원의 능력치를 직접 변경하는 효과로 작성할 수 있다.

`보호막`, `피해감소`, `피해차단`, `생존보장`은 서로 다른 방어 방식이다. 고기벽은 적이 직접 공격해
파괴하는 `방해물`이며, 같은 HP를 가진다는 이유로 `보호막`에 포함하지 않는다.

### 소환물 태그의 이름과 범위

2026-09-07 대화에서 `잔류형`의 이름을 **`소환물`**로 정했다. `잔류형`·`설치형`은 이전 이름
후보이며 별도 동의어 태그로 두지 않는다. 이 문서에 먼저 있던 `함정` 태그도 이 범용 태그로
확장한다. 적의 접근을 기다리는 래티씨아 친구의 작동 설명에서는 계속 함정이라는 말을 쓸 수 있다.

- 기존에 검토한 설치물·타일 축적·고정 영역을 묶는 효과 태그다. 반드시 HP를 가진 생물이나
  조작 가능한 독립 유닛이어야 하는 것은 아니다.
- 고기벽은 `소환물·방해물`, 회복 장판은 `소환물·회복·지속영역`처럼 기존 효과 태그와 함께 쓴다.
  원본 문서의 일반 summon 여부, HP·저지·피격·이동·명령 가능 여부는 각 효과의 기존 설계를 따른다.
- 소환물이 발생시킨 피해·회복은 해당 소환물과의 관계를 보존한다. 파편의 직접 피해나 장비의
  추가 피해 같은 원래 출처를 일괄 교체하거나 파편 전체에 소환물 태그를 부여하지 않는다.
- 타일을 한 번 공격하는 가시·폭격이나 일벌 같은 전달 연출만으로 태그를 부여하지 않는다.
  이동하는 잔영 등 경계 사례는 개별 적용 때 검토한다.

### 작동 방식

아래 태그는 효과 또는 그 효과를 실행하는 공격 순서·영역에 필요한 만큼 붙인다.

| 태그 | 의미 | 사례 |
| --- | --- | --- |
| `범위` | 정해진 공간 안의 여러 대상에 적용 | 광역 내려찍기, 회복 장판 |
| `관통` | 하나의 공격이 경로상의 여러 적을 통과해 타격 | Hello의 관통 평타, 붉은 두건의 사격 |
| `폭발` | 중심 지점 주변에 폭발 피해를 발생 | 루돌타의 선물, 나비 폭발 |
| `다중타격` | 한 번의 스킬 시전 안에서 순서가 있는 여러 직접 타격 단계를 발생 | 나무꾼의 3타, 루돌타의 연속 폭격 |
| `지속피해` | 부여된 상태가 일정 주기로 피해를 발생 | 포자 감염의 지속 피해 |
| `지연발동` | 효과를 준비·배치한 뒤 별도의 지연을 거쳐 발동 | 경로를 덮은 나비의 폭발 |
| `지속영역` | 일정 시간 공간을 유지하며 그 안의 대상에 효과를 적용 | 음/양의 장판, 태아의 지원 범위 |
| `지속시간` | 유한한 지속 시간이 있는 효과. 해당 효과가 유지되는 시간에 적용 | 음·양 장판의 유지 시간, 태아의 최대 집중 시간, 기간형 강화. `긴 호흡`의 적용 태그 |
| `집중유지` | 시전자가 집중 행동을 유지해야 효과가 지속 | 태아의 울음 |
| `흡혈` | 유효한 피해량에 비례해 회복 | 늑대 개화형의 기본 공격 흡혈 |
| `투사체` | 실제 투사체를 통해 공격을 전달 | 전달 방식이 투사체로 정해진 공격에 적용 |

- `관통`은 유닛 관통이며 방어력 관통과 구분한다.
- `다중타격`은 기존 초안의 `연속타격`을 정리한 명칭이다. 별도의 동의어 태그를 두지 않는다.
  스킬의 복수 타격 구조를 나타내며, 타격별 피해 증가 자체는 유물의 효과가 소유한다.
- `다중타격`은 `지속피해`와 별개다. 루돌타의 여러 폭격은 직접 스킬 피해이며 지속 피해 강화에
  자동으로 포함하지 않는다. 공격 속도가 스킬 타격 간격이나 횟수를 바꾸는지도 이 태그만으로 정하지 않는다.
- 한 타격이 여러 적을 맞히거나 여러 피해 type·계산 segment를 가진다는 사실만으로 `다중타격`을
  부여하지 않는다. 스킬 자체의 구분된 타격 단계를 기준으로 하며 별도 장비·유물의 추가 피해를
  원래 스킬의 새 타격 단계로 자동 포함하지 않는다.
- `지연발동`은 나비 확산 뒤 기폭 같은 효과의 별도 지연을 표현한다. 모든 기본 공격 windup이나
  일반 시전 준비 시간을 이 태그로 묶지 않는다.
- `집중유지`는 실제 channel/focus action이다. 일정 시간 남는 자기 강화나 수동 표적 선택용
  tactical focus를 포함하지 않는다.
- `지속시간`은 2026-10-18 합의로 `긴 호흡`의 적용 태그가 됐다. 집중형에 한정하지 않으며,
  효과의 지속 시간과 시전 준비·쿨다운·공명 충전·공격 및 회복 주기는 구분한다. 태그는 시간을
  늘릴 개별 효과에 붙이고, 별도 효과의 수명까지 일괄 변경하지 않는다. 무기한 효과나 즉시 효과에
  새 지속 시간을 만들지 않으며, 집중형의 행동 제한·중단 조건은 그대로 유지한다.
- `흡혈`은 `회복` 효과의 방식이다. 풍운승려의 적중 시 최대 HP 비례 1회 회복은 피해량 비례 흡혈이 아니다.
- `투사체`는 날아가는 연출만 보고 붙이지 않는다. 나비·일벌·아귀 형상의 실제 전달 방식과 object
  의미를 원본 설계에서 확인한다. 여왕벌의 일벌을 일반 소환물로 재분류하지 않는다.

### 효과 변형 태그 — 2026-10-18 사용자 추가

아래 표는 절망의 기사에서 출발한 공통 효과 변형 태그다. 증오의 여왕에 선택한 7개 연결은 별도 절에 기록한다. `피해`·`제어`·`스택`처럼
효과의 성질을 설명하는 기존 태그와 함께 기록하되, 실제 변형은 해당 유물 효과가 적용될 때 발생한다.
이름을 정식 ID나 구현 완료 선언으로 취급하지 않는다. 파편 전체에 한꺼번에 붙이지 않고 변형할
효과·획득 사건·상한·쿨다운을 지정한다.

| 사용자 태그 | 효과와 적용 의미 | 절망의 기사 적용 지점 |
| --- | --- | --- |
| `쿨다운속도감소` | 쿨다운 완료까지 걸리는 시간을 줄이는 방향으로 해석한다. 표기는 사용자 요청대로 보존하며 감소율·계산식은 미정 | 가호가 검을 생성하는 자체 쿨다운. 공명 충전이나 개화 절망의 공격·자기 피해 주기와 구분 |
| `치명적인군중제어` | 강력한 군중제어를 가한 대상에게 5초간 받는 피해 증가 부여. 증가율 미정 | 첫 찌르기·데스비오·개화 일반 큰 검의 기절 |
| `스택한도해제` | 해당 효과에 명시된 스택 한도를 무시 | 검의 기본 최대 4개 제한을 무시. 다른 수치의 상한을 일괄 해제하지 않음 |
| `보호막효율증가` | 생성하는 보호막량을 퍼센트로 증가. 증가율 미정 | 가호의 긴급 보호막량. 발동 HP 조건·전투당 횟수·15초 지속은 별도 속성 |
| `스택부여` | 다른 대상에게 부여하는 스택량을 2배로 증가 | 각 검술 단계 뒤의 상처 `c → 2c`, 개화 절망 주기 공격의 상처 `1 → 2` |
| `스택획득` | 자신이 획득하는 스택량을 2배로 증가 | 가호 쿨다운 완료 시 소유자가 얻는 검 `1 → 2` |
| `범위증폭` | 단일 대상 스킬을 작은 범위 스킬로 변경하거나, 기존 범위 스킬의 범위를 한 칸씩 확장 | 기본형 단일 공격의 작은 범위화, 데스비오·개화형 공격 범위 확장 |
| `무아지경` | 스킬 시전 중 군중제어·침묵 등 외부 효과로 시전 행동이나 집중이 중단되지 않음. 집중형에만 한정하지 않음 | 진행 중인 검술 시전과 개화 절망의 집중. 상태 부착 면역을 주는 효과는 아님 |
| `공격이어가기` | 현재 대상이 사망했을 때 진행 중인 공격의 남은 단계·타격을 다른 대상에게 이어갈 수 있는 효과 | 기본형 일반 연속기·기본형 절망 엑시큐션. 유물 `다음.`이 연결 규칙을 적용 |

적용 지점과 후속 판정은 다음처럼 구분한다.

- 검은 획득 사건, 상처는 대상에게 부여하는 사건으로 연결한다. 같은 검 생성 사건을 두 태그로
  중복 분류해 자동으로 4배 처리하는 것은 현재 적용안이 아니다. 한도 해제 없이 획득량만 늘리면
  명시된 최대량은 유지되며, 두 유물을 함께 적용하면 한도를 무시한 상태로 검을 더 빨리 모은다.
- 검 한도 해제는 소비량·작은 검 수·절망 진입 자기 피해·기본형 절망 타수·개화형 절망 유지 시간에
  기존 검 수 연동 규칙대로 영향을 준다. 유물 효과에 임의의 대체 상한을 추가하지 않는다.
- `범위증폭`의 기본 적용안은 공격 효과 단위다. 변환한 작은 범위의 크기, 직선·원형 등의 한 칸
  확장 방식, 연결된 기절·상처의 대상 범위는 제작 정의에서 명시한다. 메뉴의 가호 지정 관계와
  동시 보호 대상 수를 공격 범위 확장만으로 변경하지 않는다.
- `치명적인군중제어`에서 기본 공격 불가·둔화를 기절과 같은 강력한 군중제어로 자동 분류하지
  않는다. 상세 대상 제어 목록은 아래 유물 절에서 관리한다.
- `무아지경`의 최신 확정 설명은 **스킬 시전 중 군중제어·침묵 등 외부 효과로 시전 행동이나
  집중이 중단되지 않는다.** 집중형만이 아니라 진행 중인 스킬의 시전 동작을 보호한다. 기절·빙결·
  침묵 상태와 강제 이동 자체의 부착 면역을 주지는 않지만 그것 때문에 현재 시전 동작을 멈추지 않는다.
  피해·디버프 자체와 직접 중단·시간 만료·사망·퇴각 등 원래 종료 조건은 유지한다. 개화 절망은
  강제 이동 후에도 처음 지정한 타일의 범위를 유지한다. 침묵 중 새 스킬을 시작하게 하거나
  시전과 무관한 다른 행동 제한을 해제하지 않는다. 이 정의로 이전의 집중 중단만 막는 설명을 대체한다.
- `공격이어가기`는 대상 사망 후 남은 공격을 다른 대상에게 넘기는 기능의 적용 자격이다.
  여러 직접 타격이 있다는 구조를 나타내는 `다중타격`과 구분한다. 태그만 붙었다고 자동으로
  대상을 변경하지 않으며, `다음.` 유물을 적용했을 때 사망 위치 한 칸 이내 탐색과 시전자 사거리
  제한 없는 연결 규칙이 작동한다. 이미 끝난 공격에 타격을 추가하거나 공격을 처음부터 재시작하지 않는다.

상세 파편 동작과 연결은 [절망의 기사 검토 합의안](SKILL_DECOMPOSITION_REVIEW_DRAFT.ko.md#1-절망의-기사)을 따른다.

| `범위 증폭` | 광선·블랙홀·빛기둥의 효과 범위 확대. 히스테릭에서는 아군 피해 범위도 확대 | 공통 `범위증폭` 정의와 연결. 형태별 한 칸 확장과 피해·회복·흡인 범위 연결의 세부 판정 |
| `스택 획득` | 광선 완주·공격과 회복 동시 성공·시간 경과에 의한 하트 획득량 2배 | 공통 `스택획득` 정의와 연결. 6개를 넘는 획득과 진행 중 시전과의 처리 순서 |
| `쿨다운속도감소` | 하트 자동 획득 주기 단축. 공명 충전이나 피해·회복·흡인 판정 주기는 변경하지 않음 | 단축률·계산식 |
| `보호막효율증가` | 생성하는 보호막량 증가 방향을 태그 목록에 포함 | 현재 파편 자체에는 보호막 생성 효과가 없음. 구체적 연결 지점 미정이며, 방어구의 사랑의 결계나 새 파편 보호막을 자동으로 추가·확정하지 않음 |
| `무아지경` | 스킬 시전 중 군중제어·침묵 등 외부 효과로 시전 행동이나 집중이 중단되지 않음. 집중형에만 한정하지 않음 | 시전 전 사용 불가 조건과 히스테릭 자동 발동 조건을 별도로 유지 |

회복 후 버프 부여는 이름·등급 미정의 범용 유물 효과로 후속 설계한다. 수혜자는 실제로 회복한
해당 아군이며, 공격력·공격 속도·피해량 증가 중 어떤 버프를 줄지는 아직 고르지 않았다.
비히스테릭 파편 회복에 연결하고 히스테릭 공격에는 회복이나 회복 후 버프를 새로 만들지 않는다.
지속 시간·중첩·재부여·자기 회복 인정·회복 0 및 초과 회복 판정도 후속 결정한다.

`스택획득`은 광선 완주 1→2, 공격·회복 동시 성공 보너스 1→2, 자동 획득 1→2에 연결한다.
완주와 보너스를 모두 얻으면 합계 4개다. 6개를 넘는 획득은 6개로 제한해 히스테릭을 한 번
발동하고 초과분을 넘기지 않는 안을 추천하되, 그 처리 순서·초과분 정책은 확정하지 않는다.
`쿨다운속도감소`는 하트 생성 주기에만 연결하고 판정 주기나 공명을 자동으로 가속하지 않는다.

`보호막효율증가`는 사용자 지정 목록에 포함하되 연결 효과가 아직 비어 있다. 기존 방어구
`정의의 결계`는 관련 후보로 검토할 수 있지만, 이번 태그 지정만으로 파편에 보호막을 추가하거나
방어구 결계를 유일한 확정 연결로 삼지는 않는다.

무아지경의 공통 정의는 위 효과 변형 태그 절을 따른다. 긴 호흡·울림통·깊은 쐐기·다음.과
스택한도해제·치명적인군중제어 등은 이번 7개 선택에 자동 추가하지 않는다. 상세 동작·미정 판정은
[증오의 여왕 합의안](SKILL_DECOMPOSITION_REVIEW_DRAFT.ko.md#2-증오의-여왕)에 기록한다.

### 음양 태그와 유물 연결 — 2026-10-18 사용자 합의

음양에는 아래 5개의 연결을 채택한다. 앞서 후보였던 4개와 이미 합의한 `지속시간`을 함께
기록하며, 미정 세부까지 확정하는 뜻은 아니다. 한글 표기는 설계용이며 정식 태그 ID 등록과 구분한다.

| 합의한 태그·효과 | 음양 적용 지점 | 남은 판정 |
| --- | --- | --- |
| `회복량 증가` | 음·양 장판의 회복량 강화. 기존 가하는 회복량 증가 유물과 연결 | 최종 증가율·이름·등급, 초과 회복 집계와 전달된 순환 회복의 재증폭 여부 |
| `회복한 아군에게 버프 부여` | 실제로 회복한 아군에게 유물의 추가 버프 제공. 교집합 밖에서도 회복받으면 적용 가능 | 버프 종류·수치·지속·재부여·중첩, 회복 0·초과 회복·자기 회복·순환 회복의 발동 인정 |
| `범위 증폭` | 음·양 영역을 각각 확대하고 확대된 두 영역으로 교집합을 판정 | 공통 `범위증폭`과 연결. 모양별 확장 판정과 다른 범위 유물과의 합성 |
| `지속시간` | `긴 호흡`으로 음·양 장판 각각의 유지 시간 25% 증가 | 교집합 버프의 독립된 수명 여부는 미정. 장판 연장만으로 별도 버프 수명까지 확정하지 않음 |
| `버프효율증가` | 파편 자체의 교집합 버프 수치 강화 | 원본 버프 종류, 증폭률·계산식·중첩. 버프 종류나 지속 시간을 자동 변경하지 않음 |

- 기초 분류는 음·양 영역의 `소환물·범위·지속영역·지속시간`과 각 회복 효과의 `회복`이다.
  `소환물`에는 설치 장판이 포함된다. 교집합 버프의 세부 분류는 종류 결정 후 붙인다.
- 회복 후 유물의 추가 버프와 파편 자체의 교집합 버프는 별개다. 교집합 밖에서도 실제 회복을
  받으면 유물 버프의 대상이 될 수 있다. 두 버프의 중첩과 발동 세칙은 미정이다.
- `버프효율증가`는 이로운 버프가 제공하는 수치의 강화라는 효과 변형 태그로 추가한다.
  음양의 합의된 적용 지점은 파편 자체의 교집합 버프다. 별도 유물이 만든 버프에 대한 적용은
  자동 확정하지 않으며, 원본 버프의 종류·증폭률·계산식을 정한 뒤 구체화한다.
- `범위 증폭`은 음·양 영역을 각각 확대하고 교집합은 그 결과로 판정한다. 지정 사거리나
  중심 타일을 변경하지 않는다. `울림통`은 원형 지속영역일 때의 추가 호환 후보로 남기며,
  이번 연결 목록만으로 별도 채택하지 않는다.
- `긴 호흡`은 두 장판의 유지 시간에 연결한다. 회복량·회복 주기·순환 회복 전달 비율과
  버프 수치는 변경하지 않는다. 회복 주기 단축은 이번 5개 목록에 포함하지 않는다.
- 용 출현 전용 유물은 별도로 합의한 고유 효과다. 즉사·최대 HP 비례 피해의 세부 태그,
  범위 증폭·피해 증폭·처치 발동 등 다른 유물과의 조합은 아직 미정이다. 이 목록의 회복·버프
  연결로 용 출현 후 회복이나 버프를 새로 발생시키지 않는다.

### 세부 속성과 변경 가능한 항목

공통 태그 안의 차이는 세부 속성으로 함께 기록한다. 태그를 가졌다는 사실과 특정 변형을 허용한다는
판정은 구분한다.

| 공통 태그 | 함께 기록할 차이 |
| --- | --- |
| `피해` | 물리·마법·고정 피해, 참조 능력치 |
| `회복` | 자기·아군 대상, 직접 회복·흡혈 등 회복 방식 |
| `보호막` | 개인 보호량·여러 아군이 공유하는 보호량 |
| `제어` | 둔화·속박·빙결·기절·도발·끌어당김 |
| `스택` | 소유자, 획득·소비 방식, 상한, 전투 또는 런 동안 유지 |
| `소환물` | 설치물·타일 축적·영역의 구분, 소유자, 생성·종료와 발생 효과의 관계 |
| `받는피해증가` | 증가율, 지속 시간, 적용할 피해 출처·유형과 재부여·중첩 방식 |
| `지속영역` | 고정 위치·시전자 추종, 범위와 적용 주기 |

`제어` 전반을 강화하는 유물과 속박에만 반응하는 유물을 같은 체계로 표현한다. `스택`은 공통으로
찾되 획득량·최대량·스택당 효과 중 실제 변경 가능한 항목을 개별 효과에 명시한다. `스택` 태그만으로
모든 획득량 증폭을 허용하거나 서로 다른 자원을 병합하지 않는다.

공격력·주문력·최대 HP 중 어떤 값을 참조하는지, 피해 type과 대상 범위가 아직 미정이면 이 태그
초안으로 확정하지 않는다. 파편·장비의 run-local 진행도와 유물 자체의 전투별 누적 상태 수명도
기존 공통 정책대로 구분한다.

### 대표 파편 적용 예시

아래는 상세 본문에 근거한 기초 태그 적용 예시다. 화살표 앞뒤는 서로 다른 효과이며,
한 행의 태그를 파편의 모든 효과에 일괄 부여하지 않는다.

| 파편 | 태그 적용 예시 |
| --- | --- |
| 나무꾼 | 도끼 공격 `피해·다중타격` |
| 허수아비 | 준비 `기본공격강화` → 강화 공격 처치 후 `능력치변경` |
| 아무 것도 없는 | Hello `기본공격변형` → 변형 평타 `피해·관통` / Goodbye `피해·범위` |
| 루돌타 | 폭격 순서 `다중타격` → 개별 선물 `피해·범위·폭발` |
| 풍운승려 | 물어뜯기 `피해·범위` → 유효 적중 후 `회복` |
| 여왕벌 | 벌집에 저장된 횟수를 조건 충족 시 소비 → `회복` |
| 음/양 | 음의 영역·양의 영역 `소환물·범위·지속영역·지속시간`에서 `회복` → 초과 회복량 일부를 반대 영역에 전달하는 `회복`. 교집합은 회복과 이로운 버프. 5개 유물 연결은 위 합의 절을 따르며, 버프 종류·세부 판정과 용의 세부 태그는 미정 |
| 이름이 없는 태아 | 울음 `집중유지·지속영역` → 아군에게 `기본공격강화·능력치변경(공격 속도)` |
| 래티씨아 | 작은·큰 친구 `소환물` → 공격 `피해` / 큰 친구의 공격에는 `범위` 추가 |
| 죽을 나비의 장례 | 경로를 덮은 나비 `소환물·지연발동` 또는 사망 타일의 나비 축적 `소환물·스택` → 발동 시 `피해·폭발` |
| 녹아내리는 사랑 탱커 | 고기벽 `소환물·방해물` |
| 녹아내리는 사랑 딜러 | 감염의 전파 규칙 `전파`와 periodic 피해 `피해·지속피해` → 기폭 `피해·범위·폭발` |
| 파고드는 천국 | 주시 `스택` → 단계에 따라 `제어(둔화·속박)` |
| 절망의 기사 | 검 `스택` → 기본형의 집중 공격 / 개화형의 `피해·범위` 내려찍기 |

래티씨아 무기는 단일 기본 공격 `피해` → 피격 대상에게 거미줄 `제어(이동 속도 20% 감소)`로
기록한다. 이 둔화는 무기의 고유 효과이며, 파편의 친구 공격에 자동 상속하지 않는다. 지속 시간과
재부여·중첩 판정은 원본 무기 설계의 미정 항목으로 남긴다.

### 발동 사건과 유물 효과 기록

발동 사건은 태그 목록과 별도로 적는다. 초기 검토에 필요한 사건은 다음과 같다.

- 시전, 적중, 처치
- 실제 HP 회복, 실제 HP 손실
- 보호막 흡수, 패링 성공
- 스택 획득·소비

여왕벌의 정확한 일벌 소비 조건처럼 미정인 사건은 원본 문서의 open design으로 남긴다. 피해가
아닌 HP 비용을 실제 피격 사건으로 취급하거나 보호막 흡수를 실제 HP 손실로 바꾸지 않는다.
사건별 인정 source, 횟수와 다단 공격 집계는 개별 효과를 설계하며 명시한다.

유물에는 **적용할 태그 조건·발동 사건·추가 조건·변경하거나 생성할 효과**를 적는다.
`자신을 회복하면 다음 기본 공격을 강화한다`는 설명용 후보는 다음처럼 나눌 수 있다.

| 구분 | 내용 |
| --- | --- |
| 발동 사건 | 실제 HP 회복 발생 |
| 추가 조건 | 회복 대상이 자신 |
| 적용 대상 | 다음 기본 공격 1회 |
| 생성 효과 | `기본공격강화` |
| 후속 결정 | 흡혈·직접 회복 등 인정 source, 발동 횟수, 강화량·중첩·소비 경계 |

이 예시는 특정 회복 source와의 호환성이나 실제 유물 채택을 확정하지 않는다.

### 유물이 만든 효과와 확장

유물이 새로 만든 효과에도 같은 태그 체계를 적용한다.

```text
유물 A: 공격 적중 시 `피해·범위·폭발` 효과 생성
유물 B: `폭발` 효과의 반경 증가
→ 유물 B는 원래 파편의 폭발과 유물 A가 만든 폭발에 모두 적용될 수 있다.
```

새 폭발의 출처는 유물로 유지한다. 원래 공격의 기본 공격·흡혈·감염 부여 성질을 전부 상속하지
않는다. 다른 유물의 조건을 실제로 만족하면 연쇄할 수 있으며, 한 연쇄 경로가 동일 유물 사본의
같은 효과로 돌아오는 순환은 기존 공통 정책대로 막는다.

처형 방식, 피해 축적 방출과 별도 사격 원점처럼 특수한 기능은 해당 유물을 설계할 때 세부 태그를
추가한다. 공통 태그를 확장하더라도 파편 고유의 대상 제한·판정을 임의로 바꾸지 않는다.
침식은 기존 정책대로 유물의 증폭·추가 효과·연쇄 발동 대상에서 제외한다.

## 개별 유물 설계

### 음양 전용 이스터에그 유물 — 이름 미정

> 상태: 2026-10-18 사용자 합의 — 중심 타일 일치 시 용 1회 출현, 대상별 즉사·최대 HP 25% 피해,
> 후속 효과 없는 종료, 최초 경험 전 정체·효과 비공개와 경고 없음. 아군 즉사는 후속 답변으로 확인.
> 이름·희귀도·피해 세부 판정·발견 후 표시 방식은 미정. 설계 기록이며 구현 완료를 뜻하지 않는다.

**음양 파편 전용의 숨겨진 전환 유물이다. 장착 후 한 시전에서 음과 양의 중심 타일을 동일하게
지정하면, 해당 영역에 용이 한 번 나타나 판정하고 스킬이 끝난다.** 부분 교집합이나 다른 시전의
장판끼리 겹친다는 이유로 발동시키지 않는다. 완전히 같은 중심 타일이라는 조건이 기준이다.

| 항목 | 합의 내용 |
| --- | --- |
| 호환 | 음양 파편 전용. 개화형의 존재·설계는 여전히 미정 |
| 역할 | 회복·지원 시전을 용의 일회 출현으로 바꾸는 전환형 |
| 발동 조건 | 전용 유물 장착 + 한 시전의 음·양 중심 타일 동일 |
| 효과 범위 | 동일 중심에 지정한 해당 영역. 전장 전체로 확대하지 않음 |
| 아군 | 영역 안 아군 즉사. 시전자도 영역 안에 있으면 같은 판정 |
| 침식체 | 영역 안 침식체 즉사. 환상체·보스로 분류되는 대상은 아래 판정 |
| 환상체·보스 | 영역 안 해당 대상에게 최대 HP의 25% 피해. 현재 HP의 25%가 아님 |
| 종료 | 용 한 번 출현·판정 후 스킬 종료. 회복·순환 회복·교집합 버프·지속 장판 등의 후속 효과 없음 |
| 조건 불충족 | 원래의 독립 영역 회복·순환 회복·교집합 회복과 버프 구조 유지 |
| 선택의 비용 | 유물 슬롯과 해당 시전의 지속 지원 포기, 범위 안 아군 즉사 |

**이스터에그 공개 방식**

- 플레이어가 직접 발동해 보기 전까지 어떤 유물인지와 숨겨진 효과를 알 수 없게 한다.
  유물 설명·도움말에서 용의 출현이나 중심 타일 일치 조건을 미리 알려 주지 않는다.
- 중심 타일을 일치시켰을 때 별도 경고, 확인창, 위험 범위로 바뀌는 조준 표시, 피격 아군 강조를
  추가하지 않는다. 앞서 제안한 사전 위험 예고는 채택하지 않는다.
- 최초 경험 후 이름·설명·도감 등이 공개되는지와 방식은 미정이다. 발견 후 자동 공개 기능을
  이번 합의만으로 추가하지 않는다. 이 절은 내부 설계 기록이며 플레이어용 공개 설명이 아니다.

**기존 파편과 침식의 관계**

원래의 회복·지원 파편은 그대로 두고, 이 전용 유물과 동일 중심 시전 조건이 함께 충족될 때만
용으로 전환한다. 기존 조우·침식 설계의 용을 일반 보상으로 바로 옮기지 않는 방향에 대해,
사용자가 새로 선택한 숨겨진 전용 유물 예외다. 기존 에고 침식의 발동 조건·전장 범위·직원 대가와
합치지 않는다. 최대 HP 25%라는 값이 같아도 에고 침식의 감면·보호막·무적·페이즈·처치 연쇄
규칙을 이 유물에 자동 이식하지 않는다. 해당 세부는 후속 결정한다.

**효과 흐름과 15개 축 검토**

전용 유물 장착 → 두 위치 지정 → 중심 타일 일치 여부 → 일치 시 용 1회 출현 → 영역 내 대상별
즉사 또는 최대 HP 25% 피해 → 후속 효과 없이 종료. 불일치 시 기존 회복·지원 흐름을 따른다.

| 분해 축 | 이번 유물의 적용 |
| --- | --- |
| 1. 사용·조작 | 기존 두 위치 지정에서 같은 중심 타일 선택. 별도 경고·확인 입력 없음 |
| 2. 대상·선정 | 해당 영역 안 아군·침식체·환상체·보스. 세부 대상 자격·판정 시점은 미정 |
| 3. 공간 | 한 시전의 중심 타일 동일 조건. 범위의 정확한 모양·크기는 원본과 함께 후속 결정 |
| 4. 전달·매개 | 용 출현과 영역 판정. 별도 전장 이동 경로나 유닛 AI는 추가하지 않음 |
| 5. 시간 | 출현·판정 후 종료. 연출 시간·판정 시점 미정 |
| 6. 반복·발생 | 조건을 만족한 시전에 용 1회. 지속 반복 즉사 장판이 아님 |
| 7. 효과 종류 | 아군·침식체 즉사와 환상체·보스 최대 HP 비례 피해. 정식 태그는 후속 결정 |
| 8. 효과량·참조 | 환상체·보스 최대 HP 25%. 방어·보호막·무적 등 계산 세부 미정 |
| 9. 집계·분배 | 대상별 판정. 원래의 순환 회복량을 용 피해로 환산하지 않음 |
| 10. 자원·축적 | 원본 스킬의 공명 시전 조건. 별도 용 스택·추가 자원은 합의하지 않음 |
| 11. 비용·위험 | 슬롯·지속 지원 포기·아군 즉사. 추가 횟수 제한은 정하지 않음 |
| 12. 조건·분기 | 전용 유물과 동일 중심이면 용, 그 외에는 원본 회복·지원 |
| 13. 행동 병행·제약 | 원본 시전과 연출 중 행동·중단의 세부는 미정 |
| 14. 종료·존속 | 용 1회 후 스킬 종료. 후속 회복·버프·장판 없음 |
| 15. 출처·소유·귀속 | 장착자의 전용 유물에 의한 파편 전환. 처치·다른 유물 연쇄 세부는 미정 |

`긴 호흡`으로 정상 장판의 지속 시간을 늘리는 것과 용의 일회 판정은 구분한다. 이 유물의 용에는
지속 회복 영역이 남지 않으므로 용을 반복하거나 후속 장판을 생성하지 않는다. 범위 증폭의 적용,
피해 증폭·처치 발동 등 다른 유물과의 조합은 아직 확정하지 않는다. 이름·희귀도·획득처,
발견 전후 표시, 범위·대상 자격·출현 지연·중단, 보호막·감면·무적·생존 보장·보스 페이즈,
처치 귀속·사망 효과와 연쇄의 세부는 미정으로 남긴다.

### 무기 수치 강화 유물 — 9종 초안

> 상태: 2026-09-08 사용자 요청에 따른 AI 콘텐츠 제안. 무기 유물은 우선 단순 수치 강화까지
> 설계한다는 방향을 반영한다. 아래 이름·등급별 수치·중복 및 적용 세부는 제안이며, 사용자 확정이나
> runtime·live data 반영, 전투 밸런스 검증을 뜻하지 않는다.

공격력·공격 속도·기본 공격 피해의 세 계열에 일반·희귀·특급을 하나씩 두어 총 9종으로 시작한다.
모두 범용·강화형이며, 착용자에게 상시 적용하는 효과 하나를 가진다. 별도 발동 조건·자원·패널티를
붙이지 않고 공용 슬롯 하나를 사용한다. 등급별 항목은 별개의 유물이며, 낮은 등급의 유물을 강화하거나
합쳐 높은 등급으로 만드는 단계가 아니다.

#### 등급별 이름과 수치

| 계열 | 희귀도 | 이름 — 가칭 | 효과 — 초기 비교 수치 |
| --- | --- | --- | --- |
| 공격력 | 일반 | 무쇠 인장 | 착용자의 공격력 `+10%` |
| 공격력 | 희귀 | 거인의 인장 | 착용자의 공격력 `+20%` |
| 공격력 | 특급 | 패왕의 인장 | 착용자의 공격력 `+35%` |
| 공격 속도 | 일반 | 작은 태엽 | 착용자의 기본 공격 속도 `+10` |
| 공격 속도 | 희귀 | 정밀 태엽 | 착용자의 기본 공격 속도 `+20` |
| 공격 속도 | 특급 | 황금 태엽 | 착용자의 기본 공격 속도 `+35` |
| 기본 공격 피해 | 일반 | 돌격 훈장 | 착용자의 직접 기본 공격 피해 `+15%` |
| 기본 공격 피해 | 희귀 | 격파 훈장 | 착용자의 직접 기본 공격 피해 `+30%` |
| 기본 공격 피해 | 특급 | 섬멸 훈장 | 착용자의 직접 기본 공격 피해 `+50%` |

공격력은 그 능력치를 참조하는 파편 등에도 기여하므로 폭넓은 성장 선택으로 둔다. 기본 공격 피해는
적용 범위가 좁은 만큼 같은 등급에서 더 높은 증가율을 준다. 공격 속도는 공격 횟수와 적중 효과의
기회를 함께 늘릴 수 있어 기본 공격 피해보다 낮은 숫자로 시작한다. 이 세 효과의 실제 기여가
같다는 주장은 아니며, 효과 이름이 단순하다는 이유로 특급에 추가 기믹을 붙이지 않는다.

같은 계열에서는 높은 등급이 더 큰 수치를 제공한다. 낮은 등급 사본은 높은 등급이 부족한 동안
다른 직원에게 이전하거나 남은 슬롯에 함께 사용할 수 있다. 이 관계를 모든 유물의 성능 서열이나
획득 순서로 확대하지 않으며, 등장 빈도·후보 구성·공급량은 기존 보류 상태를 유지한다.

#### 세 계열의 적용 범위

| 계열 | 적용과 계산 의도 | 직접 변경하지 않는 항목 |
| --- | --- | --- |
| 공격력 | 직원·무기·일반 강화 등으로 구성한 착용자의 공격력을 높인다. 그 공격력을 참조하는 기본 공격·파편·장비 효과에 원래 참조 규칙대로 반영한다. 기존 `능력치변경` 태그가 있는 효과를 미리 보유할 필요는 없다. | 별도 능력치인 주문력, 공격력과 무관한 고정 효과량. Magic 피해라는 이유만으로 적용·제외를 정하지 않는다. |
| 공격 속도 | 중립 `100`인 기본 공격 속도에 수치를 가산한다. `+20`이면 `100 → 120`이다. 기본 행동이 회복인 무기는 그 기본 회복 주기에도 적용하는 안으로 둔다. | 파편의 준비·집중 시간, 다중타격 간격·횟수, 지속 피해 tick, 소환물 행동 주기. 별도 효과가 명시한 상속 관계는 원본 검토가 필요하다. |
| 기본 공격 피해 | 착용자의 직접 기본 공격으로 분류된 피해를 증폭한다. 무기 자체의 단일·범위·직선 공격과 기본 공격 출처를 유지하는 파편의 공격 교체·강화도 포함한다. 각 피해에 한 번 적용한다. | 독립 스킬 피해, 지속 피해, 반사, 별도 장비·유물 proc와 소환물 공격, 회복량. 원래 공격의 피해 type·대상·적중 횟수와 출처를 유지한다. |

- 기본 공격 속도는 [설계 당시 룰북의 시작 직원 선발](../archive/game_rulebook_legacy_2026-10-04.md#시작-직원-선발)의 중립 `100`과
  `ceil(무기 기본 주기 × 100 / 기본 공격 속도)` 표기를 따른다. 기본 주기 `1,000ms`에 속도 `120`이면
  계산 주기는 `834ms`다. `+20`을 현재 속도의 `1.2배`나 주기 `20%` 감소로 해석하지 않는다.
- 공격력 증가가 참조 효과에 전달되는 시점은 각 효과의 snapshot 규칙을 따른다. 이미 발사·예약된
  효과의 고정값을 소급해 바꾸는 공통 규칙은 추가하지 않는다. 기존 공격력 버프들과의 정확한 산술
  계층·반올림은 구현 검토에 남긴다.
- 기본 공격 피해 계열은 Hello의 변형 평타나 허수아비의 강화 평타에 적용하지만, Goodbye의
  독립 스킬 피해에 적용하지 않는다. 연출에 탄환이나 포탈이 여러 개 보여도 새 피해 판정을 만들지 않는다.
- 파편 침식형에는 세 계열의 증폭·추가 효과를 적용하지 않는다. 원래 효과의 요구 조건이 사라지면
  장착·슬롯은 유지하고 해당 효과만 비활성화하는 공통 정책을 따른다. 순수 회복 무기의 기본 행동에는
  기본 공격 피해 보너스가 적용되지 않는다.
- 기존 회복량 증가 유물은 별도 설계를 유지한다. 이번 9종에 주문력·방어·회복 계열의 등급별 항목이나
  침식된 변형 수치를 추가하지 않는다.

#### 중복·합산과 수명 — 제안

- 9종 모두 같은 직원에게 **동일 유물의 별도 사본 중복 장착을 허용**하는 안이다. 각 사본은 슬롯
  하나를 차지한다. 서로 다른 등급과 계열도 함께 장착할 수 있으며 이 9종 사이에 비호환 조건은 없다.
- 인장끼리는 같은 공격력 기준에 증가율을 합산한다. 다른 modifier가 없는 공격력 `100`에 무쇠 인장과
  거인의 인장을 장착하면 `130`이다. 사본마다 결과에 `1.1`, `1.2`를 연달아 곱하지 않는다.
- 태엽끼리는 가산량을 합산한다. 속도 `100`에 작은 태엽과 정밀 태엽이면 `130`이다.
- 훈장끼리는 같은 기본 공격 피해 증폭을 합산한다. 돌격 훈장과 격파 훈장이면 `+45%`다. 같은 종류의
  다른 기본 공격 피해 증폭도 기존 공통 합산 정책을 따르며 별도 피해 증폭 상한은 신설하지 않는다.
- 서로 다른 계열의 숫자를 합쳐 하나의 피해 증가율로 표시하지 않는다. 공격력·공격 주기·기본 공격
  피해가 각자의 계산에 참여한다. 이 문서의 합산 제안은 다른 모든 능력치·회복 산술의 확정이 아니다.
- 세 계열 모두 누적 스택·발동 횟수를 생성하지 않는다. 전투 구성과 재배치에서 장착 효과를 다시
  계산하며, 재배치마다 같은 modifier를 추가로 쌓지 않는다. 보유·장착·사망 회수·체크포인트는
  공통 정책을 따르고 별도 누적 상태를 저장하지 않는다.

#### 15개 축의 공통 검토

검토 대상은 [파편·장비 설계 문서](abnormality_skill_fragments_design_notes.md)의 무기 23개 항목에
기록된 기본 행동과 기존 공격력 참조 효과다. 계열별로 아래 표를 재사용하며,
각 등급은 동일한 효과에서 수치만 다르다. 원본의 미정 사거리·주기·대공·타격 분할은 그대로 둔다.

| 분해 축 | 원본과 이번 변경 |
| --- | --- |
| 1. 사용·조작 방식 | 원래 기본 행동·시전 입력 유지. 유물 자체는 상시 수치 modifier다. |
| 2. 대상·선정 | 변경 없음. 회복 기본 행동과 적대적 공격의 대상 구분도 유지한다. |
| 3. 공간 구조 | 사거리·범위·발생 위치 변경 없음. |
| 4. 전달·매개 | 투사체·즉시·타일 공격·회복 등 기존 전달 방식 유지. |
| 5. 시간 구조 | 태엽만 기본 행동의 속도 수치를 변경. 스킬·지속 피해 등 다른 시간은 직접 변경하지 않음. |
| 6. 반복·발생 구조 | 한 행동 안의 타격 수·순서·재타격은 변경 없음. 속도가 오르면 같은 시간에 시작하는 기본 행동 수는 달라질 수 있음. |
| 7. 효과의 종류 | 인장·태엽은 `능력치변경`, 훈장은 `기본공격강화`. 새로운 공격·회복을 생성하지 않음. |
| 8. 효과량·참조 기준 | 인장은 공격력, 태엽은 기본 공격 속도 가산량, 훈장은 직접 기본 공격 피해 증폭을 변경. |
| 9. 집계·분배·공유 | 원본 유지. 다수 대상 공격·치료의 총량을 임의로 나누거나 남는 양을 한 대상에게 몰지 않음. |
| 10. 자원·축적 | 새 자원·스택 없음. 피해·처치·공격 빈도 변화로 기존 자원의 획득이 간접적으로 달라질 수 있음. |
| 11. 비용·위험 | 공용 슬롯 1개. 추가 HP·공명 비용이나 패널티 없음. |
| 12. 조건·분기·연계 | 새 발동 사건 없음. 피해·회복·처치 결과를 읽는 원래 효과는 기존 조건대로 작동. |
| 13. 행동 병행·제약 | 저지·배치·변신·집중 중 행동 제한과 태세 규칙 변경 없음. |
| 14. 종료·존속 | 원본 공격·상태 수명 유지. 유물 modifier는 장착·활성 상태를 따르고 별도 잔류·누적 없음. |
| 15. 출처·소유·귀속 | 강화 원인은 해당 유물 사본, 공격·피해·회복의 주체는 원래 source로 유지. 새 proc나 공격 identity 없음. |

설계 의도는 기본 성능 보완과 강점 확대다. 파편과 평타를 함께 쓰면 인장, 기본 공격 중심이면 훈장,
공격 빈도·적중 효과나 기본 치료 주기가 중요하면 태엽을 검토한다. 남는 핵심 선택은 직원별 세 슬롯을
이 수치 유물과 파편 변형·연결 유물 사이에 어떻게 배분할지다.

#### 비교 기준과 후속 검증

- 일반 `10% / +10 / 15%`, 희귀 `20% / +20 / 30%`, 특급 `35% / +35 / 50%`를 초기 비교 기준으로 쓴다.
  같은 슬롯을 쓰는 조건부 유물이 조건을 잘 만족할 때 이 수치 유물보다 선택할 이유가 있는지 확인한다.
  기존 `깊은 쐐기` 등의 미정 수치를 이번 표에 맞춰 임의로 확정하지 않는다.
- 특급 세 종류를 하나씩 장착하면 공격력 `+35%`, 속도 `+35`, 기본 공격 피해 `+50%`다. 속도 기준
  `100`, 공격력에 전부 비례하는 기본 공격, 방어·다른 modifier·공격 공백·반올림을 제외한 단순 모델에서는
  기본 공격 DPS가 `1.35 × 1.35 × 1.50 = 2.73375배`다. 실제 전투·파편 피해의 보장 배율이 아니다.
- 섬멸 훈장 3개는 직접 기본 공격 피해 `+150%`이며 `1.5³`로 계산하지 않는다. 상시 수치 유물 세 개가
  변형·연결 유물 조합의 자리를 항상 차지하는지와 직원 여러 명에게 나눠 장착하는 경우를 함께 검토한다.
- 느린 단일 무기, 빠른 직선 무기, 광역 무기, 기본 공격 교체 파편, 기본 치료 무기에서 실제 기여를
  비교한다. 공속에 따른 공명·상태 부여·흡혈의 간접 이득은 각 원본 규칙을 기준으로 확인한다.
- 최종 이름·수치·중복 허용, 기본 회복의 공속 적용, 기존 능력치 modifier 합성과 정식 태그·ID는
  후속 확정 대상이다. 획득처·확률·분쇄량·침식 변형은 기존 보류 상태를 유지한다.

#### 타격별 증가와 수명

이번 타격을 포함해 같은 시전에서 같은 대상에게 적중한 횟수를 `n`이라고 하면 다음과 같다.

```text
깊은 쐐기가 해당 타격에 제공하는 피해 증가율 = min(n × 2%, 20%)
```

합의한 수치를 적용하고 다른 피해 증폭을 생략한 예시:

| 같은 시전에서 같은 대상에게 적중한 순서 | 깊은 쐐기의 피해 증가율 | 해당 타격의 피해 |
| --- | --- | --- |
| 1타 | +2% | 원래 1타 피해 × 102% |
| 2타 | +4% | 원래 2타 피해 × 104% |
| 3타 | +6% | 원래 3타 피해 × 106% |
| 4타 | +8% | 원래 4타 피해 × 108% |
| 10타 | +20% | 원래 10타 피해 × 120% |
| 11타 이후 | +20% | 해당 타격의 원래 피해 × 120% |

- 첫 타격에서 이미 `n = 1`의 보너스를 적용한다. 증가율을 더하며, 이전 타격 피해에 배율을 계속
  곱하는 복리 방식이나 앞선 타격 피해를 소급 수정하는 방식으로 계산하지 않는다.
- 10번째 유효 타격에서 상한에 도달하며 이후 타격에도 `+20%`를 유지한다. 적용 횟수를 10회로
  제한하거나 이후 보너스를 끊는 규칙이 아니다. 상한은 대상별로 독립이며 다른 적과 공유하지 않는다.
- 마지막 타격을 기다리지 않고 각 타격이 자기 순번의 보너스를 받는다. 원래 마지막 타격이 강한
  나무꾼은 같은 비율이라도 마지막 내려찍기에서 큰 추가 피해를 얻는다.
- 횟수는 예정된 공격 순서 번호가 아니라 해당 대상에게 실제로 적중한 유효 타격 수다. 빗나간
  타격과 실행되지 않은 단계는 세지 않는다.
- 대상 A에 두 번 적중한 뒤 대상 B에 처음 적중하면 B에는 1회분 보너스를 적용한다. A의 횟수를
  B에게 넘기지 않는다. 이 예시는 원본 스킬에 새 대상 재지정 기능을 추가하지 않는다.
- 광역 타격이 여러 적을 맞히면 각 대상의 횟수를 따로 계산한다. 한 번의 광역 타격으로 처음 맞은
  적 세 명은 각각 1회분 보너스를 받는다.
- 새 스킬 시전은 대상이 같아도 다시 0에서 시작한다. 각 시전의 공격 처리가 끝나면 그 시전의
  누적을 폐기하며, 이후 시전·다음 전투나 다른 직원에게 이월하지 않는다.
- 스킬의 공격 속도·타격 수·대상 선택·중단·재지정 규칙은 원본 설계를 따른다. 유물이 추가 타격이나
  마지막 단계의 실행을 보장하지 않는다.

#### 출처와 다른 효과의 조합

- 특정 환상체·파편·무기 ID를 요구하지 않는다. 나무꾼 외에도 요구 태그와 직접 타격 구조를 갖춘
  효과에 사용할 수 있다.
- 기존 타격의 피해를 증폭하며 새로운 공격이나 추가 피해 packet을 생성하지 않는다. 강화된 피해는
  원래 스킬의 출처와 피해 type을 유지한다.
- 해당 스킬 자체의 타격 단계를 센다. 지속 피해 tick, 별도 반사·장비 proc와 다른 유물이 생성한
  추가 피해는 원래 스킬의 적중 횟수에 자동 포함하지 않는다.
- 다른 동일 종류 피해 증폭과의 합산은 공통 유물 정책을 따른다. 태그만으로 무적·피해 차단이나
  Boss phase gate를 우회하지 않는다.
- 강화된 타격의 처치·흡혈·회복 판정은 기존 source 조건을 따른다. `빌린 심장`은 eligible 타격의
  실제 HP 감소량을 읽고, `양철 몸`은 eligible 직접 스킬 처치를 읽는다. 원본 장비의 회복 상한이나
  한 시전의 여러 처치 집계는 이 유물 때문에 새로 확정하지 않는다.
- 침식에는 적용하지 않는다. 유물의 중복·비호환과 연쇄 제한은 공통 정책 및 후속 개별 설계를 따른다.

#### 대표 운용

- **나무꾼:** 같은 강적에게 3타를 이어가며 각 타격을 강화한다. 앞선 두 타격에도 보너스가 있고,
  원래 위력이 집중된 마지막 일격은 더 큰 추가 피해를 얻는다. 전용 장비 없이 다른 호환 Sword와
  함께 사용해도 유물의 기능은 완결된다.
- **절망의 기사:** 기본형 일반 연속기·기본형 절망 엑시큐션·개화형 일반의 큰 검과 작은 검에
  `다중타격` 태그를 적용한다. 같은 공격 순서의 직접 타격을 대상별로 세며 개화형 절망의 장판
  주기 피해에는 적용하지 않는다. 강화된 기본 공격은 원래 기본 공격 출처를 유지한다.
  `20%` 상한은 깊은 쐐기의 보너스에만 적용하며 검 수·타격 수·상처나 엑시큐션 자체의
  후속 피해 증가율을 제한하지 않는다.
- **루돌타:** 같은 강적이 여러 선물 폭발을 맞으면 그 대상에 대한 후속 폭격이 최대 `+20%`까지 강해진다.
  새로운 적 무리를 번갈아 공격하면 대상마다 낮은 횟수에서 시작하므로 같은 보너스를 공유하지 않는다.
- 일반 공격력 증가 유물은 기본 공격과 해당 능력치를 참조하는 다른 피해도 높일 수 있다.
  깊은 쐐기는 같은 시전·같은 대상의 다중타격에 효과를 집중한다.

#### 미정 사항

- `깊은 쐐기`와 대체 이름 `때린 곳 또 때리기` 중 최종 표시 이름. 타격당 `2%p`·최대 `20%`는
  합의한 설계 수치이며 실제 전투 밸런스 검증은 후속 작업이다.
- 무적·완전 차단·피해 0과 보호막에만 피해를 준 타격을 유효 적중으로 인정할지.
- 같은 시각에 적중하는 복수 타격, 한 타격 내부의 복수 피해 segment와 추가 타격 변형의 집계 경계.
- 동일 유물 중복 장착 가능 여부, 효과 전환 유물과의 비호환 조건 및 최종 피해 산술·반올림.
- 시전 중단·시전자 이탈 뒤 이미 release된 공격의 누적 보존·정리와 checkpoint/resync의 세부 구현.
- 획득처·빈도·분쇄 보상과 정식 태그·유물 ID. 희귀도는 희귀로 확정했다.

### 붉은 실타래 — 가칭

> 상태: 2026-09-07 사용자 대화에서 전용 유물로 유지하기로 합의 /
> 래티씨아 기본·개화 파편 대상 / 기존 연결·연쇄 공격 구조 유지 /
> 최종 이름·희귀도·수치·세부 판정 미정 / 현재 runtime·live data 구현은 포함하지 않음.

**가까운 작은·큰 마녀의 친구를 거미줄로 연결한다. 적이 친구 하나를 발동시키거나 연결된 거미줄을
가로지르면, 연결된 친구들이 연쇄 공격한다.**

| 항목 | 내용 |
| --- | --- |
| 구분 | 래티씨아 파편 전용 유물 |
| 적용 대상 | 기본 파편의 작은·큰 친구와 개화 파편이 즉시 배치하는 큰 친구 |
| 희귀도 | 미정 |
| 주된 역할 | 연결형 — 배치한 친구들을 연결해 감지와 공격을 연동 |
| 연결 시점 | 친구를 배치하거나 진화시킬 때 연결 거리 안의 친구들과 연결 |
| 발동 | 적이 연결된 친구를 발동시키거나 거미줄을 가로지름 |
| 공격 순서 | 작은 친구들이 정해진 순서로 공격하고, 큰 친구가 뒤이어 강한 광역 공격 |
| 소비 | 발동한 친구는 자기 공격을 마친 뒤 사라짐. 연결망 전체 소비 여부는 미정 |

작은·큰 친구의 배치와 진화, 기본·개화형 차이를 함께 활용하므로 전용으로 둔다. 다른 파편의
고기벽·회복 장판·타일 스택을 연결 대상으로 자동 확장하지 않는다. 파편은 유물이 없어도 각 친구의
독립 발동으로 완결된다.

기존 세부 구조는 [래티씨아 파편 설계](abnormality_skill_fragments_design_notes.md#래티씨아)를 따른다.
연결 거리·최대 연결 수, 전체 연결망 또는 유효 대상이 있는 친구만 소비할지, 다른 직원이 배치한
친구와의 연결 여부, 세부 공격 순서·피해 증가·상한, 중복·비호환과 획득 방식은 후속 설계한다.

### 소환물 범용 유물 — 이름 미정

> 상태: 2026-09-07 사용자 대화에서 소환물 피해 후 대상의 받는 피해 증가 구조와 지속 시간
> 5초 합의 / 이름·증가율·희귀도·세부 판정 미정 / 문서 설계이며 현재 미구현.

**착용자의 소환물로 피해를 입은 대상은 5초간 받는 피해가 증가한다.**

| 항목 | 내용 |
| --- | --- |
| 구분 | 태그 기반 범용 유물 |
| 이름·희귀도 | 미정 |
| 요구 조건 | `소환물` 태그의 효과에서 발생한 `피해` |
| 발동 사건 | 착용자 소유의 해당 효과로 대상이 피해를 입음 |
| 상태 대상 | 그 피해를 입은 유닛 |
| 생성 효과 | 유물 출처의 `받는피해증가` 상태 |
| 지속 시간 | 5초 |
| 증가율 | 미정 |

- 증가 상태는 피해를 입은 대상에게 부여한다. 소환물이나 유물 착용자가 피격됐을 때 자신에게
  받는 피해 증가를 부여하는 효과로 해석하지 않는다.
- 대상에게 부여하는 받는 피해 증가이므로 후속 피해를 소환물 공격으로만 한정하지 않는다.
  적용할 피해 출처·유형의 세부 범위는 후속 판정에서 정하고, 침식은 공통 정책대로 제외한다.
- 친구가 공격을 마치고 사라져도 대상에게 부여한 상태는 남은 5초 동안 유지된다.
- 고기벽과 회복 장판처럼 피해를 주지 않는 소환물은 자체 효과만으로 이 유물을 발동시키지 않는다.
  태그가 있다는 이유로 새 공격이나 피해를 추가하지 않는다.
- 래티씨아 친구나 죽나장의 나비 폭발로 먼저 피해를 준 뒤, 다른 공격을 이어가는 조합에 사용할 수
  있다. `붉은 실타래`의 전용 연결 기능과는 별도 유물이다.

후속 결정: 증가율·이름·희귀도, 재부여 시 지속 시간 갱신과 중첩 여부, 최초 발동 피해의 증폭 적용
순서, 피해 0·보호막 피해의 발동 인정, 피해 출처·유형, 중복 장착·비호환과 획득 방식.

### 깨진 균형 — 강력한 군중제어 범용 유물·이름 가칭

> 상태: 2026-10-18 사용자 요청으로 범용 유물 추가. 강력한 군중제어 시 받는 피해 증가와 5초 지속은
> 합의한 설계 방향이다. `깨진 균형`은 AI 추천 이름이며 이름·증가율·희귀도·상세 판정은 미확정이다.

**착용자가 적에게 강력한 군중제어를 가하면, 그 적이 5초간 받는 피해가 증가한다.**

| 항목 | 내용 |
| --- | --- |
| 구분 | 태그 기반 범용 유물, 제어와 후속 피해를 연결 |
| 이름 후보 | 추천 `깨진 균형`. 대안 `무너진 자세`, `빈틈의 낙인` |
| 적용 태그 | `치명적인군중제어`. 원래 제어 효과의 종류·출처와 함께 확인 |
| 발동 사건 | 착용자 출처의 강력한 군중제어가 대상에게 적용됨 |
| 대표 제어 | 기절·빙결. 다른 제어의 포함 여부는 후속 정의 |
| 생성 효과 | 해당 적에게 유물 출처의 `받는피해증가` 상태 부여 |
| 지속 시간 | 5초 |
| 피해 증가율·희귀도 | 미정 |
| 대표 조합 | 절망의 기사 첫 찌르기·데스비오의 기절, 개화 일반 큰 검의 2초 기절 |

큰 검의 기절이 2초여도 유물이 부여하는 피해 증가의 수명은 5초다. 제어 효과와 피해 증가 효과는
서로 다른 상태이며, 제어가 끝났다고 피해 증가도 함께 끝나는 것으로 처리하지 않는다. 절망의 기사
상처와도 별도 출처 효과다. 상처 스택을 새로 부여하거나 기존 상처의 5% 수치를 이 유물의 증가율로
자동 채택하지 않는다.

**세부 판정 제안:** 제어가 실제로 부착된 경우에 발동하며, 면역으로 부착되지 않은 경우에는 발동하지
않는 안을 추천한다. 같은 유물 출처의 재발동은 증가율을 중첩하지 않고 지속 시간만 5초로 갱신하는
안을 추천한다. 이 두 세칙은 사용자 확정 전 제안이다.

후속 결정: 최종 이름·증가율·희귀도, 강력한 군중제어의 정확한 목록, 면역·재부여 처리,
제어를 가하는 타격 자체와 증폭의 적용 순서, 여러 출처 및 상처와의 합산·중복 장착 규칙.
침식 제외와 유물의 순환 재발동 금지는 공통 정책을 따른다.

### 다음. — 희귀 범용 유물

> 상태: 2026-10-18 사용자와 대상 사망 후 남은 공격 연결 규칙을 논의한 뒤 이름·희귀 등급·시전자
> 사거리 제한 없음에 합의했다. 중복 장착 등 아직 채택하지 않은 추천안은 아래 미정 항목에 남긴다.
> 설계 기록이며 데이터·엔진 구현 완료를 뜻하지 않는다.

**현재 공격 대상이 사망하면, 사망한 위치에서 한 칸 이내의 가장 가까운 적에게 남은 공격을 이어간다.
시전자와 새 대상 사이의 사거리는 제한하지 않는다.**

| 항목 | 합의 내용 |
| --- | --- |
| 이름 | `다음.` — 마침표 포함 |
| 희귀도 | 희귀 |
| 호환 방향 | 현재 적을 대상으로 진행 중이며 남은 단계·타격이 있는 연속 공격 |
| 적용 태그 | `공격이어가기` — 대상 사망 후 남은 공격을 넘길 수 있는 효과에 부여 |
| 발동 조건 | 현재 대상의 사망. 착용자 자신뿐 아니라 아군이 처치한 경우에도 발동 |
| 탐색 중심·거리 | 사망한 대상의 사망 당시 위치, 그 위치에서 한 칸 이내 |
| 선택 | 해당 범위의 가장 가까운 적 |
| 시전자 사거리 | 제한 없음. 원래 공격 사거리 밖의 적에게도 연결 가능 |
| 이어갈 내용 | 현재 공격의 남은 단계·타격만 수행. 공격 순서를 처음부터 다시 시작하지 않음 |
| 반복 연결 | 새 대상도 사망하면 그 대상의 사망 위치를 기준으로 같은 규칙 적용 |
| 종료 | 연결할 적이 없거나 남은 공격이 없으면 종료 |
| 대상별 상태 | 상처는 새 대상에게 이전하지 않으며, 깊은 쐐기의 누적은 새 대상의 적중 기록을 기준으로 계산 |

한 칸은 매번 사망한 적을 기준으로 하는 다음 대상 탐색 거리다. 시전자 중심의 한 칸 제한이나
최초 대상 위치를 기준으로 한 전체 연결 거리 제한이 아니다. 따라서 남은 공격이 있는 동안 적들이
이어져 있으면 시전자에게서 점점 멀어지는 공격도 가능하다. 연결 자체가 새 타격이나 공격 기회를
추가하지는 않는다.

절망의 기사 기본형에서 아탕호로 대상이 사망했다면 새 대상에게 에스토카다부터 이어가는 것이
대표 예다. 엑시큐션 도중 대상이 사망했다면 남은 찌르기를 연결한다. 유물 미적용 시에는 기존의
대상 사망에 따른 공격 종료 규칙을 유지한다. 고정 타일을 공격하는 개화형의 공격 지점을 대상 사망에
따라 이동시키는 효과로 자동 확대하지 않는다.

**연결 세칙 제안:** 같은 시전·공격의 진행 상태와 이미 지불한 비용을 유지하고, 이후 단계의 비용은
원래 규칙대로 지불하는 안을 추천한다. 동거리 후보는 공통 대상 선택 순서로 정하고, 동일 유물 중복
장착으로 연결 효과가 추가 발생하지 않게 하는 안을 추천한다. 이 세부안은 아직 사용자 확정 전이다.

후속 결정: 정식 태그·유물 ID, 구체적인 호환 공격 목록, 한 칸의 거리 판정과 동거리 선택,
시전자 사거리 외의 대상 자격·가시성·지형 조건, 단계 도중 사망 시 처리 시점과 비용 세칙,
중복 장착·비호환. 이름·등급과 시전자 사거리 무제한은 확정 사항이다.

### 가하는 회복량 증가 — 이름 미정

> 상태: 2026-09-07 사용자 대화에서 범용 유물 추가와 회복량 증가 `25~40%` 범위 합의 /
> 최종 증가율·이름·희귀도·세부 판정 미정 / 문서 설계이며 현재 미구현.

**착용자가 가하는 회복량이 25~40% 증가한다.**

| 항목 | 내용 |
| --- | --- |
| 구분·역할 | 범용 / 강화형 |
| 적용 대상 | 착용자에게 귀속되는 `회복` 효과의 회복량 |
| 변경 | 가하는 회복량 `+25~40%`. 범위 안의 최종 값은 후속 수치 설계에서 결정 |
| 대표 조합 | 여왕벌의 일벌 회복·기본 치료, 음/양의 회복 장판, 증오의 여왕의 아군 회복 |
| 이름·희귀도 | 미정 |

- 받는 쪽의 회복 배율이 아니라 회복을 제공하는 착용자의 회복량을 늘린다. 여왕벌에서는 벌집을
  부여하는 시전자에게 장착하여 그 시전자에게 귀속되는 일벌 회복을 강화하는 조합이다.
- 다른 modifier를 생략하면 기본 회복량 `100`은 `125~140`이 된다. 최대 HP 비례 회복도 계산된
  회복량에 배율을 적용하며, 최대 HP 비율에 `25~40%p`를 더하는 방식이 아니다.
- 최대 HP를 넘는 회복과 실제 회복량을 읽는 후속 효과는 기존 판정을 따른다. 보호막·최대 HP
  증가량을 직접 늘리는 효과는 아니다.
- `25~40%`는 최종 수치를 정할 범위다. 유물 강화 단계나 무작위 옵션 지급 방식을 확정하지 않는다.
- 기존 `마법소녀의 브로치`의 아군 회복량 `25%` 증가도 유지한다. 함께 사용할 때의 회복 modifier
  합성은 후속 결정이며, 피해 증폭의 합산 규칙을 그대로 적용한다고 단정하지 않는다.

후속 결정: 최종 증가율·이름·희귀도, 자기 회복·흡혈 등 회복 출처별 세부 적용, 지속·예약 회복의
배율 참조 시점, 다른 회복 증폭과의 합성·반올림, 중복 장착·비호환과 획득 방식.

### 이로운 스택당 공격력 증가 — 이름 미정

> 상태: 2026-09-07 사용자 대화에서 범용 유물 채택과 최다 보유 이로운 스택 한 종류의 수량 기준 합의 /
> `5·3·2`스택 보유 시 `5`스택분 적용 확인 / 이름·스택당 증가율·희귀도·세부 판정 미정 /
> 문서 설계이며 현재 미구현.

**착용자가 현재 보유한 이로운 스택 중, 보유량이 가장 많은 한 종류의 스택 수에 비례해
착용자의 공격력이 증가한다.**

eligible 이로운 스택만 대상으로 각 종류의 현재 보유량을 비교한다. 여러 종류의 수량을 합산하거나
효과의 위력을 비교하지 않고, 가장 높은 수량 하나를 공격력 계산에 사용한다. 기준 종류는 현재
수량에 따라 자동으로 바뀌며 별도 선택 입력이나 스택 소비는 없다.

```text
적용 스택 수 = eligible 이로운 스택 종류별 현재 보유량의 최댓값
공격력 증가율 = 적용 스택 수 × 스택당 증가율 r
```

| 현재 보유한 이로운 스택 | 적용 스택 수 |
| --- | ---: |
| A 5개, B 3개, C 2개 | 5 |
| A 5개, B 5개 | 5 |
| A 2개, B 3개, C 2개 | 3 |
| 없음 | 0 |

- 동률인 종류가 여러 개여도 한 종류분만 계산한다. 유효한 이로운 스택이 없으면 보너스는 `0`이다.
- 현재 수량이 바뀌면 최댓값을 다시 계산한다. `A 5 / B 3 / C 2`에서 A가 2로 줄면 적용 수량은
  B의 3이 된다. 최댓값에 영향을 주지 않는 스택을 잃으면 유물 보너스는 그대로다.
- 스택당 증가율 `r`과 별도 계산 상한의 채택 여부·수치는 미정이다. 기존 스택의 수량이나 상한을
  이 유물로 늘리지는 않는다.

| 검토 사례 | 적용 아이디어 |
| --- | --- |
| 여왕벌의 왕실의 벌집 | 저장된 일벌을 이로운 스택으로 분류하면, 벌집을 받은 아군이 유물을 장착. 남은 일벌 수가 최다 보유량일 때 공격력 계산의 기준이 됨 |
| 늑대의 포만 | 포만 수량이 최다 보유량일 때 기존 최대 HP·공격 속도 강화와 함께 유물의 공격력 보너스를 얻음 |
| 검은 눈물 액세서리 | 피격으로 얻은 스택 수량이 다른 이로운 스택보다 많아지면 유물 계산의 기준이 됨 |

- 이로운 스택의 판정은 `스택`의 유불리·보유자 속성으로 명시하는 안이다. 다른 아군에게 준
  스택이나 적·타일에 쌓은 스택을 시전자의 보유량으로 합산하지 않는다. 일벌의 스택 분류 자체는
  후속 결정이며, 단순 버프·공명·HP 구간·전장 object 수를 자동으로 스택으로 바꾸지 않는다.
- `탐욕의 팔찌`는 2026-09-07 후속 대화에서 **현재 가진 이로운 효과 한 종류의 스택을 전부 소비해
  고정 시간의 계단식 공격력 버프를 얻는 액티브 액세서리**로 변경했다. 상세 합의는
  [탐욕의 왕 장비 설계](abnormality_skill_fragments_design_notes.md#액세서리--탐욕의-팔찌-가칭)를 따른다.
  이 유물은 최다 보유량에 따른 상시 공격력 증가로 구분한다. 팔찌로 한 종류를 소비하면 남은
  이로운 스택들의 최댓값으로 유물 보너스를 다시 계산한다.
- 원본 스택의 생성·소비·지속 시간은 그대로 사용하며, 유물이 자체 공격력 스택을 다시 생성해
  집계량을 늘리지는 않는다.

후속 결정: 이로운 스택의 개별 범위·보유자 판정과 같은 종류의 복수 출처 처리, 스택당 증가율·계산
상한, 스택 변동·소비 공격의 공격력 참조 시점, 탐욕의 팔찌와의 modifier 합성,
이름·희귀도·중복·비호환과 획득 방식.

### 눈의 여왕 전용 유물 — 이름 미정

> 상태: 2026-09-07 사용자 대화에서 전용 유물과 파편·무기 냉기 둔화 사망 조건 합의 /
> 이름·희귀도·수치·세부 판정 미정 / 문서 설계이며 현재 미구현.

**착용자의 눈의 여왕 파편 또는 무기가 부여한 냉기 디버프로 둔화된 적이 사망하면,
그 자리에 빙결 잔영을 생성한다.**

| 항목 | 내용 |
| --- | --- |
| 구분 | 눈의 여왕 파편·무기 전용 유물 |
| 주된 역할 | 연결형 — 냉기 둔화와 적의 사망을 빙결 잔영 생성으로 연결 |
| 냉기 출처 | 착용자의 파편 `빙설의 파도` 또는 무기 `서리 마검` |
| 발동 사건 | 해당 냉기의 이동 속도 감소가 적용 중인 적의 사망 확정 |
| 처치 주체 | 착용자 막타를 요구하지 않음. 다른 아군이 처치해도 발동 |
| 생성 효과 | 사망 위치의 빙결 잔영. 이동·주변 둔화·시간 경과 후 광역 Magic 폭발은 원본 설계 사용 |
| 이름·희귀도 | 미정 |

- 파편과 무기는 각각 독립적으로 냉기 조건을 제공한다. 서리 마검과 다른 파편, 또는 빙설의 파도와
  다른 호환 무기의 조합에서도 해당 출처의 냉기로 유물을 사용할 수 있다.
- 사망 시 냉기 디버프의 둔화 효과가 유효해야 한다. 만료·해제된 냉기, 둔화가 적용되지 않는 면역
  상태, 빙결만 있는 상태는 이 유물의 냉기 둔화 조건으로 대신 인정하지 않는다.
- 냉기 출처와 처치 피해 출처를 구분한다. 다른 직원의 냉기만 있는 적이나 다른 종류의 둔화는
  조건을 충족하지 않는다. 잔영의 주변 둔화도 위 파편·무기가 부여한 냉기로 자동 재분류하지 않는다.
- 기본 파편의 직접 처치 잔영은 원래 조건대로 생성한다. 같은 착용자의 기본 조건과 유물 조건이
  한 사망에서 함께 충족되어도 잔영을 두 개 생성하지 않는다.
- 유물 조건으로 추가 생성한 잔영은 유물 출처를 보존한다. 유물로 생긴 잔영의 폭발이 다시 같은
  유물 사본의 잔영 생성 효과로 돌아오는 경로에는 공통 순환 재발동 금지를 적용한다. 잔영 폭발
  처치의 나머지 세부 연쇄 판정은 후속 설계하며, 무제한 잔영 재생성을 확정하지 않는다.
- 침식 처치는 유물·사망 시 효과를 발동하지 않는 공통 정책을 따른다.

후속 결정: 이름·희귀도, 잔영의 세부 수치와 생성 상한, 같은 대상에 대한 냉기의 복수 출처·갱신과
둔화 면역·중첩 판정, 냉기 부여와 사망이 같은 공격에서 발생할 때의 순서, 여러 착용자·유물 사본의
동시 발동, 잔영 폭발·기타 특수 처치의 연쇄, 출처별 잔영의 공격력 참조·태그 적용과 이탈 처리,
중복 장착·비호환·획득 방식.

### 단일 대상 전환·효과 증폭 — 범용 유물

> 상태: 2026-09-08 단일 전환 유물 범용화·포큐버스 적용 합의 / 2026-10-07 개인 방어막 구조로 갱신 /
> 포큐버스 일반·침식 배율은 재조정. 기존 공용 기준 2배·4배 비교안은 과거 기록 / 이전 가칭 `깊어지는 울음` /
> 범용 표시 이름·희귀도·공통 증폭 규칙·포큐버스 기본 보호량 식·세부 판정 미정 /
> 태아 전용 유물은 별도 미정 / 문서 설계이며 현재 미구현.

**여러 아군에게 적용하던 범위 지원 효과를 단일 아군 대상으로 전환하고, 그 효과량을 크게 높인다.**

- 호환: 태그 기반 범용. 태아의 범위 강화와 포큐버스의 범위 내 개인 방어막 부여에 적용한다. 환상체 ID나
  `집중유지`를 필수 조건으로 삼지 않으며, 다른 범위 효과의 호환 범위는 후속 확장한다.
- 효과 단위로 여러 아군을 지원하는 대상 구조와 `기본공격강화`·`능력치변경`·`보호막` 등 증폭할
  효과량을 확인한다. 관련 지원 효과를 함께 전환하되 무기 공격·별도 자기 회복 등은 별도로 판정한다.
- 역할·분해 축: 전문화형 / `2. 대상·선정`, `3. 공간 구조`, `4. 전달·매개`,
  `8. 효과량·참조 기준`, `9. 집계·분배·공유`.
- 한 명을 선택해 효과를 집중하며 원본의 대상 자격을 보존한다. 태아는 자신을 제외한 아군,
  포큐버스는 원래 보호 가능한 자신 또는 다른 아군이 후보다. 수동 지정·선택 사거리·대상 교체는 미정이다.
- 다른 아군은 전환된 지원 효과를 받지 않는다. 포큐버스는 생성 후 단순 범위 이탈로 방어막을
  제거하지 않는 원본 규칙을 유지한다. 태아의 이탈 판정과 각 효과의 철수·대상 무효화 처리는
  후속 결정하며, 범위 전환만으로 전장 전체 지정이나 지속 재부여를 허용하지 않는다.
- 원본의 공명 소비, 준비·지속 시간, 집중 필요 여부, 행동 병행과 중단 규칙은 유지한다.
  포큐버스에 태아의 집중 행동 제한이나 `6~8초`를 이식하지 않는다.
- 태아의 기존 합의값을 적용 사례로 보존한다. 모든 피해·능력치·보호량을 같은 배율로 늘리는
  공통 산식은 미정이다. 공격 속도 `+15 → +20`도 두 배 증가로 설명하지 않는다.
- 전환으로 사라진 지원 범위에는 `울림통`의 반경 증가를 적용하지 않는다. 지정 사거리와 효과 반경은
  별도 항목이다. `긴 호흡`은 `지속시간` 태그가 있는 유한한 지속 효과에 적용하며, 집중형에 한정하지 않는다.

| 적용 효과 | 유물 없는 원본 | 범용 유물 적용 | 침식된 범용 유물 적용 |
| --- | --- | --- | --- |
| 태아의 기본 공격 피해 강화 | 범위 내 각 아군 `+20%` | 선택한 한 명 `+40%` | 선택한 한 명 `+80%` — 기존 합의 |
| 태아의 기본 공격 속도 강화 | 범위 내 각 아군 `+15`포인트 | 같은 한 명 `+20`포인트 | 같은 한 명 `+30`포인트 — 기존 합의 |
| 포큐버스의 포자막 | 시전 시 각 아군에게 개인 보호량 `S`를 1회 부여 | 한 명에게 강화 개인 방어막 — 배율 재조정 | 같은 한 명에게 침식 강화 방어막 — 배율·패널티 재조정 |

포큐버스의 새 기준 `S`는 유물 없는 개인 방어막 하나의 보호량이다. 원본은 시전 시 대상 수 `N`에 따라
총 `N × S`를 생성하므로 개인 보호량·범위·지속 시간·공명 주기와 단일 전환 배율을 함께 재조정한다.
기존 일반 `2S`·침식 `4S`와 `1,000 → 2,000 / 4,000` 예시는 공용 보호량을 전제로 한 과거 기록이다.
새 기준에 그대로 승계하거나 침식 배율을 일반 배율에 다시 곱하지 않는다.

단일 전환은 선택한 한 명에게만 강화 개인 방어막 하나를 만든다. 원래 보호할 수 있었던 아군 수를
단일 보호량에 자동으로 곱하거나 여러 방어막을 한 대상에게 중첩하지 않는다. 제공자는 계속 시전자이며,
선택한 대상의 방어·감면 계산 후 피해를 흡수하고 잔량 초과분은 그 대상 HP에 적용한다.
`쾌락의 고리`는 시전자가 생성하는 각 방어막에 한 번씩 적용하며, 단일 전환에서는 그 하나에 적용한다.
수혜자의 장비로 다시 증폭하거나 생성 후 일반 HP 회복으로 잔량을 채우지 않는다.
유물과 액세서리 증폭의 합성은 미정이다.

#### 범용 전환의 15개 축 검토

태아의 피해·속도 강화와 포큐버스의 개인 보호량을 각각 분해해 공통 변화와 원본별 제약을 확인한다.

| 분해 축 | 공통 변화·검토 | 태아와 포큐버스의 차이 |
| --- | --- | --- |
| 1. 사용·조작 방식 | 기존 시전에 단일 대상 선정 연결. 입력 세부 미정 | 두 원본의 자기 시전을 대상 지정으로 바꾸는 처리 필요 |
| 2. 대상·선정 | 여러 아군 → 원래 자격 안의 한 명 | 태아는 자기 제외 / 포큐버스는 자기 포함 후보 |
| 3. 공간 구조 | 지원 범위 제거, 선택 사거리·이탈 판정 별도 미정 | 태아 반경 초안과 포큐버스 시전 시 범위 선정을 공통 지정 사거리로 확정하지 않음 |
| 4. 전달·매개 | 단일 대상에 지원 연결, 부착 세부 미정 | 집중에서 파생되는 강화 / 시전자가 소유하는 보호막 |
| 5. 시간 구조 | 기본 유지 시간 변경 없음 | 태아 집중 `6~8초` 방향 / 포큐버스 지속 시간 미정 |
| 6. 반복·발생 구조 | 새 타격·반복 횟수 추가 없음 | 아군의 기본 공격 유지 / 피격마다 보호량 소비 |
| 7. 효과의 종류 | 대상 구조를 바꾸고 해당 효과량 강화 | 기본 공격 피해·공격 속도 / 보호막 |
| 8. 효과량·참조 기준 | 효과별 증폭, 공통 배율 미정 | 태아 `+40% / +20` 유지 / 포큐버스 개인 보호량 식·일반/침식 배율 재조정 |
| 9. 집계·분배·공유 | 한 명에게 효과 집중 | 대상별 버프를 한 명에 적용 / 여러 개인 방어막을 한 명의 강화 방어막으로 전환 |
| 10. 자원·축적 | 원본 자원 구조 유지 | 별도 축적 없음 / 선택 대상의 독립 방어막 잔량 유지 |
| 11. 비용·위험 | 슬롯 1개, 다른 아군의 지원 포기 | 시전자 행동 포기 / 나머지 아군의 보호 상실 |
| 12. 조건·분기·연계 | 선택 대상과 원본 유지 조건 확인 | 집중 중 강화 / 보호막 생성·흡수·소진 |
| 13. 행동 병행·제약 | 원본 규칙 유지 | 집중 중 행동 제한 / 시전 후 공격·저지 가능 |
| 14. 종료·존속 | 원본 만료·소진·중단 유지, 대상 무효화 처리 미정 | 집중 종료 시 강화 제거 / 보호량 소진·시간 만료 시 종료 |
| 15. 출처·소유·귀속 | 제공자와 수혜자 구분 유지 | 아군의 공격 출처 유지 / 보호막 원천은 시전자 귀속 |

#### 침식된 단일 전환 유물 — 패널티 미정

- 침식 아이템을 이 범용 유물에 적용하는 변형으로 이어서 검토한다. 기존 태아 적용 수치
  `기본 공격 피해 +80% / 공격 속도 +30`은 보존한다. 포큐버스는 개인 방어막 기준으로 침식 배율을
  다시 결정하며, 시전자에게 줄 생존 위험과 함께 확정한다. 과거 공용 보호량의 `4배`를 승계하지 않는다.
- 태아 전용 유물로 남기지 않는다. 효과·대가는 원본 구조에 맞게 검토하며, 모든 적용 대상에
  HP 희생 집중이나 강제 집중을 추가하지 않는다.
- 죽음에 이를 수 있는 패널티의 종류·수치·유지 방식은 미정이다. HP 희생 유지, 침식체 최우선 공격
  대상, 받는 피해 `100%` 증가 중 하나를 이미 채택했거나 모두 적용하는 것으로 해석하지 않는다.
- 최대 시간 제거·HP 희생 유지도 후보다. `침식된 긴 호흡` 설명용 매초 최대 HP `6%` 소비를
  이 유물의 확정 대가로 가져오지 않는다.
- 직접 드롭 없이 침식 아이템을 적용하는 공통 정책을 따르며, HP 비용·회복·보호막·생존 보장·종료
  규칙과 대상 선정·이탈을 패널티와 함께 후속 설계한다.

후속 결정: 범용 이름·희귀도, 효과별 증폭 또는 공통 산식, 포큐버스 개인 보호량·일반/침식 배율 재조정, 대상 지정·부착·
교체·무효화 처리, 다른 범위 지원·광역 피해·회복 등에 대한 호환 확장, 중복·비호환·증폭 합성,
침식된 변형의 효과·패널티·획득 세부. 태아 수치를 전체 범용 효과의 단일 배율로 일반화하지 않는다.

### 태아 파편 기반 유물

> 상태: 2026-09-07 세 상태의 강화 수치 합의 / 2026-09-08 단일 전환·증폭 유물을 범용으로 이전 /
> 태아 전용 유물 미정 / 범용 유물의 태아 적용 수치는 유지 / 집중·선정·침식 패널티 세부 미정 / 현재 미구현

원본은 [멈추지 않는 울음 수치와 유물 적용](abnormality_skill_fragments_design_notes.md#멈추지-않는-울음-수치와-유물-적용)이다.
기본 파편은 범위 지원을 유지하고, [단일 대상 전환·효과 증폭 범용 유물](#단일-대상-전환효과-증폭--범용-유물)을
장착하면 아군 한 명에게 더 강한 지원을 제공한다. 단일 전환과 이전 합의 수치는 범용 유물의 태아
적용 사례이며, 앞으로 만들 태아 전용 유물의 효과·수치로 배정하지 않는다.

#### 상태별 강화 수치 — 합의

| 상태 | 대상 | 기본 공격 피해 증가 | 기본 공격 속도 증가 |
| --- | --- | --- | --- |
| 기본 파편 | 범위 내 다른 eligible 아군 직원 | `+20%` | `+15`포인트 |
| 단일 전환 범용 유물 적용 | 단일 아군 | `+40%` | `+20`포인트 |
| 침식된 단일 전환 범용 유물 적용 | 단일 아군 | `+80%` | `+30`포인트 |

각 값은 해당 상태에서 제공하는 **최종 증가량**이다. 피해는 `20% → 40% → 80%`, 공격 속도는
`+15 → +20 → +30`으로 교체하며 앞 상태와 합산하지 않는다. 다른 modifier가 없고 공격 속도 기준값이
100이면 각각 `115 / 120 / 130`이다. 이 세 상태를 동시 중첩하거나 유물 레벨로 해석하지 않는다.
기본 공격 피해 강화는 범용 Attack stat 증가와 구분하고, 실제 공격은 강화받은 아군의 기본 공격이다.

#### 태아 파편의 15개 축 검토

효과는 `울음 집중과 지원 유지`, `기본 공격 피해 증가`, `기본 공격 속도 증가`로 분리한다.
공유하는 조건은 함께 적되 두 강화 효과의 변경을 각각 기록한다. `초안`·`미정` 표시는 위 합의 수치와 구분한다.

| 분해 축 | 기본 파편 구조 | 유물 적용 시 변경·후속 검토 |
| --- | --- | --- |
| 1. 사용·조작 방식 | 공명 만충에서 자신에게 시전, 직접 중지 가능 | 단일 지원은 아군 한 명 수동 지정 후보. 입력 세부 미정 |
| 2. 대상·선정 | 범위 내 다른 eligible 아군 직원. 자신·Guest·소환물·방어 오브젝트 제외 | 범용 단일 전환 유물로 아군 한 명 지원 |
| 3. 공간 구조 | 시전자 중심 원형, 반경 `2타일` 초안 | `울림통`: 원형 반경 확대. 단일 지원의 지정 사거리는 별도 미정 |
| 4. 전달·매개 | 집중과 범위에서 파생되는 오라 | 범용 단일 전환은 단일 대상 부착형 후보. 이동·거리 이탈 판정 미정 |
| 5. 시간 구조 | 준비 `0.5초` 초안. 짧은 집중 `6~8초` 방향, 비교용 `8초`는 미확정 | `긴 호흡`: 유한한 최대 시간 연장. 침식 상태의 유지 방식은 패널티와 함께 결정 |
| 6. 반복·발생 구조 | 파편 자체 타격 없음. 각 아군이 기본 공격 수행 | 새 타격 생성 없음 |
| 7. 효과의 종류 | 기본 공격 피해와 공격 속도 강화 | 두 강화 효과 모두 상태별 수치로 교체 |
| 8. 효과량·참조 기준 | 기본 공격 피해 `+20%`, 공격 속도 `+15` | 범용 유물 적용 `+40% / +20`, 침식된 범용 유물 적용 `+80% / +30`. 앞 상태와 합산하지 않음 |
| 9. 집계·분배·공유 | 대상별 강화, 총량 분할 없음. 박동끼리 수치 중첩 없음 | 여러 아군 지원을 한 명의 강화로 전환 |
| 10. 자원·축적 | 별도 스택·저장 횟수 없음 | 단계별 스택이나 집중 4초 누적 보상 없음 |
| 11. 비용·위험 | 공명 소비·시전자 행동 포기. 비침식 유지 중 추가 자원 소모 없음 초안 | 침식된 유물은 죽음에 이를 수 있는 대가 추가. 종류·수치 미정 |
| 12. 조건·분기·연계 | 집중 유지와 범위 내 존재 | 단일 대상의 유효 조건으로 전환. 별도 예열 강화 조건 없음 |
| 13. 행동 병행·제약 | 기본 공격·다른 스킬 시작·태세 전환·전술 이동 등 제한. 집중 중 저지 미정 | 시전자 행동 포기 유지. 침식 패널티의 추가 행동 규칙은 미정 |
| 14. 종료·존속 | 범위 이탈·집중 종료 시 강화 즉시 제거 | 단일 대상의 이탈·무효화, 침식된 유물의 종료 조건은 미정 |
| 15. 출처·소유·귀속 | 강화 제공자는 시전자, 공격·처치 주체는 강화받은 아군 | 출처 보존. 아군의 공격·처치를 시전자에게 이전하지 않음 |

#### 긴 호흡 — 가칭·일반 제안

- 호환: **범용**. `지속시간` 태그와 유한한 지속 시간을 가진 효과. 2026-10-18 사용자 합의로 기존 `집중유지` 한정을 해제했다.
- 역할·분해 축: 강화형 / `5. 시간 구조`. 이름·일반 등급 배정은 제안 상태다.
- 효과: **착용자가 제공하는 `지속시간` 태그 효과의 지속 시간이 25% 증가한다.** 집중형·장판·기간형 강화 등에서 해당 효과의 유지 시간을 늘린다.
- 태아 적용 예시: 집중 `8초` 초안이라면 `10초`. 정확한 기본 시간이 달라지면 해당 값의 25%를 늘린다.
  준비 시간과 강화량은 바꾸지 않으며, 늘어난 시간에도 시전자가 계속 집중해야 한다.
- 음양 적용: 음의 영역과 양의 영역 각각의 장판 유지 시간을 늘린다. 회복량·회복 주기·순환 회복 전달 비율·교집합 버프 수치를 바꾸지 않는다. 교집합 버프에 별도 지속 시간이 있는지는 아직 미정이며, 장판 연장만으로 독립된 버프 수명까지 늘리는 것으로 확정하지 않는다.
- 기본 범위 지원과 유한한 시간 제한을 가진 단일 지원, 기간형 강화 등에도 `지속시간` 태그가 있으면 적용한다. 시간 제한이 없는 효과나 즉시 효과에 새 지속 시간을 만들지 않는다. 시전 준비·쿨다운·공명 충전·공격 및 회복 주기는 변경하지 않는다.
- 효과별로 적용할 지속 시간을 지정한다. 장판·그 장판의 버프·별도 투사체처럼 수명이 다른 효과에 파편 전체 태그를 일괄 적용하지 않는다. 원래의 중단·사망·퇴각·이탈 등 종료 조건도 그대로 따른다.
- 현재 직접적인 파편 적용 사례는 태아와 음양이다. 침식된 유물이 HP 희생 중 무기한 유지하는 형태를 택한다면
  그 효과에는 늘릴 유한 최대 시간이 없으므로 시간 증가를 별도로 누적하지 않는다. 해당 침식 형태의 채택은 미정이다.

#### 울림통 — 가칭·일반 제안

- 호환: **범용**. `지속영역` 태그와 원형 범위 속성을 가진 효과. 사용자가 범용안을 유지하기로 했다.
- 역할·분해 축: 강화형 / `3. 공간 구조`. 이름·일반 등급 배정은 제안 상태다.
- 효과: **착용자가 생성하는 원형 지속영역의 반경이 25% 증가한다.**
- 기본 파편 적용 예시: 반경 `2타일` 초안이면 `2.5타일`. 시전자 중심·대상 자격·강화량은 그대로다.
- 단일 전환 범용 유물로 단일 지원이 되면 이 효과의 원형 지속영역이 사라지므로 울림통은 해당 지원에
  적용되지 않는다. 단일 대상의 지정 사거리를 늘리지 않으며, 착용자의 다른 원형 지속영역은 별도로 판정한다.
- 원형 지속영역으로 작성된 회복 장판·보호 영역도 호환 후보다. 대상 수나 공유 보호량 자체를
  늘리지 않으며, 시전 사거리·일회성 폭발·직선·부채꼴 범위를 이 효과로 확대하지 않는다.

#### 단일 전환 범용 유물의 태아 적용

- 기본 공격 피해·속도를 위 상태별 값으로 교체한다. 강화는 집중 시작부터 제공하며 별도 4초 예열은 없다.
- 시전자의 집중과 기본 공격·이동 등의 행동 포기는 유지한다. 짧은 집중 `6~8초` 방향에서
  `8초`는 비교 초안이다. 이 시간을 다른 파편의 범용 적용 시간으로 사용하지 않는다.
- 기존 선정 후보는 시전 시 `2타일` 안의 아군 한 명을 수동 지정하고, 대상에게 강화가 붙는 방식이다.
  태아 적용의 지정 사거리·집중 중 대상 변경·거리 이탈·철수·전투불능 처리는 미정이다.
- 침식된 범용 유물 적용의 `+80% / +30`은 앞 상태에 더하지 않는 최종 증가량이다.
  강화 수치를 유지하되 패널티·유지 방식은 위 범용 유물의 침식된 변형에서 함께 검토한다.

#### 태아 전용 유물 — 미정

- 2026-09-08 사용자 요청으로 이름·효과·희귀도·수치를 모두 미정으로 정리한다.
- 기존 단일 대상 전환과 효과 증폭은 범용 유물로 이전했다. 같은 기능을 태아 전용 유물로 중복 기록하지 않는다.
- 태아 전용 유물의 침식된 변형도 원본 전용 효과가 정해진 뒤 설계한다. 범용 유물의 기존 태아 적용
  수치를 미정인 전용 유물에 다시 배정하지 않는다.

#### 조합과 후속 검증

- 기본 범위 지원은 `긴 호흡`과 `울림통`을 함께 활용한다. 비교 초안에서는 반경 `2.5타일`,
  집중 `10초`, 기본 공격 피해 `+20%`, 공격 속도 `+15`다.
- 단일 지원은 `긴 호흡`과 조합하면 비교 초안에서 `10초` 동안 `+40% / +20`을 제공한다.
  `울림통`을 함께 장착했다고 단일 지원의 지정 사거리나 강화량까지 증가하지 않는다.
- 침식된 단일 지원은 `+80% / +30`을 제공한다. 유지 시간과 다른 유물의 시간 연장 적용은
  아직 선택하지 않은 침식 패널티·유지 방식에 따라 정한다.

다른 강화가 없고 공격 속도 100에서 지속 공격하는 아군 한 명의 단순 기본 공격 화력은 상태별로
`1.20 × 1.15 = 1.38`배, `1.40 × 1.20 = 1.68`배, `1.80 × 1.30 = 2.34`배다. 시전자와
각 아군의 화력이 모두 100이라면 기본형으로 아군 3명을 지원할 때 합산 기본 공격 화력은
`400 → 414`다. 비침식 단일 지원은 같은 화력의 시전자·대상을 합쳐 `200 → 168`이므로,
시전자보다 강한 주력 공격수를 지원하는 조합에서 가치를 검토해야 한다. 이 계산은 파티 전체의
실전 성능·침식 대가를 검증한 결과가 아니며 준비·표적 공백·다른 modifier·스킬 피해·공명 주기를 제외한다.

후속 검토: 확정 수치의 실제 전투 밸런스, 이름·희귀도, 준비 시간·범위·정확한 집중 시간,
단일 대상의 지정·부착·교체·종료 규칙, 침식 패널티·아이템 적용 세부, 기존 공격 속도 강화와의 합성,
유물 중복 장착·범위 및 시간 modifier의 합산·반올림, 복수 source와 진행 중 공격의 강화 경계,
획득 방식. 파편 침식형 제외와 공통 연쇄 규칙은 유지한다.

#### 착용자 받는 피해 증가 — 이름 미정

**유물을 착용한 유닛이 받는 피해가 증가한다.**

- 사용자 의도: 단독으로 불리한 효과여도 향후 조합에 사용할 수 있도록 독립 범용 유물로 남긴다.
- 적용 대상·출처: 유물이 착용자 자신에게 제공하는 `받는피해증가`. 장착 효과가 활성화된 동안 적용한다.
- 증가율은 미정이다. 침식 패널티 예시의 `100%`나 소환물 유물의 `5초`를 이 효과의 수치로 가져오지 않는다.
- 효과 자체가 HP를 소비하거나 피해를 새로 발생시키지는 않는다. 실제로 받는 피해를 늘린다.
- 별도 공격력 보상이나 침식 아이템 적용 조건을 붙이지 않는다. 침식된 유물의 패널티와 독립된 유물이다.
- 분해 축: `7. 효과의 종류`, `8. 효과량·참조 기준`, `11. 비용·위험`, `15. 출처·소유·귀속`.
- 미정: 이름·희귀도·역할 분류, 증가율, 적용 피해 출처·유형, 보호막·감면·반사와의 계산 순서,
  HP 비용의 취급, 중복 장착·합성·획득 방식.

#### 잃은 체력 비례 공격력 증가 — 이름 미정

**착용자가 현재 잃은 체력의 비율에 비례해 공격력이 증가한다.**

- 과거에 받은 피해의 누적량이 아니라, 현재 최대 HP 대비 부족한 HP의 비율을 참조한다.
- 현재 체력 비율을 읽는 상시 효과로 검토한다. 회복하면 보너스가 줄고 최대 HP까지 회복하면 0이 된다.
- `능력치변경(공격력)` 효과다. 공격력을 참조하는 기본 공격·스킬 등이 각자의 계산 규칙대로 영향을 받는다.
- 선형 계산 초안: `잃은 체력 비율 = (최대 HP - 현재 HP) / 최대 HP`,
  `공격력 증가율 = 잃은 체력 비율 × 계수 k`. 계수와 최종 증가 곡선은 미정이다.
- 앞서 제안한 `k = 50%`라면 HP를 40% 잃었을 때 공격력 `+20%`, 80% 잃었을 때 `+40%`다.
  이 값은 설명용 초안이며 확정 수치가 아니다. HP 1은 최대 HP에 따라 상한에 가까운 보너스를 준다.
- 별도 스택을 만들거나 HP를 소비하지 않는다. 다른 유물이 HP를 낮추거나 생존을 보조하면 현재
  체력 비율을 통해 조합되며, 특정 유물의 동시 장착을 요구하지 않는다.
- 분해 축: `8. 효과량·참조 기준`, `11. 비용·위험`, `12. 조건·분기·연계`, `15. 출처·소유·귀속`.
- 미정: 이름·희귀도, 계수·증가 곡선, 최대 HP 변화·진행 중 공격의 참조 시점,
  다른 공격력 증가와의 합성·중복·획득 방식.

#### 빌려온 댓가 — 생존 보장과 후불 대가

> 상태: 2026-09-08 사용자 제시 이름·10초 생존 보장・HP 절반 회복・후속 `대가` 디버프 반영 /
> 대가의 효과 조합·수치·존속 세부, 발동 방식·횟수·희귀도는 미정.

**미래의 생명을 미리 끌어와 지금을 버틴다. 10초간 HP가 1 미만으로 내려가지 않으며,
지속 시간 종료 후 HP의 절반을 회복하고 `대가` 디버프를 받는다.**

유물 이름은 사용자가 제시한 `빌려온 댓가` 표기를 유지하고, 후속 디버프 이름은 `대가`로 구분한다.
생존 보장·종료 회복·후속 불이익을 각각 분해한다. 강한 효과에 후불 대가를 붙이는 범용 유물이며,
이 대가를 가진다는 이유만으로 침식 아이템을 요구하거나 침식된 유물로 분류하지 않는다.

**생존 보장과 회복**

- `생존보장`은 10초간 HP 하한을 1로 유지한다. [샤덴프로이데의 HP 1 생존 보장](abnormality_skill_fragments_design_notes.md#파편--멈추지-않는-분쇄-가칭)을 참고하되 특정 파편을 요구하지 않는다.
- 자동 발동·전투당 1회는 기존 추천안으로 유지하며 아직 확정하지 않는다. 자동 발동안에서는 다른
  방어·이미 활성화된 생존 보장을 반영한 뒤에도 해당 전투 피해가 HP를 1 미만으로 내릴 때,
  전투불능 확정 전에 해당 타격부터 보호한다. 이미 다른 효과가 살려낸 타격에는 사용하지 않는 안이다.
- 보호 중 HP는 1까지 감소하고 회복도 받을 수 있다. 회복한 HP를 강제로 1로 낮추거나 기절·빙결 등
  행동 방해를 막지 않으며, 피격·회복으로 10초를 갱신하지 않는 방향이다.
- 사용자의 `HP의 절반 회복`은 **회복 직전 최대 HP의 50%만큼 회복**하는 것으로 해석한 초안이다.
  현재 HP를 50%로 설정하거나 현재 부족한 HP의 절반만 채우는 방식과는 구분하며, 기준의 확정은 남긴다.
- 정상 만료 때 생존 보장을 종료하고 회복을 처리한 다음 `대가`를 부여한다. 새 대가의 회복 저해가
  방금 약속한 종료 회복을 먼저 깎지 않는 순서다. 같은 시각의 외부 피해와의 세부 순서는 후속 결정한다.
- 회복은 착용자의 유물에 귀속되는 `회복` 효과로 기록한다. 최대 HP를 넘지 않으며 기존 회복 증폭·저해,
  회복 발동 효과와의 조합은 후속 결정한다. 강제 사망이나 보호 중 막아낸 피해의 사후 청구는 추가하지 않는다.

| --- | --- | --- |
| 해당 전투에서 받는 피해 증가 | 빌린 생존 시간이 끝나면 같은 공격에도 더 쉽게 쓰러짐 | 증가율과 다른 받는 피해 증가의 합성 |

**추천 조합 — 미합의 초안**

`대가`를 해당 전투 종료까지 유지하며 다음 세 효과를 묶는 안이다. 아래 `50%` 수치는 초기 비교용 제안이다.

- 받는 피해 `+50%`.
- 받는 회복량 `-50%`. 가하는 회복량 감소가 아니므로 착용자가 다른 아군을 치료하는 양을 직접 줄이지 않는다.
- 대가가 적용된 상태에서 전투불능이 되면 **그 전투불능으로 새로 얻는 트라우마를 2배**로 한다.
  기존에 보유한 트라우마 전체를 두 배로 만들거나 physical damage 증가량을 두 배로 만들지 않는다.

설계 당시 [직원 condition 규칙](../archive/game_rulebook_legacy_2026-10-04.md#직원-condition-전투-hp-전투불능-런-실패)은 전투불능
instance마다 트라우마를 한 번 더한다. 따라서 사용자 표현의 `사망 시`를 전투불능 사건으로 연결하는
것을 제안한다. 영구 사망한 직원에게 별도 트라우마 사건을 만드는 효과로 확정하지 않는다.
기본 획득량이 `T`라면 `2T`를 한 번 더하는 안이며 기존 트라우마 범위를 따른다. 대가가 끝나도 이미
증가한 트라우마는 일반 condition 회복 규칙을 따르고 되돌리지 않는다.

최대 HP 감소는 우선 별도 대안으로 남긴다. 위 세 효과에 더하면 체력 총량·피격 피해·회복·전투불능
후유증을 모두 악화시킨다. 특히 최대 HP가 줄면 잃은 체력 비율도 다시 계산되므로 저체력 공격력
유물의 체감까지 달라진다. 최대 HP 감소를 채택한다면 받는 피해 증가 또는 회복 저해를 대체하는 안부터 비교한다.

**대가의 수명과 남은 판정**

- 추천안에서는 전투가 끝나면 대가의 받는 피해 증가·회복 저해를 제거한다. 트라우마의 증가 결과는 남는다.
- 전투 중 해제나 재배치만으로 대가를 지우지 않는 방향을 추천한다. 생존 보장 도중 조기 철수해도
  빌린 사실은 남기고, 같은 전투의 재배치에는 대가를 적용하는 안이다. 철수 자체를 금지하지 않는다.
- 현재 룰북의 일반 buff/debuff는 철수 시 종료하므로, 이 추천안은 전투 단위의 별도 기록과 재적용이
  필요한 미래 규칙이다. 보호 중 철수·외부 중단·전투 종료 시 회복 지급 여부와 대가 시작 시점은 미정이다.
- 전투당 1회안을 채택하면 사용 기록은 같은 전투의 재배치로 복구하지 않고 다음 전투에 초기화한다.
- HP 지불·최대 HP 희생·직접 처형, 침식된 유물의 HP 희생 유지와의 조합은 후속 결정한다.
- 분해 축: 생존 보장은 `1·5·7·10·12·14`, 종료 회복은 `7·8·12·15`,
  대가는 `5·7·8·11·12·14·15`를 중심으로 검토한다.
- 미정: 발동 방식·횟수·희귀도, 회복 기준·다른 회복 효과와의 합성, 대가 후보의 최종 조합·수치,
  전투불능 트라우마 배율의 채택, 해제·철수·재배치·중단·전투 종료 처리, 중복 장착·획득 방식.
  트라우마 배율 채택 시 전투 사건이 condition에 남기는 결과까지 확장하는 공통 정책 검토가 필요하며,
  이 콘텐츠 초안만으로 현재 룰북·runtime의 트라우마 규칙을 변경하지 않는다.

#### 저체력 조합의 15개 축 검토

각 열은 독립된 유물이다. `빌려온 댓가`는 생존 보장 → 종료 회복 → 후속 대가의 개별 효과를 함께
표시한다. 사용자 제시 구조와 추천 세부를 구분하며 원본 파편의 효과를 변경하지 않는다.

| 분해 축 | 착용자 받는 피해 증가 | 잃은 체력 비례 공격력 증가 | 빌려온 댓가 — 대가 세부 제안 |
| --- | --- | --- | --- |
| 1. 사용·조작 방식 | 장착 활성 중 상시 | 현재 체력 비율을 자동 참조 | 치명적인 전투 피해에 자동 발동하는 안은 미확정 |
| 2. 대상·선정 | 착용자 자신 | 착용자 자신 | 착용자 자신 |
| 3. 공간 구조 | 범위·사거리 해당 없음 | 범위·사거리 해당 없음 | 범위·사거리 해당 없음 |
| 4. 전달·매개 | 착용자에게 적용하는 상태 | 착용자의 공격력 변경 | HP 하한 상태 → 즉시 회복 → 대가 디버프 |
| 5. 시간 구조 | 활성 중 적용 | 현재 HP 변화에 따라 변동, 공격 참조 시점 미정 | 보호 10초 → 회복 → 대가. 추천 대가 기간은 해당 전투 종료까지 |
| 6. 반복·발생 구조 | 각 적용 대상 피해에 반영 | 타격 수 변경 없음 | 보호 중 후속 피해에도 하한 유지, 정상 만료 회복 1회 |
| 7. 효과의 종류 | 받는피해증가 | 능력치변경(공격력) | 생존보장·회복·대가. 대가의 피해 증가·회복 저해·트라우마 배율은 후보 |
| 8. 효과량·참조 기준 | 증가율·적용 피해 범위 미정 | 현재 최대 HP 대비 부족한 HP 비율, 계수 미정 | HP 하한 1, 종료 회복은 최대 HP의 50% 해석안, 대가 수치 미확정 |
| 9. 집계·분배·공유 | 자기에게만 적용, 공용 잔량 없음 | 자기에게만 적용, 공용 잔량 없음 | 보호·회복·대가 모두 착용자 대상 |
| 10. 자원·축적 | 별도 축적·소비 없음 | HP 비율 참조, 별도 스택·소비 없음 | 전투당 1회 사용 기록 제안 |
| 11. 비용·위험 | 슬롯 1개와 더 큰 피격 피해 | 슬롯 1개와 저체력 유지 위험 | 슬롯 1개, 횟수 제한 후보와 보호 종료 후 대가 |
| 12. 조건·분기·연계 | 피해를 받아 HP가 낮아지는 조합 | 회복·피격에 따른 보너스 변동 | 치명적 피해 → 보호 → 만료 회복 → 대가 → 전투불능 트라우마 확대 후보 |
| 13. 행동 병행·제약 | 새 행동 제한 없음 | 새 행동 제한 없음 | 새 행동 제한·행동 방해 면역 없음 |
| 14. 종료·존속 | 유물 비활성 시 해제 | 비활성 시 해제, 회복하면 보너스 감소 | 보호 만료 후 대가로 전환. 대가의 전투 내 유지·재배치 적용과 트라우마 결과 존속 제안 |
| 15. 출처·소유·귀속 | 유물 출처의 자기 받는 피해 증가 | 유물 출처의 자기 공격력 증가, 공격 출처 유지 | 보호·회복·대가는 착용자의 유물 출처, 트라우마는 원래 전투불능 사건의 획득량 변경 후보 |

#### 조합에서 얻는 선택

- 받는 피해 증가로 저체력 구간에 빨리 진입하고, 부족한 HP에 따른 공격력 보너스를 얻으며,
  빌려온 댓가의 생존 보장 10초 동안 공격을 이어가는 구상이다. 공격력 증가율·대가 세부는 미정이며
  성능 검증을 마친 조합은 아니다.
- 보호 종료 회복으로 부족한 HP 비율이 줄면 저체력 공격력 보너스도 낮아진다. 최대 HP 1,000,
  종료 직전 HP 1에서 다른 회복 효과가 없다면 최대 HP 50% 회복 초안은 HP 501을 만들고,
  이후 대가가 시작된다. 종료 회복을 새 대가의 회복 저해로 먼저 줄이지 않는다.
- 보호 중 강하게 공격하고, 대가가 시작된 뒤에는 줄어든 회복 효율·커진 피격 위험을 감당할 위치와
  보호 수단을 준비하는 선택이다. 기존 독립 유물의 받는 피해 증가와 대가의 증가량 합성은 후속 결정한다.
- 세 유물을 모두 장착하면 직원의 공용 슬롯 3개를 사용한다. `깨어난 흑조`를 함께 쓰려면 이 중
  하나를 빼야 하며, 전용 유물까지 네 개를 동시에 장착하는 조합으로 설명하지 않는다.
- 샤덴프로이데는 파편을 수동으로 사용해 생존 보장과 능력치 강화를 함께 얻는다. 빌려온 댓가는
  범용 유물로 생존 보장·종료 회복·후불 대가를 제공한다. 자동 발동은 후보이며 별도 공격력 강화는 없다.
- HP 1에서 추가로 막은 피해를 실제 HP 손실로 집계하지 않는다. 실제 HP 감소를 요구하는 피격·회복·반사
  연계와 HP 비용 처리는 각 원본의 조건을 확인한다.

## 실제 설계 순서

### 1. 전체를 훑어 공통 요소와 차이를 찾는다

모든 대상의 파편·장비를 먼저 간략히 읽고 효과의 단계·분기·병행 관계를 적은 뒤 개별 효과로 분리한다.
각 효과에 [15개 공통 분해 축](#15개-공통-분해-축)을 대입해 현재 구조·강점·제약과 미정 항목을 정리하고 다른
환상체와 연결될 요소를 찾는다. 이 단계에서 전체 유물 목록을 한꺼번에 만들지 않는다.

### 2. 기초 태그를 만들고 파편에 적용한다

분해 결과에서 반복되는 특징을 찾고 위 기초 태그 초안을 개별 파편 효과에 붙여 공통점과 차이를 확인한다. 효과 태그, 발동 사건,
세부 속성과 변경 가능한 항목을 나누고, 원본 설계의 보류 사항은 그대로 남긴다.
전체 태그 목록을 먼저 동결하지 않고 다음 단계의 유물 설계와 함께 수정·확장한다.

### 3. 환상체 하나씩 깊게 설계한다

유물을 설계할 때마다 [검토 양식](#복사해서-사용하는-검토-양식)에 효과 흐름을 먼저 적고 개별 효과에
15개 축을 대입한다. 기존 흐름·분해표를 재사용하는 경우에도 원본 변경 여부와 이번에 바꿀 효과·축,
다른 단계·분기에 미치는 영향을 확인한다. 그 결과를 바탕으로 다음 질문을 검토한다.

- 어떤 능력치에 투자하면 강해지는가?
- 기존 효과에서 무엇을 증폭할 수 있는가?
- 어떤 상황에 전문화할 수 있는가?
- 어떤 효과를 연결하거나 사용 방식을 바꾸면 싸우는 방법이 달라지는가?
- 유물 없이도 원래 파편·장비의 역할이 완결되는가?

그 답을 바탕으로 대표 유물을 설계한다. 사용자는 엘리트부터 하나씩 검토하고 첫 대상으로 나무꾼을
선택했다. 느리고 강한 무기, 마지막 타격에 집중된 파편, 스킬 처치 회복과 흡혈을 검토한 뒤
첫 유물 `깊은 쐐기`의 구조를 합의했다. 후속 후보도 개별 설계 절에 합의·미정 상태를 구분해 기록한다.

2026-09-08 포큐버스 검토 후 사용자는 일반 보스 유물 설계를 먼저 진행하기로 했다. 문서 순서에 따라
`죽을 나비의 장례 → 녹아내리는 사랑 → 파고드는 천국 → 아무 것도 없는 → 웃는 시체의 산 → 탐욕의 왕`을
하나씩 검토한다. 녹아내리는 사랑은 탱커·딜러 파편을 나눠 본다. 무보상 원본 `죽은 나비들의 장례`는
알에서 부화한 아종의 파편·장비를 검토하며, 남은 엘리트의 유물을 설계 완료로 처리하지 않는다.

### 4. 몇 개를 만든 뒤 서로 비교한다

- 이름만 다르고 효과가 같은 유물이 반복되는지 확인한다.
- 특정 파편과 항상 같은 유물만 선택하게 되는지 확인한다.
- 범용 유물은 다른 환상체의 장비에서도 독립적으로 쓸 수 있는지, 전용 유물은 원본 고유 구조를
  활용하는 운용 변화가 있는지 확인한다.
- 모든 상황에서 이기는 조합보다 각각 잘하는 상황이 드러나는지 본다.
- 대표 유물의 실제 필요를 바탕으로 기초 태그를 수정·확장하고 정식 태그와 비호환 조건을 정리한다.

**“이 유물은 어떤 장비 두세 개에서 서로 다르게 재미있을까?”**를 주요 검토 질문으로 사용한다.
두세 개는 모든 유물의 필수 호환 개수가 아니라, 특정 세트만 정답이 되는 것을 줄이기 위한 질문이다.

개별 유물의 합의된 효과 구조와 희귀도는 위 설계 절에 기록한다. 아직 배정하지 않은 유물의 등급,
제작 수량·확정 수치, 정식 태그 ID·목록, 획득처와 출현 빈도는 후속 설계한다.
기초 태그 초안은 스킬·유물 적용 사례를 통해 다듬는다. 이번 문서는 대표 유물 설계를 시작할 공통
기준을 기록하며, 파편·장비의 보류 항목이나 공통 시스템의
구현 계약을 대신 확정하지 않는다.
