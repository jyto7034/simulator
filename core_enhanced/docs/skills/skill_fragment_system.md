# Skill Fragment System

## Purpose

이 문서는 스킬 파편의 게임 내 의미, 획득 구조, 장착/발동 방향, 그리고 특수 보스 격리 보상으로서의 정책을 정의한다.

기존 계약 문서들은 스킬 파편의 UI 장착, 정비, 강화, 개화, command payload를 다룬다. 이 문서는 그보다 상위의 게임 디자인 정책을 다룬다.

## Core Fantasy

스킬 파편은 단순한 스킬북이나 장비가 아니다.

스킬 파편은 격리된 존재의 힘을 일부 빌려 쓰는 매개체다. 보스 또는 특수 개체를 격리하는 데 성공하면 그 힘이 파편 형태로 봉인되고, 플레이어는 그 파편을 장착하거나 발동하여 전투에 이용한다.

따라서 강력한 스킬 파편일수록 다음 원칙을 가진다.

- 획득 과정이 특정 보스 또는 특수 사건과 연결된다.
- 획득은 “격리 성공”의 결과다.
- 발동은 강력하지만, 격리 실패 위험이나 부작용을 동반할 수 있다.
- 스킬 파편은 보상인 동시에 위험 자원이다.

## General Rules

- 일반 스킬 파편은 기존 Loadout/Maintenance 계약을 따른다.
- 스킬 파편은 직원의 고정 직업이 아니라 현재 장착 무기, 전투 프로필, 파편 호환성에 따라 장착 가능 여부가 결정된다.
- 강화는 파편 가루를 소비한다.
- 개화는 1차 정책에서 스킬 파편 전용 작업이다.
- 분쇄 시 파편 가루를 획득한다.
- 특수 보스 파편은 일반 파편보다 강한 발동 효과와 고유한 리스크 시스템을 가질 수 있다.

## Boss-Linked Fragments

일부 스킬 파편은 보스 클리어 보상으로 지급된다.

이때 “보스 클리어”는 단순 처치가 아니라 해당 존재를 격리하는 데 성공했다는 의미로 본다. 스킬 파편은 그 격리된 힘을 안전하지 않은 방식으로 빌려 쓰는 장치다.

보스 연동 파편은 `game_rulebook.md`의 끝없는 탐사 모드 정책 위에서 다음 구조를 권장한다.

1. 끝없는 탐사 모드에서 범용 `BossOmen` 정책에 따라 특정 보스 계열 징조 source가 등장한다.
2. 징조 source는 새 node로 추가되지 않고, live RON의 `source_kind`에 맞는 기존 Floor node 위에 덧씌워진다.
3. 초기 source kind는 `Event`와 `Combat`이다. Event source는 Event node 위에, Combat source는 일반 Combat node 위에 덧씌워진다.
4. 덧씌워진 노드는 기존 방 위치와 연결 구조를 유지하되, 표시와 source content가 보스 전조 성격으로 바뀐다.
5. 지원/상점/보상/본부연락 기반 전조는 보스별 특수 기믹이 필요할 때 별도 정책으로 추가한다.
6. 플레이어가 징조 source를 해결하면 해당 보스 체인이 확정되고, source가 정의한 효과/비용/위험/도박/진행도가 적용된다.
7. 같은 보스 계열 source 선택을 반복하면 숨은 조건 또는 보스별 진행도가 누적될 수 있다.
8. 조건이 완성되면 별도 동적 보스 방이 강제 생성되고 다음 노드 선택지가 잠길 수 있다.
9. 보스를 클리어하면 해당 보스 스킬 파편을 획득한다.
10. 획득한 파편은 매우 강력하지만, 전투 중 별도 실패 조건을 동반한다.

## WhiteNight Fragment

### Concept

`백야` 스킬 파편은 백야를 격리하는 데 성공한 결과로 얻는 특수 파편이다.

최종 보상 파편 id는 placeholder/흔적 파편과 분리한다. 현재 live RON은 백야 보스 격리 보상의 임시 콘텐츠로 `fragment_white_night_trace`를 사용한다. 백야 전용 보스 기믹과 최종 파편 효과가 확정되면 별도 최종 id로 교체한다. 권장 id는 `fragment_white_night_containment`다.

플레이어는 백야의 힘을 파편 형태로 빌려 쓰지만, 발동 중 통제에 실패하면 백야가 격리를 탈출하고 런이 실패한다.

### Run Scope

이 문서에서 `런`은 플레이어가 모드를 선택해 게임을 시작한 뒤, 클리어 또는 실패로 종료될 때까지의 전체 과정을 뜻한다.

백야 체인과 백야 파편의 사도화 진행도는 한 런에만 종속된다. 다른 런으로 이월되지 않는다.

일반 모드는 튜토리얼 성향의 짧은 모드이며, 구조상 백야를 격리해 최종 파편을 얻는 단계까지 도달하지 않는다. 백야 체인과 백야 파편 리스크는 끝없는 탐사 모드의 콘텐츠로 본다.

### Encounter Chain

백야 체인은 끝없는 탐사의 범용 `BossOmen` 정책 위에서 작동한다.

백야가 `provisional_boss`로 선정되면 현재 층에 백야 계열 징조 source가 1개 배치될 수 있다. 이 source는 새 노드로 추가되지 않고, BossOmen step의 `source_kind`에 맞는 기존 노드 위에 덧씌워진다. 백야 고해소/거짓 고해 구조는 Event source가 자연스럽지만, 최종 source kind는 live RON의 BossOmenChain step 정의가 결정한다.

이 source는 강제가 아닌 선택 대상이다. 플레이어는 다른 노드로 이동해 백야 징조를 피해갈 수 있다. 다만 플레이어가 백야 징조 source에 진입하고 효과 대상을 선택했다면, 그 결과는 되돌릴 수 없다.

첫 백야 징조 source를 무시하고 다음 층에 진입하면 provisional boss는 boss pool에 다시 push 예약되고 체인은 확정되지 않는다. 다음 층에서는 BossOmen 후보를 다시 roll한다. 현재 live data처럼 백야만 유일한 final-boss chain인 경우에는 같은 백야가 다시 나타날 수 있다.

진입 전 명시적 위험 경고는 제공하지 않는다. 맵에는 플레이어가 본 적 없는 `???` 성격의 미지 source로 나타날 수 있으며, 플레이어의 선택에 의해 진입한다.

백야 source는 처음에는 우호적인 치료/축복처럼 보인다. 플레이어가 진입하면 아군 유닛 중 한 명을 선택해 치료 또는 강한 긍정 효과를 받을 수 있다.

하지만 효과를 받은 유닛은 내부적으로 `잠재적 사도` 표식을 얻는다.

정책:

- 표식은 런 전체에 누적된다.
- 표식은 현재 생존자만 기준으로 하지 않는다.
- 사망했거나 교체된 유닛도 표식 기록에는 남는다.
- 표식은 서로 다른 유닛에게만 유효하게 적용된다.
- 이미 잠재적 사도 표식을 가진 유닛은 다시 카운트되지 않는다.
- 서로 다른 12명의 유닛에게 표식이 적용되면 조건이 완성된다.
- 사도화 순서는 표식 획득 순서를 따른다.
- 이 표식 목록은 백야 보스 방을 여는 `potential_apostle_marks`이며, 파편 사용 중 누적되는 사도화 진행도와 구분한다.

### Boss Room Trigger

잠재적 사도 표식이 12명에게 적용되면 다음 노드에 백야 보스 방이 즉시 생성된다.

정책:

- 다른 노드는 모두 잠긴다.
- 플레이어는 백야 보스 방에 진입해야 한다.
- 이 강제 진입은 플레이어가 백야 징조 source 선택을 누적한 결과로 발생한다.
- 백야 보스 방 진입 전에도 플레이어는 노드 진입 전 Safezone 상태에 있으므로, 기존 규칙대로 장비/스킬 파편 정비가 가능하다.

### Boss Clear Reward

백야 보스 방을 클리어하면 `백야 스킬 파편`을 획득한다.

서사적으로는 백야를 처치한 것이 아니라 격리한 것이다. 스킬 파편은 격리된 백야의 힘을 담은 봉인 매개체로 본다.

## WhiteNight Fragment Battle Effect

### Activation

백야 스킬 파편을 전투 중 발동하면 필드에 백야가 등장한다.

백야 스킬 파편은 한 전투 노드에서 한 번만 사용할 수 있다. 다른 전투 노드에서는 다시 사용할 수 있다.

백야는 즉시 모든 잠재적 사도를 변화시키지 않는다. 대신 일정 시간 간격을 두고 한 명씩 사도로 변질 또는 출현시킨다.

정책:

- 잠재적 사도 명단에 있는 유닛이 표식 획득 순서대로 순차 사도화된다.
- 이미 사망한 유닛, 전장에 배치되지 않은 유닛, 현재 전투에 없는 표식 대상도 사도 형태로 자동 생성되어 필드에 출현한다.
- 살아 있는 직원은 사도로 변신한다. 기존 직원이 죽고 별도 사도가 나타나는 것이 아니다.
- 사도는 매우 강력한 아군 전투 개체로 작동한다.
- 사도는 자동 배치되며, 플레이어가 직접 배치하거나 조작할 수 없다.
- 사도화는 전투를 빠르게 정리할 수 있는 강력한 힘이지만, 동시에 카운트다운이다.
- 사도화 완료 수는 같은 런 안에서 전투 노드를 넘어 이월된다.
- 다른 런으로는 이월되지 않는다.
- 예를 들어 첫 번째 스테이지에서 2명의 사도만 완성된 상태로 클리어했다면, 다음 스테이지에서 백야 파편을 다시 발동할 때 기존 2명은 즉시 사도 상태로 변환 또는 출현하고, 3번째 사도부터 타이머에 따라 진행된다.
- 따라서 백야 파편은 반복 사용할수록 런 실패에 가까워지는 위험 자원이다.
- 전투 종료 시 사도화 자체는 원래 직원 상태로 복구된다. 다만 전투 중 받은 사망, 트라우마, 피해 등은 일반 전투 결과 규칙을 따른다.

### Failure Condition

12명의 사도가 모두 변질 또는 출현하면 백야가 격리에서 탈출한다.

결과:

- 12명의 사도는 아군도 적군도 아닌 제3세력으로 판정된다.
- 12명의 사도는 먼저 남아 있는 적군을 섬멸한다.
- 적군을 모두 섬멸해도 스테이지는 클리어되지 않는다.
- 적군 섬멸 후 사도들은 남아 있는 아군을 섬멸한다.
- 아군 섬멸 후 즉시 런 실패로 처리한다.
- 실패 원인은 “백야 격리 실패”로 표시한다.

### Success Condition

12번째 사도가 완성되기 전에 현재 스테이지를 클리어하면 백야가 완전히 깨어나기 전에 재격리된다.

결과:

- 스테이지 클리어로 처리한다.
- 백야 스킬 파편은 유지된다.
- 사도화 완료 수는 같은 런 안에서 유지되고 다음 백야 파편 발동 시 이어진다.
- 런이 클리어 또는 실패로 종료되면 백야 사도화 진행도는 종료된 런과 함께 사라진다.
- 필요하다면 파편에 피로도, 쿨다운, 봉인 안정도 같은 장기 리스크를 추후 추가할 수 있다.

## UX Requirements

백야 체인은 완전한 함정으로만 느껴지면 안 된다.

초반 백야 징조 source는 플레이어에게 이득처럼 보이되, 반복될수록 UI와 텍스트가 불길하게 변할 수 있다. 단, 진입 전 경고나 명시적 위험 고지는 제공하지 않는다.

권장 UX:

- 1-3회: 유익한 치료/축복 노드처럼 보인다.
- 4-8회: 기록 문구, 화면 효과, 사운드가 점점 이상해진다.
- 9-11회: 노드 내부 연출과 결과 기록이 불길해질 수 있지만, 직접 경고는 하지 않는다.
- 12회: 다음 노드가 백야 보스 방으로 강제 고정된다.

전투 중 백야 파편 발동 시에는 내부 사도화 진행 정보를 플레이어에게 직접 보여주지 않는다.

숨기는 정보:

- 현재 사도화 수: `n / 12`
- 다음 사도화까지 남은 시간
- 잠재적 사도 명단 또는 남은 대상 수
- 12명 완성 시 런 실패로 이어진다는 직접 경고

플레이어는 자신의 유닛이 사도화되는 현상을 보고 백야 파편의 위험을 추론해야 한다. 관리자/디버그 UI에서는 내부 상태를 표시할 수 있다.

## Data Notes

아직 최종 DTO는 확정하지 않는다. 다만 구현 시 다음 데이터가 필요하다.

Run-level state:

- 백야 징조 source 진입 누적 여부
- 잠재적 사도 표식을 받은 유닛 id 목록
- 표식 적용 횟수
- 백야 보스 방 강제 생성 여부
- 백야 보스 클리어 여부
- 백야 파편으로 이미 완성된 사도 수
- 백야 파편을 현재 전투 노드에서 이미 사용했는지 여부

Combat state:

- 백야 파편 발동 여부
- 사도화된 유닛 목록
- 사도화 예정 목록
- 다음 사도화 타이머
- 사도화 완료 수
- 백야 격리 실패 여부
- 12사도 완성 후 제3세력화 여부
- 12사도 완성 후 적군 섬멸 단계인지 아군 섬멸 단계인지

Inventory/fragment state:

- 현재 live placeholder인 `fragment_white_night_trace`
- 백야 최종 파편 효과 확정 후 교체할 `fragment_white_night_containment` 같은 별도 최종 id
- 보스 격리 보상으로 지급되었는지 여부
- 발동 가능 조건
- 전투 중 실패 조건 metadata
