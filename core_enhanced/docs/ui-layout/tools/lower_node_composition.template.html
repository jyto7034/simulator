한 원정의 전투 횟수가 아닙니다. 전조 후보 방은 51개지만 실제로는 계열별·층별 첫 진입 방에만 배정합니다. 완료한 전조와 방문 경로에 따라 출현 수가 달라집니다. 최종방의 일반전은 해당 보스 격파 후에만 열리는 제안입니다.

‘전조 대상’ 평균을 모든 행에 적용해 합산하지 않습니다. 최종방은 일반 추첨 대신 여섯 활동의 역할을 고정합니다. 일반 보스·전조·엘리트·이벤트 및 보상의 전투는 일반 침식전 수와 별도로 셉니다.

최종방의 진행 제안

방 진입 · 지원 선택 이용→보스 도전→승리 후 Gate 귀환
또는 일반전 3개와 보상 1개의 선택 갈래

후속 탐사는 ‘일반전 1 → 일반전 2 → 보상’과 ‘일반전 3’ 갈래로 나눕니다. 각 활동에서 귀환 가능한 연결을 두고, 미이용한 준비 지원으로 돌아갈 길을 유지합니다. 공개 최종방은 8층에서 상층으로 올라갈 수 없습니다. 흉탄 방은 같은 6층의 마탄 방으로 돌아가 기존 탐사를 이어갈 수 있습니다.

심층에서 달라지는 조건

4층은 일반 채용의 마지막 층입니다. 5층 이후 본사 연락은 응급지원·상점 등 기존 기능을 유지합니다. 심포니 진행이 없는 채 중앙본부동 4층에 들어왔다면 4~7층의 네 기회를 모두 완료해야 오케스트라에 접근할 수 있습니다. 흉탄은 공개 최종보스 세 종의 영구 격파 기록과 이번 원정 마탄 완료가 필요합니다.

방 규모·활동 비중·후속 탐사 배치는 검토값입니다. 실제 방문량과 전장 재사용 수는 방 내부 연결과 원정 경로를 작성한 뒤 계산합니다.
