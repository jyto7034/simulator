작은 방: 3~7층의 6개 방에 저장 1개와 지원 총수 2개가 들어가면 나머지 3개는 전부 일반전입니다. 다른 활동도 담을 거점이라면 9개 이상을 검토합니다.

큰 방: 지원을 구역마다 하나씩 보장하지 않습니다. 이벤트·보상 기회를 여러 구역에 나누되, 실제 위치는 방별 템플릿을 배정한 뒤 정합니다.

보상: 노드 수가 무료 유물 수를 뜻하지 않습니다. 보상 다섯 유형의 비중과 재화 공급은 후속 조정 대상입니다.
