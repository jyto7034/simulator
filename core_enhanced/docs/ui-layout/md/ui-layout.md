# 장면별 UI 설계

이 문서는 각 장면의 레이아웃, 표시 정보, 상호작용과 전환 규칙을 정리한다. 장면별 이미지는 시각적 참고 자료이며, 이미지와 명세가 다르면 이 문서의 확정 사항을 우선한다. 추가 제안과 미정 항목은 구현 확정 사항으로 취급하지 않는다.

작성일: 2026-09-11. 전투 장면 상호작용 추가: 2026-09-13. 휴식·지도·전투 장면을 순차적으로 정리한다. 문서에 규칙을 기록한 것과 Unity·백엔드에 구현한 것은 구분한다. 미정 사항을 하나씩 확인하는 진행 목록은 7절에서 관리한다.

## 1. 휴식 메인

### 1.1 목적과 기본 상태 — 확정

휴식 메인은 직원들이 쉬는 공간을 살피고, 대사 확인, 로드아웃 확인, 편성 순서 지정, 가방 사용 및 지도 이동을 시작하는 화면이다. 준비 버튼으로 이 장면을 표시한다.

- 기본 진입 시 가방 UI는 닫혀 있다.
- 하나의 배경 안에 최대 8명의 직원이 모두 보이도록 배치한다.
- 기존의 좌우 슬라이드에 의한 화면 이동 기능은 제거한다. 화면 밖의 직원을 찾기 위해 카메라를 이동할 필요가 없어야 한다.
- 좌우 이동 화살표를 표시하지 않는다.
- 이전의 ‘한 화면에 4~5명만 표시하고 나머지는 좌우 이동으로 확인’하는 구상은 사용하지 않는다.
- 참고 이미지에는 5명이 보이지만, 최종 휴식 메인의 배치는 최대 8명 기준으로 검증해야 한다.

수동 좌우 이동 제거는 휴식 메인 탐색에 대한 규칙이다. 기존에 논의한 로드아웃 진입 시 직원 포커스와 확대 연출은 별도의 장면 전환 규칙으로 다룬다.

### 1.2 배경과 직원 배치 — 확정

- 모닥불 또는 랜턴을 중앙에 둔 폐허의 휴식 공간이다. 참고 이미지의 산업 시설 분위기를 시각적 기준으로 삼는다.
- 직원은 각자의 위치에서 앉기, 기대기 등의 휴식·대기 동작을 한다.
- 인물은 기존 시안의 SD 스타일을 따른다.
- 8명 모두 식별하고 클릭할 수 있도록 인물 간 간격과 앞뒤 배치를 확보한다. 얼굴과 클릭 영역이 다른 직원이나 고정 UI에 가려지지 않도록 한다.
- 배낭이 닫힌 기본 상태에서는 오른쪽까지 시설 배경과 직원 공간으로 사용한다.

#### 직원 상태 요약 — 확정

각 캐릭터 아래에는 이름만 표시하는 대신 다음 세 정보를 항상 표시한다. 마우스를 올리거나 로드아웃을 열지 않아도 전체 직원의 상태를 한 번에 확인할 수 있어야 한다.

| 순서 | 정보          | 표시 규칙                                                                    |
| ---- | ------------- | ---------------------------------------------------------------------------- |
| 1    | 이름          | 해당 직원의 이름                                                             |
| 2    | 부상 단계     | `정상`, `경상`, `중상`, `치명상`, `가사상태`, `사망` 중 해당하는 하나만 표시 |
| 3    | 트라우마 수치 | `트라우마 12`처럼 항목명과 현재 수치를 간결하게 표시                         |

- 출전할 수 없는 직원에게만 작은 아이콘과 `출전 불가` 문구를 추가한다. 출전 가능한 직원에게는 별도 문구를 반복 표시하지 않는다.
- 부상 단계는 텍스트와 색으로 구분하되, 색만으로 상태를 전달하지 않는다. 구체적인 단계별 색상은 후속 조정한다.
- 이름은 밝게, 나머지 정보는 작은 글자로 정돈한다. 가독성을 위한 얕은 먹 음영을 깔되 큰 외곽 프레임은 사용하지 않는다.
- 직원 8명과 각 요약이 모두 보이도록 배치하고, 얼굴·다른 직원·하단 버튼을 가리지 않게 한다. 머리 위 대사와 아래 상태 요약의 영역을 구분한다.
- 부상 단계의 판정 기준과 출전 가능 여부는 게임 상태를 따른다. 이 UI 명세에서 새 수치 기준을 만들거나 특정 부상 단계만으로 출전 불가를 단정하지 않는다.

[상태 요약 수정 시안](휴식메인.png)은 기존 5명 구도에 표시 형태를 적용한 예시다. 표시된 수치·부상 단계·출전 불가 조합은 예시이며, 8명 배치와 단계별 색상 일관성은 후속 검증한다.

### 1.3 고정 UI — 확정

상단 위치 표시는 기존 화살촉처럼 꺾인 형태를 유지한다. 이는 이동 화살표가 아닌 상단 표시 영역의 외형이다.

#### 상단 재화 표시 — 2026-09-12 확정

- 모든 휴식 화면(메인, 가방 열림, 소모품 사용, 로드아웃, 편성)에서는 위치 표시 옆에 `엔케팔린`, `파편 가루`를 이 순서로 함께 표시한다. 각 항목은 아이콘·이름·현재 보유량으로 구성한다.
- **엔케팔린은 희귀 자원**, **파편 가루는 장비 강화에 사용하는 자원**이다. 파편 가루는 장착하는 스킬 파편과 별개이며, 아이콘도 구분한다.
- 기존 상단과 같은 높이의 간결한 재화 영역을 사용하고, 오른쪽 끝은 화살촉 형태로 마감한다. 편성·가방 등 오른쪽 위 조작부와 겹치지 않게 한다.
- 이미지의 `엔케팔린 140`, `파편 가루 480`은 표시 예시이며 초기 지급량이나 고정 수치가 아니다. 실제 UI는 현재 보유량을 표시한다.
- **지도에서는 기존 엔케팔린 표시 칸 전체를 제거한다.** 해당 자리에 다른 정보나 파편 가루를 넣지 않는다. 위치 제목의 화살촉은 유지하고, 제거한 칸의 자리에는 배경이 보인다. 이 규칙은 상단 보유량 표시에 관한 것으로 노드 미리보기의 예상 획득 표시는 별개다.

위 규칙으로 현재 참고 이미지 6장을 기존 파일명에 교체했다. 이전 생성 프롬프트의 상단 재화 지시보다 이 규칙과 [상단 수정 프롬프트 기록](상단-재화-수정-2026-09-12.prompt.md)을 우선한다.

왼쪽 아래에는 다음 세 버튼을 순서대로 모아 배치한다. 화면 전체를 가로지르는 하단 바는 사용하지 않는다.

| 버튼 | 동작                                                                                                                  |
| ---- | --------------------------------------------------------------------------------------------------------------------- |
| 설정 | 불러오기, 게임종료, 게임설정 메뉴를 연다. 게임설정에는 해상도 등 시스템 설정을 포함한다.                              |
| 지도 | 지도 장면을 표시한다. 레거시 지도 이미지의 시설 평면도, 노드와 연결 경로, 선택 지점 정보 표현을 시각적 참고로 삼는다. |
| 준비 | 중앙의 모닥불 또는 랜턴 주변에서 직원들이 쉬는 휴식 메인을 표시한다.                                                  |

오른쪽 위에는 `편성하기`, `가방` 버튼을 왼쪽부터 이 순서로 나란히 둔다. 가방은 편성하기의 바로 오른쪽에 위치하며 왼쪽 아래에는 중복 배치하지 않는다. 휴식 메인·가방 열림·소모품 드래그 상태에서 두 버튼의 화면 기준 위치와 크기는 동일하게 유지한다. 재화 바 끝에 붙이거나 배경의 슬라이드를 따라 이동시키지 않는다. 가방이 열린 동안의 표시와 입력 규칙은 2.1절을 따른다.

지도 이미지에 포함된 재화, 시간, 위험도, 노드 종류 및 진입 규칙 전체를 이번 문서로 확정하는 것은 아니다. 우측 노드 미리보기의 확정 규칙은 5절을 따르며, 나머지 지도 상세 설계는 별도로 정리한다.

2026-09-12 [지도 노드 선택 스케치 v1](지도-노드선택-스케치-v1.png)을 추가했다. 왼쪽 시설 평면도·경로와 오른쪽 선택 지점 정보·진입 버튼의 배치를 검토하는 시각 제안이다. 위험도·예상 획득·연결 관계는 예시이며 게임 규칙으로 확정하지 않는다. [생성 프롬프트](지도-노드선택-스케치-v1.prompt.md).

이후 시각 방향은 **휴식 공간 중앙의 상자 겸 테이블 위에 펼친 실제 지도를 내려다보는 구도**로 수정했다. 테이블 모서리에는 랜턴 하나가 놓여 지도를 비추고, 오른쪽 노드 미리보기는 큰 외곽 프레임 없이 먹 음영 위에 표시한다. 상단 화살촉과 왼쪽 아래 고정 버튼은 유지한다. [테이블·랜턴 수정 시안](지도-테이블-랜턴-v1.png), [생성 프롬프트](지도-테이블-랜턴-v1.prompt.md).

지도 위 노드는 **장소 사진이나 아이콘·이름이 인쇄된 작은 종이 카드와 메모를 압정으로 고정한 형태**로 표현한다. 압정 사이를 빨강·파랑 등의 보풀 있는 색실로 연결해 수사 보드에 조사 자료를 붙여둔 느낌을 낸다. 금속 노드 토큰과 발광 경로는 사용하지 않는다. 종이의 들뜬 가장자리와 실의 접촉 그림자는 랜턴 조명에 맞춘다. 오른쪽 먹 UI와 고정 버튼은 유지한다. [종이 카드·색실 수정 시안](지도-종이카드-색실-v1.png), [생성 프롬프트](지도-종이카드-색실-v1.prompt.md). 이전 금속 표식 시안의 재질 방향을 대체하며, 실 색상의 상태별 의미는 상세 설계에서 정한다.

### 1.4 직원 상호작용 — 확정

| 입력               | 결과                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------- |
| 캐릭터 short-click | 해당 캐릭터의 머리 위에 대사가 나지막하게 나타난다.                                    |
| 캐릭터 long-click  | 해당 캐릭터의 로드아웃 UI가 나타난다. [휴식로드아웃.png](휴식로드아웃.png)를 참고한다. |

대사는 캐릭터 위에 작고 절제된 텍스트로 표현한다. 구체적인 표시 시간, 문장 길이, 음성 동반 여부는 아직 정하지 않았다.

#### 직원 상호작용 피드백 — 확정

휴식 메인의 일반 상태에 다음 세 가지 피드백을 적용한다.

| 피드백                 | 동작                                                                                                                                                                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 캐릭터에 마우스 올리기 | 은은한 윤곽선과 기존 상태 요약의 이름 강조로 가리키는 직원을 표시한다. 이름을 별도로 중복 표시하지 않는다. 잠시 머물면 `클릭: 대화 · 길게 누르기: 장비 확인` 안내를 표시한다. 마우스가 벗어나면 호버 강조와 안내만 해제하고 상태 요약은 유지한다. |
| 길게 누르는 중 피드백  | 누르고 있는 동안 작은 진행 표시로 로드아웃이 열릴 시점을 알려준다. 중간에 손을 떼거나 대상에서 벗어나면 길게 누르기 진행을 취소하고 표시를 지운다. 일반적인 짧은 클릭은 위의 short-click 규칙을 따른다.                                           |
| 클릭에 작은 반응       | short-click으로 대사가 나타날 때 캐릭터가 고개를 들거나 시선을 돌리는 등의 작은 반응을 보인다. 휴식 자세와 분위기를 유지하며 입력에 반응했음을 전달한다.                                                                                          |

호버 안내 지연 시간, 진행 표시의 형태와 long-click 판정 시간, 캐릭터별 반응 모션의 구체적인 종류와 길이는 후속 조정한다. 편성 상태의 입력과 피드백은 별도의 편성 장면 설계에서 다룬다.

### 1.5 편성하기 — 확정

편성은 직원 전원을 순서대로 선택하는 방식이다. 2026-09-12 전원 선택 필수 규칙을 확정하고 [편성 시안](휴식-편성-전원선택-v1.png)을 추가했다. 순번 배지와 버튼 배치 등 구체적인 표현은 시안 검토 대상으로 둔다.

1. `편성하기`를 누르면 편성 모드에 들어간다. 가방이 열려 있으면 가방을 닫고 휴식 전체 구도로 복귀하며 편성 모드로 전환한다. 소모품 드래그 중에는 이 버튼 입력을 차단한다.
2. 각 캐릭터의 테두리가 붉은색으로 하이라이트된다.
3. 캐릭터를 클릭하면 테두리가 초록색으로 변한다. 초록색은 선택되었음을 뜻한다.
4. 편성 대상 직원 전원을 선택해야 완료할 수 있다. 8명이면 8명 모두, 인원이 더 적으면 해당 인원 모두의 순서를 지정한다. 일부만 선택한 채 완료하거나 미선택 직원을 자동으로 뒤에 붙이지 않는다.
5. 완성된 선택 순서를 저장하고 전투 화면 오른쪽 아래 로스터의 각 섹션 내부 표시 순서에 적용한다. 전투 로스터는 배치·미배치 섹션으로 나누며 상세 규칙은 6.1절을 따른다.

예를 들어 처음 세 명을 `브린 → 에이다 → 디아` 순서로 선택했다면 나머지 직원도 이어서 모두 선택해야 한다. 이 동작은 전원에 대한 로스터 순서 지정이며 전투 중 자동 배치 순서로 해석하지 않는다. 전원 선택은 한 번에 순서를 만드는 ‘전체 선택’ 버튼을 뜻하지 않는다.

시안은 8명 중 5명을 선택한 상태다. 초록 테두리와 순번 1~5, 미선택 3명의 붉은 테두리, `선택 5 / 8`, 비활성 `완료` 버튼으로 진행 상황을 표현했다. 전원 선택 후에만 완료할 수 있다는 원칙은 확정이며, 재클릭 해제와 취소 등의 세부 조작은 후속 정리한다. [생성 프롬프트](휴식-편성-전원선택-v1.prompt.md).

### 1.6 가방 — 확정

`가방` 버튼을 누르면 가방 UI가 나타난다. 시각적 참고는 [휴식가방.png](휴식가방.png)이다. 큰 외곽 프레임 대신 먹 질감의 부드러운 음영을 사용하는 공통 방향을 따르며, 슬롯 내부 테두리는 사용할 수 있다.

가방의 항목 구성, 아이템 사용과 닫기 동작은 2절을 따른다. 가방을 열고 닫을 때에는 휴식 화면이 좌우로 슬라이드하는 전환을 사용한다. 이는 버튼 조작에 따른 자동 전환이며, 휴식 메인에서 자유롭게 드래그하는 수동 카메라 탐색과 구분한다.

### 1.7 추가 제안 — 미확정

다음은 확정 사항을 보완하기 위한 제안이며, 채택 여부는 별도로 결정한다.

- **편성 순번 표시:** 초록색 테두리와 함께 `1, 2, 3…` 숫자를 표시한다. 색은 선택 여부를, 숫자는 저장할 순서를 보여준다.
- **편성 완료·취소:** 편성 모드에 완료와 취소 동작을 둔다. 완료 시 변경 순서를 반영하고 취소 시 기존 순서를 유지한다.
- **입력 분리:** 일반 상태에서는 short-click과 long-click을 구분하고, long-click이 성립한 뒤 손을 뗄 때 대사가 추가로 나오지 않도록 한다. 편성 모드에서는 클릭을 편성 선택에 사용하고 대사·로드아웃 진입은 잠시 막는다.
- **대사 가독성:** 짧은 대사를 잠시 표시한 뒤 사라지게 하고, 큰 대화창 대신 절제된 글자와 그림자를 사용한다.
- **고정 배치:** 8개의 휴식 위치를 앞뒤로 엇갈리게 설계한다. 직원 수가 줄어도 인물 크기를 과도하게 키우지 않고 공간의 안정감을 유지한다.

### 1.9 구현 확인 기준

- 직원 1~8명에서 수동 카메라 이동 없이 모든 직원을 확인하고 선택할 수 있다.
- 왼쪽 아래에는 설정·지도·준비만, 오른쪽 위에는 편성하기·가방이 이 순서로 표시된다.
- 기본 화면에서 가방은 닫혀 있고, 좌우 이동 화살표가 없다.
- 각 직원 아래에 이름·부상 단계·트라우마 수치가 항상 보이고, 출전 불가인 직원에게만 추가 표시가 나타난다.
- short-click은 머리 위 대사, long-click은 해당 직원의 로드아웃으로 연결된다.
- 마우스를 올리면 해당 직원의 은은한 윤곽선과 이름이 표시되고, 잠시 머물면 조작 안내가 나타난다.
- 길게 누르는 동안 진행 표시가 나타나고, 중간에 손을 떼거나 대상에서 벗어나면 진행 표시가 해제된다.
- short-click으로 대사가 나타날 때 해당 직원이 작은 반응 모션을 보인다.
- 편성 모드 진입 시 붉은 테두리, 선택 시 초록 테두리가 표시된다.
- 확정된 저장 규칙에 따라 선택 순서가 전투 오른쪽 아래 로스터에 반영된다.
- 화면비 변경 시 인물, 대사, 버튼의 가림과 클릭 영역 충돌을 확인한다.

위 항목은 향후 구현 검증 기준이며, 현재 통과했다는 의미가 아니다.

## 2. 휴식 가방 — 상호작용·연출 확정

초안에서 열기·닫기를 휴식 화면의 좌우 슬라이드 전환으로 수정하고, 나머지 상호작용과 연출은 채택했다. 세부 시간·이동 거리와 화면 배치는 후속 검증한다. 편성 장면은 별도로 설계한다.

### 2.1 역할과 화면 구성

가방은 휴식 공간 위에서 보유 물품을 확인하고, 직원에게 소모품을 사용하는 UI다. 장비·파편·유물은 가방에서 내용을 확인하고 실제 장착 변경은 해당 직원의 로드아웃에서 진행한다.

- 오른쪽에 가방, 왼쪽과 중앙에 휴식 중인 직원과 상태 요약을 표시한다.
- 가방은 큰 외곽 테두리 없이 먹 질감의 부드러운 음영 위에 표시한다. 슬롯 내부 테두리는 유지한다.
- 상단에는 분류 탭, 중앙에는 아이템 격자, 하단에는 선택한 아이템의 이름·효과·사용 조건을 표시한다.
- 분류는 `소모품 / 무기 / 방어구 / 액세서리 / 파편 / 유물`로 구성한다. 기존 휴식가방 이미지의 분류와 상태 라벨은 최신 명세에 맞춰 수정해야 한다.
- `편성하기`, `가방`은 휴식 메인과 같은 화면 기준 우측 상단 위치·크기로 고정한다. 가방 제목과 분류 탭은 이 조작부 아래에 간격을 두고 배치한다. 재화 바와도 겹치지 않는다.

#### 우측 상단 버튼 상태 — 2026-09-12 확정

| 상태 | 편성하기 | 가방 |
| --- | --- | --- |
| 일반 휴식 | 기본 테두리, 입력 가능 | 기본 테두리, 누르면 열림 |
| 가방 열림 | 기본 테두리, 누르면 가방을 닫고 편성으로 전환 | 파란 테두리로 열린 상태 표시, 다시 누르면 닫힘 |
| 소모품 드래그 중 | 위치·크기 유지, 일시 입력 차단 | 위치·크기와 파란 활성 테두리 유지, 일시 입력 차단 |

- 소모품 드래그 중에는 두 버튼의 아이콘·글자를 조금 흐리게 표시하되 읽을 수 있게 유지한다. 가방의 파란 테두리는 가방이 열려 있다는 상태 표시이며, 드래그 중 입력 가능을 뜻하지 않는다.
- 드래그가 끝나거나 취소되면 버튼을 일반 가방 열림 상태로 복원한다. 차단 중 버튼 위에서 놓으면 아이템 사용만 취소하며, 가방 닫기나 편성 전환을 함께 실행하지 않는다.
- 드래그 중 우클릭 또는 Esc는 드래그만 취소한다. 이후 Esc를 다시 누르거나 가방 버튼을 누르면 가방이 닫힌다.
- 이 두 버튼 규칙은 휴식 메인과 가방 상태에 적용한다. 로드아웃의 포커스 해제 및 편성 모드 자체의 취소·완료 조작은 각 절의 별도 규칙을 유지한다.

수정 시안: [휴식 가방](휴식-가방.png), [소모품 드래그 중](휴식-가방-소모품사용.png). 두 이미지는 기존 파일명으로 교체했으며 [버튼 수정 프롬프트](가방-상단버튼-수정-2026-09-12.prompt.md)를 기록했다. 이번 수정은 버튼 배치와 상태 표현에 대한 것으로, 이전 가방 시안의 분류·직원 상태 라벨은 위 명세를 우선한다.

#### 가방의 장착 중 아이템 표시

- 장착 중인 아이템도 가방 목록에 표시한다. 해당 아이템 슬롯 **테두리의 오른쪽 위에 현재 장착 중인 유닛의 작은 초상화**를 붙인다.
- 현재 포커스한 유닛이 아니라 그 아이템을 실제로 장착한 유닛의 초상화를 표시한다. 미장착 아이템에는 초상화를 표시하지 않는다.
- 초상화는 아이템 본체와 수량을 가리지 않게 배치하고, 장착·교체·해제 결과에 맞춰 갱신한다. 해제 시 같은 아이템 항목에서 초상화가 사라지며 항목을 중복 생성하지 않는다.
- 휴식 가방과 로드아웃 가방에 같은 규칙을 적용한다. 초상화는 장착자 표시이며 별도 클릭 동작은 정하지 않는다.

가방을 열 때 휴식 화면이 왼쪽으로 부드럽게 슬라이드하며 오른쪽 가방 공간을 확보한다. 닫을 때에는 오른쪽으로 슬라이드하여 원래 구도로 복귀한다. 직원이 실제로 자리를 옮기는 연출 없이 배경과 직원이 함께 이동하며, 직원 간 상대적인 위치를 유지한다. 상단 표시와 고정 버튼은 화면 이동을 따라가지 않는다. 기존 초안의 자동 축소 중심 전환은 이 슬라이드 방식으로 대체한다.

가방이 열린 상태에서도 직원 8명을 확인하고 아이템 사용 대상으로 지정할 수 있어야 한다. 단순히 화면을 밀어 가장자리 직원을 잘라내지 않도록 이동 거리·배경 여백·가방 폭을 함께 검증한다. 현 시안만으로 8명 배치가 검증된 것은 아니다. 기본 휴식 화면의 수동 좌우 탐색은 계속 사용하지 않는다.

### 2.2 열기·탐색·닫기

| 입력 / 상황            | 동작                                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 가방 버튼 클릭         | 휴식 화면이 왼쪽으로 슬라이드하면서 오른쪽 먹 음영과 가방 UI가 나타난다. 조작을 오래 기다리게 하는 연출은 피한다.     |
| 분류 탭 클릭           | 해당 분류의 물품으로 전환한다. 선택 탭은 밑줄 등으로 표시한다.                                                        |
| 아이템에 마우스 올리기 | 슬롯 테두리를 은은하게 강조한다. 클릭해서 고정한 상세 설명은 호버만으로 바꾸지 않는다.                                |
| 아이템 short-click     | 아이템을 선택하고 하단에 설명을 표시한다. 클릭만으로 소모하거나 장착하지 않는다.                                      |
| 격자 안에서 마우스 휠  | 가방 목록만 스크롤한다. 휴식 공간은 움직이지 않는다.                                                                  |
| 가방 버튼 재클릭 / Esc | 가방이 사라지면서 휴식 화면이 오른쪽으로 슬라이드해 원래 구도로 돌아간다. 단, 드래그 중 가방 버튼은 입력을 차단하고 Esc는 먼저 드래그만 취소한다. |
| 가방이 열린 상태에서 편성하기 | 가방을 닫고 휴식 전체 구도로 복귀하며 편성 모드로 전환한다. 소모품 드래그 중에는 실행하지 않는다. |

같은 휴식 구간에서 다시 열면 마지막 분류와 스크롤 위치를 기억한다. 남아 있는 아이템이면 선택도 유지한다. 빈 분류에는 작은 안내 문구를 표시한다.

### 2.3 소모품 드래그 사용

1. 소모품을 드래그하면 아이콘이 커서를 따라오고, 원래 슬롯은 현재 집고 있는 물품임을 은은하게 표시한다. 수량은 아직 줄이지 않는다.
2. 사용 가능한 직원은 약한 윤곽선으로 표시한다. 모든 직원의 상태 요약은 계속 보인다.
3. 직원 위에 올리면 해당 대상의 윤곽선을 조금 더 강조한다. 효과를 신뢰할 수 있게 계산할 수 있는 경우에만 `트라우마 38 → 28` 같은 적용 예상치를 기존 상태 옆에 잠시 표시한다. 알 수 없는 결과를 확정 수치처럼 표시하지 않는다.
4. 사용할 수 없는 대상 위에서는 금지 표시와 짧은 사유를 보여준다. 사유는 실제 아이템 사용 조건에 따른다. 출전 불가라는 이유만으로 치료 대상에서도 제외하지 않는다.
5. 유효한 직원 위에 놓으면 그 직원에 대한 사용을 요청한다. 기본 소모품은 별도 확인창 없이 드롭으로 사용한다.
6. 처리 중에는 같은 동작의 중복 사용을 막는다. 성공이 확인된 뒤 수량과 상태 요약을 갱신하고 사용 연출을 재생한다. 실패 시 물품을 유지하고 짧은 사유를 알린다.

직원이 아닌 바닥이나 가방 안에 놓거나, 사용할 수 없는 직원에게 놓으면 사용하지 않고 원래 슬롯으로 돌려보낸다. 드래그 중 우클릭 또는 Esc로도 취소할 수 있게 한다. 바닥에 놓는 동작을 아이템 버리기로 해석하지 않는다.

### 2.4 직원 입력과 구분

- 물품을 드래그하지 않을 때는 휴식 메인의 직원 호버·short-click 대사·long-click 로드아웃 동작을 유지한다. 아이템을 단순 선택해 설명을 보고 있다는 이유로 직원 클릭을 아이템 사용으로 바꾸지 않는다.
- 물품을 드래그하는 동안에는 대상 지정과 드롭만 처리한다. 직원 대사, 클릭 반응, long-click 진행은 발생시키지 않는다.
- 가방에서 로드아웃으로 들어갈 수 있지만, 포커스 해제 시에는 진입 전 가방 상태를 복원하지 않고 가방이 닫힌 휴식 메인으로 돌아온다. 로드아웃 작업 중 직원 전환에 따른 분류·스크롤 유지와는 구분한다.

### 2.5 사용 결과 연출

- 성공한 직원이 아이템에 맞는 작은 반응을 보이고, 해당 상태 값만 짧게 강조한다. 치료·안정 효과는 과도한 섬광이나 전투 이펙트 없이 표현한다.
- 변화량을 잠시 표시한 뒤 사라지게 하고, 상태 요약에는 적용 후 값을 남긴다. 부상 단계가 바뀌면 새 단계 문구로 갱신한다.
- 아이템 수량은 성공 결과에 맞춰 갱신한다. 마지막 한 개를 썼다면 해당 슬롯을 비우되, 연속 사용 중 다른 아이템이 갑자기 커서 아래로 당겨지지 않도록 목록 재배치 시점을 조정한다.
- 열기·선택·사용·취소에는 짧고 절제된 효과음을 사용한다. 반복 조작 시 소리가 과하게 겹치지 않게 한다.

### 2.6 후속 조정·검증 항목

- 열기·닫기 슬라이드의 시간·이동 거리, 직원 8명과 상태 요약의 가독성을 유지하는 배경 여백·가방 폭.
- 전환 중 버튼을 반복해서 누를 때의 동작과 이동 중인 직원에 대한 입력 처리.
- 아이템별 사용 조건과 예외 처리. 기본 사용 확정 방식은 유효한 대상에 드롭하는 것으로 정한다.
- 예상 효과를 표시할 수 있는 데이터 범위와 사용할 수 없는 대상의 사유 문구.

편성 피드백, 별도의 클릭 후 대상 선택 방식, 버리기, 자동 정렬 등의 기능은 이번 명세에 추가하지 않았다.

## 3. 휴식 로드아웃 — 상호작용·연출 확정

포커스 해제 시 가방을 복원하지 않으며 직원 전환 시 카메라가 빠르게 이동한다. 슬롯 선택은 정보 확인을 위한 단일 선택이다. 무기·방어구·액세서리는 가방 더블클릭으로 종류에 맞는 고정 슬롯에 장착하고, 유물은 선택한 유물 슬롯에 장착한다. 유닛 왼쪽 아래에는 전투 스탯을, 오른쪽 아래에는 이름·부상·트라우마를 표시한다. 이미지의 장비 효과와 수치는 예시이며, 이 문서는 게임 판정이나 콘텐츠 수치를 새로 정의하지 않는다.

### 3.1 화면 구성 — 기존 합의

직원을 long-click하면 그 직원을 포커스하고 로드아웃을 표시한다. 카메라가 이동·확대하여 선택 직원이 오른쪽 가방 영역을 제외한 공간의 중앙에 오도록 한다. 직원은 원래 휴식 위치에서 일어나 무기를 꺼내며, 화면 중앙까지 걸어오는 연출은 사용하지 않는다.

| 영역                                      | 구성                                                            |
| ----------------------------------------- | --------------------------------------------------------------- |
| 왼쪽                                      | 무기·방어구·액세서리 3슬롯과 선택한 장비의 능력치·효과 설명     |
| 중앙                                      | 포커스한 SD 직원과 무기 확인 자세                               |
| 유닛 왼쪽 다리 옆, 하단 초상 목록 바로 위 | 공격력·주문력·공격속도·방어력·치명타 등 유닛의 전투 스탯        |
| 유닛 오른쪽 아래                          | 이름·부상 단계·트라우마 수치, 해당할 때만 출전 불가 표시        |
| 중앙 오른쪽                               | 스킬 파편 1슬롯, 유물 3슬롯과 선택한 파편 또는 유물의 효과 설명 |
| 맨 오른쪽                                 | 가방 분류, 물품 목록, 선택한 가방 물품 설명                     |
| 하단                                      | 다른 직원으로 포커스를 바꾸는 직원 목록                         |

장착 슬롯은 총 7개다. 왼쪽 장비 설명과 오른쪽 파편·유물 설명은 동시에 유지한다. 유물 3개는 직원의 독립 장착 슬롯이며, 파편이나 무기의 부속 소켓처럼 연결하지 않는다.

UI 배경은 먹 질감의 부드러운 음영을 사용한다. 오른쪽 파편·유물과 가방은 하나의 연속된 음영 위에서 간격과 얇은 구분선으로 구별한다. 큰 외곽 프레임을 만들지 않고 내부 슬롯 테두리와 선택 강조를 사용한다.

### 3.2 진입·종료 연출

1. 직원 long-click이 성립하면 휴식 메인의 누르기 진행 표시와 대사 안내를 정리한다. 손을 뗄 때 short-click 대사가 중복 발생하지 않게 한다.
2. 카메라 이동·확대와 직원의 기립·무기 꺼내기를 겹쳐 진행한다. 두 연출이 끝나기를 차례대로 오래 기다리게 하지 않는다.
3. 카메라가 목표 구도에 가까워지면 양옆의 먹 음영, 슬롯, 설명과 하단 직원 목록을 짧게 나타낸다. 포커스 대상은 또렷하게, 나머지 직원은 배경에 자연스럽게 남긴다.
4. `포커스 해제` 또는 Esc로 종료하면 로드아웃과 가방 UI가 사라지고, 직원은 무기를 정리해 원래 휴식 자세로 돌아간다. 카메라는 가방이 닫힌 휴식 메인의 전체 구도로 복귀한다.

- 진입 전 가방의 열림 상태와 화면 상태는 포커스 해제 시 복원하지 않는다. 항상 가방이 닫힌 휴식 메인으로 돌아간다.
- 로드아웃 작업 중에는 오른쪽 가방을 표시한다. 가방만 따로 닫는 동작은 넣지 않는다.
- 왼쪽 아래는 시안처럼 `설정`, `포커스 해제`로 구성한다. 지도 이동과 편성은 휴식 메인으로 복귀한 뒤 진행한다.
- 무기가 없으면 맨손 장비 확인 자세를 사용한다. 기립할 수 없는 상태에는 적절한 대체 자세를 사용하며, UI를 열기 위해 가사상태·사망 직원을 일으키지 않는다. 해당 직원의 열람·장비 변경 가능 여부는 게임 규칙에 따른다.

### 3.3 슬롯 선택과 효과 확인

장비·스킬 파편·유물의 **장착 슬롯 7개를 통틀어 동시에 하나만 선택**할 수 있다. 최초 진입 시에는 선택 없이 모두 기본 테두리로 표시한다. 슬롯을 클릭하면 그 슬롯만 파란색 테두리가 되고 다른 슬롯의 선택은 해제된다. 슬롯 선택 하이라이트는 장착된 물품을 정보칸에서 확인하기 위해 유지한다.

| 입력 / 상황                          | 동작                                                                                                                                |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| 장착 슬롯에 마우스 올리기            | 기본 테두리의 밝기 등으로 은은하게 강조한다. 파란 선택 테두리를 추가하거나 현재 선택·설명을 바꾸지 않는다.                          |
| 왼쪽 장비 슬롯 클릭                  | 해당 슬롯만 파란 테두리로 선택하고 왼쪽에 이름·능력치·효과·조건을 표시한다. 오른쪽에 선택된 슬롯이 있었다면 선택 테두리는 해제한다. |
| 오른쪽 파편·유물 슬롯 클릭           | 해당 슬롯만 파란 테두리로 선택하고 오른쪽 설명을 변경한다. 왼쪽에 선택된 슬롯이 있었다면 선택 테두리는 해제한다.                    |
| 가방 물품 클릭                       | 가방 설명 영역에 후보 물품의 정보를 표시한다. 현재 장착품의 좌우 설명을 덮어쓰지 않는다.                                            |
| 가방의 무기·방어구·액세서리 더블클릭 | 장착 슬롯 선택 여부와 관계없이 아이템 종류에 맞는 고정 슬롯에 장착·교체한다.                                                        |
| 가방의 유물 더블클릭                 | 현재 선택한 유물 슬롯에 장착·교체한다. 유물 슬롯이 선택되어 있지 않으면 `유물 슬롯을 먼저 선택하세요.`를 짧게 표시한다.             |
| 빈 장착 슬롯 클릭                    | 슬롯 종류와 `미장착` 안내를 표시하고, 가방을 해당 분류로 전환한다.                                                                  |
| 설명이 영역보다 긴 경우              | 설명 영역 안에서만 스크롤한다. 캐릭터나 다른 UI 위로 설명을 늘이지 않는다.                                                          |

최초 진입 시 왼쪽은 무기, 오른쪽은 스킬 파편의 설명을 기본 표시한다. 빈 슬롯이어도 해당 분류의 안내를 보여준다. 기본 설명 표시는 슬롯 선택이 아니므로 파란 테두리를 표시하지 않는다. 좌우 설명 영역에는 마지막으로 확인한 정보를 유지할 수 있지만, 파란 선택 테두리를 양쪽에 동시에 남기지 않는다. 가방에서 선택한 후보와 현재 장착품을 각각 읽을 수 있게 하고, 능력치 변화 비교는 같은 종류의 슬롯 위에 드래그했을 때 표시한다.

설명용 선택과 별개의 두 번째 장착 대상 선택은 만들지 않는다. 현재 단일 선택이 유물 슬롯일 때 그 슬롯이 유물 더블클릭의 대상이다. 다른 장착 슬롯을 선택하면 이전 유물 슬롯을 숨은 장착 대상으로 유지하지 않는다. 가방 아이템 클릭은 장착 슬롯 선택을 해제하지 않는다.

### 3.4 장착·교체·해제

**더블클릭 장착과 교체**

- **무기·방어구·액세서리:** 가방 아이템을 더블클릭하면 현재 포커스한 유닛의 해당 종류 고정 슬롯에 바로 장착·교체한다. 슬롯을 먼저 클릭할 필요가 없다. 다른 종류의 슬롯이 정보 확인용으로 선택되어 있어도 장착 위치는 아이템 종류로 결정한다.
- **유물:** 유물 슬롯 3개 중 하나를 먼저 클릭한 다음 가방의 유물을 더블클릭하면 그 슬롯에 장착·교체한다. 유물 슬롯 미선택 또는 장비·파편 슬롯 선택 상태라면 `유물 슬롯을 먼저 선택하세요.`를 표시하고 실행하지 않는다. 빈 유물 슬롯을 임의로 찾거나 다른 유물을 임의 교체하지 않는다.
- **스킬 파편:** 이번 고정 슬롯 자동 장착 변경은 무기·방어구·액세서리에 대한 합의다. 파편의 더블클릭은 기존의 파편 슬롯 선선택 규칙을 유지하고, 고정 슬롯 자동 장착으로 통일할지는 후속 결정한다. 드래그앤드롭은 계속 가능하다.
- 이미 장착품이 있으면 기존 물품을 미장착 상태로 전환하고 새 물품을 장착한다. 가방 목록의 기존 물품 초상화를 제거하고 새 물품에 해당 유닛 초상화를 표시한다.
- 첫 클릭은 설명 선택, 더블클릭 판정은 장착·교체 요청 한 번으로 처리한다. 이 규칙은 소모품 사용이나 장착품의 더블클릭 해제를 추가하지 않는다.

**드래그앤드롭 장착과 교체**

1. 가방에서 물품을 집으면 아이콘이 커서를 따라오고, 현재 직원에게 장착 가능한 슬롯만 약하게 강조한다. 드롭 가능 표시는 기본 테두리의 밝기 등으로 표현하여 단일 파란 선택 테두리와 혼동하지 않게 한다.
2. 호환 슬롯 위에 올리면 해당 슬롯을 더 강조한다. 현재 장착품과 후보 이름, 신뢰할 수 있게 계산 가능한 능력치 변화, 주요 조건 변화를 해당 설명 영역에서 임시로 보여준다. 커서를 빼면 기존 설명으로 복원한다.
3. 유효한 슬롯에 놓으면 장착을 요청한다. 슬롯을 미리 클릭할 필요는 없다. 기존 물품은 미장착 상태로 전환하고 가방 목록의 장착자 초상화를 갱신한다. 더블클릭과 드래그앤드롭 모두 별도 확인창 없이 장착·교체를 요청한다.
4. 처리 중에는 관련 물품·슬롯의 중복 조작과 직원 전환을 잠시 막는다. 성공 후 슬롯·가방·효과 상태를 함께 갱신하고, 실패하면 기존 장착 상태를 유지하며 사유를 알린다. 교체 도중 기존 물품이 유실되거나 복제되는 중간 상태를 노출하지 않는다.

**해제와 취소**

- 장착 슬롯의 물품을 가방의 아이템 격자 영역으로 드래그하면 해제를 요청한다. 빈 칸을 정확히 맞출 필요 없이 격자 영역 전체를 해제 대상으로 강조한다.
- 현재 가방 분류와 다른 물품을 해제해도 동작한다. 성공하면 해당 분류로 전환해 돌아온 물품을 짧게 강조한다.
- 가방에 이미 보이던 장착품은 해제 후 같은 아이템 항목의 유닛 초상화만 제거한다. 물품을 새로 추가하거나 복제하지 않는다.
- 슬롯 클릭만으로는 해제하지 않는다. 바닥이나 호환되지 않는 슬롯에 놓으면 원위치로 돌아온다.
- 드래그 중 우클릭 또는 Esc는 드래그만 취소한다. 이때 로드아웃까지 동시에 닫지 않는다.
- 게임에서 실제로 해제를 제한하는 경우에만 그 사유를 표시한다. 이 문서에서 장착 필수 등의 제약을 새로 만들지 않는다.

유물은 3개 중 어느 슬롯에 넣을지 직접 선택한다. 다른 직원이 장착 중인 소유 물품의 이전은 기존 직원에서 해제한 뒤 새 직원에게 장착하는 흐름으로 진행하며, 자동으로 다른 직원의 장비를 빼오는 동작은 넣지 않는다. 다른 유물 슬롯 간 이동이나 기존 물품과의 직접 맞교환은 후속 결정한다.

### 3.5 장착 결과와 효과 상태

- 장착 성공 시 해당 슬롯에 짧은 강조와 절제된 효과음을 준다. 직원은 장비를 확인하는 작은 동작을 보인다.
- 장착 결과에 따라 가방 아이템 테두리 오른쪽 위의 장착자 초상화를 즉시 갱신한다. 다른 유닛이 장착 중인 물품도 그 유닛의 초상화로 구분한다. 초상화 표시 자체가 다른 유닛의 물품 자동 이전을 허용하는 것은 아니다.
- 무기 교체 시 확인 가능한 외형 리소스가 있으면 손에 든 무기와 대기 자세를 함께 바꾼다. 모든 방어구·액세서리가 반드시 외형을 바꾼다고 가정하지 않는다.
- 스킬 파편 설명에는 대표 스킬과 발동·대상 조건을, 유물 설명에는 효과와 현재 적용 여부를 표시한다. 모든 유물이 파편만 강화하는 것처럼 표현하지 않는다.
- 슬롯 종류 불일치와 `장착되어 있지만 효과 비활성`을 구분한다. 실제 게임 규칙에서 별도의 장착 불가 사유를 제공하는 경우에만 더블클릭·드롭 요청을 막고 사유를 표시한다. 직원별 장착 제한이 존재한다고 전제하거나 새 제한을 만들지 않는다. 효과 비활성은 슬롯의 물품을 유지하고 작은 비활성 표시와 조건 미충족 사유를 보여준다.
- 무기·파편 변경으로 유물의 효과 조건을 잃으면 유물을 자동 해제하지 않는다. 적용 상태와 설명을 갱신한다. 변경 전에 결과를 알 수 있으면 교체 미리보기에서 알려준다.
- 유닛 오른쪽 아래에는 이름·부상 단계·트라우마 수치를 표시하고 출전 불가일 때만 추가 표시한다. 시안의 `부상 0 / 6` 표기는 최신 단계 명칭으로 맞춘다.

#### 유닛 전투 스탯 — 왼쪽 아래

- 위치는 **캐릭터의 왼쪽 다리 옆, 하단 직원 초상 목록 바로 위**다. 화면 맨 왼쪽의 장비 설명 아래나 설정 버튼 위에 붙이지 않는다. 사용자 표시 이미지의 흰 박스는 위치 안내이며 실제 테두리 스타일이 아니다. [위치 수정 시안 v2](휴식로드아웃-전투스탯-v2.png)를 기준으로 한다. 교체 미리보기에서도 같은 위치를 유지한다.
- 유닛 왼쪽 아래에 공격력, 주문력, 공격속도, 방어력, 치명타 등 전투 스탯을 상시 표시한다. 개별 장비의 수치가 아니라 현재 직원의 장착 결과가 반영된 수치를 보여준다.
- 장비 자체의 능력치·효과 설명은 기존 왼쪽 장비 영역에 유지한다. 유닛 전투 스탯과 혼동되지 않도록 제목·간격으로 구분한다.
- 오른쪽 아래 상태 요약과 함께 인물 다리, 무기, 하단 직원 목록을 가리지 않도록 양옆에 배치한다. 두 영역 모두 절제된 먹 음영과 정돈된 글자를 사용한다.
- 장착·교체·해제 성공 시 유닛 스탯도 함께 갱신한다. 장착 전 예상치는 계산 가능한 경우에만 임시 비교로 표시하고 실제 적용값과 구분한다.
- 공격속도의 표시 단위, 치명타의 확률·피해 배율 구분과 추가 스탯 목록은 실제 데이터에 맞춰 후속 정리한다. 조건부 전투 효과를 근거 없이 상시 능력치에 합산하지 않는다.

### 3.6 하단 직원 전환

- 하단 직원 목록에 최대 8명의 초상과 이름을 표시하고, 현재 직원은 테두리로 강조한다. 이것은 열람 대상 선택이며 편성 순서를 수정하지 않는다.
- 다른 직원을 클릭하면 기존 직원은 휴식 자세로 돌아가고 새 직원이 장비 확인 자세를 취한다. 카메라는 새 직원의 원래 위치로 빠르게 이동해 같은 포커스 구도를 맞춘다. 부드러운 가감속을 적용하되 느린 감상용 이동으로 만들지 않는다.
- 가방의 분류와 스크롤은 유지한다. 좌우에 표시할 설명 종류도 가능하면 유지하되 설명과 호환 여부는 새 직원을 기준으로 다시 계산한다. 이전 직원의 효과나 수치를 남기지 않는다.
- 드래그 중에는 직원 전환을 실행하지 않는다. 빠른 연속 클릭 시 전환 연출을 여러 개 쌓지 않고 최종 선택 대상으로 정리한다.
- 직원이 바뀌면 장착 슬롯 선택과 파란 테두리는 해제한다. 유물 더블클릭 장착에는 새로 유물 슬롯을 선택해야 하지만 무기·방어구·액세서리는 즉시 더블클릭 장착할 수 있다. 왼쪽 아래 전투 스탯과 오른쪽 아래 상태 요약도 새 직원으로 함께 갱신한다. 가방의 장착자 초상화는 실제 장착자를 유지한다.

### 3.7 가방과 직원 입력

가방의 분류·클릭 설명·휠 스크롤·드래그 취소는 2절과 같은 규칙을 사용한다. 로드아웃에서 소모품을 사용할 때는 포커스한 직원만 드롭 대상으로 삼고, 배경의 다른 직원은 클릭·드롭 대상에서 제외한다. 다른 직원에게 사용하려면 하단 목록으로 포커스를 바꾸거나 포커스를 해제하고 휴식 메인에서 가방을 다시 연다.

장비·파편·유물은 해당 장착 슬롯에, 소모품은 직원에게 놓도록 대상 표시를 구분한다. 장착 물품을 직원 몸에 놓았다는 이유로 임의의 슬롯에 자동 장착하지 않는다.

### 3.8 후속 조정·검증 항목

- 단일 파란 선택 테두리와 호버·드롭 대상·성공 강조의 구별, 더블클릭 판정 시간과 안내문구 표시 시간.
- 스킬 파편 더블클릭을 고정 슬롯 자동 장착으로 통일할지.
- 가방 아이템 오른쪽 위 장착자 초상화의 크기·가독성과 아이템 아이콘·수량의 겹침 여부.
- 유닛 왼쪽 아래 전투 스탯과 오른쪽 아래 상태 요약, 긴 장비 효과·후보 비교의 가독성.
- 공격속도 단위, 치명타 세부 항목과 추가 전투 스탯 목록.
- 유물 슬롯끼리 이동·맞교환을 지원할지.
- 실제 장착·해제 제한의 존재 여부와 효과 비활성 사유 데이터. UI 설계만으로 제한을 가정하지 않는다.
- 무기 종류·직원 상태별 자세, 포커스 전환 시간, 화면 가장자리 직원과 최대 8명 목록의 배치.

이번 변경은 문서에 반영했으며 Unity 구현과 이미지에는 변경을 적용하지 않았다.

## 5. 지도 — 우측 노드 미리보기 규칙 확정

2026-09-12 합의 사항. 시각적 기준은 [종이 카드·색실 지도](지도-종이카드-색실-v1.png)이며, 이번 변경은 문서에만 반영한다.

### 5.1 고정 영역과 기본 대상

- 우측 노드 미리보기는 지도 장면에서 항상 표시되는 고정 UI다. 플레이어가 닫거나 숨길 수 없으며, 닫기·접기 버튼을 두지 않는다.
- 노드를 바꿔도 우측 영역의 위치와 기본 구조를 유지하고 대상에 해당하는 내용을 갱신한다. 기존의 먹 음영 표현을 따른다.
- 지도 진입 시 기본 표시 대상은 현재 자신이 서 있는 노드다.
- 게임의 첫 번째 노드는 시작 세이브포인트다. 첫 시작부터 이 세이브포인트를 현재 위치로 취급하고 그 정보를 표시한다. 방문 기록이 비어 있다는 이유로 미리보기를 비워두지 않는다.
- 현재 위치와 방문 기록은 구분한다. 이 표시 규칙 자체로 방문 완료나 보상 획득을 처리하지 않는다.

### 5.2 선택과 표시 유지

| 입력 / 상황 | 우측 표시 대상 |
| --- | --- |
| 게임 시작 후 첫 지도 진입 | 시작 세이브포인트 |
| 이후 지도 진입 | 현재 서 있는 노드 |
| 다른 노드 클릭 | 클릭한 노드 |
| 현재 위치 노드 클릭 | 현재 서 있는 노드 |
| 노드 클릭 후 추가 입력 없음 | 클릭한 노드 정보를 계속 유지 |
| 지도 빈 공간 클릭 | 현재 표시 대상 유지 |
| 지도에서 나갔다 다시 진입 | 이전 미리보기 선택을 초기화하고 현재 위치 표시 |

- ‘입력이 없으면 현재 위치’는 지도 진입 시의 기본값을 뜻한다. 일정 시간 입력이 없다고 현재 위치로 자동 복귀하지 않는다.
- 노드를 클릭하는 것은 정보 열람 대상 선택이다. 클릭만으로 실제 현재 위치를 바꾸거나 이동을 실행하지 않는다.

### 5.3 노드 상태별 내용과 진입 버튼

| 대상 상태 | 표시 정보 | 진입 버튼 |
| --- | --- | --- |
| 현재 위치 | 장소 이미지·이름·종류·설명과 `현재 위치` 표시 | 비활성화 |
| 이동 가능한 다른 노드 | 해당 노드의 공개된 정보 | 활성화 |
| 이동 불가능한 다른 노드 | 확인 가능한 정보와 이동 불가 사유 | 비활성화 |
| 미확인 노드 | `미확인` 표시와 공개 범위에 해당하는 제한된 정보 | 실제 이동 가능 여부에 따라 활성화 또는 비활성화 |

- 정보 공개 여부와 이동 가능 여부는 구분한다. 미확인이라는 이유만으로 이동 가능·불가를 새로 단정하지 않는다. 공개되지 않은 장소 이미지·정체·위험·보상을 미리보기에서 노출하지 않는다.
- 진입 버튼 영역은 유지하고, 비활성 상태에서는 진입을 실행하지 않는다. 이동 가능 여부와 사유는 실제 게임 상태를 따른다.
- 시작 세이브포인트도 현재 위치와 같은 표시 규칙을 적용한다. 장소 설명은 이곳이 출발 지점임을 전달하며, `현재 위치` 표시와 비활성 진입 버튼을 함께 보여준다. 설명의 최종 문구는 후속 작성한다.
- 구체적인 노드 정보 공개 범위, 이동 가능 조건, 진입 이후 절차와 위험·보상 수치는 별도 게임 규칙으로 정한다. 이 절은 해당 정보를 우측 UI에 표시하는 기준을 확정한다.

## 6. 전투 — 기본 화면·유닛 포커스와 상호작용

2026-09-13 정리. 전투 기본과 유닛 포커스 두 대표 이미지를 시각 기준으로 사용한다. **교대·이동·배치 등 기능별 세부 상태는 추가 이미지 대신 이 절의 과정과 결과로 정의한다.**

이 절에서 ‘확정’은 사용자와 합의한 UI 방향, ‘현행 룰북’은 현재 게임 규칙, ‘조작 초안’은 아직 세부 입력을 확정하지 않은 제안을 뜻한다. 신규 합의인 태세 무관 이동·교대와 성공 후 강제 방어는 현행 백엔드와 차이가 있으므로 6.7·6.8절의 변경 요구를 함께 적용해야 한다. 문서 작성 자체는 코드 구현이나 백엔드 룰북 수정이 아니다.

**현재 논의 범위 — B21 후속 지시:** 화면·입력·연출에 집중한다. 아래의 현행 룰북·백엔드 변경 설명은 기존 논의의 참고 기록이며, 사용자에게 내부 상태 모델이나 명령 계약을 정하도록 요구하지 않는다. 특히 작업을 내부적으로 방어 모드로 판정할지 별도 작업 모드로 판정할지는 미정이다. 화면에 보이는 작업 연출과 내부 상태 분류를 구분한다.

### 6.1 화면 구성과 표시 — 확정

#### 로스터의 두 섹션 — 2026-09-13 추가 확정

- 전투 기본·포커스 모두 로스터를 **좌측: 배치된 유닛 / 우측: 미배치 유닛** 두 섹션으로 나눈다. 두 섹션 사이에 작은 여백을 두어 구분하며 별도 큰 외곽 패널을 추가하지 않는다.
- 두 섹션은 각각 저장된 편성 순서에서 해당 상태의 유닛만 추려 표시한다. 배치된 시간·철수한 순서·전장 위치로 정렬하지 않고, 섹션 이동으로 원래 편성 순서를 다시 저장하지 않는다.
- 예: 편성 `A → B → C → D`에서 A·C가 배치되어 있으면 `A C  /  B D`로 표시한다. 이후 B가 배치되면 `A B C  /  D`, 그 상태에서 A가 철수하면 `B C  /  A D`가 된다. `/`는 설명용 구분이며 실제 화면에서는 작은 여백으로 표현한다.
- **배치 섹션의 초상화를 클릭하면 해당 전장 유닛을 클릭한 것과 같은 포커스가 발동한다.** 정보·선택 강조·명령을 해당 유닛으로 갱신하고, 진행 중 전투는 6.4절에 따라 0.5배속이 된다. 이미 포커스 중이면 대상을 전환하며 원래 복원 배속을 유지한다.
- **배치된 로스터 초상화를 빠르게 더블클릭하면 해당 유닛이 배치된 위치로 카메라가 자동 이동한다.** 일반 클릭의 정보 포커스와 구분되는 위치 찾기 입력이다. 고정/이동 가능 맵별 처리와 보완안은 6.12절을 따른다.
- 미배치 섹션에서 배치 가능한 카드는 드래그 앤 드롭으로 배치를 시작한다. 철수·전투불능 후 대기 중인 유닛과 현재 배치 불가 유닛도 미배치 섹션에 포함하고, 남은 대기시간 또는 배치 불가 사유를 표시한다. 미배치라는 것과 즉시 배치 가능하다는 것을 구분한다.
- **실제 배치·철수·전투불능 상태가 확정된 뒤에만 카드를 해당 섹션으로 옮긴다.** 로스터 고스트 드래그·타일 드롭·방향 설정 중에는 후보 배치를 이유로 카드를 옮기지 않는다. 취소·실패에는 후보에 따른 섹션 변경이 없다. 전투 중 다른 유닛의 실제 상태 변화는 최신 결과를 따른다.
- 이동·교대는 참가자가 계속 배치된 상태이므로 섹션이나 편성 기준 순서를 바꾸지 않는다. 재배치 성공 시에는 미배치 섹션에서 배치 섹션의 편성 순서상 위치로 들어간다.
- 한 섹션이 비면 섹션 사이 구분 여백도 없앤다. 빈 섹션을 위한 카드 자리나 큰 빈 영역을 남기지 않는다.
- 기존의 기본 화면 `배치 중` 문구 생략·포커스 화면 배치 카드 문구 유지 규칙은 계속 적용한다. 현재 참고 이미지는 두 섹션 분리 이전 시안이므로 섹션 구조와 클릭 동작은 이 문서를 우선한다.
- **교대 상대 선택 중에는 배치 섹션의 B 초상화 클릭도 전장의 B 클릭과 동일하게 처리한다.** B의 타일에 A 고스트를 고정하고 A 방향 설정으로 이어진다. 일반 포커스로 전환하거나 교대를 즉시 실행하지 않는다. 스킬 등 다른 명령에서의 로스터 대상 지정은 별도이며 이 합의를 확대하지 않는다.

### 6.2 타일과 명령 처리의 공통 원칙

- Ground는 지상, Platform은 높은 배치면, Obstacle은 장애물로 구분한다. 타일 데이터가 없는 좌표는 Void이며 바닥·배치·클릭 가능한 타일로 만들지 않는다.
- 배치·이동·교대는 플레이어 배치 영역과 현재 무기의 배치 적성을 검사한다. 지상·고지대 가능 여부를 캐릭터 외형이나 직업만으로 판정하지 않는다.
- 다른 아군이나 보호 대상이 점유한 칸으로 일반 배치·이동할 수 없다. 점유한 아군을 누른 이동을 자동으로 교대로 바꾸지 않는다. 교대는 별도 명령이다.
- **아군 유닛끼리는 겹쳐 있을 수 없다.** 같은 타일에 아군 둘을 쌓아 배치하거나 실제 이동·교대 연출에서 아군 중첩을 전제로 설계하지 않는다. 적이 관련된 겹침은 상황에 따라 있을 수 있으므로 로스터 초상화는 전장 클릭의 보조 입력으로 활용한다. ‘아군끼리 겹쳐 있으므로 초상화로 고른다’는 이전 설명은 잘못된 전제로 정정한다. 고스트는 미리보기이며 실제 유닛 중첩이 아니다.
- 대상에 마우스를 올리는 행위는 미리보기다. 확정 전에는 위치·태세·공명·전술 포인트를 변경하지 않는다.
- 실행 직전 최신 상태로 조건을 다시 검사한다. 미리보기 이후 대상이 전투불능이 되거나 자원이 부족해지면 실행하지 않고 짧은 사유를 표시한다.
- 실패·취소로 자원이나 대기시간을 소비하지 않는다. 불가능한 명령을 예약해 두었다가 나중에 자동 실행하지 않는다.
- 요청 처리 중 중복 확정을 막고, 확정된 결과에 맞춰 유닛·로스터·수치·버튼 상태를 함께 갱신한다.
- 사용 불가 버튼은 숨기기보다 비활성 상태와 짧은 이유로 설명한다. 선택 가능 여부를 색만으로 전달하지 않는다.

#### 고스트와 방향 설정 — 2026-09-13 확정

- 배치·이동·교대의 공통 순서는 **고스트 타일 배치 → 방향 설정 → 최종 배치 종료**다. 고스트는 배치 결과를 미리 보여주는 반투명 유닛이며 실제 전투 유닛으로 생성하거나 타일을 점유하지 않는다.
- **로스터 방식은 드래그 앤 드롭:** 카드를 누른 채 끌면 커서에 고스트가 붙고, 유효 타일에서 버튼을 놓으면 목적지 타일을 선택한다. 드롭만으로 실제 배치를 끝내지 않고 방향 설정으로 넘어간다. 최초 배치와 철수·전투불능 후 로스터에서 하는 재배치에 같은 입력을 사용한다.
- **전장 이동·교대는 드래그 앤 클릭:** 명령 선택 후 버튼을 계속 누르지 않아도 고스트가 커서를 따라온다. 유효한 목적지 또는 교대 상대를 클릭하면 고스트의 도착 타일을 정하고 방향 설정으로 넘어간다.
- 유효 타일 위에서는 고스트가 해당 타일의 중심·높이에 맞춰 붙는다. 방향 설정 동안에는 고스트를 선택한 타일에 고정하고 커서로 방향을 정하며, 방향 표시·공격 범위를 함께 미리 본다. 클릭으로 그 방향을 확정한다.
- 교대는 A의 도착 타일에서 A 방향을 먼저 확정하고, B의 도착 타일에서 B 방향을 확정한다. **B 방향을 확정하는 마지막 클릭이 교대 전체의 실행 시점**이며 별도 완료 클릭을 추가하지 않는다.
- 최종 확정 전에는 고스트와 방향 미리보기만 바뀐다. 해당 조작으로 실제 유닛을 옮기거나 태세를 바꾸거나 비용을 지불하지 않는다. 이는 전투 시간 정지를 뜻하지 않는다. 유닛 포커스에서 이어지는 이동·교대 선택은 6.4절의 0.5배속을 유지하며 실제 전투 상태는 그 속도로 계속 변할 수 있다.
- 이동·교대의 타일 선택 또는 방향 설정 도중 우클릭·Esc를 누르면 해당 명령 전체를 취소하고 출발 유닛 포커스로 돌아간다. 교대에서 A 방향까지만 정한 상태도 실제 변경 없이 모두 취소한다. 로스터 배치도 취소 시 고스트를 제거하고 실제 배치·비용 소비 없이 종료한다.

### 6.4 포커스 진입·전환·해제

**확정:** 배치된 아군을 클릭하면 그 유닛의 포커스를 연다. 현재 태세를 표시하고 태세 전환 버튼에는 실행할 태세를 표현한다. 공격 중이면 `방어 전환`, 방어 중이면 `공격 전환`이다. 공격 범위와 방향은 해당 유닛의 실제 무기·현재 상태를 따른다.

**추가 확정:** 로스터 좌측 배치 섹션의 초상화 클릭으로도 해당 유닛을 포커스한다. 일반 포커스에서 다른 배치 유닛의 초상화를 클릭하면 그 유닛으로 포커스를 전환한다.

**위임에 따른 기본 적용:** 일반 포커스에서는 다른 배치 아군 클릭으로 대상을 전환하고, 빈 공간 클릭·우클릭·Esc로 기본 화면에 돌아간다. 같은 유닛이나 그 초상화를 단일 재클릭하면 포커스를 유지한다. 초상화의 빠른 더블클릭은 B18의 카메라 이동 동작으로 구분하며 해제 토글로 사용하지 않는다.

명령 대상 선택 중에는 클릭 의미를 구분한다. 교대 모드의 아군 클릭은 포커스 전환이 아니라 교대 상대를 정하고 A 방향 설정으로 진입하는 입력이다. 이동·스킬 대상 선택도 해당 모드의 입력을 우선한다. 방향 설정 중의 클릭은 방향 확정으로 처리하며 그 아래의 유닛을 새로 선택하지 않는다. 우클릭·Esc는 현재 명령 선택 전체를 취소하고 원래 포커스로 돌아가며, 한 번의 취소로 설정 메뉴까지 연달아 열지 않는다.

#### 적 정보 확인용 포커스 — B16 확정

- 기본 화면이나 일반 포커스에서 적을 클릭하면 해당 적을 정보 열람 대상으로 선택한다. 아군 포커스와 같은 좌측 정보 영역·먹 음영 스타일을 사용한다.
- **이름·HP·주요 능력치·특성·현재 상태 효과**를 표시한다. 항목의 값과 내용은 실제 해당 적 데이터를 사용하며, 아군의 공명·장착 슬롯 등 적에게 없는 항목을 채워 넣지 않는다.
- 적 포커스에도 **0.5배속**을 적용한다. 포커스를 완전히 해제하면 진입 전 배속을 복원하고, 이미 일시정지 중이면 정지를 유지한다. 아군↔적 또는 적↔적 전환으로 임시 감속을 중첩하거나 최초 복원 배속을 덮어쓰지 않는다.
- 이동·교대·태세 전환·철수·아군 스킬 실행 버튼은 표시하지 않는다. 적 정보 열람만으로 공격 명령이나 타깃 변경을 실행하지 않는다.
- 위임에 따른 공통 입력으로 빈 곳·우클릭·Esc는 포커스를 해제하고, 다른 유닛 클릭은 해당 유닛 정보로 전환한다. 동일 적 재클릭은 유지한다. 적이 사망·퇴장하여 대상이 사라지면 포커스를 종료하고 재생 상태를 공통 규칙대로 복원한다.
- 스킬 대상 선택 등 명령 모드에서 적을 클릭하면 해당 명령의 대상 선택을 우선한다. 이때 정보 포커스를 새로 열어 스킬 선택을 취소하지 않는다.
- 선택한 적은 전장에서 식별할 수 있게 강조하되 아군 조작 버튼이나 아군 배치 타일 표시를 가져오지 않는다. 상태 효과의 상세 툴팁과 긴 특성 설명은 좌측 정보 영역 안에서 정리하는 기본안을 사용한다.

#### 포커스 자동 감속 — 2026-09-13 추가 확정

- **유닛 포커스에 진입하면 진행 중 전투의 실제 배속을 자동으로 0.5배속으로 변경한다.** 기존의 ‘일반 포커스 감속 여부 미정’ 기록을 대체한다.
- 상단 배속 표시도 실제 적용 중인 `0.5×`로 갱신한다. 현재 포커스 참고 이미지의 `1×`는 이 합의 이전 시안이며, 구현 기준은 이 문서다.

**포커스 해제 시 배속 복원 — B02 확정:** 포커스 진입 전 배속을 보존하고 포커스를 완전히 해제하면 그 배속으로 복원한다. 예: `2× → 포커스 0.5× → 해제 2×`. 0.5배속을 새로운 기본 배속으로 남기지 않는다.

다음은 통상적인 조작을 자율 적용하라는 사용자 위임에 따라 채택한 기본 동작이다. 사용자 고유 규칙이 있으면 이를 우선한다.

- 이미 일시정지 중이면 포커스를 열어도 자동 재개하지 않는다. 일시정지 상태에서는 전투 시간이 흐르지 않는다.
- 포커스 상태에서 다른 유닛으로 대상을 바꾸거나 이동·교대의 고스트 및 방향 설정으로 넘어가도 0.5배속을 유지한다. 최초 진입 전 복원 배속을 중간의 0.5배속으로 덮어쓰지 않는다.
- 이동·교대를 취소하거나 완료한 뒤 유닛 포커스가 남아 있으면 0.5배속을 유지한다. 명령 종료와 포커스 완전 해제를 구분한다.
- 포커스 안에서 수동 스킬 대상 선택을 시작해도 0.25배속으로 중첩 감속하지 않는다. 스킬 선택이 끝나 포커스로 돌아오면 0.5배속을 유지하고, 포커스를 완전히 해제할 때 진입 전 배속을 복원한다.
- 포커스 유닛의 철수·전투불능으로 포커스를 닫을 때에도 같은 복원 원칙을 적용한다. 전투 종료·후퇴로 전투 자체가 끝난 경우는 종료 처리를 우선하고 전투를 재개하지 않는다.

**로스터 배치 감속 — B03 확정:** 배치 가능한 로스터 카드의 드래그를 시작하면 0.5배속으로 전환한다. 고스트 타일 선택과 방향 설정까지 유지하고 배치 완료·취소 시 시작 전 배속으로 복원한다. 호버만으로 감속하지 않는다. 이미 정지 중이면 정지를 유지하고, 유닛 포커스 안에서 시작한 배치를 끝내도 포커스가 남으면 0.5배속을 유지한다. 기본 전투 화면까지 돌아갈 때 원래 배속을 복원한다.

**수동 조작 기본값:** 포커스·고스트·방향·스킬 대상 선택 중에는 배속 버튼을 비활성화하고 적용 배속을 표시한다. 정지·재개는 허용한다. 사용자가 직접 정지했다면 선택 종료만으로 재개하지 않으며, 직접 재개하면 선택 중에는 0.5배속으로 진행하고 전체 선택 종료 시 원래 배속으로 돌아간다. 메뉴의 자동 정지와 사용자 수동 정지는 구분한다.

### 6.5 로스터 배치·재배치 — 고스트 조작 확정과 현행 룰북

1. 로스터 우측 미배치 섹션에서 배치 가능한 유닛 카드를 누른 채 드래그하면 커서에 반투명 고스트가 붙고 진행 중 전투를 0.5배속으로 전환한다. 카드는 실제 배치 확정 전까지 미배치 섹션에 속한다.
2. 현재 배치 영역·무기 적성·점유 조건을 충족하는 타일만 강조한다. 유효 타일 위에서는 고스트를 타일 중심·높이에 맞춰 붙이고 비용을 표시한다.
3. 유효 타일에 드롭하면 해당 타일에 고스트를 고정하고 방향 설정으로 진입한다. 아직 실제 유닛을 배치하거나 비용을 지불하지 않는다.
4. 커서로 방향을 정하면서 고스트의 방향·공격 범위를 미리 보고, 클릭으로 최종 확정한다. 이때 최신 조건을 재검사하고 비용을 한 번 지불해 실제 배치한다. 확정 전 취소·잘못된 타일 드롭에는 비용이 없다.
5. 성공하면 전장 유닛과 로스터를 갱신하고 카드를 좌측 배치 섹션의 편성 순서상 위치로 옮긴다. 포커스 화면에서 배치된 카드에는 `배치 중`을 표시한다. 완료·취소 시 배치 선택의 감속을 종료하고 6.4절에 따라 이전 상태로 복원한다. 취소·실패에는 후보 배치에 따른 카드 이동이 없다.

현행 룰북상 일반 배치는 공격 태세로 시작하고 태세 전환 대기시간 1.5초를 시작한다. 현행 문서는 작업 칸 배치를 `방어 + 작업 중`으로 기술하지만, 차기 내부 분류는 B21에 따라 미정이다. UI에서는 작업 가능한 칸에 도착하면 즉시 작업 연출로 들어간다.

자발적 철수 후에는 전투 시간 30초, 전투불능 후에는 90초의 재배치 대기가 있다. 로스터에 남은 시간을 표시하고, 시간이 끝나도 현재 직원 상태와 비용 조건을 충족해야 배치할 수 있게 한다. 재배치 기본 비용은 최초 기본 비용의 150%를 올림한 값이며 실제 보정 결과를 표시한다. 재배치는 새 전투 유닛으로 구성되므로 이전 버프·공명·스킬 진행을 그대로 복원하지 않는다.

#### 공통 배치 애니메이션 — B22 확정

시각 참고: [사용자 제공 배치 GIF](references/공통-배치-착지-참고.gif). 참고 영상의 낮은 공중에서 나타나 살짝 내려앉는 느낌을 기준으로 삼으며, 정확한 높이·재생 시간·이펙트 수치를 영상에서 확정한 것으로 취급하지 않는다.

- **도착 타일의 낮은 공중에 유닛이 나타남 → 짧게 아래로 떨어짐 → 타일 표면에 가볍게 착지**하는 공통 배치 애니메이션을 사용한다.
- 로스터 최초 배치·철수 후 재배치·전술 이동·교대의 도착 연출에 재사용한다. 교대 성공 시에는 두 유닛이 각자의 도착 타일에서 같은 공통 애니메이션을 재생한다.

- 교대는 두 참가자의 원래 위치 표시를 정리한 뒤 각 도착 타일에서 함께 배치 연출을 시작하는 기본 흐름으로 한다. 아군이 서로를 통과하며 걸어가거나 한 칸에 실제 유닛 둘이 겹치는 연출을 만들지 않는다.
- 일반 타일에서는 착지 뒤 해당 상황의 자세로 이어진다. 이동·교대의 강제 방어와 이후 자동 공격 연출은 기존 합의를 따르고, 작업 가능한 칸에서는 추가 방어 대기 없이 작업 연출로 자연스럽게 연결한다.
- 사용자가 채택한 것은 이 공통 배치 연출이다. 이전 AI의 ‘짧은 잔상·페이드로 이동’ 제안은 대체하며, 별도의 순간이동 잔상이나 강한 소환 이펙트를 필수로 추가하지 않는다.
- 애니메이션은 표현 규칙이다. 새로운 공중 판정·이동 경로·무적 시간·피격 유예·추가 행동 대기를 이 항목에서 정의하지 않는다. 기존 1.5초 타이머를 애니메이션 종료 시점부터 다시 시작한다고 추론하지 않는다.

### 6.6 태세 전환 — 확정 UI와 현행 룰북

1. 유닛 포커스에서 현재 태세와 전환 후 효과를 확인한다.
2. 반대 태세 버튼을 클릭한다. 전환 불가이면 남은 대기시간 또는 상태 제한을 안내한다.
3. 성공 시 태세 표시·버튼·실제 저지 수와 효과를 갱신한다. 비용은 없고 1.5초의 전환 대기시간이 시작된다.

| 태세 / 타일 | 결과 |
| --- | --- |
| 공격 | 기본 공격과 자동·수동 스킬의 새 시작 허용 |
| 방어 / 지상 | 새 기본 공격·자동·수동 스킬 시작 중단. 무기 설정에 따른 저지 수 보너스와 받는 피해 감소 적용 |
| 방어 / 고지대 | 새 기본 공격·자동·수동 스킬 시작 중단. 방어 진입 후 온전한 1초마다 HP 3·공명 5 회복 |

- 방어 전환 전에 이미 시작한 공격·스킬은 전환만으로 취소하지 않는다. 패시브·반응형 효과도 유지한다.
- 강한 군중 제어는 태세 전환을 막고, 침묵은 전환 자체를 막지 않는다. 현장 작업 중에는 태세 전환과 일반 방어 효과가 제한된다.
- 고지대 휴식은 전술 포인트를 만들지 않는다. 정지 중에는 회복과 대기시간 모두 진행하지 않는다.
- 공격으로 돌아가면 타일의 방어 파생 효과를 해제하고 수치를 즉시 갱신한다. 방어 태세가 회복이나 방어 보너스를 언제나 동일하게 주는 것으로 표시하지 않는다.

#### 이동·교대 후 강제 방어와 자동 공격 — B20 확정

- 이동한 유닛 또는 교대한 두 유닛 모두 **강제 방어 1.5초 → 자동 공격 태세**로 전환한다. 사용자가 수동으로 방어를 해제하는 방식이 아니다. 기존의 ‘계속 방어 유지·자동 공격 복귀 없음’을 대체한다.
- 시간은 최종 명령 성공부터 계산하는 전투 시간이다. 고스트·방향 선택 중에는 시작하지 않는다. 일시정지 중에는 멈추며 0.5배속이 계속 유지되면 실제 시간으로 약 3초다.
- 강제 방어 중 태세 전환 버튼은 비활성화한다. `강제 방어`·남은 시간·`종료 시 자동 공격`을 표시하고 수동 조기 해제를 허용하지 않는다. 일반 방어 상태일 때의 `공격 전환` 버튼과 구분한다.
- 1.5초가 끝나면 추가 입력·비용 없이 공격으로 전환한다. 이동·교대 전부터 방어였던 유닛도 공격으로 전환하며 이전 태세를 복원하지 않는다. 일반 수동 방어에는 이 타이머를 적용하지 않는다.
- 기존 이동 대기시간 10초와는 별개다. 자동 공격으로 바뀌어도 이동 대기시간을 초기화하거나 단축하지 않는다.
- 자동 전환 시점은 서버의 전투 시간으로 처리한다. UI 벽시계나 나중의 수동 전환 요청에 의존하지 않는다. 철수·전투불능·전투 종료된 유닛을 타이머가 다시 활성화하지 않는다.
- 작업 가능한 칸에 도착하면 B21에 따라 즉시 작업 연출로 들어간다. 작업 시작 전에 1.5초 방어 대기 연출을 끼워 넣지 않는다. 작업의 내부 모드 분류와 자동 공격 타이머의 처리·우선순위는 시스템 설계로 유보한다. 기존 일반 태세 대기와의 관계도 현재 연출 질문의 대상에서 제외한다.

### 6.7 자리 교대 — 태세 무관 실행·강제 방어 후 자동 공격 확정

**확정 의도 — B01 답변 반영:** 두 참가자의 현재 공격/방어 태세와 관계없이 교대를 허용하고, **교대 성공 후 두 유닛을 강제로 방어 태세로 만든다.** 방어 태세를 먼저 준비하는 조작이 아니다. 전체 순서는 **`A 클릭 → 교대 클릭 → B 선택 → A 방향 확정 → B 방향 확정`**이며 B 방향을 확정하는 마지막 클릭에서 교대와 최종 방어 상태를 함께 적용한다.

1. 배치된 A를 클릭하고 `교대`를 누르면 커서에 A의 반투명 고스트가 붙는다. A는 출발 유닛으로 이미 정해졌으므로 다시 선택할 필요가 없고, 마우스 버튼을 계속 누르지 않아도 고스트가 커서를 따라온다. 이 시점에는 교대로 인한 태세·위치·자원 변경이 없다.
2. 교대 가능한 다른 배치 아군과 해당 배치 섹션 초상화를 강조한다. 교대 불가 대상은 흐리게 표시하고 호버 시 이유를 설명한다. 공격/공격·공격/방어·방어/방어 조합 모두 태세 자체를 이유로 배제하지 않는다. 출발 A 자신과 미배치 카드는 교대 상대가 될 수 없다.
3. B에 마우스를 올리면 A 고스트가 B 타일의 중심·높이에 맞춰 붙는다. A와 B의 교대 관계와 도착 위치를 화살표로 표시한다. 화살표는 실제 보행 경로가 아니라 자리 교환의 표시다.
4. `전술 포인트 5 · 교대 후 두 유닛 방어 태세`와 `우클릭 / Esc 취소`를 간결하게 표시한다. 기존 전술 포인트 총량은 확정 전까지 유지한다.
5. 전장의 B 또는 배치 섹션의 B 초상화를 클릭하면 교대 상대와 두 도착 타일이 정해진다. B가 서 있는 타일에 A 고스트를 고정하고 **A의 방향 설정**으로 진입한다. 초상화는 선택 입력이며 고스트를 로스터 위에 놓지 않는다. 실제 A와 B는 아직 원래 위치에 있다. 이후 B 방향 설정과 마지막 확정은 어떤 입력 경로로 상대를 골랐든 동일하다.
6. A 고스트의 방향·공격 범위를 커서로 미리 보고 클릭하면 A 방향만 미리보기 값으로 저장한다. 이어서 A의 원래 타일에 B 고스트를 표시하고 **B의 방향 설정**으로 넘어간다. A만 먼저 이동하거나 태세를 바꾸지 않는다.
7. B 고스트의 방향을 정하고 클릭하면 **교대 전체를 최종 확정**한다. 양쪽 위치·방향의 교대 조건을 재검사하고, 통과한 경우 두 유닛의 위치·방향을 교대하며 최종 태세를 모두 방어로 적용한다. 추가 완료 버튼은 요구하지 않는다.
8. 성공 시 전술 포인트를 **교대 전체에 5 한 번만** 지불하고 두 유닛 모두 전술 이동 대기시간 10초와 강제 방어 1.5초를 시작한다. 고스트·교대 안내를 제거하고 실제 유닛과 HUD를 갱신한다. 전투 시간 1.5초 후 둘 다 자동으로 공격 태세가 된다.
9. 대상 선택·A 방향 설정·B 방향 설정 중 우클릭·Esc를 누르면 교대 전체를 취소하고 고스트·후보 방향을 지운 뒤 원래 A 포커스로 돌아간다. 실패하면 이유를 알리고 미리보기를 최신 상태로 갱신한다. 어느 경우에도 한 명만 방어로 바뀌거나 한 명만 이동한 결과를 남기지 않는다.

**방향 설정:** A → B 순서로 두 유닛의 방향을 각각 설정하고 클릭으로 확정한다. 기존 방향을 초기 미리보기로 사용할 수 있지만 방향 설정 단계를 자동 생략하지 않는다. UI는 두 유닛의 최종 방향을 각각 명시해서 전달해야 하며, 서버가 방향을 자동으로 보존하거나 서로 바꾼다고 가정하지 않는다.

**유효성:** 두 유닛이 서로의 타일에 배치될 수 있어야 한다. 각 무기의 배치 적성, 플레이어 배치 영역, 전술 이동 대기시간, 강한 군중 제어, 아직 발사·방출되기 전의 공격/스킬 동작 등 태세 외의 현행 이동 제한은 유지한다. 일반 태세 전환을 선행 요청으로 처리하지 않는다. 강제 방어와 일반 태세 전환 대기시간의 관계는 아래 후속 계약 항목으로 분리한다. 사용할 수 없는 명령을 자동 대기시키지 않는다.

**백엔드 변경 요구:** 현행 `TacticalSwapUnits`의 방어 선행 조건을 제거하고 성공 시 두 유닛에게 강제 방어와 1.5초 후 자동 공격 전환을 적용한다. 위치·방향·강제 방어와 종료 시점·비용·이동 대기시간을 함께 검증·적용한다. 독립된 방어 전환 선행 요청이나 일부만 성공하는 처리는 사용하지 않는다. 이전의 ‘방어 유지·자동 복귀 없음’은 B20으로 대체한다. 일반 태세 대기시간과의 나머지 관계는 후속 계약으로 구분한다.

성공 후 A 포커스를 새 위치에서 유지한다. 위치가 바뀌어도 HP·버프·공명 등은 각 유닛에게 남으며 재배치 초기화나 회복을 추가하지 않는다. 실패 시 비용·태세·위치를 변경하지 않고 사유를 표시한다. A가 유효하면 고스트와 후보 방향을 지우고 교대 상대 선택 단계로 돌아가 다시 선택하게 한다. A가 철수·전투불능 등으로 무효라면 명령과 포커스를 종료한다. 이는 위임에 따른 기본 오류 처리다.

### 6.8 전술 이동 — 태세 무관 실행·강제 방어 후 자동 공격 확정

`이동`은 선택한 유닛 한 명을 다른 타일로 즉시 옮기는 기능이다. 다른 아군과 위치를 바꾸는 교대, 전장에서 제거하는 철수, 철수 후 재배치와 구분한다.

1. 공격/방어 태세와 관계없이 유닛을 포커스하고 `이동`을 선택하면 커서에 고스트가 붙는다. 마우스 버튼을 계속 누르지 않고 이동시킨다.
2. 배치 영역·무기 적성·점유 조건을 충족하는 목적지 타일을 강조한다. 고스트를 유효 타일의 중심·높이에 맞춰 표시하고 `전술 포인트 5`를 안내한다.
3. 목적지를 클릭하면 고스트를 해당 타일에 고정하고 방향 설정으로 넘어간다. 실제 유닛은 아직 원래 위치에 있다.
4. 커서로 방향·공격 범위를 미리 보고 클릭하면 최종 확정한다. 최신 조건을 검사한 뒤 동일 유닛의 위치·방향을 즉시 변경하고 전술 포인트 5를 지불하며 이동 대기시간 10초를 시작한다. **이동 성공 후 강제 방어 1.5초를 거쳐 자동으로 공격 태세가 된다.** HP·버프·공명 등은 유지한다.
5. 성공 후 이동한 유닛의 포커스를 유지한다. 취소하면 고스트를 지우고 원래 유닛 포커스로 돌아간다. 검증 실패 시 유닛이 유효하면 사유를 표시하고 목적지 선택으로 돌아가며 유닛이 무효면 명령·포커스를 종료한다. 취소·검증 실패에는 이동·비용 소비가 없다. 다른 아군이 점유한 칸을 눌러도 자동 교대하지 않는다.

현재 위치에서 방향만 바꾸는 것도 동일한 비용과 대기시간을 사용하는 전술 이동이다. 위치와 방향이 모두 같으면 실행하지 않는다.

**백엔드 변경 요구:** 현행 `TacticalRelocateUnit`의 방어 선행 조건을 제거하고 성공 시 강제 방어와 1.5초 후 자동 공격 전환을 적용한다. 위치·방향·강제 방어와 종료 시점·비용·이동 대기시간을 함께 처리하며 취소·실패 시 후보 조작으로 어느 항목도 변경하지 않는다. 태세 외의 타일·적성·점유·자원·이동 제한은 유지한다. ‘공격 태세에서는 이동 불가’는 B01, ‘방어 유지·수동 공격 복귀’는 B20으로 대체한다.

### 6.9 철수·재배치 결과

포커스의 `철수`는 해당 유닛 한 명의 철수다. 위임에 따른 기본 동작으로 클릭 즉시 실행하고 추가 확인창은 두지 않는다. 버튼은 다른 명령과 간격·색으로 구분하며 호버 시 재배치 대기와 비용 환불 없음 등을 안내한다.

실행에 성공하면 유닛을 전장에서 제거하고 기존 저지를 해제한다. 전술 포인트 소비나 배치 비용 환불은 없다. 로스터의 해당 카드를 우측 미배치 섹션의 편성 순서상 위치로 옮기고 재배치 대기를 표시한다. 전투불능 상태가 확정된 경우에도 미배치 섹션으로 옮기며 실제 대기시간·출전 가능 상태를 표시한다. 해당 유닛 포커스를 닫는 처리는 6.4절의 기본안을 따른다.

현행 룰북상 배치 중인 유닛은 공격·방어 태세, 강한 군중 제어, 침묵, 현장 작업 중 여부와 무관하게 철수할 수 있다. 이미 전투불능이거나 철수한 유닛은 다시 철수할 수 없다. 자발적 철수의 재배치 HP는 철수 순간 `현재 HP + 최대 HP의 30% 내림`을 최대 HP로 제한한 값으로 확정된다. 대기 중 계속 회복하는 것으로 표시하지 않는다.

### 6.10 수동 스킬 — 현행 룰북에 따른 UI 과정

포커스의 스킬 정보에는 효과·공명·사용 가능 여부를 표시한다. 공명 부족·방어 태세·침묵·강한 군중 제어 등의 실제 제한이 있으면 버튼 상태와 사유를 갱신한다. 자동 스킬을 수동 실행 가능한 것으로 바꾸지 않는다.

| 스킬의 선택 방식 | 입력 과정 | 결과 |
| --- | --- | --- |
| 자신 / 자동 대상 결정 | 수동 스킬 버튼 클릭 | 별도 대상 선택 없이 게임 규칙이 정한 대상으로 스킬 시작 요청 |
| 플레이어가 유닛 지정 | 스킬 클릭 → 유효 대상 호버 → 대상 클릭 | 대상 유효성을 다시 검사한 뒤 해당 유닛을 대상으로 시작 |
| 플레이어가 타일 지정 | 스킬 클릭 → 유효 타일 호버 → 타일 클릭 | 해당 타일을 대상으로 시작. 타일에 유닛이 반드시 있어야 하는 것은 아님 |

- 지정 대상 스킬은 선택 중 유효 대상·범위·효과 미리보기를 표시한다. 대상 종류나 사거리를 임의로 보정하지 않는다.
- **수동 스킬의 대상 선택 중에는 진행 중 전투가 0.5배속이 되며, 이미 정지 상태라면 그대로 정지한다.** 성공·취소 시 선택 시작 전 재생 상태를 복원한다.
- 호버는 공명을 소비하지 않는다. 확정 성공 시 실제 스킬 규칙에 맞춰 공명과 시전 상태를 갱신한다. 실패하면 선택 모드와 재생 상태를 유지하고 원인을 알린다.
- 우클릭·Esc 취소는 비용 없이 대상 선택을 종료한다. 성공 뒤 이미 시작한 스킬을 UI 취소로 되돌리거나 다른 대상으로 자동 변경하지 않는다.
- 일반 유닛 포커스에도 6.4절의 추가 합의에 따라 0.5배속을 적용한다. 스킬 대상 선택이 끝나도 유닛 포커스가 유지되면 실제 배속은 0.5배속이며, 포커스의 원래 복원 배속을 잃지 않도록 처리한다. 일반 포커스 감속은 현행 스킬 계약만으로 구현 완료된 것으로 취급하지 않는다.

### 6.11 정지·배속·설정·전투 전체 후퇴

**정지·재개:** 우측 상단 버튼으로 전투 시간 진행을 전환한다. 정지 중에도 조건에 맞는 배치·철수·태세 전환·이동·교대·수동 스킬 시작은 허용한다. 명령 결과는 즉시 반영하지만 공격 진행·회복·버프 시간·재배치 대기·각종 대기시간은 진행하지 않는다. 명령을 모았다가 재개 시 일괄 실행하는 방식은 사용하지 않는다.

**배속:** 기본 전투 화면에서는 클릭으로 `1× ↔ 2×`를 전환한다. 포커스·배치 선택의 자동 감속 중에는 `0.5×`를 표시하고 수동 배속 버튼을 비활성화한다. 정지 중 선택 모드가 아니면 재개 후 사용할 배속을 변경할 수 있지만 자동 재개하지 않는다. 임시 감속과 복원할 배속을 구분한다. 이는 위임에 따른 UI 기본값이며 지원 배속은 백엔드 계약과 맞춰 구현한다.

**설정:** 우측 상단 배속 왼쪽 버튼에서 열며 전투를 자동 일시정지한다. `계속하기`, `게임 설정`(소리·해상도 등), `전투 포기`를 기본 메뉴로 제공한다. 닫으면 메뉴 진입 직전의 정지 여부와 적용 배속을 복원한다. 이미 정지 중이었다면 정지를 유지하고, 포커스 도중 열었다면 포커스의 0.5배속으로 돌아간다. 메뉴가 전장 입력을 가로채며 후보 선택을 확정하지 않는다. 전투 중 불러오기·즉시 재시작은 현행 저장/전투 정책을 우회할 수 있으므로 기본 메뉴에 추가하지 않는다.

**전투 전체 후퇴:** 설정의 `전투 포기`에서 확인창을 표시한다. `전투를 포기하고 진입 전 상태로 돌아갑니다.`라는 결과 안내와 `포기 / 취소`를 제공한다. 취소하면 정지된 설정 메뉴로 돌아간다. 현행 룰북상 전투 종료·패배 판정 전에 실행하며, 명시적으로 후퇴를 금지한 강제 전투는 제외한다. 성공하면 전투 진입 직전의 직원 상태·소모품·인벤토리·재화·노드 및 시도 상태 등을 복원하고 전투를 종료한다. 전투 결과·보상·패널티·노드 완료·시도 소진을 발생시키지 않는다. 개별 철수처럼 로스터에 재배치 대기만 표시하는 동작이 아니다.

### 6.12 상황 변화와 기타 입력 — 후속 설계 범위

- **현장 작업 진입 — B21 확정:** 작업 가능한 칸으로 이동하면 도착 즉시 작업 상태의 연출을 시작한다. 추가 작업 버튼이나 강제 방어 1.5초 대기 연출을 거치지 않는다. 플레이어에게는 작업하는 모습으로 보이게 하며, 내부적으로 방어 모드인지 별도 작업 모드인지 이번 UI 설계에서 확정하지 않는다.
- 위임에 따른 작업 UI 기본값은 직원의 `작업 중` 표시와 작업 대상의 진행도다. 작업 칸을 떠나거나 완료되면 실제 작업 상태에 맞춰 표시·모션을 갱신한다. 미정인 내부 모드를 근거로 화면에 방어 태세를 강제 표기하거나 작업 중 공격 전환 연출을 임의 추가하지 않는다. 세부 작업 모션은 해당 오브젝트에 맞춰 제작한다.
- 전투 목표·격퇴 수·보호 대상 HP·타이머는 실제 전투 정의와 상태에 따라 갱신한다. 별도 클릭 행동은 아직 정하지 않았다. 서버의 승패 결과가 확정되면 진행 중인 선택 UI를 종료하고 결과 장면으로 연결하는 것을 초안으로 둔다.
- 적 클릭 상세 정보는 B16과 6.4절로 확정했다. 카메라 고정/이동 가능 구분과 입력은 아래 B18·B23을 따른다. 지형 호버 설명·단축키는 별도 기본 설계 항목이다.
- 연결 복구 시 현재 선택 후보가 여전히 유효한지 다시 확인한다. 현행 룰북상 재접속한 전투는 정지 상태를 유지하며 플레이어가 재개하기 전 자동 진행하지 않는다.

#### 맵별 카메라·유닛 위치 찾기·확대 축소 — B18·B23 확정

- 전투 맵에는 카메라 고정인 경우와 이동 가능한 경우가 모두 있다. 일부 보스전은 큰 맵을 사용하므로 모든 전장을 한 화면에 억지로 축소하는 공통 규칙을 적용하지 않는다.
- 카메라 이동이 가능한 맵에서는 마우스 드래그뿐 아니라 **방향키 ↑·↓·←·→**로도 전장 시야를 이동할 수 있다. 방향키는 화면 기준 위·아래·왼쪽·오른쪽으로 카메라를 움직이며, 누르고 있는 동안 이동하고 놓으면 멈추는 기본 조작을 사용한다.
- **고스트를 들고 있거나 방향 설정 중에도 방향키 카메라 이동을 사용할 수 있다.** 마우스는 배치·대상·방향 입력에 그대로 사용한다. 카메라 조작만으로 선택을 확정·취소하거나 유닛의 실제 위치·태세·배속을 변경하지 않는다.
- 타일 선택 전 고스트는 이동된 시야에서 커서 아래의 후보 타일에 맞춰 표시한다. 타일을 이미 선택해 방향 설정 중이면 고스트는 그 전장 타일에 고정하며, 카메라 이동만으로 선택 타일이나 설정 중인 방향을 바꾸지 않는다. 방향키는 유닛 방향 설정용 입력으로 중복 사용하지 않는다.
- 방향키 이동도 맵의 허용 범위를 지킨다. 정지·0.5배속과 관계없이 카메라 조작은 가능하며, 이동 속도는 시각·조작 검증으로 조정한다. 설정 등 전장 입력을 가로채는 메뉴나 텍스트 입력 중에는 해당 UI 입력을 우선한다.
- 로스터의 배치된 유닛 초상화를 빠르게 더블클릭하면 해당 유닛이 배치된 위치로 카메라가 자동 이동한다. 미배치 유닛은 전장 위치가 없으므로 이동 대상을 만들지 않는다.
- **이동 가능한 전투 맵에서는 마우스 휠로 제한된 범위 안에서 확대·축소할 수 있다.** 최소·최대 범위를 두고 유닛 식별과 타일 판독이 가능한 크기를 유지한다. 구체적인 배율과 휠 감도는 맵·화면비별 시각 검증으로 조정한다.
- 고정 맵에서는 수동 이동·확대·축소 없이 지정 구도를 유지한다. 이 변경은 전투 화면에 관한 것이며 휴식 메인의 수동 좌우 이동 제거 규칙은 유지한다. 카메라 회전·화면 가장자리 자동 스크롤은 추가하지 않는다.
- 위임에 따른 기본 입력으로 전장 위에서 휠을 조작하면 카메라 확대·축소, 스크롤 가능한 정보 UI 위에서는 해당 UI 스크롤을 우선한다. 한 번의 휠 입력을 두 곳에 동시에 적용하지 않는다. 카메라 확대·축소가 선택 확정·취소·배속 변경을 일으키지 않는다.
- 확대·축소는 전장 카메라에만 적용하고 로스터·상단바·정보창 등 고정 UI의 화면상 크기는 유지한다. 맵 이동 경계는 확대 수준에도 맞게 제한한다. 초상화 더블클릭은 현재 확대 수준을 유지하며 위치만 찾는 기본 동작으로 한다.

보완 규칙 — 사용자 수락으로 확정:

- 빈 전장 영역에서 시작한 드래그만 카메라 조작으로 판정하고, 일정 이동량 이상일 때 클릭 대신 드래그로 확정한다. 드래그 종료가 빈 곳 클릭으로 처리되어 포커스를 해제하지 않게 한다. UI·로스터·배치 고스트·방향 선택 입력을 우선한다.
- 더블클릭 이동은 짧고 부드럽게 진행하고 도착 후 카메라를 계속 유닛에 고정하지 않는다. 사용자가 카메라 드래그 또는 방향키 이동을 시작하면 자동 이동을 중단한다. 최초 클릭의 포커스는 유지하며 카메라 이동 자체가 추가 배속 변경을 만들지 않게 한다.
- 이동 범위를 맵의 허용 구역으로 제한하고 목적 유닛을 정보 UI에 가리지 않는 전장 영역 안으로 가져온다. 고정 맵에서는 구도를 유지하고 해당 유닛 강조만 제공한다.
- 큰 맵에서 화면 밖의 보호 대상이 피해를 입는 경우 화면 가장자리에 방향·위험 표시를 제공한다. 상시 미니맵 추가와는 별개다.
- 교대 등 명령 대상 선택 중에는 해당 명령 입력을 우선하고 초상화 더블클릭의 카메라 이동을 중복 실행하지 않는다. 교대 상대를 선택한 클릭에 이어지는 빠른 두 번째 클릭이 곧바로 방향 확정까지 처리되지 않도록 입력을 분리한다. 스킬의 로스터 대상 지정 지원 여부는 별도이며 이 규칙으로 새로 추가하지 않는다. 고스트·방향 설정 중 원거리 카메라 탐색은 방향키로 지원한다. 앞서 제안한 마우스 가운데 버튼 드래그는 필수 조작으로 채택하지 않는다.

검증 시에는 다음을 확인한다.

- 기본·포커스 모두 설정은 배속 왼쪽이며 총 배치 인원은 표시하지 않는다. 포커스의 배치된 카드만 현재 합의대로 `배치 중` 문구를 유지한다.
- 플랫폼을 포함한 유닛마다 머리 위 HUD가 한 묶음만 있고 발밑 중복 HUD는 없다.
- 로스터의 왼쪽은 배치·오른쪽은 미배치이며 각 섹션이 편성 순서를 보존한다. 배치·철수·전투불능 확정에 따라 카드가 올바른 위치로 이동하고, 이동·교대만으로 카드 순서를 바꾸지 않는다.
- 배치 섹션 초상화 클릭 시 해당 실제 유닛으로 포커스하고 0.5배속을 적용한다. 미배치 대기 카드는 대기/불가 상태를 표시하고 유효한 배치만 허용한다. 고스트 조작만으로 카드 섹션을 옮기지 않으며 한 섹션이 비면 구분 여백을 제거한다.
- Void·Obstacle·배치 영역 밖·부적합 타일을 배치/이동 가능으로 표시하지 않는다. 교대는 양쪽 타일 적성을 모두 검사한다.
- 로스터 드롭·이동 목적지 클릭·교대 상대 B 클릭은 고스트 타일 선택만 한다. 로스터/이동은 방향 클릭, 교대는 A 방향에 이어 B 방향을 클릭해야 실제 실행된다.
- 고스트는 커서를 따라오고 유효 타일의 중심·높이에 맞춰 붙는다. 방향 설정 중에는 타일에 고정되며 실제 유닛이나 점유 상태를 추가하지 않는다.
- 교대의 A 방향 확정만으로 태세·위치·비용이 바뀌지 않는다. 어느 방향 설정 단계에서든 취소하면 전체 후보를 버리고 A 포커스로 돌아간다.
- 교대의 호버·취소에는 상태 변화가 없고, 확정 성공 시 비용 5를 한 번만 지불하며 둘 다 방어가 된다. 실패 시 어느 한 명의 태세나 위치만 바뀌지 않는다.
- 이동·교대 성공 후 1.5초는 수동 해제 불가한 강제 방어이며 만료 시 자동 공격이 된다. 타이머는 전투 시간을 따르고 일반 수동 방어에는 자동 공격 전환을 적용하지 않는다.
- 태세/이동 대기시간, 군중 제어, 대상 전투불능, 포인트 부족과 미리보기 이후 상태 변화가 버튼과 실패 안내에 반영된다.
- 정지 중 가능한 명령은 즉시 처리되지만 회복과 대기시간은 흐르지 않는다. 스킬 대상 선택의 성공·취소 후 이전 재생 상태를 복원한다.
- 진행 중 전투의 유닛 포커스 진입 시 실제 배속과 표시가 모두 0.5배속이 된다. 기본 처리안에 따라 대상 전환·교대 방향 설정·중첩 스킬 선택에서도 중복 감속하지 않고, 전체 포커스 해제 시 진입 전 배속을 복원한다. 이미 정지 중인 전투를 포커스 진입으로 재개하지 않는다.
- 명령 대상 선택 중 아군 클릭이 의도치 않은 포커스 전환을 일으키지 않고, 취소는 현재 선택 단계만 종료한다.
- 적 클릭 시 좌측 정보와 0.5배속을 적용하고 아군 명령 버튼은 표시하지 않는다. 아군·적 간 포커스 전환에도 최초 복원 배속을 유지하며, 스킬 대상 선택 중 적 클릭을 정보 열람으로 가로채지 않는다.
- 교대 모드에서 전장 B 클릭과 배치 초상화 B 클릭 모두 같은 타일의 A 방향 설정으로 이어진다. 아군끼리 실제로 겹치는 배치나 연출을 만들지 않는다.

## 7. 미정 사항 취합과 순차 확인 — 2026-09-13 시작

**진행 방식 변경 — B03 후속 지시:** 통상적인 조작 또는 확인된 명일방주 규칙에 해당하는 사항은 매번 질문하지 않고 기본안을 적용한다. 기존 사용자 합의와 우리 게임 룰북을 우선하며, 게임 고유 정책·밸런스·서로 충돌하는 선택 등 예외만 하나씩 질문한다. 직접 답변으로 확정한 사항과 사용자 위임에 따라 채택한 기본 동작을 구분해 기록한다. 외부 게임에서 확인하지 못한 세부 동작을 ‘명일방주 원작 규칙’이라고 단정하지 않는다. 아래 목록은 모든 행을 질문해야 하는 순서표가 아니라 결정·검증 진행표다.

**B21 후속 범위 정정:** 현재는 화면·입력·연출에만 집중한다. 위의 예외 중에서도 내부 상태 분류·타이머 우선순위·게임 밸런스·경제 등 시스템 설계는 보류하고 질문하지 않는다. 기존 기록은 보존하되 사용자에게 다음 UI 질문처럼 제시하지 않는다.

답변을 받으면 해당 장면 본문·후속 결정 표·이 목록을 함께 갱신한다. 정책 후속 문서와 겹치는 게임 동작의 합의는 그 문서에 날짜별로 추가하고, 이전 기록과의 대체 관계를 남긴다. 이미 확정된 고스트 흐름·교대 방향 순서·포커스 0.5배속·두 로스터 섹션·배치 초상화 포커스는 다시 질문하지 않는다. ‘미정’ 중 코드 확인이나 시각 검증만 필요한 항목은 사용자 선택과 구분한다.

### 7.3 질문 대신 먼저 확인·검증할 항목

- 휴식 8명 배치, 화면비·가방 폭·슬라이드 거리, 초상화와 수량의 겹침, 긴 효과 설명과 스탯 배치 등은 시각·구현 검증 과제로 모은다. 검증 없이 사용자가 픽셀 수치를 먼저 정해야 한다고 취급하지 않는다.
- 호버·long-click·더블클릭·대사 시간, 선택·호버·성공 색상, 모션 길이, 로스터 여백·이동 연출, 방향 선택 커서 판정은 조정 항목이다. 동작 정책을 먼저 확정한 뒤 필요한 항목만 하나씩 제안한다.
- 아이템 사용·장착 제한, 효과 비활성 사유와 예상 효과 데이터는 룰북·데이터·코드를 먼저 확인한다. 이미 존재하는 규칙을 새 사용자 선택으로 다시 만들지 않는다.
- 신규 교대 명령 구조·일괄 적용, 포커스 배속의 서버 상태·재접속·스킬 선택 결합은 합의한 사용자 경험에 맞춰 구체화할 구현 과제다. 사용자가 내부 요청 구조를 선택해야 하는 것으로 다루지 않는다.
- 정책 후속 문서의 이전 미정 문장은 후속 확정으로 대체된 경우 질문에서 제외한다. 저지 반경 0.75·갱신 50ms 같은 구현 조사 수치는 차기 정책의 확정값과 구분한다.

### 7.4 정책 후속 문서에만 있는 별도 주제

시스템 설계를 다시 논의할 때 참고할 보류 목록이다. B21 후속 지시에 따라 현재 연출 질문 순서에 포함하지 않는다. 사용자가 해당 설계를 재개하면 관련 최신 문서에서 이미 결정되었는지 먼저 확인한다.

- **P01 저지:** 정확한 거리·타일 경계, 여러 방향·복수 적 배치, 저지 후보·해제·판정 순서.
- **P02 강화·개화 경제:** 엔케팔린과 기존 가루·필수 재료의 동반 비용, 개화 파츠와 가루의 병용/대체, 구체적인 재료·획득·레시피.
- **P03 상점:** 일반/특수 떠돌이 상점 역할, 출현·접근·재고·가격·갱신·판매·파츠 거래·독점 상품.
- **P04 연속 보스:** 한 런의 후보·동시 진행 수, 후속 전투의 층 배정과 Gate, 8층 본편에서 절망의 기사 10층 생존 조건 처리.
