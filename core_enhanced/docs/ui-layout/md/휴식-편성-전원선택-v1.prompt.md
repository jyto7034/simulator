전원을 순서대로 선택해야 편성을 완료한다는 사용자 확정 규칙을 시각화했다. 선택을 한 번에 끝내는 전체 선택 버튼을 뜻하지 않는다. 8명 중 5명을 선택한 진행 상태이며, 5명은 초록 테두리와 순번 1~5, 나머지 3명은 붉은 테두리다. 선택 5/8 및 비활성 완료 버튼, 취소 버튼은 이 규칙을 보여주는 UI 시안이다. 순번 배지·버튼 배치의 상세 디자인은 검토 대상이다.

기존 5명 참고를 8명 구도로 확장했다. 인물 이름·상태 수치는 예시다. 상태별 색상은 최종 UI에서 통일해야 한다. Unity 구현이나 원본 이미지는 변경하지 않았다.
