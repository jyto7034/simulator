# 시설 지도·원정 흐름·황금가지·보스 분류 합의

날짜: 2026-09-27. 출처: 차기 룰북과 시설 지도에 관한 사용자 대화 및 지도 시안 검토.
대화 중 수정된 내용은 마지막 사용자 결정을 따른다. 차기 목표 설계의 기록이며 구현 완료를 뜻하지 않는다.

## 문서 위치와 역할

- [차기 게임 설계서](../game_rulebook.md): 게임 전체를 읽는 입구.
- [원정 흐름과 억제력](../game_rules/expedition-and-deterrence.md): 이번 원정 주기·소진·귀환·황금가지 규칙.
- [런과 시설 탐사](../game_rules/run-and-map.md): 전체 지도와 층 내부 방, 보스 분류와 조우의 경계.
- [결과와 저장](../game_rules/results-and-save.md): 회수·대여·실패·체크포인트.
- [남은 결정](../game_rules/open-decisions.md): 미합의 수치와 정책. 이번 추가 항목은 NEXT-17~19.

상세 규칙은 위 주제별 문서에서 갱신하고, 이 기록에는 합의 근거와 대체 관계를 보존한다.
현행 룰북·런타임 계약·데이터 스키마를 이번 기록만으로 교체하지 않는다.

## 합의된 전체 방향

| 주제 | 최종 합의와 범위 |
| --- | --- |
| 반복 탐사 | 한 런에서 모든 환상체를 만나는 무한 층 방식에서, 여러 런으로 같은 시설을 조금씩 개방하는 방향으로 전환 |
| 수직 구조 | 시설 최대 깊이는 8. 우회 방문 수와 물리적 깊이를 구분하며 층 방문을 무조건 8회로 제한하지 않음 |
| 전체 지도 | 노드 하나는 층 하나. 층을 마치면 연결된 다음 층을 선택. 세 주요 하강 경로에 분기·합류·횡단 연결을 둠 |
| 나무 형상 | 세피로트·클리포트의 나무에서 착안하되 정확히 모사할 필요 없음. 회사 내부를 내려가는 느낌 유지 |
| 지도 표현 | 종이·시설 도면·원형 표식·색실 분위기. 시작 위치는 최상단 시설 입구 |
| 정보 공개 | 설계 시안에서는 전체 연결을 보여 주고 미개방 상태를 구분. 최종 보스 이름을 지도에 드러내지 않고 최하층만 표시 |
| 작전 한계 | 휴대 억제 장치의 클리포트 억제력이 층 진행에 따라 소모. 현실 시간 제한이 아님. 황금가지로 보충 가능 |
| 억제력 소진 | 귀환 또는 계속하기 선택. 귀환은 성공 생환·런 종료 |
| 무억제 지속 | 침식체를 제외한 모든 보스 강화. 자유 귀환 불가. 억제력 재확보 후 다시 소진해야 귀환 선택 기회 재발생 |
| 최종 보스 승리 | 억제력 잔량과 무관하게 자동 생환·런 종료 |
| 실패와 복구 | 전멸 등 실패 시 기존 체크포인트 복구 규칙 적용. 런당 명시적 불러오기 최대 3회 유지. 실패 확정 시 반입·획득 장비 소실 |
| 일반 보스 | 전투 또는 통과 선택. 모든 보스가 다음 층 출구를 막는 방식은 채택하지 않음 |
| 황금가지 봉인 | 봉인형 일반 보스를 지나치면 가지 포기. 가지를 회수하려 봉인을 해제하면 강화 전투 시작 |
| 봉인 후보 | 웃는 시체의 산, 아무 것도 없는, 탐욕의 왕, 파고드는 천국 네 종 |
| 강화 예외 | 이미 무억제 상태라면 봉인 해제로 추가 스탯 증가 없음. 패턴 변화 전부 무효라는 의미는 아님 |
| 직원과 빌드 | 직원 초기화·새 빌드 구성과 소수 장비·파편 계승 방향. 세부 직원 기록의 보존은 미정 |
| 회수와 대여 | 생환 시 회수 장비 전부 반납, 다음 원정에 1~2개 선택 대여. 반입품은 실패 시 소실, 생환 시 재반납·재대여 가능 |
| 강화와 개화 | 일반 강화는 시설 밖에서 초기화, 회수한 파편의 개화 유지. 메인터넌스 효과가 시설 밖에서는 사라진다는 설정 |
| 최종 보스 분류 | 공개 최종 보스 3종과 숨겨진 최종 보스 흉탄의 사수. 마탄의 사수는 흉탄 단서를 여는 선행 조우 |

회수·강화·개화의 직접 발언과 해석 경계는
[앞선 회수 합의 기록](game_rulebook_next_recovery_2026-09-27.md)을 함께 따른다.
개화 보존을 소실품 재발급이나 같은 파편 종류 전체의 영구 개화로 확대하지 않는다.

## 최종 정정의 근거

사용자는 억제력이 소진되면 귀환/계속하기를 선택하며, 계속하기 이후에는 황금가지로 다시 억제력을
얻어 소진시키거나 전멸할 때까지 진행한다고 정정했다. 이어 다음 예외를 명시했다.

> 아 마지막으로 최종보스를 잡으면 자동 귀환.

따라서 최종 보스까지 반드시 도달해야만 생환한다는 이전 합의는 대체됐다.
반대로 억제력 소진은 선택 없는 자동 귀환이나 자동 패배가 아니다.

봉인 해제의 강화 중첩에 대해서는 다음과 같이 결정했다.

> 황금가지의 억제력이 없는 경우, 황금가지 봉인 해제에 의해 스탯이 증가하지 않기로.

흉탄의 사수는 사용자가 **숨겨진 최종 보스**라고 정정했다. 기존 9월 12일의 일반 보스 통일에서
흉탄에 해당하는 부분을 대체한다. 준최종 등급을 부활시키거나 마탄까지 최종 보스로 바꾸지 않는다.

## 대체되거나 그대로 확정할 수 없는 이전 내용

| 이전 내용 | 현재 취급 |
| --- | --- |
| 1·3·5·7층 엘리트, 2·4·6층 일반 보스 필수 관문 | 새 분기 지도에 맞게 빈도·위치 재설계. 고정 필수표로 사용하지 않음 |
| 연속 일반 보스는 반드시 2층에서 시작 | 옛 일반 보스 자리표에 의존한 규칙. 새 지도의 시작·후속 위치 재검토 |
| 최종 보스에 도달하기 전 생환 불가 | 억제력 소진 시 귀환 선택으로 대체 |
| 최종 보스 승리 후 Endless 연장 | 차기 본편은 자동 귀환. 현행 구현의 비교 설명은 별도로 보존 |
| 흉탄 포함 일반 보스 14개 | 흉탄을 숨겨진 최종 보스로 이동. 선행 비전투 조우를 포함한 일반 보스 계열 항목은 13개 |
| 지도 시안의 흉탄 일반 보스 슬롯 | 분류 정정 전 시안의 오류. 확정 배치나 출현 조건으로 사용하지 않음 |

일반 보스 계열 13개 항목이 모두 즉시 싸울 수 있는 독립 전투라는 의미는 아니다.
마탄·죽은 나비의 장례는 선행 조우 성격이고, 계약·동행·부화 등의 조건이 남아 있다.
음/양은 하나의 조우 항목으로 센다. 내용은 [조우 노트](../skills/abnormality_design_notes.ko.md)를 따른다.

## 제안 또는 미정으로 남기는 내용

- 맵 폭, 전체 노드 수, 각 깊이의 노드 수, 실제 연결 방향과 재방문 규칙. 시안 좌표는 확정 데이터가 아니다.
- 층별 대표 보스 고정과 내부 방 랜덤화의 조합, 일반·엘리트 배치 빈도와 조건부 조우의 출현 변경.
- 시설 개방 조건, 실패한 런의 개방 기록 보존, 실제 플레이 중 미발견 경로의 공개 범위.
- 초기 억제력·소모·보충 수치와 정확한 시점, 황금가지 획득·충전 확정과 전투 후퇴 처리.
- 봉인형의 배정·보상·반복 회수, 무억제 강화의 수치·패턴·엘리트 등 세부 적용 범위.
- 흉탄의 진입 조건과 숨겨진 최하층 연결. 마탄의 선행 조우를 거쳐 공개 최종 보스와 갈라지는
  숨겨진 종착지를 여는 안은 제안이며 확정되지 않았다. 공개 최종 보스 처치 뒤 추가전은 자동 귀환과 충돌한다.
- 정확한 대여 수·대상·재고·저장, 직원·재화·유물·도구 등 나머지 계승 범위.
- 기존 Standard/Endless, 모노리스·숙달·징조 체인·장기 생존 조건을 새 구조로 연결하는 방법.

황금가지의 원작상 유일성·필수성이나 환상체 약화율 50~80%를 밸런스 상수로 채택한 기록은 아니다.
위 미정 사항은 [남은 결정](../game_rules/open-decisions.md)에 추적하며, 이번 문서화에서 수치를 새로 정하지 않는다.
