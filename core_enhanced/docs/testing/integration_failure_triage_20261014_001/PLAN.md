# 추가 통합17개 분류

사용자 요청: 원17의 원인·유지 가치·기존 중복을 개별 assertion과 공개 경로 기준으로 분류한다. 원본 제품/시험은 수정하지 않는다. 직전021/023의17실패 원문을 동일 입력 증거로 재사용한다.

격리 사본에서는 폐기 Standard→현재 Expedition, 필수 loan_copy_ids:[], containment_trainee의 현재 shield/last_line 기대만 보정해 다음 실패를 관측한다. 본래 assertion을 제거하거나 현재 시설을 구형 mode로 대체하지 않는다. 시작 무기는 현재 loader/공식 RON과 구형 룰북 표의 불일치도 별도 기록한다.

단일 실행, 관련 입력 고정. 기존 cache를 재사용하며 빌드 약1–3분/실행1분 이내 예상,60초 runner 관측. 5분 초과/새 실패는 로그와 진행을 진단한다. 후속 준비 오류는 추가 범위만 격리 관측하며, 분류를 구현 완료로 보고하지 않는다. 중복은 완전 대체/고유 assertion 통합 후 제거/부분 중복 유지로 구분한다.
