# U17 수동 조우·최초 보상·알 부화·반복 이행

WPD-CMER-20261015 / 현재 WR-CMER-003. P2G-10 정책 검토 완료.

사용자 U17 착수 요청으로 P2G 준비 후 GEX 구현·자체검증·최종 감사요청 인계까지 수행한다. 중간 단계검토 opt-in 없음. 기존 dirty와 선행 증거를 보존한다. 자동 감사/서브에이전트 없음.

기존 G27/G28/G29, D01/USER11, D04/USER12 및 부활×무억제 결정을 인수한다. 구저장 삭제·조용한 재해석·전체 창고 rollback을 하지 않는다. 콘텐츠 수치는 조절 가능한 작성값으로 분리한다.

## G27 — 수동 조우와 최초 보상

원정별 종류별 최초 보상은 보유량과 독립이다. 엘리트는 첫 승리 파편+장비, 이후 작성된 반복 보상만 지급하고 매번 수동 전투한다. 일반 보스와 최종보스의 기존 예외 및 도감·영구 기록을 보존한다.

- A01: 엘리트 첫 승리에 작성 파편과 장비를 지급하고, 파편 분쇄/상실 후 반복 승리에도 최초 보상을 재지급하지 않는다. 새 원정에서만 최초 원장을 초기화한다.
- A02: 엘리트 자연 반복 후보는 숙달/격파횟수에 의존하지 않고 알·자동 강화·소탕을 생산하지 않는다. 깊이/지역의 작성 난이도와 기존 노드 예약을 유지한다.
- A03: 일반 보스 첫 승리에 작성 파편과 원정 전용 알을 지급하고 최종보스에 알을 추가하지 않는다. 마탄 무보상 등 고유 계약을 유지한다.

## G28 — 알 부화와 명시적 출처 지불

부화 확정은 알·명시 소지/창고 촉매 소비·순수 미해결 일반전 노드 전환을 하나로 적용하며 전투를 시작하지 않는다. 부활 단계와 무억제 배율은 곱한다.

- A04: 부화 전 취소/부족/잘못된 대상은 알·소지/창고 촉매·노드·UUID를 바꾸지 않는다. 성공 시 전환과 출처별 비용만 원자 확정하고 전투·후퇴횟수를 시작하지 않는다.
- A05: 예약/전조/봉인/이미 해결/다른 부화 노드를 대체하지 않는다. Gate 유일 경로라는 이유로 금지하거나 우회로를 생성하지 않는다.
- A06: 현재 소지 또는 창고 촉매를 명시 선택하며 출처별 보유/소비를 공개한다. 별도 사전 반입과 원정별 사용 상한을 추가하지 않는다. 기존 일반 상인의 공용 촉매 공급을 연결한다.
- A07: 단계별 authored 강화와 보상을 진입 전 공개한다. 부활 강화×무억제 강화, 수량형 보상2배와 물품/선택 횟수 불변을 유지한다. 구 모노리스150/200%를 고정 규칙으로 계승하지 않는다.

## G29 — 단계 보상과 선택 권리

두 번째 승리는 전용 장비 선택·파츠·다음 알, 세 번째는 파츠·장비 선택만 지급한다. 승리 즉시 보상/격파/노드 소비/선택 권리를 고정하고 실제 선택을 나중에 처리한다.

- A08: 첫 알로2단계, 다음 알로3단계 전투만 열며3단계 승리에는 알이 없다. 패배에는 성공 보상/격파/알을 주지 않고 비용도 반환하지 않는다.
- A09: 2/3단계 장비 후보·선택 대기 권리는 결과 즉시 저장하며 후보를 재추첨하지 않는다. 후보 부족은 실제 후보,0개는 안내 후 생략하며 대체 보상이나 새 중복 제한을 만들지 않는다.
- A10: 장비 선택/결과 확인/재접속/동일 명령 재시도에서 보상은 한 번만 지급한다. 앞선 선택과 다른 부위도 고를 수 있는 authored 후보를 제공한다.
- A11: 알 부활한 봉인 보스에는 황금가지와 억제력 보충을 주지 않는다. 엘리트/보스에 유물을 자동 추가하지 않는다.

## RESTORE — 후퇴·복원·노드 수명

수동 후퇴는 부화 후 전투 진입 상태로 복원하며 부화비와 최초 입장비를 유지한다. 미확정 노드 Continue와 SavePoint는 해당 경계의 조우/알/소지/창고를 같이 복원한다.

- A12: 부화 후 보류/수동 후퇴는 동일 노드·단계·지불을 유지한다. 후퇴는 최대2회, 두 번째 후퇴 후 마지막 도전 가능, 승패 즉시 노드 소비와 실패 통과를 유지한다.
- A13: 노드 입장 전에 확정된 부화는 fresh Continue에 남고 미확정 노드 안 부화는 원래 조우/알/소지·창고 촉매와 함께 입장 전으로 복원한다. 같은 프로세스 재접속은 현재 상태를 유지한다.
- A14: 부화 전/후 SavePoint는 각각 당시 노드/알/촉매/선택 권리를 복원한다. 창고 전체를 덮어쓰지 않고 해당 원정의 출처별 debit을 기존 U15 방식으로 복원한다.
- A15: 같은 층 연결 재방문은 같은 미해결 부화를 유지하고 하강 뒤에는 남긴 환상체를 다음 방/원정으로 옮기지 않는다. 입장/재진입 비용을 중복 청구하지 않는다.
- A16: 실제 저장 IO 실패는 부화/비용/결과/권리의 부분 확정을 남기지 않고 정상 동일 명령 재시도가 가능하다.

## LEGACY — 구 명령·저장 이행

구 숙달·소탕·모노리스 소비를 공개 활성 경로에서 제거한다. 기존 개발 저장은 원본을 보존하고 미지원 형식으로 명시 거절한다. 조용한 재해석/자동변환을 하지 않는다.

- A17: 구 모노리스/소탕 명령은 typed rejection이며 활성 action/query/상점에는 제안하지 않는다. 새 저장/복원에 구 진행이 살아나지 않는다.
- A18: 구형 지원 저장 원본은 불변으로 보존하고 version/typed 오류로 명시 거절한다. 새 지원 형식은 현재 진행·도감·영구 기록·선택 권리를 왕복 보존한다.
- A19: 튜토리얼 전용 보상·자산/영구 기록 격리와 선행 U04/U12/U13/U14/U15/U16 기능의 영향 회귀를 유지한다.
