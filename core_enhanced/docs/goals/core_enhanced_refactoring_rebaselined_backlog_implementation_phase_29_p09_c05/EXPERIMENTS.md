## 2026-08-11 — E03 Current Authority And Compatibility Inventory

- Basic attack and skill delivery retain distinct public runtime records (`ProjectileRecord` and
  `ActiveProjectileRuntime`), identities, launch logs/events and terminal/effect adapters. Neither record is serde,
  but both are public Rust shapes and remain unchanged under CRA-POL-006.
- Basic advance removes one runtime, clamps the requested time to its launch deadline, rejects stale work, samples
  only the locked target at both window endpoints, chooses live aim for `Homing` or stored aim for `Fixed`, performs
  one continuous moving-circle sweep, commits Phase 28 damage on hit, otherwise expires or queues the next 1ms
  advance. It never considers a bystander.
- Homing skill advance has the same speed-limited endpoint, continuous sweep, fractional impact position and
  ceiling-to-event-time mechanics. Its adapter separately owns target validity, skill collision radius, impact
  event construction and Phase 14 terminal delivery.
- Fixed directional skill advance samples a fixed launch trajectory over an elapsed-time window, gathers eligible
  bodies, computes the same continuous collision facts, orders them by ceiling hit time, squared separation and
  `UnitInstanceId` byte order, then separately applies seen-hit, piercing, max-hit, max-kill, expiry and terminal
  policy. Those acceptance and lifecycle rules are not motion-kernel inputs.
- The shared private pure boundary is therefore: a typed projectile path window; typed moving-body collision
  candidates; speed-limited homing or fixed-trajectory endpoints; exact fractional impact positions; ceiling hit
  times; stable ordered collision facts; and the next 1ms reevaluation fact. Event scheduling, target selection,
  collision-policy acceptance, records, damage/effects and terminal state remain in the two adapters.
- Zero distance is an immediate overlap query, sub-millisecond travel rounds its event time upward, exact-ms travel
  stays exact, moving targets are sampled at both endpoints, and same-time candidates retain time/distance/ID
  ordering. Existing fixed-path expiry queues a terminal miss only when no earlier hit exists; this ordering is
  preserved.
- Publication remains strict: live definitions reject zero projectile speed. The defensive zero-speed branches in
  established math remain behavior-compatible implementation guards, not an accepted data fallback or alternate
  publication path.
- `BattleEvent`, `BattleLogEvent`, behavior DTO/observation and accessible Unity consumption use launch/advance/
