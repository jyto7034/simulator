# U16-3 게임 판본과 위임 초기 정책

이 문서는 P2G-10의 위임 결정이다. 근거는 로드맵 U16-3, game_rules/relic-reward-nodes.md의 게임 세부 규칙·NPC·초기 수치 위임, DECISIONS_20261004 CF-D06이다. 사용자 직접 선택과 구별하며 기존 사본/비용/복원 원칙을 변경하지 않는다. 현재 사용자 요청은 구현 후 비참여 서브에이전트 감사까지 허용한다.

## 조우와 수치

제안은 기존 VN 포트의 첫 원정 설명/짧은 반복 설명, 첫 게임 선택 뒤 별도 갬빗 VN으로 제공한다. 원정 설명 이력은 RunProgression, 조우는 RewardSession, 미완료 복원은 기존 입장 전 checkpoint가 소유한다. 첫 설명·거절 여부와 기본 지급은 조우 상태에 일회 적용한다.

초기 기본 포인트30,2배/3배 비중1:1, 최소 판돈1, Flip7 버스트/수동포기 기본손실10, Flip 점수 환산1:1, 비버스트1위 보너스20, 일반/희귀/특급 담보 원금10/30/60. 그 외 기존 작성 rarity도 담보 가능하며 default_pledge_value의 공개 원금(초기10)을 사용한다. authored 상품마다 양수 가격·재고와 고정 유물 묶음을 둔다. 수치는 플레이 조절값이며 갬빗은 오직 게임 순손익에만 적용한다. 포인트는 부호 있는 정수, 자연수3:2 배당의 반 포인트는 내림한다. 판돈은 시작 시 양수 잔액 이하이며 갬빗 손실이 잔액을 초과해도 허용한다. 구조적 정수 overflow는 무변경 오류이며 판수 게임 상한을 만들지 않는다. 현재 판과 마지막 판 결과만 유지한다.

게임 선택 뒤 Ready 단계에서 시작/취소하며 취소에는 비용이 없다. 시작 뒤 포기는 한 판의 손실이다. 정산 이후 새 게임/대출로 돌아가지 않으며 담보정산→상점→나가기 순서다. 나가기에서 포인트 소멸을 안내·확정한다. 모든 명령은 공개 session revision을 요구해 동일 요청 중복을 거절한다.

## 블랙잭

기준: [Bicycle Blackjack](https://bicyclecards.com/how-to-play/blackjack), 2026-10-15 확인.52장·Ace1/11·딜러17이상 정지·natural3:2·승리1:1·동률0을 사용한다. 이번 판본은 단일덱 S17, hit/stand/double, split·insurance 없음으로 명시한다. double은 최초2장 때만 추가 판돈을 낼 수 있으면 판돈2배/한장추가/자동stand다. 새 판마다 셔플한다. 첫2장natural은 즉시 판정하고 딜러natural과 같으면push다.21은자동stand, 버스트는패배다. 딜러hole은종료전비공개다. NPC2명도 자기 손패와딜러에대한같은판정을 받는다. 보수형은15이상, 공격형은18이상에서 멈추며 미래 카드/딜러hole을 보지 않는다. 수동포기는현재유효판돈손실이며갬빗을곱한다.

## 주사위 포커

기준: [Dice.now 구현자의 Poker Dice 규칙](https://dice.now/dice-poker), 2026-10-15 확인.5개의1~6주사위·최대3회·보유주사위재선택의판본을채택한다. 조합은 FiveKind > FourKind > FullHouse > Straight > ThreeKind > TwoPair > Pair > HighCard. 같은조합은구성주사위의높은눈,그뒤남은눈내림차순으로비교하며스트레이트는최고눈을비교한다. 보드/누적매치 대신 현재조우 한 판에서3명이겨룬다. 플레이어단독최고는+wager,공동최고는0,패배는-wager다. Flip7 보너스를 적용하지 않는다. 두NPC는 공개된 자기최대동일눈묶음을유지하고보수형은TwoPair이상,공격형은FullHouse이상에서멈춘다. 플레이어가stand하거나3회굴리면NPC잔여행동을처리하고비교한다.

## Flip7

기준: USAopoly/The Op의 **기본판 Ruleset3.1**, [발행사 FAQ](https://theop.games/pages/flip-7-faqs)와 [발행사 원문 PDF 보관 미러](https://bghub.org/r/flip7.pdf), 2026-10-15 확인. 다른 확장판은 사용하지 않는다. 숫자0은1장,1~12는각해당숫자장수, 보정+2/+4/+6/+8/+10/x2각1장,Freeze/FlipThree/SecondChance각3장으로94장이다.

3명은순서대로첫카드를받고hit/stay를선택한다. 숫자중복은bust,SecondChance가있으면그카드와중복숫자를버리고계속한다. 추가SecondChance는다른활성참가자중아직없는대상에게주고대상이없으면버린다. Freeze는대상점수확보/비활성,FlipThree는대상이3장을강제로받는다. 강제3장중Freeze/FlipThree는3장을다받은후처리하고버스트하면그대기행동을폐기한다. SecondChance는즉시사용가능하다. 어느때든7개다른숫자가모이면전체판을즉시종료한다. action/modifier는숫자7개에세지않는다. 액션소유자가활성대상(자신포함)을선택하며혼자남으면자신에게적용한다.

숫자합×(x2있으면2)+가산보정+7숫자보너스15를기본점수로한다. 점수환산+1위보너스의공동1위몫을합친뒤갬빗을곱한다. 버스트는0점공동1위에포함하지않고공개손실을차감한다. 이번조우는원작한라운드가한판이며200점목표/동점추가라운드를사용하지않는다. 조우의남은덱/버린카드는Flip판사이에유지하고모든판의공개카드를라운드종료때버림더미로옮긴다. 새덱이필요하면버림더미만셔플하며현재공개카드를섞지않는다. 새조우에서는새덱이다.

보수NPC는숫자3개또는점수20이상,공격NPC는숫자5개또는점수35이상에서stay한다. action대상은공개된다른활성참가자의현재숫자수/점수로결정하며SecondChance는받을수있는대상에게준다. NPC판단함수는덱/seed/cursor를입력받지않는다. 조회는모든공개카드·점수·참가상태와플레이어대상선택을제공하고미래덱/난수상태를숨긴다.

원본 문구/그림/에셋을 제품에 복제하지 않고 규칙을 직접 코드로 구현한다. 외부 게임 라이브러리는 도입하지 않는다.
