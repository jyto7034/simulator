## Approved Policy Boundary

CRA-POL-004 defines two distinct aggregation points:

- cast admission: useful when any step has a useful executable effect over its actual delivery targets;
- step execution/no-op: evaluate only the current step's actual delivery targets.

A useless first step does not reject a cast with a useful later step, and a no-op current step does not cancel later
work. Anchor identity is geometry input, not usefulness proof. CRA-POL-006 forbids incidental shape migration.
