# U15 사본 성장·실제 투자 환급·창고 재료 소비

WPD-CGMV-20261014 / 현재 WR-CGMV-003. P2G-10 정책 검토 완료.

사용자 U15 착수 요청으로 P2G 준비 후 GEX 구현·자체검증·최종 감사요청 인계까지 수행한다. 중간 단계검토 opt-in 없음. 기존 dirty와 선행 증거를 보존한다. 자동 감사/서브에이전트 없음.

신규 정책 선택 없이 기존 G20/G21/G22 및 D01/USER11을 인수한다. 강화 수치·한도는 D02 초기 authored 값으로 인수하고 검증한다. 창고 전체 rollback과 실제투자 추정은 금지한다.

## G20 — 사본별 정비 성장과 실제 recipe

일반 강화는 무기만·소지 장비 가루만 소비하며 기존 authored 강화 수치와 한도 초기값을 사용한다. 파편 개화는 형태별 RON 파츠와 명시 엔케팔린 비용을 한번 소비한다. 같은 사본의 선택 형태/직원 이전은 재투자하지 않고 같은 정비 노드 반복은 입장 비용을 반복하지 않는다.

- A01: 무기만 강화하고 방어구/장신구 강화는 작성/실행에서 거절한다. recipe 없는 작업은 불가이며 authored 한도 직전/도달에서 preview와 실행이 일치한다.
- A02: 중복 material은 종류별 checked 합산하며 소지/선택창고 총액과 엔케팔린 전부 충족할 때만 성장·소비가 함께 적용된다. 하나라도 부족하면 상태와 UUID를 바꾸지 않는다.
- A03: 개화 해금 뒤 형태 선택/직원 이전/같은 형태 재개화는 비용·투자를 추가하지 않는다. 무료 grant/조우 해금은 투자0을 유지한다.
- A04: 같은 정비 노드에서 여러 성장/분쇄를 해도 억제력/유예는 최초입장 한번이다. Safezone에 정비를 추가하지 않는다.

## G21 — 실제 투자 원장과 분쇄 환급

사본에 실제 소비한 강화 가루/개화 파츠를 기록하고 분쇄 때 재료 종류별 총투자의 초기50%를 내림 환급한다. 환급은 현재 소지분이며 엔케팔린 투자 환급은 없다. 기본 분쇄 recipe 보상과 환급을 구분한다.

- A05: 가루/파츠 종류별 홀수 합산 뒤50%내림이며 현재 recipe를 변경해도 실제 투자 기반 환급은 같다. 개별 거래마다 내림해 합산하지 않는다.
- A06: 무료 강화/개화는 투자 환급0이며 형태/소유 직원 변경으로 투자 증가나 중복 환급이 없다. 사본별 투자와 보상을 격리한다.
- A07: 장착 장비/파편 분쇄는 확인 필요를 query에 표시하고 미확인 거절은 무변경이다. 확인 뒤 해제·사본소멸·기본보상·환급을 함께 적용하고 반복 요청은 보상을 주지 않는다.
- A08: 무기 반출 때 강화와 그 투자 모두 초기화한다. 개화 파편 귀환→재대여→분쇄는 동일 사본의 실제 파츠 투자만 한번 환급한다.

## G22 — 공용 재료 창고와 명시적 출처 결제

소지/창고 수량과 선택 소비량을 공개하며 개화에서 명시한 출처별 재료를 직접 소비한다. 창고 사전반입/운반/원정사용한도는 없다. 성공 귀환 때 선택 파츠 종류합계2와 별도 부활촉매1만 회수하고 미사용 창고는 실패에도 유지한다.

- A09: 소지+창고 혼합 개화에서 선택량 그대로 차감하고 다른 출처로 자동 대체하지 않는다. 중복행/부족/과다/잘못된 출처는 전체 무변경이다. 창고가 없어도 소지 전용 정상 경로는 유지한다.
- A10: 공개 조회는 요구량·소지/창고 보유량·선택 비용·투자·환급을 실제 결과와 일치하게 표시하며 조회는 상태를 바꾸지 않는다.
- A11: 성공 귀환 회수 선택은 파츠 종류합계0~2와 부활촉매0~1을 각각 검증한다. 가루/알/엔케팔린/침식촉매/일반소모품은 보관하지 않으며 장비/파편2사본 대여한도와 혼동하지 않는다.
- A12: 실패/포기는 소비한 창고재료를 돌려주지 않고 미사용 재료/미대여 사본은 보존한다. 소지 환급 파츠도 귀환 선택 없이는 창고에 넣지 않는다.
- A13: U17이 사용하는 부활촉매 소지/창고 결제 포트를 제공하되 실제 알 부화/조우 실행은 U17이다. 공통 결제 경계의 원자성과 조회는 U15에서 검증한다.

## STORE — 현재 원정의 출처별 복원과 지원 저장

원정별 창고 소비 영향과 사본·투자·성장·분쇄결과를 같은 시점으로 복원한다. 전체 profile/창고를 과거 snapshot으로 덮어쓰지 않는다. 새 지원 저장은 엄격히 보존하고 미지원 구개발저장은 원본보호·명시거절한다.

- A14: 소지+창고 혼합 개화→분쇄→SavePoint 복구는 원래 사본/형태/투자/소지/창고 소비를 함께 되돌린다. 체크포인트 이전 소비는 유지하고 반복복구로 증가하지 않는다.
- A15: 미확정 정비 노드 종료 뒤 새프로세스 Continue는 입장 전 소비/결과로 복원한다. 정비 완료 후 Continue는 확정 거래를 유지한다. 같은프로세스 호출로 새프로세스 검증을 대체하지 않는다.
- A16: 복원은 현재 원정의 소비 차이만 반영하며 무관한 창고 보관과 영구기록을 보존한다. U12 회수품 합집합 merge를 재료 수량 복원에 재사용하지 않는다.
- A17: 실제 저장 IO실패와 재시도에서 소비만/성장만 반영하지 않는다. active/profile 묶음의 저장·재시작을 확인한다.
- A18: 투자 내역 없는 구지원 전제는 D01에 따라 미지원 형식으로 명시 거절하고 원본을 보존한다. 실제투자 추정/자동0이행/임의삭제하지 않는다. 새 grant의 무료 투자0은 구저장 이행과 구별한다.

## AUTHOR — 제작 입력·소비자와 비용 검증

외부 장비/파편도 같은 검증 recipe·사본·공개 명령·저장 경로를 사용한다. 잘못된 작성 참조/조합을 거절한다. 현재 기능에 필요한 경계만 바꾸며 정상/확장 workload 비용을 측정한다.

- A19: 정상 외부 RON의 복수 파츠/중복material/엔케팔린 비용은 preview와 실행이 같다. 누락 material/금지강화대상/잘못된 비용종류/합산 overflow는 정상 로더에서 거절한다.
- A20: 공개 Core application/host의 명령→조회→저장→재시작에서 실제사본과 원장·창고 결과를 확인한다. helper만의 결과를 공개 경로 완료로 주장하지 않는다.
- A21: 대표 정상·확장 입력의 실행시간/실제메모리 peak와 회수를 관측하고 내부 retained/work 회계와 구별한다. 기존 한도 변경 필요는 근거로 판단하며 임의증가하지 않는다.

현재 선택 갱신: `WR-CGMV-004` / `FPF-CGMV-001` / `PP-CGMV-002`. P2G-20 정적검토·P2G-30 동결·P2G-40 구조검증 완료. 실제 제품/시험0.
