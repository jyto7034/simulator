# U16-4 스트레스 전투 상세 계약

2026-10-15 현재 사용자 요청이 구현·검증 후 비참여 서브에이전트 감사를 승인하며 지시서의 no-subagent/감사요청대기보다 우선한다. U17/U21/Unity/개별최종보스는 제외한다.

1. 정상 RON의 StressCombat 배정에서 보호 대상 방어 연속 전투를 시작하고 첫 라운드 보상을 공개한다.
2. 최대5라운드의 작성된 웨이브를 모두 처치해야 각 라운드를 완료한다. 뒤 라운드는 콘텐츠로 강화한다.
3. HP/배치/자원/쿨다운/전투당 기록/보호 대상을 같은 전투에서 유지하며 라운드 사이 시간은 정지한다.
4. 선택 구간은 계속 방어와 보상 받고 철수만 허용하며 누적/다음 보상에 적용 배율을 공개한다.
5. 개별 라운드에는 실제 보상/XP/노드 소비를 하지 않고 성공 철수 또는5라운드 완료에서 누적분을 한번 지급한다.
6. 보호 대상 파괴 등의 패배는 미수령 보상을 전부 상실하고 공통 직원 손실/생존 XP는 전투 전체1회 적용한다.
7. 전투 중 수동 후퇴는 직원/소비/장비/유물을 진입 전 복원하고 노드 소비/보상 상실/재도전 불가를 유지한다. 최초 입장 비용은 유지하며 XP는 지급하지 않는다.
8. 무억제 진입의 적 HP/공격력 강화를 전 라운드 유지하고 성공 XP/재료/엔케팔린 총량2배, 유물 수량 불변, 패배 기본 XP 기존량을 검증한다.
9. 같은 프로세스 재접속은 선택/미수령 상태를 유지하고 fresh Continue 미완료는 입장전, 완료는 결과/소비를 함께 보존한다. SavePoint와 실제 IO 실패/동일명령 재시도를 검증한다.
10. 정상/오류 작성과 공개 application/host/query/consumer 및 기존 영향 회귀를 검증하고 정상/확장 비용과 실제 메모리 회수를 측정한다. 외부 임의 변조 방어는 제외한다.

기존 유물 보상 노드/XP/억제력/저장 규칙이 상위 정책이다. CF-D06의 통상 콘텐츠 상세화로 라운드는 정확히5개, 각 라운드는1개 이상의 명명 웨이브와 고정 RewardEffect 목록을 작성한다. 추가 고유 실패 조건은 만들지 않는다. 보호 대상은 기존 DefenseRoute의 목표와 대상 자격을 재사용한다. 보상은 누적분을 ClaimAll로 공통 grant에 연결하며 별도 선택은 없다. 라운드 경계는 같은 timestamp의 사건과 패배 판정을 먼저 정리한다. 계속/철수는 battle UUID와 완료 라운드를 확인하여 중복을 거절한다. 초기 대표 콘텐츠는 라운드당1웨이브/엔케팔린10,20,30,40,50이며 U21 최종밸런스가 아니다.
