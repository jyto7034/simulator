## 구현 담당자에게 전달할 실행 방식

1. 전체 회귀는 지시서의 기본 병렬 명령을 사용한다. 공유 상태 간섭이 재현되는 특정 시험만 격리나 개별 순차 실행을 검토한다. 전체 단일 스레드는 재현성의 일반 필수 조건이 아니다.
2. 현재 `segments/wp02_d07_static_explain_001/run.py`는 `subprocess.run(stdout=PIPE)`가 끝난 뒤 로그를 기록한다. PIPE 자체를 실행 지연 원인으로 판단하지 않는다. 진행이 안 보이고 중단 시 수집 로그가 저장되지 않는 것이 문제다.
3. 래퍼는 시작 즉시 고유 로그 파일을 열고 출력을 계속 기록하도록 개선한다. 콘솔에는 진행 또는 주기적 상태를 표시한다. 중단/시간 초과도 부분 로그와 상태를 남기고 자식 종료를 확인한다. 미완료 실행을 통과 영수증으로 기록하지 않는다. 재시도는 새 실행 ID를 사용한다.
