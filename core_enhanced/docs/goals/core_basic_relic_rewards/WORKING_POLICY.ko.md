# U16-2 기본 유물 보상: 단순 선택·가루 투자·유물 합성

WPD-CBRR-20261015 / 현재 WR-CBRR-003. P2G-10 정책 검토 완료.

사용자 U16-2 착수 요청으로 P2G 준비 후 GEX 구현·자체검증·최종 감사요청 인계까지 수행한다. 중간 단계검토 opt-in 없음. 기존 dirty와 선행 증거를 보존한다. 자동 감사/서브에이전트 없음.

G26 중 U16-2를 인수한다. CF-D06 위임에 따른 초기 가루 임계치3/9/18·후보 동일 가중치1은 플레이 조절값이다. U16-3/4는 후속 범위다.

## CHOICE — 単純選択と活動配置

U13が固定した活動種類で入場し、単純選択は authored 候補から異なる最大3種類を提示して1個を共通grantで取得する。

- A01: 지도 생성의 고정 유형/초반 단순 선택 예약을 유지하고 입장 전 유형·가루 요구량·합성 조건을 공개한다. U16-3/4는 실행 지원으로 표시하지 않는다.
- A02: 단순 선택은 서로 다른 최대3종 중1개를 Normal 사본으로 지급한다. 후보1/2개는 실제 수,0개는 이유 안내/선택 생략을 제공한다. 기존 보유/장착 제한을 후보 획득 제한으로 추가하지 않는다.
- A03: 재조회/선택 변경으로 후보를 재추첨하지 않고 미이용 퇴장은 보상/활동 비용 없이 노드를 소비한다. 최초 입장 억제력은 별도다. 중복 수령/퇴장은 추가 지급하지 않는다.

## DUST — 장비 가루 투자

장비 가루로 일반→희귀→특급의 다음 임계치까지 일괄 투자하고 현재 등급 최대3택1을 최종 한번 수령한다. 초기 누적 임계치는3/9/18이며 authored 초기 밸런스다.

- A04: 일반 최초 투자와 각 승급은 다음 누적 임계치 차액 전부를 지불한다. 부족/부분투입/최고등급 추가 투입을 거절하며 자원과 후보는 유지한다.
- A05: 투입 전에 다음 등급 후보가 존재하는지 검사한다. 불가하면 비용/기존 후보/확보한 권리를 보존한다. 현재 등급 후보/효과와 다음 등급/차액을 공개하되 미래 후보는 공개하지 않는다.
- A06: 성공한 투입은 보장 등급의 서로 다른 최대3후보로 이전 후보/선택을 대체한다. 이전 등급 수령과 누적 지급을 막고 최종 선택1개만 공통 grant로 지급하며 노드를 소비한다. 활동 내 취소 환불은 없다.

## FUSION — 유물2→1 합성

서로 다른 미장착 사본2개를 소비하고 입력 등급 조합의 고정 확률에 따라 입력 종류를 제외한 Normal 사본1개를 지급한다. authored 등급 내 가중치를 사용하며 초기 대표값은 동일가중치1이다.

- A07: 미장착의 서로 다른 사본2개를 선택한다. 침식 입력은 허용하고 장착/없는 사본/동일 사본은 거절한다. 투입 종류는 결과에서 제외하며 그 외 보유 종류는 허용한다.
- A08: 선택 후 확정 전 일반/희귀/특급 확률을 표시한다. 여섯 조합은80/19/1,40/55/5,0/70/30,0/80/20,0/40/60,0/0/100이며 입력 순서에 무관하고0% 등급은 결과가 되지 않는다.
- A09: 입력 종류 제외 뒤 확률이 양수인 모든 등급에 결과 후보가 있어야 확정 가능하다. 불가 이유를 공개하고 소비/선택/원본을 유지하며 확률 재분배/대체 지급/재추첨을 하지 않는다.
- A10: 확정은 두 입력 제거와 Normal 결과1개 공통 지급 및 노드 완료를 원자적으로 처리한다. 노드당1회이며 결과 재투입/중복확정/재접속 재지급을 막는다.

## STORE — 활동 상태와 복원

후보·선택·누적 투자·사본·비용·결과·노드 상태를 같은 저장/실패 경계에 포함한다.

- A11: 같은 프로세스 재조회/재접속은 현재 활동 진행을 유지한다. 미완료 노드 새프로세스 Continue는 입장 전 비용/사본/진행을 함께 복원하고 재입장 시 같은 지도/동일입력 후보와 추첨을 유지한다.
- A12: 완료한 수령/합성/미이용 퇴장의 결과와 소비를 새프로세스에서 유지한다. SavePoint도 그 시점의 비용/결과를 함께 복원하며 무관한 영구기록/창고를 보존한다.
- A13: 실제 정상host 저장 IO실패 때 메모리/active/profile의 부분 변경을 남기지 않고 유효 재시도로 한번만 처리한다. reader/writer와 공개consumer를 함께 검증한다.

## AUTHOR — 정상 작성과 공개 검증

지원 작성 입력의 후보/가중치/가루 임계치와 고정 활동규칙을 구분하고 정상 loader/application/host 경로와 실제 비용을 검증한다.

- A14: 정상 RON/pack으로 후보 종류·양수 가중치·증가하는 양수 가루 임계치를 작성하고 실행한다. 누락 참조/중복 종류/미지원 등급/0가중치/합계 overflow/잘못된 임계치를 로더에서 거절한다. 빈/부족 후보는 유효 입력이다.
- A15: 대표 원정의 U13배정/예약·U14입장비용·정상조회/명령·공통grant·노드완료를 검증한다. 공식 유물 catalog 공백과 외부 지원pack fixture를 구별하며 U21 콘텐츠나 전체 U16 완료를 주장하지 않는다.
- A16: 정상/확장 후보·사본의 시간/실제 메모리 peak/회수와 내부 작업량을 구분 관측하고 기존 유한 한도를 평가한다. 지원 입력 오류/실제IO는 범위 안이며 임의변조 전용 사례는 제외한다.
- A17: 기존 보상/상점/Event/소비품/저장 영향 회귀를 관련 호출 경계로 선정하고 실제 실행과 동일/비영향 재사용을 구별한다. 감사 전 복원 가능한 baseline과 최종 target을 고정한다.
