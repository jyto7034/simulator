`causal_live_sources`는 active action, nested Join held source, 독립 Periodic 이외 queue source, active cast, buff, skill/basic projectile, area 및 독립 객체 source를 읽는다. per-event settlement는 timestamp drain의 남은 event slice도 borrow해 동일 계량을 거쳐 함께 읽는다. 독립 Periodic은 여기서도 후손 carrier에서 제외한다. 이 목록의 live 관찰과 기존 `FactSummary`의 bounded latest/latest_nonzero·actor/provider/action witness는 다르다. live ancestry/Join 회수는 모든 immutable fact Arc나 process heap이 0이라는 뜻이 아니다. tests005의 정상 ApplyBuff→pending descendants Join 회귀와 current owner 제거 뒤 접수된 Periodic 자식의 원 program/numeric 존속·최종 회수가 통과했다.

공개 `causal_runtime_snapshot()`은 현재 live context/cause·참가 상태·counter/producer 수의 owned 설명이다. 반환된 값에 실행 binding이나 완료 권한은 없다. transient 상태는 기존 native work/clone/retained admission과 후보 transaction에 묶이며, 한도 실패는 정상 완료로 바꾸지 않는다. H의 exact/one-short·prefix rollback/retry는 실행 기록의 해당 source/시험 결과로 연결한다.
