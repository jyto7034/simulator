The checkpoint field macro in `world/state.rs` is the sole registry for current rewind-owned run roots. `ContinuePayload` adds only phase/recovery/result/choice/VN ownership needed for continuation, with a separate optional SavePoint. `BattleEntrySnapshot` remains the existing retreat owner. The host transports opaque Core bytes and never reconstructs rewards, node outcomes, employee condition or save semantics.

Future roadmap owners extend this inventory when implemented: U05 employee node recovery/lifetime refinements; later fixed facilities/support, suppression/power, warehouse/loan/expedition settlement, tools and relic owners under their assigned units. This inventory does not claim schema or tests for those future systems. Actual Linux local adapter/process behavior is exercised; Windows crash behavior, remote deployed populations and Unity UI are not claimed.
