### BASIC active ally target seam

`SkillTarget::AllySingle` is an explicit same-side unit selector, compatible with AutomaticUnit/PlayerUnit, with the same required Pattern range contract as EnemySingle. Automatic selection ranks living allies by HP ratio/distance/ID and checks skill usefulness; fixed player selection is revalidated at release and never retargeted. Ally healing on full HP has no useful HP effect; non-healing ally effects retain their own existing payload semantics. Instant ally release uses the existing ApplyHeal/HealExpr owner and action credential, while tile ally area uses the existing TileArea hit filter. Hostile usefulness stays unchanged. Compiler exhaustive matches cover SkillTarget consumers; strict public starter RON and command flow will exercise this seam before completion.
