# U14 입장 비용·억제력·보상 정책

Working Policy Document ID: `WPD-CEDR-20261014`

현재 head: `WR-CEDR-003`; P2G-10 complete. [결정/수용 조건](P2G_10_DECISIONS_001.json), [인수 원문](P2G_00_INITIAL_001.json).

사용자 U14 착수 요청과 후속 “1번” 선택을 근거로 P2G-00→60, GEX-00→10을 수행한다. 기본 종료점은 구현·자체 검증 후 감사 요청 인계이며 중간 단계검토는 선택하지 않았다. 기존 dirty 변경과 U13 감사 증거를 보존한다.

부활/무억제 배율은 곱셈이다. 봉인해제 추가 스탯 중복 금지는 별도 유지한다. D-02 초기 authored 수치는 구현·플레이 검증 때 조정할 수 있으나 새 게임 규칙은 추가하지 않는다. 전체 보스 본체/U16 스트레스 활동은 각 후속 owner의 범위다.

## G13 — 노드 최초 입장 비용과 처리 순서

활동 노드 authored 규정 비용을 같은 identity 최초 입장에 한 번 반영한다. 비용/receipt→Breakdown 유예·사망→소진 선택→활동 순서이며 이동/Start/Gate/재입장/후퇴/완료는 추가 비용이 없다.

- A01: 비용2/잔량1과 비용2/잔량0 모두 잔량0·규정 유예2이며, 비용0은 유예 무진행이다. 같은 노드 재입장/정비 반복은 중복 청구하지 않는다.
- A02: 공개 preview는 비용·예상 잔량·무억제 여부·직원별 예상 유예/사망을 실제 입장과 일치하게 표시하고 상태를 변경하지 않는다.
- A03: SavePoint/치료 노드도 비용과 사망을 먼저 확정하고 사망 직원을 그 노드 치료로 되살리지 않는다. 시작/Gate/방 이동은 무료다.

## G14 — Breakdown 규정 비용 누적 유예

트라우마100 유예는 규정 첫 입장 비용 누적4 초기값이며 완료노드 카운터를 제거한다. 99이하로 내려가면 폐기하고 재100시 새 유예. 밖에서의 사망은 일반 장비 회수, 전투 사망 방지 미적용.

- A04: 새 유예4에서 비용1+2+1은 마지막 입장에서 사망한다. 완료/재입장/비용0/황금가지 보충으로 유예가 바뀌지 않는다.
- A05: 트라우마99 치료 뒤100 재진입은 새 유예4이고, 입장 사망은 장비/파편/유물 회수를 수행하며 전투 사망 방지로 취소되지 않는다.
- A06: 입장 사망으로 출전 불가이면 기존 런 실패/복구 자격을 적용한다. 잔량 부족·0에서도 같은 규정 비용으로 사망한다.

## G15 — 실제 소진 전이와 활동 전 선택

U12의 >0→0 소진 선택을 재사용한다. 깊이1~2 계속/포기, 깊이3이상 귀환/계속. 해당 활동은 선택 뒤에 시작하며 소진 자체는 실패가 아니다.

- A07: 깊이2/3 비용 소진 선택을 실제 공개 명령으로 구분한다. 깊이2 귀환은 거절, 계속은 해당 활동, 포기는 실패 정산이다.
- A08: 소진 귀환은 미시작 활동 보상·완료를 주지 않으며 기존 회수품의 정상 성공 귀환은 유지한다.
- A09: 이미0인 상태의 다음 입장/깊이3 도달만으로 선택을 다시 열지 않는다. 보충후 재소진은 새 선택이다.

## PWR01 — 고정 난이도와 무억제 적 스탯

적 스탯/웨이브는 작성된 난이도만 따른다. 편성/Certified/런 최고 전투력은 적 강화에 쓰지 않는다. 무억제 전체 적 HP/ATK에 authored 1.5~2배, 부활 단계 배율은 곱한다. 속도/사거리/저지/패턴 불변.

- A10: 동일 seed/조우에서 편성·장비·최고전투력만 바꿔도 적 능력치/구성은 같다. 위험도/준비 정보는 유지할 수 있다.
- A11: 일반 적/엘리트/보스/부활의 생성 적과 지연 spawn에서 HP/ATK만 배율 적용되며 속도/사거리/저지/패턴은 불변이다.
- A12: 최초 비용 반영 후 전투 진입시 무억제 자격을 고정한다. 1.5배 부활×1.5배 무억제는2.25배이며 봉인 추가 스탯은 무억제와 중복하지 않는다.
- A13: 조우별 배율은 진입전 공개되고 작성 범위 밖/비정상 제작 입력을 로더가 거절한다. 전투마다 숨겨진 추첨은 없다.

## PWR02 — 무억제 승리 수량 보상

진입 snapshot이 무억제인 전투 승리 시 엔케팔린/가루/파츠/XP의 기존 총량을2배로 한 번 적용한다. 기본 생존XP/보너스 포함, 대상은 유지. 패배 기본XP 유지/후퇴0. 봉인 승리 보충은 snapshot에 영향 없음.

- A14: 서로 다른 기본·추가·보너스 재료/XP의 합계가 정확히2배이고 실제 참가자/전체생존/선택직원 등 기존 XP 대상과1인당 수량을 유지한다.
- A15: 물품/알/파편/장비/유물/촉매제/선택횟수/황금가지/보충량과 비전투/판매/분쇄/반출은 배율 제외다.
- A16: 패배 기본 생존XP10, 후퇴0. 승리후 억제력 보충·결과재확인·Continue로 누락/중복배율·중복보상이 없다.
- A17: U16-4가 소비할 전투 전체1회 자격/배율 seam을 제공한다. U14는 스트레스 활동 전체 구현 완료를 주장하지 않는다.

## G16 — 황금가지 작성 배치안과 지도 공개

시설 실제 이동조건에 적합한 복수 작성 배치안 중 새 원정 시작에 하나를 선택해 유지한다. 즉시 조우 고정 일반 보스4종이 정식 대상이며 조건부/부활은 제외. 도달가능·주요 하강 경로 기회와 미탐사 가지 위치 공개를 지킨다.

- A18: 새 원정에서 plan을 선택하고 같은 원정의 재방문/후퇴/저장/Continue에서 plan과 노드 배정이 같다. 경로 선택에 따라 재배정하거나 개별 보스 코인추첨하지 않는다.
- A19: 적합 배치안 부재/잘못된 후보/도달불가/작성 누락을 거절하고 정상 테스트 조우로 배치·진입을 증명한다. 정식4종 본체 전체는 U21이다.
- A20: 미탐사 방에도 가지 위치·회수 여부·현재 경로 도달가능성을 표시하되 숨긴 방/보스 정체를 추가 노출하지 않는다. 모든 가지 회수 가능을 강제하지 않는다.

## G17 — 봉인 전투·황금가지 승리 확정

봉인 해제는 강화 전투를 시작하며 승리시에만 가지/억제력 보충을 노드 결과와 함께 확정한다. 무억제 추가 스탯 중복 금지. 후퇴는 봉인 복원·비용/유예 유지, 알 부활은 가지/보충 없음.

- A21: 억제/무억제 두 상태에서 봉인 진입→승리의 스탯과 수량보상을 확인한다. 해제만으로 가지/보충을 지급하지 않는다.
- A22: 후퇴는 봉인 미해제 상태·전투 손실을 복원하되 입장비용/유예/입장사망/후퇴횟수는 유지한다. 반복 승리/재접속 중복 지급을 막는다.
- A23: 패배/부활 전투는 황금가지/보충을 지급하지 않는다. 원래 시설 봉인승리의 보충으로 유예를 되돌리지 않는다.

## G18 — 직원 성장과 생존XP

직원은 레벨1/XP0, 레벨당100XP·기본생존10 초기값. 실제 참가·생존 직원 기본XP1회, 패배 포함/후퇴 제외. 주력 중반3/최종전전6은 초기 성장 목표로 기록하며 깊이에 자동 성장하지 않는다.

- A24: 실제 참가 생존 직원에게 중복배치와 무관하게 기본XP1회, 미참가/Dead 제외. 승리 무억제만20, 패배10, 후퇴0이다.
- A25: 한번 지급으로 여러 레벨과 잔여XP를 보존한다. 일반 authored 성장 경로의 중반 목표를 관측하고 최종보스 플레이 검증은 제외로 기록한다.

## G19 — 작성 일반전 보상과 실제 성과

일반전 엔케팔린/가루를 난이도별로 작성한다. 작성된 주환상체 ClearWithin/DecisiveDamage는 실제 시간·단일 공격 원천의 비DOT 실효피해로 판정하여 승리 때 목표별1회 지급한다.

- A26: 같은 방 Easy20/Standard50/Hard30 초기 혼합과 난이도별 재화/가루를 정상 콘텐츠로 확인한다. 편성전투력 연동은 없다.
- A27: ClearWithin 경계 이내/초과를 실제 전투시간으로, DecisiveDamage는 주환상체 최대HP 비율 경계/초과·다중타격·DOT 구별을 실제 action 결과로 검증한다.
- A28: 여러 번 조건 달성해도 목표당1회이며 패배/후퇴는 보너스0, 보너스XP는 모든 살아있는 직원 각자 전액·Dead제외·파편자격 불변이다.

## PERSISTENCE — 입장·전투·결과 저장과 원자성

기존 U04/U12/U13 지원 저장/복원과 동일 노드identity에서 비용·유예·봉인·배율을 함께 다룬다. 미확정 노드 종료Continue는 입장전 복원, 후퇴는 입장후 유지, 승패확정은 결과 유지. 구저장 원본은 명시거절/보호한다.

- A29: 새프로세스 미확정 노드Continue는 비용/receipt/유예/입장사망/봉인을 입장전으로 복원하고 이미 사용한 후퇴횟수는 되돌리지 않는다.
- A30: 승패/노드 소비 확정 뒤 Continue/재확인은 보상/가지/비용을 반복하지 않는다. SavePoint는 비용·상태를 함께 과거로 복원한다.
- A31: 실제 지원 경로 IO실패/재시도에서 부분 비용/보상/가지 상태가 노출되지 않고 지원하지 않는 구저장 원본은 보호한다. 외부 임의변조 전용 방어는 범위 제외다.
