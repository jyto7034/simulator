# U16-1 기존 지원 활동: 상점·유료 HQ 채용·Event·소비품

WPD-CSNA-20261015 / 현재 WR-CSNA-003. P2G-10 정책 검토 완료.

사용자 U16-1 착수 요청으로 P2G 준비 후 GEX 구현·자체검증·최종 감사요청 인계까지 수행한다. 중간 단계검토 opt-in 없음. 기존 dirty와 선행 증거를 보존한다. 자동 감사/서브에이전트 없음.

G23/G24/G25를 인수한다. CF-D06 위임에 따른 초기 상품 기준가와 기본 공급은 Finding Triage Log에 구분 기록한다. U16-2/3/4는 후속 분리 인수 범위로 남는다.

## G23 — 상점과 유료 본부 채용

기존 엔케팔린 거래와 유료 HQ 채용을 재사용한다. 유물 구매와 서로 구분되는 부활/침식 촉매제 구매를 같은 공통 지급에 연결하고 일반 유물 매각 및 가루/파츠 거래는 허용하지 않는다.

- A01: 고정 상품의 사본/종류·수량·총가격·재고를 조회하며 구매는 비용/공통 grant/상품 소진을 한번 확정한다. 실패·부족·중복은 사본/UUID/재화/재고를 바꾸지 않고 빈자리를 자동 보충하지 않는다.
- A02: 갱신은 작성 비용/횟수로 페이지 전체를 교체하고 반복 불가 구매품을 제외한다. 후보 부족·통화 부족·실패 시 비용/횟수/페이지/상품이 유지된다. 매입 올림·매각 내림 및 차익 방지 계약을 유지한다.
- A03: 일반 유물 구매는 정상 상태의 개별 사본을 공통 grant로 지급하며 해당 종류의 기존 중복 자격을 따른다. 일반 상점 유물 매각, 장착/귀속 장비 판매, 가루/파츠 직접 구매판매, 0원 거래를 거절한다.
- A04: 부활 촉매제는 일반 상인의 기본 상품으로 제공하고 희귀 추첨으로 숨기지 않는다. 침식 촉매제는 별도 구매/보유 자원이다. 부활용은 비싸고 침식용은 과도한 비용을 피하는 초기 작성값을 두며 실제 부화는 U17이다.
- A05: 유료 채용은 가격에 기본 무기/파편 세트를 포함하고 기존 대여와 중복 지급하지 않는다. 1~4층·세션 최대2명·보유10명·부족/이미채용/비적격 거절과 후보 queue 순서를 유지한다. 자격 조회와 명령 결과가 일치한다.

## G24 — 고정 Event 판정과 무료 침식

Event는 노드별 고정 d20과 확정 선택 receipt를 사용한다. 실패도 정상 분기로 진행하며 무료 침식과 전투 분기를 기존 노드 완료/복원에 연결한다.

- A06: 선택/직원 변경이나 조회/재접속/복원으로 d20이 달라지지 않는다. raw1 치명실패/raw20 치명성공이며 2~19는 합계>=DC, 허용 DC8/12/16/20과 적성+3을 적용한다.
- A07: 선택 직원의 장착/소유 장비 최고+1/+2 하나만 적용하고 동률은 사본ID 오름차순이다. 공용 장비 제외·열쇠는 비소비/무추가보정·잘못된 선택/직원/조건 거절 무변경을 증명한다.
- A08: 확정한 선택/직원/장비증거/결과를 반복해 재지급하지 않는다. 성공/실패의 다음 장면과 전투 분기의 승패/노드 소비는 한번 처리하며 후퇴는 기존 진입 전 복원이다.
- A09: 침식 Event는 대상 효과/패널티와 자격을 공개하고 촉매/통화/재료 없이 선택 사본만 변환한다. 거절·무효 대상·반복 요청 및 재시작에서 비용/사본 결과를 보존한다.

## G25 — 소비품과 보유량

일반 소비품은 허용된 전투 전 화면에서 직원에게 하나 소비하며 활성 효과를 교체한다. UI 표시 슬롯 수는 Core 획득 상한이 아니다.

- A10: 지도/전투 진입 전 사용만 허용하고 직원당 활성 효과 하나를 새 효과로 즉시 교체한다. 성공 시 수량1 차감·환불 없음, 잘못된 대상/상태/재고 부족은 무변경이다. 즉시 치료도 기존 일반 활성 효과를 유지시키는 별도 예외를 추가하지 않는다.
- A11: 전투 결과 확정에 남은 기간을 한번 차감하고 결과 확인/중복명령에는 추가 차감하지 않는다. 비전투 완료/후퇴에는 차감하지 않으며 후퇴는 이미 사용한 전투 진입 전 효과/잔량을 복원한다.
- A12: 장비/소비품 보유가 50/60 표시 기준을 넘어도 정상 구매·보상 획득을 거절하지 않는다. 50부터10단위 표시 확장과 실제 화면은 U26-B이며 새로운 Core 보유 한도를 만들지 않는다.

## STORE — 활동 저장·복원과 완료

상점/HQ/Event/소비품의 비용·사본·결과·queue·효과·노드 상태를 하나의 저장 경계에서 보존한다. 미완료 노드 새프로세스 이어하기는 입장 전이고 완료 노드는 결과를 유지한다.

- A13: 같은프로세스 재접속은 진행 중 offer/roll/선택/효과를 유지한다. 새프로세스 Continue는 미완료 노드 입장 전 거래·지불·채용·사본/원장을 함께 복원하며 노드 배정은 재추첨하지 않는다.
- A14: 완료한 상점/HQ/Event의 결과·소비를 새프로세스에서 유지하고 중복 완료/구매/채용/판정은 추가 지급하지 않는다. SavePoint는 당시 비용/결과를 함께 복원하되 무관한 영구기록/창고는 보존한다.
- A15: 실제 정상 host의 저장 IO실패는 메모리/active/profile의 부분 거래를 남기지 않고 재시도로 한 번만 반영한다. 지원 새 형식의 loader/writer·세대 입력·실제 소비자를 함께 검증하고 구개발 저장을 바꾸어 성공시키지 않는다.

## AUTHOR — 정상 제작 입력·공개 소비자·검증

상품/후보/비용·활동 조건은 정상 작성 입력과 공개 application/host로 소비한다. 대표 콘텐츠와 지원 경로 오류 검증 및 필요한 비용 측정을 같은 묶음에서 수행한다.

- A16: 유물/촉매제 상품 및 기존 장비/소비품은 실제 RON/pack loader를 통과하여 공개 query/command에 나타난다. 누락 참조·가루/파츠 상품·0가격/0수량·overflow·불법 작성 조합을 로더에서 거절한다.
- A17: U13 실제 노드 배정·예약과 U14 최초 입장 비용·완료 의미를 유지한 대표 원정에서 상점/HQ/Event/소비품을 실행한다. 내부 helper fixture와 공개 host/fresh-process 검증을 구분하고 전체 U16 완료로 확대하지 않는다.
- A18: 정상/확장 상품·사본 workload의 시간/실제 메모리 peak/회수를 관측하고 기존 제한 조정 필요를 근거로 판단한다. 외부 임의 파일/메모리 변조 전용 시험은 제외하며 실제 IO장애와 지원 입력 오류는 검증한다.
