# 플레이 흐름 예시

이 문서는 정책 설명이 아니라, 플레이어가 실제로 어떤 화면과 선택지를 마주치는지 보여주는 짧은 플레이 기록 예시다.

## 시작 직원 선발

본부가 이번 탐사에 투입 가능한 직원 후보를 전송한다.

후보 목록은 `game_resources/data/employees/starter_candidates.ron`에서 로드된다. 아래는 현재 기본 데이터 기준 예시다.

```text
시작 후보 6명 중 3명을 선발하십시오.

[field_medic] 이서연 / 현장 의무 보조
  붕괴 현장에서 끝까지 동료를 끌고 나온 기록이 있다.

[breach_guard] 강민재 / 격리문 경비
  브리칭 경보가 울릴 때 가장 먼저 문 앞으로 선 직원.

[records_clerk] 한유진 / 기록 보조
  죽은 관리자의 명령 로그를 끝까지 복원하려 했다.

[scout_runner] 오지훈 / 정찰 러너
  길을 잃은 팀을 두 번이나 출구까지 이끈 적이 있다.

[containment_trainee] 박하린 / 격리 절차 훈련생
  훈련 성적은 낮지만, 위험 명령을 끝까지 듣는 편이다.

[maintenance_tech] 최도윤 / 정비 기술자
  망가진 관측 장비를 임시 배터리 하나로 살려냈다.
```

플레이어는 이서연, 강민재, 한유진을 선발한다. 세 직원은 모두 기본 평타 강화 파편만 가진 상태로 시작한다. 선발이 끝난 뒤에야 본부가 탐사 맵과 시작 자원을 전송한다.

## 시작 상태

본부가 탐사 맵을 전송한다.

```text
Act 1 - 봉쇄 구역

        [1A] Combat: 작은 환상체
Start - [1B] Support: Medical
        [1C] HeadquartersContact: 본사 연락

        [1A] -> [2A] Elite Combat ------> [3A] Boss
        [1B] -> [2B] Support: Maintenance -> [3A]
        [1C] -> [2C] Reward ------------> [3A]
```

선발된 직원:

- 이서연: HP 100/100, 트라우마 0, 기본 파편
- 강민재: HP 100/100, 트라우마 0, 기본 파편
- 한유진: HP 100/100, 트라우마 0, 기본 파편

현재 가능한 행동:

- 노드 선택
- 장비 장착/해제
- 스킬 파편 장착/해제
- 인벤토리 확인

이 구간은 Safezone 성격의 진입 전 준비다. 기본 장면은 `노드 탐색`이며, 하단바 좌측 버튼으로 `아이템 사용` 장면과 오갈 수 있다. `아이템 사용` 장면에서 유닛을 길게 누르면 `장비 장착/해제` 장면이 열린다. 아직 전투 배치는 하지 않는다. 전투 노드를 선택하면 그 노드의 전장과 `DeploymentZone`을 미리 확인하고, 실제 배치는 전투 시작 후 live 명령으로 수행한다.

## Safezone Loadout: 무기와 파편 호환

플레이어는 `아이템 사용` 장면에서 강민재를 길게 눌러 `Loadout`을 연다.

현재 장비/파편:

- 강민재: 훈련용 검, 기본 평타 강화 파편
- 이서연: 응급 스태프, 기본 평타 강화 파편
- 한유진: 보급 석궁, 기본 평타 강화 파편

가방:

- 낡은 총: `Ranged / Gun`, `LowDefenseFirst`
- 붉은 시선 파편: `Melee` 또는 `Sword/Axe` 계열 요구
- 검은 탄환 파편: `Gun/Crossbow` 계열 요구
- 안정화 파편: 범용

플레이어가 강민재에게 `검은 탄환 파편`을 드래그하면 Unity는 현재 무기인 훈련용 검과 호환되지 않는다는 표시를 보여주고 command를 보내지 않는다.

플레이어가 먼저 강민재의 무기를 `낡은 총`으로 교체하면 강민재의 현재 역할은 원거리 `Gun` 아키타입으로 바뀐다. 기본 공격은 `LowDefenseFirst` 프로필을 따르며, 이후 `검은 탄환 파편`을 장착할 수 있다.

반대로 `붉은 시선 파편`을 쓰고 싶다면 강민재는 검/도끼 같은 근거리 무기를 유지해야 한다.

이 구조에서 파편 제한은 벌칙이 아니라 빌드 목표다. 플레이어는 쓰고 싶은 환상체 파편에 맞춰 무기를 준비하거나, 현재 무기에 맞는 파편을 선택한다.

## 노드 선택: 1A Combat

플레이어는 `[1A] Combat: 작은 환상체`를 선택한다.

본부 제공 정보:

- 전장: 좁은 격리실
- 아군 배치 가능 구역: 남서쪽 출입구 주변
- 적: 작은 환상체 1체
- 예상 적 출현 구역: 북쪽 격리 캡슐 근처
- 위험도: 낮음
- 예상 피해: 낮음
- 보상 후보: 스킬 파편, 장비, 자원

아직 노드는 소비되지 않았다. 현재는 노드 진입 확인 단계다.

진입 확인 단계에서 가능한 행동:

- 노드 진입 확정
- 맵으로 돌아가기
- 해당 노드 전장/route/배치 가능 구역 미리보기
- 장비 장착/해제
- 스킬 파편 장착/해제

이 단계도 Safezone/NodeConfirm 계열의 준비 구간이다. 노드를 실제로 소비하는 시점은 `노드 진입 확정`을 누른 뒤다.

플레이어는 기본 브리핑을 보고 해당 전장 미리보기를 연다. 필드 전체가 표시되고, 아군 배치 가능 타일만 파란색으로 칠해져 있다. 플레이어는 route와 배치 가능 구역을 확인한 뒤 노드 진입을 확정한다. 이 시점에 노드가 소비되고 전투가 시작되며, 실제 직원 배치는 전투 중 live 배치 명령으로 수행한다.

## 전투 결과

전투 결과:

- 강민재 Battle HP 100 -> 62
- 이서연 Battle HP 100 -> 100
- 한유진 Battle HP 100 -> 100
- 전투불능 직원 없음. Run HP 변화 없음.
- 환상체 격파

획득:

- 붉은 시선 파편
- 엔케팔린 소량

현재 가능한 행동:

- 보상 확인
- 인벤토리 확인
- 스킬 파편 장착/해제
- 다음 노드 선택

플레이어는 맵 복귀 후 Safezone 성격의 준비 구간에서 붉은 시선 파편을 강민재에게 장착한다. 강민재는 이제 기본 평타 외에 대표 액티브 스킬 하나를 갖는다.

## 다음 노드 선택

현재 맵:

```text
        [1A 완료] -> [2A] Elite Combat ------> [3A] Boss
Start - [1B 잠김] -> [2B] Support: Maintenance -> [3A]
        [1C 잠김] -> [2C] Reward ------------> [3A]
```

현재 선택 가능한 노드:

- `[2A] Elite Combat`
- `[2B] Support: Maintenance`

현재 직원 상태:

- 강민재: Run HP 100/100, 트라우마 0, 붉은 시선 파편 장착
- 이서연: HP 100/100, 트라우마 0, 기본 파편
- 한유진: HP 100/100, 트라우마 0, 기본 파편

현재 가능한 행동:

- 노드 선택
- 장비 장착/해제
- 스킬 파편 장착/해제
- 인벤토리 확인

플레이어는 Safezone에서 장비/파편을 정리할 수 있지만, 아직 전투 배치를 할 수 없다. 정예 전투를 선택하면 그 노드의 전장 미리보기와 배치 가능 구역을 확인할 수 있다.

`[2A] Elite Combat`의 기본 브리핑은 아래와 같다고 가정한다.

- 전장: 무너진 사무실
- 아군 배치 가능 구역: 남쪽 복도와 중앙 책상 뒤
- 주요 적: 고속 돌진형 환상체
- 예상 적 출현 구역: 북동쪽 또는 북서쪽
- 불확실성: 보조 적 위치는 `Suspected` confidence로만 표시

플레이어는 지금은 Maintenance를 선택할 생각이지만, 정예 전투의 위험을 보고 다음 전투에서 후퇴/재배치 여지를 남겨두기로 한다.

## 정예 전투 NodeConfirm: 전장 확인

현재 전장:

```text
[적 출현 예상][ ][장애물][ ][적 출현 예상]
[ ][ ][ ][ ][ ]
[파란 배치 가능][파란 배치 가능][파란 배치 가능][ ][ ]
```

강민재의 HP가 낮다. 플레이어는 이번 전장의 파란 배치 가능 타일과 route를 확인하고, 전투가 시작되면 강민재를 후열 쪽에, 이서연을 전열 쪽에 배치하기로 계획한다.

변경 후:

```text
[ ][ ][이서연][ ][ ]
[ ][강민재][ ][한유진][ ]
```

진입을 확정하면 맵 노드가 소비되고 실시간 전투 UI로 전환된다.

## 노드 선택: 2B Maintenance

플레이어는 정예 전투 대신 `[2B] Support: Maintenance`를 선택한다.

본부 제공 정보:

- 노드 유형: Maintenance
- 효과: 정비 작업 공간 개방
- 주의: 노드 진입 후 완료하면 노드는 소비됨

현재는 진입 확인 단계다. 플레이어는 정비가 필요하다고 판단하고 노드 진입을 확정한다.

Maintenance에서 가능한 행동:

- 스킬 파편 강화
- 스킬 파편 개화
- 스킬 파편 분쇄
- 장비 복원/분해/강화
- 인벤토리 확인
- 노드 완료

이 행동들은 Safezone의 간단 정비가 아니라 Maintenance 노드 전용 작업이다.

현재 보유 파편:

- 붉은 시선 파편 x1
- 사용하지 않는 파편 x2

플레이어는 사용하지 않는 파편 1개를 분쇄한다.

결과:

- 사용하지 않는 파편 x2 -> x1
- fragment_dust +2

이후 붉은 시선 파편을 강화하려 하지만, 동일 등급 재료 파편을 마지막 1개만 보유 중이라 재료로 사용할 수 없다. 플레이어는 정비를 마치고 노드를 완료한다.

## 다음 노드 선택

현재 선택 가능한 노드:

- `[3A] Boss`

현재 직원 상태:

- 강민재: Run HP 100/100, 트라우마 0, 붉은 시선 파편 장착
- 이서연: HP 100/100, 트라우마 0, 기본 파편
- 한유진: HP 100/100, 트라우마 0, 기본 파편

현재 가능한 행동:

- 보스 노드 선택
- 장비 장착/해제
- 스킬 파편 장착/해제
- 인벤토리 확인

플레이어는 Safezone에서 마지막 장비/파편 상태를 확인한 뒤 `[3A] Boss`를 선택해 기본 브리핑을 확인한다. 전장 미리보기는 보스 노드를 선택한 뒤 `NodeConfirm` 단계에서 열린다.

보스 브리핑:

- 전장: 넓은 중앙 홀
- 아군 배치 가능 구역: 남쪽 입구 전체
- 주요 적: 보스 환상체 1체
- 예상 적 출현 구역: 중앙 제단
- 위험 요소: 좌우 측면에서 증원 가능성 있음

기본 브리핑:

- 보스 시작 위치: 중앙 제단
- 증원 출현 후보: 서쪽 문, 동쪽 문으로 추정
- 보스 사거리: 중거리로 추정
- 우선 공격 대상: 가장 가까운 직원일 가능성이 높음

플레이어는 이 정보를 보고 보스 전투 전 마지막으로 배치 계획을 세운다. 실제 배치는 전투가 시작된 뒤 안정화치를 사용해 수행한다.

## 위기 예시: 전투 불능과 Medical

만약 정예 전투에서 강민재의 Battle HP가 0이 되면, 강민재는 즉시 사망하지 않고 전투불능 처리된다. 이때 트라우마가 증가하고 Run HP가 일부 감소한다.

다음 선택 가능한 노드가 아래와 같다고 가정한다.

- `[2B] Support: Medical`
- `[2C] Combat`

현재 가능한 행동:

- Medical 노드 선택
- Combat 노드 선택
- 인벤토리 확인

출전 가능한 직원이 없다면 Combat 노드는 진입이 차단된다. 하지만 Medical이 남아 있으므로 런은 실패하지 않는다.

플레이어는 Medical을 선택한다.

Medical 정보가 표시되고, 플레이어는 진입을 확정한다.

Medical에서 가능한 행동:

- 치료 대상 선택
- `EmergencyCare` 선택
- `Counseling` 선택
- `BalancedCare` 선택
- 노드 완료

플레이어는 강민재에게 `EmergencyCare`를 적용한다.

결과:

- 강민재 Run HP 일부 회복
- 강민재는 다시 출전 가능
- 트라우마는 그대로 남거나 선택한 치료에 따라 일부 회복됨

이제 플레이어는 다시 전투 노드를 선택할 수 있다.
