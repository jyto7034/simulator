# 플레이 흐름 예시

이 문서는 정책 설명이 아니라, 플레이어가 실제로 어떤 화면과 선택지를 마주치는지 보여주는 짧은 플레이 기록 예시다.

## 시작 직원 선발

본부가 이번 탐사에 투입 가능한 직원 후보를 전송한다.

후보 목록은 `game_resources/data/employees/starter_candidates.ron`에서 로드된다. 아래는 현재 기본 데이터 기준 예시다.

```text
시작 후보 6명 중 3명을 선발하십시오.

[field_medic] 이서연 / 현장 의무 보조
  붕괴 현장에서 끝까지 동료를 끌고 나온 기록이 있다.

[breach_guard] 강민재 / 격리문 경비
  브리칭 경보가 울릴 때 가장 먼저 문 앞으로 선 직원.

[records_clerk] 한유진 / 기록 보조
  죽은 관리자의 명령 로그를 끝까지 복원하려 했다.

[scout_runner] 오지훈 / 정찰 러너
  길을 잃은 팀을 두 번이나 출구까지 이끈 적이 있다.

[containment_trainee] 박하린 / 격리 절차 훈련생
  훈련 성적은 낮지만, 위험 명령을 끝까지 듣는 편이다.

[maintenance_tech] 최도윤 / 정비 기술자
  망가진 관측 장비를 임시 배터리 하나로 살려냈다.
```

플레이어는 이서연, 강민재, 한유진을 선발한다. 세 직원은 모두 기본 평타 강화 파편만 가진 상태로 시작한다. 선발이 끝난 뒤에야 본부가 탐사 맵과 시작 자원을 전송한다.

## 시작 상태

본부가 탐사 맵을 전송한다.

```text
Act 1 - 봉쇄 구역

        [1A] Combat: 작은 환상체
Start - [1B] Support: Medical
        [1C] HeadquartersContact: 본사 연락

        [1A] -> [2A] Elite Combat ------> [3A] Boss
        [1B] -> [2B] Support: Maintenance -> [3A]
        [1C] -> [2C] Reward ------------> [3A]
```

선발된 직원:

- 이서연: HP 100/100, 트라우마 0, 기본 파편
- 강민재: HP 100/100, 트라우마 0, 기본 파편
- 한유진: HP 100/100, 트라우마 0, 기본 파편

현재 가능한 행동:

- 노드 선택
- 장비 장착/해제
- 스킬 파편 장착/해제
- 인벤토리 확인

아직 전투 배치는 하지 않는다. 전투 배치는 특정 전투 노드를 선택한 뒤, 그 노드의 전장과 `DeploymentZone`을 보고 새로 확정한다.

## 노드 선택: 1A Combat

플레이어는 `[1A] Combat: 작은 환상체`를 선택한다.

본부 제공 정보:

- 전장: 좁은 격리실
- 아군 배치 가능 구역: 남서쪽 출입구 주변
- 적: 작은 환상체 1체
- 예상 적 출현 구역: 북쪽 격리 캡슐 근처
- 위험도: 낮음
- 예상 피해: 낮음
- 보상 후보: 스킬 파편, 장비, 자원
- 정밀 스캔: 사용 가능하지만 권장하지 않음

아직 노드는 소비되지 않았다. 현재는 노드 진입 확인 단계다.

진입 확인 단계에서 가능한 행동:

- 노드 진입 확정
- 맵으로 돌아가기
- 정밀 스캔 사용
- 해당 노드 전장 배치창 열기
- 장비 장착/해제
- 스킬 파편 장착/해제

플레이어는 저위험 노드에 정밀 스캔을 쓰지 않기로 한다. 대신 기본 브리핑만 보고 해당 전장 배치창을 연다. 필드 전체가 표시되고, 아군 배치 가능 타일만 파란색으로 칠해져 있다. 플레이어는 강민재를 격리 캡슐 쪽 길목에 배치한 뒤 노드 진입을 확정한다. 이 시점에 노드가 소비되고 전투가 시작된다.

## 전투 결과

전투 결과:

- 강민재 Battle HP 100 -> 62
- 이서연 Battle HP 100 -> 100
- 한유진 Battle HP 100 -> 100
- 전투불능 직원 없음. Run HP 변화 없음.
- 환상체 격파

획득:

- 붉은 시선 파편
- 엔케팔린 소량

현재 가능한 행동:

- 보상 확인
- 인벤토리 확인
- 스킬 파편 장착/해제
- 다음 노드 선택

플레이어는 붉은 시선 파편을 강민재에게 장착한다. 강민재는 이제 기본 평타 외에 대표 액티브 스킬 하나를 갖는다.

## 다음 노드 선택

현재 맵:

```text
        [1A 완료] -> [2A] Elite Combat ------> [3A] Boss
Start - [1B 잠김] -> [2B] Support: Maintenance -> [3A]
        [1C 잠김] -> [2C] Reward ------------> [3A]
```

현재 선택 가능한 노드:

- `[2A] Elite Combat`
- `[2B] Support: Maintenance`

현재 직원 상태:

- 강민재: HP 62/100, 트라우마 0, 붉은 시선 파편 장착
- 이서연: HP 100/100, 트라우마 0, 기본 파편
- 한유진: HP 100/100, 트라우마 0, 기본 파편

현재 가능한 행동:

- 노드 선택
- 장비 장착/해제
- 스킬 파편 장착/해제
- 인벤토리 확인

플레이어는 아직 배치창을 열 수 없다. 정예 전투를 선택하면 그 노드의 전장에 맞는 배치창이 열린다.

`[2A] Elite Combat`의 기본 브리핑은 아래와 같다고 가정한다.

- 전장: 무너진 사무실
- 아군 배치 가능 구역: 남쪽 복도와 중앙 책상 뒤
- 주요 적: 고속 돌진형 환상체
- 예상 적 출현 구역: 북동쪽 또는 북서쪽
- 불확실성: 보조 적 위치 미확인
- 정밀 스캔: 사용 가능, 남은 횟수 2

플레이어는 지금은 Maintenance를 선택할 생각이지만, 정예 전투의 위험을 보고 다음 전투 전 정밀 스캔을 아껴두기로 한다.

## 정예 전투 NodeConfirm: 노드별 배치

현재 전장:

```text
[적 출현 예상][ ][장애물][ ][적 출현 예상]
[ ][ ][ ][ ][ ]
[파란 배치 가능][파란 배치 가능][파란 배치 가능][ ][ ]
```

강민재의 HP가 낮다. 플레이어는 이번 전장의 파란 배치 가능 타일 안에서 강민재를 후열 쪽에 두고, 이서연을 전열 쪽에 둔다.

변경 후:

```text
[ ][ ][이서연][ ][ ]
[ ][강민재][ ][한유진][ ]
```

배치를 확정하고 맵으로 돌아온다.

## 노드 선택: 2B Maintenance

플레이어는 정예 전투 대신 `[2B] Support: Maintenance`를 선택한다.

본부 제공 정보:

- 노드 유형: Maintenance
- 효과: 정비 작업 공간 개방
- 주의: 노드 진입 후 완료하면 노드는 소비됨

현재는 진입 확인 단계다. 플레이어는 정비가 필요하다고 판단하고 노드 진입을 확정한다.

Maintenance에서 가능한 행동:

- 스킬 파편 강화
- 스킬 파편 개화
- 스킬 파편 분쇄
- 인벤토리 확인
- 배치창 열기
- 노드 완료

현재 보유 파편:

- 붉은 시선 파편 x1
- 사용하지 않는 파편 x2

플레이어는 사용하지 않는 파편 1개를 분쇄한다.

결과:

- 사용하지 않는 파편 x2 -> x1
- fragment_dust +2

이후 붉은 시선 파편을 강화하려 하지만, 동일 등급 재료 파편을 마지막 1개만 보유 중이라 재료로 사용할 수 없다. 플레이어는 정비를 마치고 노드를 완료한다.

## 다음 노드 선택

현재 선택 가능한 노드:

- `[3A] Boss`

현재 직원 상태:

- 강민재: HP 62/100, 트라우마 0, 붉은 시선 파편 장착
- 이서연: HP 100/100, 트라우마 0, 기본 파편
- 한유진: HP 100/100, 트라우마 0, 기본 파편

현재 가능한 행동:

- 보스 노드 선택
- 배치창 열기
- 장비 장착/해제
- 스킬 파편 장착/해제
- 인벤토리 확인

플레이어는 `[3A] Boss`를 선택해 기본 브리핑을 확인한다.

보스 브리핑:

- 전장: 넓은 중앙 홀
- 아군 배치 가능 구역: 남쪽 입구 전체
- 주요 적: 보스 환상체 1체
- 예상 적 출현 구역: 중앙 제단
- 위험 요소: 좌우 측면에서 증원 가능
- 정밀 스캔: 사용 가능, 남은 횟수 2

플레이어는 보스 노드이므로 정밀 스캔을 사용한다.

정밀 스캔 결과:

- 보스 시작 위치: 중앙 제단
- 증원 출현 후보: 서쪽 문, 동쪽 문
- 보스 사거리: 중거리
- 우선 공격 대상: 가장 가까운 직원

플레이어는 이 정보를 보고 보스 전투 전 마지막으로 배치창을 연다.

## 위기 예시: 전투 불능과 Medical

만약 정예 전투에서 강민재의 Battle HP가 0이 되면, 강민재는 즉시 사망하지 않고 전투불능 처리된다. 이때 트라우마가 증가하고 Run HP가 일부 감소한다.

다음 선택 가능한 노드가 아래와 같다고 가정한다.

- `[2B] Support: Medical`
- `[2C] Combat`

현재 가능한 행동:

- Medical 노드 선택
- Combat 노드 선택
- 배치창 열기
- 인벤토리 확인

출전 가능한 직원이 없다면 Combat 노드는 진입이 차단된다. 하지만 Medical이 남아 있으므로 런은 실패하지 않는다.

플레이어는 Medical을 선택한다.

Medical 정보가 표시되고, 플레이어는 진입을 확정한다.

Medical에서 가능한 행동:

- 치료 대상 선택
- `EmergencyCare` 선택
- `Counseling` 선택
- `BalancedCare` 선택
- 노드 완료

플레이어는 강민재에게 `EmergencyCare`를 적용한다.

결과:

- 강민재 Run HP 일부 회복
- 강민재는 다시 출전 가능
- 트라우마는 그대로 남거나 선택한 치료에 따라 일부 회복됨

이제 플레이어는 다시 전투 노드를 선택할 수 있다.
