# 남은 결정

[게임 설계서](../game_rulebook.md) · [출처와 통합 기록](../decisions/game_rulebook_next_restructure_2026-09-26.md)

2026-10-03까지의 공통 합의, 2026-10-04 도구 재구성, 2026-10-07 유물 보상 노드 및 2026-10-10 튜토리얼 시나리오 포팅 합의를 반영했다. 아래 표는 확정된 출발점과 남은 결정을 구분한다.
2026-10-04 연속 구현 인수의 [CF-D01–07](../roadmaps/core_first/execution/DECISIONS_20261004.ko.md)을 추가 적용한다.
구저장 호환 제외·보상 후보 부족/0개·팔찌 미배치·우상 희생 사망 방지는 사용자 직접 결정이며, 이후 승인 범위의
필요 정책은 위임 근거·판단·영향을 기록한 뒤 해당 owner에서 구현한다.
초기 조절값과 검토 후보는 확정 밸런스가 아니며, 구현 완료도 뜻하지 않는다.
NEXT ID는 기존 문서와의 대응을 위해 유지한다.
게임 경험을 크게 바꾸는 정책은 추천안과 함께 하나씩 논의한다. 기존 합의에서 따르는 통상적인
세부 처리는 판단해 정리하고 보고하며, 밸런스 수치는 실제 플레이 검증 대상으로 남긴다.
문서 수정은 사용자가 명시적으로 반영을 요청할 때만 수행한다. 대화 중 동의만으로 매번 문서를 수정하지 않는다.
정책을 갱신할 때는 현재 유효한 규칙과 남은 결정만 유지한다.
