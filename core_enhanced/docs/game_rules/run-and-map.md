# 런과 시설 탐사

[게임 설계서](../game_rulebook.md) · [성장과 보상](growth-and-rewards.md) · [미결정 사항](open-decisions.md)

## 한 런의 구성

여러 원정에 걸쳐 같은 시설의 정보를 밝혀 가며 다른 경로를 탐사한다. 입구는 0층이고 공개 최종보스 방은
8층에 있다. 흉탄은 마탄 옆 같은 층의 별도 방에 배치하는 예외다. 같은 층에 여러 방이 있으므로 방문한 방 수와 도달한 층은 다르다.

원정 길이는 활동 노드 최초 입장에서 소모하고 황금가지로 보충하는 클리포트 억제력과 연결된다.
방 사이 이동 자체에는 별도 소모가 없다. Gate와 억제력 소진에 따른 성공 귀환은 현재 3층 이상일 때
선택할 수 있다. 1~2층에서는 Gate로 이동만 가능하고, 소진되면 무억제 탐사를 계속하거나 회수 없이
원정을 포기한다. 최종보스 격파 후에는 귀환 또는 계속 탐사를 선택한다.
[원정 흐름과 억제력](expedition-and-deterrence.md)이 정확한 상태 전환을 소유한다.

일반 보스와 일반 침식체 전투는 생략할 수 있다. 일반전은 장비 가루의 주 공급처이며 모든 선택 전투를
생략한 편성의 승리를 보장하지 않는다. 일반 보스 출현 노드는 고정하고 엘리트의 빈도·위치는 별도로 정한다.
방 내부에서 방문할 노드 수에 별도 상한을 두지 않는다. 빠른 하강은 낮은 성장에 따른 전투 위험,
넓은 탐사는 추가 보상과 부상·재화·억제력 소모를 함께 감수한다.

## 전체 시설 지도

| 용어 | 의미 |
| --- | --- |
| 맵 | 전체 게임 세계인 시설 지도 |
| 방 | 전체 맵을 구성하는 공간. 하나의 방에 여러 활동 노드가 있음 |
| 노드 | 방 내부의 전투·Event·정비·상점·Gate 등 활동 지점 |
| 층 | 방의 깊이. 같은 층에 여러 방이 있으며 입구 0층, 공개 최종보스 8층. 흉탄은 마탄 옆 같은 층의 예외 |

기존 문서의 ‘층 노드/한 층’은 공간을 가리킬 때 ‘방’, 그 내부의 ‘방’은 ‘노드’로 읽는다.
숫자로 표시하는 층은 깊이이며, 현행 구현의 Floor/Room 식별자 변경까지 승인하는 뜻은 아니다.

- 맵과 각 방 내부의 규모·연결은 손으로 설계해 고정한다. 세 주요 하강 경로에 분기·합류·횡단 연결을 둔다.
- 같은 층에서 연결된 방은 양방향 이동과 재방문이 가능하다. 서로 다른 층은 하강만 허용하고 상승은 금지한다.
  연결되지 않은 방으로 순간이동하지 않는다. 재방문해도 노드 배정·완료·최초 입장 비용을 초기화하지 않는다.
- 모든 7층 방에는 8층 최종보스 방으로 이어지는 고정 연결이 있다. 각 7층 방이 어느 보스 방으로
  이어지는지는 지도에 작성한다. 보스의 개방 조건과 실제 경로가 모두 충족되어야 입장할 수 있다.
  다른 보스에 가려면 실제 연결을 따라 해당 7층 방으로 이동해야 하며 모든 7층 방의 횡단 연결을 보장하지 않는다.
- 일반 노드의 종류·조우·상품·보상은 새 원정마다 배정하고 같은 원정에서는 유지한다.
  시작·Gate·고정 조우·SavePoint·고정 정비 노드는 예약 요소로 보호한다.
- 일반 방의 위치·연결·이동 방향은 처음부터 공개하고 상세 정보는 탐사로 공개한다.
  방 클리어로 확정한 고정 정보는 영구 기록하며 생환 여부나 체크포인트 복구와 무관하게 보존한다.
- 기록이 없는 최종보스 방과 진입 연결은 숨기고 이번 원정의 선행 조건으로 공개·개방한다.
  영구 격파·탐사 기록으로 알려진 보스 방은 위치·보스 정보를 표시하되 이번 원정의 조건 전까지 잠근다.
  과거 격파·탐사 기록은 유지하지만 새 원정의 전조 진행과 개방 자격을 대신하지 않는다.

맵 폭·총 방 수·층별 좌표·정확한 보스 위치는 미정이다. 일반 보스가 있는 방은 일반 활동 노드와
고정 보스 노드가 섞인 구성을 기본으로 하며 보스를 지나갈 경로를 둔다.
최종보스 격파 후에는 새 보상을 준비 화면에서 장착하고 현재 방의 미해결 노드와 실제로 연결된 방을
계속 탐사할 수 있다. 같은 층 재방문은 허용하고 상승은 금지한다. 8층 이후를 새로 생성하지 않는다.
격파 후 보상을 사용할 탐사 기회와 Gate 접근 동선은 고정 지도 설계에서 함께 검토한다.

### 방향별 징조와 퍼즐 발현

세 주요 진행방향마다 최종보스 계열을 고정한다. 전조는 **3~7층에서 계열별·층별 최대 1개** 배정한다.
해당 층에서 그 계열에 속한 방에 처음 들어갈 때 조건에 맞는 미완료 전조가 풀에 있으면 반드시 하나를
배정하고, 방 내부에 들어온 뒤 전조 노드를 공개한다. 전조의 종류와 방 안 배치 위치는 조건에 맞게
무작위로 선택할 수 있지만 출현 여부를 확률로 거르지 않는다. 들어가기 전 전체 맵에서는 전조를 미리 표시하지 않는다.

| 고정 진행방향 | 전조 계열 |
| --- | --- |
| 좌측 | 종말새: 큰 새·심판 새·징벌 새 |
| 중앙 | 고요한 오케스트라: 서로 다른 심포니 4종 |
| 우측 | 백야: 교회의 직원 치료 |

좌 종말새·중앙 오케스트라·우 백야의 대응을 고정한다. 여러 경로가 합류해도 각 방은 단 하나의 계열에 속한다.
들어온 경로에 따라 계열이 바뀌거나 한 방이 복수 계열을 겸하지 않는다.
흉탄은 별도 자격·발현 조건을 유지하며 위 세 계열의 일반 전조 풀에 자동 편입하지 않는다.

- 같은 층의 다른 방이나 같은 방을 재방문해도 해당 계열 전조를 추가 생성하거나 재추첨하지 않는다.
  서로 다른 세 계열의 조건을 모두 만족하면 그 층 전체에 최대 3개까지 배정될 수 있다.
- 다른 방향으로 이동하면 도착한 방의 계열을 사용하며 이전 계열 진행도 해당 원정 동안 유지한다.
  활성 보스 하나만 허용하거나 시작한 계열을 다른 방향에 우선 배정하지 않는다.
- 전조 방문은 선택이다. 그 계열을 피하거나 나타난 노드를 무시하면 보스 조건을 마치지 못할 수 있다.
  보스가 개방되지 않아도 3층 이상 Gate·억제력 소진 귀환은 정상적으로 가능하다.
- 전조는 풀에서 자격과 상태를 관리하고 기존 활동 노드 위에 배정한다. 예약된 Gate·SavePoint·정비 등
  필수 시설을 없애지 않는다. 호환 노드 확보와 일반 노드 배정의 정확한 처리 순서는 후속 설계 대상이다.

전조별 후퇴 횟수·결과 완료와 미완료 전조 재제안은 [전조 풀](growth-and-rewards.md#보스-징조와-반복-조우)을 따른다.

### 전체 지도 가시성과 탐사 기록

전체 연결 구조를 보고 하강·횡단 경로를 계획할 수 있게 하되, 각 방의 상세 정보는 탐사로 공개한다.
다음 정책은 전체 시설의 방 지도에 적용한다. 방 내부는 아래 [노드 지도 공개 규칙](#시설-지도와-노드-선택)을
따른다. 이번 원정의 황금가지 위치는 미탐사 방까지 포함해 원정 시작부터 전체 지도에 공개한다.

| 정보 | 공개 방식 |
| --- | --- |
| 일반 방 위치·연결·이동 방향 | 처음부터 공개 |
| 미탐사 방 상세 | 어두운 방 표식으로 표시하며 이름·컨셉·보스 정체는 숨김 |
| 이번 원정의 황금가지 위치 | 원정 시작부터 미탐사 방까지 가지 표식 공개. 방 상세·보스 정체는 기존 공개 조건 유지 |
| 다음에 이동 가능한 인접 방 | 진입 전에 이름·컨셉 등 기본 정보를 공개. 보스 정체까지 자동 공개하지 않음 |
| 클리어한 방의 고정 정보 | 영구 탐사 기록으로 보존. 생환 여부와 무관하게 다음 원정에 공개하며 실패·체크포인트 복구로 지우지 않음 |
| 명시된 이동 조건으로 잠긴 방 | 잠금 상태 표시. 정보 미공개만으로 일반 방의 이동을 잠그지 않음 |
| 숨겨진 방·비밀 연결 | 발견 조건 충족 후 공개 |
| 최종 보스 방·진입 연결 | 보스별 이번 원정 선행 조건으로 개방. 영구 기록이 없는 방은 숨기고, 알려진 방은 위치·보스 정보와 잠금 표시. 기존 격파만으로 개방하지 않음 |

탐사 기록으로 알려진 고정 정보와 이번 원정의 노드 구성·상품·보상·황금가지 배정을 구분한다.
지난 원정의 가변 정보를 이번 원정의 현재 정보처럼 표시하지 않는다. 영구 기록이 없는 최종 보스 방은
개방 전에 미리 드러내지 않는다. 알려진 보스 방은 위치·보스 정보를 보여 주고 잠금 상태를 표시한다.
황금가지 표식은 이번 원정의 선택된 배치안을 기준으로 표시하며, 회수 여부와 현재 경로에서의
도달 가능 여부를 구분해 보여준다. 표식 공개가 이동 조건이나 미탐사 상세를 함께 해제하지는 않는다.
해당 방을 클리어하면 그 방의 고정 정보를 영구 탐사 기록으로 확정한다. 이후 원정 실패나 과거
체크포인트 복구로 이 기록을 지우지 않으며, 생환을 기록 보존의 조건으로 요구하지 않는다.
단순 방문·인접 방 미리보기로 현재 원정에 보이는 정보와 클리어로 확정한 영구 기록을 구분한다.
방 진입 시 내부 노드를 공개하는 정책은 유지하되, 그것만으로 다음 원정의 방 정보 공개가 확정되지는 않는다.
일반 경로에 보스 첫 격파·이벤트 달성에 따른 별도 영구 해금 체계를 추가하지 않는다.
비밀 방·연결의 발견 조건, 명시된 이동 조건과 원정 내 전투·이벤트에 따른 잠금은 별도로 취급한다.
정보 공개 범위가 늘어나도 원정 시작 때 선택한 황금가지 배치안은 유지한다.
방 클리어는 다음 기준으로 확정한다. 모든 노드 해결이나 일반 보스 격파를 공통 조건으로 요구하지 않는다.

| 상황 | 방 클리어와 영구 탐사 기록 |
| --- | --- |
| 일반 방에서 선택 가능한 Gate를 통해 다음 방으로 이동 | 떠나는 방의 클리어와 기록 확정. 하강·지정 횡단에 동일 적용 |
| 깊이 3 이상 일반 방에서 선택 가능한 Gate를 통해 귀환 | 해당 방의 클리어와 기록 확정 후 성공 귀환 |
| 최종 보스가 있는 방에서 최종 보스 격파 | 해당 방의 클리어와 기록을 확정한 뒤 귀환 또는 계속 탐사 선택. 계속 탐사해도 기록은 유지 |
| Gate 도달·화면 확인만 하고 이동/귀환하지 않음 | 아직 클리어하지 않음 |
| 깊이 3 이상에서 억제력 소진으로 Gate 이용 없이 귀환하거나, 클리어 전에 전멸 | 현재 방의 신규 클리어 기록 없음. 이미 확정한 다른 방의 기록은 유지 |

최종 보스 방의 개방 기록은 해당 방 진입·보스 격파·방 클리어와 별개로 선행 조건 달성 시 확정한다.
징조·퍼즐의 부분 진행과 개방 상태는 해당 원정에 속하며 새 원정에 계승하지 않는다. 중단 후 이어하기는
확정된 진행을 보존하고 미확정 노드는 입장 전으로 복원한다. 체크포인트 복구는 당시 진행·조건·개방 상태를 함께 복원한다.
현재 위치에서 그 방으로 가는 실제 연결과 하강 제한을 따른다. 같은 층 재방문은 허용한다. 개방은 순간이동이나
보스 승리·보상 지급을 뜻하지 않는다. 영구 탐사 정보와 격파 기록은 유지하지만 개방 자격을 대신하지 않는다.
그 밖의 비밀 발견 기록과 구체적인 지도 좌표·표현은 NEXT-19에서 정한다.

### 방 규모와 컨셉

방마다 규모가 다르며 소형 6개·중형 9개·대형 12개를 노드 수 검토의 기준점으로 삼는다.
시작 노드와 Gate는 이 수에서 제외하고 고정 조우 노드는 포함한다. 세 숫자를 강제하는 템플릿이나
방문 상한이 아니며, 노드 수를 늘리면 총보상과 성장곡선도 함께 조절한다.

방 컨셉은 한 번 지정하면 원정마다 바꾸지 않는 방향의 가정책이다. 후보는 식당·의료·무기실·
격리·연구·기록의 여섯 종류이며 실제 방 배정과 세부 보상은 아직 정하지 않았다.
컨셉은 관련 고가치 보상·이벤트·특수 상인의 기회를 높이되 필수 보급이나 최소 보상을 보장하지 않는다.
일부 대표 보상만 해당 컨셉 전용으로 두고, 나머지는 다른 방에서도 낮은 확률로 얻을 수 있게 한다.
컨셉 방에서도 원하는 보상을 반드시 얻는 것은 아니다.

## 보스 분류와 연속 조우

보스 등급은 엘리트·일반 보스·최종 보스이며 준최종은 사용하지 않는다.
2026-09-27 정정에 따라 **흉탄의 사수는 숨겨진 최종 보스**다.

| 최종 보스 | 공개 구분 |
| --- | --- |
| 백야, 고요한 오케스트라, 종말새 | 기본 최종 보스 3종. 기존 ‘공개 최종 보스’ 분류도 지도상 초기 공개를 뜻하지 않으며, 방·연결은 선행 조건으로 개방 |
| 흉탄의 사수 | 숨겨진 최종 보스. 선행 마탄 조우와 구분 |

| 일반 보스 계열 조우 — 13개 항목 |
| --- |
| 아무 것도 없는, 웃는 시체의 산, 녹아내리는 사랑, 탐욕의 왕, 파고드는 천국, 마탄의 사수 |
| 절망의 기사, 증오의 여왕, 붉은 두건의 용병, 커다랗고 나쁠 늑대, 죽은 나비들의 장례, 음/양 |
| 죽을 나비의 장례 |

음/양은 하나의 조우 항목이다. 이 표는 선행·비전투 조우도 포함하며 13개의 독립된 즉시 전투를 뜻하지 않는다.
마탄의 사수는 흉탄의 단서를 여는 선행 조우이며 흉탄 자체와 바꾸어 세지 않는다.

흉탄은 공개 최종 보스 **백야·고요한 오케스트라·종말새를 각각 한 번 이상 격파한 영구 기록**이 있을 때,
현재 원정의 마탄 호위·생존 조우를 마치면 접근할 수 있다. 마탄 옆 **같은 층의 고정된 별도 방**과 직접 연결이 열린다.
공개 최종보스의 8층 배치에 대한 명시적 예외이며 흉탄의 최종보스 분류, 최대 깊이 8, 상승 금지는 유지한다.
같은 원정에 세 보스를 모두 잡거나 별도의 전조 체인·모노리스 조건을 달성할 필요는 없다.
흉탄 난입 목격은 이야기 기록이며 과거 원정에서 미리 확보해야 하는 추가 입장 조건이 아니다.
세 보스 영구 기록이 있는 플레이어의 첫 마탄 완료도 즉시 이번 원정의 흉탄 방을 열 수 있다.
새 원정에는 방을 다시 잠그고 마탄 조우를 다시 완료해야 한다. 흉탄에게 도전할지는 선택이다.

마탄 최초 조우는 전체 이야기·호위전을 보여 주고, 반복 조우는 도입을 줄이되 같은 호위·생존 전투와
흉탄이 나타나 마탄을 사살하는 결말을 유지한다. 첫 조우와 반복 조우 모두 일반 전투 보상·파편·알을 주지 않는다.
흉탄 격파의 단일 파편과 전용 무기·방어구·액세서리 고정 세트는 유지하며 **흉탄 본체 전투 설계는 보류**한다.
격파 기록의 보존은 [영구 도감과 기록](results-and-save.md#영구-도감과-기록)을 따른다.

분류만으로 원본·파생 관계, 선행 Event, 동행·계약, 부화, 개별 승패·보상 조건을 없애지 않는다.
상세는 [콘텐츠 카탈로그](../skills/lobotomy_content_catalog.md)와
[조우 설계](../skills/abnormality_design_notes.ko.md)를 따른다.

기존 연속 조우의 2층 시작 규칙은 옛 고정 관문표에 의존하므로 새 지도에 맞춰 재검토한다.
시작 방·후속 배치·동시 진행 수를 아직 확정하지 않았고, 최초 계약·동행만으로 제압 보상을 주지 않는다.
절망의 기사의 보호 계약은 축복 후 같은 원정에서 해당 직원이 직접 출전한 서로 다른 전투에서
10회 무사 승리하는 조건으로 바꾼다. 축복 후 어느 전투에서든 HP 0이면 도전 실패와 기존 구조전으로
전환한다. 대기 명단에서 얻은 승리·후퇴 후 재진입 자체는 집계하지 않고 같은 전투의 승리는 한 번만 센다.
10회는 초기 검증값이며 Event 배치·보호 난도·보상 획득 후 사용 기회를 함께 검증한다.
세부 집계와 보상은 [절망의 기사](../skills/abnormality_design_notes.ko.md#절망의-기사)를 따른다.

## 직원 선발과 채용

탐사 인력인 ‘직원’은 회사가 데려온 수감자이며, 시작 선발과 원정 중 채용 모두 이 설정을 따른다.
원정이 끝나면 회사는 정보 유출 방지를 명목으로 생존한 탐사 인력을 살처분한다. 성공 귀환으로도
이 처분을 피하지 못한다. 관리자는 동일 인물로 계속 원정을 지휘하고, 다음 원정에는 새로운
수감자를 선발하여 빌드를 구성한다. 이전 인물의 성장·부상·트라우마·신뢰·기억은 계승하지 않는다.
사망하거나 처분된 인물이 다음 원정에 같은 사람으로 복귀하지 않는다.

아래 직원 정의 목록은 선발·채용 콘텐츠의 기준이다. 원정마다 정의를 재사용하더라도 이전 인물의
부활이나 재고용을 뜻하지 않는다. 새 인물을 구별하는 이름·외형·배경의 생성과 표시 방식은
NEXT-02에서 후속 설계한다. 아래는 원정 내부 선발·채용 기준이다.

- 원정 중 일반 직원 채용은 **1~4층에서만** 제공한다. 5~8층에는 채용을 제공하지 않는다.
  0층의 시작 선발은 별도이며, 5층 이후 본사 연락의 다른 기능을 없애는 규칙은 아니다.
- 시작 후보와 본사 채용 후보는 같은 직원 정의 목록에서 온다. 시작 때 고르지 않은 후보와
  시작 후보 자격이 없는 직원은 미합류 채용 대기열에 들어간다.
- 대기열 순서는 런 시작 때 한 번 정한다. 본사 연락은 앞에서 정해진 수의 후보를 제시하고,
  다시 열거나 재접속해도 재추첨하지 않는다.
- 채용한 직원은 런 안의 새 직원 개체로 합류한다. 고르지 않은 후보는 제시 순서대로 대기열
  뒤로 돌아간다. 응급지원·본사 상점을 선택하면 현재 후보 전부를 같은 순서로 되돌린다.
- 한 직원 정의는 대기열·현재 제안·소속 직원 중 한 곳에만 있다. 방 이동과 저장 복구도
  소유와 순서를 보존한다. 콘텐츠의 직원 정의와 런 안의 직원 개체를 구분한다.
- 직원 정의에는 역할·배경·초기 장비·기본 전투 능력과 성격을 명시한다. 성격은 위험 성향
  `Brave / Cautious / SurvivalInstinct`와 사회 성향 `Obedient / Defiant / Comradely`를 하나씩 가진다.
- 전투 적성 `Balanced / Defensive / Offensive`는 표시 정보다. 장비 제한이나 불일치 페널티를
  만들지 않는다. 별도 specialties는 현재 기준에 없다.
- **시작 후보 6명 중 3명 선발, 보유 상한 10명, 전투 동시 배치 상한 8명**으로 한다. 별도의 출전 명단이나
  전투 등록 상한 없이 보유 인원 전원을 전투 중 배치 후보로 둔다. 두 전선의 방어와 작업·교대
  인원을 운용할 여지를 두며 모든 전투가 8명을 요구하지는 않는다.
- 전투 중 한 명을 철수시키면 다른 미배치 인원을 투입할 수 있다. 부상·트라우마·무기 등 출전 조건과
  개인별 배치 비용·재배치 대기를 적용하며, 전투 중 장비·파편·유물 변경은 허용하지 않는다.
  [배치와 철수](combat.md#배치와-철수)
- 초반 방에 고정 본사 연락을 두어 최대 2명을 채용할 기회를 제공한다. 무료·자동 채용은 아니며
  채용 직원도 기본 무기·파편 세트를 받고 비용에 이를 포함한다. 정확한 방·가격은 미정이다. 추가 본사 연락은 일반 배정 규칙을 따른다.
- 초반 고정 본사 연락은 지원 노드 상한 2개 안에 포함하고, 해당 방의 지원 수 분포를 개별 작성한다.
  중반 이후의 고정 채용 기회나 매 방 채용은 보장하지 않는다.
- 선발한 직원마다 기본 무기·파편을 한 세트씩 받는다. 딜러·탱커·힐러 후보 각 2명이며
  회수품 대여와 별도다. 추가 훈련용 파편 1개 선택은 제공하지 않는다. [훈련용 파편](equipment-and-fragments.md#회사-지급-훈련용-파편)
- 회사는 새 원정 시작 때 엔케팔린 기본 예산을 한 번 지급한다. 이전 원정의 성공·실패와 무관하게
  같은 지급 기준을 적용하며, 액수는 초반 채용·상점 가격과 함께 플레이로 조절한다.
  [원정별 예산](growth-and-rewards.md#재료와-엔케팔린)

부상·트라우마·사망과 복구 가능성은 [직원 상태와 실패](results-and-save.md#직원-상태)가 결정한다.
채용 직원의 기본 무기·파편과 실제 출전 가능 상태를 함께 검사한다.

## 시설 지도와 노드 선택

이 절은 전체 맵이 아니라 **한 방 내부의 노드 지도**를 다룬다.
방 내부의 노드와 방향이 있는 연결을 따라 탐사한다. 현재 위치에서 통과 가능한 노드를 거쳐 도달할 수
있는 미해결 노드를 선택한다. 승리·패배 결과가 확정된 노드는 소비되어 다시 내용을 실행하지 않는다.
실패 통과는 승리·격파·성공 완료 조건을 만족하지 않는다.

**방에 진입하면 방 내부 노드의 위치·연결·이동 방향·종류를 모두 공개**한다.
일반 전투·보스·Event·상점·정비·SavePoint·Gate 등의 배치를 보고 탐사 순서와 억제력 사용을 계획한다.
인접한 노드만 공개하거나 일반 노드의 지도 정보를 안개로 가리지 않는다. 잠긴 노드도 위치·종류와
잠금 상태를 표시하며, 공개와 현재 이동 가능 여부를 구분한다.
구체적인 적 구성·상품·보상은 각 노드의 미리보기 규칙을 따른다. 별도 발견 조건을 가진 비밀 보너스 노드는
아래의 조건 충족 후 공개 예외를 유지한다.

| 상태 | 의미 |
| --- | --- |
| Available | 선택 가능한 미해결 노드 |
| Completed | 해결되어 통과에만 쓰는 노드 |
| 실패 통과 | 일반 전투의 패배 확정으로 소비된 노드. 통과만 허용하며 해당 원정 재도전·승리 보상·격파 기록 없음 |
| Locked / Unavailable | 조건이나 진행 때문에 선택할 수 없는 노드 |
| Revealed | 종류와 미리보기를 공개 |
| Obscured | 미리보기 상세의 비공개 상태. 일반 노드의 위치·연결·종류를 가리는 근거로 사용하지 않음 |
| Concealed | 숨겨져 있으며 선택 불가 |

- 방 시작 노드는 완료·공개 상태의 실제 노드이며 현재 위치가 된다. 연결에는 양방향과 단방향이 있다.
- 노드의 종류·콘텐츠·난수는 원정 내 해당 방 배정 때 확정한다. 맵 재요청·재접속·이어하기로 재추첨하지 않는다.
- 황금가지 배치안은 원정 시작 때 시설 연결과 실제 이동 조건에 맞춰 선택하고 원정 내내 유지한다.
  방별 노드 배정에서는 이 배치안을 따르며, 자세한 자격·경로 기준은 [황금가지 봉인](expedition-and-deterrence.md#일반-보스와-황금가지-봉인)을 따른다.
- 전투 노드 선택은 진입 전 확인 화면을 연다. 실제 위치 변경과 진입은 무장하고 출전 가능한
  직원이 한 명 이상인 상태에서 최종 확인했을 때 확정한다.
- 미리보기·입장 전 취소는 비용이 없고, 실제 최초 입장 시 노드별 억제력 비용과 시한부 유예를 반영한다.
  최초 입장 여부와 노드 완료 여부는 별도로 보존한다. 후퇴·미해결 노드 재입장은 입장 비용을
  반환하거나 다시 청구하지 않는다. 부활 전투로 노드를 전환해도 최초 입장 기록은 유지한다.
  입장 처리 후의 소진·시한부 사망·출전 가능 상태를 확인하고 노드 활동을 시작한다.
- 게임 종료 후 이어하기는 진행 중 노드의 미확정 상태를 입장 전으로 복원한다. 입장 비용·유예·부화·창고 소비도
  결과와 함께 복원하되 이미 결정된 승패와 노드 소비는 결과 확인 버튼과 무관하게 유지한다.
  승패 전 종료 복구는 후퇴 횟수를 추가 차감하지 않으며 이미 사용한 수동 후퇴 기회도 반환하지 않는다. [저장 경계](results-and-save.md#저장과-복구)를 따른다.
- 지도는 Core가 허용한 목적지를 보여준다. 완료 노드 사이의 이동을 별도 플레이 행동으로 소비하지 않는다.
- 부화시킨 환상체에게서 도망쳐도 해당 노드는 미해결 환상체 조우로 남는다. 같은 방에서 다시 도전하거나
  다른 연결 경로로 우회할 수 있으며, 도망을 노드 완료나 해당 노드의 무료 통과로 처리하지 않는다.
  우회로가 없거나 Gate의 유일한 통로여도 기존 부화 자격을 만족하면 부화를 허용한다. 그 결과의
  진행 위험은 플레이어가 판단하며, 부화 때문에 별도 우회로를 보장하거나 자동 생성하지 않는다.
  다른 방에 갔다가 같은 층 연결을 통해 재방문할 수 있다. 더 깊은 층으로 내려간 뒤에는 돌아올 수 없다. 비용·후퇴 복원은 [부화 확정과 제압·도망](growth-and-rewards.md#부화-확정과-제압도망)을 따른다.
- 비밀 보너스 노드는 미리 작성된 선택 콘텐츠다. 지정한 선행 노드를 순서와 무관하게 모두 성공
  완료하면 한 번 공개한다. 실패·후퇴·취소·단순 방문은 조건을 만족시키지 않는다.
  Gate·SavePoint·필수 보스 같은 진행 필수 노드를 이 보너스에 숨기지 않는다.
- 시설 template, 노드 배정 검증과 좌표 연결은 [데이터 계약](../data_loading_contract.md)이 소유한다.

<a id="방-종류-배정"></a>

### 노드 종류 배정

노드 배정은 다음 순서의 목표 설계를 사용한다. RON 작성 의미와 실행 계약은 구분하며,
아래 방식이 현재 엔진에 모두 구현되었다고 간주하지 않는다.

1. 고정 연결 구조에 시작·Gate·일반 보스 출현 노드를 포함한 고정 조우·지정 SavePoint·고정 정비 방의 정비 노드를 예약하고 교체 대상에서 보호한다.
   첫 주요 갈림길 전의 초반 유물 보상 노드도 예약한다. 위치를 예약하되 유물 후보는 원정별 배정 규칙을 따른다.
2. 나머지 일반 후보 노드를 일반 침식체 전투로 채운다.
3. RON의 개수·범위·비율·가중치·출현 확률과 위치 조건으로 특수 노드를 배정한다.
   이미 선택한 자리를 다시 덮어쓰지 않고, 본사 연락 안의 상점 기능을 별도 상점 노드로 중복 집계하지 않는다.
4. 특수 노드 교체가 끝난 뒤 남은 일반전 수를 기준으로 난이도와 보상을 배정하고 위치를 섞는다.

전조는 위의 일반 특수 노드 출현 확률과 구분한다. 3~7층의 해당 계열 첫 진입 방에서 후보가 있으면
반드시 하나를 배정하며, 호환 노드 확보와 위 처리 순서의 결합은 별도 구현 설계에서 정한다.

고정 개수, 전체 후보 중 비율, 후보 간 상대 가중치, 출현 여부의 확률은 서로 다른 의미로 작성한다.
비율을 정수 개수로 바꿀 때 정수 부분을 먼저 배정하고 남은 자리는 소수 부분이 큰 항목부터 배분한다.
같은 원정에서는 동률 처리와 위치 배정도 재현 가능해야 한다. 수량·위치 조건이 충돌하면 중요 노드를
임의 삭제하지 않고 작성 데이터 오류로 알린다.

| 배정 대상 | 기본 정책과 초기 조절값 |
| --- | --- |
| 일반전 난이도 | 최종 일반전 수의 Easy 20% / Standard 50% / Hard 30%. 방별 작성값으로 조절 가능 |
| 지원 노드 | Maintenance·상점·본사 연락 합계 0~2개. 일반 배정은 0개 40% / 1개 45% / 2개 15%를 초기 분포로 사용. 고정 정비 방은 예약된 정비를 포함해 1~2개인 방별 예외로 작성 |
| 지원 노드 종류 | 2개일 때 기본적으로 서로 다른 종류. 특수 상인 둘 등 명시한 방별 예외만 중복 허용 |
| 고정 정비 | 지정 방의 같은 위치에 정비 노드 하나를 예약. 지원 노드 상한 2개에 포함하고 나머지 지원은 남은 자리 안에서 배정 |
| SavePoint | 지원 노드 추첨에서 분리하여 지정 방에 고정 배치 |
| 일반 보스 | 출현 노드 고정. 황금가지는 매 원정 재생성하며, 원정 시작 때 시설 연결과 실제 이동 조건에 맞는 사전 작성 배치안 하나를 선택. 즉시 조우 가능한 일반 보스만 배정 대상 |
| Event·보상·엘리트 | 매 방 보장하지 않음. 첫 주요 갈림길 전에는 접근 가능한 유물 보상 노드를 예약. 그 외 수·빈도는 조절 대상 |

위 비율은 플레이 검증에 따라 조절할 초기값이다. 지원 종류별 가중치와 방별 예외는 별도로 작성한다.
고정 정비 방 외에는 정비가 없는 방도 허용한다. 상점·이벤트도 매 방 보장하지 않으며,
방이 커졌다고 지원 수를 비례해서 늘리지 않는다.
유물 보상 노드는 보상 노드로 분류하며 Maintenance·상점·본사 연락의 지원 노드 상한에는 포함하지 않는다.
초반 보상 노드는 단순 선택형으로 예약하여 기본 무기·훈련용 파편에 활용할 범용 유물 선택 기회를 제공한다. 이후 유물 보상 노드는
매 방 고정 지급보다 주요 성장 경로의 도달 가능한 기회와 우회 비용을 기준으로 배정한다.
유물 보상 활동은 단순 선택·자원 투입·도박·유물 투입 가챠·스트레스 전투의 다섯 종류다.
초반 예약을 제외한 유형은 지도 생성 때 무작위 배정·고정한다. 노드 정보를 확인하면 진입 전에 유형·이용 조건을 공개하며, 재방문으로 재추첨하지 않는다.
입장 시 다섯 활동 중 직접 선택하는 방식은 사용하지 않는다. 유형별 가중치·깊이별 분포는 별도 작성한다.
모든 보상 노드를 공통 3택1로 만들지 않는다. 활동 규칙은 [유물 보상 노드](relic-reward-nodes.md), 공급은 [유물 보상](relics.md#획득과-표시)을 따른다.
유물 보상이 있는 일부 엘리트·고위험 일반전은 지도·진입 전 미리보기에서 해당 보상 기회를 표시한다.
구체적인 수량·간격·후보 구성은 [유물 공급](relics.md#획득과-표시)을 따른다.

SavePoint의 좌표는 고정한다. 간격은 층 수 대신 **주요 경로에서 수행할 활동 노드 수와 예상 플레이 시간**으로
설계한다. 고위험 구간의 간격은 일반 구간과 같거나 더 짧게 둔다. 정확한 수와 시간은 플레이로 조절한다.
분기·합류·횡단에 따른 실제 접근 간격을 확인하며 방문 횟수에 따라 동적으로 생성하지 않는다.
[저장과 복구](results-and-save.md#저장과-복구)

### 고정 정비 방과 접근성

시설 지도를 작성할 때 **정비를 포함하는 방을 고정하고, 해당 방의 정비 노드 하나를 매 원정
같은 위치에 예약**한다. 정비 방에는 일반전·Event·보상 등 일반 탐사 노드도 함께 배정한다.
고정 정비 노드는 일반 콘텐츠 추첨에서 교체하지 않으며, 나머지 노드는 기존 원정별 배정 규칙을 따른다.

세 주요 하강 경로에서 정비 공백이 지나치게 길어지지 않도록 접근 기회를 확보한다.
첫 정비는 초반 재료를 확보한 뒤 이용할 수 있는 위치로 잡고, 이후 **약 2층 간격**을 초기 검증
기준으로 삼는다. 구체적인 방·노드 좌표와 최대 공백은 지도 작성 및 플레이 검증에서 정한다.
깊이 숫자만으로 배치하지 않고 분기·합류·같은 층 양방향 연결과 상승 금지를 고려해 실제
이용 가능한 경로를 확인한다. 선택형 보스 격파를 정비 접근의 필수 조건으로 두지 않는다.

정비는 플레이어가 이용하거나 지나칠 수 있다. 고정 접근 기회는 매 방 정비, 무료 강화·개화,
또는 정비를 건너뛴 뒤 대체 노드를 자동 생성하는 규칙을 뜻하지 않는다. 작업 비용과 노드 최초 입장의
억제력 소모는 기존 규칙을 따른다. 고정 위치의 공개는 기존 지도 가시성·탐사 기록 규칙을 따른다.

고정 정비도 Maintenance·상점·본사 연락의 **지원 노드 상한 2개에 포함**한다. 해당 방은 지원 노드
1~2개인 예외로 작성하고, 추가 지원 노드는 남은 한 자리 안에서 상점·본사 연락 등을 배정한다.
고정 초반 채용을 같은 방에 두면 정비와 본사 연락으로 두 자리를 모두 사용한다. 예약된 지원 노드를
다시 추첨하거나 별도 수량으로 중복 집계하지 않는다. 구체적인 추가 지원 확률은 후속 조절 대상이다.

## Gate와 비전투 준비

Gate는 다음 방 이동 또는 성공 귀환을 선택하는 독립 노드이며 엘리트·보스나 SavePoint와 구분한다.
일반 방에서는 Gate까지 이어지는 경로의 노드를 해결해 도달하면 별도 해금 조건 없이 이용한다.
성공 귀환은 **현재 3층부터** 선택할 수 있으며 깊이 1~2에서는 다음 방 이동만 가능하다.
방문 방 수·횡단 횟수·이동할 목적 방의 깊이로 귀환 자격을 대신하지 않는다.
일정 수의 노드 해결·일반 보스 처치·열쇠 획득을 공통 이용 조건으로 추가하지 않는다.
보이는 Gate라도 연결 경로상 현재 도달 가능해야 한다. 현행 비교 기준은 기본 하나이며 특수 방의 여러 후보를 개별 작성할 수 있다.
7층 방별 8층 보스 방의 연결 대상은 고정한다. 각 방 내부의 Gate와 여러 연결 목적지의
구체적인 대응은 NEXT-03·19에서 정한다.
잠김·비밀 Gate는 명시 정책이 있는 콘텐츠에만 사용한다.
일반 방에서 Gate의 다음 방 이동 또는 귀환을 실제로 확정하면 해당 방을 클리어한 것으로 기록한다.
Gate를 보기만 하거나 선택을 취소한 경우에는 클리어를 확정하지 않는다.

Gate로 더 깊은 층의 방에 하강하면 생존 직원의 현재 트라우마 10%를 올림하여 줄인다.
Critical·Breakdown도 회복 대상이고 Dead는 제외한다.
같은 층 이동·재방문과 귀환에는 이 회복을 적용하지 않는다. 신체 부상·전투 HP·체크포인트는 바꾸지 않는다. 직원 상태·장비·
파편·유물 보유와 장착·소비 아이템·재화는 다음 방으로 이어진다.

Safezone은 노드 사이에서 지도와 편성을 다루는 준비 화면이다. 노드를 소비하거나 보상·치료·정비를
자동 지급하지 않는다. 장비·파편 교체, 유물 장착 변경과 허용된 소비 아이템 사용을 한다.
장비 이동과 같은 슬롯의 교체는 전체가 성공하거나 전체가 취소된다.

SavePoint·Maintenance·본사 연락·상점은 한 번 소비하는 비전투 노드이다.
보상 노드는 [활동 유형](relic-reward-nodes.md)에 따라 비전투 활동 또는 스트레스 전투를 수행한다.
스트레스 전투는 최대 5라운드의 연속 방어전이며 노드당 한 번만 시도한다. 라운드 사이 철수·최종 라운드 완료·패배·전투 중 수동 후퇴에서 활동을 종료하고 노드를 소비한다.
개별 라운드 완료를 별도 노드 소비로 취급하지 않는다. 라운드 사이에는 전투 시간을 멈추고 누적·다음 보상을 확인한 뒤 계속 방어 또는 보상 받고 철수만 선택한다.
성공·패배의 직원 손실은 일반 전투처럼 반영한다. 전투 중 후퇴는 진입 전 상태를 복원하지만 노드 소비·미수령 보상 상실을 유지하며 재도전하지 못한다.
[SavePoint](results-and-save.md#저장과-복구)는 저장·트라우마 회복,
[Maintenance](equipment-and-fragments.md#정비)는 강화·개화·분쇄,
본사 연락은 채용·보급 등의 선택을 담당한다. 본사 연락은 파편 연구나 대기 중인 파편 수령처가 아니다.

## Event

Event는 삽화·텍스트·선택·직원 판정으로 진행하는 독립 노드이다. 선택지가 없는 장면도 진행 입력을
받는다. 차기에는 매 방 하나를 보장하지 않으며, 방별 수와 출현 가중치는 작성 데이터로 정한다.

- 직원은 Medical·Security·Analysis·Reconnaissance·Containment·Maintenance 중 Event 적성 하나를
  가진다. 요구 적성과 일치하면 +3이다. 성격·신뢰·전투 능력은 일반 판정 보정이 아니다.
- 판정 선택지는 요구 적성, 난이도 8/12/16/20, 필요한 열쇠를 명시한다. 같은 적성에 적용되는
  해당 직원의 장착·소유 장비 중 가장 높은 +1/+2 하나를 더한다. 공용 인벤토리 장비는 적용하지
  않으며 동률은 장비 개체 ID 오름차순이다. 열쇠 조건 자체는 소비나 추가 보정을 뜻하지 않는다.
- 한 Event에서 선택·직원과 독립적인 d20을 한 번 확정한다. 1은 치명적 실패, 20은 치명적 성공,
  2~19는 주사위와 보정의 합이 난이도 이상이면 성공이다. 판정 가능한 장면은 최대 하나다.
- 확정한 선택·직원·주사위·보정·결과를 재접속·불러오기·후퇴로 다시 굴리지 않는다. 잘못된 요청은
  판정과 자원을 바꾸지 않는다. 실패도 작성된 다음 장면으로 진행하는 정상 결과다.
- 선택지가 전투를 시작하면 승리로 Event를 완료한다. 패배 결과를 확정하면 같은 Event에서
  재시도할 수 없다. 결과 판정 전 후퇴는 공통 복원 규칙을 따른다.
- BossOmen에서 시작한 Event 전투는 [전조 풀과 후퇴 횟수](growth-and-rewards.md#보스-징조와-반복-조우)을 따른다.
- 침식 Event는 보유 유물 하나의 효과·패널티를 미리 확인하고 선택하여 그 자리에서 변환하는 추가 기회다.
  촉매제나 추가 재화·재료를 소비하지 않으며 거절할 수 있다. 상점 촉매제 구매를 보완하고,
  정확한 배치 빈도는 플레이로 조절한다. [침식된 유물](relics.md#침식된-유물)

## 물품과 소비 아이템

일반 인벤토리에는 장비 개체와 소비 아이템 종류별 묶음이 들어가며 보유량 때문에 획득을 거절하지
않는다. 장비 하나와 소비 아이템 한 종류가 표시용 슬롯 하나씩 차지한다. 재화·재료·파편은
이 집계에서 제외한다. 슬롯 표시는 50에서 시작해 넘을 때 10단위로 늘고 물품을 줄여도 감소하지 않는다.
유물의 표시용 슬롯 포함 여부는 NEXT-10에서 정한다.

소비 아이템은 지도 보기와 전투 진입 전 확인에서 직원에게 사용한다. 성공하면 해당 종류의 수량을
하나 줄인다. 직원당 활성 효과는 하나이며 새 아이템은 기존 효과를 즉시 대체한다. 별도 덮어쓰기
확인이나 환불은 없다. 전투·결과·비전투 노드 내부에서는 사용할 수 없다.

효과의 남은 기간은 전투 결과 확정마다 한 번 줄인다. 후퇴와 비전투 방에서는 줄지 않는다.
사용이 끝난 아이템 자체를 되돌리는 기능은 없으며, 전투 후퇴는 진입 전에 이미 사용한 상태를 복원한다.

### 도구형 환상체의 소비·계약 구분

2026-10-04 채택에 따라 거목수액·발광 팔찌는 위 일반 소비품 한 칸을 사용한다. 수액의 효과를
교체해도 원정 공통 위험 장부는 초기화되지 않는다. 팔찌는 효과와 종료 시 HP 계약을 함께
교체하며 아이템을 환불하지 않는다. 전투 중 철수·재배치로 계약을 지울 수 없다.

이계의 초상은 소비품 교체로 해제되지 않는 지속 계약, 살점 우상은 명시된 전투 중 도구,
부서져 가는 갑옷은 특수 슬롯 조립 장비다. 피의 욕조·오래전의 믿음과 약속은 즉시 치료/강화,
지옥행 급행열차는 전장 기믹 보유권, 웰치어스는 직원 불참/복귀 상태로 다룬다.
이들을 모두 일반 소비품 효과 한 칸에 넣거나 일반 장비/유물 슬롯 수를 함께 바꾸지 않는다.

도구 조우의 구체적인 노드 종류·공급 빈도/위치는 기존 예약·배정과 입장 비용 규칙 안에서 작성한다.
새로운 필수 노드 종류나 매 방 도구 공급은 이 합의에 포함하지 않는다.
웰치어스 복귀는 층/Gate 수가 아니라 **납치 뒤 서로 다른 활동 노드 해결 5개**를 초기값으로 쓴다.
전투 승패 확정에 따른 소비와 비전투 완료를 세며 후퇴·재방문·Gate 이동/귀환은 세지 않는다.
조건 도달 노드의 결과와 복귀/보상을 함께 확정하고 활동 종료 후 준비 화면에서 보여준다.

도구 9종의 개별 대상·대가·기간·복원과 남은 수치는
[도구 설계](../skills/abnormality_design_notes.ko.md#tool-policy-20261004)를 따른다.

## 상점

상점은 엔케팔린으로 물품을 구입하고 판매 가능한 보유품을 파는 노드이다. 본부 상점에서는 일반
아이템·섭취 아이템·구급상자 등을 구입한다. 일반·특수 떠돌이 상점도 경제 사용처로 존재하며
상품·출현·추가 비용은 [NEXT-04](open-decisions.md#성장과-경제)에서 정한다.

엔케팔린은 전투 승리로 주로 확보하며 Event와 판매가 보조 공급처다. 판매 가능한 남는 장비는
엔케팔린을 얻는 판매와 장비 가루를 얻는 정비 분쇄 중 선택한다.
판매 가능 목록과 가격은 [재료 경제](growth-and-rewards.md#재료와-엔케팔린)에서 다룬다.

환상체 부활용 촉매제는 일반 상인의 기본 상품으로 취급한다. 희귀 상품 추첨을 전제로 하지 않고,
다른 상품 구매·채용과 비교해 구매를 고민할 정도의 비싼 가격으로 조절한다. 정확한 가격·재고는 미정이다.
이는 일반 상인 자체를 매 방 보장한다는 뜻은 아니다.
[알과 촉매제](growth-and-rewards.md#알과-촉매제)

유물 침식용 촉매제는 상점 구매를 기본 공급처로 둔다. 엔케팔린으로 구매해 보관했다가 원하는 보유
유물에 사용하며, 침식 자체의 위험에 과도한 구매 비용을 더하지 않도록 가격을 조절한다.
판매 상점·가격·재고·공급 빈도는 플레이 검증 대상으로 남긴다. 부활용 촉매제의 비싼 가격 기준을
그대로 적용하지 않는다. [침식된 유물](relics.md#침식된-유물)

- 상품과 수량·총가격·재고를 확정해 제시한다. 구매 후 빈자리를 자동 보충하지 않는다.
- 갱신은 작성된 비용과 횟수를 소비하여 페이지 전체를 교체한다. 부족하면 변경하지 않는다.
  같은 세션에서 반복 불가 상품을 샀으면 갱신해도 다시 나오지 않는다.
- 귀속·장착 장비와 0원 거래는 허용하지 않는다. 구매가는 기준 비율을 올림하고 판매가는 내림한다.
  상점 사이 또는 같은 상점에서 반복 매매로 차익을 만드는 가격은 허용하지 않는다.
- 유물은 엔케팔린으로 구입해 조합을 보완할 수 있으며 일반 상점 매각은 불가하다.
  도박형의 [딜러 보상 상점](relic-reward-nodes.md#딜러-보상-상점)은 해당 조우의 담보별 무이자 원금 회수·포기를 정산한 뒤 남은 포인트로 이용한다. 상점의 나가기에서 조우 완료·노드 소비를 확정한다.
  전용 유물은 관련 특수 상점 등에서 더 많이 제공하며, 정확한 상품 목록·가격·재고·출현은 NEXT-04·06에서 정한다.
- 장비 가루·환상체 파츠는 상점에서 직접 구매하거나 판매할 수 없다.
- 물품 수용량 때문에 구매·보상을 지연하지 않는다.

## 진입 전 브리핑

전투 모드·임무, 전장과 배치 가능 구역, 주요 경로·진입 방향, 위험도·보상 후보, 주요 적과 위협
경고의 신뢰도를 무료로 제공한다. 재화를 써서 정보량을 늘리지 않는다.
모든 웨이브와 등장 시각·숨은 기믹의 세부는 전투 중 관찰과 허용된 후퇴 후 재진입으로 배울 수 있다.
납득 가능한 배치를 할 정보가 부족하면 기본 브리핑을 보강한다.
무억제 전투는 HP·공격력의 조우별 강화 배율과 변경값, 승리 보상 2배의 적용 대상을 함께 보여준다.
최초 입장 비용을 반영한 예상 억제력 잔량과 시한부 직원의 잔여 유예·사망 위험도 함께 보여준다.
[무억제 강화와 보상](expedition-and-deterrence.md#무억제-강화와-보상)

## 현행 모드와의 연결

차기의 제품 모드는 **튜토리얼과 원정** 두 가지다. Standard·Endless 모드 구분은 제거한다.
튜토리얼은 전용 지도·사전 설정 직원과 장비로 진행하며 반복해서 플레이할 수 있다.
원정 인벤토리·창고·영구 진행 기록에 영향을 주지 않는다. 첫 실행에는 권장하지만 건너뛸 수 있고,
메인 메뉴에서 원정을 즉시 시작할 수 있다. 튜토리얼 완료를 원정 해금 조건으로 요구하지 않는다.
원정은 이 문서의 새 시설 지도와 귀환·실패 규칙을 따른다.
일반전 난이도 Easy/Standard/Hard의 Standard는 난이도 이름이며 제품 모드가 아니다.
기존 모드 구현과 저장 이행은 [과거 모드 규칙](../archive/game_rulebook_legacy_2026-10-04.md#게임-모드)을 비교 기준으로 삼는다.
