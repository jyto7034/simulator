# 전투 조작과 화면

[게임 설계서](../game_rulebook.md) · [전투 규칙](combat.md) · [미결정 사항](open-decisions.md)

이 페이지는 9월 13일 후속 합의의 입력·표시 규칙을 통합한다. 위임으로 채택한 일반 조작도
포함하며 직접 답변과 위임의 출처는 [통합 기록](../decisions/game_rulebook_next_restructure_2026-09-26.md)에 구분한다.
세부 화면 배치는 [Unity UI 설계](../../../../../unity%20projects/ark/docs/ui-layout/ui-layout.md)가 소유한다.

## 로스터와 대상 확인

- 보유 인원 전원을 로스터에 표시하며 전투 전 별도의 출전 명단을 고르지 않는다.
  동시 배치 상한 8명에 도달하면 미배치 인원에게 상한 도달을 배치 불가 사유로 표시한다.
- 왼쪽은 배치된 직원, 오른쪽은 미배치 직원이다. 각 구역은 원래 편성 순서를 유지하며
  작은 여백으로 나눈다. 빈 구역에는 큰 공간이나 여백을 남기지 않는다.
- 편성 `A B C D`에서 A·C가 배치되면 `A C / B D`다. B 배치 성공 후 `A B C / D`,
  A 철수 후 `B C / A D`가 된다. 배치 후보를 고르는 것만으로 카드를 옮기지 않는다.
- 미배치에는 재배치 대기와 배치 불가 직원도 포함하고 남은 시간·사유를 표시한다.
  전술 이동·교대는 배치 상태와 편성 순서를 바꾸지 않는다.
- 배치 초상화를 클릭하면 해당 아군의 정보와 명령을 보여주는 포커스를 연다.
  기본 화면의 배치 카드에는 `배치 중` 문구를 생략하고 포커스 화면에서는 유지하며 총 배치 인원 표시는 생략한다.
- 적 클릭은 이름·HP·주요 능력·특성·현재 상태를 보여주는 정보 포커스다. 아군 명령이나
  아군 전용 공명·장착 정보를 넣지 않는다. 적 사망·퇴장 시 닫는다.
- 빈 곳·우클릭·Esc로 일반 포커스를 닫고 같은 대상을 다시 클릭하면 유지한다.
  스킬 대상을 고르는 중 적 클릭은 스킬 입력으로 처리한다.

### 판정 위치와 대상 미리보기

선택한 유닛의 판정용 타일과 연속 위치를 구분해 확인할 수 있게 한다. 공격·치유·스킬을 선택하면
현재 조건에서 실제로 유효한 대상과 범위를 미리 표시한다. 선택 유닛의 저지 관계도 함께 보여 주고,
저지한 상대를 기본 공격할 때의 사거리 예외를 표시한다. 전장의 모든 관계를 항상 펼쳐 놓지는 않는다.
미리보기는 현재 상태의 판정이며 적 이동·상태 변화 이후의 명중을 보장하지 않는다. 최종 실행은 최신 조건을 검사한다.
로스터 카드의 입력 중 위치 고정 여부는 별도 보류 사항이며 현재 좌/우 배치 구분 규칙을 변경하지 않는다.

## 포커스와 배속

아군·적 포커스에 들어가면 실제 전투를 0.5배속으로 낮추고 표시도 `0.5×`로 바꾼다.
로스터 배치·재배치도 드래그 시작부터 타일·방향 선택이 끝날 때까지 같은 감속을 적용한다.

- 전체 선택을 끝내면 진입 전 배속으로 돌아간다. 예를 들어 `2× → 0.5× → 2×`다.
- 대상 전환과 이어지는 이동·교대·스킬 선택 동안 최초 복원 배속을 유지한다.
  선택이 겹쳐도 0.25배속처럼 감속을 곱하지 않는다. 일반 포커스가 남으면 0.5배속을 유지한다.
- 이미 정지 중이면 선택 진입으로 재개하지 않는다. 선택 중 수동 정지·재개는 허용하되,
  수동으로 정지한 전투를 선택 종료만으로 재개하지 않는다.
- 기본 화면은 1×/2× 클릭 전환이다. 포커스·고스트·방향·스킬 선택 중 수동 배속 버튼은 비활성이다.
- 전투 종료·후퇴는 포커스 복원보다 우선한다. 종료된 전투를 다시 진행시키지 않는다.

공통 감속의 저장·재접속과 수동 스킬 선택 상태의 결합은 [NEXT-13](open-decisions.md#저지와-전투-조작)에 남아 있다.

## 배치와 전술 이동

로스터 카드는 누른 채 끌어서 타일에 놓는다. 전장 유닛의 이동은 명령을 선택한 뒤 버튼을
계속 누르지 않아도 따라오는 고스트로 목적지를 클릭한다. 두 방식 모두 다음 단계를 거친다.

1. 반투명 고스트로 유효한 타일을 고른다. 타일 중심과 높이에 맞춰 표시한다.
2. 타일에 고스트를 고정하고 커서로 방향·공격 범위를 미리 본다.
3. 방향을 클릭하여 실제 배치 또는 이동을 최종 확정한다.

고스트는 실제 유닛이나 점유를 만들지 않는다. 선택 중에는 해당 입력으로 위치·태세·비용을 바꾸지
않으며 최종 확정 때 최신 조건을 검사한다. 진행 중인 전투의 다른 상태 변화는 계속된다.

## 자리 교대

1. 배치된 A를 포커스하고 교대를 선택한다. A 고스트와 선택 가능한 아군을 표시한다.
2. 전장의 B 또는 배치 구역의 B 초상화를 클릭한다. A 자신·미배치·교대 불가 직원은 선택할 수 없다.
3. B의 타일에서 A 방향을 고르고 클릭한다.
4. A의 원래 타일에서 B 방향을 고른다. **B 방향의 클릭이 교대 전체의 최종 실행**이다.

B 선택만으로 실행하거나 일반 B 포커스로 바꾸지 않는다. 두 방향 설정을 생략하지 않으며
별도 완료 버튼은 없다. `전술 포인트 5 · 교대 후 강제 방어 1.5초 · 이후 자동 공격`을 안내한다.

최종 확정 전 우클릭·Esc는 전체 교대를 취소해 A 포커스로 돌아간다. 성공 후에도 A 포커스를
유지한다. 이동은 이동 유닛의 포커스를 유지한다. 검증 실패 시 사유를 표시하고 목적지/상대
선택으로 돌아가며 자동 대기 후 실행하지 않는다. 출발 유닛이 무효이면 명령·포커스를 종료한다.

## 도착과 작업 연출

배치·재배치·전술 이동·교대 성공 후 도착 타일의 낮은 공중에 나타나 짧게 내려앉는 공통 연출을
쓴다. 교대의 두 도착은 함께 시작한다. 선택·취소·실패 때 성공 연출을 재생하지 않는다.
높이·시간·착지 효과는 제작 수치이며 공중 판정·무적·피격 유예·추가 행동 대기를 뜻하지 않는다.

일반 이동·교대는 강제 방어의 남은 시간과 자동 공격 전환을 표시한다. **작업 가능한 칸에 도착하면
즉시 작업 연출로 연결**하며 별도 버튼이나 1.5초 방어 대기 연출을 요구하지 않는다.
작업 진행도와 작업 중 표시를 제공한다. 작업 시작은 강제 방어 타이머를 취소하며 완료 후 공격 태세로 전환한다.
이동·작업 전 태세를 저장해 복원하지 않는다.

## 카메라

고정 구도를 쓰는 전장과 이동 가능한 전장이 있다. 이동 가능한 전장은 마우스 드래그와 방향키로
시야를 옮기고 제한된 범위의 휠 확대·축소를 지원한다.

- 배치 초상화 더블클릭은 해당 직원 위치로 짧고 부드럽게 이동한다. 현재 확대 수준을 유지하고
  정보창에 가리지 않게 가져온다. 수동 드래그·방향키로 중단하며 도착 후 계속 추적하지 않는다.
- 고정 전장은 구도를 유지하며 대상을 강조한다. 미배치 직원의 없는 위치로 이동하지 않는다.
- 방향키는 화면 기준으로 누르는 동안 이동한다. 고스트·방향 설정 중에도 선택 단계와 타일을
  유지하고 시야만 옮긴다. 타일 선택 전에는 커서 아래 후보를 다시 보이며, 방향 설정 중
  카메라 이동만으로 고정한 타일이나 방향을 바꾸지 않는다.
- UI·로스터·고스트·방향·명령 대상 입력을 카메라보다 우선한다. 카메라 드래그 종료를 포커스
  해제 클릭으로 처리하지 않는다. 교대 대상 더블클릭이 상대 선택과 방향 확정을 함께 실행하지 않는다.
- 전장 위 휠은 카메라, 스크롤 UI 위 휠은 그 UI만 조작한다. 확대해도 고정 UI 크기는 유지한다.
- 정지·감속 중에도 시야를 움직일 수 있다. 카메라 입력은 배치 확정·취소·전투 배속을 바꾸지 않는다.
  설정 메뉴·텍스트 입력 등 입력을 잡는 UI는 우선한다.
- 맵 이동 경계와 확대 한도를 지킨다. 큰 맵에서 화면 밖 보호 대상이 피해를 받으면 방향·위험을 알린다.

카메라 회전·미니맵·화면 가장자리 스크롤·마우스 가운데 버튼 필수화는 이번 합의에 포함되지 않는다.

## 설정과 전투 포기

설정을 열면 자동 정지하고 계속하기·게임 설정·전투 포기를 제공한다. 닫으면 직전 정지·배속 상태를
복원한다. 전투 포기는 진입 전 상태로 돌아가는 결과를 안내하고 확인받는다.
노드 최초 입장에 이미 쓴 억제력과 시한부 유예 진행은 반환하지 않으며, 후퇴 기회 1회가 소비되고 별도 재화 비용은 없음을 함께 안내한다.
일반전·전조는 남은 후퇴 횟수(최대 2회)를 표시하며 0회이면 전투 포기를 비활성화한다. 개별 직원 철수와 구분한다.
명시된 활동 예외에서는 공통 2회 안내를 사용하지 않고 Core가 제공하는 현재 후퇴 자격·결과를 표시한다.
[스트레스 전투](relic-reward-nodes.md#스트레스-전투)의 전투 중 후퇴는 전투 변화를 복원하되 노드를
소비하고 미수령 보상을 잃으며 재도전할 수 없다. 라운드 사이의 **보상 받고 철수**는 누적 보상을
지급하는 성공 정산 선택이므로 전투 중 후퇴와 별도 입력·안내로 구분한다. 고유 후퇴 금지가 적용되는
활동은 해당 사유와 함께 전투 포기를 비활성화한다. U16-4와 각 활동 owner가 자격·결과를 제공하고
U26-A는 일반전·전조·스트레스·고유 금지의 메뉴와 실제 Core 결과가 일치하는지 검증한다.
승리·패배 조건이 성립하면 즉시 노드와 결과를 저장하고 수동 전투 포기를 닫는다.
결과 화면의 확인은 다음 화면으로 진행하는 입력이며, 확인 전 종료해도 승패와 노드 소비는 유지한다.
승패 전 게임 종료는 후퇴 횟수를 차감하지 않는 예외다. 노드 입장 전 복구는 [별도 저장 규칙](results-and-save.md#저장과-복구)을 따른다.
개별 직원 철수는 추가 확인 없이 실행한다. 전투 중 불러오기·즉시 재시작은 별도 저장 정책을
우회할 수 있어 기본 메뉴에 추가하지 않는다.
