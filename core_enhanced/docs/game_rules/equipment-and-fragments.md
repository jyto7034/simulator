# 장비와 스킬 파편

[게임 설계서](../game_rulebook.md) · [성장과 보상](growth-and-rewards.md) · [유물](relics.md)

## 장비와 무기

일반 장비와 E.G.O 장비는 무기·방어구·액세서리 슬롯을 사용한다.
무기는 기본 공격·공격 범위·대상 선정·공격 주기·기본 저지 수와 배치 가능한 타일을 제공한다.
직원의 직업·전투 적성이나 방어구가 무기의 기본 저지 수를 대신하지 않는다.

직원의 기본 공격 속도 100은 중립이다. 최종 공격 주기는
`ceil(무기 기본 주기 × 100 / 직원 공격 속도)`다. 무기가 없으면 기본 저지는 0이고,
직원은 편성과 장비 관리에는 남지만 전투 배치·재배치·범위 미리보기를 할 수 없다.
출전 불가 상태도 함께 있으면 그 상태의 사유를 먼저 보여준다.

| 무기 적성 | 작성할 타일 효과 |
| --- | --- |
| GroundOnly | 지상 방어 효과 |
| PlatformOnly | 발판 휴식 효과 |
| Any | 두 타일의 효과 모두 |

타일 효과와 무기 기본 저지는 별개다. 파편의 최소 저지 조건은
방어 중 증가분 대신 무기의 기본 저지 수를 사용한다. 기존 Certified 계산도 같은 기준이지만
차기의 적 난이도는 편성 전투력을 따라 조정하지 않는다.
이어받은 첫 콘텐츠의 값은 다음과 같고, 무기별 명시 값을 적용한다.

| 계열 | 적성 | 기본 저지 | 방어 시 효과 |
| --- | --- | --- | --- |
| Staff | PlatformOnly | 0 | 1초마다 HP 3, 공명은 공통 자동 충전 |
| Bow / Gun | GroundOnly | 0 | 저지 +0·받는 피해 10% 감소 |
| Sword / Spear | GroundOnly | 1 | 저지 +1·받는 피해 10% 감소 |
| Shield | GroundOnly | 3 | 저지 +1·받는 피해 10% 감소 |

일반 강화는 무기 개체가 제공하는 공격력·주문력을 높인다. 강화 상태는 같은 이름의 모든 무기가
공유하지 않고 보유한 개체를 따른다. 방어구·액세서리는 능력치·복잡한 자체 특수 효과를 가질 수
있지만 일반 강화는 없다. 정확한 강화 한도·수치·비용과 기존 강화 상태 전환은 NEXT-07에서 정한다.

일반 강화 효과는 시설 밖으로 반출하면 사라진다. 성공적으로 생환해 반납한 무기도 일반 강화는
초기화된 상태로 다시 대여한다. 시설 내 메인터넌스가 부여하는 강화 효과는 시설 안에서만 유지된다는
설정이다. 메인터넌스의 정체가 환상체인지 다른 생명체인지는 아직 정하지 않았다.

## 장비 효과의 발동

장비는 전투 시작·기본 공격 적중·피격·처치·사망·아군 사망에 명시한 효과를 발동한다.
같은 사건에서는 일반 효과를 능력 활성화보다 먼저 처리하고, 여러 장비·직원의 순서는
[런타임 계약](../core_runtime_contract.md)이 정한 결정론적 순서를 따른다.

- 전투 시작은 일반 효과와 활성 능력을 모두 적용한다.
- 공격·피격 장비 발동은 확정된 기본 공격 적중에서 발생한다. 일반 스킬·버프 틱·장판 피해가
  이를 다시 만들지 않는다.
- 사망 시 능력은 사망한 소유자가 실행할 수 있다. 처치는 실제 처치자, 아군 사망은 같은 편의
  살아 있는 나머지 유닛을 기준으로 한다.
- 피격 시 공격자에게 반격하는 추가 피해는 원래 적중에서 한 번 계산한다. 소유자에게 들어오는
  피해를 증폭하는 효과가 아니며, 반격으로 공격/피격 장비 발동을 다시 수집하지 않는다.
  공격자가 없거나 죽었으면 다른 상대에게 옮기지 않는다.

## 파편 장착과 능력

직원은 기본 고유 active skill 대신 장착한 파편의 대표 active skill을 쓴다. 기본 active 파편
슬롯은 하나다. 환상체 유래 파편은 각각 원본 환상체 하나에 대응하며 한 환상체가 여러 파편을
가질 수 있다. 회사 지급 훈련용 파편은 환상체 유래가 아닌 별도 범주다.
환상체 자체 능력과 직원용 모방 스킬은 별도 콘텐츠다.

파편은 passive 장비가 아니다. 평타 강화·일시 능력·버프·공명 변화도 active skill의 결과로
표현한다. 기존 직접 BasicAttackModifier 파편들은 제작 전 임시 콘텐츠이며 정식 정책의 구현
완료 근거로 사용하지 않는다.

장착 조건은 직원 직업명이 아닌 장착 무기의 전투 profile을 사용한다. 근접/원거리·무기 계열·
기본 저지 등의 제한을 둘 수 있으며 모든 무기와의 호환을 보장하지 않는다. 최종 자격은 Core가
검증한다. 개별 콘텐츠는 [파편 설계](../skills/abnormality_skill_fragments_design_notes.md)를 따른다.

흑조형 패링 파편은 개별 예외로, 장착한 실제 사본의 직원이 배치되어 있는 동안 공명과 무관한
피해 경감·확률 반사를 제공할 수 있다. 기존 active 슬롯 하나를 그대로 사용한다. 모든 형태에
SelfUnit/Instant 패링이 있어야 하며 상시 경감과 유한 패링 경감을 중복 작성하지 않는다.
철수·전투불능·전투 종료 시 상시 효과가 사라지고 재배치 시 장착 사본에서 다시 파생한다.
실패 빈틈은 해당 사본의 경감만 해제한다. 반사는 직접 적 타격의 실제 HP 손실을 기준으로
대상별 첫 양수 segment에서 한 번 판정하며, 반사·받아치기·자기 피해·HP 비용은 입력에서 제외한다.
패링/무적에 막힌 타격은 반사하지 않는다. 공격자 소실 또는 반사 소유자의 전투불능 시 반사를
실행하지 않으며, 새 대상을 선택하지 않는다. 수치는 콘텐츠별 검증 데이터이며 fixture 수치를
공식 밸런스로 간주하지 않는다.

## 회사 지급 훈련용 파편

원정 시작 후보는 **6명이며 그중 3명**을 선발한다. 후보마다 기본 무기와 기본 파편을 한 세트씩 지급한다.
채용 직원도 같은 방식으로 기본 세트를 갖추며 채용 비용에는 세트를 포함한다. 회수품 대여와 별도다.
역할은 초기 구성이고 직업 고정 장비 제한이 아니다. 전투 밖에서 일반 장착 조건에 따라 서로 이전할 수 있다.

| 후보 역할 | 기본 무기 | 기본 파편 |
| --- | --- | --- |
| 딜러 1 | 총 | 아드레날린: 공격력·공격 속도 증가 |
| 딜러 2 | 검 | 버서커: 공격력·공격 속도 증가와 생명력 흡수 |
| 탱커 1 | 방패 | 최후의 전선: 받는 피해 감소 |
| 탱커 2 | 대검 또는 도끼 | 돌파: 전방 범위 타격과 짧은 자기 보호막 |
| 힐러 1 | 단일 치유 지팡이 | 강한 단일 아군 회복 |
| 힐러 2 | 범위 치유 지팡이 | 선택 영역의 아군들을 약하게 회복 |

지팡이의 기본 행동은 순수 치유다. 공격이나 보호막으로 대신하지 않는다. 단일·범위 치유의 정확한
수치·주기·사거리와 후보 파편 계수는 콘텐츠 작성·플레이 검증 대상이다.
훈련용은 일반 파편과 active 슬롯·공명·발동 규칙을 공유하고, 환상체 파편은 고유 기믹과 조합으로 확장한다.
별도로 힐링·딜링·탱킹 중 하나를 골라 추가 파편 1개를 받던 규칙은 이 기본 세트 지급으로 대체한다.

## 개화와 형태 선택

파편 일반 강화는 없다. 개화는 새 형태를 해금하고 기존 형태도 남긴다. Maintenance에서 사용할
형태를 선택한다. 다른 환상체의 파츠를 요구해 선행 조우와 개화 접근 난이도를 조절할 수 있다.
일부 고성능 파편의 개화에는 다른 환상체의 재료를 요구한다. 필요한 재료를 미리 공개하여
원정 경로와 부활 대상을 계획할 수 있게 하고, 세 번째 격파를 개화 재료 파밍 단계로 사용한다.

개화는 시설 밖으로 회수·반납해도 유지한다. 일반 강화의 반출 초기화 규칙을 개화에 적용하지 않는다.
다음 원정에 가져간 개화 파편을 잃으면 해당 회수품도 잃는다는 회수·대여 원칙을 따른다.
이는 같은 종류의 모든 파편에 개화를 영구 해금한다는 뜻은 아니다.
[원정 귀환과 회수품 대여](results-and-save.md#원정-귀환과-회수품-대여)

개화 요구 비용은 **해당 스킬 파편을 정의한 RON에 개화 형태별로 직접 작성**한다.
필요한 환상체 파츠의 ID·수량 목록과 엔케팔린 동반 비용을 데이터로 지정한다.
엔케팔린은 개별 recipe에서 요구한 경우에만 소비하며, 별도의 공통 개화 수수료는 없다.
요구 비용을 미리 보여 주고 전부 충족할 때 함께 소비하여 해당 사본의 개화 형태를 해금한다.
구체적인 RON 필드·검증·기존 데이터 이행과 실행 구현은 [NEXT-07](open-decisions.md#성장과-경제)의 후속 작업으로 남긴다.

BossOmen처럼 개별 작성한 조우 진행은 결과 확정에서 같은 파편 identity의 현재 형태·단계를
전환할 수 있다. 파편을 추가 지급하거나 정적 원본을 덮어쓰는 방식이 아니다. 그 진행과 자유로운
형태 선택·개화 조건의 관계, 해금 형태/선택 형태 저장은 [NEXT-07](open-decisions.md#성장과-경제)에서 정한다.

## 정비

무기 강화 비용은 장비 가루로만 지불한다. 일반전이 가루의 주 공급처이며 장비·유물 분쇄로
추가 확보할 수 있다. 가루 지급량·분쇄량·강화 요구량은 [재료 경제](growth-and-rewards.md#재료와-엔케팔린)를 따른다.

Maintenance는 작업을 여러 번 한 뒤 완료하는 독립 노드이다.
재료 공용 창고 UI를 사용하는 장비 노드도 이 정비 지점을 뜻한다.
주요 하강 경로의 접근 기회는 [고정 정비 방](run-and-map.md#고정-정비-방과-접근성)으로 확보한다.
지정 방의 정비 노드는 매 원정 같은 위치에 예약하며, 첫 정비는 초반 재료 확보 뒤 이용할 위치로 둔다.
약 2층 간격은 초기 검증 기준이고 실제 배치는 분기·합류·횡단 경로를 함께 고려한다.
정비 이용은 선택이며, 고정 배치도 강화·개화 재료 비용과 노드 최초 입장 비용을 유지한다.
한 정비 노드에서 여러 작업을 해도 억제력과 시한부 유예는 최초 입장 시 한 번만 처리한다.

| 대상 | 가능한 작업 |
| --- | --- |
| 무기 | 명시 recipe에 따른 강화·분쇄 |
| 방어구·액세서리 | 명시 recipe에 따른 분쇄 |
| 스킬 파편 | 개화·기본/개화 형태 선택·분쇄 |
| 유물 | 장착·해제·교체·직원 간 이전·분쇄 |

Core가 대상별 가능 여부·불가 사유·비용·획득·변경 전후를 보여준다. 실제 실행 때 소유·장착·
재료 상태를 다시 검증하고 전체 작업을 함께 성공시키거나 변경하지 않는다. 장착한 대상의 분쇄는
확인 후 자동 해제할 수 있다. 같은 재료가 recipe에 여러 번 있으면 합계로 검증·소비한다.

recipe가 없는 작업에 임의의 비용·획득을 주지 않는다. 기존 standard_armor 강화는 차기 방어구
강화 정책으로 이어받지 않는다. 장비 제작과 강화 자동 이전은 정비 작업에 포함되지 않는다.
Safezone에서는 장착을 바꿀 수 있지만 이 강화·개화·분쇄 작업을 자동 제공하지 않는다.

새 recipe·명령·저장 형식과 재료 경제는 [NEXT-04·07·10](open-decisions.md)에 남아 있다.

### 분쇄와 투자 재료 환급

분쇄하면 해당 사본을 소모하고 기본 분쇄 보상에 더해 실제 투자 재료 일부를 돌려받는다.
초기 환급률은 **50%**이며, 사본에 실제 소비한 재료를 종류별로 합산한 뒤 비율을 적용하고 내림한다.
비율은 플레이테스트로 조절한다.

| 대상 | 투자분 환급 |
| --- | --- |
| 강화한 무기 | 현재 유지 중인 일반 강화에 실제 소비한 장비 가루의 50% |
| 개화한 스킬 파편 | 해당 사본의 개화에 실제 소비한 환상체 파츠를 종류별로 50% |

엔케팔린 비용은 환급하지 않는다. 기본 분쇄 보상량은 개별 recipe가 정하며 투자분 환급과 구분한다.
형태를 바꾸거나 소유 직원을 바꾸어도 투자 내역을 중복 계산하지 않는다. 무료로 얻은 강화·개화에는
투자분 환급이 없고, 현재 recipe의 정가 대신 실제 소비량을 기준으로 한다.

회수할 때 일반 강화가 초기화된 무기는 해당 강화의 투자 내역도 비운다. 개화를 유지해 반납·대여하는
파편은 사본별 파츠 투자 내역을 함께 보존한다. 분쇄 환급은 원래 소지·창고 중 어디에서 소비했든
현재 원정의 소지 재료로 지급하며, 창고 보관에는 성공 귀환 시 선택 회수가 필요하다.
분쇄 전 사본 소멸과 기본 보상·환급량을 보여 주며, 확정 시 사본·투자 내역 소비와 보상을 함께 처리한다.
체크포인트는 사본·강화/개화·투자 내역·분쇄 보상을 같은 시점으로 복원한다.

## 재료 공용 창고

공용 창고는 다음 원정의 빌드 구성을 앞당기는 수단이다. 성공 귀환 때 **환상체 파츠는 종류 합계 최대 2개,
부활 촉매제는 별도로 최대 1개**를 선택 회수한다. 두 한도는 초기 플레이테스트 값이며 가중 용량으로 합치지 않는다.
장비·파편은 별도의 합계 최대 2사본 대여를 따른다. 장비 가루·알·엔케팔린·침식 촉매제와 일반 회복·전투 소모품은
회수·창고 보관하지 않는다. 일반 소모품은 해당 원정 안에서만 쓰며 창고로 전투 편의 물품을 축적하지 않는다.
무기 강화에는 현재 원정에서 보유한 장비 가루를 사용한다.

장비 노드에서 개화할 때 현재 원정의 소지 재료와 공용 창고 재료를 함께 사용할 수 있다.
재료를 출발 전에 반입하거나 별도로 운반할 필요가 없으며, 사용량·인출량의 원정별 제한도 두지 않는다.
실제 작업에 필요한 만큼만 차감하고 재료 소비와 개화 결과를 함께 확정한다. UI는 요구 재료와
소지·창고 수량 및 소비량을 보여준다. 여러 원정에 걸쳐 모은 재료로 멀리 떨어진 조우를 반복하는
부담을 줄이되, 새 재료의 영구 보관은 성공 귀환 때 선택 회수하는 규칙을 따른다.

부화 화면에서도 현재 소지분 또는 창고의 부활 촉매제를 선택해 직접 소비한다. 출처별 보유량·소비량을
확인하며 사전 반입이나 별도 원정별 사용 한도는 없다. 알은 반드시 현재 원정에서 확보한 것을 사용한다.

창고에 남은 재료는 현재 원정 실패로 사라지지 않는다. 사용한 재료로 개화한 파편은 현재 원정의
회수품으로서 실패 시 소실될 수 있다. 체크포인트 복구 없이 실패를 확정하면 사용한 재료는 반환하지 않는다.
체크포인트를 불러오면 그 이후의 소비와 개화 결과를 함께 되돌리고, 소비 재료는 소지·창고의 원래 출처로
복원한다. 체크포인트 이전의 소비는 유지하며 반복 복구로 재료가 늘어나지 않는다.
종료 후 이어하기는 미확정 노드의 소비와 결과도 입장 전으로 함께 복원한다. 저장 구현 세부는 NEXT-10·16에서 정한다.
