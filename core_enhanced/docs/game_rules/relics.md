## 효과와 희귀도

유물은 무기·파편의 효과를 강화하거나 새 효과를 더하여 런마다 다른 조합을 만든다.
범용 유물은 효과 태그와 세부 속성, 전용 유물은 지정한 파편·장비·기본형/개화형 같은 형태를
조건으로 사용한다. 효과의 범위는 전투 안이며 상점 가격·보상량·맵 생성에 직접 영향을 주지 않는다.

자체 레벨이나 반복 강화는 없다. 재획득은 독립 사본 추가다.

현재 Core의 구조 유물 RON·typed 편집·유한 효과·공개 조회·저장 재구성 포트는
[스킬 작성 모델의 U09 구현 참조](../skills/skill_authoring_model.ko.md#u09-구조-유물-작성-포트)를 따른다.
대표 시험의 수치는 공식 밸런스 확정값이 아니다.

| 희귀도 | 역할 |
| --- | --- |
| 일반 | 자주 만나며 조합의 기초를 이루는 선택 |
| 희귀 | 특정 운용·조합에서 높은 효과를 내는 선택 |
| 특급 | 런에 큰 영향을 주어 드물게 제공할 선택 |

희귀도는 강화 단계나 효과의 복잡성·역할 분류와 독립적이다. 일반 유물도 마지막까지 사용할
가치가 있어야 한다. 첫 무기 유물의 설계 범위는 단순 수치 강화다. 기존 파편 변형·연결과
장비 효과는 유지하되 모든 무기의 변신·공격 방식을 바꾸는 전용 유물을 필수로 만들지는 않는다.

## 소유와 장착

- 직원마다 공용 슬롯 3개를 가진다. 공격·방어·보조나 장비 부위로 나누지 않는다.
  장비를 해제해도 슬롯을 닫거나 유물을 회수하지 않는다.
- 런 전체의 장착 합계나 보유량에는 추가 상한이 없다. 각 사본은 런 공용 자산이고 직원 사이에
  옮길 수 있으며 직원·장비에 귀속하지 않는다.
- 사본 하나가 슬롯 하나를 차지한다. 같은 사본을 여러 직원·슬롯이 공유하지 않는다.
- 중복 가능 유물은 같은 직원에게 독립 사본 여러 개를 장착할 수 있다. 중복 불가는 같은 종류를
  직원당 하나만 허용한다. 다른 직원에게 별도 사본을 주는 것은 가능하다.
- Safezone의 지도·진입 전 준비와 Maintenance에서 무료로 횟수 제한 없이 바꾼다.
  전투 중에는 변경할 수 없다. 직원 사망 시 장착 유물을 공용 보관함으로 회수한다.

## 조건과 비활성

무기·파편을 바꾸어 요구 태그가 없어지면 유물은 슬롯에 남고 효과만 비활성화한다.
처음부터 조건이 없어도 장착할 수 있고, 조건을 다시 얻으면 자동 활성화한다.
다른 유물이 만든 새 효과의 태그로도 조건을 만족시킬 수 있다.

활성 조건은 현재 무기·파편 등이 제공하는 효과와 조건 없이 제공되는 유물 효과에서 시작해
판정한다. 여기서 조건을 만족해 추가된 효과로 다른 유물의 조건도 충족할 수 있으며, 더 활성화할
효과가 없을 때까지 이어서 판정한다. **서로의 조건만 충족하는 유물끼리는 스스로 활성화하지 않는다.**
예를 들어 화상이 있어야 폭발을 추가하는 유물과 폭발이 있어야 화상을 추가하는 유물은, 시작점에
화상도 폭발도 없으면 둘 다 비활성이다. 실제로 둘 중 하나를 제공하는 효과가 있으면 이를 시작점으로
활성화할 수 있다. 시작점이 사라지면 현재 구성에서 다시 판정하며, 이전에 서로 제공하던 효과만으로
활성을 유지하지 않는다. 이는 전투 중 연쇄 발동의 순환 금지와 별개인 활성 조건 규칙이다.

전용 유물의 지정 파편·장비·형태 조건은 일반 태그 부여로 대체할 수 없다.
비활성 유물에도 중복·비호환 장착 제한은 적용한다.

### 선행 유물

2026-10-20 합의. **선행 유물은 후속 유물의 효과 활성에 필요한 것으로 명시한 특정 유물이다.**
후속 유물과 같은 직원에게 함께 장착되어 있고, 선행 유물 자체도 활성 상태여야 조건을 충족한다.
공용 보관함에 보유하거나 다른 직원이 장착한 것만으로는 충족하지 않는다.

- 획득·장착 순서는 상관없다. 선행 유물이 없어도 후속 유물을 획득하고 장착할 수 있으며,
  선행 조건을 충족할 때까지 후속 효과만 비활성화한다. 획득 후보를 제한하는 규칙으로 사용하지 않는다.
- 선행 유물의 장착 해제·이전 또는 활성 조건 상실 시 후속 효과도 비활성화한다.
  조건을 다시 충족하면 자동 활성화하며, 후속 유물 자체의 태그·전용 대상 등 다른 조건도 함께 검사한다.
- `A → B → C`와 같은 단계적 선행 관계는 허용한다. `A → A`, `A → B → A` 등 직접·간접
  순환 선행 관계는 콘텐츠 오류로 금지한다. 전투 중 효과의 연쇄 발동 제한과 별개의 규칙이다.
- 활성 판정은 위의 실제 효과·무조건 부여 효과를 시작점으로 삼는다. 선행 조건과 효과 조건을
  섞었더라도 후속 효과가 제공하는 조건에만 기대어 선행 유물을 스스로 활성화하거나 유지할 수 없다.
- 유물 설명에 선행 유물과 현재 충족 여부를 표시한다. 조건을 충족하지 못하면 선행 유물의
  미장착·비활성 등 이유를 확인할 수 있어야 한다.
- 각 사본은 기존대로 슬롯 하나를 차지한다. 선행 관계가 슬롯·중복·비호환 제한을 면제하지 않는다.

특정 유물의 기능을 확장하는 후속 유물에 선행 관계를 명시한다. 단순히 잘 어울린다는 이유로
기존 유물에 선행 조건을 추가하지 않는다. 같은 효과를 제공하는 다른 출처로도 충족할 수 있다면
특정 유물을 요구하는 선행 관계 대신 효과 조건으로 작성한다.

이는 설계 합의다. 정식 참조 ID·데이터 표현, 활성 재평가·표시·검증 구현 및 복수 선행 조건의
모두/택일 표현은 후속 과제로 남긴다.

### 유물 관계의 구분

| 관계 | 기준 |
| --- | --- |
| 선행 유물 | 명시한 특정 유물이 같은 직원에게 장착·활성 상태여야 후속 효과 활성 |
| 효과 조건 | 필요한 효과·태그와 세부 속성으로 판정. 허용된 무기·파편·장비·유물 출처로 충족 가능 |
| 상호 보완 | 각자의 규칙을 적용하면서 함께 사용할 때 특정 성능·운용이 성립. 동시 장착 자체를 활성 조건으로 추가하지 않음 |
| 비호환 | 충돌하는 유물은 같은 직원에게 함께 장착 불가 |
| 중복 제한 | 같은 종류의 독립 사본을 같은 직원에게 여러 개 장착할 수 있는지 결정 |

상호 보완을 이유로 별도 보너스를 자동 지급하지 않는다. 특정 유물 조합에 추가 보너스를 주는
**세트 효과는 현재 도입하지 않으며**, 필요해지면 별도 설계한다.
콘텐츠 작성 예시는 [유물 관계 작성 기준](../content/principles/relics.md#유물-관계-작성-기준)을 따른다.

## 효과의 결합

태그는 적용 대상을 고르고 실제 변화는 각 유물의 효과가 정한다. 스택 획득량·최대치·스택당 효과,
관통 횟수·피해 감소 완화, 폭발 반경·피해 등을 강화할 수 있다. 새로 만든 효과에도 태그와 출처를
붙이고 다른 유물이 강화할 수 있다.

유물이 같은 효과의 피해량을 바꿀 때는 고정 증가량을 먼저 합산한 뒤, 동일 종류의 비율 증폭을
합산해 적용한다. 예를 들어 기본 피해 100에 고정 증가 20, 비율 증폭 +20%와 +30%가 있으면
`(100 + 20) × (1 + 0.2 + 0.3) = 180`이다.
예시 수치는 콘텐츠 확정값이 아니며 이 산술을 다른 수치 속성·저항이나 기존 피해 계산 전체에
확대하지 않는다.
공통 피해 증폭 상한과 공통 연쇄 발동 횟수 상한은 두지 않는다. 직원당 3슬롯과 아래 순환 금지를 유지하고,
문제가 되는 개별 효과의 발동 간격·대상 수·투사체 수 등을 조절한다. 다수 적·직원 조합은 플레이로 검증한다.

한 유물의 효과가 다른 유물의 조건을 만족하면 연쇄 발동할 수 있다. **같은 연쇄 경로가 같은
사본의 같은 효과로 돌아오는 순환 발동은 금지**한다. 다음 기본 공격 같은 별도 원인으로 시작한
연쇄는 다시 발동할 수 있으며 유물당 전투 한 번의 제한이 아니다.

갈라진 연쇄는 갈라지기 전의 발동 기록을 함께 이어받고, 이후 각 갈래에서 추가된 기록은 다른
갈래와 공유하지 않는다. **여러 경로의 결과를 받아 하나의 후속 효과를 만드는 합류에서는 실제로
참여한 모든 경로의 발동 기록을 합쳐 이어받는다.** 어느 참여 경로에서든 이미 발동한 같은 사본의
같은 효과는 합류 이후 다시 발동하지 못한다. 아직 거치지 않은 효과는 조건에 따라 발동할 수 있고,
합류로 만들어진 효과 자체의 피해는 정상 적용한다.
같은 적에게 동시에 적중하거나 피해량을 합산해 표시하는 것만으로는 합류로 보지 않는다.
합류하지 않은 다른 경로와 별도 원인으로 시작한 새 연쇄에는 이 기록을 전역으로 적용하지 않는다.

**독립적으로 반복하는 주기 효과는 발생할 때마다 새 연쇄를 시작한다.** 예를 들어 다른 효과의
발동이나 적중 없이 3초마다 발생하는 충격파가 이에 해당한다. 주기 수치는 설명용 예시다.
반면 적중·유물 발동 등으로 생성된 추가 공격·지연 폭발·지속 피해는 원인이 된 연쇄의 발동 기록을
이어받는다. 유물 A가 만든 화상의 각 피해로 같은 A 사본의 같은 효과를 다시 발동할 수 없다.
시간 경과·주기 반복·투사체 도착만으로 기록을 초기화하지 않는다. 새 연쇄인지는 시간을 예약하는
방식이 아니라 효과를 발생시킨 원인으로 구분하며, 구체적인 판정과 기록 전달은 구현에서 검증한다.

함께 성립할 수 없는 효과는 비호환 태그로 같은 직원에게 함께 장착하지 못하게 한다.
장착 순서와 무관하게 검사하며 다른 직원까지 제한하지 않는다. 같은 스킬의 스택 전부 소모와
소모 금지가 예시다. 중복 불가와 비호환은 별개의 제한이다.

정식 태그 목록·활성 조건 재평가의 구현·연쇄 평가 세부는
[NEXT-08](open-decisions.md#유물과-저장)에서 다룬다.
현재 Core의 typed 구독·실제 Join·독립 Periodic·Wedge 작성/관찰 경계는
[U10 작성 포트](../skills/skill_authoring_model.ko.md#u10-원인-연쇄-작성-포트)에 연결한다.
정식 tag ID·개별 콘텐츠 수치·live catalog와 전체 Goal 검증 완료를 대신하는 참조는 아니다.

## 판매와 분쇄

일반 상점에 유물을 판매하는 것은 불가하다. 도박형 보상 노드에서는 [담보 대출](relic-reward-nodes.md#유물을-담보로-한-포인트-대출)을 이용하고, 해당 조우에서 무이자 원금을 상환해 회수하거나 포기한다. 회수할 사본을 일부만 고를 수 있으며 포기한 사본은 제거한다.
Maintenance에서 분쇄하면 장비 가루를 얻으며 장착 중이면 확인 후
자동 해제할 수 있다. 분쇄량은 미정이다. 별도의 유물 강화 경제는 없다.
장비 가루는 무기 강화에 사용한다. 일반전을 주 공급처로, 장비·유물 분쇄를 보조 공급처로 둔다.
[재료 경제](growth-and-rewards.md#재료와-엔케팔린)

## 상태 보존

유물 보유와 장착은 체크포인트에 포함해 저장 시점대로 복원한다. 누적 스택·발동 횟수 등은
해당 전투에서만 유지하고 새 전투 시작 때 초기화한다. **같은 전투의 재배치는 일시 스택만
초기화하며 전투당 N회 사용 기록을 유지**한다.

침식 여부는 개별 유물 사본에 저장한다. 종료 후 이어하기는 미확정 노드의 소비·침식 결과를 입장 전으로
함께 복원하며, 그 이전에 확정한 침식과 같은 프로세스의 재접속 상태는 유지한다.
침식 적용 전 체크포인트로 복구하면 적용에 소비한 아이템·비용과 변형 결과를 함께 되돌린다.
적용 후 체크포인트로 복구하면 그 시점의 침식 상태와 소비를 유지한다. 전투 후퇴도 해당 전투 진입
시점의 침식 상태를 복원하며, 후퇴만으로 전투 전에 적용한 침식을 해제하지 않는다.
이 처리는 [소비와 결과의 동시 복원](results-and-save.md#저장과-복구)을 따르며, 일반적인 원정 내 침식 해제 기능과 구분한다.
구체적인 후퇴·재접속 저장 구현과 기존 세이브 전환은 [NEXT-10](open-decisions.md#유물과-저장)에서 정한다.
이 정책이 현재 저장 형식에 이미 구현됐다는 뜻은 아니다.

## 침식된 유물

침식 촉매제를 기존 유물에 적용하거나 침식 Event에서 보유 유물을 변환해 만든다.
침식된 완제품을 직접 드롭하지 않는다.
효과를 크게 강화하는 대신 유닛을 죽음에 이르게 할 수 있는 패널티를 짝지어 설계한다.

**해당 유물 RON에 침식형이 정의된 유물만 침식할 수 있다.** 유물별로 침식 후 효과와 패널티를
직접 작성하며, 침식형이 없는 유물은 촉매제·Event 모두 변환 대상에서 제외한다.
적용 전에 작성된 침식형의 효과·패널티를 보여 주고, 확정 시에도 대상 사본과 침식형 정의를 검증한다.
적용할 수 없는 대상에는 촉매제 소비나 변형을 발생시키지 않는다.
구체적인 RON 스키마와 변환 구현은 후속 작업이다.

**한 유물 사본은 일반 상태에서 침식 상태로 한 번만 변환할 수 있다.** 촉매제와 Event에 같은 제한을
적용하며, 이미 침식한 사본은 변환 대상으로 선택할 수 없다. 재적용 요청은 추가 소비·효과 중첩·
단계 상승 없이 거절한다. 같은 종류의 다른 사본은 각각 독립적으로 침식할 수 있다.

**상점의 침식 촉매제 구매를 기본 공급처로 두고, 침식 Event를 추가 변환 기회로 제공한다.**

- 상점에서 엔케팔린으로 촉매제를 구매해 보관했다가 전투 밖에서 원하는 보유 유물 사본 하나에 사용한다.
  유물·다른 상품 구매 등과 지출을 비교하게 하되, 침식 자체의 패널티에 높은 구매 비용까지 겹쳐
  선택하기 어려워지지 않도록 조절한다. 위험 전투의 희소 보상을 필수 획득 경로로 삼지 않는다.
- 침식 Event에서는 보유 유물 사본 하나를 골라 그 자리에서 변환한다. 촉매제나 추가 재화·재료를
  소비하지 않으며, 원하지 않으면 거절할 수 있다. 해당 경로를 찾아가는 탐사와 노드 최초 입장의 억제력,
  침식 자체의 패널티를 대가로 삼는다.
- 두 방식 모두 대상 사본의 변환 효과와 패널티를 미리 보여 준다. 촉매제는 사용 시점을 보류할 수 있고,
  Event는 방문 당시 보유한 유물로 결정하는 차이를 둔다.

침식 촉매제는 [환상체 부활용 촉매제](growth-and-rewards.md#알과-촉매제)와 용도를 구분한다.
침식 촉매제는 원정 전용이며 성공 귀환·실패 모두 다음 원정으로 넘기지 않고 공용 창고에 보관할 수 없다.
중단 후 이어하기·체크포인트 복구에서는 해당 시점의 보유량을 유지·복원한다. 침식 촉매제의 가격·재고·
판매 상점과 공급 빈도, Event 배치 빈도는 실제 플레이로 조절하며 매 방 공급을 보장하지 않는다.

**한번 침식한 유물 사본은 원정 중 원상복구할 수 없다.** 침식 상태를 자유롭게 켜고 끄거나
정비로 정화하는 기능은 두지 않는다. 적용 전에 변형 효과·패널티·소비 비용과 원상복구 불가를 보여 주고
대상 사본을 확인하여 적용한다. 적용을 확정하기 전 취소는 소비나 변형을 만들지 않는다.

침식 유물도 일반 유물과 같은 전투 밖 장착·해제·교체·직원 간 이전 규칙을 따른다.
전투 중에는 교체할 수 없고, 장착 해제·직원 간 이전·직원 사망 후 공용 보관함 회수로 침식이 사라지지 않는다.
장착 해제는 변형을 취소하거나 사용한 침식 아이템을 돌려주는 행동이 아니다.
체크포인트 복구는 위 [상태 보존](#상태-보존)의 소비·결과 동시 복원 원칙을 따른다.

자기 HP 희생·침식체의 우선 공격 목표·받는 피해 증가 등이 후보이며 모든 유물에 적용하는
공통 패널티는 아니다. 침식은 희귀도와 구별되는 변형 상태다. 희귀도 처리와 촉매제의 구체적인 판매처·가격·재고·사용 화면,
Event 배치·중복·비호환과
각 패널티의 HP·보호막·사망·경로·시작/종료 규칙은 [NEXT-09](open-decisions.md#유물과-저장)에서 정한다.

## 에고 침식과의 경계

기존 파편 침식형의 명칭은 **에고 침식**으로 한다. 유물 사본을 변환하는 유물 침식과 구분한다.
에고 침식의 즉시 처치 대상은 현재 전장의 **일반 침식체**다. 엘리트·일반 보스·최종 보스에는
즉시 처치 대신 **대상 최대 HP의 25% 피해**를 초기 검증값으로 적용한다. 방어력·일반 피해 감소는
무시하지만 일반 보호막은 먼저 소모한다. 무적·대상 지정 불가와 보스의 페이즈별 HP 하한·필수 전환은 지킨다.
처치 가능한 상태라면 해당 피해로 처치할 수 있으나 필수 페이즈를 건너뛰지 않는다.
상세 발동 조건과 직원의 대가는 [에고 침식 설계 메모](../tmp/ego_corrosion_system_design_notes_2026-08-19.ko.md)가
소유하며 이번 통합은 아래 경계만 다룬다.

- 범용·전용 유물의 증폭·추가 효과·연쇄를 에고 침식에 적용하지 않는다.
- 에고 침식 처치로 유물·장비·파편의 처치 시 효과나 적의 사망 시 효과를 발생시키지 않는다.
- 처치한 적은 웨이브 정리·다음 웨이브·승리 검사에서 정상 처리한다. 남은 전투 진행을 모두
  무시하는 무조건 즉시 승리는 아니며 환상체 연출을 일반 소환·스킬로 해석하지 않는다.
- 이 경계가 침식된 유물 자체를 비활성화하는 뜻은 아니다.

직원의 철수·트라우마 100은 유지하며, 이후 새 노드 최초 입장의 규정 억제력 소모가 누적 4에 도달하기 전까지
회복하지 못하면 사망하는 [Breakdown 유예](results-and-save.md#breakdown의-유예)를 초기 기준으로 적용한다.
무억제 상태에서도 유예는 진행한다. 신체 부상 추가는 채택하지 않는다.
25%의 체감은 플레이 검증 과제다. 2026-10-22 일반 판정 위임에 따라 다음 실행 세칙을 적용한다.
최대 HP 비율은 규칙 설정값이며 한 번 올림해 정수 피해로 만든다. 기존 무적/대상 가능 여부를 먼저
확인한 뒤 일반 보호막, 생존 하한, 현재 보스 페이즈의 다음 HP 전환 하한 순으로 처리한다.
필수 전환을 대기 중인 페이즈의 하한은 전환이 확정될 때까지 유지한다. 패링의 새 반격·반사 창은
발동하지 않는다. 일반 위협 등급의 침식 직원과 적 일반 소환물은 즉시 처치하며,
엘리트/보스 위협 등급과 환상체 출처는 비율 피해가 우선한다. 시설 객체 등 이 분류에 속하지 않는
중립적 객체를 일괄 처치 대상으로 올리지 않는다. 즉시 처치와 비율 피해의 치사 모두 침식 사망으로
기록해 선택적 처치·사망 연쇄를 억제한다.

## 획득과 표시

유물은 **유물 보상 노드를 주 공급처**로 두고, 일부 위험 전투에서 추가 확보하며 상점에서 조합을 보완한다.
유물 보상 노드는 단순 선택·자원 투입·도박·유물 투입 가챠·스트레스 전투의 다섯 종류로 구성한다.
각 활동과 딜러의 미니게임·포인트·담보·상점 정책은 [유물 보상 노드](relic-reward-nodes.md)가 소유한다.
해당 방까지의 탐사와 노드 최초 입장에 억제력을 투자하고, 노드별 활동과 조건에 따라 보상을 얻는다. 유물을 찾아가는 경로가 일반전의 장비 가루·환상체의 파편/장비/개화 경로와
서로 다른 성장 필요를 해결하도록 배치한다.

| 획득처 | 공급 역할 |
| --- | --- |
| 유물 보상 노드 | 주 공급처. 다섯 유형의 활동 규칙에 따른 선택·희귀도 상승·포인트 구매·무작위 획득·라운드 성과 보상. 여러 일반 유물 묶음도 허용 |
| 유물 보상이 표시된 일부 엘리트·고위험 일반전 | 위험을 감수하고 더 좋은 유물 보상에 도전. 승리하면 표시한 보상을 확정 제공 |
| 상점 | 현재 조합에 부족한 효과를 골라 구매. 다른 상품·채용·촉매제와 엔케팔린 사용을 비교 |
| Event | 조건·대가를 통해 특별한 유물을 얻는 보조 기회. 안정적인 기본 공급량으로 계산하지 않음 |
| 일반 보스·부활 전투 | 기존 파편·알·장비·개화 보상 중심. 유물은 개별 조우 보상에 명시한 경우에만 추가 |
| 최종 보스 | 명시된 유물 보상이 있다면 계속 탐사를 선택한 뒤 해당 원정에서 사용 가능. 후반 선택 보상으로 평가하며 초중반 기본 공급량으로 계산하지 않음 |

일반전 전체에 무작위 유물 드롭을 추가하거나 모든 보스에 유물을 자동 지급하지 않는다.
모든 유물 보상 노드를 3개 중 1개 선택으로 통일하지 않는다. 단순한 3택1도 일부 유형으로 유지한다.
노드의 클리어 성과·충족 조건에 따라 보상 품질·수량·후보 수를 다르게 작성할 수 있으며,
공통 성적 등급표는 만들지 않고 노드별 조건을 명시한다. 도박과 유물 투입 가챠는 각 게임·추첨 규칙에 따른
무작위 결과를 허용하며, 스트레스 전투의 실제 클리어 성과를 단순 성공 확률로 대체하지 않는다.
상점·Event·개별 조우도 각 획득처에 작성한 방식을 따른다.
침식된 완제품은 직접 드롭하지 않는다. 담보를 회수할 때는 맡겼던 사본과 침식 상태를 그대로 반환한다.
침식은 상점에서 구매한 촉매제를 사용하거나 침식 Event에서
보유 유물을 변환하는 방식으로 제공한다. 자세한 정책은 [침식된 유물](#침식된-유물)을 따른다.

### 초반과 경로별 배치

첫 주요 갈림길 전에 접근 가능한 단순 선택형 유물 보상 노드를 두어 **초반 유물 선택 기회**를 보장한다.
이후 활동 유형은 지도 생성 때 무작위로 배정·고정하고, 노드 정보를 확인하면 진입 전에 유형·이용 조건을 공개한다. 재방문으로 유형을 재추첨하지 않는다.
기본 무기·훈련용 파편에도 활용할 수 있는 범용 후보를 제공한다. 강적 격파를 첫 유물 획득의
필수 선행 조건으로 두지 않는다. 원정 시작 인벤토리에 유물을 자동 지급하는 규칙은 아니다.

그 이후에는 주요 성장 경로에 유물 확보 기회가 이어지도록 배정한다. 매 방 유물 노드나 고정
수량을 보장하지 않으며, 빠른 하강을 선택하면 일부 기회를 포기할 수 있다. 최대 깊이와 실제 방문
방 수가 다르므로 횡단·우회·일방향 연결까지 포함해 도달 가능한 공급 기회를 검토한다.
노드 해결 개수만 늘려 공급량을 맞추지 않고, 노드별 획득량도 함께 조절한다.

### 공급량과 후보 구성

직원당 3슬롯에 독립 사본을 장착하므로 부대 전체에 적용되는 유물처럼 공급량을 잡지 않는다.
일반 유물은 비교적 충분히 공급하며, 일부 보상 노드의 일반 유물 묶음도 활용한다.
성장 목표는 **주력 직원에게 조합이 생기고 다른 출전 직원에게도 기본 보완 효과가 생기는 것**이다.
모든 직원의 슬롯을 채우거나 편성 인원에 비례해 보상을 자동 증감하는 규칙을 확정하지 않는다.

후보는 범용 유물을 바탕으로 방의 성격에 맞는 효과를 섞는다. 현재 파편에 꼭 맞는 후보만 반복
제공하거나 활용할 수 없는 전용 유물만 제시하는 구성을 피한다. 전용 유물은 관련 조우·특수 상점처럼
찾아갈 이유가 있는 획득처에 더 많이 배치한다. 범용·전용 여부를 희귀도나 효과의 복잡성과 동일시하지 않는다.

다음 항목은 실제 플레이로 조절한다.

- 첫 유물을 사용하는 시점과 중반에 조합을 활용하는 직원의 범위.
- 유물 노드·위험 전투·상점의 공급량, 후보 수·선택 수·묶음 수량·희귀도 분포와 가격.
- 유물 보상 노드가 일반전·부활 전투보다 항상 우선되지 않는지, 추가 탐사의 억제력 비용에 맞는 가치가 있는지.

후보가 예정 수보다 적으면 실제 지급 가능한 후보만 제시한다. 0개이면 보상 없음 안내 후 선택 절차를 생략한다.
부족분을 채우기 위한 임의 대체 보상이나 재추첨은 하지 않는다. 기존 authored 지급 조건을 유지하고 중복 보유·
희귀도 제한을 새로 추가하지 않는다. 확정한 후보는 저장·재접속으로 다시 뽑지 않는다.
근거: [CF-D02/03](../roadmaps/core_first/execution/DECISIONS_20261004.ko.md).

정확한 획득처별 목록·빈도·수량·후보 호환 판정·분쇄량은
[NEXT-06](open-decisions.md#유물과-저장)의 남은 범위다. 방별 두 개 같은 이전 시험값을 확정 수치로 사용하지 않는다.

### 효과 표시

활성 효과를 포함한 편성 전투력을 적 난이도 조정에 사용하지 않는다. 적 난이도는 깊이·지역·조우별
작성값을 따른다. 유물 효과의 실제 평가·가중치와 위협 안내는 NEXT-08에서 정한다.
무기·파편 설명에서 추가·강화된 효과, 적용 조건과 원인이 된 유물을 확인할 수 있어야 한다.
UI 배치·tooltip·전달 형식은 후속 설계한다.

## 2026-10-22 그래프 작성의 공통 세부 정책

현재 작업의 일반 판정 위임 범위에서 다음을 공통 작성 계약으로 고정한다. 아래는 작성과 후속 실행의
기준이며, Core 전투 검증을 완료했다는 뜻은 아니다. 미정 증가율·범위 마스크·버프 종류를 새 수치로
확정하지 않는다. 각 파편 연결표에서 채택한 지점에만 장착 조건과 변경 정의를 연결한다.

- 장착 조건은 동일 직원의 실제 장비/유물 정의 ID·부위·비침식/침식 변형을 검사한다. 선행 조건은
  모두 활성이어야 하며 순환은 거절한다. 비침식 변경을 침식 사본에 자동 상속하지 않는다.
- 같은 종류의 시간·피해·회복 증가율은 합산하여 한 번 적용한다. 시간은 최종 밀리초로 올림한다.
  정수 획득량의 배율은 곱한 뒤 내림한다. 원본 작성값, 이전 재고, 소비·이전·이월 결과를 덮어쓰지 않는다.
- 깨진 균형은 연결한 기절/빙결의 실제 적용 성공 뒤 생존 대상에게 약화를 부여한다. 사냥의 낙인은
  연결한 소환 효과의 양수 HP 피해 뒤 생존 대상에게 부여한다. 보호막만 소모한 피해·피해 0·면역에
  따른 제어 실패는 발동하지 않는다. 발동 타격에 소급하지 않으며 같은 사본·대상은 갱신하고 다른
  사본의 약화 기여는 합산한다. 두 약화는 제어·소환물·소유자 종료와 별개로 5초 수명을 따른다.
- 남은 온기는 실제 HP 회복이 양수인 아군(유효한 자기 회복 포함)에 적용한다. 회복 0·초과분만
  발생한 결과는 제외한다. 전달 회복은 실제 수신자에게 적용하며 같은 사본·대상은 갱신한다.
  버프 종류·계산 방식·수치·수명은 여전히 미정 입력이며 미정 상태로 컴파일할 수 없다.
- 응징의 표식/도전자의 갑주는 피해 직전 현재 자기 도발 관계를 검사한다. 전자는 직접 기본 공격과
  기본 공격 교체에만, 후자는 그 적의 직접 공격·스킬·지속 피해에만 적용한다. 반사·환경·침식은 제외한다.
- 주 대상 공격을 타일 한 칸 피해로 바꾸는 넓어진 지평은 피해만 범위화하고 후속 기절·상처는 원래
  주 대상에 적용한다. 이미 범위인 공격은 별도의 효과 마스크 변경을 사용한다. 다른 형상의 확대는
  미정 마스크를 명시적으로 작성해야 하며 감지·선택 거리까지 자동 확대하지 않는다.
- 다음.은 사망 위치에서 가장 가까운 유효 적을 선택하며 동률은 안정 ID순이다. 원래 사용·공격 순서·
  비용·남은 타이밍을 보존하고, 시전자 사거리·이전 대상의 상처/연타 기록을 새 대상에게 이전하지 않는다.
- 래티씨아의 폭발 증폭은 작은/큰/특별한 친구의 최종 피해에 각각 한 번 적용한다. 큰 친구의 기초
  계산과 특별한 친구의 추가 계산에서 중복 증폭하지 않는다. 특별한 친구의 최종 확대 마스크는
  기본 두 배 범위 계산 뒤 적용하며, 원본 감지/대기/도약 시간은 보존한다.

전용 장비 사건·전용 유물 전환·침식 패널티와 아직 연결하지 않은 항목은 각 원문의 채택/보류 상태를
따른다. 이 공통 정책만으로 새 호환 조합이나 보류된 형태를 추가하지 않는다.
