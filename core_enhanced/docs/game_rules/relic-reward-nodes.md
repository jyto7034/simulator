# 유물 보상 노드

[게임 룰북](../game_rulebook.md) · [유물](relics.md) · [시설 지도](run-and-map.md#노드-종류-배정) · [남은 결정](open-decisions.md#유물과-저장)

정책 갱신: 2026-10-07. 유물 보상 노드의 활동 종류, 도박형의 미니게임·포인트·담보·딜러 상점과 스트레스 전투의 연속 방어 규칙을 정한다.
보상 노드는 유물의 주 공급처이며, 초반 선택 기회·경로별 배치·공급 원칙은 [유물 공급](relics.md#획득과-표시)을 따른다.
아래 정책은 구현 완료를 뜻하지 않는다. 활동 구현은 [U16](../roadmaps/core_first/ROADMAP.ko.md#u16--상점유료-채용event소비품유물-보상-활동), 지도 배치는 U13, 비전투 활동 화면은 U26-B, 스트레스 전투 화면은 U26-A가 담당한다.

## 보상 노드의 다섯 종류

| 종류 | 활동과 보상 |
| --- | --- |
| 단순 선택 | 초기 정책은 유물 후보 3개 중 1개 선택이다. 후보 부족·0개는 공통 보상 규칙을 따른다. |
| 자원 투입 | 장비 가루를 투입해 일반 → 희귀 → 특급 단계로 보상을 올린다. 최종 도달 단계에서 한 번 수령하고 노드를 소비한다. 투입량·임계치는 미정이다. |
| 도박 | 플레이어가 미니게임을 선택하고 성과에 따라 포인트를 얻거나 잃는다. 종료 시 남은 포인트로 딜러가 공개한 유물을 구매한다. |
| 유물 투입 가챠 | 기존 유물 2개를 투입하고 무작위 유물 1개를 얻는다. 투입 등급 조합별 초기 확률표를 적용한다. |
| 스트레스 전투 | 현재 편대로 보호 대상을 지키는 최대 5라운드의 연속 방어전. 라운드마다 더 강한 적과 추가 보상에 도전하거나 철수한다. 철수·최종 완료 시 누적 보상을 받고, 패배하면 미수령 보상을 잃는다. |

이 다섯 종류를 현재 구성으로 삼는다. 모든 노드를 공통 3택1이나 동일 성적표로 통일하지 않는다.
도박과 유물 투입 가챠는 각각의 규칙에 따라 무작위 결과를 허용한다. 스트레스 전투의 성과를 단순 성공 확률로 대체하지 않는다.
아래 딜러·포인트·대출 규칙은 도박형에 적용하며, 나머지 네 유형에 자동 적용하지 않는다.
비전투 활동은 선택·투입 전에 이용하지 않고 떠날 수 있으나 노드를 소비하며 활동 비용·보상은 발생하지 않는다.
노드 최초 입장의 공통 억제력 비용은 별개다. 도박형의 조우 기본 포인트는 공통 활동 비용이 아니며, 미이용 퇴장 때 남은 포인트도 만남 종료 규칙대로 소멸한다.

## 유료 활동의 보상 후보 사전 검증

유물 합성·장비 가루 투입은 소비를 확정하기 전에 결과를 지급할 수 있는지 검사한다.
유효한 보상을 만들 수 없으면 이유를 안내하고 해당 투입을 막는다. 유물·가루를 소비하지 않고 현재 선택·투입 전 상태를 유지한다.
가챠는 선택한 두 종류를 제외한 뒤, 확률이0보다 큰 각 결과 등급에 지급 가능한 후보가 있어야 한다.
후보가 없는 등급의 확률을 다른 등급에 나누거나 임의 대체 보상·재추첨으로 처리하지 않는다.
자원형은 다음 단계의 지급 가능성을 확인한 뒤 가루를 차감한다. 상위 단계가 불가능하면 현재 단계의 후보·이미 확보한 권리를 유지한다.
이는 비용을 내기 전의 검증이며, 이미 확정된 무상 선택 보상의 후보가0개일 때 안내 후 선택을 생략하는 공통 정책과 구분한다.

## 유형 배정과 사전 공개

보상 노드 유형은 지도 생성 때 다섯 종류 중 하나로 무작위 배정하고 고정한다. 입장할 때 다섯 활동 중 직접 고르지 않는다.
노드 정보를 확인할 수 있게 되면 진입 전에 유형과 이용 조건을 공개한다. 자원형의 가루 요구량, 가챠의 투입 조건,
스트레스 전투의 방어 활동과 위험 등 경로 선택에 필요한 정보를 안내한다. 지도 전체의 정보 공개 범위는 공통 탐사 규칙을 따른다.
재방문·재접속으로 유형을 다시 추첨하지 않으며, 같은 지도 상태를 복원하면 같은 배정을 유지한다.

첫 주요 갈림길 전 보장하는 초반 유물 기회는 **단순 선택형**으로 예약한다. 이후 노드의 유형별 가중치·깊이별 분포는 플레이로 조절한다.
유형을 무작위 배정한다는 이유로 모든 유형을 같은 확률로 배정하거나 매 방 하나씩 보장하지 않는다.

## 자원 투입형의 초기 정책

장비 가루를 투입해 게이지를 채운다. 같은 가루를 무기 강화에 사용할지 유물 획득에 투자할지 선택하게 한다.
각 임계치에 도달하면 보상 등급을 일반 → 희귀 → 특급으로 올린다. 다음 단계까지 필요한 가루와 현재 받을 수 있는 보상을 보여 준다.
플레이어는 현재 단계의 보상을 받거나 추가 투입해 다음 단계로 올릴 수 있다.

보상은 **최종 도달 단계에서 한 번만** 수령한다. 앞 단계의 보상을 누적 지급하지 않으며, 보상을 받으면 노드를 소비한다.
투입을 확정한 가루는 활동 내 취소로 반환하지 않는다. 게임 종료·저장 복구는 아래 공통 소비·결과 동시 복원 정책을 따른다.
등급은 투입량으로 보장하고 유물 종류에는 무작위성을 둔다. 충분히 투자한 등급보다 낮은 결과를 추첨하지 않는다.
이미 공개한 보상은 같은 단계의 화면 재진입·재접속으로 다시 추첨하지 않는다.

투입은 다음 등급에 도달하는 데 필요한 가루를 한 번에 지불한다. 최초 일반 단계도 같은 방식이며,
필요량이 부족하면 투입할 수 없고 가루를 차감하지 않는다. 임계치에 못 미치는 부분 투입은 허용하지 않는다.
현재 등급의 보상 후보를 공개하고 등급을 올리면 이전 후보를 대체한다. 상위 단계로 올린 뒤 이전 단계 후보를 선택하지 않는다.
각 단계에서 서로 다른 유물 최대3개를 공개하고 그중1개를 선택해 받는다. 후보가1~2개이면 실제 후보만 제시하고,0개이면 앞의 사전 검증에 따라 투입을 막는다.
현재 단계의 후보·효과는 모두 공개한다. 다음 단계는 추가 가루 요구량과 등급만 안내하고, 실제 후보는 추가 투입 확정 후 공개한다.
상위 등급은 보장하지만 현재 편대와의 조합 적합성까지 보장하지 않는다. 구체적인 가루 요구량은 무기 강화 비용과 함께 플레이로 조절한다.

## 유물 투입 가챠의 초기 확률

서로 다른 사본 2개를 소비해 결과 유물 1개를 얻는다. 입력 두 개의 등급 조합으로 결과 등급의 확률을 정한다.
아래 수치는 2026-10-06 사용자가 초안으로 채택한 **초기 밸런스**이며 플레이 검증 뒤 조정할 수 있다.

| 투입 유물 | 일반 획득 | 희귀 획득 | 특급 획득 |
| --- | ---: | ---: | ---: |
| 일반 + 일반 | 80% | 19% | 1% |
| 일반 + 희귀 | 40% | 55% | 5% |
| 일반 + 특급 | 0% | 70% | 30% |
| 희귀 + 희귀 | 0% | 80% | 20% |
| 희귀 + 특급 | 0% | 40% | 60% |
| 특급 + 특급 | 0% | 0% | 100% |

입력 순서로 확률이 바뀌지 않는다. 투입할 두 사본을 선택하면 적용 확률을 보여 주고, 확정 시 두 개 소비와 결과 하나 지급을 함께 처리한다.
같은 시도의 결과를 종료·재접속으로 다시 추첨하거나 중복 지급하지 않는다. 특급 두 개는 결과 등급을 유지하면서 종류를 추첨한다.
노드당 합성은 1회이며, 완료하면 노드를 소비한다. 결과를 같은 노드에 다시 투입해 연속 합성하지 못한다.
미장착 유물만 투입할 수 있다. 침식 유물도 투입할 수 있지만 결과는 침식되지 않은 일반 상태로 생성한다.
투입한 두 유물의 종류는 결과에서 제외한다. 그 밖에 이미 보유한 종류는 결과로 나올 수 있다.
등급 안의 후보 구성·가중치는 상세화한다. 입력 종류 제외 후 가능한 결과를 지급할 수 없는 경우에는 [유료 활동의 사전 검증](#유료-활동의-보상-후보-사전-검증)에 따라 투입을 막는다.
침식된 완제품을 새 보상으로 생성하지 않는 기존 규칙은 유지한다.

## 딜러와의 만남

시설 탐사 중 알 수 없는 개체가 다가와 게임을 제안한다. 개체는 딜러, 탐사자는 플레이어가 된다.
원정에서 처음 만난 딜러는 비주얼노벨 대사로 포인트의 획득·손실과 상품 구매를 설명한다.
예시 대사는 “간단한 게임입니다. 이기면 포인트를 얻고, 지면 잃죠. 모은 포인트는 유용하게 쓰실 수 있습니다.”다.
같은 원정의 이후 조우에서는 도입을 짧게 처리하되 참여·거절 선택은 유지한다. 첫 만남 설명 여부는 원정별 상태이며 다음 원정에서는 새로 시작한다.
딜러는 게임 규칙·기본 손익·갬빗 배율·보상 유물·가격을 알려 주고, 고지한 규칙과 보상 지급을 지킨다.
정체·목적·성격·실제 대사와 출현 빈도는 별도 콘텐츠로 정한다.

### 화면과 진행 순서

| 단계 | 선택과 다음 진행 |
| --- | --- |
| 게임 제안 | 수락하면 세 게임 선택으로 이동한다. 거절하면 보상 없이 조우를 종료하고 노드를 소비한다. |
| 게임 선택 | 블랙잭·주사위 포커·플립 7 중 하나를 고른다. 첫 게임을 고른 뒤에는 갬빗을 결정하고, 이후에는 선택한 게임을 시작한다. |
| 첫 갬빗 선택 | “좀 더 위험하게 하시겠습니까?”라는 대사와 배율·손익 안내를 보고 예·아니오를 선택한다. 해당 조우에서 한 번만 결정한다. |
| 미니게임 | 선택한 게임을 진행하고 판이 끝나면 이번 판의 포인트 증감과 현재 잔액을 표시한다. |
| 판 사이 | 계속하기·담보 맡기기·정산하기를 보여 준다. 계속하기는 잔액이 양수일 때 가능하며 게임 선택으로 이동한다. |
| 담보 맡기기 | 인벤토리에서 미장착 유물을 복수 선택하고 지급 후 잔액을 확인한다. 확정하면 담보 처리·포인트 지급 뒤 게임 선택으로 자동 이동한다. 취소하면 판 사이 화면으로 돌아간다. |
| 담보 정산 | 회수할 사본들을 선택하고 원금을 상환한다. 포기할 사본을 함께 확인하여 정산한다. 담보가 없으면 바로 상점으로 이동한다. |
| 보상 상점 | 남은 포인트로 공개된 상품을 구매한다. 잔액이 부족해도 목록을 보고 나갈 수 있다. |
| 나가기 | 우측 하단의 나가기 버튼으로 조우 결과와 노드 소비를 확정하고 탐사로 돌아간다. |

플레이어는 판마다 게임을 바꿀 수 있다. **판수 제한 없이 포인트가 양수인 동안 계속 플레이**할 수 있다.
잔액이0이거나 음수이면 계속하기를 비활성화하고 담보 맡기기 또는 정산하기를 선택하게 한다. 담보는 양수 잔액에서도 이용할 수 있다.
판 시작 전 선택 취소는 포인트를 차감하지 않는다. 이미 결정한 갬빗 여부는 유지한다.
시작한 판을 수동 포기하면 해당 판을 패배로 정산하고 해당 조우 갬빗이 적용된 손실을 한 번 반영한다.
수동 판 포기는 게임 종료 후 이어하기의 공통 복구 정책과 구분한다.

정산하기를 선택하면 **담보 정산 → 보상 상점 → 나가기** 순서로 진행한다. 손익에 관계없이 같은 정산 흐름을 사용한다.
정산에 들어간 뒤에는 게임 선택이나 새 담보 대출로 돌아가지 않는다. 구매로 잔액이0이 되어도 그대로 쇼핑을 마치고 나갈 수 있다.

## 포인트와 갬빗 배율

제안자와 조우하면 기본 포인트를 지급한다. 같은 만남의 재접속으로 다시 지급하지 않는다.
포인트가 **0점 이하**이면 다음 판을 시작할 수 없다. 담보로 잔액을 양수로 만들면 계속할 수 있고, 정산을 선택할 수도 있다.
탐사 재화로 포인트를 추가 구매하는 기능은 우선 두지 않으며, 유물 담보 대출을 허용한다.
포인트는 이번 만남에서만 사용한다. 정산 후 남은 포인트는 소멸하고 다음 만남이나 원정으로 이월하지 않는다. 소멸은 종료 전에 안내한다.

첫 미니게임을 선택한 뒤 실제 판을 시작하기 전에 갬빗 활성화 여부를 선택한다. 선택 전에 손익과 적용 배율을 안내하며, 예·아니오 어느 선택이든 세 미니게임을 포함한 해당 조우 전체에 고정한다.
갬빗을 끄면 게임별 기본 포인트 계산을 적용하고, 켜면 **획득과 손실에 같은 2~3배 배율**을 적용한다.
기본 손익은 각 미니게임의 승패·성과·판돈 규칙으로 정한다.

`최종 포인트 증감 = 게임별 기본 포인트 증감 × 갬빗 배율`

비활성 시 배율은1이다. 예를 들어 기본 획득+10/손실-10인 판에3배를 적용하면+30/-30이다. 이 숫자는 계산 예시다.
잔액 전체를 곱하는 것이 아니며, 조우 기본 지급·대출·상환액·상품 가격에 이 배율을 적용하지 않는다.
첫 게임 시작 전에 확정한 갬빗 활성화 여부는 판 사이·게임 변경·같은 프로세스의 재접속으로 바꾸거나 철회할 수 없다. 프로세스 종료 후 복구는 아래 조우 전체의 복원 기준을 따른다.
갬빗 배율은 조우마다2배 또는3배로 미리 배정하고 입장 시 공개한다. 플레이어는 공개된 배율의 활성화 여부만 선택한다.
배율과 활성화 여부는 **해당 조우에만** 적용하며 원정 전체에 적용하지 않는다. 다음 딜러 조우에서는 그 조우에 배정된 배율을 안내하고 활성화 여부를 새로 선택한다.
같은 조우의 판 사이·게임 변경·재접속으로 배율을 재추첨하거나 변경하지 않는다.
플립7의 기본 포인트 산정에는 자기 점수 환산분과 해당 판1위 보너스를 포함하고, 갬빗은 그 판의 포인트 증감에 적용한다.

보유 포인트와 이번 판의 미확정 손익을 구분해 보여 준다. 판돈을 사용하는 게임의 일부/전부 걸기와 배율 적용 후 최대 손실을 함께 표시해야 한다.
포인트 잔액은 음수가 될 수 있다. 손실이 보유 포인트를 넘는다는 이유만으로 갬빗 참여를 거절하거나 손실을0까지로 잘라내지 않는다.
음수 결과도 실제 포인트 증감으로 기록하고 다음 판 시작을 막는다. 음수 포인트는 퇴장 시 소멸하며 다음 조우·원정으로 넘기거나 다른 자산에서 추심하지 않는다.
담보 대출은 별도로 정산한다. 상환할 포인트가 부족한 담보 유물은 제거하고 해당 빚을 소멸시킨다. 음수 포인트 소멸이 담보의 무상 반환을 뜻하지 않는다. 게임별 판돈 한도와 조우별2배/3배 배정 분포는 별도로 정한다.
포인트 잔액·담보·정산 진행·퇴장 시 포인트 소멸을 같은 복원 기준으로 처리한다. 같은 프로세스의 재접속으로 음수만 지우고 게임을 재개하거나 담보를 돌려주지 않는다.

보상 구매에는 최고 도달 기록이 아니라 상환·담보 포기를 처리한 뒤 실제 남은 포인트를 사용한다.

세 미니게임은 직접 구현하며, 필요한 구성 요소는 사용 조건을 확인한 외부 라이브러리나 기존 코드를 활용한다.
게임별 통상적인 세부 규칙·예외 처리·NPC 판단은 합의된 조우 정책 안에서 상세화하고, 포인트·판돈·가격 등의 수치는 플레이로 검증할 초기값으로 정한다.
아직 특정 판본의 모든 부가 규칙을 확정한 것은 아니다. 갬빗 손익 배율·만남별 포인트·담보·상품 구매는 이 게임의 기존 정책을 유지한다.
각 게임의 승리 또는 확보한 성과를 도박형 노드의 포인트로 환산하며, 원작의 베팅·누적 목표·다인 경쟁이 현재 조우 구조와 충돌하는 부분은 명시적으로 정한다.
카드 뒤집기에서는 딜러가 상대 패로 겨루는 대신 진행자를 맡는다. 게임 결과를 기본 포인트 증감으로 환산한 뒤 갬빗 배율을 적용한다.

규칙 출처는 블랙잭의 [Bicycle 규칙](https://bicyclecards.com/how-to-play/blackjack), 플립 7의 기본판 규칙과 [발행사 공식 FAQ](https://theop.games/pages/flip-7-faqs)를 참조한다.
주사위 포커는 5개 주사위로 참가자들이 조합을 비교하는 방식에 맞는 규칙 판본을 지정한다.
플립 7 원작의 액션 카드는 다른 활성 참가자에게도 지정할 수 있고, 혼자 남으면 자신에게 적용한다. 원작의 누적200점 경쟁도 존재한다.
현재 조우에서는 아래의 가상 참가자 경쟁과 원작 한 라운드를 미니게임 한 판으로 처리하는 정책을 채택한다. 원작의 누적200점 도달을 만남 종료의 필수 조건으로 삼지 않는다. 원작 규칙의 상세 전사·구현 검증은 별도 작업이다.

## 가상 참가자와 판 단위 경쟁

초기 구성은 **플레이어1명 + 가상 참가자2명**이다. 플립7에서 딜러는 경쟁자가 아닌 진행자를 맡는다.
가상 참가자 하나는 적당한 점수를 확보하면 일찍 멈추는 보수형, 다른 하나는 높은 점수와 역전을 노리는 공격형으로 둔다.
공개 카드·점수·계속 여부를 보여 주며, NPC 행동은 빠르게 처리한다. NPC는 공개 정보로 판단하고 미공개 카드·미래 난수 결과를 이용하지 않는다.

플립7은 **원작의 한 라운드를 미니게임 한 판**으로 처리한다. 매 라운드 세 참가자가 함께 경쟁하고 원작의 액션 대상 규칙을 적용한다.
플레이어의 포인트 보상은 자신이 확보한 점수에 따른 환산분에 해당 판1위 보너스를 더한다.
공동1위가 발생하면 추가 승부 없이1위 보너스를 공동1위 인원수로 균등 분배하고, 정수 포인트의 나머지는 버린다. 분배 후 자기 몫과 점수 환산분에 갬빗 배율을 적용한다.
버스트하면 이번 판의 미확정 점수를 잃고, 시작 전에 공개한 기본 손실 포인트를 차감한다. 갬빗은 이 차감액에도 적용한다.
버스트한 참가자를0점 공동1위로 취급해 보너스를 주지 않는다. 정확한 점수 환산량·기본 손실·1위 보너스 액수는 후속 밸런스로 정한다.
갬빗을 활성화하면 해당 판의 획득·손실 포인트를 같은 배율로 늘린다. 기본 상태에 원금 보호 규칙을 두지 않는다.
판 사이에는 다른 미니게임으로 바꾸거나 담보를 맡기거나 종료·정산할 수 있다.

주사위 포커에도 같은 가상 참가자들을 등장시켜 조합을 겨룬다. 블랙잭에서는 같은 테이블에 앉되 각자 딜러와 승부한다.
플립7의 점수 환산·1위 보너스를 다른 두 게임에 자동 적용하지 않으며, 각 게임의 정상 판정과 기본 정산과 갬빗 배율을 따른다.

## 딜러 보상 상점

게임 시작 전에 구매 가능한 유물의 효과·상태·가격·재고를 공개한다. 보상 목록은 만남마다 달라질 수 있으나 해당 만남에서는 고정한다.
미니게임 결과를 본 뒤 보상 후보를 다시 뽑거나 바꾸지 않는다.

저렴한 일반 유물, 일반 유물 묶음, 비싼 희귀·특급 유물을 섞어 구성한다. 정확한 상품 수·가격·수량·희귀도 분포는 미정이다.
가격이 해당 보상을 얻기 위한 목표 포인트가 된다. 높은 등급 하나와 여러 직원에게 나눌 일반 유물 사이에서 선택할 수 있게 한다.

정산을 선택하면 담보 회수 또는 포기를 먼저 처리하고, 남은 포인트를 지불해 공개된 유물을 구매한다.
포인트와 재고가 허용하는 범위에서 여러 상품을 구매할 수 있다. 구매 확정 때 포인트 차감·재고 차감·사본 획득을 함께 처리하고 중복 지급하지 않는다.
잔액이 부족한 상품의 구매는 비활성화한다. 상점 목록과 나가기 버튼은 잔액에 관계없이 표시하며, 구매 없이 나갈 수도 있다.
도박형의 기본 보상은 공개 상품 구매이며, 무작위 고등급 상자나 별도의 보상 가챠를 기본으로 두지 않는다.

이 상점은 해당 만남의 포인트를 사용하는 딜러 보상 상점이다. 엔케팔린으로 거래하는 [일반 상점](run-and-map.md#상점)과 통화를 구분한다.

## 유물을 담보로 한 포인트 대출

판 사이에는 포인트 잔액과 관계없이 미장착 유물을 담보로 맡길 수 있으며, 여러 유물을 동시에 선택할 수 있다.
장착 중인 유물을 맡기려면 먼저 해제한다. 이미 담보로 맡긴 사본은 다시 선택할 수 없다.
인벤토리에서 사본별 지급 포인트, 선택한 사본의 총지급액과 **지급 후 잔액**을 보여 준다.
이자는 없으며, 회수할 때는 해당 사본을 맡기고 받은 원금만 지불한다. 원금과 포기 시 유물 제거를 맡기기 전에 공개한다.

`지급 후 잔액 = 현재 잔액 + 선택한 담보의 총지급 포인트`

미장착 사본을 하나 이상 선택하고 지급 후 잔액이 양수일 때 우측 하단의 담보 버튼을 활성화한다.
확정하면 선택한 모든 사본의 담보 처리와 포인트 지급을 함께 적용한 뒤 미니게임 선택 화면으로 자동 이동한다.
취소하면 사본·포인트를 변경하지 않고 판 사이 화면으로 돌아간다. 맡길 유물이 없거나 양수 잔액을 만들 수 없어도 정산하기는 가능하다.

담보는 해당 조우에서 맡기고 정산한다. 담보 유물은 회수 또는 포기 전까지 사용·장착·이전·분쇄 등 다른 용도로 소비하지 못한다.
유물의 종류뿐 아니라 맡긴 사본과 침식 여부 등 변형 상태를 보존한다.

정산하기를 선택하면 회수할 유물을 복수 선택한다. 선택한 사본의 **총상환액·회수 후 잔액·포기할 사본**을 함께 표시한다.
회수할 사본들의 원금 합계가 보유 포인트를 넘을 수 없으며, 일부 사본만 회수하거나 전부 포기할 수도 있다.
잔액이0이거나 음수여서 회수할 수 없는 경우에는 담보 전부의 포기를 확인하고 상점으로 넘어간다.
회수·포기를 확정하기 전에는 선택을 수정할 수 있다. 조기 상환과 한 사본의 원금을 나누어 갚는 부분 상환은 허용하지 않는다.

| 떠나기 전 담보 정산 선택 | 처리 |
| --- | --- |
| 회수 | 선택한 사본의 원금을 포인트에서 차감하고 맡겼던 사본과 변형 상태를 그대로 반환한다. |
| 포기 | 회수하지 않기로 확정한 사본을 제거하고 해당 빚을 소멸시킨다. 보유 포인트는 유지한다. |

상환할 포인트가 충분해도 포기를 선택할 수 있다. 모든 담보를 정산한 뒤 남은 포인트로 보상 상점을 이용한다.
빚을 다음 만남이나 원정으로 넘기지 않으며, 다른 보유 자산에서 추가 추심하지 않는다.
유물을 포기해 포인트로 바꾸는 이용도 허용하므로, 담보 평가액과 딜러 상품 가격은 함께 조절한다.

## 스트레스 전투

현재 편대의 지속 전투 능력을 시험하는 **보호 대상 방어전**이다. 워프레임 방어전의 연속 웨이브·구간별 철수 선택·누적 보상 구조를 참고한다.
하나의 연속 전투 안에서 1라운드부터 최대 5라운드까지 진행하며, 무한 방어전으로 만들지 않는다.
해당 노드에서는 한 번만 도전할 수 있다. 승리·패배뿐 아니라 전투 중 수동 후퇴도 즉시 노드를 소비하며 재도전하지 못한다.
일반 전투의 최대 2회 후퇴 후 재진입 규칙을 이 활동에 적용하지 않는다. 게임 종료·명시적 저장 복구는 아래 공통 복원 정책을 따른다.
도박형의 갬빗 배율이나 포인트 상점을 이 전투에 자동 적용하지 않는다.

### 웨이브와 라운드

- 보호 대상을 적의 공격으로부터 지킨다. 보호 대상이 파괴되면 도전에 실패한다.
- 보호 대상에 적용할 수 있다고 명시된 회복·보호 효과만 허용하며, 직원 전용 회복·보호 효과는 적용하지 않는다.
- 해당 웨이브의 적을 모두 처치하면 웨이브를 완료한다. 여러 웨이브를 묶어 한 라운드로 구성한다.
- 뒤 라운드일수록 더 어렵고 강한 적이 등장한다. 적 구성·수·능력치·등장 간격은 콘텐츠로 작성한다.
- 라운드당 웨이브 수는 실제 전투 시간에 맞춰 조절하며 아직 확정하지 않았다. 3웨이브씩 총 15웨이브는 비교 예시다.

직원의 체력·배치·전투 상태·남은 자원·쿨다운과 보호 대상의 상태를 다음 웨이브·라운드로 이어간다.
라운드가 바뀌었다는 이유로 자동 회복하거나 새 전투로 초기화하지 않는다. 기존 회복 능력의 전투 중 사용을 금지하는 규칙은 아니다.
라운드 사이의 선택 구간에서는 전투 시간을 멈추므로, 선택을 오래 기다리는 것만으로 회복하거나 쿨다운을 진행시키지 않는다.
선택 구간에서는 누적 미수령 보상과 다음 라운드의 추가 보상을 확인하고 **계속 방어 / 보상 받고 철수**만 선택한다.
계속 방어하면 현재 상태와 전투당 사용 기록을 유지한 채 다음 라운드를 진행한다. 전투 진행 중 가능한 행동은 공통 전투 규칙을 따른다.

### 계속 방어와 철수

첫 라운드를 시작하기 전에도 해당 라운드의 보상을 공개한다.
1~4라운드를 완료할 때마다 지금까지 쌓인 미수령 보상과 **다음 라운드를 완료하면 추가되는 보상**을 보여 주고 **계속 방어 / 보상 받고 철수**를 선택하게 한다.
플레이어가 다음 보상의 가치를 확인한 뒤 도전을 결정하게 하며, 계속 방어를 선택한 뒤 그 보상을 다시 추첨하지 않는다.
철수하면 현재 성과로 전투를 성공 종료하고 누적 보상을 받는다. 계속 방어하면 현재 상태로 다음 라운드를 시작한다.
5라운드를 완료하면 최종 성공으로 종료하고 누적 보상을 받는다. 6라운드로 이어가지 않는다.

라운드 사이의 철수는 성공 정산 선택이다. 일반 전투 도중의 수동 후퇴와 구분한다.
진행 중인 웨이브에서도 수동 후퇴할 수 있으나, 즉시 활동을 종료하고 노드를 소비한다. 재도전은 허용하지 않는다.
전투 중 후퇴는 성공 정산이 아니며 미수령 보상을 지급하지 않는다. 직원 상태·소비품·장비·유물 등 전투 중 변화는 일반 전투처럼 해당 전투 진입 전으로 복원한다.
노드 소비와 미수령 보상 상실은 유지한다.
노드 최초 입장 때 이미 확정한 억제력 비용·입장 기록 등은 공통 후퇴 규칙대로 되돌리지 않는다.

### 누적 보상과 패배

클리어한 라운드마다 추가 보상을 쌓으며, 더 높은 라운드까지 클리어할수록 총보상이 높아진다.
진행 중 보상은 미수령 상태이고, 철수 또는 5라운드 완료로 성공 종료할 때 실제로 획득한다.
계속 도전했다가 실패하면 앞선 라운드에서 쌓은 것을 포함해 **이번 스트레스 전투의 미수령 보상 전부를 잃는다**.
각 라운드의 구체적인 추가 보상은 도전 전에 확정·공개한다. 성공 종료 때 누적분을 그대로 지급하며, 별도의 보상 후보 선택 절차를 두지 않는다.
라운드별 보상의 종류·수량·희귀도는 콘텐츠로 작성하며, 원작의 보상표 순환을 그대로 적용하지 않는다.

스트레스 전투도 실제 전투다. 성공·패배 결과의 직원 사망·부상과 전투 손실은 공통 전투 규칙대로 원정에 반영한다.
보상 도전이라는 이유로 직원 상태를 자동 복구하는 모의전으로 취급하지 않는다. 직원 사망 시 장착 유물 회수도 기존 유물 규칙을 따른다.
기본 생존 XP는 [공통 XP 규칙](growth-and-rewards.md#xp와-보상-확정)에 따라 전투 전체 종료 때 한 번 처리한다.
패배해도 기본 생존 XP는 지급하지만, 라운드 누적 보상에 포함된 XP·재료·유물은 모두 잃는다. 전투 중 수동 후퇴에는 XP를 지급하지 않는다.
[무억제 강화와 보상](expedition-and-deterrence.md#무억제-강화와-보상)도 실제 전투로서 적용한다. 전투 진입 시 정한 적 HP·공격력 강화는 모든 라운드에 유지한다.
라운드 사이 철수 또는 최종 완료로 성공하면 원래 지급하는 엔케팔린·장비 가루·환상체 파츠·XP의 총량을2배로 받는다. 기본 생존 XP도 포함하며 유물 수량은 늘리지 않는다.
패배 때의 기본 생존 XP는 기존량으로 지급한다. 라운드별 보상 안내에는 실제 적용 배율을 반영하고 결과에서 다시 중복 적용하지 않는다.
보호 대상 파괴 외에 이 활동에 추가할 고유 실패 조건은 별도로 정한다.

## 저장과 복원

[공통 저장·복구 정책](results-and-save.md#저장과-복구)을 따른다. 같은 프로세스의 재접속과 게임 종료 후 이어하기를 구분하며,
미완료 노드의 종료 복구는 입장 전 상태로 되돌린다. 이미 완료를 확정한 노드의 결과는 유지한다.
원정 첫 만남 설명 여부·조우 진행 단계·갬빗 선택·포인트·판돈·미니게임 진행과 난수·상품·담보 사본과 원금·회수 및 제거 결과·획득 결과를 같은 복원 기준으로 다룬다.
유물만 복제되거나 빚만 사라지고 획득 결과가 남는 상태를 만들지 않는다. 기존 SavePoint 복구도 소비와 결과를 함께 복원한다.

같은 프로세스의 재접속은 현재 조우 단계·게임 결과·선택을 유지한다. 프로세스 종료 후 미완료 조우를 복구할 때는 난수·상품·보상 배정도 같은 기준으로 복원하여 재추첨하지 않는다.
딜러 조우는 **최초 제안 거절 또는 상점의 나가기**에서 완료와 노드 소비를 확정한다. 미니게임 한 판 종료·담보 정산·개별 구매는 조우 전체 완료가 아니다.
미완료 조우의 종료 복구에서는 담보 사본·포인트·중간 구매를 포함한 조우 내 변화를 함께 입장 전으로 되돌린다.
완료한 조우의 회수·제거·구매 결과와 잔여 포인트 소멸·노드 소비는 함께 보존하며, 나가기 중복 입력이나 재접속으로 다시 지급하지 않는다.
상점의 나가기는 조우 완료를 요청하는 게임 행동이다. 이미 확정한 전투 결과 화면을 닫는 표시 확인과 구별한다.
스트레스 전투의 개별 라운드 완료는 전투 전체의 승리·노드 소비·실제 보상 지급으로 처리하지 않는다.
라운드 사이 철수, 5라운드 완료, 도전 실패 또는 전투 중 수동 후퇴에서 활동 전체의 결과와 노드 소비를 확정한다.
미수령 보상과 실제 획득을 구분해 복원한다. 직원 손실·전투 중 후퇴의 세부 저장 구현은 확정된 연속 전투·최종 정산 구조에 맞춰 상세화한다.

## 남은 결정

- 보상 노드 유형별 가중치·깊이별 분포. 지도 생성 시 무작위 고정·진입 전 유형/조건 공개·초반 단순 선택형 예약은 확정이다.

- 기본 포인트·판돈 단위·게임별 기본 손익·조우별 갬빗2배/3배의 배정 분포. 판수 제한 없이 양수 잔액에서 계속하고,0점 이하에서는 담보 또는 정산을 선택한다.
- 미니게임별 실제 규칙의 기준 판본·세부 검증, 게임별 포인트 환산·플립7의 기본 손실/1위 보너스 액수·NPC 판단 기준, 특수 결과·무효 입력의 처리. 판 시작 전 취소는 포인트 무차감, 시작 후 수동 포기는 패배/갬빗 적용 손실1회 정산으로 확정이다.
- 딜러의 출현 빈도, 정체·목적·대사.
- 상품 수·가격·수량·희귀도 분포와 담보 평가액. 복수 담보의 지급 후 양수 조건·무이자 원금 회수·일부 사본 회수/나머지 포기와 정산 순서는 확정이다.
- 자원 투입형의 가루 요구량·초기 최대3택1의 플레이 검증. 다음 등급 필요량 일괄 투입·부족 시 무차감·추가 투입 후 상위 후보 공개/이전 후보 대체는 확정이다.
- 유물 가챠의 등급 내 후보/가중치와 초기 확률표의 플레이 검증. 후보가 없으면 비용 없이 투입 거절·확률 변경/대체 지급 없음은 확정이다. 노드당1회·미장착 입력·침식 입력 허용/일반 상태 출력·투입 종류 제외/기타 보유 종류 허용은 확정이다.
- 단순 선택형의 초기3택1 플레이 검증. 비전투 활동 미이용 퇴장 시 노드 소비·활동 비용/보상 없음은 확정이다.
- 스트레스 전투의 라운드당 웨이브 수·적/보호 대상 구성·추가 고유 실패 조건.
- 스트레스 전투의 라운드별 고정 보상표, 전투 중 후퇴의 상태/소비 복원과 노드 소비를 함께 처리하는 세부 저장 구현.

대화에 나온 대출액·상환액·상품 가격의 설명용 숫자는 확정 밸런스로 사용하지 않는다. 위 가챠 확률표는 별도로 채택한 초기값이다.
