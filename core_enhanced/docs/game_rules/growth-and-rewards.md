# 성장과 보상

[게임 설계서](../game_rulebook.md) · [장비와 파편](equipment-and-fragments.md) · [유물](relics.md)

## 성장의 역할

| 대상 | 성장 방식 |
| --- | --- |
| 직원 | 전투와 보상으로 XP·레벨 성장 |
| 무기 | 장비 가루를 소비하는 일반 강화로 제공 공격력·주문력 증가 |
| 방어구·액세서리 | 자체 능력과 특수 효과 제공, 일반 강화 없음 |
| 스킬 파편 | 개화 형태 해금과 형태 선택, 일반 강화 없음 |
| 유물 | 기존 효과 강화·새 효과·연쇄 조합, 자체 레벨·반복 강화 없음 |

직원의 공격력과 주문력은 별개다. 무기는 어느 능력을 얼마나 제공하는지 명시하며 모든 무기가
둘 다 제공한다고 가정하지 않는다. 파편은 공격력·주문력·둘 모두 중 참조 능력과 계수를 명시한다.
무기 성장과 유물에 따라 파편의 실제 위력이 달라진다.

```text
공격형 = 기본 피해 + (직원 공격력 + 무기 공격력) × 공격 계수
주문형 = 기본 피해 + (직원 주문력 + 무기 주문력) × 주문 계수
혼합형 = 기본 피해 + 공격 기여 + 주문 기여
```

위 식은 개념식이다. 실제 능력 합성·피해 산술·계수·반올림은
[NEXT-07](open-decisions.md#성장과-경제)에서 결정한다.

유물은 보상 노드를 주 공급처로 두어 장비 가루를 얻는 일반전과 파편·장비·개화 재료를 얻는
환상체 전투에 더해 별도의 성장 탐사 이유를 제공한다. 표시된 일부 엘리트·고위험 일반전에서
추가 유물 보상을 얻고, 상점으로 조합을 보완하며 Event는 조건·대가가 있는 보조 획득처로 쓴다.
초반 선택 기회와 경로별 공급·후보 구성은 [유물 공급](relics.md#획득과-표시)을 따른다.
다섯 보상 활동과 도박형의 포인트·담보·딜러 거래는 [유물 보상 노드](relic-reward-nodes.md)를 따른다.
자원 투입형에서는 장비 가루를 소비해 보상 등급을 올리고 최종 단계에서 한 번 수령한다. 무기 강화와 유물 획득 사이의 투자 선택이며, 요구량은 강화 비용과 함께 조절한다.

## 재료와 엔케팔린

핵심 경제 자원은 다음 세 종류다.

| 자원 | 용도 |
| --- | --- |
| 엔케팔린 | 본부 상점·일반/특수 떠돌이 상점에서 물품 구매 |
| 장비 가루 | 해당 원정의 무기 강화·자원 투입형 유물 보상. 원정 간 계승·공용 창고 보관 불가 |
| 환상체 파츠 | 파편 개화 |

환상체 알·부활용 촉매제·침식 촉매제는 개별 용도의 소모품이고, 황금가지는 억제력 보충과 연결되는
특수 획득물이다. XP·전술 포인트·억제력은 각각 직원 성장·전투 조작·탐사 운용 수치로 구분한다.

**엔케팔린은 전투 승리를 주 공급처로, Event와 물품 판매를 보조 공급처로 둔다.**

| 획득처 | 엔케팔린 보상 |
| --- | --- |
| 일반전 | 장비 가루와 함께 지급 |
| 엘리트·일반 보스·부활 전투 | 해당 조우의 고유 보상과 함께 지급 |
| Event | 선택·조건에 따라 추가 획득 |
| 상점 판매 | 판매 가능한 보유품을 엔케팔린으로 교환 |

전투 엔케팔린은 승리 판정 즉시 다른 보상과 함께 확정·저장한다. 전투 경로에 따라 무기 강화·
파편·장비·개화 재료를 확보하면서 구매 재화도 얻을 수 있게 한다. 판매 가능한 남는 장비는
엔케팔린을 얻는 판매와 장비 가루를 얻는 분쇄 중 선택한다. 유물은 일반 상점 매각 없이 분쇄할 수 있다.
도박형 딜러의 [담보 대출](relic-reward-nodes.md#유물을-담보로-한-포인트-대출)은 조우 포인트를 지급하고, 헤어지기 전에 사본별 무이자 원금을 상환해 회수하거나 포기하는 거래다. 포기하거나 상환할 수 없는 사본은 제거하고 해당 빚을 소멸시킨다.
엔케팔린 지급량과 판매 가격은 상점 상품·촉매제 가격을 함께 보며 플레이로 조절한다.

엔케팔린은 **원정마다 독립된 예산**으로 운용한다. 회사는 새 원정 시작 때 기본 예산을 한 번 지급하며,
이전 원정의 성공·실패와 관계없이 같은 지급 기준을 적용한다. 성공 귀환 시 남은 엔케팔린은 회사가
회수하고 다음 원정의 사용 잔액에 누적하지 않는다. 원정 실패 때도 잔액을 계승하지 않는다.
초기 예산 액수는 초반 채용·상점 가격과 함께 플레이로 조절한다.
중단 후 이어하기·체크포인트 복구는 해당 시점의 잔액을 유지·복원하며 기본 예산을 다시 지급하지 않는다.
[귀환 정산](results-and-save.md#원정-귀환과-회수품-대여)

**무기 강화 비용은 장비 가루로만 지불한다.** 일반 침식체 전투가 가루의 주 공급처이며,
장비·유물 분쇄가 보조 공급처다. 일반전에서는 난이도에 따라 지급량을 다르게 작성한다.
분쇄는 사용하지 않는 물품을 무기 강화에 투자하는 선택이며, 일반전을 통한 확보가 충분히
가치 있도록 지급량·분쇄량·강화 요구량을 실제 플레이로 조절한다.
장비 가루는 원정 전용 재료다. 성공 귀환·실패 모두 남은 가루를 다음 원정으로 넘기지 않으며,
선택 회수와 공용 창고 보관 대상에서 제외한다. 중단 후 이어하기는 확정 경계의 보유량을 복원하고,
체크포인트 복구는 저장 시점의 가루와 강화 상태를 함께 복원한다.

장비 가루·환상체 파츠는 상점에서 직접 구매하거나 판매할 수 없다.

환상체 격파로 얻는 파츠 같은 특수 재료를 파편 개화에 사용한다. 어려운 보스의 재료를 요구해
개화 접근 난이도를 조절할 수 있다. 일부 고성능 파편은 다른 환상체의 재료를 요구한다.
개화 요구 파츠와 수량, 엔케팔린 동반 비용은 해당 스킬 파편 RON의 개화 형태별 recipe에 작성한다.
작성된 비용만 소비하며 구체적인 스키마와 구현은 후속 작업이다.
성공 귀환 시 환상체 파츠는 종류 합계 최대 2개를 선택 회수하는 초기값을 쓰고 다음 개화에 사용한다.
[재료 공용 창고](equipment-and-fragments.md#재료-공용-창고)

무기·파편을 분쇄하면 기본 분쇄 보상에 더해 실제 강화·개화 투자 재료의 일부를 현재 원정 소지분으로
돌려받는다. 초기값은 재료 종류별 실제 소비량의 50%를 내림하며, 엔케팔린은 환급하지 않는다.
환급된 장비 가루는 원정 전용이고, 환상체 파츠는 성공 귀환 때 선택 회수할 수 있다.
[분쇄와 투자 재료 환급](equipment-and-fragments.md#분쇄와-투자-재료-환급)

다음 연결은 아직 미정이다.

- 일반전의 가루 지급량·장비/유물 기본 분쇄량·강화 요구량과 환급률의 플레이 검증.
- 초기 엔케팔린 예산·조우별 지급량·Event 보상 조건·판매 가능 물품과 가격.
- 시작 보급·보스·Event의 추가 가루 지급.
- 개별 파츠의 수량·확률·추가 보상처, 개화 recipe의 구체적인 요구 비용.

경제 결정을 모은 곳은 [NEXT-04·07](open-decisions.md#성장과-경제)이다.

## XP와 보상 확정

직원은 레벨 1, 현재 레벨 XP 0에서 시작한다. 성장 전투를 적절히 선택하는 원정의 주력 직원이
**중반 레벨 3, 최종보스 도전 전 레벨 6**에 도달하는 것을 초기 플레이테스트 목표로 둔다.
깊이에 따라 레벨을 자동 지급하지 않으며 우회·추가 전투에 따라 성장량이 달라진다.
이어받은 비교 기준은 레벨마다 100 XP,
전투 결과 생존 직원의 기본 XP 10, 레벨 1/3/6에서 전투 tier I/II/III다.
XP 기준값은 위 성장 속도에 맞게 플레이로 조절한다. tier 자체는 스탯 배율이 아니다. 레벨업이 별도의 GrowthStack을 늘리지 않으며 현재 그 생산 경로도 없다.

- 한 번의 지급으로 여러 레벨을 넘을 수 있고 남은 XP는 유지한다.
- 같은 직원이 여러 번 배치돼도 기본 생존 XP는 한 번이다. 패배에도 지급하고 후퇴에는 지급하지 않는다.
- 스트레스 전투는 라운드를 합친 하나의 전투다. 기본 생존 XP는 성공·패배 때 한 번 처리하고 전투 중 후퇴에는 지급하지 않는다. 실패하면 라운드에 누적한 XP 등 미수령 보상은 잃지만 기본 생존 XP는 유지한다.
- 보상의 XP 수치는 대상 **직원 한 명당** 지급량이다. 20 XP를 3명에게 주면 각자 20을 받는다.
- 지급 대상은 살아 있는 전체 직원, 명시된 전투 참가자, 선택 직원, 생사와 무관한 전체 직원으로
  구분한다. 정확한 기본 생존 XP 대상·지급 시점은 [성장 런타임 계약](../core_runtime_contract.md#reward-and-employee-growth-boundary)을 따른다.
- 패배에는 성공 보상·보너스 목표·파편·승리 격파 횟수를 지급하지 않는다.
- 보상과 상태 변화는 승패 판정 즉시 노드 소비와 함께 확정·저장한다. 일부 재료나 XP만 남는 실패를 만들지 않는다.

현재 일반 자동 보상은 모두 받기(ClaimAll) 기준이다. 차기의 반복 격파 전용 장비 선택은 아래 목표 설계이며,
현재 선택 보상이 모두 구현되었다는 뜻은 아니다. 유물은 [보상 노드별 활동과 성과](relics.md#획득과-표시)를 따른다.
연구도·본사 분석/송신·대기 중인 파편 지급은 사용하지 않는다.

### 무억제 전투 보상

무억제 상태로 진입한 전투에 승리하면 엔케팔린·장비 가루·환상체 파츠·XP의 **기존 지급 총량을
2배**로 한다. 기본 보상과 달성한 보너스 목표의 해당 수량에 적용하며, 기본 생존 XP도 승리 시에는
포함한다. XP는 기존 지급 대상 직원별로 2배를 적용하고 대상·조건 자체는 바꾸지 않는다.
패배 시 기본 생존 XP는 기존량을 유지하며, 후퇴에는 XP나 보상을 지급하지 않는다.

파편·알·장비·유물·촉매제 등 물품의 수량, 보상 후보 수·선택 횟수, 황금가지 수량·억제력 보충량은
두 배로 만들지 않는다. 드롭 확률·지급 자격·격파 단계·비전투 노드 보상·판매가·분쇄량에도 적용하지 않는다.
새 보상 항목을 만드는 규칙이 아니며, 원래 지급하는 엔케팔린·장비 가루·환상체 파츠·XP에만 적용한다.
스트레스 전투도 적용 대상이다. 라운드 사이 철수·최종 완료 시 누적된 해당 보상과 기본 생존 XP에 한 번 적용하고, 패배 시 기본 생존 XP는 기존량을 유지한다. 유물 수량은 늘리지 않는다.
부활 전투는 해당 단계의 원래 지급량을 기준으로 하며, 보상 배율은 한 번만 적용한다.
강화와 보상 적용 여부는 노드 최초 입장 비용을 반영한 뒤 전투 진입 시 함께 확정하고 승패 판정 즉시
상태·진행·보상과 함께 반영한다. 입장 소모로 억제력이 0이 되고 계속했다면 그 전투부터 무억제 배율을 적용한다.
봉인 보스 승리 후 보충으로 배율을 소급 변경하지 않는다.
[무억제 강화와 보상](expedition-and-deterrence.md#무억제-강화와-보상)

## 보너스 목표

주 환상체가 있는 전투에서 개별 작성한 목표만 평가한다. 승리 후 목표마다 전투당 한 번 추가
재료·XP를 지급하며 여러 보상 효과를 함께 가질 수 있다. 파편 획득 조건에는 영향을 주지 않는다.

| 목표 | 판정 |
| --- | --- |
| ClearWithin | 전투 시작부터 승리까지 제한 시간 이내. 늦게 등장하는 보스에는 사용하지 않음 |
| DecisiveDamage | 주 환상체에게 한 공격 원천이 준 지속 피해 외 실효 피해가 최대 HP의 지정 비율 이상 |

DecisiveDamage는 여러 틱을 합산하지 않고 마지막 일격일 필요도 없다.
보너스 XP는 배치·무장·출전 가능 여부와 관계없이 살아 있는 전체 직원에게 각자 전액 지급하고
Dead만 제외한다. 직접 레벨을 주지 않는다. 환상체 부위는 별도 스킬 파편이 아닌 보너스 재료의
표현으로 사용할 수 있다.

## 전투력과 난이도

편성 전투력·Certified·런 최고 전투력에 따른 적 난이도 조정을 제거한다.
적의 스탯·웨이브·구성은 깊이·지역·조우별 작성된 고정 난이도를 사용한다. 장비·파편·유물로
직원이 강해졌다고 적이 함께 강해지지 않으며, 과거 최고 전투력을 유지해 난이도를 올리는 규칙도 사용하지 않는다.

같은 방의 일반 침식체 전투에는 Easy·Standard·Hard를 섞는다. 특수 노드 배정 뒤 남은 일반전을
기준으로 Easy 20% / Standard 50% / Hard 30%를 초기 조절값으로 사용하고 방별로 조정한다.
세 난이도 모두 장비 가루를 주되 지급량과 추가 보상을 다르게 작성한다.
어려운 전투를 선택할 성장상의 이유를 제공하며 정확한 수량·비율은 플레이 검증으로 맞춘다.

부활 단계·억제력 소진·황금가지 봉인 해제 같은 명시적인 조우 조건에 따른 강화는
편성 전투력을 따르는 조정과 별개다. 무억제 강화는 일반 침식체를 포함한 전체 적의 HP·공격력에
조우별 작성값 1.5~2배를 적용한다. 배율은 진입 전에 공개하며 패턴·이동 속도·공격 속도·사거리·
저지 요구량은 바꾸지 않는다. 해당 전투 승리의 지정 수량형 보상은 위 규칙에 따라 2배로 지급한다.
부활 단계 강화는 유지하면서 무억제 배율을 곱한다(2026-10-14 사용자 선택).
구체적인 조우별·단계별 수치는 NEXT-18의 플레이 검증 대상으로 남긴다.
위험도·출전 준비 경고는 계속 제공할 수 있지만 적 스탯을 편성에 맞추는 근거로 사용하지 않는다.

## 파편 획득과 반복 전투

시작 직원은 각자 기본 무기·훈련용 파편 세트를 받으며 별도의 추가 파편 1개 선택은 없다.
[기본 세트](equipment-and-fragments.md#회사-지급-훈련용-파편)는 회수품 대여와 별도다.

**엘리트와 일반 보스의 수집 흐름을 구분한다.** 엘리트는 자연 반복 조우할 수 있고 알을 남기지 않는다.
같은 종류의 엘리트를 해당 원정에서 처음 격파하면 **파편과 장비**를 지급한다. 두 번째 이후는
장비 가루·XP·환상체 파츠 등 조우별로 작성한 반복 보상을 준다. 모든 항목을 매번 보장하지 않는다.
난이도와 보상은 깊이·지역·조우별 작성값을 사용하고 누적 격파 횟수로 자동 강화하지 않는다.
최초 파편 보상은 종류별·원정별 한 번이며, 잃거나 분쇄해도 지급 자격을 초기화하지 않는다. 새 원정에서는 다시 시작한다.

고정 출현하는 **일반 보스**의 기본 수집 흐름은 아래와 같다. 첫 파편 보상은 원정별 한 번이며,
두 번째·세 번째 격파는 알과 촉매제로 여는 선택형 부활 전투다.

| 단계 | 보상과 다음 진행 | 역할 |
| --- | --- | --- |
| 첫 격파 | 해당 환상체의 기본 파편 + 알 | 새로운 스킬을 편성에 활용 |
| 두 번째 격파 | 전용 장비 선택 + 개화 재료 + 다시 남은 알 | 해당 환상체 중심의 성장 |
| 세 번째 격파 | 개화 재료 중심 보상 + 추가 전용 장비 선택. 알은 더 남지 않음 | 필요한 개화를 위한 파밍 |

두 번째·세 번째 격파는 선택형 부활 전투다. 일부 고성능 파편은 다른 환상체의 재료를 요구하므로,
그 환상체의 파편을 쓰지 않더라도 세 번째 격파에 도전할 이유가 생긴다. 필요한 개화 재료와
부활 전투의 보상·수량을 미리 보여주고, 세 번째에는 해당 환상체의 개화 재료를 확정 지급한다.
전용 장비는 필요한 것을 선택하며 후속 선택에서 앞서 받지 않은 부위를 고를 수 있게 한다.
단계별 정확한 장비 수·후보·재료량과 recipe는 콘텐츠 작성 및 밸런스 조절 대상이다.
위 수집 흐름을 이유로 모든 엘리트·일반 보스·부활 단계에 유물을 자동 추가하지 않는다.
유물은 보상을 표시한 일부 엘리트나 개별 일반 보스·부활 조우에서 추가 보상으로 명시한 경우에 지급한다.
황금가지 봉인 보스를 알로 부활시킨 경우에도 황금가지를 지급하지 않는다.
황금가지 획득과 그에 따른 억제력 보충은 [원래 시설의 봉인 전투](expedition-and-deterrence.md#일반-보스와-황금가지-봉인)에서만 제공한다.

기본 반복 흐름은 세 번째 격파까지이며 그 뒤 무제한 부활 파밍을 확정하지 않는다.
계약·동행·분기·연속 전투 같은 고유 조우의 승리 조건과 보상 예외는 유지한다. 일반 보스의 재현에
선행 사건 전체를 반복시킬지 등 개별 부활 전투 구성은 별도로 작성한다. 최종 보스의 알·반복 부활을
이 표로 추가하지 않으며 최종 보스 승리 파편·고유 보상은 유지한다. 승리 후 귀환 또는 계속 탐사를
선택하고, 계속하면 새 보상을 해당 원정에서 장착·사용할 수 있다.

환상체 유래 파편은 원본 환상체 하나에 대응한다. 환상체 하나가 여러 파편을 가질 수 있지만
각 보상 source는 지급할 파편을 명시하고, 개별 선택 보상 합의 없이 대응 파편 전체를 일괄 지급하지 않는다.
보상은 승리 판정 즉시 확정·저장하고 결과 확인 버튼이나 본사 수령을 기다리지 않는다. 일반 침식체 전투·보상 노드·상점·본사 연락은
정규 환상체 파편의 기본 지급처로 바꾸지 않는다.

## 알과 촉매제

모노리스를 제거하고 **일반 보스 격파 후 남은 알에 촉매제를 조합하여 환상체를 부활**시키는 방식으로 대체한다.
알은 해당 원정에서만 사용하고 성공 귀환해도 회수하거나 공용 창고에 보관하지 않는다.

- 첫 격파 후 얻은 알과 촉매제로 두 번째 전투를 열고, 다시 남은 알과 촉매제로 세 번째 전투를 연다.
- 순수한 미해결 일반 침식체 전투 노드에서 부활 전투로 전환한다. 일반전의 장비 가루를 얻을 기회와
  촉매제를 투자하는 선택이며, 부활 전투 노드도 최초 입장 때 억제력을 소모한다.
  이미 입장한 노드의 전환·재입장에는 입장 비용을 다시 청구하지 않으며 부화 비용은 별도로 적용한다.
- 촉매제는 환상체 공용이고 일반 상인의 기본 상품으로 구매한다. 희귀 무작위 상품으로 만들지 않으며,
  다른 상품 구매·채용과 비교해 구매를 고민할 만큼 비싸게 조절한다. 가격·재고·정확한 소비량은 별도로 작성한다.
- 촉매제는 재료 공용 창고의 보관 대상이다. 부화 화면에서 현재 소지분 또는 창고분을 선택해 직접 사용한다.
  출처별 보유·소비량을 확인하고 사전 반입·원정별 추가 사용 한도는 두지 않는다. 알은 현재 원정에서 확보한다.
- 후속 부활은 단계별 강화 전투로 설계하되 기존 모노리스의 150%·200% 스탯을 확정값으로 계승하지 않는다.
  명시적인 전투 후퇴는 아래의 부화 후 전투 진입 상태를 기준으로 공통 무손실 복원 원칙을 따른다.

### 부화 확정과 제압·도망

부화와 전투 진입을 분리한다. **부화를 확정할 때 알·촉매제 소비와 해당 노드의 환상체 조우를 함께 확정**한다.
부화가 끝나면 이미 존재하는 환상체를 제압하거나 도망칠 수 있으며, 도망쳐도 부화를 취소하지 않는다.

| 행동·상태 | 처리 |
| --- | --- |
| 부화 확정 전 취소 | 알·촉매제와 원래 노드 상태를 유지 |
| 부화 확정 | 알·촉매제를 소비하고 미해결 일반 침식체 노드를 해당 단계의 환상체 조우로 전환 |
| 부화 후 제압을 보류하거나 전투에서 도망 | 환상체는 그 노드에 남음. 알·촉매제를 반환하거나 원래 침식체 노드로 되돌리지 않음 |
| 같은 방에서 다시 제압 시도 | 동일한 환상체·부활 단계에 도전하며 알·촉매제를 추가 소비하지 않음 |
| 제압 성공 | 해당 단계의 보상·격파 진행·노드 해결을 확정. 다음 알 지급은 단계별 보상 규칙 적용 |

도망은 공통 전투 후퇴로 처리한다. 전투 중 변경된 직원 상태·소비 아이템·전투 진행은
**부화가 끝난 뒤의 해당 전투 진입 직전 상태**로 복원한다. 이미 확정한 부화 비용은 복원하지 않으며,
부분 피해나 전투 진행을 다음 시도에 누적하지 않는다. 노드 최초 입장 때 확정한 억제력 소모·시한부 유예 진행도 유지한다.
전투 중 도망은 후퇴 기회 1회를 쓰며 최대 2회까지 허용한다. 보상·XP·노드 완료·추가 억제력 소모는 없다.
후퇴 후 같은 노드에 재진입할 때 입장 비용을 중복 청구하지 않는다. 전투 시작 전 제압 보류는 전투 후퇴가 아니다.
이는 전투 진입 전에 확정한 조우를 보존하는 것으로, 봉인 해제 전 상태로 되돌리는 황금가지 전투와 구분한다.

같은 방에서 편성·정비 후 연결 경로상 도달 가능한 해당 노드에 다시 도전하거나, 다른 경로로 우회해 떠날 수 있다.
도망친 노드는 미해결 상태로 남으며, 도망만으로 완료 통과 노드가 되지 않는다. 우회 가능 여부는 실제 지도 연결을 따른다.
**Gate로 가는 유일한 경로의 노드라는 이유로 부화를 제한하지 않는다.** 기존 부화 자격을 만족하면
우회 경로가 없어도 부화할 수 있고, 환상체를 감당하지 못해 진행이 막힐 위험은 플레이어가 판단한다.
부화 이후의 우회로를 별도로 보장하거나 생성하지 않으며, 경로가 막혔다는 이유로 비용을 반환하거나
미해결 노드를 자동 완료하지 않는다. 귀환·체크포인트 복구·원정 포기는 각각 기존 조건을 따른다.
같은 층에서는 연결을 따라 해당 방에 재방문할 수 있다. 하강 뒤에는 상승할 수 없으며,
남겨 둔 환상체를 다른 방이나 다음 원정으로 옮기지 않는다.
게임 종료 후 이어하기는 미확정 노드를 입장 전으로 복원한다. 입장 전에 이미 확정된 부화는 유지하고,
미확정 노드 안의 부화는 조우·알·소지/창고 촉매제를 함께 되돌린다. 수동 도망은 부화 비용을 유지한다.
부화 전 SavePoint로 복구하면 조우·원래 노드·알·촉매제를 함께 복원하고, 부화 후 SavePoint라면 당시 상태를 유지한다.
[소비와 결과의 동시 복원](results-and-save.md#저장과-복구)을 따른다.

부활 전투도 **수동 후퇴 최대 2회, 그에 따른 도전은 최초 포함 최대 3회**다.
승리·패배가 확정되면 즉시 해당 노드를 소비하며 패배 후에는 다시 도전할 수 없다.
패배한 노드는 통과 가능하지만 성공 보상·격파 기록은 주지 않고 부화 비용도 반환하지 않는다.
두 번째 후퇴만으로는 완료하지 않으며 마지막 도전이 남는다. 모든 노드 정책의 RON 확장은 NEXT-20에서 다룬다.
흉탄은 [세 공개 보스의 영구 격파 기록과 이번 원정의 마탄 완료](run-and-map.md#보스-분류와-연속-조우)로
마탄 옆 같은 층의 별도 방에 접근한다. 기존 잔재 교환·변질된 모노리스나 별도 전조 체인을 요구하지 않는다.

## 파편 획득의 현행 비교 기준

기존 Endless의 엘리트 세 번째 승리 지급은 차기의 첫 격파 지급으로 대체한다.
기존 source별 지급 완료·반복 보상·재획득 예외는
[과거 파편 획득](../archive/game_rulebook_legacy_2026-10-04.md#연구도-폐기와-스킬-파편-획득)에서 비교할 수 있다.
최초 파편을 잃거나 분쇄해도 해당 원정의 보상 자격은 다시 열리지 않는다. 숙달·소탕은 차기에서 제거한다.

## 엘리트와 모노리스의 비교 기준

기존의 자연 승리 후 모노리스 구매, 강화 재현 두 단계, 잔재 교환과 반복 pool은
[과거 모노리스 정책](../archive/game_rulebook_legacy_2026-10-04.md#elite-모노리스와-강화-재현)에 보존한다.
차기에서는 위의 알·촉매제를 사용하며, 기존 상인 출현 층·단계 수치·잔재 교환을 새 규칙으로 계승하지 않는다.

## 숙달 소탕의 비교 기준

기존 Endless는 엘리트의 세 번째 직접 승리로 파편·숙달을 얻고, 이후 같은 대상을 다시 만나면
직접 전투 또는 소탕을 선택했다. 파편이 없으면 소탕에서 재지급하고 있으면 반복 보상을 주는
예외도 있었다. 상세 비교 기준은 [과거 숙달 소탕](../archive/game_rulebook_legacy_2026-10-04.md#숙달-elite-소탕)에 보존한다.

차기에서는 **숙달과 자동 소탕을 제거하고 매 조우를 직접 전투**한다. 도감·격파 기록은 유지한다.
엘리트의 자연 반복과 일반 보스의 알 부활 보상은 위의 서로 다른 흐름을 따른다.

## 보스 징조와 반복 조우

### 원정별 전조 풀

전조의 상태와 사용한 후퇴 횟수는 등장한 노드가 아니라 **해당 원정의 전조 풀**이 소유한다.
각 전조는 보스 계열·발현 자격·선행 조건·진행 상태·후퇴 사용 횟수·현재 배정 노드를 가진다.
같은 전조를 동시에 여러 노드에 배정하지 않는다. 배치 층과 방향은
[방향별 전조 발현](run-and-map.md#방향별-징조와-퍼즐-발현)을 따른다.

전투 전조도 공통 **후퇴 최대 2회**를 적용한다. 첫 진입과 후퇴 후 재진입을 합쳐 최대 3회 도전할 수 있지만,
어느 도전에서든 승리·패배가 확정되면 그 전조는 완료되고 해당 노드를 소비한다. 패배 후 재도전은 없다.
백야의 비전투 치료는 실제 치료로만 조건을 충족하며 이 전투 규칙으로 대체하지 않는다.

| 결과 | 풀 상태·보상·보스 선행 조건 |
| --- | --- |
| 승리 | 성공 완료·노드 소비. 성공 보상 1회, 후보에서 제거, 해당 전조 경험 인정 |
| 패배 | 즉시 실패 완료·노드 소비. 성공 보상 없이 후보에서 제거, 해당 전조 경험 인정 |
| 수동 전투 후퇴 | 후퇴 기회 1회 소비. 미완료 유지, 경험 완료·보상 없음. 최초 입장 비용 유지 |
| 미방문 | 후퇴 기회 소비·완료 없음 |

수동 후퇴 후에는 같은 노드에 다시 진입할 수 있다. 후퇴 2회를 모두 썼어도 마지막 도전을 할 수 있고,
그 전투에서는 더 후퇴할 수 없다. 같은 층에서는 실제 연결을 따라 기존 배정 노드에 돌아갈 수 있다.
하강으로 미완료 전조를 남기면 기존 배정을 해제하고 이후 같은 계열 후보로 돌리되 **후퇴 사용 횟수를 유지**한다.
새 위치에 배정되어도 후퇴 기회를 채우지 않는다. 승리·패배로 완료한 전조는 같은 원정에 다시 제안하지 않는다.
후퇴 기회 소진이나 단순 방문만으로 임의의 실패 완료를 선언하지 않는다.

공개 최종보스는 모든 필수 전조의 경험 완료와 개별 조건을 요구한다. 전투 전조는 성공 완료와 실패 완료를
모두 인정하며 단순 방문·후퇴는 완료가 아니다. 개방은 기존 8층 보스 방으로 가는 자격이며
현재 맵을 강제 보스 전장으로 교체하거나 순간이동하지 않는다.

### 기본 최종보스의 조건과 준비 보상

| 보스 | 이번 원정의 조건 | 성공에 따른 준비 효과 |
| --- | --- | --- |
| 종말새 | 큰 새·심판 새·징벌 새 3개 전조를 순서 무관하게 모두 성공 또는 실패 완료 | 기존 세 전조의 전투 원리를 학습. 별도 자동 보너스는 추가하지 않음 |
| 고요한 오케스트라 | 서로 다른 심포니 4개 전조를 순서 무관하게 모두 성공 또는 실패 완료 | 첫 심포니 승리에서 전용 단일 파편과 충전 1회, 다른 심포니 첫 승리마다 +1회. 최대 4회 |
| 백야 | 현재 생존한 소속 직원 전원의 치료·잠복 사도 표식. 미치료 직원을 새로 채용하면 그 직원도 치료 필요 | 직원당 한 번 신체 부상·트라우마 전부 회복 및 일시 스탯 강화. 한 전조 최대 3명 치료 |

오케스트라 전조 실패 완료는 충전을 주지 않는다. 충전은 공격·방어가 공유하고 발동마다 1회 소모한다.
1~3악장 종료 공격은 각각 방어 1회로 막으며 4악장 종료 공격은 방어 불가능한 전멸 제한 시간이다.
전조를 모두 이겼다면 3회 방어와 4악장 1회 공격 배분이 가능하다. 세부 악장 제한은
[오케스트라 설계](../skills/abnormality_design_notes.ko.md#고요한-오케스트라)를 따른다.

백야의 가시 면류관은 입장 조건이 아니다. 마지막 치료 후 교회를 조사하지 않아 면류관이 없으면
보스의 필연적 붕괴에서 전멸한다. 면류관이 있을 때만 One Sin 고해 문답을 거쳐 기존 후속 전투로
이어진다. 치료·발견·문답의 세부는 [백야 설계](../skills/abnormality_design_notes.ko.md#백야)를 따른다.

### 원정 초기화와 기록

새 원정에서는 전조 풀의 부분 진행·후퇴 사용 횟수·배정·치료 기록·사도 표식·심포니 준비 충전·면류관과
보스 방 개방을 처음부터 진행한다. 이전 격파가 이번 전조를 자동 완료하거나 충전을 채우지 않는다.
중단 후 이어하기는 이미 판정된 승패와 소비한 노드를 유지한다. 승패 전 종료는 입장 전으로 복원하며
후퇴 횟수를 추가로 차감하거나 이미 사용한 수동 후퇴 기회를 반환하지 않는다.
체크포인트는 당시 풀·보상·직원·개방 상태를 함께 복원한다.
영구 격파·탐사 기록과 불러오기 사용 횟수는 되돌리지 않는다.

흉탄은 일반 전조 풀 밖의 숨겨진 최종보스다. 공개 세 보스의 영구 격파 기록이 있으면
이번 원정의 마탄 조우 완료로 마탄 옆 같은 층의 고정된 별도 방과 직접 연결이 열린다.
과거 목격 기록이나 추가 전조·모노리스를 요구하지 않는다. 새 원정에는 마탄 완료가 다시 필요하다.
흉탄 본체의 전투 패턴 설계는 보류한다.
최종보스 격파 후에는 보상·기록을 확정하고 귀환 또는 기존 고정 맵의 계속 탐사를 선택한다.

### 현행 구현과의 비교

현행 일반 보스 pool의 cycle 소진·재충전과 FinalBoss의 단일 활성 BossOmen chain, 실패 단계의
다음 Floor 재제안, 강제 전장 교체, white_night bootstrap 등은
[과거 BossOmen 정책](../archive/game_rulebook_legacy_2026-10-04.md#finalboss-pool과-bossomen-chain)에 보존한다.
위의 차기 전조 풀을 현재 구현 완료로 읽지 않으며, 현행 cycle 규칙을 차기에 자동 적용하지 않는다.
