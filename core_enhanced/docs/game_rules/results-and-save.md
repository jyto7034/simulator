## 결과 확정과 노드 소비

승리·패배 조건이 성립하는 즉시 상태·소비 아이템 기간·보상·XP·격파 기록·노드 소비를 함께 확정하고 저장한다.
결과 화면은 확정된 승패·직원 상태·통계·보상·진행을 보여주며, 확인 버튼은 화면을 닫고 다음 진행으로 넘어가는 역할이다.
확인 버튼을 누르기 전 종료해도 이미 결정된 승패와 노드 소비를 되돌리지 않는다.
처리 실패로 일부 보상이나 상태만 남기지 않으며 재접속 때 같은 결과를 중복 지급하지 않는다.
딜러 조우의 제안 거절·상점 나가기는 [활동 완료 행동](relic-reward-nodes.md#저장과-복원)으로 노드를 소비한다. 이미 확정된 전투 결과 화면을 닫는 확인과 구별한다.

선택형 보상이 있으면 승리 시 보상 획득 권리·후보·선택 대기 상태를 함께 저장하고, 실제 선택은 이후에 처리한다.
보상을 아직 선택하지 않았다는 이유로 승패·노드 소비를 되돌리거나 보상 후보를 다시 뽑지 않는다.
후보가 예정 수보다 적어도 1개 이상이면 실제 지급 가능한 후보만 제시한다. 후보가 0개이면 보상 없음 안내 후
선택 절차를 생략하며 대체 보상을 만들지 않는다. 이 결정으로 중복 보유·희귀도 등의 새 지급 제한을 추가하지 않는다.

같은 종료 시점에 승리와 패배가 함께 성립하면 패배가 우선한다. 시간 종료를 쓰는 전투는 그
결과를 명시한다. 여러 번 배치된 직원도 결과 통계는 한 행으로 합치고 마지막 전투 개체가 최종
HP·생존을 대표한다. 전투 중 누적한 부상·트라우마는 승패 확정 때 직원에게 한 번 반영한다.

**승리 또는 패배 결과가 확정되면 해당 전투 노드를 소비한다. 패배 후 재도전은 없다.**
다시 싸울 기회는 결과가 나기 전에 수동 후퇴했을 때만 남는다. 후퇴는 원정 내 해당 전투 노드당
최대 2회이므로, 첫 진입과 두 번의 후퇴 후 재진입을 합쳐 **최대 3회 도전**할 수 있다.
**스트레스 전투는 노드당 한 번만 도전하는 예외이며, 수동 후퇴해도 즉시 노드를 소비한다.**
이는 패배를 세 번 허용한다는 뜻이 아니다. 첫 도전에서 패배해도 그 노드는 소비한다.
이 최대 3회는 수동 후퇴를 통한 정상 진행 기준이다. 승패 전 게임 종료의 복구 예외는 아래 저장 규칙을 따른다.

| 진행 | 가능한 선택 |
| --- | --- |
| 첫 도전 | 승패 성립 전 첫 후퇴 가능. 승리·패배 확정 시 노드 소비 |
| 첫 후퇴 후 두 번째 도전 | 승패 성립 전 두 번째 후퇴 가능. 승리·패배 확정 시 노드 소비 |
| 두 번째 후퇴 후 세 번째 도전 | 수동 후퇴 불가. 승리·패배 확정 시 노드 소비 |

두 번째 후퇴 자체로 노드를 소비하지 않는다. 미해결 상태에서 마지막 도전을 할 기회가 남는다.
남은 후퇴 횟수가 있어도 승리·패배가 확정된 노드는 다시 실행할 수 없다.

| 전투 | 결과 확정 후 처리 |
| --- | --- |
| 일반전·엘리트·일반 보스·알 부활 전투 | 승리는 보상과 성공 완료, 패배는 승리 보상 없는 실패 완료. 모두 노드를 소비하고 통과 가능 |
| FinalBoss | 승리는 보상·기록과 귀환/계속 탐사 선택, 패배는 런 실패 후보. 해당 전투 노드 재도전 불가 |
| Event 전투 | 승패에 따라 노드 소비와 작성된 Event 결과 처리. 패배 후 재도전 불가 |
| 스트레스 전투 | 라운드 사이 철수·최종 라운드 완료는 누적 보상 지급. 패배·전투 중 후퇴는 미수령 보상 상실. 모두 노드 소비·재도전 불가 |

실패 완료는 격파·성공 완료가 아니며 승리 보상·파편·알·격파 기록과 격파에 따른 해금 조건을 주지 않는다.
패배 XP는 기존 규칙을 따르되 노드를 소비하므로 같은 노드에서 패배 XP를 반복 수령하지 않는다.
알 부활 전투의 패배도 소비한 알·촉매제를 반환하지 않는다. 고유 조우의 승패·보상·런 실패 조건은 유지한다.

모든 노드 유형의 정책·수치를 RON으로 설정하는 확장은 [NEXT-20](open-decisions.md#후속-설계구현-작업)의
후속 구현 과제다. 패배 뒤 남은 도전 횟수로 재실행하거나 무제한 재도전하는 정책은 사용하지 않는다.

### 전조의 차기 도전 정책

전투 전조도 **최대 2회 후퇴 후 재진입**을 허용하고, 승리 또는 패배가 확정되면 노드를 소비한다.
승리는 성공 완료·성공 보상 1회, 패배는 즉시 보상 없는 실패 완료다. 둘 다 보스의 전조 경험 조건으로 인정한다.
수동 후퇴는 후퇴 기회 1회를 쓰고 미완료로 남는다. 미방문은 횟수를 쓰지 않는다.
다음 층에서 미완료 전조가 재제안되어도 이미 사용한 후퇴 횟수는 유지한다. 결과를 확정한 전조는 다시 제안하지 않는다.
백야의 비전투 치료 조건과 개별 문답 판정에는 전투 후퇴 횟수를 적용하지 않는다.
[전조 풀](growth-and-rewards.md#보스-징조와-반복-조우)이 배정·완료와 보스별 조건을 소유한다.

## 전투 후퇴

전투 전체 후퇴는 개별 직원 철수와 다르다. **승리나 패배 조건이 성립하기 전까지만** 전투를 포기하고 전투 진입 전
상태로 돌아간다. 정지·시전·웨이브 진행 중에도 가능하지만 명시한 강제 조우는 금지할 수 있다.

직원 상태·소비 아이템·인벤토리·재화·노드·진행·체크포인트와 난수 진행을 복원한다. 후퇴 사용 횟수는 별도로 유지한다.
결과·보상·전투 손실·노드 완료를 만들지 않지만 **수동 후퇴 기회 1회는 소비**한다.
성공한 후퇴와 횟수 차감을 함께 확정하며 전투 상태 복원으로 이 차감을 취소하지 않는다.
[스트레스 전투](relic-reward-nodes.md#계속-방어와-철수)의 전투 중 후퇴는 상태·소비품을 같은 기준으로 복원하되, 즉시 노드 소비와 미수령 보상 상실을 확정한다.
이 예외에서는 재진입 기회를 남기지 않으며, 라운드 사이의 성공 철수와 구분한다.
거절되거나 취소한 후퇴 입력은 횟수를 쓰지 않는다. 새 유물 상태의 복원 구성은 NEXT-10에서 다룬다.
전투에서 생긴 손실은 복원하며 후퇴에는 XP를 지급하지 않는다. 후퇴 기회 외에 억제력·재화를 추가 소모하지 않는다.
일반전·엘리트·일반 보스·부활·전조·최종보스에 같은 최대 2회 한도를 적용하며 명시된 후퇴 금지는 유지한다.
방 이동·재방문·재접속으로 후퇴 횟수를 초기화하지 않는다. 개별 직원 철수는 이 횟수와 무관하다.
**노드 최초 입장 때 이미 확정한 억제력 비용·입장 기록·시한부 유예 진행과 그에 따른 사망은 되돌리지 않는다.**
복원하는 전투 상태는 입장 비용 처리 후를 기준으로 한다. 지도 위치는 기존 후퇴 복귀 위치를 따르며,
후퇴로 미해결 노드를 무료 통과하거나 완료 처리하지 않는다. 같은 노드에 다시 입장해도 입장 비용과 유예를 재차 차감하지 않는다.
알 부활 전투의 후퇴 기준은 **부화가 끝난 뒤의 해당 전투 진입 직전 상태**다. 부화 시 확정한
알·촉매제 소비와 노드의 환상체 조우는 유지하고, 그 전투에서 생긴 상태 변화만 복원한다.
환상체는 미해결 노드에 남고 도망만으로 완료·통과·보상을 만들지 않는다.
[부화 확정과 제압·도망](growth-and-rewards.md#부화-확정과-제압도망)
황금가지 봉인 전투에서도 후퇴를 허용하며, 봉인·가지는 봉인 해제 전 상태로 복원하고 최초 입장 비용과 유예 진행은 유지한다.
가지 획득과 억제력 보충은 [봉인 보스 승리 후](expedition-and-deterrence.md#일반-보스와-황금가지-봉인)에만 확정한다.

일반전·전조·최종보스에 같은 후퇴 종료 경계를 적용한다. 승패 조건이 이미 성립했다면 결과 확인 버튼을
누르기 전이어도 수동 후퇴할 수 없고 노드는 이미 소비·저장된 상태다.
승패가 아직 나지 않은 전투의 게임 종료 복구만 아래 별도 규칙을 따른다.

## 원정 귀환과 회수품 대여

시설 밖으로 성공적으로 생환해 원정을 마치는 귀환은 위의 전투 후퇴와 별개다.
전투 진입 전 상태를 복원하는 Battle Retreat를 실행했다고 회수품을 런 밖으로 반납하지 않는다.

- 성공적으로 생환하면 가져간 장비와 원정에서 획득해 보유 중인 장비를 모두 반납하고 대여 가능
  목록에 넣는다. 다음 원정에는 그중 소수의 장비·스킬 파편을 선택해 가져간다.
- 장비·파편은 다음 출발 때 **합계 최대 2사본**을 선택 대여한다. 0~2개를 자유롭게 고르고,
  무기 1개·파편 1개처럼 종류별 할당은 두지 않는다. 시작 직원 3명의 기본 세트와 별도이며 초기 검증값이다.
- 다음 원정에 가져간 회수품은 원정에 실패하면 사라진다. 성공적으로 생환하면 다시 반납하고
  대여할 수 있다. 이번 원정에 가져가지 않은 보관 회수품은 유지한다. 등록 이력만으로 잃은 사본을 재발급하지 않는다.
- 시설 밖으로 반출한 장비의 일반 강화는 초기화하고, 회수한 파편의 개화는 유지한다.
  설정 근거와 개화의 범위는 [장비와 스킬 파편](equipment-and-fragments.md)을 따른다.
- 성공 귀환 시 남은 엔케팔린은 회사가 회수하며 다음 원정의 사용 잔액으로 넘기지 않는다.
  원정 실패 때도 잔액을 계승하지 않는다. 엔케팔린은 재료 선택 회수나 공용 창고의 대상이 아니다.
  새 원정에는 이전 성공·실패와 무관하게 같은 기준의 기본 예산을 한 번 지급한다.
  중단 후 이어하기·체크포인트 복구는 기존 잔액을 유지·복원하고 기본 예산을 다시 지급하지 않는다.

선택형 성공 귀환은 **현재 3층부터**, 선택 가능한 Gate 또는 억제력 소진 시 허용한다.
방문 방 수·횡단 횟수는 조건에 포함하지 않는다. 최종 보스 승리 후에도 `귀환 / 계속 탐사`를 선택한다.
승리 보상·격파·방 클리어 기록은 먼저 확정하며, 계속 탐사를 선택하면 보상을 그 원정에서 장착·사용할 수 있다.
실제 귀환 전까지 장비·파편 반납과 재료 선택 회수는 하지 않고, 이후 실패 시 최종 보스 보상도 기존 손실 규칙을 따른다.
깊이 1~2의 Gate는 다음 방 이동만 허용하며, 억제력 소진 자체로 런을 실패시키지는 않는다.
소진 후 계속 탐사했다면 깊이 3 이상에서 도달한 선택 가능한 Gate에서 귀환할 수 있다.
자발적 원정 포기는 성공 귀환이 아니며 반입·획득 회수품을 잃고 재료 선택 회수도 하지 않는다.
사용하지 않은 기존 창고 재료와 이미 확정된 영구 탐사 기록의 보존 규칙은 그대로 적용한다.
정확한 진행은 [원정 흐름](expedition-and-deterrence.md#소진과-귀환)을 따른다.

직원 개인은 아래의 원정 종료 후 처분에 따라 다음 원정에 계승하지 않는다. 새 수감자의 생성·표시,
일반 회복·전투 소모품은 원정 전용이다. 사본 관리와 저장 구현은 NEXT-02·10·16에 남긴다.
이 규칙은 목표 설계이며 현재 profile·체크포인트에 구현된 기능으로 취급하지 않는다.

## 원정 종료와 탐사 인력 처분

이번 게임의 탐사 ‘직원’은 회사가 데려온 수감자다. 회사는 원정이 끝나면 정보 유출 방지를
명목으로 생존한 탐사 인력을 살처분한다. 시작 선발 인원과 도중에 채용한 인원에 동일하게 적용하며,
성공 귀환도 처분을 면제하지 않는다. 전투에서 사망한 인원과 귀환 후 처분된 인원 모두 다음 원정에
같은 인물로 다시 합류하지 않는다.

성공 귀환에서는 정보·회수품의 정산을 마친 뒤 인력을 처분한다. 이 처분으로 성공 귀환을 원정 실패로
바꾸거나 반납한 장비·파편·재료를 소실시키지 않는다. 실패 원정에는 기존 회수품 손실 규칙을 적용한다.
관리자는 동일 인물로 유지하고 새로운 수감자를 선발하여 다음 원정을 시작한다.
직원의 성장·부상·트라우마·신뢰·기억은 해당 원정의 인물에게 속하며 다음 인원에게 넘기지 않는다.
관리자·회사 측의 도감·탐사 기록·회수 자산은 각각 정해진 영구 보존 규칙을 따른다.

중단 저장·이어하기·전투 후퇴·체크포인트 복구는 원정 종료가 아니므로 인력을 처분하거나
새 인물로 교체하지 않는다. 해당 원정의 직원 정체성과 상태를 각 저장·복원 규칙대로 유지한다.
새 인물의 이름·외형·배경 생성 방식은 후속 설계한다.

### 첫 성공 귀환의 이야기

**첫 원정 성공 귀환에 한 번만** 긴 VN을 재생한다. 앱 실행마다 반복하지 않으며 튜토리얼은 이를 소비하지 않는다.
회수품과 주요 전투 통계를 보고하는 직원이 “수고했습니다, 관리자님”으로 브리핑을 시작한다.
다음 임무를 안내하던 중 화면 밖에서 총성과 비명이 들리고, 관리자가 반응하며 확인하려 하자
보고 직원이 냉정하게 제지하고 브리핑에 집중하도록 한다. 마지막에는 “다음 원정 때까지 푹 쉬어주십시오”라는
취지로 마무리한 뒤 메인 메뉴로 돌아간다. 정확한 대사는 작성 과정에서 다듬는다.

처분 설정을 튜토리얼에서 먼저 설명하거나 이 장면에서 전모를 즉시 풀어내지 않는다.
이후 귀환은 짧은 정산·보고로 처리한다. 성공 귀환 정산을 확정한 뒤 최초 귀환 연출 이력을 영구 기록하며,
미확정 원정이나 튜토리얼 실행으로 이력을 소비하지 않는다. 처분은 정산 자산을 잃게 하지 않는다.

## 재료 회수와 공용 창고

재료 공용 창고는 원하는 빌드의 재료를 얻기 위해 매 원정마다 먼 경로를 반복하는 부담을 줄인다.
장비·파편 완제품은 위의 대여 대상이며 이 창고에서 꺼내는 대상이 아니다.

- 성공 귀환 때 **환상체 파츠는 모든 종류를 합쳐 최대 2개**, **부활 촉매제는 별도로 최대 1개**를 선택한다.
  파츠는 한 종류에 집중하거나 나누어 회수할 수 있다. 두 한도는 서로 교환하지 않으며 가중 용량도 아니다.
  모두 초기 플레이테스트 값이다. 선택하지 않은 재료는 다음 원정으로 이어지지 않는다.
- 다음 원정의 장비 노드(Maintenance)에서 개화할 때 소지 재료와 공용 창고 재료를 함께 사용한다.
  출발 전 반입·운반은 필요 없고, 별도 인출·사용량 제한 없이 실제 소비량만 차감한다.
- 부화 화면에서도 현재 소지분 또는 창고의 촉매제를 직접 선택해 소비한다. 출처별 수량·소비량을 확인하고
  별도 반입·원정별 사용 한도는 두지 않는다. 알은 현재 원정 소지분만 쓴다.
- 일반 회복·전투 소모품은 해당 원정 전용으로 회수·창고 보관하지 않는다. 창고는 빌드 구성의 속도를 높이는 용도다.
- 사용하지 않은 창고 재료는 원정 실패로 잃지 않는다. 창고 재료로 개화한 현재 원정의 파편은
  실패 시 소실되는 회수품 규칙을 따른다. 체크포인트 복구 없이 원정 실패를 확정하면 이미 사용한
  창고 재료를 반환하지 않으며, 남아 있는 재료만 보존한다.
- 환상체 파츠·부활 촉매제는 재료 창고 대상에 포함한다.
- 장비 가루와 환상체의 알은 해당 원정 전용이며 회수·보관하지 않는다. 장비 가루는 성공 귀환과
  실패 모두 다음 원정에 계승하지 않는다. 중단 후 이어하기에서는 아래 확정 경계의 보유량을 복원하고,
  체크포인트 복구에서는 저장 시점의 가루와 강화 상태를 함께 복원한다.
- 침식 촉매제도 성공 귀환·실패 모두 다음 원정에 계승하지 않으며 공용 창고에 보관할 수 없다.
  중단 후 이어하기·체크포인트 복구에서는 해당 시점의 보유량을 유지·복원한다.
- 분쇄로 환급받은 재료는 현재 원정 소지분으로 지급한다. 환상체 파츠는 성공 귀환 시 선택 회수
  대상이며 장비 가루는 원정 전용이다. 원래 창고에서 소비한 재료라도 분쇄만으로 창고에 자동 반환하지 않는다.

창고 UI와 개화 처리는 [정비와 공용 창고](equipment-and-fragments.md#재료-공용-창고)를 따른다.
**체크포인트 이후의 재료 소비와 그 사용 결과는 함께 되돌린다.** 개화 전 체크포인트를 불러오면
개화 결과를 되돌리고, 해당 개화에 쓴 소지 재료와 창고 재료를 각각 원래 출처로 복원한다.
체크포인트에 이미 반영된 소비·개화는 유지한다. 같은 체크포인트를 반복해서 불러와도 재료가 누적 반환되지 않는다.
이 복구는 해당 원정에서 되돌리는 작업의 소비와 결과에 한정하며, 창고의 무관한 기록이나 다른 영구 기록까지 되돌리지 않는다.
구체적인 저장 형식·소비 기록 관리·일괄 복원 구현은 NEXT-10·16의 후속 작업이다.
분쇄 환급에 필요한 사본별 실제 투자 내역도 강화·개화 상태와 함께 보존한다. 일반 강화의 반출 초기화와
개화 파편의 반납·대여에 따른 투자 내역 수명은 [분쇄 규칙](equipment-and-fragments.md#분쇄와-투자-재료-환급)을 따른다.
체크포인트 복구는 분쇄한 사본·투자 내역과 받은 기본 보상·환급을 함께 복원한다.

## 도구의 확정 결과와 복구

2026-10-04 도구 재구성 합의도 이 문서의 공통 복구 경계를 사용한다. 전투 전에 사용한 수액·팔찌는
수동 후퇴로 아이템으로 환불하지 않고 전투 진입 시의 효과/계약을 복원한다. 전투 중 발생한
우상 사용·초상 부담·직원 대가 등은 전투 복원 범위에 함께 넣으며 최초 입장 비용·유예와 후퇴
횟수는 각 공통 예외를 유지한다. 이미 확정된 승패와 도구 결과는 결과 화면에서 종료해도 보존한다.

도구의 명시적 희생/저주 사망과 무기 소멸도 **과거 SavePoint 복구를 금지하는 별도 예외가 아니다.**
당시의 도구 수량·효과·위험·계약·직원 생사/불참·무기·시도 상태를 함께 복원한다. 중복 입력은
한 번만 처리하고, 복구한 동일 시도의 주사위/문제/결과를 다시 뽑지 않는다. 결과 재추첨 방지를
이유로 모든 도구 장부를 체크포인트보다 우선하는 영구 누적으로 만들지 않는다.

웰치어스는 납치 뒤 해결한 서로 다른 활동 노드와 복귀/보상 상태를 함께 저장한다. 기준은 활동
노드 5개를 초기값으로 하며 층/Gate 수를 세지 않는다. 조건 도달 노드의 확정 결과와 복귀/보상을
한 번만 저장하고 준비 화면은 이를 표시한다. 복귀 전 원정 종료가 확정되면 이후 보상을 생성하지 않는다.
과거 저장으로 복원할 때도 납치·직원/장비·진행·복귀/보상을 같은 시점으로 맞춘다.

전투불능은 공통 부상·트라우마를 누적하며 도구가 별도로 명시한 대가만 영구 run 사망이다.
피의 욕조의 완전 치료는 기존 Breakdown 유예를 해제하되 입장에서 이미 확정된 사망을 취소하지 않는다.
원정 전용 도구 상태와 무기 특별 강화는 다음 원정으로 계승하지 않는다.
세부 정책·미정은 [도구 설계](../skills/abnormality_design_notes.ko.md#tool-policy-20261004)를 따른다.

## 직원 상태

전투 HP와 런에 남는 상태를 구분한다. 런 상태는 신체 부상 `0..6`과 트라우마 `0..100`이다.

| 값 | 상태와 참여 |
| --- | --- |
| 부상 0 | Normal |
| 부상 1~3 | Minor |
| 부상 4 | Major |
| 부상 5 | Critical: 전투·Event·고위험 참여 불가, 치료·장비 관리 가능 |
| 부상 6 | Dead: 모든 직원 행동에서 제외 |
| 살아 있고 트라우마 100 | Breakdown: 참여 불가, 치료·장비 관리 가능 |

전투·Event·고위험 참여는 부상 0~4와 트라우마 0~99에서만 가능하다. 전투 배치에는 무기도 필요하다.
전투 HP를 지속 부상값으로 되쓰지 않는다. 전투 개체가 전투불능이 될 때마다 부상 +1과 작성된
트라우마를 해당 시도에 정확히 한 번 누적한다.

신체 부상은 명시적 치료만 줄인다. 살아 있으면 부상이 0이어도 유효한 치료 대상이며 효과량과
관계없이 선택한 치료를 소비한다. SavePoint·Gate는 트라우마만 회복하고 사망을 되돌리지 않는다.
일반 사망 시 직원 기록은 남기고 장비·공유 active 파편·장착 유물을 회수하며 소비 아이템 효과를
제거한다. 사망 방지가 발동하면 회수하지 않는다.

## Breakdown의 유예

트라우마 100은 즉시 사망은 아니지만 시한부다. 도달한 뒤 **새로운 노드 최초 입장에 따른 억제력의
규정 소모량을 누적**하고, 한계에 도달할 때까지 99 이하로 낮추지 못하면 해당 직원은 영구사망한다.
초기 검증 한계는 **누적 소모량 4**다. 노드 입장 비용이 2이면 유예도 2만큼 줄며 노드 수로 세지 않는다.
트라우마 100이 되기 전에 이미 처리한 소모는 소급 계산하지 않는다.

- 실제 억제력 잔량이 0이거나 입장 비용보다 적어도 규정 소모량 전부를 유예에 반영한다.
  무억제 상태에서도 유예는 진행하며 황금가지 보충으로 누적 소모를 줄이지 않는다.
- 미리보기·입장 전 취소·완료 노드 통과·같은 노드 재입장·후퇴 후 재진입은 새 소모가 아니므로
  유예를 추가 차감하지 않는다. 후퇴로 최초 입장 때의 유예 진행을 되돌리지 않는다.
- 입장 소모로 누적량이 한계 이상이 되면 그 입장 처리에서 사망을 확정한다. 해당 노드의 치료·
  SavePoint 회복 활동을 나중에 실행해 사망을 취소하지 않는다. 입장 전에 잔여 유예와 사망 위험을 표시한다.
- 트라우마를 99 이하로 낮추면 해당 유예를 폐기한다. 다시 100이 되면 새로 시작한다.
  에고 침식으로 생긴 트라우마 100에도 같은 규칙을 적용한다.

이 사망도 일반 장비 회수 규칙을 쓰며 전투 밖 진행이므로 전투 사망 방지 효과로 막지 않는다.
중단 후 이어하기는 노드의 미확정 입장 비용·유예 진행·사망도 입장 전으로 되돌린다. 이미 결정된 승패와 노드 소비는 유지한다.
체크포인트 복구는 당시 직원 상태·누적량과 노드별 최초 입장
기록·억제력을 함께 복원한다. 영구사망이라는 명칭으로 기존 체크포인트 복구까지 금지하지 않는다.
한계 4의 체감은 실제 노드별 소모량·치료 접근성과 함께 검증한다. 기존 노드 완료 횟수 기준을 차기 규칙에 병용하지 않는다.

## 런 실패와 복구 경로

생존자가 없거나 전투에 복귀할 실제 경로가 없으면 런 실패 후보가 된다. 출전 가능 직원이 없을 때는
보유 치료, 지금 선택 가능한 SavePoint/Gate, 실제 후보가 있는 본사 채용을 함께 살핀다.
채용 직원의 기본 무기·파편 세트와 출전 가능 상태도 함께 검사한다.
Gate를 통한 하강의 트라우마 회복과 성공 귀환의 층 조건은 구분한다.
같은 층 방 이동·재방문은 트라우마를 회복하지 않는다. [Gate 규칙](run-and-map.md#gate와-비전투-준비)을 따른다.
깊이 1~2에서 Gate가 선택 가능하다는 이유만으로 성공 귀환이 가능하다고 판정하지 않는다.

복구 제한 중에는 실제 회복 행동과 체크포인트 불러오기만 허용하고 가능한 노드·사유를 보여준다.
행동이 끝날 때마다 복구 가능성을 다시 계산한다. 경로가 사라지면 실패 후보가 된다.

모든 gameplay 실패 후보는 유효하고 횟수가 남은 체크포인트가 있으면 먼저 복구 또는 실패 확정을
선택하게 한다. 없으면 즉시 실패를 확정한다. 런 완료·확정 실패·자발적 포기는 이어하기를 무효화한다.
차기 생환 조건은 [Gate·억제력 소진·최종 보스 격파](expedition-and-deterrence.md#소진과-귀환)를 따른다.
억제력 소진 자체는 런 실패가 아니며, 실패 확정과 성공 생환의 회수품 처리를 구분한다.

## 저장과 복구

SavePoint 완료 시 생존 직원 트라우마의 현재값 15%를 올림해 줄이고 런의 단일 체크포인트를
덮어쓴 뒤 준비 화면으로 돌아간다. Critical·Breakdown은 포함하고 Dead는 제외한다.
신체 부상·신뢰·기억은 바꾸지 않는다. 회복·노드 완료·저장을 한 번에 확정한다.
SavePoint는 지원 노드 무작위 추첨과 분리해 시설의 지정 방에 고정 배치한다.
주요 경로의 활동 노드 수·예상 플레이 시간으로 간격을 정하며 고위험 구간은 같거나 더 짧게 둔다. 상세는
[노드 종류 배정](run-and-map.md#노드-종류-배정)을 따른다.

**게임 종료 후 이어하기는 진행 중인 노드의 입장 전 상태로 복원**한다. 전투·Event·상점·정비·보상 등
모든 노드에 적용하며 전투 도중 상태를 저장해 재개하지 않는다. 마지막 SavePoint로 자동 복구하는 것도 아니다.

- 미확정 노드의 최초 입장 비용·입장 기록·억제력·Breakdown 누적/사망·직원 상태·인벤토리·창고 소비·
  개화·부화·보상·노드 진행을 모두 입장 전으로 함께 되돌린다. 재료만 돌려주고 결과를 남기지 않는다.
- **승패가 결정된 전투와 완료를 확정한 비전투 노드는 유지**한다. 전투 결과 화면의 확인 여부는 묻지 않는다.
  승리·패배 상태·직원 손실·보상·노드 소비를 함께 보존하므로 결과 화면에서 종료해도 다시 싸울 수 없다.
- **승패가 아직 나지 않은 전투에서 종료하면 기존 입장 전 복구를 유지**한다. 종료 복구는 수동 후퇴가 아니므로
  후퇴 횟수를 차감하지 않는다. 이미 소비한 수동 후퇴 횟수도 반환하지 않는다.
  두 번 후퇴한 뒤의 전투에서도 이 종료 복구 예외는 유지한다. 따라서 수동 후퇴를 통한 최대 3회가
  종료·재실행까지 합친 절대 진입 횟수 상한을 뜻하지 않는다.
- 노드 입장 전에 이미 확정한 부화는 유지한다. 복원 범위인 미확정 노드 안에서 수행한 부화는 조우와
  알·촉매제를 함께 되돌린다. 종료 여부만으로 모든 부화를 유지하거나 모든 부화를 취소하지 않는다.
- 난수·보상 배정도 같은 기준으로 복원하여 종료 후 다시 열기로 후보를 재추첨하지 않는다.
- 도박형의 원정 첫 만남 설명 여부·조우 단계·갬빗 선택·포인트·판돈·게임 결과·담보 사본/원금·회수 및 제거 결과·딜러 상품도 같은 복원 기준으로 함께 처리한다.
  최초 제안 거절 또는 상점 나가기에서 조우 완료·노드 소비를 확정한다. 개별 판 종료·담보 정산·구매는 조우 전체 완료가 아니다.
  미완료 조우는 중간 구매·담보 사본·포인트를 함께 입장 전으로 복원하고, 완료한 조우의 회수·제거·구매·잔여 포인트 소멸과 노드 소비는 유지한다.
  [유물 보상 노드](relic-reward-nodes.md#저장과-복원)의 최종 정산 경계를 따른다.
- 스트레스 전투는 개별 라운드 완료로 전투 전체의 승리·노드 소비·실제 보상 지급을 확정하지 않는다.
  라운드 사이 철수 또는 5라운드 완료 때 누적 보상을 지급하고, 패배하면 이번 전투의 미수령 보상을 전부 잃는다.
  기본 생존 XP는 성공·패배 때 전투 전체에서 한 번 처리하고 전투 중 후퇴에는 지급하지 않는다. 무억제 성공 시 해당 누적 수량 보상·기본 생존 XP에 공통 배율을 적용하며 패배 XP는 기존량이다.
  [연속 방어 규칙](relic-reward-nodes.md#스트레스-전투)에 따라 활동 전체의 결과를 확정하며, 직원 손실·전투 중 수동 후퇴와 세부 저장 구현은 후속 범위다.
- 이어하기에는 SavePoint 복구 횟수를 쓰지 않는다. 같은 서버 프로세스의 일시 연결 끊김은
  [자동 정지와 재접속](combat.md#정지와-명령-처리)을 따르고 프로세스 종료 후 로드와 구분한다.

**SavePoint의 명시적 과거 복구**는 다음 규칙을 유지한다.

- 명시적 불러오기는 런당 최대 3회이며 Core가 가능하다고 표시할 때 사용한다.
  성공한 사용 횟수는 저장 덮어쓰기·복구·재시작·백업으로 줄어들지 않는다.
- 노드별 최초 입장 기록·후퇴 사용 횟수·억제력 잔량·Breakdown 누적 소모량·직원 생사도 함께 저장한다.
  이미 확정한 입장을 유지하는 이어하기·재접속에는 비용과 유예를 다시 차감하지 않는다. 체크포인트 복구는 이 상태를
  같은 시점으로 함께 되돌리며, 노드 진입 전으로 복원한 뒤 다시 입장하면 그 시점에서 한 번만 적용한다.
- 최종 보스 승리 보상 확정과 귀환/계속 탐사 선택 상태도 보존한다. 이어하기는 보상이나 격파를
  중복 지급하지 않으며, 승리 후 계속 탐사 중이라는 이유로 원정을 완료 처리하지 않는다.
- 절망의 기사 보호 계약의 승리 횟수·집계한 전투·축복과 도전 상태·보상 지급 여부도 함께 보존한다.
  이어하기는 승리나 보상을 중복 집계하지 않고, 체크포인트는 해당 시점의 진행과 상태를 함께 복원한다.
- 이어하기를 새 런으로 교체할 때 명시적 확인을 받는다. 저장은 런의 자산·진행·상태를 복원하지만
  영구 도감·방 클리어로 확정한 지도 탐사 기록·개인 기록·불러오기 횟수는 되돌리지 않는다.
  난이도용 런 최고 전투력은 차기에서 사용하지 않는다.
- 새 유물의 보유·장착·사본별 침식 상태도 저장 대상이다. 확정 경계에 포함된 침식은 이어하기·재접속에도 유지한다.
  침식 적용 전 체크포인트로 복구하면 소비한 아이템·비용과 변형을 함께 되돌리고, 적용 후라면
  해당 저장 시점의 침식 상태를 유지한다. 일반적인 원정 내 원상복구는 허용하지 않는다.
  선택 파편 형태·후퇴/재접속 상태의 구체적인 저장 구현과 미지원 구형 거절은 [NEXT-10](open-decisions.md#유물과-저장)의 미정 사항이다.
- 전조 풀의 자격·미완료/성공 완료/실패 완료·사용한 후퇴 횟수·배정 노드와 계열별·층별 배정 사용 기록을
  함께 보존한다. 중단 후 이어하기·같은 층 재방문으로 재추첨하거나 이미 소비한 수동 후퇴 기회를 채우지 않는다.
- 백야는 직원별 치료 여부·직원 identity·치료 직전 상태·거짓말 여부·치료 순서·잠복 사도 표식·일시 스탯,
  해당 전조의 치료 인원·의사 퇴장·면류관 발견/보유 상태와 현재 생존 직원 기준 입장 자격을 함께 저장한다.
  치료 회복과 일시 스탯 제거를 구분하며, 보스 진행을 저장하는 경계에서는 문답 질문·답변·오답/정정 상태와
  봉쇄 성과·구속구·억제 작전 진행도 함께 다룬다. 노드 종료 복구에서는 미확정 전투 진행을 남기지 않는다.
- 오케스트라는 서로 다른 심포니 4종의 완료·성공 보상 기록, 단일 파편·강화 형태·공용 충전을 함께 저장한다.
  체크포인트는 전조의 시도·성공 보상·직원 상태·면류관·충전·보스 개방을 같은 시점으로 되돌린다.
  새 원정에서는 이 선행 진행을 초기화하며, 일반 대여 가능한 격파 보상 파편의 보존 정책과 구분한다.
- 원정 시작 때 선택한 황금가지 배치안과 배정 결과도 보존한다. 중단 후 이어하기와 SavePoint 복구로
  배치안을 다시 선택하지 않으며, 가지 획득 여부는 해당 저장 시점의 원정 진행 상태를 따른다.
- 위 복구 기준에 포함된 부화의 환상체·부활 단계·노드 상태와 알·촉매제 소비는 함께 보존한다.
  복구 기준에 포함된 부화는 도망 후 재개해도 비용을 다시 청구하지 않는다.
  복구 기준 뒤 미확정 노드에서 수행한 부화라면 위 종료 복구 규칙대로 소비와 조우를 함께 되돌린다.
  부화 전의 SavePoint로 복구하면 부화한 조우를 제거하고 원래 노드·알·촉매제를 함께 복원한다.
  부화 후의 SavePoint로 복구하면 해당 저장 시점의 조우·단계·소비 상태를 유지한다.
  부화 화면에서 직접 소비한 창고 촉매제도 같은 소비·결과 동시 복원 원칙을 적용한다.
- 개화·부화·유물 침식과 그 후속 보상 등 체크포인트 이후의 원정 상태는 소비와 결과를 한 번에 복원한다.
  재료만 반환하고 결과를 남기거나, 결과만 되돌리고 재료를 잃게 하지 않는다. 복원은 원래 소비 출처를 따르며
  소지 재료와 창고 재료를 이중 지급하지 않는다. 미확정 노드 종료 복구에도 같은 소비·결과 동시 복원 원칙을 적용한다.

새 억제력·귀환 선택·봉인/황금가지·방 클리어/탐사 기록·대여·재료 창고·알/격파 단계와 중단 저장은
위 합의된 복원 원칙을 따른다. 미결 세부와 새 지원 저장 형식의 구현·미지원 구형 거절 검증은 NEXT-10·16~19에서
다룬다. 현재 체크포인트로 이미 안전하게 복구되는 구현 상태라고 가정하지 않는다.

현재 V4 형식의 검증·오류 거절·난수와 identity 복원·파일 게시 순서는
[런타임 계약](../core_runtime_contract.md)이 소유한다. 위 목표가 기존 저장 형식에 구현됐다고 보지 않는다.

### 차기 규칙 전환의 구저장 지원 범위 — 2026-10-04

기존 저장은 개발·테스트용이라는 사용자 결정에 따라, 차기 원정 규칙에서는 새 게임으로 시작한다.
구형 active run/profile의 변환·호환은 필수 구현에서 제외한다. 미지원 형식은 원본을 보존하고 명시 안내하며,
자동 삭제·덮어쓰기·필드 무시로 새 형식처럼 읽지 않는다. 새로 지원하는 형식의 중단 저장·이어하기·SavePoint와
쓰기 장애 복구는 계속 필수다. 위 본문의 옛 저장 이행 언급은 현재 구현 비교 자료이며 새 필수 변환 목표가 아니다.
현재 취소 결함 교정 등 전환 전 작업에서 기존 reader를 즉시 제거하라는 뜻도 아니다.

## 영구 도감과 기록

현행 비교 기준의 런 밖 profile에는 도감, 튜토리얼 완료/Endless 해금, 기념용 개인 기록을 보존한다.
현행의 직원·장비·재화·파편·유물·격파·숙달·모노리스·pool은 해당 런에만 속한다.
차기 설계는 위의 회수품 반납·대여와 개화 보존, 선택 회수한 재료의 공용 창고,
방 클리어에 따른 영구 탐사 기록을 추가한다. 알은 영구 저장 대상이 아니다.
해당 방을 클리어하면 그 방의 고정 정보를 영구 기록하며, 생환 여부와 무관하게 다음 원정에도 공개한다.
클리어로 확정한 기록은 원정 실패·체크포인트 복구로 지우지 않는다. 단순 방문이나 미리보기만으로는
해당 방의 영구 정보 공개를 확정하지 않는다. 일반 방은 Gate를 통해 다음 방으로 이동하거나 귀환할 때,
최종보스 방은 최종 보스 격파 시 클리어와 기록을 확정한다. Gate 이용 전 억제력 소진으로 귀환하면
현재 방의 신규 클리어 기록은 만들지 않는다. 자세한 기준은 [방 클리어와 탐사 기록](run-and-map.md#전체-지도-가시성과-탐사-기록)을 따른다.
이 기록은 일반 경로의 영구 해금 상태가 아니며, 원정마다 바뀌는 노드 구성·상품·보상·황금가지 배정을
다음 원정으로 계승하지 않는다. 최종 보스 방·진입 연결의 개방은 이번 원정의 보스별 선행 조건
달성 시 확정하며 영구 기록으로 보존하지 않는다. 격파·클리어 기록이 있어도 새 원정에서는 부분
진행과 개방 상태를 초기화하고 처음부터 다시 진행한다. 중단 후 이어하기는 확정 진행을 유지하고 미확정 노드는 입장 전으로 복원하며,
체크포인트 복구는 전조 풀·치료 기록·표식·면류관·심포니 충전과 개방 상태를 같은 시점으로 함께 복원한다.
영구 도감·탐사 정보·격파 기록은 유지하지만 이번 원정의 선행 조건을 자동 충족시키지 않는다.
영구 기록으로 알려진 보스 방은 위치·보스 정보를 공개하고 이번 원정의 조건 전까지 잠금 표시한다.
그 밖의 비밀 발견 기록은 NEXT-19에서 정한다.
다른 자산·조우 진행까지 자동 계승하지 않으며, 구체적인 영구 저장 형식은 NEXT-10·16에서 정한다.

차기의 **백야·고요한 오케스트라·종말새 격파 기록은 보스별로 원정 간 누적 보존**한다.
각 보스의 승리 판정 즉시 해당 기록을 확정·저장하며 새 원정·실패·체크포인트 복구로 지우지 않는다.
세 보스를 각각 한 번 이상 격파한 뒤 현재 원정의 마탄 호위·생존 조우를 완료하면 마탄 옆 같은 층의
흉탄 방과 직접 연결을 개방한다. 과거 마탄 목격 기록을 추가 필수 조건으로 요구하지 않는다.
새 원정마다 마탄 조우 완료가 다시 필요하며, 영구 격파 기록 자체로 물품·재화를 지급하지 않는다.
[흉탄 접근과 반복 조우](run-and-map.md#보스-분류와-연속-조우)

차기에는 튜토리얼·원정만 제공하고 튜토리얼이 원정 자산이나 영구 탐사·격파 기록을 변경하지 않는다.
첫 성공 귀환 VN의 재생 이력은 원정의 영구 진행으로 별도 보존한다. 아래 옛 모드 기록은 이행 비교 자료다.

- 도감은 **승리한 시도에서 실제 출현한** 적군 환상체·침식 직원 profile을 등록한다.
  해당 적의 사망·생존·주 환상체 여부·개별 처치 credit은 묻지 않는다.
- 미리보기·아직 출현하지 않은 웨이브·소환물은 후보가 아니고 패배·후퇴·프로세스 종료는
  등록하지 않는다. 승리 확정 때 후보 전체를 영구 집합에 더한다.
- 등록한 ID는 체크포인트·새 런·실패·일반 처리 rollback으로 지우지 않는다.
  현재 catalog에 없는 ID도 보존하고 화면에서는 숨긴다. 미등록은 `???`, 등록 항목만 정보를 보여준다.
- 현행 비교 기준의 Standard 3층 보스 승리 확정이 튜토리얼 해금 플래그를 남긴다. Endless의 최고 도달 방,
  최장 무사망 연속 방, 한 런의 모든 일반 FinalBoss chain 완료는 기념 기록이다.
- 수치 최고 기록은 달성 즉시, 모든 최종 보스 기록은 당시 비어 있지 않은 production chain 목록을
  전부 완료했을 때 보존한다. reference는 제외하고 이후 보스 추가로 기존 달성을 취소하지 않는다.
- 위 현행 기념용 기록은 능력·물품·재화·파편·콘텐츠 해금을 지급하지 않는다. 차기의 지정 세 보스
  격파 기록은 앞서 명시한 흉탄 접근 자격에 사용한다. title에서 확인한 전체 profile 초기화만
  도감·튜토리얼 해금·기록을 지운다. 옛 모드 기록은 차기 저장 호환 대상이 아니며, NEXT-01·10에서 명시 거절을 검증한다.

## Psychology

신뢰·기억은 해당 원정의 수감자 개인에게 속한다. 원정 종료 후에는 위의 처분 정책에 따라
다음 원정의 새로운 인원에게 계승하지 않는다. 아래 수치와 작동은 현행 비교 기준이다.

직원의 고정 성격과 런 안의 신뢰·기억은 별개다. 신뢰는 -100~100이며 다음 band를 사용한다.

| band | 범위 |
| --- | --- |
| Distrust | -100~-51 |
| Uneasy | -50~-11 |
| Neutral | -10~25 |
| Trusting | 26~70 |
| Devoted | 71~100 |

현재 production에서 신뢰를 바꾸는 경로는 없다. SavePoint/Gate의 트라우마 회복은 신뢰·기억·
최근 사건을 생산하지 않는다. 같은 종류/대상의 기억은 합치고 기간이 있으면 노드 완료마다 줄인다.
최근 반응은 최대 8개다. 직원 기록·체크포인트·후퇴에 보존하며 사망해도 남는다.
신뢰 기반 명령 거부·전투 보정·대사·표정은 아직 확정 gameplay 규칙이 아니다.
