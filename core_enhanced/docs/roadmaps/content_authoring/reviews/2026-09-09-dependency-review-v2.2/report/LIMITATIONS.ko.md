# 확인 수준·미검토·조건·재개 위치

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

아래 제한은 해당 범위에만 적용한다. 일부 미정/미검토를 이유로 모든 코드 관찰이나 원래 M0 성과를 무효화하지 않는다. 반대로 조사한 관계/문서가 있다는 이유로 게임 구현·전체 콘텐츠·독립 감사가 완료됐다고 말하지 않는다.

## L01 — 실제 게임/컴파일/회귀/성능 시험 미실행

**영향 범위:** 모든 runtime 완료·GEX 자격.

**근거/현재 상태:** 연결 도구는 read/search/status/history 전용이며 새 명령 실행 기능이 없다. 과거 PASS는 기존 증거로만 인수했다.

**정확한 재개 방향:** 각 R의 owner가 승인된 구현 범위에서 actual nonzero 결과/exit/revision을 남긴다.

## L02 — dirty 전체 snapshot/hash 미확보

**영향 범위:** 조사 전체의 원자적 현재성.

**근거/현재 상태:** 브랜치/HEAD/dirty, 읽은 구간·앵커와 일부 Git blob ID만 식별했다. 앵커 SHA256은 전체 파일 해시가 아니다.

**정확한 재개 방향:** 적용/구현 인수 시 영향 경로 내용을 다시 비교한다. 새 변경이 있으면 해당 판단만 다시 검토한다.

## L03 — 354 COV/127 BOSS-COV의 fresh 행별 전수 재검증 아님

**영향 범위:** 전체 개별 콘텐츠 표현력의 완료 주장.

**근거/현재 상태:** 기존 CA00 기준선의 구조·출처·일부 head/footer 및 원문 주요 정책을 인수했다. 게임 기능별 실제 전체 row 증거는 없다.

**정확한 재개 방향:** S078 원본 requirements/boss coverage의 각 owner_ca를 M_CA_MAPPING에 연결해 유지하고 R21의 전체 표현력 대조에서 닫는다.

## L04 — R17 정밀 line-crossing/geometry 알고리즘 미검토

**영향 범위:** 선 통과 판정의 정밀도·성능·exact tie-break.

**근거/현재 상태:** 관계/source/소비/수명 선행은 조사했으나 spatial/movement 전체 연속 본문과 geometry 시험까지 확장하지 않았다.

**정확한 재개 방향:** core/battle spatial 및 movement의 segment crossing 생산자/소비자와 R17의 object epoch/tie-break를 추가 확인한다.

## L05 — 미정 정책은 family-local 조건

**영향 범위:** 침식 실제 시전 경계·합류/root·공유/개인 방어·공식 수치/평가.

**근거/현재 상태:** 승인된 의미를 보존했지만 보고서가 threshold/방어순서/획득량/가중을 결정하지 않는다.

**정확한 재개 방향:** POLICY_GATES의 exact family/owner에서 확정. 독립 단위는 지정 조건부 분기로 계속 가능하다.

## L06 — 보스 상세 콘텐츠·도구형 9종은 baseline 인수

**영향 범위:** 개별 content authored 완성도.

**근거/현재 상태:** 보스 raw/compiler/runtime와 대표 경계는 확인했다. 3266줄 전체를 이번에 다시 읽거나 모든 공식 능력을 검증하지 않았다.

**정확한 재개 방향:** C01–C07 실제 이식과 별개 전체 boss-COV/도구 scope disposition을 유지. 도구 command/획득 신규범위는 사용자 owner.

## L07 — 원본 개별 CA markdown 카드 전량 독립 재독 아님

**영향 범위:** 원본 카드에만 존재할 수 있는 추가 문구.

**근거/현재 상태:** 원본 GOALS.json 946줄 전체, ROADMAP/DEP/K/PG/T/C 및 A01–A08을 읽었다. 목표/선행의 주 기준은 이 원본들이다.

**정확한 재개 방향:** 원본 별도 카드와 JSON의 기존 불일치가 발견되면 그 행만 보존·수정 owner로 환류; 이를 현재 정식 정책으로 임의승격하지 않는다.

## L08 — 외부 consumer·독립 감사·업로드 미수행

**영향 범위:** 서버/Unity/실제 배포·independent review.

**근거/현재 상태:** 코어 측 projection/저장/소비 영향만 기록했다. 독립 reviewer나 제3자 작성자 참여가 없었다. 로컬 산출물이며 저장소 미반영이다.

**정확한 재개 방향:** 별도 권한/범위의 후속 작업. 본 문서 검사를 GEX 독립 감사로 세지 않는다.

## L09 — 특정 오래된 문서/기존 소스의 극단 경계는 한정 확인

**영향 범위:** 저장 V4 문구·log sequence exhaustion 전체 영향.

**근거/현재 상태:** 구체 불일치와 해당 실제 body는 확인했으나 이를 현 세션에서 수정/회귀 검증하지 않았다.

**정확한 재개 방향:** F07/F21의 지정 owner와 입력으로 확인하고 무관한 최소 Goal까지 범위를 확대하지 않는다.
