# 다른 AI에게 전달하는 방법

이 묶음은 simulator의 전체 코드 의존성 조사와 로드맵 재설계를 이어 맡기기 위한 문서다. 프로젝트 소스 코드는 포함하지 않는다.

## 사용

HANDOFF_PROMPT.ko.md 내용을 새 AI의 사용자 요청으로 전달한다. 원 요청문과 RESUME_CHECKPOINT.ko.md도 함께 첨부한다. 해당 AI가 simulator 작업공간에 접근할 수 있도록 연결하거나, 현재 미커밋 변경을 포함한 검토 대상 사본을 별도로 제공해야 한다.

## 포함 파일

- HANDOFF_PROMPT.ko.md: 전체 검토·개정 작업을 맡기는 인수인계 프롬프트.
- 붙여넣은 텍스트 (1).txt: 기존 사용자 요청문 원본의 바이트 그대로인 사본.
- RESUME_CHECKPOINT.ko.md: 이전 재개 체크포인트 원본의 바이트 그대로인 사본.

체크포인트는 과거 탐색 단서와 중단 보고다. 현재 코드 검증, 현재 도구 장애, 전체 검토 완료, 구현 승인 또는 테스트 PASS의 근거가 아니다. 최신 상태는 제공된 작업공간에서 확인해야 한다. 이 패키지를 만드는 과정에서 프로젝트 연결에 대한 새로운 조회·코드 검토·게임 테스트·로드맵 개정·GEX 실행을 수행한 것은 아니다.

원 요청의 세부 요구와 함께 읽고, 기존 저장소의 정식 정책·Plan·Goal·Handoff 원본을 이 문서로 대체하지 않는다. 기존 sandbox 경로가 다른 AI 환경에도 존재한다고 가정하지 않는다.
