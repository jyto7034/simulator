## 3. 동반 전환 범위

선행에서 이미 실행한 최소RON prototype을 최신 외부 공식pack에 통합 + source→compiled→runtime→result trace + 두보스/장비/무기/파편/유물 + inherited모든COV재대조.

이 카드가 소비하는 선행 atomic group은 이미 유효해야 한다. 통합 검증 카드는 새 상태 저장을 처음 도입하는 자리가 아니다.

## 5. 직후 유효 상태

정해진 대표구조가 실제RON으로 실행되고 전체baseline의 누락/정책대기 상태도 별도로 드러남.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
