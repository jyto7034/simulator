# R08 — 보스 최소 스킬 요청·완료·실패·취소·방향 adapter

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA16. 기본 순서 번호: 8. 현재 상태: `proposed_not_implemented`.

## 1. 목적과 먼저 필요한 설계

K04 닫힌 TaskRequest/ActionHandle/결과 mapping; K09 보스 task authority와 wave 분리.

## 2. 구현 선행과 검증 선행

기능상 선행: [R01](R01.ko.md), [R04](R04.ko.md).

검증 선행: 없음.

진행상 권장: [R07](R07.ko.md).

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

BossTask raw/compile/admission/result mapping + 공통 내부 ActionService adapter + facing/target + state-owned cancel/timeout + RON 보스 fixture.

최소 동시 전환 묶음: AT08. 서로 다른 atomic group이나 한 카드의 여러 기능을 모두 단일 runtime transaction으로 합치라는 뜻은 아니다.

## 4. 재사용·교체·제거

**재사용:** 기존 compiled phase/behavior/pattern/state/task graph·task activation·boss boundary clone/commit.

**교체·제거 방향:** RouteCombat 자동 행동만 가능한 경계에 명시 호출 adapter 추가. 보스별 전용 executor나 스킬 VM에 보스 전체 흡수 금지.

## 5. 직후 유효 상태

기존 보스 graph가 현재 지원 스킬을 명시적으로 요청하고 release/settled를 선택해 기다린다. 설치물·공유 shield·전체 Flow 없이도 정상·실패 route가 유효.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
