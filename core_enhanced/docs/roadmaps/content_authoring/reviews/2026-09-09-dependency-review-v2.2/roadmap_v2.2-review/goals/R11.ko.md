# R11 — 가역 modifier·membership·channel·기본 공격 교체

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA08. 기본 순서 번호: 11. 현재 상태: `proposed_not_implemented`.

## 1. 목적과 먼저 필요한 설계

K05 source handle/lease; K04 natural/reinput/cancel; 공격·이동·저지 lock 소유.

## 2. 구현 선행과 검증 선행

기능상 선행: [R05](R05.ko.md), [R06](R06.ko.md), [R10](R10.ko.md).

검증 선행: 없음.

진행상 권장: 없음.

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

ModifierLedger·AuraMembership·ChannelActivation·BasicAttackOverlay + source-local 제거 + reinput 비용/remaining time + 일반 기본 공격 방향/관통/범위 전달 + snapshot/퇴장/회귀 tests.

최소 동시 전환 묶음: AT11. 서로 다른 atomic group이나 한 카드의 여러 기능을 모두 단일 runtime transaction으로 합치라는 뜻은 아니다.

## 4. 재사용·교체·제거

**재사용:** 기본 공격 start/release/recovery·기존 stat pipeline·R05 lease.

**교체·제거 방향:** 직접 stat mutation을 지속 효과의 owner없는 복구 수단으로 쓰지 않음.

## 5. 직후 유효 상태

오라 진입/이탈·집중 종료가 자기 modifier만 제거하고, Hello natural expiry는 복귀만 하며 재입력은 Goodbye 후 복귀.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
