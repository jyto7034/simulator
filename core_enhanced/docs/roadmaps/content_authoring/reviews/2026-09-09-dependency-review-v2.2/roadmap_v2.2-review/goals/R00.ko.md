## 2. 구현 선행과 검증 선행

검증 선행: 없음.

## 3. 동반 전환 범위

문서만: 기존 원본은 보존. 본 연구의 코드 근거·CA 대응·old edge disposition을 별도 배포.

## 4. 재사용·교체·제거

**재사용:** CA00 요구·COV와 CA01 검토·Freeze·Plan·Goal·Handoff.

**교체·제거 방향:** 기존 문서/ID 변경 없음. 연구용 후보 순서만 새 경로에 작성.

## 5. 직후 유효 상태

기존 CA00와 CA01 P2G-60 성과가 인수되고 최소 Goal은 계속 미활성 상태.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
