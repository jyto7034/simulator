이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA01, CA07, CA22. 기본 순서 번호: 10. 현재 상태: `proposed_not_implemented`.

## 2. 구현 선행과 검증 선행

검증 선행: 없음.

진행상 권장: [R09](R09.ko.md).

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

Sequence/Branch/Parallel/유한Repeat + result slot/상대지연/중단 + target/anchor/origin/방향/retarget + Instant/Projectile/Area adapter + ActionHandle 호환 + RON/runtime/readiness/preview/예산 검사.

최소 동시 전환 묶음: AT10. 서로 다른 atomic group이나 한 카드의 여러 기능을 모두 단일 runtime transaction으로 합치라는 뜻은 아니다.

## 4. 재사용·교체·제거

**재사용:** 현재 current cast/delivery kernels·R04 handle·R06 식.

**교체·제거 방향:** offset 목록만으로 표현 불가한 flow를 새 구조로 전환하되 지원하지 않는 combination은 compile 거부.

## 5. 직후 유효 상태

AoE 피해 뒤 자기 회복 한 번, 결과 조건·유한 기회 반복·병행 join이 실제 실행된다. 기존 최소 주소와 보스 adapter가 같은 service를 소비.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
