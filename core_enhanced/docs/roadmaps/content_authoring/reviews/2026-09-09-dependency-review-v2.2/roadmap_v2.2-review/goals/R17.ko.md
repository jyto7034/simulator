# R17 — 연결망·원천별 감염·공간 집계/일제 소비

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA15, CA12. 기본 순서 번호: 17. 현재 상태: `proposed_not_implemented`.

## 1. 목적과 먼저 필요한 설계

K05 source membership/resource; K08 전파transaction/fork/join; 공간 tie-break/소비정책.

## 2. 구현 선행과 검증 선행

기능상 선행: [R06](R06.ko.md), [R13](R13.ko.md), [R16](R16.ko.md).

검증 선행: 없음.

진행상 권장: 없음.

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

RelationStore node/edge·접근/선 통과 사건 + object진화/delete invalidation + source-scoped status/자원 집계 + tile group-by + 전파/기폭 suppression + composer등록/예산/RON.

이 카드가 소비하는 선행 atomic group은 이미 유효해야 한다. 통합 검증 카드는 새 상태 저장을 처음 도입하는 자리가 아니다.

## 4. 재사용·교체·제거

**재사용:** 현재 spatial/area query와 R13 object/R16chain 기반.

**교체·제거 방향:** global감염망·콘텐츠명분기·무제한node재귀 금지.

## 5. 직후 유효 상태

연결 node와 감염 원천이 분리되고 타일별 상태·유닛값을 명시 단위로 집계한다.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.

## 7. 조건·미정·범위

정책 gate: PG02, PG03, PG04, PG05, PG06.

공간 line-crossing의 전체 구현/성능 경계는 이번에 연속 본문을 확보하지 못했다. 데이터모델·source/transaction 의존성은 판정했으나 정밀 geometry/tie-break는 아래 한계표에 남긴다. 원문 전파/소비 범위 미정은 임의확정하지 않는다.
