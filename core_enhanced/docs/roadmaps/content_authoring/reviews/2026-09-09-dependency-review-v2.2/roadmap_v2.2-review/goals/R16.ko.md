# R16 — 반응형 연쇄·branch-local 재방문·비동기 인과

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA13. 기본 순서 번호: 16. 현재 상태: `proposed_not_implemented`.

## 1. 목적과 먼저 필요한 설계

K08 root/fork/join/visited(copy,effect); K06 dispatch/suppression; 합성closure와 실행chain 별개.

## 2. 구현 선행과 검증 선행

기능상 선행: [R04](R04.ko.md), [R05](R05.ko.md), [R14](R14.ko.md), [R15](R15.ko.md).

검증 선행: 없음.

진행상 권장: 없음.

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

event subscription/queue dispatcher + branch ancestry + copy/effect visited + timer/projectile/area/후속생성 context + fanout budget + log 독립 상태회수 + 침식 suppression 인수.

최소 동시 전환 묶음: AT15. 서로 다른 atomic group이나 한 카드의 여러 기능을 모두 단일 runtime transaction으로 합치라는 뜻은 아니다.

## 4. 재사용·교체·제거

**재사용:** 현재 occurrence/proc-source 정렬·R04receipt·R14소유출처.

**교체·제거 방향:** presentation parentseq만으로 연쇄 권한을 추적하는 대체 금지.

## 5. 직후 유효 상태

A1.e→B1.e→A1.e만 차단하고 다른 사본/효과/독립공격은 허용. 지연시켜도 동일 인과 경로는 유지.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
