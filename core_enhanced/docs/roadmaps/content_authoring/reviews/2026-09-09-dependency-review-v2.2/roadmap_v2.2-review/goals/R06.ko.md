# R06 — ValueExpr·집계·Attack/SpellPower와 무기 성장

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA05, CA10, CA17. 기본 순서 번호: 6. 현재 상태: `proposed_not_implemented`.

## 1. 목적과 먼저 필요한 설계

K02 유한 typed 식; K05 resource 참조; K06 result 참조; snapshot/live·단위·산술·평가 포트.

## 2. 구현 선행과 검증 선행

기능상 선행: [R01](R01.ko.md), [R04](R04.ko.md), [R05](R05.ko.md).

검증 선행: 없음.

진행상 권장: 없음.

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

식 compiler/evaluator·Attack/SpellPower stat·weapon 성장/프로필 조립·공격속도 point↔interval·영구 enhancement 저장 검증·preview/explain/Certified 입력 계약·RON 시험.

최소 동시 전환 묶음: AT06. 서로 다른 atomic group이나 한 카드의 여러 기능을 모두 단일 runtime transaction으로 합치라는 뜻은 아니다.

## 4. 재사용·교체·제거

**재사용:** stat_pipeline·scale_attack_interval_ms·기존 enhancement 소유/저장.

**교체·제거 방향:** 고정 literal만 있는 새 효과량 표현을 typed 식으로 확장. 기존 모든 Percent를 한 수학으로 통일하지 않음.

## 5. 직후 유효 상태

상수/stat/HP/시간/resource/result 식과 유한 count/sum/max를 실행한다. 무기 성장의 각 입력은 한 번만 합산된다. 파편 구형 rank 제거는 R07까지 기존 동작을 보존.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
