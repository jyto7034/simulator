# R12 — 개인/공유 보호막·생존·제어·HP 비용 중재

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA09. 기본 순서 번호: 12. 현재 상태: `proposed_not_implemented`.

## 1. 목적과 먼저 필요한 설계

K06 mitigation→absorption→HP; K05 pool/membership; parry/HP1/cost 우선순위.

## 2. 구현 선행과 검증 선행

기능상 선행: [R04](R04.ko.md), [R05](R05.ko.md), [R06](R06.ko.md), [R11](R11.ko.md).

검증 선행: 없음.

진행상 권장: 없음.

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

공용 pool/source와 membership + 피해 중재 결과/흡수/초과HP + control별 behavior/movement + parry/survival/HP cost + 생명/시간 종료 단일화 + RON/test.

최소 동시 전환 묶음: AT12. 서로 다른 atomic group이나 한 카드의 여러 기능을 모두 단일 runtime transaction으로 합치라는 뜻은 아니다.

## 4. 재사용·교체·제거

**재사용:** 기존 damage reduction·control/movement·R05 resource/R11 membership.

**교체·제거 방향:** MaxHP 증가를 shield로, 모든 control을 Stun으로, 거대damage를 처형으로 쓰는 대체 금지.

## 5. 직후 유효 상태

여러 대상은 하나의 잔량만 공유하며 피해·회복·충전·HP 비용의 사건 의미가 분리됨.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
