# R01 — 효과 주소·태그·typed property 최소 전환 — 현 GOAL 유지

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA01, CA02. 기본 순서 번호: 1. 현재 상태: `formal_authored_not_activated`.

정식 대상은 기존 **GS-CAMEC-P2G50-001 / GOAL-CAMEC-01** 그대로다. 여기의 R01은 그 대상에 대한 로드맵 대응 ID이며 새 Goal ID가 아니다.

## 1. 목적과 먼저 필요한 설계

K01 정의 주소 ≠ compiled index ≠ 사본/시전; K02 literal Damage/Heal/Instant 지원; K10 SourceMap.

## 2. 구현 선행과 검증 선행

기능상 선행: 없음.

검증 선행: [R00](R00.ko.md).

진행상 권장: 없음.

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

WP-CAMEC-01 compiler/descriptor/locator + WP-CAMEC-02 최신 RON/catalog·직접 runtime consumer를 AG-CAMEC-01로 동시 전환. WP-CAMEC-03 durable 시험은 같은 Single Goal이 소유.

최소 동시 전환 묶음: AT01. 서로 다른 atomic group이나 한 카드의 여러 기능을 모두 단일 runtime transaction으로 합치라는 뜻은 아니다.

## 4. 재사용·교체·제거

**재사용:** 기존 SkillId·계산·Instant/Projectile/Area kernel·ValidatedGameData 게시·현재 P2G 성과.

**교체·제거 방향:** 현재 AST→consumer를 필요한 metadata 주소에 연결하되 전투 의미·V4 reader를 제거하지 않음.

## 5. 직후 유효 상태

기존 embedded 검증 로딩과 Damage/Heal 실행에 효과별 주소·지원 정보·진단이 붙는다. 개인별 합성·외부 팩·새 저장은 아직 약속하지 않음.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.

## 6. 검증 owner·입력·기대 결과

| 항목 | 내용 |

| 구현·자체 검증 owner | R01 |
