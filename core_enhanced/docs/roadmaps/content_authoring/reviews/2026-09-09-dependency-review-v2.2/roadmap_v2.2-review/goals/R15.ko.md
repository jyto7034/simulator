# R15 — 유한 활성 closure·생성 효과·구조 recipe

**2.2-review.1 · 2026-09-09 · 조사·개정 권고 / 저장소 미적용 / 게임 구현·Goal 실행 미승인**

이 문서는 **로드맵 작업 카드**다. 정식 P2G Goal 또는 GEX activation이 아니다. 기존 CA 대응: CA12. 기본 순서 번호: 15. 현재 상태: `proposed_not_implemented`.

## 1. 목적과 먼저 필요한 설계

K07 긍정 최소 closure/negative cycle/typed write set/preserve set; effect≠carrier.

## 2. 구현 선행과 검증 선행

기능상 선행: [R11](R11.ko.md), [R12](R12.ko.md), [R14](R14.ko.md).

검증 선행: 없음.

진행상 권장: 없음.

이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

selector/tag/property + 비순환 유한 non-reactive grant + activation/dormancy + Add/Scale/Replace 단계 + 구조 변환 recipe + 최종 graph 재검증/SourceMap/explain/caching.

이 카드가 소비하는 선행 atomic group은 이미 유효해야 한다. 통합 검증 카드는 새 상태 저장을 처음 도입하는 자리가 아니다.

## 4. 재사용·교체·제거

**재사용:** R14 immutable plan/selector·R11membership/R12pool.

**교체·제거 방향:** 일반 문자열 patch·last-writer-wins·태그 파편합집합 매칭 금지.

## 5. 직후 유효 상태

새로 부여한 효과도 다른 유물 선택 대상이 되며 같은 장착 집합은 같은 plan. 포큐버스 단일2S·태아 상태별 전환이 각 계약대로 작동.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
