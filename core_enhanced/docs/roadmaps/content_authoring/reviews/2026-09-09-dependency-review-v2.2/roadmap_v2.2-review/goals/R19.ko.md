이 목록은 선행 단위 전체의 모든 기능을 요구하는 것이 아니다. [관계별 producer output와 consumer](../DEPENDENCIES.ko.md)가 필요한 최소 계약을 특정한다. 기본 순서는 별도로 보수적인 순차 진행을 택했다.

## 3. 동반 전환 범위

abnormality/reward-source/encounter/progression/claim normal transaction + 복수fragment identity/선택 payload + shop/grant/룰profile + Certified평가model version/cache/fingerprint + domain E2E.

## 4. 재사용·교체·제거

**재사용:** 기존 EconomyGrantState·encounter progression·Certified sort/profile.

**교체·제거 방향:** catalog hardcoded count/onefragment 연결의 목표와충돌하는 부분만 전환; 무관경제전면재작성 금지.

## 5. 직후 유효 상태

새 보스 등장→전투→정상보상→장착/저장과 공식교체가 연결. 단일source fragment 가정을 최신 승인정책으로 전환한다.

다음 단계를 전혀 수행하지 않아도 이 약속이 충족되어야 한다. 미지원 후속 기능은 publication/descriptor에 명시하고 빈 executor·임시 성공·조용한 fallback으로 완료하지 않는다.
