# Core 우선 로드맵 검토 종합 결과

**현재 실행 순서는 유지하는 편이 좋다.** Core의 규칙·원정·제작 기반을 먼저 완성하고 Unity를 처음 연결하는 방향은 일관돼 있다. 검토한 34개 활성 카드에서 전체 순서를 다시 짜야 할 근거는 확인하지 못했다. 보완 우선순위는 현재 상태 안내와 단계 사이의 인계, 지도 예약과 전조의 연결, 후속 Unity의 활성 전투 콘텐츠 구현 책임이다.

2026-10-12 사용자 요청에 따라 검토 중 메모를 누적하고 각 카드 종료 시 결과를 따로 작성했다. [단계별 결과 색인](README.ko.md), [누적 메모](NOTES.ko.md), [발견 사항 상세](FINDINGS.ko.md)를 함께 볼 수 있다.

## 검토 범위

로드맵의 목표·요구 배정·의존성·34개 카드·저장/검증 책임·Core/Unity 인수·기존 요구 대응·콘텐츠 목록을 대조했다. 최신 룰북과 관련 상세 규칙, U12의 최신 정책/코드 검토/실행 계획을 읽었고, 의심되는 채용·회복 가능성 경계는 현재 코드의 해당 함수까지 확인했다.

이는 **로드맵의 범위·순서·계약 검토**다. 일반13·엘리트11·도구9의 모든 콘텐츠 원문과 실제 구현을 전종 감사한 것은 아니며, 기존 완료 단계를 재감사하거나 제품 시험·Unity 실행을 수행하지 않았다. 구현 중인 U12의 실제 완료 상태도 새로 판정하지 않았다. 입력 기준은 [INPUTS](INPUTS.json)에 남겼으며, 후속 구현이 진행되면 해당 owner 문서의 최신 상태를 다시 인수한다.

## 유지할 구조

**U00–U11의 기반 순서.** 취소·실행 한도/오류·결과와 저장·공명·기본 전투·생성/유물·실제 mod 적용의 생산자와 소비자가 연결돼 있다. 완료된 기반을 이번 검토 때문에 다시 개발하거나 감사할 이유는 없다. 새 기능이 실제로 변경하는 경로만 관련 증거를 갱신한다.

**U12–U17의 원정 확장.** U12는 유효한 기존 지도/튜토리얼 실행기에 최소 실제 원정과 귀환을 붙인다. U13 전체 지도와 U14 전체 억제력, U15 재료 창고를 한꺼번에 선행시키는 구조가 아니다. 상세 계획을 읽기 전 의심했던 순환은 해소했다. 후속 인계가 명확하면 현재 순서를 유지할 수 있다.

**U18–U21의 공통 기능과 콘텐츠 구분.** 관계/감염·공통 보스 표현력을 먼저 만들고 정상 등장·획득과 고유 콘텐츠를 이어가는 방식이 타당하다. U21은 이미 실제 불가분 묶음으로 상세화하도록 돼 있다. 추가 범용 엔진이나 거대한 콘텐츠 Goal을 새로 요구하지 않는다. 최종보스 본체 제외와 공통 기능 유지, 독립 보상 실행과 실전 획득 제외도 구분돼 있다.

**Core 검증 여섯 단계의 목적 분리.** U27은 지원/획득, U28은 교차 저장, U29는 독립 외부 제작, U30-C는 기술 성능, U32는 원정 종단, U33은 독립 인수다. 단순히 검사 단계가 많다는 이유로 합치기보다 각 단계가 새로 입증할 주장만 확인해야 한다. 기존 §6.3/6.4/8.7의 증거 재사용 규칙은 충분한 출발점이다. 실제 과거 검증 비용의 과잉을 측정한 결과는 아니다.

**Unity 후속 원칙.** U26-A/B/C는 새 클라이언트·전투·원정·모드·복구 화면을 처음 구현한다. Core 앞에 작은 Unity 프로젝트를 추가하는 제안은 하지 않는다. 후속 화면이 규칙을 복제하지 않도록 명령·조회·선택/거절 상태와 실제 소비 책임을 인수하는 것이 핵심이다.

## 단계 종료 시 인계에 필요한 내용

별도 관리 시스템을 만들 필요는 없다. 기존 완료 인수/계획에 다음 네 가지를 짧게 연결하면 된다.

- 이번 단계에서 실제로 가능한 정상 행동과 그 명령·조회·저장 근거.
- 후속 단계가 재사용할 identity·자격·확정/복원 계약과 바꿔야 할 부분.
- 유지되는 이전 의미·미지원·실제 미정 및 그 담당 단계.
- 새로 검증한 경계와 재사용한 증거, 현재 적용성에 영향을 주는 변경.

상세 함수명·후반 schema·Unity 클래스·최종 수치를 지금 모두 고정하지 않는다. 기술 상세는 각 단계 착수 때 현재 코드로 좁히고, 게임 의미가 실제로 미정인 항목만 별도로 결정한다.

## 검토 기록의 종료

34개 카드의 단계별 검토는 모두 종료했다. F01–F06의 권고 반영과 기능 구현·검증은 수행하지 않았으며, 이 문서가 기존 실행 순서나 완료 판정을 변경하지 않는다. 원본 정책·로드맵·동결 증거와 누적 개발 변경은 그대로 둔다.
