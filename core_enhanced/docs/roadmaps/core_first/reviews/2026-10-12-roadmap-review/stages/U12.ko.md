# U12 튜토리얼과 원정 수명 검토 결과

검토 종료: 2026-10-12. 판단: **인계 보완 필요**. 제품 구현 완료 판정과 별개다.

## 판단

최신 상세 계획의 최소 실제 원정·유료 채용·입장 소진과 귀환을 인수하면 현재 순서는 성립한다. 튜토리얼·원정 격리, 새 직원 identity, 대여 사본 단일 소유, 기억·신뢰 제거를 같은 수명 전환에서 처리하는 이유도 설명돼 있다.

## 발견과 후속 경계

F02. 로드맵은 채용을 U16, 비용을 U14로 크게 나누지만 U12 상세 계획은 실제 유료 채용·최소 소진을 이미 도입한다. 후속 단계가 무엇을 인수하고 무엇만 확장할지 명시해야 한다. 단순 순환 의심은 상세 계획 확인 후 해소했다.

## 권고와 확인 기준

U12 완료 인수에 기존 지도 profile/채용 eligibility/first-entry receipt/귀환 cause/terminal 저장·검증 경로를 연결하고 U13/U14/U16이 이를 소비하도록 한다. 기존 튜토리얼 포팅 합의를 다시 묻거나 U19 전체를 선행시키지 않는다.
