# U21 공식 콘텐츠와 고유 계약 검토 결과

검토 종료: 2026-10-12. 판단: **유지하되 인계 보강**. 로드맵 범위와 후속 연결의 검토다.

## 판단

일반13·엘리트11·도구9·합의 유물/파편/장비의 실전 등장·획득·사용·저장까지 요구하므로 대표7 사례 성공을 전체 완성으로 오인하지 않는다. 두건↔늑대, 장례↔아종처럼 실제 불가분 묶음으로 상세화한다는 기존 방침이 적절하다.

## 발견과 후속 경계

범위는 크지만 로드맵이 이미 거대 단일 Goal 동결을 금지한다. 새 분할 로드맵을 추가할 필요는 없다. D-03/D-09의 실제 미정은 해당 항목만 막으며, 필수 활성 콘텐츠를 조용히 제외해 전체 완료로 처리할 수 없다. F05에 따라 고유 전투/도구의 화면 소비 요구가 후속 카드로 넘어가야 한다.

## 권고와 확인 기준

각 콘텐츠 묶음 종료에 기존 catalog의 정상 획득/독립 시험 전용/미지원 구분과 query·자산 참조·특수 입력을 연결한다. 도구의 철수/전투 후퇴/노드 종료/귀환/복원 의미를 분리하고, 납치·기도·대가사망은 모든 직원 행동/회복 판정을 함께 바꾼다. 개별 콘텐츠 원문 전체에 대한 전종 구현 감사는 이번 범위가 아니다.
