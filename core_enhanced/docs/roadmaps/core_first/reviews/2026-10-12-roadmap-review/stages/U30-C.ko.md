# U30-C Core 성능과 결정론 검토 결과

검토 종료: 2026-10-12. 판단: **유지**. 검증 단계의 목적과 범위에 대한 검토다.

## 판단

실제 유효 입력·정상 Core 흐름과 U29 외부 조합으로 비용·결정론·회수를 측정하고, Unity 렌더링/조작은 U30-P로 남기는 분리가 적절하다. U07-M의 개발용 측정 경로를 소비하는 구조도 유지한다.

## 발견과 후속 경계

개발용 cap 통과가 배포 적합성을 뜻하지 않는다. 또한 무효 입력을 빠르게 거절한 결과를 정상 큰 부하 처리 성능으로 세면 안 된다. 둘 다 카드에 이미 구분돼 있다. 20분 시험 제외를 우회한 시간 조건을 새로 만들지 않는다.

## 권고와 확인 기준

실제 실행된 unit/object/relation/branch 규모·환경·profile·반복 후 회수를 기록한다. 무제한 딜러 판수는 유한한 반복 시험으로 검증하되 시험 횟수를 gameplay cap으로 바꾸지 않는다. 최적화가 영향을 준 U27–29 증거만 근거를 갖고 갱신한다.
