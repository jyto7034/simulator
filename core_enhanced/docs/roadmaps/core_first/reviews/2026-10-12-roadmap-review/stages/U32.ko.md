# U32 Core 원정 종단 검증 검토 결과

검토 종료: 2026-10-12. 판단: **유지**. 검증 단계의 목적과 범위에 대한 검토다.

## 판단

MAIN-CORE A–E를 정상 loader·application·host·저장으로 연결하는 목적이 U28의 교차 저장과 구별된다. 선택한 개발 profile의 한계를 표시하는 요구도 적절하다.

## 발견과 후속 경계

U12 최소 원정 성공을 전체 지도/콘텐츠 성공으로 확대하거나, 반대로 모든 시험을 이 단계에서 처음 만드는 방식은 금지돼 있다. 각 도입 단계의 정상 명령 시나리오를 이어 붙이는 현재 원칙을 실행에서 유지해야 한다.

## 권고와 확인 기준

새 게임→선발/대여→탐사/성장/활동→귀환 또는 실패→다음 원정의 실제 경로를 수행한다. 결과 ack 전 종료·선택 대기·복원·누락 mod·스트레스/딜러를 교차 연결한다. 자료 직접 덮어쓰기는 좁은 반례 시험으로만 구분한다.
