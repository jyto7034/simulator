# U26-C 모드 화면과 전체 복구 검토 결과

검토 종료: 2026-10-12. 판단: **유지**. Unity를 Core 이후 처음 구현한다는 전제를 유지한다.

## 판단

앞서 만든 전투/원정 화면과 실제 Lab/Apply gate를 한 빌드에서 결합하는 단계가 적절하다. 모드 의존/조합 실패·stale 승인·버전 불일치·저장 실패의 표시를 Core 권위와 맞춘다.

## 발견과 후속 경계

F05의 활성 전투 화면이 A/B에서 완료돼 있어야 통합 검증이 최초 기능 구현으로 커지지 않는다. 전투·딜러·라운드 선택의 같은 프로세스 재접속과 프로세스 종료 복구는 서로 다른 결과다. 카드가 이 차이를 이미 요구한다.

## 권고와 확인 기준

A/B의 입력/화면 coverage를 인수한 뒤 MAIN-UI A–D와 MOD-UI를 수행한다. 승인 상태·명령 revision·durable ack가 늦게 도착하거나 순서가 바뀌는 상황을 검증한다. 서버 전체 제품화나 중앙 서비스 추가를 선행으로 확대하지 않는다.
