# U16 지원 활동과 유물 보상 검토 결과

검토 종료: 2026-10-12. 판단: **인계 보완 필요**. 제품 구현 완료 판정과 별개다.

## 판단

기존 지원 활동·기본 보상·딜러/미니게임·스트레스의 네 묶음은 서로 다른 종료·정산을 잘 구분한다. 이 내부 분할을 유지하고 하나의 거대 Goal로 합치지 않는 편이 좋다.

## 발견과 후속 경계

F02의 채용 소비 범위와 F04의 노드 RON 정책 책임을 명확히 할 필요가 있다. 세 미니게임 기준 판본/세부 판정은 실제 미정이므로 단순 라이브러리 선택으로 대신 확정하지 않는다. 스트레스 후퇴 예외와 딜러 나가기의 최종 확정은 상세 규칙과 일치한다.

## 권고와 확인 기준

U16-1은 U12 유료 채용 경로를 확장한다. U16-2/3/4는 각자 비용→선택→결과→복원→조회까지 닫는다. U16-3 상세화 때 기준 규칙과 NPC 공개정보 제약을 정하고, U21은 정식 상품/수치/NPC 콘텐츠를 인수한다. 판수 무제한 요구를 임의 상한으로 축소하지 않는다.
