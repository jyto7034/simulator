# U06 기본 전투와 명령 조회 검토 결과

검토 종료: 2026-10-12. 판단: **유지**. 로드맵 계약·후속 연결에 대한 검토이며 제품 재감사가 아니다.

## 판단

Unity 없이 starter 전투·치유·이동·교대·작업·시간을 실제 명령으로 실행하고 조회하게 한 설계가 Core 우선 전제에 맞는다. 입력 불가 사유와 예측/실제 판정 구분도 화면 연결에 필요한 최소 범위다.

## 발견과 후속 경계

화면이 없는 지금 조작감을 검증했다고 할 수 없다. 저지 판정 타일과 연속 위치·시각 보정은 별개이며 U26-A가 권위 상태를 임의 수정하지 않도록 해야 한다.

## 권고와 확인 기준

U26-A는 현재 선택 가능 대상·배치/이동 자격·거절 사유를 소비한다. 시야 밖 대상과 조회 후 상태 변경 시 거절 사례를 화면 검증에 포함한다.
