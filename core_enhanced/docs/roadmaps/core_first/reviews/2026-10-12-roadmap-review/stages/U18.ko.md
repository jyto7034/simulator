# U18 연결망과 원천별 감염 검토 결과

검토 종료: 2026-10-12. 판단: **유지**. 로드맵 범위와 후속 연결의 검토다.

## 판단

U07 객체 수명과 U10 인과를 실제 source별 감염·공간 집계에 연결하는 순서가 타당하다. 거미줄 내부 구현을 범용 공개 언어로 강제하지 않고 완성 기믹의 재사용·명시 설정값만 제공하는 범위도 합의와 맞는다.

## 발견과 후속 경계

기술적 거리·교차 판정과 제품 의미를 바꾸는 대상/전파 규칙을 구별해야 한다. 전부 미정이라는 이유로 공통 source 기능을 막거나, 반대로 내부 geometry를 곧바로 공개 계약으로 만들지 않는다. F05의 화면 인계에는 실제로 공개할 연결/감염 상태를 포함할 필요가 있다.

## 권고와 확인 기준

source A/B 독립, 전파 도중 생성/진화/삭제, 공격 불가 친구 미소비를 정상 RON으로 확인한다. U11 승인 capability와 U27 공개 지원표도 갱신한다. U21은 정상 등장·획득을 연결하며 같은 엔진을 다시 만들지 않는다.
