# U26-A Unity 최초 전투 클라이언트 검토 결과

검토 종료: 2026-10-12. 판단: **책임 범위 보완 필요**. Unity를 Core 이후 처음 구현한다는 전제를 유지한다.

## 판단

Unity 미구현을 전제로 실제 프로젝트·bridge·입력·표시를 처음 만드는 카드다. U33 이후 순서를 유지하며 starter 실전 조작과 스트레스 화면을 첫 확인 대상으로 삼는 것은 적절하다.

## 발견과 후속 경계

F05. starter와 스트레스 외의 활성 전투 기능군을 어느 내부 묶음에서 처음 표시·조작 가능하게 하는지 보강해야 한다. F06. 일반 2회 후퇴 안내를 공통 UI에 고정하면 스트레스 수동 후퇴/성공 철수 예외를 잘못 안내할 수 있다.

## 권고와 확인 기준

최소 bridge/starter 뒤에 생성물·진화·방어막·연결/감염·일반 보스 전환·작업/예고 등 활성 기능군의 화면 소비를 닫는 내부 인수 묶음을 둔다. 고유 선택 UI의 U26-B 책임을 함께 정한다. 자산 ID·현재 state/revision·권위 명령을 소비하고 local animation으로 규칙을 만들지 않는다.
