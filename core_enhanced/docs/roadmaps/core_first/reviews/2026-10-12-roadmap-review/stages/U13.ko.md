# U13 시설 지도와 노드 배정 검토 결과

검토 종료: 2026-10-12. 판단: **설계 인계 보완 필요**. 제품 구현 완료 판정과 별개다.

## 판단

전체 방 지도와 방 내부 노드·표시 좌표와 실제 연결·영구 지식과 현재 원정 상태를 분리한 구조가 적절하다. 미구현 최종방은 공개 조건을 지키면서 Core에서 차단하는 현 방침을 유지한다.

## 발견과 후속 경계

F03. 고정 예약과 후속 전조 배정의 호환 계약이 카드 수준에서 빠져 있다. 지원 노드·고정 보스·SavePoint·초반 유물을 배정한 뒤 U20이 필수 전조를 넣을 자리가 없으면 ‘반드시 배정’ 정책을 지키기 어렵다. 룰북도 이 결합 순서는 별도 설계라고 명시한다. 현재 생성기의 실패를 재현한 결과는 아니다.

## 권고와 확인 기준

U13 상세화에서 U20이 소비할 호환 노드 조건과 예약 충돌 판정 책임을 정한다. 전조 없는 floor/family, 후보 없음, 후보 있음+가용자리 있음/없음의 데이터 검증을 구분한다. 전조 미구현을 가짜 활동으로 채우거나 모든 방에 전조를 확정 배정하지 않는다.
