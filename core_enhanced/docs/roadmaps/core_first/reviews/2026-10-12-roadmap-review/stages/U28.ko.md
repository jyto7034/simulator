# U28 교차 저장과 장애 복구 검토 결과

검토 종료: 2026-10-12. 판단: **유지**. 검증 단계의 목적과 범위에 대한 검토다.

## 판단

기능별 저장 도입 이후 복합 상태의 교차 복원을 확인하는 독립 목적이 있다. U04나 각 상태 owner의 저장 시험을 통째로 반복하는 단계로 읽을 필요는 없다.

## 발견과 후속 경계

창고 혼합 지불·부화·담보·도구 계약·영구 기록의 복원 기준이 달라 오류 위험이 크다. 기존 §6.1/6.2와 카드가 주요 조합을 배정한다. 구형 개발 저장 변환 제외와 새 지원 저장의 보존 의무를 계속 구분해야 한다.

## 권고와 확인 기준

기존 단일 기능 증거를 재사용하고 기능 간 상호작용과 실제 crash/retry를 추가한다. 딜러 미완료 거래 전체 복원·스트레스 후퇴 노드 소비·영구 지식 비복원의 서로 다른 결과를 같은 시나리오에 대조한다.
