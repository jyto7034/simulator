# Core 우선 로드맵 검토

2026-10-12 사용자 요청에 따른 설계·순서·완료 기준 검토다. Core 우선, Unity 최초 구현은 후속, 개별 최종보스 전투 제외를 유지한다. 검토 중 발견과 판단 변화는 [검토 메모](NOTES.ko.md)에 기록하고, 단계별 결론은 `stages/`에 남긴다. 개발 현황은 기존 [단일 현황](../../../content_authoring/ROADMAP_STATUS.md)이 소유한다.

## 검토 기준

1. 최신 룰북의 확정 정책과 단계별 책임이 일치하는가.
2. 선행·후행 사이에 순환 또는 임시 구현의 큰 재작업이 있는가.
3. 정상 명령으로 단계 종료 상태를 실행·조회·저장·복원할 수 있는가.
4. Unity가 처음 연결될 때 필요한 조회·명령·오류 상태가 준비되는가.
5. 공개 제작 범위와 검증 비용이 실제 요구에 비례하는가.

완료된 단계는 기록된 판정을 인수하고 후속 연결을 검토한다. 이번 검토는 제품 독립 감사나 재시험이 아니며, 기존 완료를 재판정하지 않는다. 발견 사항은 확인된 문서 문제, 설계상 위험, 착수 때 확인할 항목을 구별한다. 제안은 로드맵·제품에 자동 적용하지 않는다.
