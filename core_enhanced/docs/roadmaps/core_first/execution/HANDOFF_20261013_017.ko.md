## 발견한 결함과 마지막 실제 실행

V4 profile current/backup 중 한 사본에 제거된 `standard_tutorial_completed: true`가 있어도 정상 상대 사본이 있으면 approved preflight가 이를 허용한다. normal Continue가 성공하고 후속 정상 `AbandonRun`이 미지원 원본을 덮어쓴다. strict decode 오류가 `InvalidEnvelope`로 분류되고 approved/unbound 원본 보호가 이를 일반 손상 backup 복구로 처리하는 경로다. 원인 위치는 `game_server/src/persistence/player_profile_store.rs:135,368` 및 `player_profile_store/application_intent.rs:139,193`이다. 직접 수용 조건 A-13-2 및 canonical runtime contract의 unknown-field 원본 보호와 충돌한다.
