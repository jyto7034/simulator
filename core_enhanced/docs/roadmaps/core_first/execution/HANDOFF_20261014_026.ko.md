## 확보한 인수 근거

- U12의 최초 입장 receipt·실제 소진 전이·귀환·복원 수명을 재사용한다. 현재 첫 입장 비용은 전역 초기값을 소비하며, Breakdown은 완료 노드 기반이다. U14는 작성된 규정 비용 누적 유예로 전환하고 비용→유예/사망→소진 선택→활동 순서를 지킨다.
- 확정 범위는 전체 적의 작성형 HP/공격력 1.5~2배, 최초 입장 비용 반영 후 전투 진입 snapshot, 해당 승리 수량 보상 총량 2배, 패배 기본 생존 XP 유지다. 무억제와 봉인 해제의 추가 스탯 중복 금지는 이미 확정됐으며 재질문하지 않는다.
- 황금가지 배치안은 원정 시작 때 하나 선택하여 저장·재방문·후퇴에도 유지한다. 미탐사 위치 공개와 보스 정체 비공개를 구분한다. 구체적인 배치 수치·가중치는 D-02/NEXT-18의 초기값·플레이 검증 경계로 남으며 이번 착수에서 임의 확정하지 않았다.
- 개별 보스 본체·고유 패턴과 U16-4 스트레스 전투 전체 구현은 후속 단계다. U14는 공통 입장·보상·무억제 계약과 후속 소비 경계를 담당한다. 최종보스 플레이 검증은 제외한다.

## 사용자 판단이 필요한 정책

**부활 단계 강화와 무억제 강화의 결합 방식**이 [원정 규칙](../../../game_rules/expedition-and-deterrence.md#무억제-강화와-보상)·[NEXT-18](../../../game_rules/open-decisions.md) 및 로드맵 D-04에 미정으로 남아 있다. 기존 합의는 두 강화의 유지이며, 곱셈 또는 증가분 합산 중 하나를 도출할 근거는 없다. 이는 단순한 수치 조정과 달리 전투 난이도의 계산 규칙을 결정하므로 사용자 의논 대상으로 분류했다.

질문/권고: 두 배율을 곱하는 방식을 권고한다. 예를 들어 부활 강화가 1.5배이고 무억제 강화가 1.5배인 경우 기준 스탯의 2.25배가 된다. 대안인 증가분 합산은 같은 예에서 2.0배다. 이 예는 부활 단계별 실제 수치의 신규 확정이 아니다. 봉인 해제 추가 스탯 중복 금지는 어느 선택에서도 유지한다. 사용자 답변은 아직 없다.

[P2G §8.6](../../../policy_to_goal_pipeline_revised_v2.md#86-blocker와-중단-조건)의 “주 작업 담당자는 진행을 임시중단하고, 일반 채팅의 최종 답변으로 질문한 뒤 사용자 답변을 기다린다”에 따라 최소 인계 정리 후 대기한다. 진행 중인 독립 작업은 없다. U14 미완료이며 Goal 시스템의 paused/complete 상태를 적용했다고 주장하지 않는다.

**다음 행동:** 사용자 답변을 실제 policy owner에 반영하고, 기존 U14 승인 범위 안에서 P2G 초기화·정책/현재 코드 근거·실행 묶음·GEX 구현 및 검증으로 이어간다. 미응답·추천안을 승인으로 기록하지 않는다. 최종 독립 감사는 해당 역할·요청 경계에서 인계한다.
