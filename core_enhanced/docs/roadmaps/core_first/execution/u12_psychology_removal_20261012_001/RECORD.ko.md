사용자 원문: “기억, 신뢰도 시스템은 완전히 제거하는거로 합의봤을텐데, 게임 룰북을 읽어볼래? 거기엔 기억이 없을거야.”

룰북 본문에는 개인 수명 문장에 신뢰·기억이, results-and-save 끝에는 ‘현행 비교 기준’ Psychology가 남아 있었다. 로드맵은 이를 기억 보존 요구로 명시했다. 이 문서 잔존을 최신 사용자 의도보다 우선한 해석은 잘못이며 철회한다. 이번 답변을 보존안/생성안 승인으로 바꾸어 기록하지 않는다.

현재 계약은 기억·신뢰 시스템 완전 제거다. 기억과 해당 최근 반응/사건·점수/band·초기화·전용 입력·상태·조회/표시·신규 저장·복원 재생성을 제거한다. 기억 합침/기간/recent8 기반을 새로 구현하거나 후속 기억 gameplay를 필수로 남기지 않는다. 고정 성격 두 축·성장·부상·트라우마·사망·새 인원 초기화와 도감/탐사/귀환/획득 기록은 별개로 유지한다. 미지원 구형 개발/테스트 저장은 원본 보호 후 명시 거절한다.

룰북과 상세3페이지, 현재 로드맵의 PS01/PS02·U12/U28/U32/U26-B 및 상태 view를 정정했다. 과거 source 색인/발행 이력은 이력으로 구분했고 과거 audit/Goal/frozen artifacts는 수정하지 않았다. 원문은 DOCUMENTS_BEFORE.tar.gz, 정확한 수정은 DOCUMENTS.diff와 RECORD.json으로 보존한다.
