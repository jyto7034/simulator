# 포큐버스 개인 방어막 정책 변경 — 2026-10-07

사용자는 공용 방어막을 개인당 방어막으로 바꾸고, 시전 순간 범위 내 대상에게 한 번씩 부여하는
방향을 로드맵·스킬 파편 등 문서에 반영하도록 요청했다. 이번 변경은 문서 정책이며 제품 코드·RON의
구현 완료를 뜻하지 않는다.

## 합의와 미결정

- 시전 시 범위 내 자격 있는 아군(시전자 포함)에게 개인 방어막을 1회 부여한다. 각자의 잔량과
  지속 시간을 가지며 제공자 출처는 시전자다. 한 아군의 피격은 다른 아군의 잔량을 소모하지 않는다.
- 시전 뒤 진입한 대상에게는 부여하지 않고, 받은 대상은 단순 범위 이탈 후에도 유지한다.
  재진입·시전자 이동으로 추가 부여하거나 잔량을 충전하지 않는다.
- 대상의 방어·감면 → 그 대상의 방어막 → 초과분 HP 순서를 유지한다. HP 희생·비용은 흡수하지 않는다.
- 같은 개인량 S를 N명에게 부여하면 총량은 N × S다. 개인량·범위·지속 시간은 재조정 대상이다.
  쾌락의 고리는 제공자가 생성하는 각 방어막에 한 번 적용하며 수혜자 장비로 다시 증폭하지 않는다.
- 단일 전환 유물은 여러 개인 방어막을 한 명의 강화 방어막으로 바꾼다. 공용 기준 일반 2S·침식
  4S 비교안은 과거 기록으로 남기고 새 일반/침식 배율과 패널티를 다시 결정한다. 태아 수치는 유지한다.
- 최종 범위·계산식·수치, Guest/소환물/오브젝트 자격, 재시전·철수·사망 lifecycle의 미정 세부는
  파편 상세를 따른다. 기존 종료/교체 초안을 새 확정 규칙으로 승격하지 않는다.

## U09와 증거 인수

현재 로드맵의 U09/C06·C04 및 콘텐츠 요약을 새 정책으로 갱신했다. 진행 중 계획은 다음 안전한
인수 경계에서 이 정책과 현재 코드·RON을 대조하고, 이미 고정한 입력이 있다면 변경 영향을 검토한
후 후속 판본에 반영한다. 과거 P2G/GEX·감사·동결 자료를 덮어쓰거나 옛 공용/2S 시험 결과를 새 정책의
실행 증거로 재사용하지 않는다. 이 기록 자체는 기존 실행을 중단하거나 완료 판정을 바꾸는 지시가 아니다.

기존 R12의 일반 공용 보호 기능·다른 콘텐츠의 공유 자원 지원과 포큐버스 원본 보스의 거리/잠복/작업
정책은 이 변경의 대상이 아니다. U09 기능과 U21 콘텐츠 통합에서 포큐버스의 새 동작을 검증한다.

변경 문서: 스킬 파편 설계, Run 유물 설계, 환상체 설계의 플레이어 보상 요약, 유물 규칙·미결정 목록,
Core 우선 로드맵·콘텐츠 제작 현황. 문서 검증은 개인 부여/흡수/이동 규칙, 유물 수치의 보류 상태,
요약과 U09 완료 조건의 일치 및 링크 대상을 확인한다.
