## 현재 기준과 재사용

[기계 대조](CURRENTNESS.json): 기존 독립 감사가 열거한 387개 대상과 같은 membership을 사용했다.
386개가 동일하고 차이는 `ROADMAP_STATUS.md` 한 개다. 추가/누락은 없다. 기존 동결 records 1,435개와
archives/patches 9개를 SHA-256으로 확인했으며 불일치는 없다. 이는 과거 실행을 다시 수행했다는 뜻이 아니다.
전후 문서 변경의 실제 before는 [manifest](BEFORE.json)와 `SOURCE_BEFORE.tar.gz`에 보존했다.
기존 dirty/untracked 작업은 `git_status.txt.gz`, HEAD와 branch는 인접 기록으로 구분한다.

로드맵 G-02가 ZIP에서 부족하다고 설명한 runner·verify_target·PC_RECOMPARE·R05_RECHECK와 공개 취소
oracle은 실제 저장소에 있다. 최초 intake에서는 저장된 5개 oracle(2 PASS/3 FAIL)을 인수하며 U01에서 새 실행한다.
전체 workspace·Unity·운영 DB·지원 기기의 실제 완성을 증명한 것은 아니다.

F01은 `detach_boss_action`이 pending cast가 있을 때만 취소하는 실제 분기와 연결된다. 이미 준비가 끝난
structured Flow의 미방출 continuation은 별도 생존한다. 첫 교정은 정확 action 취소·방출물 보존·영향 회귀다.
기존 `GS-CARX-001 / GOAL-CARX-01 / HA-CARX-001`을 재사용하고 F01의 GEX-10 교정 successor로 들어간다.
정책을 바꾸지 않는 이 교정을 위해 P2G를 처음부터 생성하지 않는다. 기존 Not Complete 판정은 보존한다.

[로드맵](../../ROADMAP.ko.md)의 §3 요구 owner, §5 순서, 부록 A의 지원 범위표를 현재 인수한다.

재사용/공개 설정값 범위와 도구 9종 정책을 유지한다. 최종보스 본체·결합 전조는 XF이며 독립 합의 보상은
부록 A.4/FR01–04의 해당 owner에서 검증한다. 일반 마탄 사건은 U21, 실제 흉탄 본체/격파 획득은 XF04다.

이번 대화의 새 정책은 [CF-D01–07](../DECISIONS_20261004.ko.md), 실행 권한은
[연속 요청](../CONTINUOUS_REQUEST_20261004.ko.md)에 연결한다. 구저장 변환은 향후 필수가 아니지만
현행 U01 baseline의 저장 경로를 여기서 제거하지 않는다. 후반 미정은 해당 owner에 남고 무관한 F01을 막지 않는다.
