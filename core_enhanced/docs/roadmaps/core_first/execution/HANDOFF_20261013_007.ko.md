## 다음 필수 묶음과 재사용 경계

[독립 시험 계획](../../../goals/core_expedition_lifecycle/execution/single_goal/test_parts/TEST_PLAN_001.ko.md)의38수용/19통합/10차원/3최종 노드가 기준이다. Tutorial 고정3층 실제 완주 및 원정으로 얻은 nonempty profile 불변, 정상 승인 host의 실제 출발·채용·전투·귀환·대여·story ACK·다음 인스턴스, 별도 프로세스 저장/복원과 accepted crash가 남았다. 기존 server 시험의 Abandon/reset crash와 초기 stale Start만으로 **실제 획득품 loan/Return·profile-only story ACK의 durable/CAS 경계**를 대체하지 않는다. 독립 author가 이 관련 누락을 새 모듈에 작성했고 등록을 마쳤고 실제 실행이 남아 있다.

G11의 기존 수집기는 vault 규모별 clone/capture/import 경계를 측정하지 않는다. 외부 public 측정과 private budget 검증의 최소 추가 seam을 독립 author가 설계 중이며 아직 추가 source 작성은 없다. 기존 owner_extent는 battle/pending/relic 계량이므로 vault retained heap으로 해석하지 않는다. 실제 allocator/RSS 회수와 관련 회계를 구분한다. G11은 별도 trusted 측정 pack의 기존6개 적·funding160·geometry/encounters·roster16/500/1000·배치1/8/8·60×1000ms recipe를 유지한다. 일반 official의 밸런스 근거와 구분하며 현재 준비·실측·비용 판단은 미완료다. 실제 source 영향에 필요한 회귀, canonical 문서/제거 계약, 수용 coverage, Astra 수용 검토, 정역 복원·exact target·비참여 전체 감사 후 다음 승인 작업으로 이어간다.
