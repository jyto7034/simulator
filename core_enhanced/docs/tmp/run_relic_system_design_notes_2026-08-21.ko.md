# Run 유물 시스템 설계 노트

## 문서 상태

- 최초 작성: 2026-08-21.
- 정책 기록 갱신: 2026-09-08 사용자 대화 결정 반영.
- 상태: **공통 정책의 사용자 결정 기록 / 획득 정책 보류 / 대표 유물 설계 후 콘텐츠 작성 / 코드 검토 및 최종 동결 전**.

이 문서는 신규 Run 유물 시스템과 그 도입에 필요한 성장 체계 변경의 목표 정책을 기록한다.
아래의 대화 결정은 구현 완료나 현재 runtime 동작을 뜻하지 않는다. Gameplay canonical,
live RON/schema/runtime 또는 Unity 계약으로 승격한 문서도 아니다. 실제 코드에 근거한 설계 검토와
필요한 후속 정책 결정을 거쳐 최종 동결한다.

과거 Artifact를 복원하지 않는 신규 시스템이라는 범위는 유지한다. 기존 제거 이력은
[artifact_legacy_removal](../goals/artifact_legacy_removal/PLAN.md)을 참고한다.

문서 안의 상태는 다음과 같이 구분한다.

| 구분 | 의미 |
| --- | --- |
| 대화 결정 | 이번 대화에서 사용자가 선택하거나 직접 정정한 목표 정책 |
| 보류 | 사용자가 추후 논의하기로 한 획득 관련 정책 |
| 후속 콘텐츠 | 기초 태그 초안을 스킬·유물에 적용하며 확장하고, 대표 유물 설계로 다듬을 정식 태그·유물·수치와 개별 조건 |
| 기존 참고 | 이전 노트의 방향이나 콘텐츠 아이디어를 보존한 것으로, 이번 대화에서 개별 콘텐츠를 확정한 것은 아님 |
| 구현 검토 | 코드 조사와 설계 검토가 필요한 영역. 검토에서 새로운 gameplay 선택이 필요하면 별도로 결정 |

기존 초안과 이번 대화 결정이 다르면 이 문서의 대화 결정을 목표 정책으로 사용한다. 특히
장비 연동 슬롯, 유물 레벨 강화, 방어구·액세서리의 자체 특수 효과 금지는 아래 결정으로 교체됐다.
호환성은 태그 기반 범용 유물을 기본으로 하며, 2026-09-07 후속 결정에 따라 전용 유물도 허용한다.
같은 날짜의 추가 대화에서 침식 아이템을 기존 유물에 적용하는 **침식된 유물**을 도입하기로 했다.
획득 방식과 효과·대가의 방향은 아래에 기록하며, 세부 적용 규칙과 개별 패널티는 후속 설계한다.

## 목적과 효과 범위 — 대화 결정

- 런마다 서로 다른 무기·파편 조합과 전투 빌드를 만든다.
- 범용 유물은 무기·파편이 가진 효과를 태그로 판별해 강화하거나, 새로운 효과를 부여한다.
- 전용 유물은 명시한 파편·장비의 고유한 구조를 확장한다.
- 새로 부여한 효과에도 태그를 연결하여 다른 유물과 조합할 수 있게 한다.
- 유물 효과의 범위는 전투 안으로 한정한다. 상점 가격, 보상량과 맵 생성에 직접 영향을 주는
  비전투 효과는 제외한다.
- 유물의 획득·보관·장착·분쇄 같은 비전투 관리는 위 효과 범위 제한과 별개의 소유·관리 규칙이다.

2026-09-08 대화에서는 **무기에 적용할 유물의 첫 설계 범위를 단순 수치 강화까지**로 정리했다.
무기마다 공격 방식·변신 규칙을 바꾸는 전용 유물을 만드는 작업은 현재 필수 과제로 두지 않는다.
파편의 변형·연결 설계와 이미 기록된 무기·장비 효과는 유지한다. 사용자가 요청한 등급별 수치 유물은
[무기 수치 강화 유물 9종 초안](../skills/run_relic_content_design_notes.ko.md#무기-수치-강화-유물--9종-초안)에
기록한다. 이름·공격력/공속/기본 공격 피해 수치·중복과 적용 세부는 AI 제안이며 사용자 확정 전이다.

## 성장 체계 — 대화 결정

| 대상 | 역할과 성장 |
| --- | --- |
| 무기 | 일반 강화를 지원한다. 해당 무기가 제공하는 공격력·주문력을 높인다. |
| 방어구·액세서리 | 능력치와 자체 특수 효과를 가질 수 있다. 효과를 간단한 것에 한정하지 않는다. 일반 강화는 지원하지 않는다. |
| 스킬 파편 | 일반 강화를 제거하고, 개화로 새로운 형태를 해금하는 성장을 유지한다. |
| 유물 | 기존 효과 강화와 새 효과 부여로 빌드를 구성한다. 자체 레벨이나 반복 강화 단계는 없다. 침식 아이템에 의한 침식된 유물 변형은 아래 별도 정책을 따른다. |

방어구·액세서리에 자체 특수 효과를 허용하며, 유물로 더 특수한 효과를 추가할 수 있다.
장비의 특수 효과를 모두 유물로 옮기거나 방어구·액세서리를 순수 능력치 장비로 제한하지 않는다.

### 파편 피해와 무기 성장

- 직원의 공격력과 주문력은 별도 능력치다.
- 파편마다 공격력, 주문력 또는 둘 모두 중 어떤 능력치를 참조할지 명시한다.
  기존 노트의 개념 분류인 Attack / SpellPower / Hybrid에 해당한다.
- 무기마다 공격력·주문력의 제공 여부와 수치를 정한다. 모든 무기가 두 능력치를 모두
  제공한다고 가정하지 않는다.
- 무기 강화는 그 무기가 제공하는 능력치를 높이며, 해당 능력치를 참조하는 파편의 피해도
  함께 증가한다. 주문형 파편도 무기의 주문력 성장에 영향을 받는다.
- 파편 자체의 일반 강화 단계를 제거해도 직원·무기의 성장과 유물 효과로 실제 위력은 달라진다.

기존 노트의 개념식을 이번 결정에 맞게 표현하면 다음과 같다. 실제 계수, 강화 증가량과
세부 피해 산술은 콘텐츠·밸런스 및 구현 검토에서 정한다.

    공격형 파편 피해
    = 기본 피해 + (직원 공격력 + 무기 공격력) × 공격 계수

    주문형 파편 피해
    = 기본 피해 + (직원 주문력 + 무기 주문력) × 주문 계수

    혼합형 파편 피해
    = 기본 피해
      + (직원 공격력 + 무기 공격력) × 공격 계수
      + (직원 주문력 + 무기 주문력) × 주문 계수

### 개화 형태 선택

- 개화는 새로운 형태를 해금하며, 개화 전 형태도 유지한다.
- 플레이어는 **Maintenance에서 개화 전·후 형태 중 사용할 것을 선택**할 수 있다.
- 이 선택 방식은 2026-09-06 대화에서 유지하기로 확인했다. 구체적인 저장 구조와 선택 상태의 구현은
  후속 코드·설계 검토 대상이다.

### 개화 재료와 선행 콘텐츠

- 파편 가루는 제거하지 않고 개화용 재료로 유지한다.
- 개화에는 환상체 파츠 같은 추가 재료를 요구할 수 있다.
- 파편의 원본 환상체뿐 아니라 다른 환상체에서 얻는 재료도 개화 조건으로 요구할 수 있다.
- 이 재료 조건을 통해 특정 환상체 콘텐츠를 먼저 거치도록 만들고 밸런스 조절에 활용한다.
- 어떤 파편이 어느 환상체의 어떤 재료를 얼마나 요구하는지는 후속 콘텐츠·밸런스에서 정한다.
  공통 획득 조건이나 수량을 여기서 추론하지 않는다.

기존 파편 강화 진행, 관련 보상과 저장 데이터의 전환 처리는 아직 결정하지 않았다.
파편 가루 유지 결정과 기존 데이터의 구체적인 전환 방법은 구분한다.

## 유물의 희귀도 — 대화 결정

2026-09-07 대화에서 유물에 **일반·희귀·특급**의 세 가지 획득 희귀도를 두기로 했다.

| 희귀도 | 설계 방향 |
| --- | --- |
| 일반 | 자주 만나며 빌드의 기초를 만드는 선택 |
| 희귀 | 특정 운용이나 조합에서 높은 효과를 내는 선택 |
| 특급 | 런 전체에 미치는 영향이 커서 드물게 제공할 선택 |

- 희귀도는 획득의 기대감과 등장 빈도를 설계하는 기준이다. 유물 자체의 레벨·강화 단계가 아니며,
  동일 유물 획득 시 별도 사본을 얻는 기존 정책을 유지한다.
- 강화형·전문화형·연결형·전환형 역할 분류와 희귀도는 독립적이다. 효과의 복잡성이나 역할 이름만으로
  등급을 정하지 않는다. 일반 유물도 특정 빌드에서 끝까지 사용할 가치가 있어야 한다.
- 개별 유물의 등급 배정은 콘텐츠 문서가 기록한다. 첫 유물 `깊은 쐐기`는 **희귀**로 확정했고,
  `때린 곳 또 때리기`는 같은 유물의 대체 이름이다.
- 등급별 정확한 획득처·출현 확률·후보 구성·선택 방식은 보류한다. 현재 결정은 정식 schema enum이나
  runtime·live data 적용 완료를 뜻하지 않는다.

## 침식된 유물 — 대화 결정과 후속 설계

2026-09-07 대화에서 사용자는 효과를 대폭 강화하는 대신 **유닛을 죽음에 이르게 할 수 있는
패널티**를 가진 `침식된 유물`을 만들기로 했다.

- 침식된 유물 자체를 드롭으로 얻지 않는다. **침식 아이템을 유물에 적용해 얻는다.**
- 사용자 예시는 집중 중 자신의 HP를 희생하는 동안 유지, 침식체들의 최우선 공격 목표가 됨,
  받는 피해 `100%` 증가다. 서로 다른 패널티 후보이며 모든 침식된 유물에 동시에 붙이지 않는다.
- 개별 유물의 강화 효과와 패널티를 짝지어 설계한다. 단일 전환 범용 유물의 태아 적용은 아래
  콘텐츠 문서의 기존 강화 수치를 유지하며, 구체적인 패널티는 아직 선택하지 않았다.
  2026-09-08 후속 결정으로 태아 전용 유물 자체는 미정으로 되돌렸다.
- 기존 일반·희귀·특급과 구별되는 변형 상태로 정리하는 방향이다. 새 희귀도나 반복 가능한 레벨
  강화로 확정한 것은 아니며, 정식 상태 표현·원래 희귀도 처리·재적용 규칙은 후속 설계한다.
- 이 개념은 필드 적 처형 행동인 **파편 침식형**과 구분한다. 기존의 `침식에 유물 미적용`은
  파편 침식형에 증폭·추가 효과·연쇄를 적용하지 않는 규칙이며, 침식된 유물 자체를 비활성화하는 뜻이 아니다.

후속 설계: 침식 아이템의 획득처·소모량, 적용 장소·시점과 대상 사본, 변형의 해제·재적용·상태 보존,
중복 장착과 비호환, 패널티의 종류·수치·시작 및 종료 조건. HP 희생의 비용·피해 구분과 회복·보호막·
생존 보장·HP 0 판정, 공격 우선순위의 사거리·저지·경로 규칙도 개별 효과에서 정한다.
앞서 제안한 매초 최대 HP `6%` 소비는 설명용 후보이며 공통 확정 비용이 아니다.

## 태그 기반 유물 효과 — 대화 결정

### 적용 대상과 강화 항목

2026-09-07 후속 대화에서 **태그 기반 범용 유물을 기본으로 삼되, 전용 유물도 남기기로 했다.**
모든 유물을 태그 조건만으로 범용화하던 이전 결정을 수정한다.

- 범용 유물은 특정 파편·무기 ID 대신 효과 태그와 세부 속성으로 적용 대상을 판별한다.
- 전용 유물은 특정 파편·장비의 고유한 구조를 확장한다. 전용 대상과 기본형·개화형 등 적용 형태를
  개별 설계에 명시한다. 전용 조건의 정식 ID·schema 표현은 후속 구현 검토에서 정한다.
- 첫 전용 사례는 `붉은 실타래`이며, 래티씨아 기본·개화 파편의 작은·큰 친구에 적용한다.
  다른 파편의 효과가 같은 일반 태그를 가진다는 이유만으로 연결 대상이 되지는 않는다.
- 전용 유물도 공용 슬롯·직원 간 이전·중복·연쇄 정책을 따르며, 새 효과에 태그와 출처를 부여한다.
  범용·전용 구분만으로 희귀도나 획득처를 정하지 않는다.
- 최종 보스도 같은 범용·전용 정책을 따르며, 침식에는 어느 쪽 유물도 적용하지 않는다.

파편 등의 효과를 스택, 관통, 폭발 같은 태그로 표현한다. 유물은 그 태그가 가리키는 효과를
강화하며, 새로운 효과를 부여하는 것도 허용한다. 태그가 적용 대상을 판별하고 실제 변화는
해당 유물의 효과 정의가 소유한다.

밸런스 수치를 확정한 표가 아니다.

| 효과 예시 | 강화 항목 예시 |
| --- | --- |
| 스택 | 획득량, 최대 스택, 스택당 효과 |
| 투사체 관통 | 관통 횟수, 관통 후 피해 감소 완화 |
| 폭발 | 폭발 반경, 폭발 피해 |

### 새 효과와 다른 유물의 조합

- 유물로 새로 부여한 효과에도 태그를 붙인다.
- 다른 유물은 새로 부여된 효과도 태그 조건에 따라 강화할 수 있다.
- 예를 들어 폭발 부여 유물로 생긴 폭발에 폭발 반경 증가나 폭발 피해 증가 유물을 적용할 수 있다.
- 2026-09-06 후속 대화에서 기초 태그 초안을 먼저 만들고 스킬·유물에 적용하며 확장하기로 했다.
  초안과 적용 예시는 [Run 유물 콘텐츠 설계 노트](../skills/run_relic_content_design_notes.ko.md#기초-태그-초안)에
  기록한다. 정식 태그 목록과 허용할 개별 변형은 대표 유물 설계를 통해 다듬는다.

### 피해 증폭의 합산과 상한

- 같은 효과에 대한 동일 종류의 피해 증폭은 합산한다.
- 예: 폭발 피해 +20%와 +30%를 함께 적용하면 +50%다. 예시 수치는 실제 유물 수치가 아니다.
- 유물이 제공하는 피해 증폭에는 별도 공통 상한을 두지 않는다.
- 밸런스는 개별 유물의 수치와 직원당 3개 장착 제한으로 조절한다.
- 이 결정은 동일 종류의 피해 증폭에 관한 것이다. 서로 다른 효과의 모든 수치나 기존 피해
  계산의 전체 연산을 일괄 합산으로 바꾼다는 뜻은 아니다.

### 연쇄 발동과 순환 제한

- 유물이 만든 효과가 다른 유물의 발동 조건을 만족하면 연쇄 발동할 수 있다.
- 예: 공격 적중으로 유물이 만든 폭발이 적을 처치하면, 그 처치로 다른 유물의 스택 획득 효과가
  발동할 수 있다.
- 한 연쇄 경로가 **동일 유물 사본의 같은 효과**로 되돌아오는 순환 재발동은 금지한다.
  폭발 → 추가 탄환 → 폭발처럼 서로를 계속 발동시키는 순환을 막는다.
- 새로운 기본 공격 등에서 시작한 별도 연쇄는 다시 정상 발동할 수 있다.
- 순환 제한을 전투 전체에서 유물당 한 번만 발동하는 제한으로 해석하지 않는다.
  연쇄의 원인과 경로를 표현하는 내부 방식은 구현 검토에서 정한다.

### 비호환 태그

- 함께 성립할 수 없는 효과는 유물의 비호환 태그, 즉 네거티브 태그로 표현한다.
- 서로 호환되지 않는 유물은 장착 순서와 관계없이 함께 장착할 수 없다.
- 예: 같은 스킬의 스택을 반드시 전부 소모하게 하는 효과와 소모하지 않게 하는 효과.
- 비호환 제한의 범위는 **같은 직원이 장착한 유물 조합**이다.
  서로 다른 직원의 유물끼리는 이 태그로 장착을 제한하지 않는다.
- 아래의 중복 장착 태그와 비호환 태그는 각각 별도의 제한을 나타낸다.

## 슬롯·소유·장착 — 대화 결정

### 공용 슬롯과 런 소유

- 직원마다 장비 장착 여부와 무관한 **공용 유물 슬롯 3개**를 기본 제공한다.
- 무기·방어구·액세서리별 슬롯으로 구분하거나 공격·방어·보조 용도로 제한하지 않는다.
- 장비를 해제했다고 유물 슬롯이 닫히거나 장착 유물이 자동 회수되지 않는다.
  무기·파편 변경으로 효과의 요구 태그가 사라지는 경우는 아래 비활성 규칙을 따른다.
- 직원별 3개 제한 외에 보유 직원 전체의 유물 장착 합계에는 별도 상한을 두지 않는다.
- 유물은 런 공용 자산이며 특정 직원이나 장비에 귀속하지 않는다. 직원 사이에서 옮겨 장착할 수 있다.
- 중복 사본을 포함한 런의 유물 보유 총수량에는 상한을 두지 않는다.
- 직원 사망 시 장착 유물은 모두 런 공용 보관함으로 회수한다.

### 사본과 중복 장착 태그

- 동일 유물을 다시 획득하면 독립된 사본이 추가된다.
- 보유한 각 사본은 하나의 장착 슬롯을 차지한다.
- 중복 획득을 기존 유물의 레벨 증가나 단계 강화로 바꾸지 않는다. 유물 자체의 강화는 없다.

| 중복 장착 태그의 의미 | 같은 직원의 장착 제한 |
| --- | --- |
| 중복 가능 | 보유한 동일 유물 사본을 여러 개 장착할 수 있다. 각각 슬롯 하나를 차지한다. |
| 중복 불가 | 동일 유물은 최대 1개만 장착할 수 있다. |

중복 태그는 **같은 직원에게 동일 종류의 유물을 여러 개 장착할 수 있는지**를 뜻한다.
한 사본을 여러 직원이 동시에 공유하거나, 한 사본만으로 여러 슬롯을 채우는 의미가 아니다.
중복 불가 유물도 별도 사본을 서로 다른 직원에게 장착하는 것은 이 태그로 금지하지 않는다.

### 변경 시점과 비용

- 유물의 장착·해제·교체와 직원 간 이전은 Safezone과 Maintenance에서 할 수 있다.
- Safezone은 지도 보기와 전투 진입 전 준비를 포함한다.
- 장착 변경은 위 시점에서만 허용하며 전투 중에는 허용하지 않는다.
- 허용 시점의 장착·해제·교체에는 재화 비용이나 횟수 제한이 없다.
  슬롯, 중복 태그와 비호환 태그 제한은 계속 적용한다.

### 요구 태그 미충족과 비활성

- 파편·무기를 교체해 유물의 요구 태그가 사라져도 유물은 장착 상태를 유지한다.
- 이때는 **유물 효과만 비활성화**한다. 슬롯은 계속 차지한다.
- 다시 요구 태그를 만족하면 효과가 자동으로 활성화된다.
- 최초 장착 때부터 요구 태그가 없어도 미리 장착할 수 있으며, 조건을 만족할 때까지 효과만
  비활성 상태로 둔다.
- 다른 유물이 새로 부여한 효과의 태그로 요구 조건을 만족해도 활성화할 수 있다.
- 예: 폭발이 없는 파편에 폭발 피해 증가 유물을 먼저 장착해 둘 수 있다.
  이후 폭발 부여 유물을 장착하거나 폭발 파편으로 교체하면 증가 효과가 작동한다.
- 요구 태그 미충족에 따른 비활성 허용이 비호환·중복 제한 위반을 허용하는 것은 아니다.
- 전용 유물도 대상 파편·장비와 적용 형태를 충족하지 않으면 같은 비활성 규칙을 따른다.
  다른 유물이 일반 효과 태그를 부여하는 것만으로 전용 대상 조건을 대신 충족하지 않는다.

## 판매와 분쇄 — 대화 결정

- 유물은 상점에서 판매할 수 없다.
- Maintenance에서 유물을 분쇄해 **기존 장비 가루**를 얻을 수 있다.
- 장착 중인 유물도 사용자 확인 후 자동 해제하여 분쇄할 수 있다.
- 분쇄한 유물을 장비 가루로 활용하는 것이며, 유물 강화용 재료나 별도 유물 강화 경제를 만들지 않는다.
- 유물별 분쇄 획득량은 후속 콘텐츠·밸런스에서 정한다.

## 상태 보존과 전투 수명 — 대화 결정

### 체크포인트

유물의 보유 수량과 장착 상태는 체크포인트에 포함하며, 불러오면 저장 시점 그대로 복원한다.
구체적인 저장 shape와 기존 저장 데이터의 전환 방식은 구현 검토 대상이다.

### 전투마다 초기화

- 유물 효과로 쌓이는 스택·발동 횟수 등의 누적 상태는 해당 전투 안에서만 유지한다.
- 다음 전투를 시작하면 초기화하며 이전 전투의 누적 상태를 이월하지 않는다.

### 같은 전투에서의 재배치

- 재배치하면 스택 같은 일시 상태는 초기화한다.
- '전투당 N회' 효과의 사용 기록은 같은 전투의 재배치로 되돌리지 않고 유지한다.
- 따라서 재배치가 전투당 효과 사용 제한을 초기화하는 수단이 되지 않는다.

기존 룰북의 전투 후퇴와 같은 process 재접속 계약에 연결할 구체적인 상태 구성·복원 경로는 코드 검토에서
확인한다. 이번 기록만으로 해당 경로가 구현 또는 검증됐다고 판단하지 않는다.

## 침식과의 경계 — 대화 결정

이 절의 침식은 **파편 침식형: 현재 전장에 있는 적을 즉시 kill 판정하고 연출을 진행하는 행동**이다.
위에서 정의한 `침식된 유물`의 변형 상태와 구분한다.

- 침식에는 유물의 증폭, 추가 효과와 연쇄 발동을 적용하지 않는다.
- 침식 처치로 유물·장비·파편의 처치 시 효과와 적의 사망 시 발동 효과를 발생시키지 않는다.
- 다만 죽은 적은 웨이브 정리, 다음 웨이브 진행과 승리 조건 검사에서 정상적인 처치로 인정한다.
- 현재 적의 처치와 정상적인 진행 판정을 뜻하며, 남은 전투 진행을 무시한 무조건 즉시 승리로
  치환하지 않는다.

[침식 시스템 메모](ego_corrosion_system_design_notes_2026-08-19.ko.md)가 침식의 발동 조건·직원의 대가·
연출 정책을 소유한다. 2026-09-06 후속 침식 대화에서 발동 조건을 운영 리스크 중심으로 변경했고,
위의 처치·효과 미발동·진행 판정 경계는 유지했다. 원본 환상체의 등장 연출을 유물 효과가 작동하는
일반 소환·스킬 경로로 해석하지 않는다. 구체적인 연출 구현은 후속 코드·설계 검토 대상이다.

## 전투력과 표시 — 대화 결정

- 현재 활성화된 유물 효과를 Certified 전투력 평가에 포함한다.
- 그 평가가 이후 Endless 층의 난이도 결정에도 반영되도록 한다.
- 조건부 효과와 태그 변형을 어떻게 평가하고 가중할지는 대표 유물과 실제 코드를 검토한 뒤 정한다.
- 무기·파편 설명에서 유물로 추가·강화된 효과와 적용 조건을 확인할 수 있게 한다.
- 어떤 유물 때문에 바뀌었는지도 확인할 수 있게 한다.
- 구체적인 UI 배치, tooltip 형식과 계산 결과 전달 구조는 후속 설계에서 정한다.

## 획득 정책 — 사용자 보류

일반 유물의 구체적인 획득처는 추후 논의하기로 했다. 후속 대화에서 침식된 유물은 직접 드롭하지
않고 침식 아이템을 기존 유물에 적용해 얻는 방식만 정했으며, 침식 아이템의 획득처는 미정이다.
다음 사항은 미결정이며 이번 대화의 다른 결정으로 자동 채택하지 않는다.

- 첫 파편 획득 시 호환 유물 3개 중 1개를 함께 고르는 보상의 채택 여부.
- 유물 획득처, 층별 제공 빈도와 수량.
- 후보의 종류·비율·호환성 기준과 후보 부족 처리.
- 선택 개수, 건너뛰기와 재추첨 등 획득 선택 방식.

기존 노트의 후보는 아래에 참고로만 보존한다.

| 기존 획득 후보 | 현재 취급 |
| --- | --- |
| 최초 파편 획득 시 호환 유물 선택 | 보류. 보상 지급을 확정하지 않음. |
| Reward node의 RelicCache에서 3개 중 1개 선택 | 보류. 전용 선택 흐름과 후보 구성 미결정. |
| Unknown Shop의 고가 구매 offer | 보류. 판매 금지 결정이 구매처 채택을 뜻하지 않음. |
| 위험·대가를 교환하는 Event | 보류. |
| NormalBoss 반복 격파 보상 | 획득처는 보류. 이전의 '기존 유물 강화 선택'은 강화 없음 결정과 맞지 않아 채택하지 않음. |
| FinalBoss·숨겨진 보스 보상 | 보류. 호환성은 위 범용·전용 정책을 따름. |
| 일반 Combat 무작위 drop | 채택 여부 미결정. 이전 노트는 기본 획득처로 삼지 않는 방향을 선호했음. |

일반 보스 재조우는 장비·재화 파밍을 목적으로 별도 재설계한다. 보스 반복 격파를 유물 획득처로 채택할지는
계속 보류하며, 채택을 논의할 때 재조우 횟수와 보상 정책도 함께 확인한다.

## 대표 유물 설계 후 작성할 콘텐츠

유물의 재미와 강화·전문화·연결·전환 역할 분류, 기초 태그 초안과 환상체별 검토 순서는
[Run 유물 콘텐츠 설계 노트](../skills/run_relic_content_design_notes.ko.md)에 기록한다.
이 분류는 희귀도나 성장 단계가 아니며, 설명용 효과 예시를 개별 유물의 채택으로 해석하지 않는다.

**기초 태그 초안을 먼저 기록하고 스킬·유물에 적용하며 확장한다.** 대표 유물들을 설계한 뒤
실제 콘텐츠와 정식 태그 목록으로 다듬는다. 초안 기록은 유물 catalog, 정식 tag ID, 개별 유물 효과와
수치 또는 runtime 구현 계약의 확정을 뜻하지 않는다.

2026-09-07 첫 개별 유물 `깊은 쐐기`의 타격별 누적 피해 증가 구조를 합의했다. 기존 초안의
`연속타격` 명칭은 `다중타격`으로 정리한다. [개별 유물 설계](../skills/run_relic_content_design_notes.ko.md#깊은-쐐기--가칭)가
효과 구조와 합의·미정 상태를 소유하며, 희귀도는 희귀, 대체 이름은 `때린 곳 또 때리기`다.
타격당 `10%p`는 예시 수치다. 이 기록으로 구체적인 획득처·확률이나
runtime 구현 계약을 확정하지 않는다.

같은 날 후속 대화에서 `잔류형`으로 검토하던 태그 이름을 `소환물`로 정하고, **소환물로 피해를
입은 대상에게 5초간 받는 피해 증가를 부여하는 범용 유물**을 기록했다.
[소환물 범용 유물](../skills/run_relic_content_design_notes.ko.md#소환물-범용-유물--이름-미정)이
적용 범위와 합의·미정 상태를 소유한다. 이름·증가율·희귀도·재부여와 중첩 판정은 미정이다.

후속 여왕벌 검토에서 **가하는 회복량 `25~40%` 증가 범용 유물**을 추가했다.
[회복량 증가 유물](../skills/run_relic_content_design_notes.ko.md#가하는-회복량-증가--이름-미정)이
합의 범위와 최종 증가율·이름·희귀도 등의 미정 사항을 소유한다. 후속 대화에서는
[이로운 스택당 공격력 증가 유물](../skills/run_relic_content_design_notes.ko.md#이로운-스택당-공격력-증가--이름-미정)도
채택했다. **현재 보유한 이로운 스택 중 보유량이 가장 많은 한 종류의 수량만** 적용한다.
`5·3·2`스택이면 `5`스택분이며, 여러 종류의 수량은 합산하지 않는다. 스택당 증가율·이름·희귀도와
개별 스택 적용 범위는 미정이다. 별도 후속 대화에서 액세서리
`탐욕의 팔찌`는 사용 시 이로운 효과 한 종류의 스택을 전부 소비하고, 고정 시간 동안 소모량에 따른
단계별 공격력 버프를 얻는 액티브 구조로 변경했다. 상세 합의와 미정 사항은
[탐욕의 팔찌 설계](../skills/abnormality_skill_fragments_design_notes.md#액세서리--탐욕의-팔찌-가칭)가 소유한다.

눈의 여왕 검토에서는 **착용자의 파편 또는 무기가 부여한 냉기로 둔화된 적이 사망하면 빙결 잔영을
생성하는 전용 유물**을 채택했다. 빙설의 파도·서리 마검을 각각 냉기 출처로 인정하며 착용자 막타를
요구하지 않는다. [눈의 여왕 전용 유물](../skills/run_relic_content_design_notes.ko.md#눈의-여왕-전용-유물--이름-미정)이
합의·미정 상태를 소유한다. 침식 제외와 동일 유물 사본·효과의 순환 재발동 금지는 그대로 적용한다.

태아 검토에서 정한 단일 전환·효과 증폭은 2026-09-08 후속 결정으로 **범용 유물**로 옮기며,
포큐버스의 공용 보호막에도 적용한다. [단일 대상 전환·효과 증폭](../skills/run_relic_content_design_notes.ko.md#단일-대상-전환효과-증폭--범용-유물)은
여러 아군 지원을 한 명에 집중하고 효과량을 높인다. 포큐버스는 한 명만 사용하는 강화된 보호막으로
전환한다. 포큐버스 보호량은 기본 대비 **2배**를 채택하고, 침식된 유물의 **4배**는 패널티와 함께
확정할 비교값으로 둔다. 기본 보호량 식·대상 선정 세부는 미정이다. 태아 전용 유물은 이름·효과·수치 미정으로 정리한다.

**기본 파편 / 단일 전환 범용 유물 적용 / 침식된 범용 유물 적용** 시 태아의 기본 공격 피해
`20% / 40% / 80%`, 공격 속도 가산량 `15 / 20 / 30`은 기존 합의대로 유지한다. 이는 태아 적용 수치이며
모든 범위 효과에 쓰는 동일 증폭률은 아니다. 상태별 최종 증가량을 교체하며 서로 합산하지 않는다.
[태아 파편 기반 유물](../skills/run_relic_content_design_notes.ko.md#태아-파편-기반-유물)이 상세 수치와
분해 검토를 소유한다. 짧은 집중 `6~8초` 방향의 정확한 값·단일 선정과 범용 유물의 침식 패널티는
후속 설계하며, 태아의 집중을 포큐버스에 요구하거나 `8초`·HP `6%` 소비를 확정 수치로 승격하지 않는다.

후속 작성 대상:

- 기초 초안의 적용 사례를 바탕으로 다듬을 정식 효과 태그와 비호환 태그의 목록·의미.
- 대표 유물의 요구 태그, 부여 효과, 강화 항목, 중복 가능 여부와 비호환 조합.
- 대표 조합의 연쇄 발동과 순환 제한 적용 사례.
- 개별 유물 수치와 분쇄 시 장비 가루 획득량.
- 파편의 공격형·주문형·혼합형 분류와 계수, 무기별 능력치·강화 수치.
- 개화에 필요한 환상체 파츠와 선행 콘텐츠, 요구 수량.
- 콘텐츠를 바탕으로 한 전투력 평가와 밸런스 검토.

### 기존 기본 성능 방향 — 참고

아래는 이전 노트가 지향한 콘텐츠 방향을 보존한 것이다. 이번 대화에서 구체적인 성능 서열이나
대표 유물의 실제 성능을 새로 확정한 것은 아니다.

- 모든 파편은 호환 유물이 없어도 자기 역할을 완성한다.
- 유물 없는 NormalBoss 파편은 Elite 파편보다 높은 기본 성능을 지향한다.
- 투자한 Elite 파편은 특정 조건과 역할에서 유물 없는 NormalBoss 이상이 될 수 있다.
- 같은 투자량의 NormalBoss 파편은 전반적으로 더 강하거나 유연한 방향을 지향한다.
- Elite의 단순한 문법을 전문 빌드로 발전시키고, NormalBoss의 기존 선택·대가·전달 방식을
  다른 방향으로 활용한다.
- 순수 피해 증가 유물도 일부 후보로 두되, 규칙과 운용이 달라지는 조합을 중시한다.

### 기존 두건 관련 메모 — 콘텐츠 재검토용

붉은 두건의 용병 파편과 무기는 이전 노트의 첫 검토 예시였다. 당시 태그 후보는 다음과 같다.
이는 실제 태그 vocabulary의 확정 목록이 아니다.

| 대상 | 이전 태그 후보 |
| --- | --- |
| 기본형 | Trajectory, Projectile, BountyMark, KillStack, PlayerTile |
| 개화형 | Contract, Projectile |
| 권총 | BasicAttack, Projectile, Ranged |
| 도끼 | BasicAttack, Melee, Block |

기존 아이디어는 창 생성, 지정·집중사격, 선불 계약, 권총·도끼 전환, 저지 시 도끼 공격과
대상 선정의 변형이었다. 현상금 대상, 저지 중인 적, 집중사격 탄도 중첩 같은 조건의 피해 증폭도
검토 대상으로 남아 있다. 실제 유물은 대표 설계 이후 태그 기반 정책에 맞춰 작성한다.

이 밖에 이전 노트의 계통 태그 후보였던 Heal, Summon, Channel, TileArea도 참고로만 보존한다.
이 후보 목록이 실제 지원할 태그나 유물을 확정하지 않는다.

### 기존 흉탄 관련 메모 — 콘텐츠 재검토용

이전 노트는 흉탄의 사수 보상 파편의 기본형 마탄과 개화형 흉탄, 저격총·산탄총 전환,
1~6번째 일반 사격과 7번째 자해 계약을 콘텐츠 배경으로 삼았다.

당시 유물 아이디어는 7번째 계약 탄환의 최초 관통 대상을 사용자에서 적격 아군 1명으로 바꾸는
것이었다. 관통당한 아군이 전투불능이 되어도 이미 발생한 강화 산탄과 후속 확산은 끝까지
처리하고, 사용자의 HP 보존과 아군 타일을 산탄 원점으로 삼는 위치 이득을 검토했다.

이 메모를 특정 파편 ID 전용 유물의 구현 지시로 사용하지 않는다. 대표 유물 설계에서 채택할 경우
범용·전용 호환 범위와 이번 공통 정책에 맞게 구체화한다. 다음 사항은 계속 미정이다.

- 아군의 수동·자동 선정, 사전 표식과 피해 preview.
- 대상 소실 시 재선정과 아군 부재 시 처리.
- 아군 타일을 산탄 원점으로 사용하는 안의 채택.
- 기본형에도 적용할지 개화형에만 적용할지와 이를 표현할 실제 태그 조건.

## 후속 코드·설계 검토

다음은 공통 정책을 실제 프로젝트에 연결하기 위한 검토 항목이다. 구현 방식을 임의로 고정하거나
이번 기록을 최종 정책 동결로 간주하지 않는다.

- 기존 파편 강화·보상·세이브의 전환 처리.
- 무기 주문력, 파편 계수와 개화 재료의 실제 데이터·산술 경계.
- 태그 기반 유효 효과 구성, 비활성 판정과 비호환 검사.
- 새 효과의 출처, 연쇄 경로와 동일 사본·효과의 순환 재발동 차단.
- 유물 사본·장착·분쇄·사망 회수·체크포인트의 소유와 상태 변경 경계.
- 전투별·재배치별 상태 수명, 후퇴와 재접속 경로.
- 침식의 kill 판정, 효과 미발동과 정상적인 웨이브·승리 판정의 분리.
- 활성 유물의 전투력 평가와 변경 효과·조건·원인 표시.
- RON schema, 내부 타입·모듈 배치, validation, 저장·projection 구조.

검토 중 새로운 gameplay 의미나 저장 데이터 손실·전환 선택이 필요하면 사용자와 별도로 결정한다.
플레이어 표시명의 최종 확정과 내부 code identity의 명명도 현재 기록으로 고정하지 않는다.
