# 차기 룰북 후속 정책 합의 기록

작성일: 2026-09-10.

상태: **후속 사용자 합의 기록 / 2026-09-26 차기 문서 통합 반영 / 최종 동결·구현 상태는 별도.**

> **2026-09-26 통합 기록:** 아래 9월 10~13일 합의 19개를 [차기 게임 설계서](../game_rulebook.md)와
> 주제별 규칙에 통합했다. 각 항목의 기존 ‘미반영’·‘미정’ 표시는 기록 당시 상태로 보존하며,
> 최신 반영 위치·후속 대체 관계는 [통합 대응표](../decisions/game_rulebook_next_restructure_2026-09-26.md#후속-합의별-반영)를 따른다.
> 현재 gameplay canonical 교체·최종 동결·구현 완료를 뜻하지 않는다.

## 기록 범위와 원칙

사용자 요청:

> 지금부터 새로 합의하는 내용은 임시문서에 기록해두자. 나중에 구별하기 쉽게 말이야

- 위 요청 이후 새로 합의한 게임 정책을 이 문서에 날짜·주제별로 기록한다.
- 사용자 합의, AI 제안, 미정 사항을 구분한다. 설명용 예시나 AI 추천을 합의로 올리지 않는다.
- 각 합의에는 적용 범위, 기존 규칙과의 관계, 남은 결정 사항과 룰북 통합 여부를 함께 남긴다.
- 새 합의를 기록할 때마다 기존 룰북이나 새 룰북 본문을 자동 수정하지 않는다. 나중에 사용자가
  통합을 요청하면 해당 합의를 반영하고 이 기록에 반영 위치·날짜를 남긴다.
- 후속 합의가 이전 결정을 바꾸면 이전 내용을 지우지 않고 변경된 항목과 대체 관계를 표시한다.
- 이 기록 자체는 runtime·RON·Unity 계약·세이브 변경이나 구현 완료를 뜻하지 않는다.

## 새 정책 합의

### 2026-09-10 / 최초 저지 위치와 두 좌표의 역할

상태: **사용자 정정·합의 / 룰북 미반영**.

사용자 설명:

> 아군은 타일의 중앙에 서있지만, 적군은 타일의 끝자락에서 싸우고 있어.
> 즉, 저지 유닛 바로 타일 앞까지 왔어도 타일 중앙이나 타일 진입하자마자 저지 되는것이 아니야.

합의 내용과 적용 예시:

- 직선 route의 최초 접근 예시에서 아군 A는 자신의 타일 중앙에 서 있다.
- 적 B는 A 앞 타일에 진입한 즉시 저지되지 않는다. 해당 타일의 중앙에서도 멈추지 않고,
  A에 가까운 쪽 끝자락까지 연속 좌표상으로 이동한 뒤 저지되어 싸운다.
- 따라서 앞 타일에 있다는 사실만으로 저지를 성립시키지 않는다. 그 타일 안에서도 연속 좌표가
  실제 저지 위치에 도달했는지 구분해야 한다.
- 이때 B의 판정용 타일은 여전히 A 앞 타일이다. 연속 좌표상으로 아군 가까이에서 멈추는 것과
  판정용 타일을 아군의 타일로 변경하는 것은 별개다.
- 연속 좌표는 실제 이동·거리·충돌 판정에 쓰이는 게임 상태다. 연속 좌표상의 접근과 정지를
  화면상의 연출 보정만으로 설명하지 않는다. 스프라이트 등의 순수 시각 보정과 구분한다.

기존 규칙과의 관계:

- 새 룰북에 이미 기록된 최초 저지 적의 앞 타일 유지, 아군 타일 통과 중 저지 적의 해당 타일
  유지는 계속 유지한다. 이번 합의는 그중 최초 접근 시 실제 정지 시점을 구체화한다.
- 앞선 AI의 연속 위치를 단순 연출로 취급한 설명과 아군의 중앙 배치까지 불명확하게 표현한
  설명을 정정한다. 타일 진입 즉시 정지하거나 타일 중앙으로 정렬하는 정책을 추가하지 않는다.
- 앞선 GIF는 위치 관계를 설명하는 참고 자료다. 영상에서 원작 내부 좌표나 정확한 반경을
  측정·확정한 것으로 취급하지 않는다.

미정 사항:

- 정확한 저지 거리·범위와 타일 경계에서의 판정 기준.
- 여러 방향의 접근, 중간 저지의 연속 좌표 정지 위치, 복수 적의 배치·겹침 처리 세부.
- 신규 저지 후보 우선순위, 이동·사망·새 저지 판정 순서와 실제 거리 이탈 시 해제 조건.

룰북 통합: **미반영**. 현재 룰북·새 룰북·구현 계약·코드에는 이번 정정을 아직 반영하지 않는다.

#### 현행 코드 확인 — 같은 날 후속 대화

아래는 신규 정책 승인과 별도로 확인한 작업 트리의 구현 사실이다. 사용자는 설명을 듣고 이미
원하던 구조가 구현돼 있는지 확인했다. 코드 열람에 근거하며 실제 전투 실행 검증은 수행하지 않았다.

- 현재 한 타일은 연속 좌표 1.0이며, 직원 기본 프로필의 저지 반경은 0.75다. 새 저지는 저지
  여유·대상 자격과 아군·적 중심 간 연속 좌표 거리를 검사한다.
- 같은 가로줄에서 접근할 때 앞 타일 중앙은 아군 중심에서 1.0 떨어져 있으므로 저지 반경 밖이다.
  거리가 0.75가 되는 지점은 아군 타일 경계보다 바깥쪽으로 0.25 떨어진 앞 타일 내부다.
- 타일 좌표는 연속 좌표를 내림해 얻는다. 확인한 좌표·범위 조회 경로는 저지가 성립했다고 적의
  좌표를 아군 좌표로 덮어쓰지 않는다.
- 기존 저지 관계를 먼저 유지한 뒤 남은 저지 수로 범위 안의 미저지 적을 검사한다. 따라서 저지
  여유가 생기면 아군 타일 안을 통과 중인 적도 현재 위치에서 새 저지 후보가 된다.
- 현재 이동 갱신 간격은 50ms이며 저지된 적의 이동을 제한한다. 정확히 반경 경계에 위치를 맞추는
  방식은 아니므로 실제 정지 위치는 이동 속도·검사 시점에 따라 달라질 수 있다.
- 이미 맺어진 저지 관계를 유지할 때는 거리를 다시 검사하지 않는다. 이 거리 해제 정책은 앞서
  남긴 미정 사항과 구분해 계속 검토한다.

따라서 최초 접근 시 앞 타일 내부에서 멈추는 구조, 현재 위치에서의 타일 계산과 통과 중 재판정은
현행 코드에 존재한다. 앞선 사용자 설명을 전부 미구현 기능으로 분류하거나 이 구조를 다시 만드는
작업을 시작하지 않는다. 기존 룰북의 표현과 실제 코드의 관계는 별도로 확인한다.
현행 수치 0.75·50ms를 조사한 것만으로 차기 정책의 확정 수치로 채택하지 않는다.

### 2026-09-12 · 엔케팔린 공통 비용과 개화 재료·상점 구분

사용자 확정 내용:

- 경제 사용처로 강화 시스템, 개화 시스템, 본부 상점, 일반 떠돌이 상점, 특수 떠돌이 상점이 존재한다.
- 엔케팔린은 범용 재화이며, 사용자는 “모든 행동엔 엔케팔린이 사용”된다고 명시했다. 이번 대화의
  강화·개화·상점 경제에서 공통 비용으로 요구한다. 전투 배치·이동 등까지 엔케팔린 비용을 새로
  적용하는 범위는 이번 발언만으로 확장하지 않는다.
- 환상체를 격파하면 얻는 환상체 파츠 같은 특수 재료가 있으며, 파편 개화에 사용한다.
- 어려운 보스의 파츠를 개화 재료로 요구하여 개화 접근 난이도를 조절한다. 개별 보스·파츠·recipe,
  지급 수량·확률·필요 수량과 대체 획득처는 아직 정하지 않았다.
- 본부 상점에서는 일반 아이템, 섭취 아이템, 구급상자 등을 엔케팔린으로 구매한다.
- 일반 떠돌이 상점과 특수 떠돌이 상점의 역할·상품·추가 비용은 검토 중이다.

기존 규칙과의 관계·남은 결정:

- 파츠의 개화 사용은 확정한다. 기존 파편 가루를 함께 요구하는지, 대체하는지는 미정이다.
- 기존 장비 가루 및 일반 전투의 무기 강화 필수 재료와 엔케팔린의 동반 비용 관계는 추가로 정한다.
- 상점 출현·접근 주기, 재고·가격·갱신·판매, 파츠 거래 가능 여부와 상점별 독점 상품은 미정이다.
- 이번 합의만으로 별도 상점 전용 화폐를 추가하거나 특수 떠돌이 상점의 파츠 결제를 확정하지 않는다.

### 2026-09-12 · 일반 보스 분류 통일

사용자 원문:

> 일단 아종, 특수 등 수식어를 제거하고 모두 일반 보스로 통일해줄래?

직전 대화에서 열거한 엘리트·최종 보스 외 14개 항목을 모두 **일반 보스**로 분류한다.
음/양은 하나의 항목이다. 기존 아종·특수·숨겨진 보스라는 별도 분류는 사용하지 않는다.

| 분류 | 대상 |
| --- | --- |
| 일반 보스 | 아무 것도 없는, 웃는 시체의 산, 녹아내리는 사랑, 탐욕의 왕, 파고드는 천국, 마탄의 사수 |
| 일반 보스 | 절망의 기사, 증오의 여왕, 붉은 두건의 용병, 커다랗고 나쁠 늑대, 죽은 나비들의 장례, 음/양 |
| 일반 보스 | 죽을 나비의 장례, 흉탄의 사수 |

- 명칭·분류의 통일이다. 선행 Event, 동행·계약, 알 부화, 별도 발현 조건, 승패와 보상은 유지한다.
- ‘아종’이라는 원본과 파생 개체의 콘텐츠 관계나 ‘숨겨진 조우’라는 등장 방식은 설명에 남을 수 있지만 별도 보스 등급으로 사용하지 않는다.
- 같은 일반 보스라는 이유로 모든 조우를 동일한 무작위 배정 풀이나 고정 보상에 넣지 않는다.
- 엘리트·최종 보스 분류는 유지한다. 같은 날 후속 결정으로 준최종 보스 구분은 폐기했다.
- 기존 파편 역할 집계와 첫 유물 콘텐츠 검토에서 흉탄을 제외했던 범위는 유지하되, 제외 대상을 이름으로 명시한다.

### 2026-09-12 · 8층 배치와 준최종 폐기·연속 조우의 시작 순서

사용자 원문:

> 준최종보스도 그냥 잊어주고 엘리트 4개 일반 보스3개 최종보스 하나로 하자.
> 대신, 절망의 기사, 증오의 여왕, 두건과 늑대 등.
> 여러 턴에 걸쳐서 진행되는 보스들 있지? 그것들은 1번째에 무조건 나오게 해야돼.

직전 사용자가 명시한 층 순서를 이어받고 6층 준최종을 일반 보스로 변경한다.

| 층 | 보스 분류 |
| --- | --- |
| 1 | 엘리트 |
| 2 | 일반 보스 |
| 3 | 엘리트 |
| 4 | 일반 보스 |
| 5 | 엘리트 |
| 6 | 일반 보스 |
| 7 | 엘리트 |
| 8 | 최종 보스 |

- 엘리트 4회·일반 보스 3회·최종 보스 1회의 8층 구성이다. 준최종 보스 분류와 승격 후보 검토를 폐기한다.
- 절망의 기사·증오의 여왕·두건과 늑대처럼 여러 단계에 걸쳐 이어지는 보스가 해당 런에 등장하면 **첫 일반 보스 자리인 2층에서 반드시 시작**하도록 배치한다.
- **사용자 확인 완료:** “맞아, 첫 일반 보스 자리인 2층.” 따라서 1층 시작을 뜻하지 않으며, 4·6층에서 해당 연속 조우를 처음 시작하는 배정은 하지 않는다.
- 이 발언만으로 열거한 보스 전부가 매 런 동시에 등장한다고 결정하지 않는다. 한 런의 후보 선정·동시 진행 수는 별도 설계한다.

- 이동 가능한 전투 맵에서 마우스 드래그에 더해 방향키 ↑·↓·←·→로도 카메라를 움직인다.
  고정 맵의 지정 구도는 유지한다.
- 직전 논의의 고스트·방향 설정 중 원거리 시야 이동을 방향키로 지원한다. 선택 중인 유닛과
  입력 단계는 유지하고, 카메라 이동만으로 배치/교대를 확정하거나 취소하지 않는다.
- 타일 선택 전에는 이동된 시야의 커서 아래 후보 타일을 미리 본다. 방향 설정 중에는 선택한
  전장 타일에 고스트를 고정하며 카메라 이동만으로 방향을 바꾸지 않는다.

위임에 따른 기본 조작:

- 화면 기준 방향으로 누르고 있는 동안 이동하고 놓으면 멈춘다. 방향키로 유닛 방향 설정을
  중복 실행하지 않는다. 기존 맵 이동 범위는 유지한다.
- 수동 방향키 입력은 더블클릭 자동 카메라 이동을 중단한다. 정지·감속 중에도 카메라 입력은
  가능하며 카메라 때문에 전투 배속을 바꾸지 않는다.
- 설정 메뉴·텍스트 입력 등 전장 입력을 가로채는 UI는 해당 입력을 우선한다.

기존 기록과의 관계:

- B18의 고스트·방향 설정 중 카메라 보조 입력 미정을 방향키 지원으로 구체화한다.
- AI가 제안했던 마우스 가운데 버튼 드래그를 필수 입력으로 채택하지 않는다. 로스터 초상화
  더블클릭의 위치 찾기는 기존 합의대로 유지한다.
