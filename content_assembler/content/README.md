# 프로젝트 콘텐츠 폴더

> 2026-10-22: 아래 P1–P6 절의 수치·검사 개수·미구현 표시는 해당 단계 당시 기록이다.
> 현재 지원 대상은 공통 Core 컴파일·IR/RON·전투 실행에 연결되어 있으며 최신 결과는
> [작업 파이프라인](../docs/skill-authoring-pipeline.tmp.md)을 따른다. 원본의 미정 밸런스 값은 유지한다.

노드 화면의 **그래프 목록**(Ctrl+O)은 이 폴더의 `*.node-graph.json` 파일 목록과 실제 경로를 표시한다.
**새 그래프**는 빈 문서를 만들며, 노드 화면의 초기 문서도 빈 그래프다.
**저장**은 같은 폴더에 파일을 기록하며, 성공한 파일을 편집기의 저장 기준으로 삼는다.

- `hello-goodbye.node-graph.json`: 편집 가능한 Hello / Goodbye 시작 예제.
- 다른 위치에 있는 파일은 그래프 목록의 **다른 위치에서 가져오기**로 읽은 뒤 이 폴더에 저장한다.
- 내려받을 사본이 필요하면 **JSON 내보내기**를 사용한다.
- 새 파일 이름이 기존 파일과 겹치면 다른 이름을 사용한다. 기존 파일을 수정하려면 먼저 열고 저장한다.
- 읽은 이후 외부에서 변경된 파일은 덮어쓰지 않는다. 다시 열거나 다른 이름으로 저장한다.

현재 이 폴더의 UI 연결 대상은 **노드** 작업 공간이다. 맵·기존 스킬 화면의 파일 동작은 별도다.
하위 폴더 탐색과 파일 삭제 기능은 제공하지 않는다.

프로젝트의 `npm run dev`, `npm run preview`, Tauri 개발 앱에서 이 폴더를 사용한다.
프로젝트가 없는 배포용 데스크톱 앱은 운영체제의 앱 데이터 디렉터리 아래 `content`를 사용한다.
실제 경로는 그래프 목록·저장 창에 표시한다. 정적 웹 배포만으로는 로컬 콘텐츠 폴더에 접근할 수 없다.

## 그래프 그룹

그룹 제목을 클릭하거나 키보드로 선택한 뒤 Enter/Space를 누르면 소속 그래프를 펼치거나 접는다.
제목 옆 숫자는 현재 폴더에 있는 소속 그래프 수다. 그룹에 넣지 않은 파일은 **미분류**에 표시한다.
공명 소비 예제 9개는 **공명 소비 예제** 그룹에 묶여 있고, Hello / Goodbye는 미분류에서 연다.

1. **그룹 편집** → **그룹 추가**로 빈 그룹을 만들고 이름을 입력한다.
2. 각 파일의 소속 목록에서 그룹 또는 미분류를 선택한다. 한 파일은 한 그룹에만 속한다.
3. 이름 변경과 **그룹 해제**도 같은 화면에서 준비한다. 그룹 해제는 소속 파일을 미분류로 옮긴다.
4. **그룹 적용**이 성공하면 저장된다. **편집 취소** 또는 Escape는 준비한 변경 전체를 취소한다.
   편집을 마친 뒤 Escape는 목록 창을 닫고 원래 버튼으로 포커스를 돌린다.

그룹 편집 중에는 그래프 열기·새로고침을 막고, 저장 중에는 중복 적용·닫기를 막는다.
빈 이름·중복 이름·중복 소속은 적용할 수 없다. 그룹은 최대 200개, 이름은 최대 80자다.
새로 저장한 그래프는 미분류에 나타나며 목록에서 소속을 정할 수 있다.

소속과 이름은 같은 폴더의 `.graph-groups.json`에 저장한다. 그래프 파일의 이름·위치·내용은 바뀌지 않는다.
그룹이 없던 폴더는 기존 파일 전체를 미분류로 표시한다. 외부에서 파일을 지우면 목록에서 사라지지만
그룹 소속은 보존하여 같은 이름으로 복원하면 원래 그룹에 나타난다. 그룹 해제는 파일을 삭제하지 않는다.
접고 펼친 상태는 현재 목록 창에서만 유지한다. 그래프의 Undo/Redo와 미저장 여부는 그룹 편집과 별개다.

그룹 저장도 기존 파일 저장과 같은 잠금·임시 파일 교체·리비전 충돌 검사를 사용한다.
외부 변경 충돌은 초안을 유지한 채 알린다. **편집 취소 → 새로고침** 후 최신 목록에서 다시 편집한다.
손상된 그룹 파일이나 읽기 오류를 빈 그룹으로 덮어쓰지 않는다. 브라우저와 Tauri 파일 계층이 같은 계약을 쓴다.

## 공통 범위 구조 예제

- `range-front-strike.node-graph.json`: 순수 스킬 범위 → 시전자 기준 배치 → 전방 일격. 위치와 방향 고정 시점은 미정이다.
- `range-selected-ground.node-graph.json`: 대상 선택 범위 → 지정 타일 요청·접수와 효과 범위 → 고정 장판 생성을 분리한다.

지정 타일 장판은 ㄱ자를 포함한 비대칭 패턴도 작성한 방향 그대로 놓는다. 시전자 방향으로
회전하거나 뒤집지 않는다. 범위·유지 시간·피해 수치는 실제 콘텐츠 밸런스로 채우지 않았다.
이 예제는 범위 구조 확인용이며, 장판의 피해·회복·진입·체류·주기 효과는 아직 연결하지 않았다.
기존 Hello / Goodbye 예제와 기존 파일은 자동 변환하지 않는다.

## 장판 사건·효과 예제

- `ground-damage.node-graph.json`: 장판 주기 → 현재 대상별 실행 → 피해.
- `ground-heal.node-graph.json`: 장판 주기 → 현재 아군 대상별 실행 → 회복.
- `ground-status.node-graph.json`: 진입 둔화·체류 후 기절·이탈 표시·장판 종료. 상태 수명과 중첩은 정의별 설정이다.

첫 발동은 생성 즉시/한 주기 뒤 중 선택한다. 생성 당시 내부 대상도 진입으로 처리하며
장판 종료 시각의 주기 효과는 발생하지 않는다. 상태는 이탈 시 해제하거나 장판 종료까지
유지하도록 설정하고, 수치 효과의 중첩은 합산/가장 강한 값을 선택한다. 기절은 수치 입력이 없다.
장판 종료는 해당 장판의 상태 기여분만 정리한다. 자동 수명을 보이기 위해 이탈 사건에 강제 해제를
덧붙이지 않았으며, 더 이른 해제가 필요한 그래프에서는 명시 해제 동작을 연결할 수 있다.

수치와 미정 정책은 비워 둔 작성 예제다. 실제 전투 효과·Core 실행 검증은 포함하지 않는다.

## 파고드는 천국 기본형

`burrowing-heaven.node-graph.json`은 공명 만충·전량 소비 → 집중 → 시전 위치에 고정된 종속 장판을 작성한다.
집중 중 기본 공격을 중지하고 직접 취소를 허용한다. 장판 진입의 20% 증폭과 체류에 따른 선형 둔화,
도달 후 장판 종료까지 유지하는 기절, 시작·종료의 빨간 눈 연출을 연결한다. 모든 집중 종료에서 종속 효과를 정리한다.

최대 공명·최대 집중 시간·장판 범위·기절까지 체류 시간·최대 둔화율의 다섯 값은 아직 미정이다.
진단을 통해 해당 값을 찾을 수 있으며 미정 상태 그대로 저장·재열기할 수 있다. 수치를 채워 진단이 없어져도
Core 실행 완료를 뜻하지 않는다. 유물 자동 변형과 독립 수명 약화는 후속 작성 범위다.

## P5 감염·나비 폭발 작성 예제 — 2026-10-22

- `melting-love.node-graph.json`: 공격형의 출처별 감염망·연속 위력·기폭. 고기벽은 보류 범위다.
- `funeral-of-dying-butterflies.node-graph.json`: 전체 경로를 덮는 지연 폭발.
- `funeral-of-dying-butterflies-bloom.node-graph.json`: 무기 표식의 사망 타일 이전과 등급별 폭발.
- `funeral-of-dying-butterflies-orb.node-graph.json`: 검은 고치 적용 구성. 구체 범위는 별도 미정이다.

각 그래프의 미정 작성값은 각각 9·3·6·10개다. 실제 Core 실행 준비 완료와 구분한다.
배포 예제는 연결 방향으로 배치했으며 **흐름 정렬**을 다시 실행해도 의미·ID·연결은 유지한다.
캔버스의 값 버튼과 입력 옆 연결값 버튼으로 편집하고 한 번에 실행 취소할 수 있다. 공유값 표시는
다른 소비자에도 같은 값이 적용된다는 뜻이다. 상세 검사 상태는 [파이프라인](../docs/skill-authoring-pipeline.tmp.md)을 따른다.
