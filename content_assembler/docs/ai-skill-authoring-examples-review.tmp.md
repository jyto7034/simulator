# 대표 스킬 작성·대조 — 3단계 자체 재검토 기록

작성일: 2026-10-23. 같은 작성자가 수행하는 자체 재검토이며 독립 감사가 아니다.
대상은 [예시 진입점](ai-skill-authoring-examples.tmp.md)과 연결된 예시, 필요한 [구조 초안](ai-skill-authoring-data-model.tmp.md) 보완이다.
현재 상태: 작성·의미 대조·발견 선기록·교정·교정 후 자체 재검토 완료. 저장소 최종 검사는 아래 결과에 기록한다.

## 1. 입력과 범위

기준은 최신 위키·사용자 요청과 1·2단계 7문서다. 일반 리워크·엘리트 잠정·최종보스/보류 제외를 유지한다.
작업 시작 7문서의 사본/지문과 기존 dirty 목록을 보존했다. 제품 코드·콘텐츠 원문·Forge 고정 사본은 수정하지 않는다.
포큐버스→Hello / Goodbye→여왕의 전체 작성, 다섯 추가 경계, 67행 대조와 편집/진단 과제가 대상이다.
문서상 대조·정적 코드 조사·실제 실행을 구분한다. 과거 검토 기록은 덮어쓰지 않는다.

## 4. 교정 후 재검토

R01~07을 교정한 문서와 G01의 집계 정의를 다시 고정하여 원문·정의·흐름·대응표를 재독했다.
제품 실행 결과는 없으며 아래 검사는 문서 완성과 저장소 정적 검사 범위다.

재검토 발견 R08(C12/N09-c): V05 분류는 공통표에 있으나 실제 원본 속성에서 확인된 미지원과
미확인을 비교하는 과제가 부족했다. 교정 전에 기록한다. 현재 overlay lower의 curve 거부 분기를 읽고,
HG.v.pierceCurve의 미정(V01)·작성된 비선형 후보의 현 target 미지원(V05)·장비 종단 미확인(V06)을 HG.edit6에서 분리했다.
기능 이름만으로 Core 전체에 비선형 계산 능력이 없다고 확대하지 않는다.

재검토 발견 R09(C07/N02): QH.v의 공유 기간/주기/하트상한을 선언했지만 phase/조건 표에 같은 숫자를
직접 반복해 독립 원본으로 읽힐 여지가 있었다. 공유 편집 전후의 전파를 보장하려면 해당 행에서 값 정의를
참조해야 한다. phase 기간·tick, 상한/예약 조건·수동입력 상한을 명시 참조로 교정하고 괄호 숫자는 현재 해석값으로만 둔다.

### 재검토 결론과 남은 범위

- G01과 R01~R09의 교정을 다시 대조했다. 독립된 기본 action 집계와 광선 시전 집계, 취소 폐기/방출 child 수명,
  접수 영수증과 실제 대체 판정, 여왕 공유값의 단일 원본을 확인했다. 해결하지 못한 필수 구조 결함은 이번 작성 범위에서 발견하지 못했다.
- PC는 방출 대상·단계별 내림·개인 잔량/부분 교체/이탈·HP비용 우회와 단일/고리 미정 합성, HG는 방출 교체·활성 소비 전 시간 고정·공명 잠금·직접HP합산·장착무기 흡혈만,
  QH는 사본하트/기억·예약 대기·반열린 단계·자연완료 보상·강제중단·유물7개와 장비 실제회복 연결을 확인했다.
- A1~A5는 확정 전 취소/정지 복원, 한 회차 기본회복 뒤 전달, 승급거래/사본별상태, 사망 전후 출처와 중복키,
  대여이력/승패정산/Retreat의 수작업 반례를 포함한다. 전체 스킬 실행으로 확대하지 않는다.
- 원문 ID→작성 정의→그래프/속성→진단→실행역할→cue를 문서에서 추적할 수 있다. 같은 원본 편집·공유 영향·오류식 보존·Undo/Redo·저장 snapshot·오래된 비동기 결과와 배치를 구분했다.
- 67행 모두 대응하며 전체/부분/공통 참조·미정/보류를 나눈다. 공통 행의 개별 스킬 흐름과 모든 장비/유물 조합은 추가 검증이 필요하다.
  엘리트는 잠정, 최종보스/보류형태는 새 요구로 추가하지 않았다.
- 남은 콘텐츠 결정은 PC 계수/범위/기간/단일·고리 합성, HG 곡선/상한/흡혈 정수화, QH 위력/형상/자동광선기간·유물/결계 세칙,
  공통 침식 임계치·자동/재입력 종단 경계, 시체경합 등이다. 정확 타입/이유/선택 의존은 각 U와 추가 대응표에 남겼다.
- 연출 자산·상세시계/부착·미정연출 산출 허용 정책(D05), 새원본 파서/공유정의/진단 위치·저장/원정복원·Rust/Unity 종단은 미정 또는 미확인이다.
  비선형 관통은 현 overlay lower의 거부 경로만 확인했으며 Core 전체 미지원으로 확대하지 않았다.
- 4단계는 PC.edit1~6/HG.edit1~6/QH.edit1~6과 A1~A5를 그대로 후보 포맷 비교 과제로 사용한다. 실제 AI 비교/편집기 사용성은 아직 시험하지 않았다.

첫 npm run check는 typecheck/lint를 통과했으나 재검토 문서의 표 정렬로 format:check에서 멈췄다. 문서 포맷을 교정한 뒤 전체 check 재실행이 통과했다(typecheck, lint, format:check, contract:check).
