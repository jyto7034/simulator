# 전투 맵 조립기 프로토타입

## 작업과 실행

`content_assembler/`에서 `npm run dev` 후 안내된 로컬 주소를 연다.
브라우저에서 새 전장을 만들고 영역·지형·구역·경로·조건 웨이브를 작성한다.
`저장`은 JSON 다운로드 요청이다. 실제 내려받은 파일을 확인한 뒤 `다운로드 확인`을 누르면
해당 스냅샷을 저장 기준으로 기록한다. 확인 이후 편집은 계속 미저장으로 남는다.
`열기`는 파일 선택·읽기·구조 검사를 마친 뒤 현재 문서 교체를 제안한다.
파일 읽기부터 교체 확인까지 문서가 바뀌거나 더 최신 열기 요청이 시작되면 이전 결과를 적용하지 않는다.

도구 단축키는 왼쪽 팔레트와 툴팁에 표시한다. Ctrl+Z / Ctrl+Shift+Z(또는 Ctrl+Y)는
실행 취소 / 다시 실행, Ctrl+S는 다운로드, Ctrl+O는 열기다.
텍스트 입력·선택 상자·메뉴·대화상자·IME 조합 중 편집기 단축키는 동작하지 않는다.

- 브러시와 사각형은 포인터를 놓을 때 한 번 확정한다. Escape·포인터 취소는 미리보기를 버린다.
- 좌클릭은 현재 속성을 적용하고 우클릭은 해당 도구의 내용만 제거한다. 지형 도구에서는
  일반 바닥으로 복원하고, 구역 도구에서는 선택한 구역의 셀만 빼며, 유효 영역 도구에서는
  셀을 제거한다. 경로/지점 도구의 우클릭은 가리킨 점만 지운다. 선택 도구의 우클릭은 변경하지 않는다.
- Shift+좌드래그는 사각형 적용, Shift+우드래그는 사각형 제거다. 시작할 때 정한 범위를
  Shift를 놓아도 유지한다. 반투명 셀·점선 경계·셀 수로 미리 보고 마우스를 놓아 확정한다.
  Ctrl+Z 한 번으로 획 전체를 되돌린다. 경로/지점 도구에는 사각형 칠하기를 적용하지 않는다.
- 선택 도구로 경로 점·이름 있는 지점을 끌어 옮긴다. 경로 도구는 선택한 점 다음에 삽입한다.
  경로의 선분 또는 목록에서 경로 자체를 선택하면 마지막에 추가한다.
  같은 경로는 한 타일에 점 하나만 둘 수 있다. 세부 스냅에서도 같은 타일의 추가·이동·좌표 수정은
  거부하며 기존 위치와 이력을 유지한다. 서로 다른 경로는 같은 타일을 공유할 수 있다.
  기존 파일의 중복 점은 보존하고 `ROUTE_POINT_OVERLAP` 진단에서 해당 점으로 이동할 수 있다.
- 개별 타일을 선택한 뒤 편집 도구를 고르면 타일 선택을 해제한다. 도구 버튼·단축키·Q 메뉴에
  같은 규칙을 적용하며, 구역·경로의 작업 대상 선택은 유지한다. 속성 패널에서 셀 지형을 직접
  바꾸거나 화면 이동·확대를 할 때도 선택을 유지한다. Esc는 진행 중 작업을 먼저 취소하며,
  작업 중이 아닐 때 개별 타일 선택을 해제한다. 입력 필드·메뉴·대화상자의 Esc는 해당 UI가 처리한다.
- 이름·숫자 입력은 Enter 또는 포커스 이동으로 확정한다. Escape는 미확정 입력을 버린다.
  숫자가 아닌 입력은 포커스 이동 시 이전 값으로 복원하고 입력 아래 이유를 표시한다.
- 표시를 끈 레이어는 캔버스/목록에서 숨긴다. 잠금은 속성·삭제·이력까지 공통 적용한다.
  숨김과 잠금은 화면 상태로, 파일과 이력에 넣지 않는다.
- 하단 패널은 웨이브와 진단을 전환하며 `패널 확장`으로 높이를 늘릴 수 있다. 진단을 선택하면 대상과 관련 속성으로 이동한다.
- 휠과 확대 버튼으로 줌, 가운데 버튼 또는 H 도구로 화면 이동, 화면 맞춤으로 복귀한다.

### 캔버스의 빠른 도구 선택

마우스를 캔버스에 두고 **Q를 누른 채** 원하는 방향으로 이동한다. Q를 놓으면 강조된
도구가 선택되고 메뉴가 닫힌다. 선택/이동, 일반 바닥, 고지대, 장애물, 배치 구역,
등장 구역, 경로, 지형 지우기는 항상 같은 방향에 놓인다. 중앙 또는 원 바깥에서 놓기,
Esc, 창 포커스 이탈은 취소다. 화면 가장자리에서는 메뉴 전체가 보이도록 위치를 조정한다.
메뉴 선택 자체는 타일을 바꾸지 않으며, 선택 후 클릭·드래그로 편집한다.

캔버스 위 `도구 Q` 버튼으로도 열 수 있다. 방향키/Home/End로 이동하고 Enter로 선택하며,
Esc 또는 Tab으로 닫으면 호출 전 포커스로 돌아간다. 입력 중이거나 획을 그리는 동안에는
Q 메뉴를 열지 않는다.

배치·등장·경로 도구의 작업 대상은 캔버스 위 선택창에서 고른다. Q 메뉴는 현재 선택과
종류가 맞으면 그 대상을, 그렇지 않으면 해당 종류의 첫 대상을 선택한다. 대상이 없거나
`+ 새 …`를 누르면 첫 편집 때 새 구역/경로를 생성한다. 생성과 첫 획/점은 한 번의 실행 취소로
되돌릴 수 있다. 취소한 획과 유효 셀이 없는 구역 획은 빈 구역을 남기지 않는다.
레이어 숨김·잠금은 빠른 편집에도 그대로 적용한다.

**Space를 누르는 동안 화면 이동**, **D를 누르는 동안 지형 지우기**로 잠시 전환한다.
키를 놓으면 원래 도구로 돌아간다. 이미 시작한 획은 포인터를 놓을 때 같은 도구로 확정하며,
Esc로 취소할 수 있다. 기존 E/H 등의 도구 고정 단축키와 왼쪽 팔레트도 사용할 수 있다.

## 형식과 좌표

`format: "battle-map"`, `version: 1`인 편집기 전용 JSON이다. 코어 저장 형식이 아니다.
문서·구역·경로·경로 점·이름 있는 지점·임시 슬롯·웨이브·적 구성 항목은 안정적인 ID를 갖는다.
ID는 문서 전체에서 유일해야 한다. 알 수 없는 필드·버전, 중복 ID, 잘못된 타입·비유한 수는 거부한다.
파일 제한은 저장·읽기 모두 UTF-8 5MB, 맵 크기는 각 축 1~128셀이다. 누락 참조, 빈 경로, 음수 수량 등 작성 중
의미 오류는 진단하며 저장을 허용한다.

새 문서는 16×12 전체 유효 셀로 시작한다. 좌측 상단 원점, 오른쪽 +X, 아래쪽 +Y이며
셀 (x,y)는 `[x,x+1) × [y,y+1)`을 소유한다. 연속 좌표 단위는 셀이다.
기본 스냅은 `정수 + 0.5`, 고급은 N=2/4/8의 **셀 내부 분할선 교점**이다.
각 축에서 `정수 + k/N` (k=1…N−1)에 스냅하므로 모든 N에서 중심을 선택할 수 있다.
모드/N 변경은 입력만 바꾸며 기존 좌표를 재작성하지 않는다.
좌표·화면 변환·스냅·선분 통과 셀 검사는 `src/editor/coordinates.ts`가 소유한다.

`valid`는 셀 키 집합, `terrain`은 셀 키별 지형이다. 생략한 지형은 일반 바닥이다.
맵 정보에서 가로·세로를 늘리면 새로 포함된 범위를 유효 셀로 추가하여 바로 지형·구역을
칠할 수 있다. 기존 사각 범위 안의 구멍은 채우지 않으며, 보존된 범위 밖 데이터도 덮어쓰지 않는다.
크기 변경과 유효 셀 추가는 한 번에 실행 취소한다. 이미 저장된 빈 영역은 자동 보정하지 않는다.
이전 동작으로 확장해 빗금으로 남아 있는 범위는 유효 영역 추가(A)에서 Shift+드래그로 채울 수 있다.
구역은 `deploy`(아군 배치 가능) 또는 `spawn`(적 등장)이고 별도의 셀 집합을 갖는다.
배치와 등장은 같은 셀에 공존하지 않는다. 구역을 칠하면 그 셀을 반대 종류의 구역에서
제거하며, 속성 패널에서 종류를 바꾸면 변경한 구역의 셀이 우선한다. 같은 종류 구역의
겹침은 유지한다. 구역 ID와 웨이브 참조는 보존하고, 교체는 한 번의 이력으로 기록한다.
기존 파일의 겹침은 자동 삭제하지 않고 `ZONE_KIND_OVERLAP`으로 진단한다. 유지할 구역으로
다시 칠하거나 불필요한 구역 셀을 지우면 해결된다.
고지대가 배치 구역을 자동 생성하지 않는다. 지형 지우기는 일반 바닥으로 되돌리며 영역을 지우지 않는다.
유효 영역 제거·크기 축소는 기존 지형·구역·경로·지점을 보존해 진단한다. 맵 크기를 다시
늘리거나 영역을 다시 칠하면 보존 데이터가 다시 나타난다. 범위 밖 유효 셀 정리는 명시적인 별도 동작이다.

## 참조와 조건

삭제 전 영향을 안내한다. 다른 객체의 참조는 자동 변경하지 않고 끊어진 ID를 보존한다.
실행 취소는 같은 ID와 참조를 복원한다. 웨이브 복제는 웨이브·적 구성 항목에 새 ID를 발급하고
구역·경로·슬롯·지점·다른 웨이브 참조는 유지한다. 자기 참조만 복제 대상 자신으로 바꾸며
자기 참조/순환 진단은 그대로 남긴다.

시간 표시 단위는 초, 문서 단위는 밀리초다. 비정수 밀리초나 음수 시간은 진단한다.
HP 임계값은 0~100%, 도달 반경은 0 이상의 정수 셀이다.
전투 시간 / 선행 웨이브 정리 / 지정 개체 HP / 지정 개체 사망 / 지정 개체의 지점 도달을 지원한다.
비시간 조건에 선택적인 대체 발동 시각을 붙인다. 이는 만료가 아니라 기본 조건과 별개의
발동 기회이며, 동시 충족은 기본 조건 우선, 각 웨이브는 한 번 발동한다는 의미를 폼에 표시한다.
목록 순서는 정리 용도이며 조건 평가나 실행 순서로 해석하지 않는다.

조건의 개체 참조는 문서 내부 임시 보스 개체 슬롯이다. 적 콘텐츠 ID·수량과는 독립적이다.
실제 코어 슬롯 바인딩, 적 카탈로그 검증, 조건 평가, 전투 실행, 길 찾기는 구현하지 않았다.
선분의 빈 영역·장애물 통과 진단은 기하 검사이며 코어 이동 가능성 판정이 아니다.

## 책임과 이력

- `model.ts`, `coordinates.ts`, `operations.ts`: 데이터와 순수 편집 규칙.
- `serialization.ts`, `diagnostics.ts`: 구조 검사와 작성 중 의미 진단.
- `history.ts`: 단일 문서 원본, 스냅샷 이력, 잠금 검사, 선택 정리, 저장 기준.
- `files.ts`: 외부 파일 경계, 겹친 저장 제한, 오래된 비동기 결과 보호.
- `MapCanvas.tsx`, `Toolbox.tsx`, `Inspector.tsx`, `BottomPanel.tsx`, `WavePanel.tsx`, `fields.tsx`: 화면·입력 해석.
- `App.tsx`: 문서 교체, 단축키, 확인 대화상자와 패널 조정.

`EditorSession.commit`은 독립된 초안 준비 → 구조·잠금 검증 → 문서·이력·리비전 확정 →
구독자 알림 순서로 처리한다. 생성·열기·확정 시 문서 참조를 분리하고 중첩 객체까지 동결하여,
외부 입력 객체나 보관한 초안이 현재 문서와 과거 이력을 뒤늦게 수정하지 못하게 한다.
편집 콜백 안의 세션 변경과 Promise를 반환하는 비동기 편집은 거부한다. 비동기 준비는
확정 전에 끝내야 하며, 확정 전 실패는 기존 문서·이력·미저장 판정을 유지한다.
구독자 예외는 오류로 기록하고 다른 구독자 알림을 계속한다. 이미 확정된 편집이나
성공한 다운로드 요청을 알림 실패 때문에 취소·저장 실패로 판정하지 않는다.

`DocumentFiles.read`는 문서와 요청 번호·epoch·revision을 담은 준비 결과를 반환한다.
확인 후 `open`이 이를 다시 검사하고 문서를 교체한다. 새 문서 교체 확인에도 대기 중
epoch·revision 변경을 검사한다. 이 검사는 메모리 상태의 경계이며 디스크 쓰기 보장은 아니다.

이력은 최근 100개 변경을 보관한다. 실제 변경 없는 연산은 이력·다시 실행을 건드리지 않는다.
잠긴 레이어를 바꾸는 실행 취소도 잠금 해제 전에는 적용하지 않는다.
미리보기와 폼 버퍼, 줌·팬·선택·테마는 문서 밖에 둔다. 저장하는 문서 스냅샷은 이후 편집과
공유 변형하지 않는다. 다운로드 중 추가 편집은 다운로드 확인 후에도 미저장으로 남는다.
다운로드를 통한 파일 저장은 덮어쓰기 완료를 확인하지 않으므로 교체 시 자동 저장 후 진행하지 않는다.

## 검증과 제한

`npm run test`는 기존 Playwright 러너를 이용한 순수 모델 검사이며 서버·브라우저를 시작하지 않는다.
`npm run check`, `npm run build`, `npm run ui:inspect`로 정적·빌드·실제 화면 검사를 수행한다.
`tests/model/fixtures.ts`는 작은 맵, 비정형/구멍, 많은 경로·웨이브/긴 한글 이름,
빈 영역, 미완성 참조를 재현한다. 파일 실패와 완료 순서는 테스트 입출력 경계에서 제어한다.

Windows WebView2·Tauri 네이티브 파일 대화상자·IME와 설치 프로그램은 별도 검증 대상이다.
프로토타입은 브라우저 파일 선택/다운로드를 구현했다. 네이티브 파일 저장 어댑터는 없다.
