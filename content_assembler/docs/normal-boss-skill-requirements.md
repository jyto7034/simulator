# 일반보스 스킬의 콘텐츠 기반 작성 요구사항

2026-10-20 · 스킬 작성 명세 1차 구성

일반보스의 직원용 스킬 파편을 기준으로 작성 도구가 표현해야 하는 동작을 정리한다.
콘텐츠의 합의된 동작이 기준이며, 현재 Core의 타입이나 지원 연산을 표현력의 상한으로 삼지 않는다.
첫 상세 사례는 [Hello / Goodbye 작성 명세](hello-goodbye-spec.md)다.

## 범위와 기준

- 2026-10-21 사용자 합의: 현재 제작은 일반 보스 파편을 기준으로 진행하고 엘리트도 공통 기능으로
  수용한다. 엘리트의 후속 검토는 해당 콘텐츠 조정으로 반영한다. 최종보스는 설계 완료 뒤 별도 단계로
  추가하며 이번 구현의 선행 조건으로 삼지 않는다. [현재 제작 범위](project-purpose.md#현재-제작-범위--2026-10-21)를 따른다.
- 사용자가 일반보스 스킬의 동작 합의가 끝났고 기본 밸런스 수치가 남았음을 확인했다.
  이 작업은 합의한 콘텐츠를 작성 가능한 형태로 옮기는 작업이다.
- 대상은 일반보스에서 얻는 **직원용 스킬 파편**이다. 적 보스의 행동 그래프, 조우 진행,
  보상 지급, 장비 전체의 명세는 별도다. 파편 의미에 필요한 장비·유물 연결만 함께 기록한다.
- 아래 전체 목록은 [일반보스 로스터](../../core_enhanced/docs/content/abnormalities/README.md)를 따른다.
  최신 리워크 본문을 사용하며 이전 기록의 기능을 다시 섞지 않는다.
- 기본형과 문서에 합의된 개화형을 포함한다. 명시적으로 보류한 형태를 임의로 채우지 않는다.
  침식은 별도 사용 조건과 공통 판정을 가진 확장으로 남긴다. 옛 일괄 처형 문구를 기본 스킬로 가져오지 않는다.
- 여기서 사용하는 상태·사건·결과 이름은 작성 명세의 개념 이름이다. Rust 타입, 최종 JSON/RON,
  편집기 노드 목록이나 Core 변경 계획을 확정하지 않는다.

원문에 과거 `미정`·`후속` 표기가 남아 있더라도 합의한 구조를 다시 미합의로 돌리지 않는다.
수치는 매개변수로, 내용 충돌이나 실행 의미의 공백은 **원문 정합성 확인 항목**으로 기록한다.
명세 구성에 필요한 빈칸을 임의의 신규 게임 규칙으로 채우거나 모두 수치 문제로 숨기지 않는다.

## 게임 판정과 연출의 구분

게임 판정은 실제 대상·위치·자원·피해·상태·시간·사건 순서를 바꾸는 내용이다.
연출은 그 결과와 진행을 플레이어에게 보여주는 모습이다. 연출이 복잡하다는 이유로
게임 로직에도 동일한 수의 개체나 이동·충돌 계산을 요구하지 않는다.

| 구분               | 작성할 내용                                             | 예시                                           |
| ------------------ | ------------------------------------------------------- | ---------------------------------------------- |
| 게임 판정          | 입력, 대상 선택, 상태 변화, 효과 발생 시점, 결과와 종료 | 같은 범위에 큰 검 1회와 작은 검 여러 회의 피해 |
| 연출               | 모습·배치·동작·음향·카메라와 판정에 맞춰 표시할 시점    | 각 작은 검이 서로 다른 위치에 꽂히는 모습      |
| 연출과 판정의 연결 | 어느 실제 사건을 어떤 모습으로 표시할지                 | 큰 검 착지에 첫 범위 타격을 맞추기             |

연출의 위치·개수·이름만으로 새로운 피해 범위·타격 수·소환물·이동을 추론하지 않는다.
반대로 실제로 명시된 투사체 비행, 단계별 적중, 시간 정지와 재개는 장식으로 지우지 않는다.
아래의 최소 판정 표현은 구현 규모를 줄이기 위한 분석이지 현재 실행기의 구현 완료 판정은 아니다.

## 스킬별 동작 요구사항

각 항목의 ID는 작성 요소와 검토 사례에서 원래 콘텐츠로 돌아가기 위한 참조다.
수치가 들어간 합의도 보존하되 최종 밸런스 고정값으로 승격하지 않는다.

### NB01 증오의 여왕

- **시작과 입력:** 광선 방향용 타일 선택. 메뉴에서 광선·수동 블랙홀을 선택하며
  기본형 수동 블랙홀은 하트 3~5개, 개화형은 0~5개에서 사용한다. 공명 조건과 하트 조건을 구분한다.
- **판정 흐름:** 일반 광선은 고정 방향으로 집중하며 주기마다 적 피해와 아군 회복을 판정한다.
  끝까지 시전하면 하트 1개, 같은 시전에서 실제 적 피해와 실제 아군 HP 회복이 모두 있으면 추가 1개를 얻는다.
  두 보상은 완료 후 각각 한 번이며 대상 수·주기 수만큼 반복하지 않는다.
- **상태와 결과:** 파편 사본의 전투 로컬 하트, 자동 획득 타이머, 마지막 지정 타일,
  이번 시전의 피해 성공·회복 성공 기록을 구분한다. 하트 상한은 6이다.
- **다른 경로:** 수동 블랙홀은 보유 하트를 소비해 침식체 적을 반복 흡인하고 아군을 회복한다.
  개화형은 중심 빛기둥의 주기 피해·회복으로 이어진다. 하트 6개에서는 히스테릭 자동 시전으로
  블랙홀과 후속 공격이 아군·적군을 모두 공격하고 회복하지 않는다.
- **자동 전환:** 사용자 승인에 따라 진행 중인 시전과 완료 보상을 정리한 뒤 추가 공명 없이 시작한다.
  예약 중 새 수동 입력은 막고 Hard CC·침묵 해제를 기다린다. 실제 중단에는 소진·정상 복귀하며 자동 재개하지 않는다.
- **종료:** 히스테릭 종료 후 하트를 소진하고 정상 복귀한다. 하트는 후퇴·전투 종료·사망 시 초기화한다.
  자동 획득의 정지·재시작과 블랙홀 소비에 따른 타이머 초기화가 필요하다.
- **연출과 최소 표현:** 광선·블랙홀·빛기둥은 방향/중심과 주기 판정으로 표현할 수 있다.
  빛 입자마다 게임 객체를 만들 필요는 없다. 적 흡인은 실제 위치 변화이므로 판정에서 유지한다.
- **조정값:** 광선·블랙홀·빛기둥의 시간·주기·범위·피해·회복·흡인량, 하트별 증폭식.

- **P3 작성:** 기본형·개화형의 실제 그래프와 실제 결과/사본 자원/단계 집중 진단을 추가했다.
  [작성 계약](common-skill-graph-contract.md#실제-결과사본-자원단계-집중두-영역--p3-2026-10-22)을 따른다. 유물·침식형 대조와 Core 실행은 후속이다.

### NB02 웃는 시체의 산

- **시작과 입력:** 시전자 중심의 넓은 영역에 있는 유효한 적을 선택한다.
- **판정 흐름:** 기존 아군의 저지를 해제하고 시전자를 향해 추적하게 한다.
  도발·이동 속도 증가·시전자 1타일 이내 공격 제한을 같은 시간 동안 부여한다.
  원거리 기본 공격과 공격 스킬도 거리 제한을 적용받는다.
- **상태와 결과:** 대상별로 적용 출처와 공통 만료 시점을 보관한다. 새 근접 공격이나 무제한 저지를 만들지 않는다.
  도발 중에는 시전자만 새로 저지할 수 있으며 실제 접근 후 시전자의 원래 저지 수·조건을 적용한다.
- **종료:** 도발 출처의 세 효과를 함께 제거하고 원래 행동 규칙으로 돌아간다.
  파편은 직접 피해·기절·처형을 제공하지 않는다. 무기 `웃음`의 주 대상 기본 공격 막타 성장은 별도다.
- **연출과 최소 표현:** 적을 끌어모으는 모습은 기존 추적 이동과 행동 제약의 결과다.
  순간이동·벽 통과·흡인 물리 시뮬레이션을 새로 요구하지 않는다.
- **조정값:** 범위·형상·유지 시간·이동 속도 증가율. 1타일 제한은 별도 명시값으로 보존한다.
- **작성 상태:** P2 기본형 그래프·공통 대상 상태·진단·편집/저장 검증 완료. 도발 면역·경합·출처 이탈·공격 취소는
  원문의 2026-10-21 작성 정책을 따른다. 실제 전투 실행과 유물 자동 변형은 후속이다.

### NB03 녹아내리는 사랑 공격형

- **시작과 입력:** 장착 중 포자 출처를 가진 기본 공격에 대상별 감염 확률 판정을 연결한다.
  한 공격의 여러 피해 구간은 같은 적에게 최초 감염 판정을 중복 생성하지 않는다.
  액티브는 자기 출처의 감염체가 있을 때 별도 대상 입력 없이 일제 기폭한다.
- **판정 흐름:** 비감염 적은 최초 감염 확률을, 이미 감염된 적은 같은 출처 무기 피격 시 전파를 사용한다.
  사망도 전파하며 치명타격은 피격·사망 전파를 중복하지 않는다. 새 감염체는 같은 전파 처리에서 즉시 재전파하지 않는다.
- **상태와 결과:** 파편 사본별 감염망과 연속 수치인 감염 위력을 구분한다. 살아 있는 감염체 수·유지 시간에 따라
  위력이 성장하고 각 숙주의 주기 피해가 현재 위력을 읽는다. 감염체 0명에서는 유예 후 자연 감소한다.
- **기폭과 종료:** 현재 위력으로 기준 피해를 고정하고 숙주 위치마다 폭발한다. 숙주에는 배율 피해 한 번을 주며
  자신의 기본 폭발 피해를 더하지 않는다. 기본은 기폭 전체에서 대상당 한 번, 중첩된폭발 유물은 폭발별 한 번이다.
  감염과 위력을 전량 소비하고 기폭으로 재감염·사망 전파를 만들지 않는다. 후퇴·전투 종료 시 감염망을 폐기한다.
- **연출과 최소 표현:** 감염 흔적·포자 이펙트는 숙주 상태를 표시한다. 포자 입자마다 이동체를 만들지 않는다.
  실제 전파는 출처별 유한 후보 선택과 상태 부여이며, 타일 오염을 남기는 NB09와 구분한다.
- **조정값:** 최초 감염률·전파 범위/수·위력 성장·유예·감쇠·주기·피해식·숙주 배율.

### NB04 절망의 기사

- **시작과 입력:** 메뉴에서 가호 대상 1명을 지정·해제·교체한다. 자기 지정도 가능하다.
  기본형 일반 상태의 시전은 다음 기본 공격을 연속기로 바꾸고, 개화형은 공격할 타일을 선택한다.
- **공통 상태:** 가호의 타이머, 파편의 검 수·긴급 보호막 전투당 사용 기록·절망 전환 예약을 구분한다.
  가호 교체로 보호막 사용 기록을 초기화하지 않는다. 검 기본 상한은 4이며 유물의 획득·한도 변경 지점이 있다.
- **기본형 일반:** 찌르기 후 시작 검 수로 단계당 소비량을 한 번 정한다.
  네 단계가 검을 각각 소비하고 공격 직후 상처를 부여한다. 앞 단계의 상처는 뒤 단계에 반영한다.
  대상 사망 시 남은 단계는 종료하고 아직 시작하지 않은 단계의 검은 소비하지 않는다.
- **절망 전환:** 가호 대상의 HP 0 퇴각에서 예약하고 현재 행동 종료 후 다음 행동 직전에 전환한다.
  수동 철수는 조건이 아니다. 검 수에 따른 보호막 무시 자기 피해는 검을 소비하지 않는다.
- **기본형 절망:** 별도 시전으로 엑시큐션을 시작한다. 검을 보존하며 같은 총시간에 타수를 늘린다.
  시전·대상에 귀속된 후속 타격 증폭을 사용하고 일반 상태의 상처와 구분한다.
- **개화형:** 일반은 큰 검 방출 시 검 전량을 소비하고 큰 검 뒤 작은 검이 동일 범위를 순차 타격한다.
  절망은 검을 보존하며 범위 주기 피해·상처와 별도의 주기 자기 피해를 유지한다.
  검 수는 최대 유지 시간에 연결한다. 만료·직접 중단·사망·행동 차단 제어·침묵에 종료하며 기존 상처는 자체 수명을 따른다.
- **연출과 최소 표현:** 부유·자기 관통·낙검·바닥에서 솟는 검은 연출이다. 작은 검의 시각적 위치가
  실제 범위를 나누지 않으며 각 검의 물리 이동체도 필수가 아니다. 다만 합의된 순차 타격과 두 주기는 실제 사건이다.
- **조정값:** 검 생성 주기·피해 계수·단계 간격·총 공격 시간·타수·유지 시간 함수·범위·가호 경감률.

- **P4 작성:** 기본/개화 실제 그래프에서 관계 수명·단계 소비·예약 전환·반복·두 주기를 표현한다. Core 실행과 장비/유물 조합은 후속이다.

### NB06 파고드는 천국

- **시작과 입력:** 유한한 최대 유지 시간을 가진 집중을 시작하고 장판을 유지한다. 직접 취소할 수 있다.
- **판정 흐름:** 대상별 체류 시간에 따라 둔화를 진행해 기절에 도달한다. 기절 전 이탈은 둔화와 진행도를 지우고,
  재진입은 처음부터 시작한다. 도달한 기절은 장판 종료까지 유지한다.
- **상태와 결과:** 장판의 수명과 대상별 제어 진행도를 구분한다. 진입 즉시 적용하는 받는 피해 20% 증가는
  기절 면역과 독립적이며 범위 이탈·장판 종료 때 해제한다. 장판 자체의 직접 피해는 없다.
- **종료:** 집중 종료 시 장판과 그 출처의 둔화·진행도·기절·기본 피해 증폭을 제거한다.
  긴 호흡은 최대 집중 시간에, 제어 진행 가속은 기절 도달 속도에 연결한다.
- **연출과 최소 표현:** 빨간 눈은 집중 표시이며 공격하거나 피격되는 소환물이 아니다.
  장판 한 개와 대상별 체류 기록으로 필요한 판정을 설명할 수 있다.
- **조정값:** 최대 집중 시간·제어 곡선·기절 도달 시간·범위와 각 증폭률.

### NB07 붉은 두건의 용병

- **시작과 입력:** 전투 시간으로 일반 창을 얻고 별도 사냥감 늑대 처치로 강화 창을 얻는다.
  준비 시 전투를 멈추고 사격 방식·배치 재사용 여부·창별 타일·방향을 입력한다.
- **판정 흐름:** 정밀 사격은 배치 순서대로 방향을 기록한다. 집중 사격은 공통 목표 타일에서 창별 방향을 계산한다.
  조준 클릭은 피해나 발사를 발생시키지 않는다. 재사용은 배치만 가져오며 방향은 새로 정한다.
- **상태와 결과:** 보유 창과 임시 배치·사격 계획을 구분한다. 창 종류·원점·방향·순서를 가진 전체 계획을
  검증한 뒤 창·공명 소비, 전체 동시 방출, 전투 재개를 함께 확정한다.
- **전달과 종료:** 방출 뒤 각 탄환의 실제 비행·충돌·관통을 처리한다. 강화탄의 피해와 2초 속박은 별도 효과다.
  확정 전 단절은 임시 입력 폐기·미소비·정지 유지, 확정 후 응답 유실은 이미 확정한 소비·발사를 되돌리지 않는다.
- **연출과 최소 표현:** 창에 두건이 나타나고 직원이 사라지는 모습은 조준 연출이다.
  직원의 실제 배치·점유·저지를 옮기지 않는다. 반면 별도 사냥감 늑대와 발사된 탄환은 실제 게임 대상·전달이다.
- **조정값:** 획득·출현 주기·보유량·배치 범위·일반/강화 피해·탄환 속도·폭·길이·관통 한도.

- **P4 작성:** 장착 중 실제 적 늑대 출현·독립 재고·정지 입력·원자적 동시 방출을 실제 그래프로 작성했다. 조준 게임 UI와 전투 실행은 후속이다.

### NB09 죽을 나비의 장례

- **시작과 입력:** 기본형은 이동 경로 타일들을 덮고 지연 후 해당 타일 위의 적을 폭발로 공격한다.
  단일 방향 사격으로 축소하지 않는다.
- **개화 상태:** 전용 무기 피해가 유닛의 나비 스택을 만들고 사망 시 해당 타일로 옮긴다.
  시전 시 타일 스택과 그 타일의 유닛 스택을 합산한다. 개화에 따른 무기의 미니건 승급은 지속적인 장비 변화다.
- **계산과 결과:** 기초스택과 몫인 결과스택을 구분한다. 결과스택 0은 기초스택 횟수의 일반 폭발,
  1 이상은 결과스택 횟수의 해당 등급 폭발이다. 각 차례 안의 대상 중복 제한과 다음 차례의 재적중을 구분한다.
- **변형과 종료:** 범위 증가와 중첩된폭발의 적용 지점이 다르다. 전용 구체는 조건을 만족하면
  기존 폭발을 대체하고 모은 스택을 소비한다. 일반 등급별 폭발의 소비 세칙은 원문 정합성 확인에 남긴다.
- **연출과 최소 표현:** 경로를 채우는 나비는 타일 집합·예고·지연 폭발로 표현할 수 있다.
  나비마다 경로 탐색하는 유닛은 필요하지 않다. 등급 색은 전용 연출이다. 차례별 실제 피해는 유지한다.
  전용 구체의 전투 정지·재개는 화면 효과만으로 대체하지 않는다.
- **조정값:** 확산/대기 시간·등급 임계치·폭발 계수·차례 간격·구체 전환 기준과 위력.

### NB10 아무 것도 없는

- **시작과 입력:** 공명 만충에서 Hello를 시작한다. 유지 중의 재입력은 추가 공명 없이 Goodbye를 사용한다.
- **판정 흐름:** 일정 시간 기본 공격을 직선 관통으로 교체한다. 재입력하면 남은 시간을 포기하고
  그 값에 따라 강해지는 전방 광역 일격을 사용한다. 자연 만료에는 마무리를 자동 발동하지 않는다.
- **상태와 결과:** 변형 수명, 개별 기본 공격의 관통 이력·실제 HP 피해 합계, 마무리의 잔여 시간 값을 구분한다.
  Hello 피해는 무기의 직접 기본 공격, Goodbye는 파편의 직접 스킬 피해다.
- **종료:** 같은 Hello의 마무리는 한 번만 사용한다. 변형이 끝나면 원래 기본 공격으로 복귀한다.
  파편 자체에 흡혈·재생·부활을 추가하지 않는다.
- **연출과 최소 표현:** 포신·생체 칼날은 같은 직원의 외형 변화다. 무기 종류·배치 위치·저지·직원 개체를
  교체할 이유가 없다. 공격 교체 상태와 종료 분기로 표현한다.
- **조정값:** 변형 지속 시간·관통 공격 profile·마무리 범위·남은 시간별 위력 함수.
  상세는 [별도 명세](hello-goodbye-spec.md)를 따른다.

### NB11 탐욕의 왕

- **시작과 입력:** 시전을 시작해 포탈을 전개하고 재입력으로 이번 사출량을 확정한다.
  포탈 하나가 실제 생성될 때 재고 1을 소비한다. 방출·적중 때 중복 청구하지 않는다.
- **상태와 결과:** 파편 인스턴스에 재고, 대여 사용 기록, 다음 전투로 이어지는 미상환액을 둔다.
  전투마다 기본 10 지급, 자동 대여 잔고 하한 −20, 대여 사용 다음 전투에는 대여 불가라는 구조를 보존한다.
  양수 재고는 이월하지 않고 채무는 차감 지급으로 정산한다.
- **전개와 종료:** 전투 시간의 발사 기한과 포탈 붕괴를 관리한다. 재입력 후 확정한 준비 보구는
  뒤 차례를 기다린다는 이유로 붕괴하지 않는다. 붕괴·취소·중단의 재고와 대출은 환불하지 않는다.
- **실제 공격:** 자신의 회수 상태가 없는 유효 적을 우선해 루트 진행도로 선택한다.
  한 발의 실제 착탄·범위 피해·상태 부여·사망·재고 회수까지 마친 후 다음 대상을 선택한다.
  빗나가 종료된 전달도 다음 선택으로 진행한다. 처치 회수는 확정된 이번 사출량을 늘리지 않는다.
- **외부 사건:** 자기 귀속 피해는 적에게 회수 상태를 부여·갱신한다. 막타 주체와 무관하게 유효한
  사망마다 같은 출처 재고를 한 번 얻는다. 치명타격도 부여 후 사망·회수 순서를 보존한다.
- **연출과 최소 표현:** 포탈과 보구를 드러내는 모습은 준비 목록·수명·소비 사건으로 표현할 수 있다.
  포탈 각각에 AI·충돌·HP를 붙일 근거는 없다. 실제 보구 비행과 착탄 완료 후 다음 선택은 필수 판정이다.
- **조정값:** 전개 곡선·상한·기한·붕괴 간격·회수 상태 시간·피해·비행 속도·반경.
  무한 사출의 HP 비용은 전용 유물 경로에만 둔다.

- **P4 작성:** 사본 원장·실제 생성 비용·사출 수 고정·착탄 정산 뒤 선택을 실제 그래프로 작성했다. 원장 승계와 유물 조합, Core 실행은 후속이다.

### NB13 음양

- **시작과 입력:** 두 위치를 지정해 독립된 음·양 영역을 만든다.
- **판정 흐름:** 각 주기에 현재 영역의 아군에게 기본 회복을 적용하고 실제 HP 상한 때문에 남은 양의 일부를
  반대 영역 부상 아군에게 전달한다. 빈 영역에서는 전달량을 만들지 않으며 전달 초과분은 재전달하지 않는다.
- **상태와 결과:** 영역 두 개의 소속 시전, 각 주기의 대상 집합·회복 결과·전달 예산을 구분한다.
  사용자 승인에 따라 기본 회복은 한 번만 적용하고 교집합에는 기본 공격 속도 증가를 부여한다.
  기본형은 적 피해·아군 HP 대가를 요구하지 않는다.
- **초기값과 종료:** 현재 수치는 미정이다. 첫 회복은 한 주기 뒤, 종료 시각에는 정리가 우선한다.
  새 생성 성공 시 같은 사본의 이전 두 영역을 교체하고 사망·철수·전투 종료에 정리한다.
  과거 12초·1초·공격 속도 +10 시험값은 현행 기본값으로 가져오지 않는다.
- **연출과 최소 표현:** 두 영역의 모양과 순환하는 시각 효과가 별도 회복 투사체를 요구하지 않는다.
  실제 회복 결과 집계·영역 관계·추가 회복으로 설명할 수 있다. 숨겨진 용 전환은 별도 유물 경로다.
- **조정값:** 범위·지속 시간·주기·회복 계수·전달률·교집합 버프 값. 최초 판정·중복 집계 등의 의미는 수치와 구분한다.

- **P3 작성:** 두 위치 원자 접수, 독립 두 영역, 기본 결과/전달 결과 타입 분리와 교집합 기여분을 실제 그래프로 작성했다.
  [작성 계약](common-skill-graph-contract.md#실제-결과사본-자원단계-집중두-영역--p3-2026-10-22)을 따른다. 용 유물 전환·침식형과 실제 실행은 후속이다.

## 밸런스와 의미를 다루는 방식

값마다 이름·단위·적용 지점·기존값의 지위를 기록한다. 예를 들어 변형 지속 시간은 초,
관통 길이는 거리, 회복 비율은 비율이며 같은 숫자로 취급하지 않는다.
현재 문서의 합의값·초기 테스트값·미기입값을 구분하고 새 기본값을 채우지 않는다.

| 분류            | 처리                                  | 예시                                                 |
| --------------- | ------------------------------------- | ---------------------------------------------------- |
| 합의 동작       | 콘텐츠 요구로 고정                    | 두건은 전체 동시 발사, 탐욕은 착탄 완료 후 다음 선택 |
| 밸런스 매개변수 | 동작을 유지하면서 조절                | 피해 계수·지속 시간·획득 주기                        |
| 명시된 시험안   | 시험안 상태로 참조                    | 음양의 교집합 공격 속도 +10과 배분 방식              |
| 원문 정합성     | 원문 위치와 필요한 의미를 연결해 기록 | Hello 도중 공명 획득 서술과 공통 사용 잠금의 관계    |
| 보류·외부 기능  | 활성 기능에 자동 포함하지 않음        | 두건 개화형, 녹아내리는 사랑 방어형, 장비의 부활     |

수치 조정으로 해결되지 않는 원문 항목에는 같은 시각 사건의 우선순위, 취소·재입력 자격,
대상 집계·동률·중복, 일반 폭발의 소비 범위 등이 있다. 이 목록을 새 승인 절차나 전체 작업의
중단 조건으로 만들지 않는다. 상세 사례를 작성할 때 관련 원문과 함께 확인할 지점으로 둔다.

## 상세 명세를 확장하는 순서

현재 작업 순서·완료 조건·진행 위치는 [임시 파이프라인](skill-authoring-pipeline.tmp.md)에서 관리한다.
다음 구현 대상은 **파고드는 천국**이며 새 그래프의 Core 실행은 후속 연동 단계다.
아래는 10월 20일의 명세 검토 순서로, 요구사항 누락을 대조하는 자료다.
콘텐츠 설계를 다시 승인받는 순서로 사용하지 않는다.

1. **Hello / Goodbye:** 상태·공격 교체·재입력·시간 값·출처·종료를 끝까지 표현한다.
2. **증오의 여왕:** 실제 결과 집계와 자원에 따른 자동 전환을 추가한다.
3. **붉은 두건:** 임시 입력 계획과 확정, 동시 방출과 개별 적중을 분리한다.
4. **음양:** 여러 영역과 실제 초과 회복의 집계·분배를 추가한다.
5. **절망의 기사·탐욕의 왕:** 행동 완료를 기다리는 전환, 단계 소비, 실제 착탄 대기와 전투 사이 상태를 검토한다.
6. **녹아내리는 사랑·죽을 나비의 장례·파고드는 천국·웃는 시체의 산:** 출처별 전파,
   공간 집계, 중복 적중, 상태 종료와 행동 관계를 검토한다.

각 단계의 완료 기준은 원래 스킬을 게임 판정·연출·조정값으로 다시 표현하고,
동작이 설명 문자열 속에만 숨거나 기존 편집기/Core의 한계 때문에 누락되지 않는 것이다.
최종 구현 지원 여부의 대조는 이 작성 명세를 기준으로 별도 수행한다.

실행 가능한 파일로 가장하지 않는다. Core 소스·데이터·문서와 편집기 제품 코드는 변경 대상이 아니다.
