# 추가 경계 작성과 67개 요구 대응

[진입점·S 계약·V 진단](ai-skill-authoring-examples.tmp.md) · [구조 초안](ai-skill-authoring-data-model.tmp.md)

A1~A5는 부분 작성이다. 입력·전이·관측을 구체화하며 해당 스킬 전체 검증을 주장하지 않는다.
원문 링크와 요구 ID가 역방향 근거이고 실행/거래 키는 구조 제안이다. case 수치는 설명용이며 콘텐츠 변경이 아니다.
모든 사례는 수작업 의미 대조로, 실행 시험이 아니다.

## 1. A1 붉은 두건 — 다중 입력과 전술 정지
