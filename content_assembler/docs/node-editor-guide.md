# 노드 편집기 사용과 계약

상단 **노드**를 열면 빈 그래프로 시작한다. **새 그래프**는 새 빈 문서를 만든다.
**그래프 목록**에서 저장 폴더의 파일을 선택해 기존 작업을 연다.
[Hello / Goodbye 스킬 파편](hello-goodbye-node-guide.md)도 이 목록에서 연다.
포트와 연결·스킬 동작을 작성하지만 계산·전투 동작을 실행하지 않는다.
Blender/Godot에서 참고한 경로와 적용 판단은 [분석 기록](node-editor-reference-analysis.md)을 따른다.

## 편집

- 캔버스 위에서 마우스 휠만으로 확대·축소한다. 가운데 버튼을 끌면 화면을 이동한다.
- 왼쪽 목록, `Shift A`, 빈 캔버스 우클릭으로 노드를 추가한다. 검색은 이름과 분류를 대상으로 한다.
- **그래프 탐색**에서 노드·프레임을 선택해 해당 위치로 확대 이동한다.
- 출력 포트에서 입력 포트로 끌어 연결한다. 포트 이름을 클릭하면 키보드로 대상을 선택할 수 있다.
- 연결 끝을 끌어 재연결한다. 빈 곳에 놓거나 Escape로 취소하면 기존 연결을 보존한다.
  연결을 선택한 뒤 속성 패널에서도 양 끝을 변경할 수 있다.
- 새 연결을 빈 곳으로 끌면 호환되는 노드를 추가할 수 있다. 노드 추가와 연결은 Undo 한 건이다.
- 연결을 더블 클릭하거나 연결 속성의 **경유 노드 삽입**으로 선을 나눈다.
- 제목을 끌어 이동한다. Ctrl/Command 클릭 또는 빈 공간의 영역 선택으로 여러 항목을 선택한다.
  한 번의 드래그는 한 번의 Undo이며, Escape는 미확정 위치를 취소한다.
- 노드를 선택하면 직접 연결된 입력·출력 선도 테두리와 같은 색으로 굵게 강조한다.
  여러 노드를 선택하면 각 노드에 연결된 선을 함께 강조하며, 선택을 해제하면 원래 색으로 돌아간다.
  연출 연결의 점선은 유지한다. 연결선 자체의 선택과 구분되어 문서·편집 이력은 바뀌지 않는다.
- Ctrl D로 복제하고 Ctrl C/V로 복사/붙여넣는다. 선택 내부 연결만 복사하며 새 ID를 발급한다.
- Ctrl G 또는 **묶기**로 프레임을 만든다. 프레임 이동은 소속 노드를 함께 이동한다.
  **풀기**는 소속을 해제한다. 프레임은 시각적 묶음이며 함수나 실행 단위가 아니다.
- Delete는 선택 항목과 관련 연결을 함께 삭제한다. 프레임 삭제에는 소속 노드가 포함된다.
  Ctrl Z / Ctrl Shift Z 또는 도구 버튼으로 복원한다.
- 우클릭 또는 Shift F10으로 복제·복사·묶기·풀기·삭제 메뉴를 연다. Escape로 닫는다.

속성은 **변경 적용**으로 확정하거나 **취소**로 되돌린다. 입력 중에는 다른 문서 편집을
잠시 막아 미적용 값이 다른 대상에 반영되지 않게 한다. **저장**은 미적용 속성을 먼저
확정하며 유효하지 않은 값이면 저장하지 않는다. 위치 입력과 일반 속성 입력은 별도 적용
단위다. 캔버스의 가운데 버튼·스크롤과 확대 도구로 화면을 이동하고 **전체 보기**로 맞춘다.

스킬 노드는 카드와 속성 패널에 **상태 선언·시작 사건·실행 동작·설정값·값 계산·연출**의
역할을 표시한다. 역할은 노드 종류에 따른 안내이며 별도 저장 속성이 아니다.
상태 참조와 값 연결은 실행 순서를 뜻하지 않는다. 연결 목록에는 포트의 표시 이름을 사용한다.

## 저장·열기·진단

파일은 `*.node-graph.json`, `format: "node-graph"`, `version: 1`이다. 노드 종류·ID·포트
참조·속성·위치·프레임을 저장한다. 선택·줌·열린 메뉴·Undo 기록은 파일에 포함하지 않는다.
기존 스킬 초안 JSON과는 별도 형식이다.

**그래프 목록**(Ctrl+O)은 현재 저장 폴더의 노드 파일 목록을 연다.
목록 상단에 실제 경로를 표시하며, 개발 환경에서는 프로젝트의 `content/`를 사용한다. **저장**은 같은 폴더에
파일을 기록하고, 완료된 파일을 저장 기준으로 삼는다. 새 파일의 이름 충돌이나 열기 이후
발생한 외부 변경은 덮어쓰지 않는다. 실제 폴더 경로는 대화상자에 표시한다.
다른 위치의 파일은 **다른 위치에서 가져오기**로 읽는다.

다운로드 사본은 **JSON 내보내기**로 만든다. 이 경우에만 파일을 확인한 뒤 **다운로드 확인**을
눌러 저장 기준을 반영한다. 저장/다운로드 이후 추가 편집은 미저장으로 남는다. 저장 실패나
잘못된 파일 열기는 현재 문서와 이력을 보존한다. 미저장 문서 교체에는 확인 대화상자를 표시한다.

없는 ID/포트, 중복 ID, 잘못된 자료형과 좌표, 지원하지 않는 필드/버전은 거부한다.
연결하지 않은 필수 입력과 순환/순환 의존은 작성 진단으로 남기며 저장할 수 있다.
순환을 허용한다는 것은 반복 실행 의미가 정의되었다는 뜻이 아니다.

입력 제한은 노드 2,000개, 연결 8,000개, 프레임 200개, JSON 5MB다. 이 제한 전체의
렌더링 성능을 보장한다는 뜻은 아니다. Undo는 최근 100건 또는 패치 32MB까지 보존한다.
문서 교체 시 이력과 이전 파일 작업의 문서 버전을 무효화한다. 파일 읽기·클립보드 준비 후
문서가 바뀌었다면 오래된 결과를 적용하지 않고 현재 작업을 보존한다.

## 책임과 검증 범위

`src/nodes/core/`의 TypeScript 코어가 문서·기본값·포트 계약·편집·검증·이력을 소유한다.
React Flow는 확정 문서를 표시하고 선택·뷰포트·드래그 미리보기를 담당한다.
포인터 이동마다 편집 확정이나 전체 문서 직렬화를 수행하지 않는다.
`store.ts`가 동기 편집 결과를 화면에 알리며, 구독자 오류가 확정된 편집을 되돌리지 않는다.

브라우저와 Tauri 화면은 같은 TypeScript 코어를 사용한다. 노드 편집에 Cargo, 전용 IPC,
편집 연산에는 Vite 개발 브리지가 필요하지 않다. 프로젝트 폴더의 파일 입출력은 Vite의
로컬 파일 API 또는 Tauri 명령으로 처리한다. 기존 `node-graph` version 1 저장 형식을 유지한다.
Windows WebView2·IME·실제 파일 다운로드는 WSL Chromium 검증과 별도로 확인해야 한다.
구현 검사와 성능의 실제 측정 범위는 [검증 기록](node-editor-validation.md)에 기록한다.

프런트엔드 의존성 고지는 `public/third-party-notices.txt`에 있다. 제거한 Rust 노드 코어의
별도 고지 생성기는 사용하지 않는다. Tauri 호스트와 OS 라이브러리의 배포 고지는 별도 범위다.
