## 1. 기준선과 방법

최초 요청의 이관 전 기준은 사용자 후속 정정으로 대체했다. 최신 위키의 일반보스 합의와 엘리트 잠정안을 적용한다.
기존 dirty/untracked 변경을 보존하고 이번 문서만 편집한다. commit만으로 dirty 소스를 식별하지 않는다.

- 초안 요구사항 SHA-256: `fd180fba6918fd3f31d0cefe32c11230c1c11a038bdf6c9d508793181651a534`.
- 초안 문서 사본·참조파일 134개의 해시 목록: 로컬 작업 증거 `/tmp/ai-skill-stage1-20261023/review/draft-manifest.json`.
  manifest SHA-256: `50f7e9fdf0420442df5055d43cf0c65ed412e281edc33be8590c8fee93c905fd`.
  임시 증거 위치는 저장소 산출물이 아니며 장기 보존을 보장하지 않는다. 본문에 필요한 발견·근거·결과는 이 기록에 남긴다.
- 초안 고정 후 요구사항을 수정하지 않고 원문, K 경로의 주장 범위, 링크/ID와 대표 사례를 대조했다.
- 아래 발견을 먼저 기록하고, 그 다음 교정한다. 교정 후 다시 원문/영향 행을 확인한다.
- 실행 테스트를 읽은 것과 실행한 것을 구분한다. Rust/UI/Unity 테스트를 수행하지 않았으며 지원 전체를 PASS로 보고하지 않는다.

## 3. 교정 및 2차 재검토

교정 전 기록 완료. 교정과 재검토 결과는 후속으로 아래에 추가한다.

2차 원문 대조 중 추가 발견 R06: E05-a와 F04가 태아의 기본/일반 단일 전환/침식된 단일 전환 **유물**을
파편 기본/개화/침식형처럼 표현했다. 태아 원문의 수치·유물 적용 표는 +20%/+15포인트,
+40%/+20포인트, +80%/+30포인트의 대체값이며 이전 값과 합산하지 않는다.
포큐버스도 단일 전환 유물의 형태를 별도 파편 형태로 추정할 근거가 없다. 확신 높음, 원인은 ‘침식’ 용어의 범위 혼동이다.
E05-a/b·F04를 교정하고, 지원형 침식 파편을 새로 만들지 않았는지 및 시작 자격·수혜자 제외를 다시 확인한다.
이 추가 교정 전까지 2차 판정은 교정 필요다.

## 5. 검사와 보존 범위

- `content_assembler`에서 `npm run check` **통과**: TypeScript 검사, ESLint, 저장소 Prettier 검사, 노드 계약 export 대조.
  이후 변경은 문서의 교정·상태/검토 기록뿐이며, 마지막 변경 5문서의 Prettier 검사와 링크/ID 검사도 다시 수행했고 통과했다.
- 문서 검사: 요구 행 67개/중복 ID 0, 스킬별 요구 표의 6열, 장비22계열의 출처·요구 행, 전체 5문서의 참조 정의와 로컬 대상 존재를 확인했다.
  첫 링크 검사에서 URL 인코딩된 괄호를 해제하지 않아 기존 정상 링크를 누락으로 보고했다. 검사 도구에 URL 해석을 적용해 재실행했고 실제 깨진 링크는 0이다.
- 초안 이후 해시로 비교한 제품 코드·콘텐츠 참조 파일은 변경되지 않았다. 기존 사용자 변경을 reset/clean하거나 전체 저장소 format을 실행하지 않았다.
- 도구 실행 중 `python` 실행파일 부재와 한 차례 작업 디렉터리 기준 경로 오류는 `python3`와 저장소 루트 경로로 고쳐 재실행했다. 제품/문서 의미 결함과 구분한다.
- Rust runtime 테스트·UI/스크린샷·Windows WebView2/Tauri IPC·Unity 재생·새 포맷 AI 사용성은 **미실행**이다. 문서 변경의 필수 검사가 아니며, 이번 결과로 완료를 주장하지 않는다.
- 최종 자체 재검토 범위의 미해결 문서 결함은 없다. U 등록부의 콘텐츠 미정과 종단 경로 미확인은 다음 단계의 명시적 입력이며, 1단계 조사 완료를 막는 숨긴 누락으로 처리하지 않는다.

사용자에게 필요한 점검은 일반보스 최신 의도·보류범위와 엘리트 잠정안의 방향이다.
새로운 게임 의미의 판단이 필요하기 전까지 단계별 전체 재승인을 요구하지 않는다.
