# 외부 설계 참고 자료

이 폴더는 우리 스킬 노드 그래프를 설계할 때 비교할 외부 프로젝트를 보관한다.
2026-10-21 사용자 합의로 Forge를 선정하고, 웹 링크를 매번 열지 않아도 코드·문서·테스트를
직접 검색할 수 있도록 내려받았다. 후속 작업자와 AI가 같은 검토 버전을 참고하는 것이 목적이다.

| 사본           | 참고 목적                                                                                     |
| -------------- | --------------------------------------------------------------------------------------------- |
| `forge/`       | 엔진 독립적인 Statescript 실행 구조, 상태와 효과의 소유권, 종료·취소·재실행 처리, 테스트 사례 |
| `forge-godot/` | Godot의 그래프 작성·저장·로더와 실제 스킬 샘플                                                |

두 사본은 분석용 외부 소스다. 우리 제품의 구현 완료나 사용 라이브러리 목록을 뜻하지 않는다.
우리 목표는 **스킬 그래프 → Core 검증·컴파일 → IR → RON → 게임 실행**이며,
Forge를 활용하는 범위는 필요한 설계 원리와 검증 사례의 선별 적용이다.

처음 읽는 작업자는 [설계 참고와 적용 기준](../content_assembler/docs/forge-statescript-reference.md)의
‘처음 작업하는 사람과 AI의 읽기 순서’와 ‘Statescript 실행 구조 안내’부터 확인한다.
채택 원리, 우리와의 차이, 고정 커밋, 로컬 파일 지도, 복구·갱신 방법도 그 문서에서 관리한다.
진행 상태는 [스킬 작성 파이프라인](../content_assembler/docs/skill-authoring-pipeline.tmp.md)을 따른다.

우리 안내 문서는 저장소 관리 대상이고, 두 외부 사본은 루트 `.gitignore`에서 제외한다.
새 환경에 사본이 없으면 기준 문서의 복구 명령을 사용한다. 버전 정보와 정책을 이곳에 중복 기록하지 않는다.
